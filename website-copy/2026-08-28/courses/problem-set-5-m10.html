Problem Set 5: Relations and Functions

Mathematics 10 - Chapter 5 Medium

Problems

Problem 1

Determine if the relation \(\{(1,2), (2,3), (3,4), (4,5)\}\) is a function.

Problem 2

Find the domain and range of \(f(x) = \sqrt{x-3}\)

Problem 3

If \(g(x) = 2x^2 - 5x + 1\), find \(g(-1)\) and \(g(0)\)

Problem 4

Find the distance between \((2, 3)\) and \((7, 11)\) using \(d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}\)

Problem 5

Find the domain of \(f(x) = \frac{1}{x+2} + \sqrt{2x-4}\)

Problem 6

Given the table: \(x: -2, 0, 1, 3, 5\) and \(y: 5, 2, 1, 3, 7\). Is this a function? What is the domain and range?

Problem 7

Find the midpoint of the line segment joining \((4, -2)\) and \((-6, 8)\)

Problem 8

Determine if \(f(x) = x^2 + 3x - 2\) is even, odd, or neither by checking if \(f(-x) = f(x)\) or \(f(-x) = -f(x)\)

Bonus Problems

Bonus Problem 1 Medium

Domain Detective: A function is defined by \(f(x) = \sqrt{9 - x^2}\). Without graphing, determine the maximum value that \(f(x)\) can output. What geometric shape would the graph of the relation \(x^2 + y^2 = 9\) form?

Bonus Problem 2 Hard

Composite Function Puzzle: Given \(f(x) = x^2\) and \(g(x) = x + 3\), find all real values of \(x\) such that \(f(g(x)) = g(f(x))\). Then, if \(h(x) = 2x - 1\), find \(f(g(h(x)))\).

Bonus Problem 3 Hard

Distance Mystery: A point \((x, y)\) is equidistant from both \((2, 3)\) and \((6, -1)\). Without using the distance formula directly, find the equation of the line where all such points must lie. What is the significance of this line?
