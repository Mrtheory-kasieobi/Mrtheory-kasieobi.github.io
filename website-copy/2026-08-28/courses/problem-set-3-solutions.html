Problem Set 3 Solutions: Quadratic Functions

Precalculus 11 - Solutions
Topics: Quadratic Functions, Vertex Form, Transformations

Solutions

Problem 1

Convert \(f(x) = x^2 + 6x + 5\) to vertex form and identify the vertex.

Solution:

Complete the square: \(f(x) = (x^2 + 6x + 9) - 9 + 5 = (x + 3)^2 - 4\)

Vertex form: \(f(x) = (x + 3)^2 - 4\)

Vertex: \((-3, -4)\)

Problem 2

Find the x-intercepts of \(f(x) = x^2 - 5x + 6\) by factoring.

Solution:

Factor: \(x^2 - 5x + 6 = (x - 2)(x - 3) = 0\)

x-intercepts: \(x = 2\) and \(x = 3\)

Problem 3

For \(f(x) = -2(x - 3)^2 + 5\), identify the vertex, axis of symmetry, and direction of opening.

Solution:

Vertex: \((3, 5)\)

Axis of symmetry: \(x = 3\)

Direction: Opens downward (since \(a = -2 < 0\)), so it has a maximum value of 5

Problem 4

A ball is thrown upward with height \(h(t) = -5t^2 + 20t + 2\). When does it reach maximum height, and what is that height?

Solution:

Maximum at vertex: \(t = -\frac{b}{2a} = -\frac{20}{2(-5)} = 2\) seconds

Maximum height: \(h(2) = -5(4) + 20(2) + 2 = -20 + 40 + 2 = 22\) meters

Problem 5

Graph \(f(x) = 2(x + 1)^2 - 3\) and identify the vertex and transformations from \(y = x^2\).

Solution:

Vertex: \((-1, -3)\)

Transformations: Shift left 1, down 3, vertical stretch by factor of 2

Problem 6

Find the maximum or minimum value of \(f(x) = -x^2 + 4x - 1\) and state whether it is a maximum or minimum.

Solution:

Convert to vertex form: \(f(x) = -(x^2 - 4x) - 1 = -(x^2 - 4x + 4 - 4) - 1 = -(x - 2)^2 + 4 - 1 = -(x - 2)^2 + 3\)

Maximum value: 3 (since the parabola opens downward)

Problem 7

A farmer wants to enclose a rectangular field with 100 m of fencing. What dimensions maximize the area?

Solution:

Let \(x\) = width, \(y\) = length. Perimeter: \(2x + 2y = 100\), so \(y = 50 - x\)

Area: \(A = x(50 - x) = 50x - x^2\)

Maximum at vertex: \(x = -\frac{50}{-2} = 25\) m

Dimensions: \(25 \times 25\) m (a square)

Problem 8

Determine the nature of the roots for \(2x^2 + 5x - 3 = 0\) without solving.

Solution:

Discriminant: \(D = b^2 - 4ac = 25 - 4(2)(-3) = 25 + 24 = 49\)

Since \(D > 0\), there are two distinct real roots.

Bonus Solutions

Bonus Solution 1

Solution:

Original equation: \(x^2 - 6x + 9 = 0\) has roots \(x = 3, 3\) (double root).

Doubled roots: \(x = 6, 6\)

New equation: \((x - 6)^2 = 0\), so \(x^2 - 12x + 36 = 0\)

Bonus Solution 2

Solution:

Minimum value -4 means vertex is at \((h, -4)\). Points (0,2) and (4,2) are symmetric about x = 2.

So vertex is at \((2, -4)\) and \(a = 1\) (since points are 2 units above vertex).

Equation: \(f(x) = (x - 2)^2 - 4 = x^2 - 4x\)

X-intercepts: \(x^2 - 4x = 0\), so \(x = 0\) or \(x = 4\)
