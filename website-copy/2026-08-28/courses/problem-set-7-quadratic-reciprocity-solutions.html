Solutions: Problem Set 7: Quadratic Reciprocity

Solutions

Problem 1

Solution: \(\left(\frac{3}{11}\right) = -\left(\frac{11}{3}\right) = -\left(\frac{2}{3}\right) = -(-1) = 1\).

Problem 2

Solution: \(\left(\frac{5}{13}\right) = \left(\frac{13}{5}\right) = \left(\frac{3}{5}\right) = -\left(\frac{5}{3}\right) = -\left(\frac{2}{3}\right) = -(-1) = 1\).

Problem 3

Solution: \(\left(\frac{7}{23}\right) = -\left(\frac{23}{7}\right) = -\left(\frac{2}{7}\right) = -(-1) = 1\).

Problem 4

Solution: \(\left(\frac{11}{17}\right) = \left(\frac{17}{11}\right) = \left(\frac{6}{11}\right) = \left(\frac{2}{11}\right)\left(\frac{3}{11}\right) = (-1)(-1) = 1\).

Problem 5

Solution: \(\left(\frac{13}{29}\right) = \left(\frac{29}{13}\right) = \left(\frac{3}{13}\right) = -\left(\frac{13}{3}\right) = -\left(\frac{1}{3}\right) = -1\).

Problem 6

Solution: For \(p = 3\): \(\left(\frac{q}{3}\right) = 1\) iff \(q \equiv 1 \pmod{3}\), and \(\left(\frac{3}{q}\right) = 1\) iff \(q \equiv \pm 1 \pmod{12}\).

Problem 7

Solution: By quadratic reciprocity: \(\left(\frac{p}{q}\right)\left(\frac{q}{p}\right) = (-1)^{\frac{(p-1)(q-1)}{4}}\).

Problem 8

Solution: \(\left(\frac{2}{p}\right) = 1\) when \(p \equiv \pm 1 \pmod{8}\), i.e., \(p = 8k \pm 1\).

Problem 9

Solution: If \(p \equiv 1 \pmod{4}\), then \(\frac{p-1}{2}\) is even, so \(\left(\frac{q}{p}\right) = \left(\frac{p}{q}\right)\).

Problem 10

Solution: \(\left(\frac{61}{113}\right) = \left(\frac{113}{61}\right) = \left(\frac{52}{61}\right) = \left(\frac{4}{61}\right)\left(\frac{13}{61}\right) = \left(\frac{13}{61}\right) = \left(\frac{61}{13}\right) = \left(\frac{9}{13}\right) = 1\).

Bonus Problems

Bonus Problem 1

Solution:

Step 1: 561 = 3 × 11 × 17 is a Carmichael number.

Step 2: Verify Korselt's criterion: 561 is square-free and for each prime \(p | 561\), we have \((p-1) | (560)\).

Step 3: \(3-1=2\) divides 560, \(11-1=10\) divides 560, \(17-1=16\) divides 560. ✓

Bonus Problem 2

Solution:

Step 1: In the multiplicative group \((\mathbb{Z}/n\mathbb{Z})^*\) of order \(\phi(n)\), every element has order dividing the group order.

Step 2: By Lagrange's theorem, \(a^{\phi(n)} = 1\) in the group, meaning \(a^{\phi(n)} \equiv 1 \pmod{n}\).

Bonus Problem 3

Solution:

Step 1: Find the order of 2 modulo 37. The order divides 36.

Step 2: Check divisors: \(2^9 = 512 \equiv 27 \pmod{37}\), \(2^{12} = 4096 \equiv 1 \pmod{37}\).

Conclusion: The smallest \(k\) is 12.
