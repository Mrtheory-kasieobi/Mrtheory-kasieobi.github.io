Solutions: Problem Set 13: Irrational Numbers

Solutions

Problem 1

Solution: Assume \(\sqrt{3} = \frac{a}{b}\) in lowest terms. Then \(3b^2 = a^2\). So \(3|a^2\), hence \(3|a\). Write \(a=3c\): \(3b^2 = 9c^2\), so \(b^2 = 3c^2\), hence \(3|b\). Contradiction since \(\gcd(a,b)=1\).

Problem 2

Solution: Assume \(\sqrt{p} = \frac{a}{b}\). Then \(pb^2 = a^2\). By unique factorization, \(p\) appears to odd power in \(a^2\), contradiction. So \(\sqrt{p}\) is irrational.

Problem 3

Solution: If \(\alpha\) is irrational, assume both \(\alpha\) and \(1-\alpha\) are rational. Then \(\alpha = 1 - (1-\alpha) \in \mathbb{Q}\), contradiction. ✓

Problem 4

Solution: By Dirichlet's theorem, there exist \(p, q\) with \(0 < q \leq 100\) and \(|q\sqrt{2} - p| < \frac{1}{100}\). Using convergents: \(\frac{140}{99} \approx 1.41414\) with error \(\approx 0.00007\).

Problem 5

Solution: If \(\frac{p}{q}\) is a convergent to \(\sqrt{2}\), then \(|q\sqrt{2} - p| < 1\). This is a key property of convergents.

Problem 6

Solution: Liouville numbers \(\alpha\) satisfy \(|\alpha - \frac{p}{q}| > \frac{c}{q^n}\) for any \(c, n\). By Roth's theorem, algebraic irrationals have exponent 2+ε, so Liouville numbers are transcendental.

Problem 7

Solution: \(\mathbb{Q}\) is countable (finitely many fractions with bounded numerator/denominator). \(\mathbb{R}\) is uncountable. \(\mathbb{R} \setminus \mathbb{Q}\) must be uncountable since countable union of countable sets is countable.

Problem 8

Solution: By Kronecker's theorem, if \(\alpha\) is irrational, the set \(\{n\alpha \mod 1 : n \in \mathbb{Z}\}\) is dense in \([0,1]\).

Problem 9

Solution: Assume \(e = \frac{a}{b}\). Then \(b!e = b!\sum_{n=0}^{\infty} \frac{1}{n!}\) is an integer plus \(\sum_{n=b+1}^{\infty} \frac{b!}{n!}\). The tail is between 0 and 1, contradiction.

Problem 10

Solution: By Dirichlet's approximation theorem, for any irrational \(\alpha\) and \(\epsilon > 0\), there exist integers \(p, q\) with \(q > 0\) and \(|\alpha - \frac{p}{q}| < \epsilon\).

Bonus Problems

Bonus Problem 1

Solution:

Step 1: Assume \(\log_2 3 = \frac{p}{q}\) for integers \(p, q > 0\).

Step 2: Then \(2^{p/q} = 3\), so \(2^p = 3^q\).

Step 3: Left side is a power of 2, right side is a power of 3. The only common value is 1, but \(2^p = 1\) implies \(p=0\), contradiction.

Conclusion: \(\log_2 3\) is irrational.

Bonus Problem 2

Solution:

Step 1: Hurwitz's theorem: For any irrational \(\alpha\), there are infinitely many \(\frac{p}{q}\) with \(|\alpha - \frac{p}{q}| < \frac{1}{\sqrt{5}q^2}\).

Step 2: For \(\phi = \frac{1+\sqrt{5}}{2}\), the convergents satisfy \(|\phi - \frac{p_n}{q_n}| \sim \frac{1}{\sqrt{5}q_n^2}\).

Step 3: No larger constant works: consider \(\phi\) itself, for which the constant \(\frac{1}{\sqrt{5}}\) is optimal.

Bonus Problem 3

Solution:

Step 1: If \(p \equiv 3 \pmod{4}\) is prime and \(p\) is congruent, there exists a rational right triangle with area \(p\).

Step 2: This corresponds to an elliptic curve \(y^2 = x^3 - p^2 x\) having a point of order 2.

Step 3: By 2-descent, this curve has rank 0 for \(p \equiv 3 \pmod{4}\), so only trivial points exist.

Conclusion: No such triangle exists, so \(p\) is not congruent.
