Lecture 13: Irrational Numbers and Approximation

Lecture 13Irrational Numbers and Approximation

1. Irrationality of \(\sqrt{2}\)

Theorem 13.1 The number \(\sqrt{2}\) is irrational.
Proof (by contradiction):

Assume \(\sqrt{2} = \frac{p}{q}\) where \(p, q \in \mathbb{Z}^+\) and \(\gcd(p, q) = 1\).

Then \(2 = \frac{p^2}{q^2}\), so \(2q^2 = p^2\).

Thus \(p^2\) is even, so \(p\) is even. Write \(p = 2k\).

Substituting: \(2q^2 = (2k)^2 = 4k^2\), so \(q^2 = 2k^2\).

Thus \(q^2\) is even, so \(q\) is even.

But then 2 divides both \(p\) and \(q\), contradicting \(\gcd(p, q) = 1\). \(\square\)

Theorem 13.2 (General Principle) If \(p\) is a prime and \(p \mid a^n\) for some integer \(a\) and positive integer \(n\), then \(p \mid a\).
Proof: By induction on \(n\).

Base case (\(n = 1\)): Trivial.

Inductive step: If \(p \mid a^n\), then \(p \mid a \cdot a^{n-1}\). If \(p \mid a\), we're done. If \(p \mid a^{n-1}\), then by induction, \(p \mid a\). \(\square\)

2. Liouville's Theorem on Approximation

Theorem 13.3 (Liouville's Theorem) Let \(\alpha\) be an algebraic number of degree \(n \geq 2\). Then there exists \(c = c(\alpha) > 0\) such that for all rationals \(\frac{p}{q}\): \[\left|\alpha - \frac{p}{q}\right| > \frac{c}{q^n}\]

This theorem shows that algebraic numbers are not "too well" approximable by rationals. The proof uses the Mean Value Theorem and the fact that the minimal polynomial of \(\alpha\) has no rational roots.

Key idea: If \(\alpha\) satisfies \(f(x) = 0\) where \(f\) is irreducible of degree \(n\), then for any rational \(\frac{p}{q} \neq \alpha\): \[|f(p/q)| \geq \frac{1}{q^n}\] (since the numerator is a non-zero integer.)

By the Mean Value Theorem, \(|f(p/q)| = |f(p/q) - f(\alpha)| = |f'(\xi)| \cdot |p/q - \alpha|\) for some \(\xi\) between \(p/q\) and \(\alpha\).

For large \(q\), \(|f'(\xi)|\) is bounded by some constant \(M\), so: \[\left|\alpha - \frac{p}{q}\right| \geq \frac{1}{M q^n}\] Set \(c = \frac{1}{M}\). \(\square\)

3. Transcendental Numbers

Definition 13.4 (Transcendental Number) A real or complex number \(\alpha\) is transcendental if it is not algebraic, i.e., not a root of any non-zero polynomial with integer coefficients.
Example 13.1 (Liouville Numbers) The number \[L = \sum_{k=1}^{\infty} 10^{-k!} = 0.110001000000000000000001000\ldots\] is transcendental.

Proof: Suppose \(L\) is algebraic of degree \(n\). By Liouville's theorem, there exists \(c > 0\) such that for all \(\frac{p}{q}\): \[\left|L - \frac{p}{q}\right| > \frac{c}{q^n}\]

Consider the rational approximation \(\frac{p_m}{q_m} = \sum_{k=1}^{m} 10^{-k!}\). Then \(q_m = 10^{m!}\) and: \[\left|L - \frac{p_m}{q_m}\right| = \sum_{k=m+1}^{\infty} 10^{-k!} < 2 \cdot 10^{-(m+1)!}\]

But \(\frac{c}{q_m^n} = \frac{c}{10^{n \cdot m!}}\). For large \(m\), \(n \cdot m! < (m+1)!\), giving a contradiction. Thus \(L\) is transcendental. \(\square\)

Exercises:
  1. Prove that \(\sqrt{3}\) is irrational.
  2. Show that \(\sqrt{p}\) is irrational for any prime \(p\).
  3. Prove that if \(\alpha\) is irrational, then \(\{n\alpha\}\) (fractional part) is dense in \([0, 1]\).
  4. Find a continued fraction expansion for \(\sqrt{5}\) and verify it is periodic.
  5. Prove that \(e\) is irrational using the series \(e = \sum_{n=0}^{\infty} \frac{1}{n!}\).
  6. Show that the golden ratio \(\phi = \frac{1+\sqrt{5}}{2}\) is irrational.
  7. Prove: If \(\alpha\) is irrational, there exist integers \(x, y \neq 0\) with \(|x + y\alpha| < \frac{1}{|y|}\).
