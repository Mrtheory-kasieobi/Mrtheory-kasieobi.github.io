Problem Set 7: Systems of Linear Equations

Mathematics 10 - Chapter 7 Solutions

Solutions

Problem 1: Solve by substitution: \(y = 2x + 1\) and \(3x + y = 10\)
Substitute \(y = 2x + 1\) into \(3x + y = 10\):
\(3x + (2x + 1) = 10\)
\(5x + 1 = 10\)
\(5x = 9\)
\(x = \frac{9}{5}\)
Find \(y\): \(y = 2(\frac{9}{5}) + 1 = \frac{18}{5} + \frac{5}{5} = \frac{23}{5}\)
Answer: \((\frac{9}{5}, \frac{23}{5})\) or \((1.8, 4.6)\)
Problem 2: Solve by elimination: \(2x + 3y = 12\) and \(4x - 3y = 6\)
Add the equations to eliminate \(y\):
\((2x + 3y) + (4x - 3y) = 12 + 6\)
\(6x = 18\)
\(x = 3\)
Substitute into first equation: \(2(3) + 3y = 12\)
\(6 + 3y = 12\)
\(3y = 6\)
\(y = 2\)
Answer: \((3, 2)\)
Problem 3: Solve: \(x + y + z = 6\), \(2x - y + z = 2\), \(x + 2y - z = 4\)
Label equations: (1) \(x + y + z = 6\), (2) \(2x - y + z = 2\), (3) \(x + 2y - z = 4\)
Add (1) and (3): \(3x + 3y = 10\)
Add (1) and (2): \(3x + 2z = 8\)
From (1): \(z = 6 - x - y\)
Substitute into (2): \(2x - y + (6 - x - y) = 2\)
\(x - 2y + 6 = 2\)
\(x - 2y = -4\)
From \(3x + 3y = 10\): \(x + y = \frac{10}{3}\)
Solve system: \(x - 2y = -4\) and \(x + y = \frac{10}{3}\)
Subtract: \(-3y = -4 - \frac{10}{3} = -\frac{22}{3}\), so \(y = \frac{22}{9}\)
\(x = \frac{10}{3} - \frac{22}{9} = \frac{30 - 22}{9} = \frac{8}{9}\)
\(z = 6 - \frac{8}{9} - \frac{22}{9} = 6 - \frac{30}{9} = 6 - \frac{10}{3} = \frac{8}{3}\)
Answer: \((\frac{8}{9}, \frac{22}{9}, \frac{8}{3})\)
Problem 4: Investment problem - $3000 split between 4% and 6% accounts, $150 total interest
Let \(x\) = amount at 4%, then \((3000 - x)\) = amount at 6%
Interest equation: \(0.04x + 0.06(3000 - x) = 150\)
Expand: \(0.04x + 180 - 0.06x = 150\)
Combine: \(-0.02x + 180 = 150\)
\(-0.02x = -30\)
\(x = 1500\)
So: $1500 at 4% and $1500 at 6%
Answer: $1500 at 4% and $1500 at 6%
Problem 5: Find intersection of \(y = x + 2\) and \(y = -2x + 10\)
Set equations equal: \(x + 2 = -2x + 10\)
\(3x = 8\)
\(x = \frac{8}{3}\)
Find \(y\): \(y = \frac{8}{3} + 2 = \frac{8}{3} + \frac{6}{3} = \frac{14}{3}\)
Answer: \((\frac{8}{3}, \frac{14}{3})\) or approximately \((2.67, 4.67)\)
Problem 6: Determine number of solutions for \(3x + 2y = 6\) and \(6x + 4y = 12\)
Notice that \(6x + 4y = 12\) is exactly \(2(3x + 2y = 6)\)
The second equation is a multiple of the first - they are the same line
Answer: Infinitely many solutions (same line)
Problem 7: Solve \(\frac{1}{2}x + \frac{1}{3}y = 2\) and \(\frac{1}{4}x - y = -1\)
Clear fractions from first equation (multiply by 6): \(3x + 2y = 12\)
Clear fractions from second equation (multiply by 4): \(x - 4y = -4\)
From second: \(x = 4y - 4\)
Substitute into first: \(3(4y - 4) + 2y = 12\)
\(12y - 12 + 2y = 12\)
\(14y = 24\)
\(y = \frac{24}{14} = \frac{12}{7}\)
\(x = 4(\frac{12}{7}) - 4 = \frac{48}{7} - \frac{28}{7} = \frac{20}{7}\)
Answer: \((\frac{20}{7}, \frac{12}{7})\)
Bonus Problem 1: Reflection Puzzle
Reflect A(2, 3) over line \(y = x + 1\)
Step 1: Find perpendicular line through A. Slope of y = x + 1 is 1, so perpendicular slope is -1
Equation of perpendicular: \(y - 3 = -1(x - 2)\), so \(y = -x + 5\)
Step 2: Find intersection of y = x + 1 and y = -x + 5
Set equal: \(x + 1 = -x + 5\), so \(2x = 4\), \(x = 2\)
\(y = 2 + 1 = 3\). Intersection point: (2, 3) = A itself!
Wait - A is on the line y = x + 1? Check: 3 = 2 + 1 ✓
So A is on the line, and its reflection is itself!
A' = (2, 3)
Reflect A' over x-axis: y-coordinate changes sign
B = (2, -3)
Answer: A' = (2, 3), B = (2, -3)
Bonus Problem 2: Intersection Detective
Find intersection of L₁ and L₂:
L₁: \(y = x + 1\)
L₂: \(y = -x + 5\)
Set equal: \(x + 1 = -x + 5\), \(2x = 4\), \(x = 2\)
\(y = 3\). P₁ = (2, 3)
Find intersection of L₁ and L₃:
L₃: \(y = 2x - 1\)
\(x + 1 = 2x - 1\), \(x = 2\), \(y = 3\). P₂ = (2, 3)
Find intersection of L₂ and L₃:
\(-x + 5 = 2x - 1\), \(3x = 6\), \(x = 2\), \(y = 3\). P₃ = (2, 3)
All three lines intersect at (2, 3)!
All distances are 0, so all pairs are tied for shortest
Answer: All three lines intersect at (2, 3). All distances are equal (0).
Bonus Problem 3: System Constraint
Original system: \(2x + 3y = 12\) and \(ax + by = 10\)
If we swap coefficients in second: \(bx + ay = 10\)
Let original solution be (x₀, y₀) and swapped solution be (x₁, y₁)
Given: \(x_1 - x_0 = 2\) and \(y_1 - y_0 = 2\)
From first equation: \(y_0 = \frac{12 - 2x_0}{3}\)
Original second: \(ax_0 + by_0 = 10\)
Swapped second: \(bx_1 + ay_1 = 10\)
With \(x_1 = x_0 + 2\) and \(y_1 = y_0 + 2\)
Substitute and solve for a and b
Let's try specific values. If a = 3, b = 2 (swapped from first equation):
Original: \(2x + 3y = 12\), \(3x + 2y = 10\)
Solve: multiply first by 3, second by 2: \(6x + 9y = 36\), \(6x + 4y = 20\)
Subtract: \(5y = 16\), \(y = 16/5 = 3.2\)
\(x = (12 - 3(3.2))/2 = (12 - 9.6)/2 = 1.2\)
Swapped system: \(2x + 3y = 12\), \(2x + 3y = 10\)? No, that's the same
Actually swapped would be: \(2x + 3y = 12\), \(3x + 2y = 10\) - same as original if a=3, b=2
Need different approach. Let a = b for the constraint to work
Answer: This problem requires more constraints to solve uniquely.
