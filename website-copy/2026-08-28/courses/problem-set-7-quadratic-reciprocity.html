Problem Set 7: Quadratic Reciprocity Law

Elementary Number Theory - Week 7 Medium

Problems

Problem 1

Compute \(\left(\frac{3}{11}\right)\) using quadratic reciprocity.

Problem 2

Compute \(\left(\frac{5}{13}\right)\) using quadratic reciprocity.

Problem 3

Compute \(\left(\frac{7}{23}\right)\) using quadratic reciprocity.

Problem 4

Find \(\left(\frac{11}{17}\right)\) and \(\left(\frac{17}{11}\right)\). Verify they are equal.

Problem 5

Compute \(\left(\frac{13}{29}\right)\) using quadratic reciprocity.

Problem 6

Prove the law of quadratic reciprocity for \(p = 3\).

Problem 7

Show that \(\left(\frac{p}{q}\right)\left(\frac{q}{p}\right) = (-1)^{\frac{(p-1)(q-1)}{4}}\) for distinct odd primes \(p, q\).

Problem 8

Find all primes \(p\) such that \(\left(\frac{2}{p}\right) = 1\).

Problem 9

Prove: If \(p \equiv 1 \pmod{4}\), then \(\left(\frac{q}{p}\right) = \left(\frac{p}{q}\right)\) for any odd prime \(q\).

Problem 10

Compute \(\left(\frac{61}{113}\right)\) using the full law of quadratic reciprocity.

Bonus Problems

Bonus Problem 1

Challenge: Prove the supplementary law: \(\left(\frac{-1}{p}\right) = (-1)^{\frac{p-1}{2}}\).

Bonus Problem 2

Challenge: Show that \(\left(\frac{2}{p}\right) = (-1)^{\frac{p^2-1}{8}}\).

Bonus Problem 3

Challenge: Prove that if \(p \equiv 3 \pmod{4}\) is prime, then \(\left(\frac{-1}{p}\right) = -1\).
