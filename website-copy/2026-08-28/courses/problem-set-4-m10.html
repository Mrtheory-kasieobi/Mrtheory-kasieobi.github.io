Problem Set 4: Roots and Powers

Mathematics 10 - Chapter 4 Medium

Problems

Problem 1

Simplify: \(x^5 \times x^3 \div x^2\) using the law \(a^m \times a^n = a^{m+n}\) and \(\frac{a^m}{a^n} = a^{m-n}\)

Problem 2

Simplify: \((x^2 y^3)^4 \div (x y^2)^2\)

Problem 3

Simplify: \(\frac{(2a^{-3})^2}{(4a^{-1})^2}\)

Problem 4

Express in scientific notation: \(0.0000456\) and \(5,400,000\)

Problem 5

Simplify: \(\left(\frac{a^{-2}b^3}{a^4b^{-1}}\right)^{-2}\)

Problem 6

Evaluate: \((2.5 \times 10^3) \times (4 \times 10^5)\) in scientific notation

Problem 7

Simplify: \(\frac{(3x^2y^{-1})^3}{(9xy^2)^2}\)

Problem 8

Find the value of \(n\) if \(2^n = 0.125\) (Hint: \(0.125 = \frac{1}{8} = \frac{1}{2^3}\))

Bonus Problems

Bonus Problem 1 Hard

Exponent Detective: If \(2^a \times 3^b = 72\) and \(2^c \times 3^d = 108\), find the value of \(a + b + c + d\) without calculating 72 or 108 directly. Then, given that \(x = 2^a \times 3^b\) and \(y = 2^c \times 3^d\), find the prime factorization of \(xy\).

Bonus Problem 2 Medium

Scientific Notation Puzzle: A very large number is written as \(N = 2.5 \times 10^{100}\). What is the value of \(N \times 10^{-50} + N \times 10^{-50}\)? Express your answer in scientific notation. How many zeros are between the first and last digit of this number?

Bonus Problem 3 Hard

Power Tower Challenge: Find the smallest positive integer \(k\) such that \(k = 2^a + 2^b\) for some non-negative integers \(a\) and \(b\) where \(a \neq b\), and \(k\) is divisible by 3. Then express \(k\) in scientific notation.
