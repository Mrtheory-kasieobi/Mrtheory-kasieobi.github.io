Problem Set 5: Radical and Rational Expressions

Precalculus 11 - Chapter 5 Solutions

Solutions

Problem 1: Simplify \(\sqrt{72}\)
Factor 72: \(72 = 36 \times 2 = 6^2 \times 2\)
\(\sqrt{72} = \sqrt{6^2 \times 2} = 6\sqrt{2}\)
Answer: \(6\sqrt{2}\)
Problem 2: Solve \(\sqrt{x + 3} = 5\)
Square both sides: \(x + 3 = 25\)
Solve: \(x = 22\)
Check: \(\sqrt{22 + 3} = \sqrt{25} = 5\) ✓
Answer: \(x = 22\)
Problem 3: Simplify \(\frac{x^2 - 9}{x - 3}\)
Factor numerator: \(x^2 - 9 = (x - 3)(x + 3)\)
\(\frac{(x - 3)(x + 3)}{x - 3} = x + 3\), where \(x \neq 3\)
Answer: \(x + 3\), \(x \neq 3\)
Problem 4: Solve \(\frac{2}{x} + \frac{3}{x+1} = 1\)
Multiply both sides by LCD \(x(x+1)\):
\(2(x+1) + 3x = x(x+1)\)
Expand: \(2x + 2 + 3x = x^2 + x\)
Combine: \(5x + 2 = x^2 + x\)
Rearrange: \(x^2 - 4x - 2 = 0\)
Use quadratic formula: \(x = \frac{4 \pm \sqrt{16 + 8}}{2} = \frac{4 \pm \sqrt{24}}{2} = 2 \pm \sqrt{6}\)
Check restrictions: \(x \neq 0\) and \(x \neq -1\)
Both solutions are valid: \(x = 2 + \sqrt{6}\) and \(x = 2 - \sqrt{6}\)
Answer: \(x = 2 \pm \sqrt{6}\)
Problem 5: Simplify \(\sqrt[3]{54x^6}\)
Factor: \(54x^6 = 27 \times 2 \times x^6 = 3^3 \times 2 \times (x^2)^3\)
\(\sqrt[3]{54x^6} = \sqrt[3]{3^3 \times 2 \times (x^2)^3} = 3x^2\sqrt[3]{2}\)
Answer: \(3x^2\sqrt[3]{2}\)
Problem 6: Solve \(\sqrt{2x - 1} = x - 1\)
Square both sides: \(2x - 1 = (x - 1)^2 = x^2 - 2x + 1\)
Rearrange: \(x^2 - 4x + 2 = 0\)
Quadratic formula: \(x = \frac{4 \pm \sqrt{16 - 8}}{2} = \frac{4 \pm \sqrt{8}}{2} = 2 \pm \sqrt{2}\)
Check both solutions:
For \(x = 2 + \sqrt{2} \approx 3.41\): LHS = \(\sqrt{2(3.41) - 1} \approx 2.41\), RHS = \(2.41\) ✓
For \(x = 2 - \sqrt{2} \approx 0.59\): LHS = \(\sqrt{0.18} \approx 0.42\), RHS = \(-0.41\) ✗ (extraneous)
Answer: \(x = 2 + \sqrt{2}\)
Problem 7: Simplify \(\frac{x^2 + 5x + 6}{x^2 + 3x + 2}\)
Factor numerator: \(x^2 + 5x + 6 = (x + 2)(x + 3)\)
Factor denominator: \(x^2 + 3x + 2 = (x + 1)(x + 2)\)
\(\frac{(x + 2)(x + 3)}{(x + 1)(x + 2)} = \frac{x + 3}{x + 1}\), where \(x \neq -2\)
Answer: \(\frac{x + 3}{x + 1}\), \(x \neq -2\)
Problem 8: Solve \(\frac{3}{x-2} = \frac{5}{x+1}\)
Cross multiply: \(3(x + 1) = 5(x - 2)\)
Expand: \(3x + 3 = 5x - 10\)
Solve: \(-2x = -13\), so \(x = \frac{13}{2} = 6.5\)
Check restrictions: \(x \neq 2\) and \(x \neq -1\), and \(x = 6.5\) satisfies these
Answer: \(x = \frac{13}{2}\)

Bonus Solutions

Bonus Problem 1: Rational Equation Chain
Note: \(x^2 - 1 = (x-1)(x+1)\)
Domain restrictions: \(x \neq 1\) and \(x \neq -1\)
Multiply both sides by \((x-1)(x+1)\):
\(2(x+1) + 3(x-1) = 5\)
Expand: \(2x + 2 + 3x - 3 = 5\)
Combine: \(5x - 1 = 5\)
\(5x = 6\), so \(x = \frac{6}{5} = 1.2\)
Check: \(x \neq 1\) and \(x \neq -1\), so \(x = 1.2\) is valid
Answer: \(x = \frac{6}{5}\), valid since \(x \neq \pm 1\)
Bonus Problem 2: Nested Radicals
Square both sides: \(x + \sqrt{2x + 3} = 9\)
Isolate radical: \(\sqrt{2x + 3} = 9 - x\)
Square again: \(2x + 3 = (9 - x)^2 = 81 - 18x + x^2\)
Rearrange: \(x^2 - 20x + 78 = 0\)
Quadratic formula: \(x = \frac{20 \pm \sqrt{400 - 312}}{2} = \frac{20 \pm \sqrt{88}}{2} = 10 \pm \sqrt{22}\)
Check: \(10 + \sqrt{22} \approx 14.7 > 9\), but \(\sqrt{2x+3} = 9 - x\) requires \(x \leq 9\)
So \(x = 10 + \sqrt{22}\) is extraneous
Check: \(10 - \sqrt{22} \approx 5.3\)
LHS: \(\sqrt{5.3 + \sqrt{13.6}} \approx \sqrt{5.3 + 3.69} \approx \sqrt{9} = 3\) ✓
Answer: \(x = 10 - \sqrt{22}\)
Bonus Problem 3: Rational Function Analysis
Factor numerator: \(x^2 - 4 = (x-2)(x+2)\)
Factor denominator: \(x^2 - 5x + 6 = (x-2)(x-3)\)
Original domain: \(x \neq 2\) and \(x \neq 3\)
Simplify: \(f(x) = \frac{(x-2)(x+2)}{(x-2)(x-3)} = \frac{x+2}{x-3}\), where \(x \neq 2\)
Set equal to 2: \(\frac{x+2}{x-3} = 2\)
Cross multiply: \(x + 2 = 2(x - 3)\)
Expand: \(x + 2 = 2x - 6\)
Solve: \(x = 8\)
Check: \(x = 8 \neq 2\) and \(x = 8 \neq 3\) ✓
Answer: Domain: \(x \neq 2, 3\). \(f(x) = 2\) when \(x = 8\).
