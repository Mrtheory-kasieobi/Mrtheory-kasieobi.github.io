Solutions: Problem Set 14: Diophantine Equations

Solutions

Problem 1

Solution: The linear Diophantine equation \(ax + by = c\) has solutions iff \(\gcd(a,b) | c\). For \(6x + 9y = 15\): \(\gcd(6,9)=3\) and \(3|15\), so solutions exist. Divide by 3: \(2x + 3y = 5\).

Problem 2

Solution: Particular solution: \(x_0 = 1, y_0 = 1\) satisfies \(2(1) + 3(1) = 5\). General solution: \(x = 1 + 3t\), \(y = 1 - 2t\) for \(t \in \mathbb{Z}\).

Problem 3

Solution: Pell's equation \(x^2 - 2y^2 = 1\). Fundamental solution: \((3, 2)\) since \(3^2 - 2(2)^2 = 1\). All solutions: \(x_n + y_n\sqrt{2} = (3 + 2\sqrt{2})^n\).

Problem 4

Solution: By Fermat's theorem on sums of two squares, prime \(p = 2\) or \(p \equiv 1 \pmod{4}\) iff \(p = x^2 + y^2\) for integers \(x, y\).

Problem 5

Solution: For \(x^2 + y^2 = 25\): Solutions are \((\pm 5, 0)\), \((0, \pm 5)\), \((\pm 3, \pm 4)\), \((\pm 4, \pm 3)\). Total: 12 solutions.

Problem 6

Solution: \(x^3 + y^3 = z^3\). By Fermat's Last Theorem, no non-trivial integer solutions exist for exponent 3.

Problem 7

Solution: \(xy = 12\). Factor pairs of 12: \((1,12), (2,6), (3,4), (4,3), (6,2), (12,1)\), plus negatives. All solutions: \((\pm 1, \pm 12)\), \((\pm 2, \pm 6)\), \((\pm 3, \pm 4)\).

Problem 8

Solution: \(x^2 - 2y^2 = 7\). Check small values: \(x=3, y=1\) gives \(9 - 2 = 7\). Solutions from \((3 + \sqrt{2})(1 + 0\sqrt{2})^n\).

Problem 9

Solution: \(\frac{1}{x} + \frac{1}{y} = \frac{1}{2}\). Rewrite: \(y + x = \frac{xy}{2}\), so \(xy - 2x - 2y = 0\). Factor: \((x-2)(y-2) = 4\).

Problem 10

Solution: From \((x-2)(y-2) = 4\): pairs \((1,4), (2,2), (4,1), (-1,-4), (-2,-2), (-4,-1)\). So \((x,y) \in \{(3,6), (4,4), (6,3), (1,-2), (0,0), (-2,1)\}\).

Bonus Problems

Bonus Problem 1

Solution:

Step 1: Solve \(x^2 + y^2 = z^2\) (Pythagorean triples). Parameterize: \(x = m^2 - n^2\), \(y = 2mn\), \(z = m^2 + n^2\) for \(\gcd(m,n)=1\), \(m > n > 0\).

Step 2: To get primitive triples, require \(m, n\) coprime and not both odd.

Step 3: All primitive solutions generated by this formula.

Bonus Problem 2

Solution:

Step 1: Euler's conjecture: \(x^n + y^n + z^n = w^n\) has no non-trivial solutions for \(n > 2\).

Step 2: Counterexample for \(n=5\): \(27^5 + 84^5 + 110^5 + 133^5 = 144^5\).

Step 3: This disproves Euler's conjecture for \(n=5\).

Bonus Problem 3

Solution:

Step 1: The equation \(x^3 + y^3 + z^3 = w^3\) has infinitely many solutions.

Step 2: Example: \(3^3 + 4^3 + 5^3 = 6^3\) since \(27 + 64 + 125 = 216\).

Step 3: Parametric family: \((3a^2+5ab-5b^2)^3 + (4a^2-4ab+6b^2)^3 + (5a^2-5ab-3b^2)^3 = (6a^2-4ab+4b^2)^3\).
