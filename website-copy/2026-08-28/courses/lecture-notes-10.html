Lecture 11Applications of Gaussian Integers

1. The Sum of Two Squares Theorem

Theorem 11.1 (Sum of Two Squares) A positive integer \(n\) can be expressed as \(n = x^2 + y^2\) for integers \(x, y\) if and only if in the prime factorization of \(n\), every prime \(p \equiv 3 \pmod{4}\) appears with an even exponent.

Necessity (\(\Rightarrow\)): Suppose \(n = x^2 + y^2\). If a prime \(p \equiv 3 \pmod{4}\) divides \(n\) to an odd power, write \(n = p^{2k+1} m\) where \(p \nmid m\).

Since \(n = x^2 + y^2\), we have \(p^{2k+1} \mid (x^2 + y^2)\).

If \(p \mid x\), then \(p \mid y\) (since \(p \mid x^2 + y^2\)). Write \(x = px', y = py'\). Then \(p^{2k+1} \mid p^2(x'^2 + y'^2)\), so \(p^{2k-1} \mid x'^2 + y'^2\).

Continue until we get \(p \mid (x_0^2 + y_0^2)\) where \(p \nmid x_0\) or \(p \nmid y_0\).

But if \(p \nmid x_0\), then \(x_0^2 + y_0^2 \equiv 0 \pmod{p}\), so \(-y_0^2 \equiv x_0^2 \pmod{p}\), giving \((xy^{-1})^2 \equiv -1 \pmod{p}\).

This contradicts that \(-1\) is not a quadratic residue modulo \(p\) when \(p \equiv 3 \pmod{4}\). \(\square\)

Sufficiency (\(\Leftarrow\)): If \(n\) satisfies the condition, then \(n = x^2 + y^2\).

It suffices to show:

  1. If \(n_1 = x_1^2 + y_1^2\) and \(n_2 = x_2^2 + y_2^2\), then \(n_1 n_2 = x_3^2 + y_3^2\).
  2. \(p^k = x^2 + y^2\) for any prime \(p \equiv 1 \pmod{4}\) and any \(k \geq 1\).
  3. \(2^k = x^2 + y^2\) for any \(k \geq 1\).

Part 1 (Brahmagupta-Fibonacci identity): \[(x_1^2 + y_1^2)(x_2^2 + y_2^2) = (x_1x_2 - y_1y_2)^2 + (x_1y_2 + x_2y_1)^2\]

Verification by expansion is straightforward. \(\square\)

2. Pell's Equation via Gaussian Integers

Definition 11.1 (Pell's Equation) An equation of the form \(x^2 - Dy^2 = 1\) where \(D\) is a positive non-square integer is called Pell's equation.
Example 11.1 Find solutions to \(x^2 - 2y^2 = 1\).

Try small values: \(y = 1\) gives \(x^2 = 3\) (no), \(y = 2\) gives \(x^2 = 9\), so \(x = 3\).

Fundamental solution: \((3, 2)\). All solutions are given by \((3 + 2\sqrt{2})^n\).

3. Applications to Diophantine Equations

Theorem 11.2 The equation \(x^2 + y^2 = z^n\) has integer solutions for any \(n \geq 1\).
Step 1: Use Gaussian integers

Write \(x + yi = (a + bi)^n\) for some Gaussian integer \(a + bi\).

Then \(x^2 + y^2 = N(x + yi) = N(a + bi)^n = (a^2 + b^2)^n\). \(\square\)

Exercises:
  1. Express 50 as a sum of two squares in all possible ways.
  2. Show that 21 cannot be written as a sum of two squares.
  3. Find a solution to \(x^2 - 3y^2 = 1\).
  4. Find integers \(x, y\) such that \(x^2 + y^2 = 343\).
  5. Prove: If \(n = x^2 + y^2\) and \(\gcd(x, y) = 1\), then no prime \(p \equiv 3 \pmod{4}\) divides \(n\).
  6. Show that \(x^2 + y^2 = 2^n\) has solutions for all \(n \geq 1\).
  7. Find the fundamental solution to \(x^2 - 5y^2 = 1\).
  8. Prove: If \(p \equiv 1 \pmod{4}\) is prime, then \(x^2 + y^2 = p\) has exactly 8 solutions (counting signs and order).
