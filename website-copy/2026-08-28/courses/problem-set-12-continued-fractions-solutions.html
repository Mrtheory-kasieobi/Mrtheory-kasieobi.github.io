Solutions: Problem Set 12: Continued Fractions

Solutions

Problem 1

Solution: \(\frac{19}{7} = 2 + \frac{5}{7} = 2 + \frac{1}{\frac{7}{5}} = 2 + \frac{1}{1+\frac{2}{5}} = 2 + \frac{1}{1+\frac{1}{2}}\). So \([2; 1, 2]\).

Problem 2

Solution: For \([1; 2, 2, 2, 2]\): Convergents: \(\frac{p_0}{q_0} = \frac{1}{1}\), \(\frac{p_1}{q_1} = \frac{3}{2}\), \(\frac{p_2}{q_2} = \frac{7}{5}\), \(\frac{p_3}{q_3} = \frac{17}{12}\), \(\frac{p_4}{q_4} = \frac{41}{29}\).

Problem 3

Solution: \(\sqrt{7} = 2 + (\sqrt{7}-2)\). Let \(r_0 = \sqrt{7}+2\). Then \(\frac{1}{r_0} = \frac{\sqrt{7}-2}{3}\). Continuing gives \(\sqrt{7} = [2; 1, 1, 1, 4, 1, 1, 1, 4, \ldots]\) with period 4.

Problem 4

Solution: Using recurrence \(p_n = a_n p_{n-1} + p_{n-2}\), \(q_n = a_n q_{n-1} + q_{n-2}\) with \(p_{-1}=1, p_0=a_0, q_{-1}=0, q_0=1\). The determinant formula: \(p_n q_{n-1} - p_{n-1} q_n = (-1)^{n-1}\).

Problem 5

Solution: \(\frac{22}{7} = 3 + \frac{1}{7} = [3; 7]\). Verify: \(3 + \frac{1}{7} = \frac{22}{7}\). ✓

Problem 6

Solution: For rational \(\frac{p}{q}\), apply Euclidean algorithm: \(p = q a_0 + r_1\), \(q = r_1 a_1 + r_2\), etc. The quotients give the continued fraction.

Problem 7

Solution: Convergents of \(\pi\): \(\frac{3}{1}, \frac{22}{7}, \frac{333}{106}, \frac{355}{113}, \ldots\). \(\frac{22}{7} \approx 3.142857\), error \(\approx 0.00126 < 0.01\). ✓

Problem 8

Solution: From theory: \(\left|\alpha - \frac{p_n}{q_n}\right| < \frac{1}{q_n q_{n+1}}\). This is the key property of convergents.

Problem 9

Solution: \(\frac{1+\sqrt{5}}{2} = [1; 1, 1, 1, \ldots]\) (all 1s). This is the golden ratio.

Problem 10

Solution: Golden ratio satisfies \(\phi = 1 + \frac{1}{\phi}\). Solving: \(\phi^2 = \phi + 1\), so \(\phi = \frac{1+\sqrt{5}}{2}\). Continued fraction: \([1; 1, 1, 1, \ldots]\).

Bonus Problems

Bonus Problem 1

Solution:

Step 1: If \(\frac{p_n}{q_n}\) and \(\frac{p_m}{q_m}\) are convergents with \(n < m\), then \(\left|\frac{p_n}{q_n} - \frac{p_m}{q_m}\right| \geq \frac{1}{q_n q_m}\).

Step 2: Since convergents are distinct fractions, they cannot be equal.

Step 3: The minimum distance between \(\frac{p_n}{q_n}\) and any other fraction with denominator \(\leq q_m\) is achieved by convergents.

Conclusion: All convergents are in lowest terms.

Bonus Problem 2

Solution:

Step 1: From the recurrence: \(q_{n+1} = a_{n+1} q_n + q_{n-1} > q_n\).

Step 2: The error bound: \(\left|\alpha - \frac{p_n}{q_n}\right| < \frac{1}{q_n q_{n+1}}\).

Step 3: Since \(q_{n+1} > q_n\), we have \(\left|\alpha - \frac{p_n}{q_n}\right| < \frac{1}{q_n^2}\).

Bonus Problem 3

Solution:

Step 1: \(x^2 - 11y^2 = 1\). Compute continued fraction of \(\sqrt{11} = [3; 3, 6, 3, 6, \ldots]\).

Step 2: Convergents: \(\frac{3}{1}, \frac{10}{3}, \frac{63}{19}, \frac{199}{60}, \ldots\).

Step 3: Check: \(10^2 - 11 \cdot 3^2 = 100 - 99 = 1\).

Conclusion: Fundamental solution: \((10, 3)\).
