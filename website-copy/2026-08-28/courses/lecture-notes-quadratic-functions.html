Quadratic Functions

Precalculus 11 - Lecture Notes
British Columbia Curriculum | Last Updated: 2026

1. Introduction to Quadratic Functions

A quadratic function is a polynomial function of degree 2. It has the general form:

\[f(x) = ax^2 + bx + c\]

Where \(a\), \(b\), and \(c\) are constants, and \(a \neq 0\).

Definition: The graph of a quadratic function is a parabola - a U-shaped curve that opens either upward or downward.

1.1 Characteristics of Quadratic Functions

  • Direction of opening: If \(a > 0\), the parabola opens upward. If \(a < 0\), it opens downward.
  • y-intercept: The point \((0, c)\)
  • Axis of symmetry: The vertical line \(x = -\frac{b}{2a}\)
  • Vertex: The turning point at \((-\frac{b}{2a}, f(-\frac{b}{2a}))\)

2. Vertex Form of Quadratic Functions

The vertex form of a quadratic function makes it easy to identify the vertex:

\[f(x) = a(x - h)^2 + k\]

Where \((h, k)\) is the vertex of the parabola.

2.1 Converting from Standard to Vertex Form

To convert from standard form \(f(x) = ax^2 + bx + c\) to vertex form, we use completing the square:

Example 1: Converting to Vertex Form

Convert \(f(x) = x^2 + 6x + 5\) to vertex form.

Solution:

Step 1: Group the first two terms: \(f(x) = (x^2 + 6x) + 5\)

Step 2: Complete the square: Add and subtract \((\frac{6}{2})^2 = 9\)

\[f(x) = (x^2 + 6x + 9 - 9) + 5\]

\[f(x) = (x + 3)^2 - 9 + 5\]

\[f(x) = (x + 3)^2 - 4\]

Vertex: \((-3, -4)\)

2.2 Properties from Vertex Form

From the vertex form \(f(x) = a(x - h)^2 + k\):

  • Vertex: \((h, k)\)
  • Axis of symmetry: \(x = h\)
  • Direction: Opens up if \(a > 0\), down if \(a < 0\)
  • Maximum/Minimum: If \(a > 0\), minimum value is \(k\). If \(a < 0\), maximum value is \(k\).

3. Standard Form and Factored Form

3.1 Standard Form

The standard form is: \(f(x) = ax^2 + bx + c\)

3.2 Factored Form

The factored form is: \(f(x) = a(x - r_1)(x - r_2)\)

Where \(r_1\) and \(r_2\) are the roots (x-intercepts) of the function.

Axis of Symmetry (from factored form):
\[x = \frac{r_1 + r_2}{2}\]

4. Transformations of Quadratic Functions

Quadratic functions can be transformed by changing the parameters in vertex form:

\[f(x) = a(x - h)^2 + k\]

4.1 Types of Transformations

  • Vertical stretch/compression: \(|a| > 1\) stretches, \(0 < |a| < 1\) compresses
  • Reflection: If \(a < 0\), reflects across x-axis
  • Horizontal shift: \(h\) units right if \(h > 0\), left if \(h < 0\)
  • Vertical shift: \(k\) units up if \(k > 0\), down if \(k < 0\)
Example 2: Analyzing Transformations

For \(f(x) = -2(x - 3)^2 + 5\):

Reflection: Yes (negative \(a\))

Vertical stretch: By factor of 2

Horizontal shift: 3 units right

Vertical shift: 5 units up

Vertex: \((3, 5)\)

5. Solving Quadratic Equations

5.1 Methods for Solving Quadratics

  1. Factoring: Set each factor equal to zero
  2. Completing the square: Convert to vertex form
  3. Quadratic formula: \(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\)
  4. Graphing: Find x-intercepts

5.2 The Discriminant

The discriminant \(D = b^2 - 4ac\) determines the nature of the roots:

\[D = b^2 - 4ac\]
  • If \(D > 0\): Two distinct real roots
  • If \(D = 0\): One real root (repeated)
  • If \(D < 0\): No real roots (two complex roots)
Example 3: Using the Discriminant

Determine the nature of the roots for \(2x^2 + 5x - 3 = 0\).

Solution:

\(a = 2\), \(b = 5\), \(c = -3\)

\[D = 5^2 - 4(2)(-3) = 25 + 24 = 49\]

Since \(D > 0\), there are two distinct real roots.

6. Applications of Quadratic Functions

6.1 Optimization Problems

Quadratic functions are used to model optimization problems where we want to maximize or minimize a quantity.

Example 4: Optimization

A farmer wants to enclose a rectangular field with 100 m of fencing. What dimensions maximize the area?

Solution:

Let \(x\) = width, \(y\) = length

Perimeter: \(2x + 2y = 100\), so \(y = 50 - x\)

Area: \(A = x(50 - x) = 50x - x^2\)

This is a downward parabola with maximum at vertex:

\[x = -\frac{b}{2a} = -\frac{50}{-2} = 25\]

Maximum area: \(25 \times 25 = 625 \text{ m}^2\) (a square)

6.2 Projectile Motion

The height of a projectile can be modeled by a quadratic function:

\[h(t) = -\frac{1}{2}gt^2 + v_0t + h_0\]

Where \(g\) is acceleration due to gravity, \(v_0\) is initial velocity, and \(h_0\) is initial height.

8. Practice Problems

Problem 1

Convert \(f(x) = 2x^2 - 12x + 7\) to vertex form and identify the vertex.

Problem 2

Find the x-intercepts of \(f(x) = x^2 - 5x + 6\) by factoring.

Problem 3

Use the quadratic formula to solve \(3x^2 + 2x - 1 = 0\).

Problem 4

A ball is thrown upward with height \(h(t) = -5t^2 + 20t + 2\). When does it reach maximum height, and what is that height?
