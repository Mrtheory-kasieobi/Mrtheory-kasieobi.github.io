Problem Set 2: Trigonometry

Mathematics 10 - Chapter 2 Solutions

Solutions

Problem 1: Ladder against wall
Given: ladder = 10 m, angle = 60°, height up wall = 8 m
Using cosine: cos 60° = adjacent/hypotenuse = distance/10
distance = 10 × cos 60° = 10 × ½ = 5 m
Verify with sine: sin 60° = opposite/hypotenuse = 8/10 = 0.8
But sin 60° = √3/2 ≈ 0.866, so there's an inconsistency. The given height (8 m) doesn't match the angle (60°) and ladder length (10 m).
Answer: 5 m from the wall (theoretical), but the given values are inconsistent.
Problem 2: Tree height
Distance = 30 m, angle = 25°
tan 25° = height/30
height = 30 × tan 25° ≈ 30 × 0.4663 = 13.99 m
Answer: Approximately 14 m tall.
Problem 3: Right triangle trig ratios
Legs: 5 cm and 12 cm. Hypotenuse = √(5² + 12²) = √(25 + 144) = √169 = 13 cm
Angle opposite 5 cm side (call it θ): sin θ = 5/13, cos θ = 12/13, tan θ = 5/12
Answer: sin θ = 5/13, cos θ = 12/13, tan θ = 5/12
Problem 4: Building height
Distance = 20 m, angle = 35°
height = 20 × tan 35° ≈ 20 × 0.7002 = 14.00 m
If 5 m closer (15 m from building):
new height = 15 × tan 35° ≈ 15 × 0.7002 = 10.50 m (same building)
Answer: Building ≈ 14 m tall. Angle from 15 m: tan⁻¹(14/15) ≈ 43°
Problem 5: Airplane altitude
Observers 40 m apart, angles 30° and 45°
Let h = altitude, d = horizontal distance from first observer
tan 30° = h/d → d = h/tan 30° = h√3
tan 45° = h/(40-d) → 40-d = h → d = 40-h
h√3 = 40-h → h(√3 + 1) = 40 → h = 40/(√3 + 1) ≈ 40/2.732 ≈ 14.64 m
Answer: Approximately 14.6 m altitude.
Problem 6: Right triangle with hypotenuse 10
Hypotenuse = 10, angle = 40°
Adjacent side = 10 × cos 40° ≈ 10 × 0.7660 = 7.66
Opposite side = 10 × sin 40° ≈ 10 × 0.6428 = 6.43
Answer: Other sides ≈ 7.66 and 6.43.
Problem 7: Kite string length
Height = 40 m, angle = 65°
sin 65° = opposite/hypotenuse = 40/string
string = 40/sin 65° ≈ 40/0.9063 ≈ 44.13 m
Answer: Approximately 44.1 m.

Bonus Solutions

Bonus Problem 1: Angle Chase
Let tree height = h, distance from A to tree base = d
From point A: tan 30° = h/d → h = d tan 30° = d/√3
From point B (20 m closer): tan 45° = h/(d-20) → h = d - 20
Set equal: d/√3 = d - 20 → d = √3(d - 20) → d = √3d - 20√3
d(1 - √3) = -20√3 → d = 20√3/(√3 - 1) = 20√3(√3 + 1)/2 = 10√3(√3 + 1)
h = d - 20 = 10√3(√3 + 1) - 20 = 30√3 + 10√3 - 20 ≈ 71.96 m
Point C is 10 m farther than B, so distance from C = d + 10
Angle from C: tan θ = h/(d + 10)
θ = tan⁻¹(h/(d + 10)) ≈ tan⁻¹(71.96/81.96) ≈ 41.2°
Answer: Approximately 41.2°
Bonus Problem 2: Reciprocal Angles
In right triangle ABC with right angle at C: A + B = 90°, so B = 90° - A
Given: tan(A) × sin(B) = 1
Since B = 90° - A: sin(B) = sin(90° - A) = cos(A)
So: tan(A) × cos(A) = 1
tan(A) = sin(A)/cos(A), so: sin(A)/cos(A) × cos(A) = sin(A) = 1
Therefore A = 90°, but this contradicts A + B = 90°
Re-check: If B = 90° - A, then sin(B) = cos(A)
tan(A) × cos(A) = sin(A)/cos(A) × cos(A) = sin(A) = 1
This means A = 90°, which is impossible for a right triangle
The only solution is when the triangle degenerates: A = 90°, B = 0°
Answer: No valid solution in a proper right triangle.
Bonus Problem 3: Nested Triangles
Isosceles triangle with vertex angle 20°, base angles = 80° each
Interior point P with angles to base vertices: 30° and 50°
Let the base be AB, with angle at P to A = 30°, to B = 50°
Third angle at P: 180° - 30° - 50° = 100°
By Law of Sines in triangle PAB: PA/sin(50°) = PB/sin(30°) = AB/sin(100°)
Answer: The small triangle has angles 30°, 50°, 100°.
