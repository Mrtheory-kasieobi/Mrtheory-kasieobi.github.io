Techniques of Integration

Calculus II - Chapter 7.1-7.8

1. Integration by Parts

Integration by Parts: \(\int u \, dv = uv - \int v \, du\)
Example: \(\int x e^x \, dx\): Let \(u = x, dv = e^x dx\), then \(du = dx, v = e^x\) \(\int x e^x \, dx = x e^x - \int e^x \, dx = x e^x - e^x + C\)

2. Trigonometric Integrals

Strategy:
  • For \(\int \sin^m x \cos^n x \, dx\): Use substitution based on odd/even powers
  • For \(\int \sin^m x \cos^n x \, dx\) with odd m: Let \(u = \cos x\)
  • For \(\int \sin^m x \cos^n x \, dx\) with odd n: Let \(u = \sin x\)

3. Trigonometric Substitution

Substitution Rules:
  • For \(\sqrt{a^2 - x^2}\): Use \(x = a\sin\theta\)
  • For \(\sqrt{a^2 + x^2}\): Use \(x = a\tan\theta\)
  • For \(\sqrt{x^2 - a^2}\): Use \(x = a\sec\theta\)

4. Integration of Rational Functions

Partial Fractions: For \(\frac{P(x)}{Q(x)}\), decompose into simpler fractions: \(\frac{P(x)}{Q(x)} = \frac{A_1}{x - r_1} + \frac{A_2}{x - r_2} + \cdots\)

5. Strategy for Integration

Integration Strategy:
  1. Look for obvious substitutions
  2. Identify if it's a product (try integration by parts)
  3. Check for trigonometric forms
  4. Try partial fractions for rational functions
  5. Consider algebraic manipulation

6. Approximate Integration

Numerical Methods:
  • Trapezoidal Rule: \(T_n = \frac{\Delta x}{2}[f(x_0) + 2f(x_1) + \cdots + 2f(x_{n-1}) + f(x_n)]\)
  • Simpson's Rule: \(S_n = \frac{\Delta x}{3}[f(x_0) + 4f(x_1) + 2f(x_2) + \cdots + f(x_n)]\)

7. Improper Integrals

Improper Integral: \(\int_a^{\infty} f(x) \, dx = \lim_{t \to \infty} \int_a^t f(x) \, dx\)
