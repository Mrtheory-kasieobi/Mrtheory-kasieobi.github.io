Lecture 6: Quadratic Residues and the Legendre Symbol

Lecture 6Quadratic Residues and the Legendre Symbol

1. Quadratic Residues

Definition 6.1 (Quadratic Residue) Let \(p\) be an odd prime and \(\gcd(a, p) = 1\). We say that \(a\) is a quadratic residue modulo \(p\) if there exists an integer \(x\) such that \(x^2 \equiv a \pmod{p}\).
Example 6.1 Determine which elements of \(\mathbb{Z}_7^*\) are quadratic residues.

Compute squares modulo 7: \[1^2 \equiv 1, \quad 2^2 \equiv 4, \quad 3^2 \equiv 9 \equiv 2 \pmod{7}\] \[4^2 = (7-3)^2 \equiv 3^2 \equiv 2, \quad 5^2 = (7-2)^2 \equiv 2^2 \equiv 4 \pmod{7}\] \[6^2 = (7-1)^2 \equiv 1^2 \equiv 1 \pmod{7}\]

The quadratic residues modulo 7 are \(\{1, 2, 4\}\). \(\square\)

2. The Legendre Symbol

Definition 6.2 (Legendre Symbol) For an odd prime \(p\) and integer \(a\) with \(\gcd(a, p) = 1\), the Legendre symbol \(\left(\frac{a}{p}\right)\) is defined by: \[\left(\frac{a}{p}\right) = \begin{cases} 1 & \text{if } a \text{ is a quadratic residue modulo } p \\ -1 & \text{if } a \text{ is a quadratic non-residue modulo } p \end{cases}\] We extend the definition by setting \(\left(\frac{0}{p}\right) = 0\).
Example 6.2 Compute the Legendre symbols modulo 7.

From Example 6.1, the quadratic residues are \(\{1, 2, 4\}\).

\[\left(\frac{1}{7}\right) = 1, \quad \left(\frac{2}{7}\right) = 1, \quad \left(\frac{3}{7}\right) = -1\] \[\left(\frac{4}{7}\right) = 1, \quad \left(\frac{5}{7}\right) = -1, \quad \left(\frac{6}{7}\right) = -1\] \(\square\)

3. Properties of the Legendre Symbol

Theorem 6.1 (Multiplicativity) For any integers \(a, b\) and odd prime \(p\): \[\left(\frac{ab}{p}\right) = \left(\frac{a}{p}\right) \left(\frac{b}{p}\right).\]
Proof:

Let \(\varepsilon_1 = \left(\frac{a}{p}\right)\) and \(\varepsilon_2 = \left(\frac{b}{p}\right)\) where \(\varepsilon_1, \varepsilon_2 \in \{-1, 1\}\).

By definition, there exist integers \(x_1, x_2\) such that \(x_1^2 \equiv a \pmod{p}\) if \(\varepsilon_1 = 1\), and no such \(x_1\) exists if \(\varepsilon_1 = -1\).

Similarly for \(b\).

If \(\varepsilon_1 = \varepsilon_2 = 1\), then \((x_1 x_2)^2 \equiv ab \pmod{p}\), so \(\left(\frac{ab}{p}\right) = 1 = \varepsilon_1 \varepsilon_2\).

If \(\varepsilon_1 = 1, \varepsilon_2 = -1\), then \(a\) is a QR but \(b\) is not. Suppose \(ab\) is a QR. Then \((ab)x_1^2 \equiv a \cdot b \cdot x_1^2 \equiv a \cdot (\text{something}) \pmod{p}\). This would imply \(b\) is a QR, contradiction. Thus \(\left(\frac{ab}{p}\right) = -1 = \varepsilon_1 \varepsilon_2\).

The cases \(\varepsilon_1 = -1, \varepsilon_2 = 1\) and \(\varepsilon_1 = \varepsilon_2 = -1\) are similar. \(\square\)

4. Euler's Criterion

Theorem 6.2 (Euler's Criterion) Let \(p\) be an odd prime and \(\gcd(a, p) = 1\). Then: \[\left(\frac{a}{p}\right) \equiv a^{\frac{p-1}{2}} \pmod{p}.\] More precisely, \(\left(\frac{a}{p}\right) = (-1)^{\frac{p-1}{2}}\) when \(a\) is a quadratic non-residue.
Proof:

Let \(g\) be a primitive root modulo \(p\). Then any \(a\) with \(\gcd(a, p) = 1\) can be written as \(a \equiv g^k \pmod{p}\) for some \(k\).

We compute: \[\left(\frac{a}{p}\right) = \left(\frac{g^k}{p}\right) = \left(\frac{g}{p}\right)^k\]

By Fermat's Little Theorem, \(g^{p-1} \equiv 1 \pmod{p}\). Also, \(g^{\frac{p-1}{2}} \not\equiv 1 \pmod{p}\) (otherwise \(g\) wouldn't be a primitive root).

Therefore \(g^{\frac{p-1}{2}} \equiv -1 \pmod{p}\), so \(g\) is a quadratic non-residue, meaning \(\left(\frac{g}{p}\right) = -1\).

Thus \(\left(\frac{a}{p}\right) = (-1)^k\).

Now compute \(a^{\frac{p-1}{2}} = g^{k \cdot \frac{p-1}{2}} = (g^{\frac{p-1}{2}})^k \equiv (-1)^k \pmod{p}\).

Therefore \(\left(\frac{a}{p}\right) = a^{\frac{p-1}{2}}\) as integers (both equal \((-1)^k\)). \(\square\)

Example 6.3 Use Euler's Criterion to compute \(\left(\frac{3}{7}\right)\).

Compute \(3^{\frac{7-1}{2}} = 3^3 = 27 = 7 \cdot 3 + 6 \equiv -1 \pmod{7}\).

Thus \(\left(\frac{3}{7}\right) = -1\), confirming that 3 is a quadratic non-residue modulo 7. \(\square\)

Exercises:
  1. Find all quadratic residues modulo 11.
  2. Compute \(\left(\frac{2}{11}\right)\) using Euler's Criterion.
  3. Verify that \(\left(\frac{5}{7}\right) = \left(\frac{5}{7}\right)\) using multiplicativity.
  4. Prove: If \(p \equiv 1 \pmod{4}\), then \(\left(\frac{-1}{p}\right) = 1\).
  5. Find all solutions to \(x^2 \equiv 5 \pmod{11}\).
  6. Compute \(\left(\frac{13}{17}\right)\) using Euler's Criterion.
  7. Show that \(\left(\frac{a}{p}\right) = 1\) if and only if \(x^2 \equiv a \pmod{p}\) has a solution.
