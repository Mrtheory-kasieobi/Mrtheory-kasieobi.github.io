Solutions: Problem Set 8: Gaussian Integers

Solutions

Problem 1

Solution: Compute \(N(3+4i) = 3^2 + 4^2 = 9 + 16 = 25\). \(N(2-i) = 2^2 + (-1)^2 = 4 + 1 = 5\). \(N(-1+2i) = (-1)^2 + 2^2 = 1 + 4 = 5\).

Problem 2

Solution: \((1+i)(1-i) = 1 - i^2 = 1 - (-1) = 2\). \(N(1+i) = 1^2 + 1^2 = 2\).

Problem 3

Solution: Addition: \((2+3i) + (1-2i) = 3 + i\). Multiplication: \((2+3i)(1-2i) = 2 - 4i + 3i + 6 = 8 - i\). Both results are in \(\mathbb{Z}[i]\).

Problem 4

Solution: The inverse of \(2+i\) in \(\mathbb{Q}(i)\) is \(\frac{1}{2+i} = \frac{2-i}{(2+i)(2-i)} = \frac{2-i}{5} = \frac{2}{5} - \frac{1}{5}i\). Since \(\frac{2}{5}\) and \(\frac{1}{5}\) are not integers, the inverse is not in \(\mathbb{Z}[i]\).

Problem 5

Solution: Using Euclidean algorithm in \(\mathbb{Z}[i]\): \(\gcd(2+3i, 1+i)\). Compute \(\frac{2+3i}{1+i} = \frac{(2+3i)(1-i)}{(1+i)(1-i)} = \frac{5+i}{2} = \frac{5}{2} + \frac{1}{2}i\). Nearest Gaussian integer is \(2\). Remainder: \((2+3i) - 2(1+i) = i\). Continue with \(\gcd(1+i, i)\)... Result: \(\gcd = 1+i\) (up to associates).

Problem 6

Solution: \(N((1+2i)(2-i)) = N(4+3i) = 16 + 9 = 25\). \(N(1+2i) \cdot N(2-i) = 5 \cdot 5 = 25\). ✓

Problem 7

Solution: \(N(a+bi) = a^2 + b^2 = 0\) iff \(a = b = 0\), so \(a+bi = 0\). Conversely, if \(\alpha = 0\), then \(N(0) = 0\). ✓

Problem 8

Solution: We need \(a^2 + b^2 = 1\). Since \(a^2, b^2 \geq 0\), the only solutions are \((a,b) = (\pm 1, 0), (0, \pm 1)\). Thus the units are \(1, -1, i, -i\).

Problem 9

Solution: \(N(1+i) = 1^2 + 1^2 = 2\), which is prime in \(\mathbb{Z}\). In \(\mathbb{Z}[i]\), if \(N(\alpha)\) is prime in \(\mathbb{Z}\), then \(\alpha\) is irreducible.

Problem 10

Solution: If \(\gcd(a,b) = 1\) and \(a^2 + b^2 = z^n\), then in \(\mathbb{Z}[i]\), \((a+bi)(a-bi) = z^n\). Since \(\gcd(a+bi, a-bi) = 1\) or \(1+i\), both factors are \(n\)th powers (up to units).

Bonus Problems

Bonus Problem 1

Solution:

Step 1: For any \(\alpha, \beta \in \mathbb{Z}[i]\) with \(\beta \neq 0\), consider \(\frac{\alpha}{\beta} = \frac{\alpha\bar{\beta}}{N(\beta)}\).

Step 2: Write \(\frac{\alpha}{\beta} = q + r\) where \(q\) is the nearest Gaussian integer to \(\frac{\alpha}{\beta}\).

Step 3: Then \(N(r) = N(\frac{\alpha}{\beta} - q) < 1\) (since the maximum distance to nearest integer is \(\frac{\sqrt{2}}{2}\)).

Step 4: Thus \(N(\alpha - q\beta) = N(\beta)N(r) < N(\beta)\), proving the division algorithm.

Bonus Problem 2

Solution:

Step 1: If \(N(a+bi) = a^2 + b^2 = p\) is prime in \(\mathbb{Z}\), suppose \(a+bi = \gamma\delta\) in \(\mathbb{Z}[i]\).

Step 2: Then \(p = N(a+bi) = N(\gamma)N(\delta)\).

Step 3: Since \(p\) is prime, one of \(N(\gamma), N(\delta)\) equals 1, making it a unit.

Conclusion: \(a+bi\) is irreducible in \(\mathbb{Z}[i]\).

Bonus Problem 3

Solution:

Step 1: \(\mathbb{Z}[i]\) is Euclidean with respect to \(N(a+bi) = a^2 + b^2\).

Step 2: Euclidean domains are UFDs (unique factorization domains).

Step 3: In a Euclidean domain, every non-zero non-unit element has a factorization into irreducibles, and this factorization is unique up to units.

Conclusion: \(\mathbb{Z}[i]\) has unique factorization.
