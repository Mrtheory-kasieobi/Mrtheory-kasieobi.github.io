Solutions: Problem Set 11: Diophantine Equations

Solutions

Problem 1

Solution: \(12x + 18y = 6\) simplifies to \(2x + 3y = 1\). One solution: \(x = -1, y = 1\). General: \(x = -1+3t, y = 1-2t\) for \(t \in \mathbb{Z}\).

Problem 2

Solution: For \(a^2+b^2=25\) with \(\gcd(a,b)=1\): \(3^2+4^2=25\). So \((a,b,c) = (3,4,5)\) is the only primitive triple with \(c=25\).

Problem 3

Solution: If \(x^2+y^2=3z^2\), then \(x^2+y^2 \equiv 0 \pmod{3}\). Squares mod 3 are 0,1, so \(x^2 \equiv y^2 \equiv 0 \pmod{3}\), meaning \(3|x,y\). Write \(x=3x', y=3y'\): \(9x'^2+9y'^2=3z^2\), so \(3(x'^2+y'^2)=z^2\), hence \(3|z\). Infinite descent applies.

Problem 4

Solution: \(x^2 - 3y^2 = 1\). Fundamental solution: \((x,y) = (2,1)\) since \(4 - 3 = 1\). All solutions: \(x_n + y_n\sqrt{3} = (2+\sqrt{3})^n\).

Problem 5

Solution: \(65 = 1^2 + 8^2 = 1 + 64\). Also \(65 = 7^2 + 4^2 = 49 + 16\). So \(65 = (1+8i)(1-8i) = (7+4i)(7-4i)\).

Problem 6

Solution: If \(\gcd(x,y)=1\) and \(x^2+y^2=z^n\), then in \(\mathbb{Z}[i]\), \((x+yi)(x-yi) = z^n\). Since \(\gcd(x+yi, x-yi) = 1\) (or \(1+i\)), both factors are \(n\)th powers up to units.

Problem 7

Solution: \(85 = 9^2 + 2^2 = 81 + 4\). So \(85 = (3+2i)(3-2i)\). Wait, let me recalculate: \(7^2+4^2=49+16=65 \neq 85\). Actually \(85 = 7^2+6^2 = 49+36 = 85\). So \(85 = (7+6i)(7-6i)\).

Problem 8

Solution: \(85 = 5 \times 17 = (2+i)(2-i)(4+i)(4-i)\). This is the prime factorization in \(\mathbb{Z}[i]\).

Problem 9

Solution: \(125 = 5^3 = (2+i)^3(2-i)^3\). Verify: \(N(2+i) = 5\), so \(N((2+i)^3) = 5^3 = 125\). ✓

Problem 10

Solution: If \(p = a^2+b^2\) is prime, then \(p^k = \text{Re}((a+bi)^k)^2 + \text{Im}((a+bi)^k)^2\) by De Moivre's formula. For example, if \(p=5\), then \(5^k = \text{Re}((1+2i)^k)^2 + \text{Im}((1+2i)^k)^2\).

Bonus Problems

Bonus Problem 1

Solution:

Step 1: Fermat's Two Squares Theorem: An odd prime \(p\) is a sum of two squares iff \(p \equiv 1 \pmod{4}\).

Step 2: Proof uses that \(-1\) is a quadratic residue mod \(p\) iff \(p \equiv 1 \pmod{4}\).

Step 3: If \(p \equiv 1 \pmod{4}\), find \(k\) with \(k^2 \equiv -1 \pmod{p}\).

Step 4: Then \(p | (k^2+1)\), so \(p = (k+i)(k-i)\) in \(\mathbb{Z}[i]\).

Bonus Problem 2

Solution:

Step 1: Suppose \(p = a^2+b^2 = c^2+d^2\) with \(a,b,c,d > 0\) and \((a,b) \neq (c,d), (d,c)\).

Step 2: In \(\mathbb{Z}[i]\): \(p = (a+bi)(a-bi) = (c+di)(c-di)\).

Step 3: By unique factorization, \(a+bi\) and \(c+di\) differ by a unit factor.

Step 4: The units are \(1, -1, i, -i\), giving at most 4 representations, all equivalent up to signs and order.

Bonus Problem 3

Solution:

Step 1: \(x^2 - 10y^2 = 1\). Find fundamental solution by testing small values.

Step 2: \(3^2 - 10 \cdot 1^2 = 9 - 10 = -1\). So \((3,1)\) solves \(x^2 - 10y^2 = -1\).

Step 3: Then \((3+\sqrt{10})^2 = 19 + 6\sqrt{10}\) gives \(19^2 - 10 \cdot 6^2 = 361 - 360 = 1\).

Conclusion: Fundamental solution: \((19, 6)\).
