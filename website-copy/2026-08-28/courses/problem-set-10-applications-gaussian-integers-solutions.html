Solutions: Problem Set 10: Applications of Gaussian Integers

Solutions

Problem 1

Solution: \(5 = 1^2 + 2^2 = (1+2i)(1-2i)\). Both factors are Gaussian primes since \(N(1 \pm 2i) = 5\) is prime in \(\mathbb{Z}\).

Problem 2

Solution: \(13 = 2^2 + 3^2 = (2+3i)(2-3i)\). Check: \(N(2+3i) = 13\) prime, so both factors are Gaussian primes.

Problem 3

Solution: \(17 = 1^2 + 4^2 = (1+4i)(1-4i)\). Verify: \(N(1+4i) = 17\) prime in \(\mathbb{Z}\).

Problem 4

Solution: \(29 = 2^2 + 5^2 = (2+5i)(2-5i)\). Check: \(N(2+5i) = 29\) prime in \(\mathbb{Z}\).

Problem 5

Solution: Primes \(p \equiv 1 \pmod{4}\) can be written as sum of two squares: 5, 13, 17, 29, 37, 41, 53, 61, 73, 89, 97, ... This is Fermat's Two Squares Theorem.

Problem 6

Solution: \(65 = 1^2 + 8^2 = 64 + 1\) and \(65 = 7^2 + 4^2 = 49 + 16\). So \(65 = (1+8i)(1-8i) = (7+4i)(7-4i)\).

Problem 7

Solution: \(85 = 2^2 + 9^2 = 4 + 81\) and \(85 = 6^2 + 7^2 = 36 + 49\). So \(85 = (2+9i)(2-9i) = (6+7i)(6-7i)\).

Problem 8

Solution: \(85 = 5 \cdot 17 = (1+2i)(1-2i)(2+3i)(2-3i)\). This is the prime factorization in \(\mathbb{Z}[i]\).

Problem 9

Solution: \(125 = 5^3\). In \(\mathbb{Z}[i]\): \(5 = (2+i)(2-i)\), so \(125 = (2+i)^3(2-i)^3\).

Problem 10

Solution: If \(p = a^2+b^2\) is prime, then \(p^k = \text{Re}((a+bi)^k)^2 + \text{Im}((a+bi)^k)^2\) by De Moivre's formula.

Bonus Problems

Bonus Problem 1

Solution:

Step 1: If \(p \equiv 1 \pmod{4}\) is prime, then \(p = a^2+b^2\) is unique up to signs and order.

Step 2: Suppose \(p = a^2+b^2 = c^2+d^2\) with \(a,b,c,d > 0\).

Step 3: In \(\mathbb{Z}[i]\): \((a+bi)(a-bi) = (c+di)(c-di) = p\).

Step 4: By unique factorization, \(a+bi = u(c+di)\) for some unit \(u \in \{1, -1, i, -i\}\).

Step 5: This gives \((a,b) = (c,d), (-c,-d), (-d,c), (d,-c)\), all essentially the same representation.

Bonus Problem 2

Solution:

Step 1: Use the identity: if \(p \equiv 1 \pmod{4}\), then \(-1\) is a quadratic residue.

Step 2: Find \(k\) with \(k^2 \equiv -1 \pmod{p}\) using Tonelli-Shanks or by testing.

Step 3: Then \(p | (k^2+1) = (k+i)(k-i)\). Since \(k+i\) and \(k-i\) are not divisible by \(p\), we have \(p = (k+i)(k-i)\) up to units.

Step 4: The triangle with sides \((k, 1, \sqrt{p})\) has area \(\frac{k}{2}\).

Bonus Problem 3

Solution:

Step 1: If \(p \equiv 3 \pmod{4}\), then \(\left(\frac{-1}{p}\right) = -1\).

Step 2: So \(x^2 \equiv -1 \pmod{p}\) has no solution.

Step 3: If \(p\) were congruent, there would exist \(a,b\) with \(a^2+b^2 = p\).

Step 4: Then \((a/b)^2 \equiv -1 \pmod{p}\), contradiction.

Conclusion: No right triangle with integer sides has area \(p\).
