Trigonometry: Angles and Unit Circle

Precalculus 11 - Lecture Notes
British Columbia Curriculum | Last Updated: 2026

1. Introduction to Angles

An angle is formed by two rays sharing a common endpoint called the vertex. Trigonometry is the study of relationships between angles and sides of triangles, particularly right triangles.

Definition: An angle is a measure of rotation from one ray to another around a common vertex. Angles are measured in degrees (°) or radians (rad).

1.1 Angle Measurement

Angles can be measured in two common units:

  • Degrees: One complete rotation = 360°
  • Radians: One complete rotation = \(2\pi\) radians
Conversion between Degrees and Radians:
\[\text{Radians} = \text{Degrees} \times \frac{\pi}{180^\circ}\]

\[\text{Degrees} = \text{Radians} \times \frac{180^\circ}{\pi}\]
Example 1: Converting Degrees to Radians

Convert \(90^\circ\) to radians:

\[90^\circ \times \frac{\pi}{180^\circ} = \frac{\pi}{2} \text{ radians}\]

Example 2: Converting Radians to Degrees

Convert \(\frac{3\pi}{4}\) radians to degrees:

\[\frac{3\pi}{4} \times \frac{180^\circ}{\pi} = 135^\circ\]

1.2 Standard Position

An angle is in standard position when its vertex is at the origin and its initial side lies along the positive x-axis. The angle is measured counterclockwise from the initial side to the terminal side.

1.3 Coterminal Angles

Two angles are coterminal if they share the same terminal side. Coterminal angles differ by multiples of \(360^\circ\) or \(2\pi\) radians.

Finding Coterminal Angles:
\[\theta_{\text{coterminal}} = \theta \pm 360^\circ n\]
or
\[\theta_{\text{coterminal}} = \theta \pm 2\pi n\]
Example 3: Coterminal Angles

Find a positive coterminal angle for \(-45^\circ\):

\[-45^\circ + 360^\circ = 315^\circ\]

2. The Unit Circle

The unit circle is a circle with radius 1 centered at the origin of the coordinate plane. It is a fundamental tool in trigonometry for defining trigonometric functions for all angles.

Definition: The unit circle is the set of all points \((x, y)\) such that \(x^2 + y^2 = 1\). For any angle \(\theta\) in standard position, the point where the terminal side intersects the unit circle has coordinates \((\cos \theta, \sin \theta)\).

2.1 Coordinates on the Unit Circle

For any angle \(\theta\) in standard position, if the terminal side intersects the unit circle at point \(P(x, y)\), then:

  • \(x = \cos \theta\) (x-coordinate)
  • \(y = \sin \theta\) (y-coordinate)

2.2 Special Angles on the Unit Circle

There are several special angles whose coordinates on the unit circle are commonly used:

Angle (degrees) Angle (radians) \(\cos \theta\) \(\sin \theta\)
\(0^\circ\) \(0\) \(1\) \(0\)
\(30^\circ\) \(\frac{\pi}{6}\) \(\frac{\sqrt{3}}{2}\) \(\frac{1}{2}\)
\(45^\circ\) \(\frac{\pi}{4}\) \(\frac{\sqrt{2}}{2}\) \(\frac{\sqrt{2}}{2}\)
\(60^\circ\) \(\frac{\pi}{3}\) \(\frac{1}{2}\) \(\frac{\sqrt{3}}{2}\)
\(90^\circ\) \(\frac{\pi}{2}\) \(0\) \(1\)
\(180^\circ\) \(\pi\) \(-1\) \(0\)
\(270^\circ\) \(\frac{3\pi}{2}\) \(0\) \(-1\)
\(360^\circ\) \(2\pi\) \(1\) \(0\)
Memory Aid:

A common mnemonic for remembering the special angle values is to use the "hand trick" or memorize the patterns in the table above. Notice that cosine values decrease from 1 to 0 as angles increase from \(0^\circ\) to \(90^\circ\), while sine values increase from 0 to 1.

3. Trigonometric Ratios

For a right triangle with angle \(\theta\), the three primary trigonometric ratios are defined as follows:

Right Triangle Definitions:

\[\sin \theta = \frac{\text{opposite}}{\text{hypotenuse}} = \frac{o}{h}\]

\[\cos \theta = \frac{\text{adjacent}}{\text{hypotenuse}} = \frac{a}{h}\]

\[\tan \theta = \frac{\text{opposite}}{\text{adjacent}} = \frac{o}{a}\]

3.1 Reciprocal Trigonometric Functions

In addition to the three primary functions, there are three reciprocal functions:

\[\csc \theta = \frac{1}{\sin \theta} = \frac{\text{hypotenuse}}{\text{opposite}}\]

\[\sec \theta = \frac{1}{\cos \theta} = \frac{\text{hypotenuse}}{\text{adjacent}}\]

\[\cot \theta = \frac{1}{\tan \theta} = \frac{\text{adjacent}}{\text{opposite}}\]
Example 4: Finding Trigonometric Ratios

In a right triangle, if \(\theta = 30^\circ\) and the hypotenuse is 10 cm, find the opposite and adjacent sides.

Solution:

Using \(\sin 30^\circ = \frac{1}{2}\):

\[\sin 30^\circ = \frac{\text{opposite}}{10} = \frac{1}{2}\]

\[\text{opposite} = 10 \times \frac{1}{2} = 5 \text{ cm}\]

Using \(\cos 30^\circ = \frac{\sqrt{3}}{2}\):

\[\cos 30^\circ = \frac{\text{adjacent}}{10} = \frac{\sqrt{3}}{2}\]

\[\text{adjacent} = 10 \times \frac{\sqrt{3}}{2} = 5\sqrt{3} \approx 8.66 \text{ cm}\]

4. Reference Angles

A reference angle is the acute angle formed by the terminal side of an angle and the x-axis. Reference angles are useful for finding trigonometric values of angles in any quadrant.

Definition: The reference angle \(\theta_{\text{ref}}\) is the positive acute angle between the terminal side of \(\theta\) and the x-axis.

4.1 Finding Reference Angles

The method for finding the reference angle depends on the quadrant:

  • Quadrant I: \(\theta_{\text{ref}} = \theta\)
  • Quadrant II: \(\theta_{\text{ref}} = 180^\circ - \theta\) or \(\pi - \theta\)
  • Quadrant III: \(\theta_{\text{ref}} = \theta - 180^\circ\) or \(\theta - \pi\)
  • Quadrant IV: \(\theta_{\text{ref}} = 360^\circ - \theta\) or \(2\pi - \theta\)
Example 5: Finding Reference Angles

Find the reference angle for \(\theta = 210^\circ\):

Since \(210^\circ\) is in Quadrant III:

\[\theta_{\text{ref}} = 210^\circ - 180^\circ = 30^\circ\]

4.2 Using Reference Angles

To find the trigonometric value of any angle \(\theta\):

  1. Find the reference angle \(\theta_{\text{ref}}\)
  2. Find the trigonometric value of the reference angle
  3. Apply the appropriate sign based on the quadrant
ASTC Rule (All Students Take Calculus):

In Quadrant I: All functions are positive
In Quadrant II: Sine and cosecant are positive
In Quadrant III: Tangent and cotangent are positive
In Quadrant IV: Cosine and secant are positive

5. Trigonometric Functions of Any Angle

Using the unit circle, we can define the six trigonometric functions for any angle \(\theta\):

Unit Circle Definitions:

\[\sin \theta = y\]
\[\cos \theta = x\]
\[\tan \theta = \frac{y}{x} = \frac{\sin \theta}{\cos \theta}\]

\[\csc \theta = \frac{1}{y} = \frac{1}{\sin \theta}\]
\[\sec \theta = \frac{1}{x} = \frac{1}{\cos \theta}\]
\[\cot \theta = \frac{x}{y} = \frac{\cos \theta}{\sin \theta}\]

5.1 Domain and Range

  • Sine and Cosine: Domain is all real numbers, Range is \([-1, 1]\)
  • Tangent and Cotangent: Domain excludes angles where the function is undefined, Range is all real numbers
  • Secant and Cosecant: Domain excludes angles where the function is undefined, Range is \((-\infty, -1] \cup [1, \infty)\)

6. The Sine Law

The Sine Law (also called the Law of Sines) is used to solve oblique triangles (triangles that do not contain a right angle). It relates the sides of a triangle to the sines of its angles.

The Sine Law:
\[\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}\]

Where \(a\), \(b\), and \(c\) are the side lengths opposite to angles \(A\), \(B\), and \(C\) respectively.

6.1 When to Use the Sine Law

The Sine Law can be used when you know:

  • Two angles and one side (AAS or ASA)
  • Two sides and an angle opposite one of them (SSA) - the ambiguous case
Example 6: Using the Sine Law

In triangle \(ABC\), \(A = 35^\circ\), \(B = 65^\circ\), and \(a = 12\) cm. Find side \(b\).

Solution:

First, find angle \(C\):

\[C = 180^\circ - 35^\circ - 65^\circ = 80^\circ\]

Using the Sine Law:

\[\frac{a}{\sin A} = \frac{b}{\sin B}\]

\[\frac{12}{\sin 35^\circ} = \frac{b}{\sin 65^\circ}\]

\[b = \frac{12 \cdot \sin 65^\circ}{\sin 35^\circ} \approx \frac{12 \cdot 0.9063}{0.5736} \approx 18.97 \text{ cm}\]

6.2 The Ambiguous Case (SSA)

When given two sides and a non-included angle (SSA), there may be:

  • No solution: If \(a < h\) (where \(h = b \sin A\))
  • One solution: If \(a \geq b\) or \(a = h\)
  • Two solutions: If \(h < a < b\)
Ambiguous Case:

When using SSA, always check if the given information produces one or two possible triangles. The height \(h = b \sin A\) helps determine the number of solutions.

7. The Cosine Law

The Cosine Law (also called the Law of Cosines) is used to solve triangles when the Sine Law cannot be applied. It relates the lengths of the sides of a triangle to the cosine of one of its angles.

The Cosine Law:
\[a^2 = b^2 + c^2 - 2bc \cos A\]
\[b^2 = a^2 + c^2 - 2ac \cos B\]
\[c^2 = a^2 + b^2 - 2ab \cos C\]

7.1 When to Use the Cosine Law

The Cosine Law can be used when you know:

  • Three sides (SSS) - to find an angle
  • Two sides and the included angle (SAS) - to find the third side
Example 7: Using the Cosine Law

In triangle \(ABC\), \(a = 8\) cm, \(b = 10\) cm, and \(C = 60^\circ\). Find side \(c\).

Solution:

Using the Cosine Law:

\[c^2 = a^2 + b^2 - 2ab \cos C\]

\[c^2 = 8^2 + 10^2 - 2(8)(10) \cos 60^\circ\]

\[c^2 = 64 + 100 - 160(0.5)\]

\[c^2 = 164 - 80 = 84\]

\[c = \sqrt{84} \approx 9.17 \text{ cm}\]

7.2 Finding Angles Using the Cosine Law

To find an angle when all three sides are known, rearrange the formula:

\[\cos A = \frac{b^2 + c^2 - a^2}{2bc}\]
\[\cos B = \frac{a^2 + c^2 - b^2}{2ac}\]
\[\cos C = \frac{a^2 + b^2 - c^2}{2ab}\]
Example 8: Finding an Angle

In triangle \(ABC\), \(a = 7\) cm, \(b = 8\) cm, and \(c = 9\) cm. Find angle \(C\).

Solution:

Using the rearranged Cosine Law:

\[\cos C = \frac{a^2 + b^2 - c^2}{2ab}\]

\[\cos C = \frac{7^2 + 8^2 - 9^2}{2(7)(8)}\]

\[\cos C = \frac{49 + 64 - 81}{112} = \frac{32}{112} \approx 0.2857\]

\[C = \cos^{-1}(0.2857) \approx 73.4^\circ\]

8. Solving Triangle Problems

8.1 Strategy for Solving Triangles

  1. Draw a diagram and label all known information
  2. Determine which law to use (Sine Law or Cosine Law)
  3. Apply the appropriate law
  4. Solve for the unknown values
  5. Check your answer using the triangle angle sum or other relationships

8.2 Applications

The Sine and Cosine Laws are used to solve real-world problems involving:

  • Navigation and bearings
  • Surveying and mapping
  • Physics (forces, vectors)
  • Engineering problems
Example 9: Real-World Application

A ship leaves port and sails 15 km on a bearing of \(045^\circ\), then changes course and sails 20 km on a bearing of \(135^\circ\). How far is the ship from the port?

Solution:

This forms a triangle with two sides and the included angle. Use the Cosine Law:

\[c^2 = 15^2 + 20^2 - 2(15)(20) \cos 90^\circ\]

\[c^2 = 225 + 400 - 0 = 625\]

\[c = 25 \text{ km}\]
