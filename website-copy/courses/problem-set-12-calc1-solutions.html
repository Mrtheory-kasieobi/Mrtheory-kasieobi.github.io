Problem Set 12: Midterm Review - SOLUTIONS

Calculus I - Week 11

Solution Guide

Problem 1: \(\lim_{x \to 0} \frac{\sin x}{x}\)

Solution: Standard limit = 1. Can use L'Hôpital or squeeze theorem.

Problem 2: \(\lim_{x \to \infty} \frac{e^x}{x^3}\)

Solution: Exponential grows faster. \(\infty\). L'Hôpital 3 times: \(\frac{e^x}{6}\)

Problem 3: \(\lim_{x \to 0} \frac{1-\cos x}{x^2}\)

Solution: L'Hôpital: \(\frac{\sin x}{2x} = \frac{\cos x}{2} = \frac{1}{2}\)

Problem 4: \(\lim_{x \to 1} \frac{x^3-1}{x-1}\)

Solution: Factor: \(\frac{(x-1)(x^2+x+1)}{x-1} = x^2+x+1\). Limit = 3.

Problem 5: Continuity of \(f(x) = \frac{x^2-4}{x-2}\)

Solution: Discontinuous at \(x = 2\). Removable discontinuity (hole).

Problem 6: \(\frac{d}{dx}[\sin(x^2+3x)]\)

Solution: Chain rule: \(\cos(x^2+3x)(2x+3)\)

Problem 7: \(\frac{d}{dx}[e^{x^2}]\)

Solution: Chain rule: \(e^{x^2} \cdot 2x = 2xe^{x^2}\)

Problem 8: Critical points of \(f(x) = x^3 - 6x^2 + 9x + 1\)

Solution: \(f'(x) = 3x^2 - 12x + 9 = 3(x-1)(x-3)\). Critical at \(x=1,3\).

Problem 9: \(\int_0^1 (4x^3 - 2x) \, dx\)

Solution: \(\left[x^4 - x^2\right]_0^1 = 1 - 1 = 0\)

Problem 10: Find \(a\) so \(\int_0^a x(1-x) dx = 0\)

Solution: \(\left[\frac{x^2}{2} - \frac{x^3}{3}\right]_0^a = \frac{a^2}{2} - \frac{a^3}{3} = 0\).
\(a^2(\frac{3}{6} - \frac{2a}{6}) = 0 \Rightarrow a = 0\) or \(a = \frac{3}{2}\)

Bonus 1: \(\lim_{x \to 0} \frac{e^x - 1}{x}\)

Solution: L'Hôpital or definition of derivative: = 1

Bonus 2: If \(f'(x) = x^2\) and \(f(0) = 3\), find \(f(x)\)

Solution: \(f(x) = \frac{x^3}{3} + C\). Using \(f(0) = 3\): \(C = 3\).
\(f(x) = \frac{x^3}{3} + 3\)
