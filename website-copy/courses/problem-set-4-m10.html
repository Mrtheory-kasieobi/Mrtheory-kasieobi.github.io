Problem Set 4: Roots and Powers

Mathematics 10 - Chapter 4 Medium

Problems

Problem 1

Simplify: \(x^5 \times x^3 \div x^2\) using the law \(a^m \times a^n = a^{m+n}\) and \(\frac{a^m}{a^n} = a^{m-n}\)

Problem 2

Simplify: \((x^2 y^3)^4 \div (x y^2)^2\)

Problem 3

Simplify: \(\frac{(2a^{-3})^2}{(4a^{-1})^2}\)

Problem 4

Express in scientific notation: \(0.0000456\) and \(5,400,000\)

Problem 5

Simplify: \(\left(\frac{a^{-2}b^3}{a^4b^{-1}}\right)^{-2}\)

Problem 6

Evaluate: \((2.5 \times 10^3) \times (4 \times 10^5)\) in scientific notation

Problem 7

Simplify: \(\frac{(3x^2y^{-1})^3}{(9xy^2)^2}\)

Problem 8

Find the value of \(n\) if \(2^n = 0.125\) (Hint: \(0.125 = \frac{1}{8} = \frac{1}{2^3}\))

Bonus Problems

Bonus Problem 1

Challenge: A computer chip has \(8\) GB of memory. Express this in bytes using scientific notation, given that \(1\) GB \(= 10^9\) bytes. Then express the number of bits if each byte contains \(8\) bits. (Hint: \(8 = 8 \times 10^0\))

Bonus Problem 2

Challenge: Simplify: \(\left(\frac{2^{-3} \times 4^2}{8^{-1}}\right)^2\) without using a calculator. (Hint: Write all bases as powers of \(2\): \(4 = 2^2\), \(8 = 2^3\))

Bonus Problem 3

Challenge: The mass of an electron is approximately \(9.11 \times 10^{-31}\) kg and the mass of a proton is approximately \(1.67 \times 10^{-27}\) kg. How many times heavier is a proton than an electron? Express your answer in scientific notation. (Hint: Divide the proton mass by the electron mass)
