Problem Set 4: Chain Rule and Implicit Differentiation - SOLUTIONS

Calculus I - Week 4

Instructions

Show all work. No calculators. Write clearly and show each step.

Solution Guide

Problem 1: Find \(\frac{dy}{dx}\) for \(y = \sin(x^3 + 2x)\)

Solution: Apply chain rule with outside function \(\sin u\) and inside function \(u = x^3 + 2x\).
\(\frac{dy}{dx} = \cos(x^3 + 2x) \cdot (3x^2 + 2) = (3x^2 + 2)\cos(x^3 + 2x)\)

Problem 2: Find \(\frac{d}{dx}[e^{\tan(x^2)}]\)

Solution: Apply chain rule with three layers:
Outside: \(e^u\), Middle: \(\tan v\), Inside: \(v = x^2\)
\(\frac{d}{dx} = e^{\tan(x^2)} \cdot \sec^2(x^2) \cdot 2x = 2xe^{\tan(x^2)}\sec^2(x^2)\)

Problem 3: Find \(\frac{d}{dx}[\ln(\sin(x^2))]\)

Solution: Chain rule with outside \(\ln u\) and inside \(u = \sin(x^2)\)
\(\frac{d}{dx} = \frac{1}{\sin(x^2)} \cdot \cos(x^2) \cdot 2x = \frac{2x\cos(x^2)}{\sin(x^2)} = 2x\cot(x^2)\)

Problem 4: If \(y = \sqrt[3]{x^2 + 1}\), find \(\frac{dy}{dx}\)

Solution: Rewrite as \(y = (x^2 + 1)^{1/3}\). Apply chain rule:
\(\frac{dy}{dx} = \frac{1}{3}(x^2 + 1)^{-2/3} \cdot 2x = \frac{2x}{3(x^2 + 1)^{2/3}}\)

Problem 5: Find \(\frac{dy}{dx}\) for \(y = (2x^3 - 5)^{-4}\)

Solution: Chain rule with outside \(u^{-4}\) and inside \(u = 2x^3 - 5\)
\(\frac{dy}{dx} = -4(2x^3 - 5)^{-5} \cdot 6x^2 = -\frac{24x^2}{(2x^3 - 5)^5}\)

Problem 6: Use implicit differentiation to find \(\frac{dy}{dx}\) for \(x^2y + y^3 = 6\)

Solution: Differentiate both sides:
\(2xy + x^2\frac{dy}{dx} + 3y^2\frac{dy}{dx} = 0\)
Collect terms: \(\frac{dy}{dx}(x^2 + 3y^2) = -2xy\)
\(\frac{dy}{dx} = -\frac{2xy}{x^2 + 3y^2}\)

Problem 7: Find \(\frac{dy}{dx}\) for \(\sin(x+y) = x + y\) (solve for \(\frac{dy}{dx}\) in terms of \(x\) and \(y\))

Solution: Differentiate implicitly:
\(\cos(x+y)(1 + \frac{dy}{dx}) = 1 + \frac{dy}{dx}\)
Expand: \(\cos(x+y) + \cos(x+y)\frac{dy}{dx} = 1 + \frac{dy}{dx}\)
Collect: \(\frac{dy}{dx}[\cos(x+y) - 1] = 1 - \cos(x+y)\)
\(\frac{dy}{dx} = \frac{1 - \cos(x+y)}{\cos(x+y) - 1} = -1\) (when \(\cos(x+y) \neq 1\))

Problem 8: A spherical balloon is being inflated. If the radius increases at 2 cm/s, how fast is the volume increasing when \(r = 10\) cm?

Solution: Volume of sphere: \(V = \frac{4}{3}\pi r^3\).
\(\frac{dV}{dt} = 4\pi r^2 \frac{dr}{dt}\).
When \(r = 10, \frac{dr}{dt} = 2\):
\(\frac{dV}{dt} = 4\pi(100)(2) = 800\pi\) cm³/s

Problem 9: Find the equation of the tangent line to \(y = e^{x^2}\) at \(x = 1\)

Solution: Point: \(y = e^{1} = e\), so \((1, e)\).
Derivative: \(y' = e^{x^2} \cdot 2x\). At \(x = 1\): \(y' = 2e\).
Tangent line: \(y - e = 2e(x - 1)\), or \(y = 2ex - e\)

Problem 10: Find \(\frac{d}{dx}[x^{x}]\) using logarithmic differentiation

Solution: Let \(y = x^x\). Take \(\ln\): \(\ln y = x\ln x\).
Differentiate: \(\frac{1}{y}\frac{dy}{dx} = \ln x + x \cdot \frac{1}{x} = \ln x + 1\).
\(\frac{dy}{dx} = y(\ln x + 1) = x^x(\ln x + 1)\)

Bonus 1: Find \(\frac{dy}{dx}\) for \(y = (\sin x)^{\cos x}\)

Solution: Logarithmic differentiation. Take \(\ln\): \(\ln y = \cos x \ln(\sin x)\).
Differentiate: \(\frac{1}{y}\frac{dy}{dx} = -\sin x \ln(\sin x) + \cos x \cdot \frac{\cos x}{\sin x}\)
\(\frac{dy}{dx} = y[-\sin x \ln(\sin x) + \cot x \cos x]\)

Bonus 2: If \(f(g(x)) = x\) for all \(x\), prove that \(g(f(x)) = x\) for all \(x\) in the appropriate domains

Solution: Since \(f(g(x)) = x\), \(g\) is a left inverse of \(f\).
Differentiating: \(f'(g(x)) \cdot g'(x) = 1\), so \(f'(g(x)) \neq 0\).
This means \(f\) is locally invertible with inverse \(g\), so \(g(f(x)) = x\) on the range of \(f\).
