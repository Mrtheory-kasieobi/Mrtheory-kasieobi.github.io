Problem Set 2: Limits and Continuity - SOLUTIONS

Calculus I - Week 2

Solution Guide

Note: These are detailed solution outlines. Show all work when completing problems.

Problem 1: Evaluate \(\lim_{x \to 2} \frac{x^2 - 4}{x - 2}\)

Solution: Factor numerator: \(\frac{(x-2)(x+2)}{x-2} = x+2\) for \(x \neq 2\). Then \(\lim_{x \to 2} (x+2) = 4\).

Problem 2: Evaluate \(\lim_{x \to 0} \frac{\sin(5x)}{x}\)

Solution: \(\lim_{x \to 0} \frac{\sin(5x)}{x} = \lim_{x \to 0} 5 \cdot \frac{\sin(5x)}{5x} = 5 \cdot 1 = 5\)

Problem 3: Evaluate \(\lim_{x \to 0} \frac{\sqrt{x+4} - 2}{x - 2}\)

Solution: Rationalize: multiply by conjugate \(\frac{\sqrt{x+4} + 2}{\sqrt{x+4} + 2}\). Result: \(\frac{1}{\sqrt{x+4} + 2}\). Limit = \(\frac{1}{4}\).

Problem 4: Find \(\lim_{x \to \infty} \frac{3x^2 + 2x - 1}{2x^2 + 5}\)

Solution: Divide numerator and denominator by \(x^2\): \(\frac{3 + \frac{2}{x} - \frac{1}{x^2}}{2 + \frac{5}{x^2}}\). Limit = \(\frac{3}{2}\).

Problem 5: Find \(\lim_{x \to 0^+} \ln x\)

Solution: As \(x \to 0^+\), \(\ln x \to -\infty\). The limit is \(-\infty\).

Problem 6: Evaluate \(\lim_{x \to 0} \frac{e^x - 1}{x}\)

Solution: This is the definition of the derivative of \(e^x\) at \(x = 0\). Limit = \(e^0 = 1\).

Problem 7: Evaluate \(\lim_{x \to 1} \frac{x^3 - 1}{x^4 - 1}\)

Solution: Factor: \(\frac{(x-1)(x^2+x+1)}{(x-1)(x+1)(x^2+1)}\). Cancel \((x-1)\) and evaluate at \(x=1\): \(\frac{3}{4}\).

Problem 8: Continuity at \(x = 2\) for \(f(x) = \frac{x^2 - 1}{x - 1}\)

Solution: \(f(2) = \frac{3}{1} = 3\). \(\lim_{x \to 2} f(x) = \lim_{x \to 2} (x+1) = 3\). Continuous at \(x = 2\).

Problem 9: Find \(a\) such that \(f(x) = \begin{cases} x^2 + 1 & x < 2 \\ ax + 3 & x \geq 2 \end{cases}\) is continuous

Solution: Need \(\lim_{x \to 2^-} f(x) = \lim_{x \to 2^+} f(x) = f(2)\). Left limit = 5. Right limit = \(2a + 3\). So \(2a + 3 = 5 \Rightarrow a = 1\).

Problem 10: Prove \(\lim_{x \to 0} \frac{1 - \cos x}{x} = 0\)

Solution: Multiply by \(\frac{1 + \cos x}{1 + \cos x}\): \(\frac{\sin^2 x}{x(1+\cos x)} = \frac{\sin x}{x} \cdot \frac{\sin x}{1+\cos x}\). Limit = \(1 \cdot 0 = 0\).

Bonus Problems

B1 Solution: \(\lim_{x \to 0} \frac{\tan x - \sin x}{x^3} = \frac{1}{2}\) using Taylor series or L'Hôpital's Rule.
B2 Solution: If \(f\) and \(g\) are continuous at \(a\), then \(f+g\) is continuous: \((f+g)(a) = f(a) + g(a)\), and limits preserve sums.
