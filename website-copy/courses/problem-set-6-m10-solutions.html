Bonus Solutions

Bonus Solution 1

Step 1: Find the intersection of \(x + y = 4\) and \(x - y = 2\)

Adding: \(2x = 6\), so \(x = 3\)

Substituting: \(y = 4 - 3 = 1\)

Point of intersection: \((3, 1)\)

Step 2: Find the slope of the perpendicular line

Original line: \(2x - 3y + 5 = 0\) → \(y = \frac{2}{3}x + \frac{5}{3}\), slope = \(\frac{2}{3}\)

Perpendicular slope: \(m = -\frac{3}{2}\)

Step 3: Write the equation using point-slope form

\(y - 1 = -\frac{3}{2}(x - 3)\)

\(y - 1 = -\frac{3}{2}x + \frac{9}{2}\)

\(y = -\frac{3}{2}x + \frac{11}{2}\)

Bonus Solution 2

Step 1: Find the lengths of the sides using the distance formula

\(AB = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = \sqrt{25} = 5\)

\(BC = \sqrt{(7-4)^2 + (2-6)^2} = \sqrt{9 + 16} = \sqrt{25} = 5\)

\(AC = \sqrt{(7-1)^2 + (2-2)^2} = \sqrt{36} = 6\)

Step 2: The longest side is AC with length 6

Step 3: Find the area using the base-height method

Base \(AC = 6\), height = vertical distance from B to line AC = 4

Area = \(\frac{1}{2} \times 6 \times 4 = 12\) square units

Step 4: Equation of line AC (passing through A(1,2) and C(7,2))

Since both points have y = 2, the line is \(y = 2\)
