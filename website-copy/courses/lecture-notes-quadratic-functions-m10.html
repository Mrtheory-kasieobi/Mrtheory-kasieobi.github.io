Lecture 3: Quadratic Functions

Mathematics 10 - Parabolas and Quadratic Equations

Introduction to Quadratic Functions

A quadratic function is a function of the form \(f(x) = ax^2 + bx + c\) where \(a \neq 0\). The graph of a quadratic function is a parabola.

Standard Form and Vertex Form

Standard form: \(f(x) = ax^2 + bx + c\)

Vertex form: \(f(x) = a(x - h)^2 + k\) where \((h, k)\) is the vertex

Properties of Quadratic Functions

Vertex

The vertex of a parabola is the maximum or minimum point. For \(f(x) = ax^2 + bx + c\), the x-coordinate of the vertex is \(x = -\frac{b}{2a}\).

Axis of Symmetry

The axis of symmetry is the vertical line \(x = -\frac{b}{2a}\) that passes through the vertex.

Direction

If \(a > 0\), the parabola opens upward (minimum at vertex). If \(a < 0\), it opens downward (maximum at vertex).

Factoring Quadratic Expressions

Common factoring patterns:

  • \(a^2 - b^2 = (a - b)(a + b)\) - Difference of squares
  • \(a^2 + 2ab + b^2 = (a + b)^2\) - Perfect square trinomial
  • \(ax^2 + bx + c\) - Factor by finding two numbers that multiply to \(ac\) and add to \(b\)
Solving Quadratic Equations by Factoring

To solve \(ax^2 + bx + c = 0\) by factoring:

  1. Factor the quadratic expression
  2. Set each factor equal to zero
  3. Solve for \(x\)

Example: \(x^2 - 5x + 6 = 0\) factors as \((x - 2)(x - 3) = 0\), giving \(x = 2\) or \(x = 3\)

Quadratic Formula

If factoring is not possible, use the quadratic formula:

\(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\)
