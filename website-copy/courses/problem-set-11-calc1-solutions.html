Problem Set 11: Integration Techniques - SOLUTIONS

Calculus I - Week 10

Solution Guide

Problem 1: \(\int \frac{1}{x^2 + 4x + 5} \, dx\)

Solution: Complete square: \(x^2 + 4x + 5 = (x+2)^2 + 1\).
\(\int \frac{1}{(x+2)^2 + 1} dx = \tan^{-1}(x+2) + C\)

Problem 2: \(\int x \ln x \, dx\)

Solution: Integration by parts: \(u = \ln x, dv = x dx\).
\(du = \frac{1}{x}dx, v = \frac{x^2}{2}\).
\(\frac{x^2}{2}\ln x - \int \frac{x}{2}dx = \frac{x^2}{2}\ln x - \frac{x^2}{4} + C\)

Problem 3: \(\int \frac{\ln x}{x^2} \, dx\)

Solution: Integration by parts: \(u = \ln x, dv = \frac{1}{x^2}dx\).
\(du = \frac{1}{x}dx, v = -\frac{1}{x}\).
\(-\frac{\ln x}{x} + \int \frac{1}{x^2}dx = -\frac{\ln x}{x} - \frac{1}{x} + C\)

Problem 4: \(\int \frac{1}{x \ln x} \, dx\)

Solution: Substitution: \(u = \ln x, du = \frac{1}{x}dx\).
\(\int \frac{1}{u}du = \ln|\ln x| + C\)

Problem 5: \(\int \sec^2(3x) \, dx\)

Solution: \(\frac{1}{3}\tan(3x) + C\)

Problem 6: \(\int e^x \cos x \, dx\)

Solution: Integration by parts twice. Let \(I = \int e^x \cos x dx\).
\(I = e^x \cos x + \int e^x \sin x dx = e^x \cos x + e^x \sin x - I\).
\(2I = e^x(\cos x + \sin x)\). \(I = \frac{e^x}{2}(\sin x + \cos x) + C\)

Problem 7: \(\int \frac{1}{\sqrt{1-x^2}} \, dx\)

Solution: \(\sin^{-1} x + C\)

Problem 8: \(\int \frac{x}{\sqrt{1+x^2}} \, dx\)

Solution: Substitution: \(u = 1+x^2, du = 2x dx\).
\(\frac{1}{2}\int u^{-1/2}du = \sqrt{1+x^2} + C\)

Problem 9: \(\int \frac{1}{x^3 - x} \, dx\)

Solution: Partial fractions: \(\frac{1}{x(x-1)(x+1)} = \frac{A}{x} + \frac{B}{x-1} + \frac{C}{x+1}\).
\(= \ln|x| - \frac{1}{2}\ln|x-1| - \frac{1}{2}\ln|x+1| + C\)

Problem 10: \(\int \tan x \, dx\)

Solution: \(\int \frac{\sin x}{\cos x}dx = -\ln|\cos x| + C = \ln|\sec x| + C\)

Bonus 1: \(\int \frac{1}{x^2\sqrt{x^2-1}} \, dx\)

Solution: Trig substitution: \(x = \sec\theta\). Result: \(\frac{\sqrt{x^2-1}}{x} + C\)

Bonus 2: \(\int \frac{e^{2x}}{e^{2x}+1} \, dx\)

Solution: Substitution: \(u = e^{2x}+1\). Result: \(\frac{1}{2}\ln(e^{2x}+1) + C\)
