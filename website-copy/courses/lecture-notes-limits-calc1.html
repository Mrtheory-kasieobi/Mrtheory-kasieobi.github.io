Limits and Derivatives

Calculus I - Chapter 2.1-2.8 (Detailed Notes)

1. The Tangent and Velocity Problems

1.1 The Tangent Line Problem

Tangent Line: The tangent line to a curve \(y = f(x)\) at point \(P(a, f(a))\) is the line that best approximates the curve near \(P\). Its slope is the limit of secant line slopes.

Given a point \(P(a, f(a))\) on the curve, consider a nearby point \(Q(a+h, f(a+h))\). The slope of the secant line through \(P\) and \(Q\) is:

\(m_{secant} = \frac{f(a+h) - f(a)}{h}\)

As \(h \to 0\), the secant line approaches the tangent line, giving us the derivative formula.

Example 1.1: Find the tangent line to \(y = x^2\) at point \((2, 4)\).

Solution: The slope is \(f'(2) = \lim_{h \to 0} \frac{(2+h)^2 - 4}{h} = \lim_{h \to 0} \frac{4 + 4h + h^2 - 4}{h} = \lim_{h \to 0} (4 + h) = 4\)

The tangent line is \(y - 4 = 4(x - 2)\), or \(y = 4x - 4\).

1.2 The Velocity Problem

Velocity: If \(s(t)\) represents the position of an object at time \(t\), the velocity at time \(t = a\) is: \(v(a) = \lim_{h \to 0} \frac{s(a+h) - s(a)}{h} = s'(a)\)

This is the same limit as the tangent line problem! Both involve the derivative.

Example 1.2: A ball is dropped from a height of 100 meters. Its position is \(s(t) = 100 - 4.9t^2\). Find its velocity after 3 seconds.

Solution: \(v(t) = s'(t) = -9.8t\). After 3 seconds: \(v(3) = -29.4\) m/s (downward).

2. The Limit of a Function

Definition: Limit We write \(\lim_{x \to a} f(x) = L\) if we can make \(f(x)\) arbitrarily close to \(L\) by taking \(x\) sufficiently close to \(a\) (but not equal to \(a\)).

2.1 Intuitive Definition

\(\lim_{x \to a} f(x) = L\) means: For every \(\varepsilon > 0\), there exists a \(\delta > 0\) such that if \(0 < |x - a| < \delta\), then \(|f(x) - L| < \varepsilon\).

2.2 One-sided Limits

One-sided Limits:
  • \(\lim_{x \to a^-} f(x) = L\) (left-hand limit): \(x\) approaches \(a\) from below
  • \(\lim_{x \to a^+} f(x) = L\) (right-hand limit): \(x\) approaches \(a\) from above

2.3 Limit Laws

Limit Laws: If \(\lim_{x \to a} f(x) = L\) and \(\lim_{x \to a} g(x) = M\), then:
  • \(\lim_{x \to a} [f(x) + g(x)] = L + M\)
  • \(\lim_{x \to a} [f(x) - g(x)] = L - M\)
  • \(\lim_{x \to a} [f(x) \cdot g(x)] = LM\)
  • \(\lim_{x \to a} \frac{f(x)}{g(x)} = \frac{L}{M}\) (if \(M \neq 0\))
  • \(\lim_{x \to a} [c \cdot f(x)] = cL\)

3. Calculating Limits Using Limit Laws

3.1 Direct Substitution

If \(f\) is a polynomial or rational function and \(a\) is in the domain, then \(\lim_{x \to a} f(x) = f(a)\).

3.2 Indeterminate Forms

Indeterminate Forms: The forms \(\frac{0}{0}\) and \(\frac{\infty}{\infty}\) require further analysis.

3.3 Techniques for Evaluating Limits

  • Factoring: For polynomials, factor and cancel common terms
  • Rationalization: Multiply by conjugate to eliminate radicals
  • Trigonometric limits: Use \(\lim_{x \to 0} \frac{\sin x}{x} = 1\)
Example 3.1: \(\lim_{x \to 2} \frac{x^2 - 4}{x - 2} = \lim_{x \to 2} \frac{(x-2)(x+2)}{x-2} = \lim_{x \to 2} (x+2) = 4\)

4. The Precise Definition of a Limit

Epsilon-Delta Definition: \(\lim_{x \to a} f(x) = L\) means: For every \(\varepsilon > 0\), there exists a \(\delta > 0\) such that if \(0 < |x - a| < \delta\), then \(|f(x) - L| < \varepsilon\).

4.1 How to Use the Definition

To prove \(\lim_{x \to a} f(x) = L\), we need to find \(\delta\) in terms of \(\varepsilon\).

Example 4.1: Prove \(\lim_{x \to 3} (2x + 1) = 7\).

We need: \(|2x + 1 - 7| < \varepsilon\) when \(0 < |x - 3| < \delta\).

\(|2x - 6| = 2|x - 3| < \varepsilon\) when \(|x - 3| < \frac{\varepsilon}{2}\).

Choose \(\delta = \frac{\varepsilon}{2}\).

5. Continuity

Definition: Continuity A function \(f\) is continuous at \(a\) if:
  1. \(f(a)\) is defined
  2. \(\lim_{x \to a} f(x)\) exists
  3. \(\lim_{x \to a} f(x) = f(a)\)

5.1 Types of Discontinuities

  • Removable discontinuity: Limit exists but doesn't equal function value
  • Jump discontinuity: Left and right limits exist but are different
  • Infinite discontinuity: Function approaches \(\pm\infty\)

5.2 Intermediate Value Theorem

Intermediate Value Theorem: If \(f\) is continuous on \([a, b]\) and \(f(a) < k < f(b)\), then there exists \(c \in (a, b)\) such that \(f(c) = k\).

6. Limits at Infinity; Horizontal Asymptotes

Limit at Infinity: \(\lim_{x \to \infty} f(x) = L\) if \(f(x)\) approaches \(L\) as \(x\) becomes large.

6.1 Horizontal Asymptotes

If \(\lim_{x \to \infty} f(x) = L\) or \(\lim_{x \to -\infty} f(x) = L\), then \(y = L\) is a horizontal asymptote.

6.2 Limits for Rational Functions

Rule for Rational Functions: For \(f(x) = \frac{P(x)}{Q(x)}\), compare degrees:
  • If deg(P) < deg(Q): limit is 0
  • If deg(P) = deg(Q): limit is ratio of leading coefficients
  • If deg(P) > deg(Q): limit is \(\pm\infty\)

7. Derivatives and Rates of Change

Definition: Derivative The derivative of \(f\) at \(a\) is: \(f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}\)

7.1 Alternative Forms

Alternative Form: \(f'(a) = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}\)

7.2 Notation

  • \(f'(x)\) - Lagrange notation
  • \(\frac{dy}{dx}\) - Leibniz notation
  • \(\frac{d}{dx}f(x)\) - Operator notation
  • \(Df(x)\) - Euler notation

7.3 Interpretation

Interpretation:
  • Instantaneous rate of change of \(f\) with respect to \(x\)
  • Slope of the tangent line to the curve \(y = f(x)\)
  • If \(f\) represents position, \(f'\) represents velocity
Example 7.1: Find the derivative of \(f(x) = x^2 - 3x + 2\).

Solution: \(f'(x) = \lim_{h \to 0} \frac{(x+h)^2 - 3(x+h) + 2 - (x^2 - 3x + 2)}{h}\)

\(= \lim_{h \to 0} \frac{2xh + h^2 - 3h}{h} = \lim_{h \to 0} (2x + h - 3) = 2x - 3\)

8. The Derivative as a Function

8.1 Differentiability

Differentiable Function: A function \(f\) is differentiable on an interval if \(f'(a)\) exists for all \(a\) in that interval.

8.2 Higher Derivatives

  • \(f''(x) = (f'(x))'\) - Second derivative (concavity)
  • \(f'''(x) = (f''(x))'\) - Third derivative
  • \(f^{(n)}(x)\) - nth derivative

8.3 Relationship Between Continuity and Differentiability

Important: Differentiability implies continuity, but not vice versa. A function can be continuous but not differentiable (e.g., \(f(x) = |x|\) at \(x = 0\)).
