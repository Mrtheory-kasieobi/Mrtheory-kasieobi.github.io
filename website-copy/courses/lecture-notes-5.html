Lecture 5: Fermat's Little Theorem, Euler's Theorem, Wilson's Theorem

Lecture 5Fermat's Little Theorem, Euler's Theorem, Wilson's Theorem

1. Fermat's Little Theorem

Theorem 5.1 (Fermat's Little Theorem) If \(p\) is prime and \(a\) is any integer not divisible by \(p\), then \[a^{p-1} \equiv 1 \pmod{p}.\] Equivalently, for any integer \(a\) and prime \(p\), \[a^p \equiv a \pmod{p}.\]
Proof (using group theory perspective):

Let \(A = \{1, 2, \ldots, p-1\}\) be the set of non-zero residue classes modulo \(p\). Consider the set \(aA = \{a \cdot 1, a \cdot 2, \ldots, a \cdot (p-1)\}\) reduced modulo \(p\).

Step 1: Show elements of \(aA\) are distinct modulo \(p\).

Suppose \(a \cdot i \equiv a \cdot j \pmod{p}\) for some \(1 \leq i < j \leq p-1\). Then \(p \mid a(i - j)\). Since \(p \nmid a\) (by assumption) and \(0 < |i - j| < p\), we must have \(p \mid (i - j)\), which is impossible. Thus all elements of \(aA\) are distinct.

Step 2: Show elements of \(aA\) are non-zero modulo \(p\).

If \(a \cdot i \equiv 0 \pmod{p}\), then \(p \mid ai\). Since \(p \nmid a\), we have \(p \mid i\), but \(1 \leq i \leq p-1\) contradicts this. Thus all elements are non-zero.

Step 3: Conclude \(aA = A\) as sets.

Since \(A\) has \(p-1\) elements and \(aA\) has \(p-1\) distinct non-zero elements, we have \(aA = A\).

Step 4: Compute the product.

\[\prod_{k=1}^{p-1} (ak) \equiv \prod_{k=1}^{p-1} k \pmod{p}\] \[a^{p-1} \prod_{k=1}^{p-1} k \equiv \prod_{k=1}^{p-1} k \pmod{p}\]

Since \(\prod_{k=1}^{p-1} k\) is coprime to \(p\) (it's the product of all non-zero residues), we can cancel it to get \(a^{p-1} \equiv 1 \pmod{p}\). \(\square\)

Example 5.1 Verify Fermat's Little Theorem for \(p = 5\).

For \(a = 2\): \(2^4 = 16 = 5 \cdot 3 + 1 \equiv 1 \pmod{5}\). ✓

For \(a = 3\): \(3^4 = 81 = 5 \cdot 16 + 1 \equiv 1 \pmod{5}\). ✓

For \(a = 4\): \(4^4 = 256 = 5 \cdot 51 + 1 \equiv 1 \pmod{5}\). ✓

2. Euler's Theorem

Theorem 5.2 (Euler's Theorem) If \(\gcd(a, n) = 1\), then \[a^{\phi(n)} \equiv 1 \pmod{n}\] where \(\phi(n)\) is Euler's totient function.
Proof:

Let \(A = \{a_1, a_2, \ldots, a_{\phi(n)}\}\) be a reduced residue system modulo \(n\) (i.e., a set of \(\phi(n)\) integers coprime to \(n\), pairwise incongruent modulo \(n\)).

Step 1: Show \(aA = \{aa_1, aa_2, \ldots, aa_{\phi(n)}\}\) is a reduced residue system modulo \(n\).

Since \(\gcd(a, n) = 1\), if \(aa_i \equiv aa_j \pmod{n}\), then \(n \mid a(a_i - a_j)\). Since \(\gcd(a, n) = 1\), we have \(n \mid (a_i - a_j)\), so \(a_i \equiv a_j \pmod{n}\). By the distinctness of elements in \(A\), we have \(i = j\). Thus elements of \(aA\) are distinct.

Also, if \(aa_i \equiv 0 \pmod{n}\), then \(n \mid aa_i\). Since \(\gcd(a, n) = 1\), we have \(n \mid a_i\), contradicting \(\gcd(a_i, n) = 1\). Thus all elements are coprime to \(n\).

Therefore \(aA = A\) as sets (both have \(\phi(n)\) elements).

Step 2: Compute the product.

\[\prod_{i=1}^{\phi(n)} aa_i \equiv \prod_{i=1}^{\phi(n)} a_i \pmod{n}\] \[a^{\phi(n)} \prod_{i=1}^{\phi(n)} a_i \equiv \prod_{i=1}^{\phi(n)} a_i \pmod{n}\]

Since each \(a_i\) is coprime to \(n\), the product \(\prod a_i\) is also coprime to \(n\). We can cancel it to get \(a^{\phi(n)} \equiv 1 \pmod{n}\). \(\square\)

Example 5.2 Verify Euler's Theorem for \(a = 3, n = 10\).

Since \(\gcd(3, 10) = 1\), we need to compute \(\phi(10)\).

\(10 = 2 \cdot 5\), so \(\phi(10) = 10 \cdot \left(1 - \frac{1}{2}\right) \cdot \left(1 - \frac{1}{5}\right) = 10 \cdot \frac{1}{2} \cdot \frac{4}{5} = 4\).

Compute \(3^4 = 81 = 10 \cdot 8 + 1 \equiv 1 \pmod{10}\). ✓

3. Wilson's Theorem

Theorem 5.3 (Wilson's Theorem) \((p-1)! \equiv -1 \pmod{p}\) if and only if \(p\) is prime.

Forward direction (\(p\) prime \(\Rightarrow\) \((p-1)! \equiv -1 \pmod{p}\)):

Consider the multiplicative group \(\mathbb{Z}_p^* = \{1, 2, \ldots, p-1\}\) under multiplication modulo \(p\).

Step 1: Identify self-inverse elements.

An element \(a \in \mathbb{Z}_p^*\) is its own inverse if \(a^2 \equiv 1 \pmod{p}\), i.e., \(p \mid (a^2 - 1) = (a-1)(a+1)\).

Since \(p\) is prime, \(p \mid (a-1)\) or \(p \mid (a+1)\). Thus \(a \equiv 1 \pmod{p}\) or \(a \equiv -1 \equiv p-1 \pmod{p}\).

Therefore, the only self-inverse elements are \(1\) and \(p-1\).

Step 2: Pair up the other elements.

For each \(a \in \mathbb{Z}_p^*\) with \(a \neq 1\) and \(a \neq p-1\), there exists a unique \(b \neq a\) such that \(ab \equiv 1 \pmod{p}\).

These elements can be partitioned into pairs \(\{a, b\}\) where \(ab \equiv 1 \pmod{p}\).

Step 3: Compute the product.

Pairing all elements: \[(p-1)! = 1 \cdot (p-1) \cdot \prod_{\text{pairs } \{a,b\}} (ab)\] \[= 1 \cdot (p-1) \cdot \prod_{\text{pairs}} 1 = 1 \cdot (p-1) = p-1 \equiv -1 \pmod{p}.\]p>

Thus \((p-1)! \equiv -1 \pmod{p}\). \(\square\)

Reverse direction: If \((n-1)! \equiv -1 \pmod{n}\), then \(n\) must be prime.

Proof: Suppose \(n\) is composite with \(n = ab\) where \(1 < a, b < n\). Then \(a \mid (n-1)!\) (since \(a \leq n-1\)), so \((n-1)! \equiv 0 \pmod{a}\). But \((n-1)! \equiv -1 \pmod{n}\) implies \(n \mid ((n-1)! + 1)\), so \(a \mid ((n-1)! + 1)\). This contradicts \((n-1)! \equiv 0 \pmod{a}\) unless \(a = 1\). Thus \(n\) cannot be composite (for \(n > 4\)). \(\square\)

Example 5.3 Verify Wilson's Theorem for \(p = 5\).

\((5-1)! = 4! = 24 = 5 \cdot 4 + 4 \equiv -1 \pmod{5}\). ✓

Verify Wilson's Theorem for \(p = 7\).

\((7-1)! = 6! = 720 = 7 \cdot 102 + 6 \equiv -1 \pmod{7}\). ✓

Exercises:
  1. Verify Fermat's Little Theorem for \(p = 11\) with \(a = 2, 3, 5\).
  2. Find the remainder when \(7^{100}\) is divided by 11.
  3. Verify Euler's Theorem for \(a = 5, n = 12\).
  4. Compute \(3^{100} \pmod{13}\) using Fermat's Little Theorem.
  5. Prove Wilson's Theorem for \(p = 11\).
  6. Show that if \(p \equiv 1 \pmod{4}\), then \(\left(\frac{p-1)!}{2}\right)^2 \equiv -1 \pmod{p}\).
  7. Find all solutions to \(x^2 \equiv 1 \pmod{p}\) for prime \(p\).
  8. Prove: If \(p\) is prime, then \(p \mid \binom{p}{k}\) for \(1 \leq k \leq p-1\).
