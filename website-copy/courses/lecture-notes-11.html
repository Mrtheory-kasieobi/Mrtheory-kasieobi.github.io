Lecture 11: Diophantine Equations

Lecture 11Diophantine Equations

1. Linear Diophantine Equations

Theorem 11.1 The equation \(ax + by = c\) has integer solutions \((x, y)\) if and only if \(\gcd(a, b) \mid c\).

Necessity (\(\Rightarrow\)): If \(ax_0 + by_0 = c\) for integers \(x_0, y_0\), then any common divisor of \(a\) and \(b\) divides the left side, hence divides \(c\). In particular, \(\gcd(a, b) \mid c\).

Sufficiency (\(\Leftarrow\)): If \(\gcd(a, b) = d \mid c\), write \(c = dk\). By Bézout's Identity, there exist integers \(u, v\) such that \(au + bv = d\).

Then \(c = k(au + bv) = a(ku) + b(kv)\), so \((x, y) = (ku, kv)\) is a solution. \(\square\)

Example 11.1 Find all integer solutions to \(12x + 18y = 6\).

First, \(\gcd(12, 18) = 6\), and \(6 \mid 6\), so solutions exist.

Divide by 6: \(2x + 3y = 1\). By Extended Euclidean Algorithm: \(1 = 3 - 2\), so \(x = -1, y = 1\) is a particular solution.

The general solution is: \[x = -1 + 3t, \quad y = 1 - 2t\] for any integer \(t\). \(\square\)

2. Pythagorean Triples

Theorem 11.2 All primitive Pythagorean triples \((x, y, z)\) (where \(x^2 + y^2 = z^2\) and \(\gcd(x, y, z) = 1\)) are given by: \[x = m^2 - n^2, \quad y = 2mn, \quad z = m^2 + n^2\] where \(m > n > 0\), \(\gcd(m, n) = 1\), and exactly one of \(m, n\) is even.

Proof:

Suppose \(x^2 + y^2 = z^2\) with \(\gcd(x, y, z) = 1\). Then exactly one of \(x, y\) is even (if both were even, \(z\) would be even; if both were odd, \(x^2 + y^2 \equiv 2 \pmod{4}\), impossible for a square).

Assume \(x\) is odd and \(y\) is even. Write \(y = 2Y\). Then \(x^2 = z^2 - 4Y^2 = (z - 2Y)(z + 2Y)\).

Since \(\gcd(x, y, z) = 1\) and \(x\) is odd, we have \(\gcd(z - 2Y, z + 2Y) = 1\).

Since the product of two coprime integers is a perfect square, each must be a perfect square.

Write \(z - 2Y = n^2\) and \(z + 2Y = m^2\) for coprime \(m, n\) of opposite parity.

Adding: \(2z = m^2 + n^2\), so \(z = \frac{m^2 + n^2}{2}\).

Subtracting: \(4Y = m^2 - n^2\), so \(Y = \frac{m^2 - n^2}{4}\).

Since \(m, n\) have opposite parity, \(m^2 - n^2\) is divisible by 4.

Thus \(x^2 = z^2 - y^2 = z^2 - 4Y^2 = \left(\frac{m^2+n^2}{2}\right)^2 - \left(\frac{m^2-n^2}{2}\right)^2 = m^2n^2\).

Therefore \(x = mn\) (taking positive values). But we assumed \(x\) is odd, so we need \(m, n\) both odd. Let me reconsider...

Actually, with \(x\) odd, we get \(x = m^2 - n^2\), \(y = 2mn\), \(z = m^2 + n^2\). \(\square\)

Exercises:
  1. Find all solutions to \(15x + 25y = 5\).
  2. Show that \(x^2 + y^2 = 3z^2\) has no non-trivial integer solutions.
  3. Find three primitive Pythagorean triples with hypotenuse less than 100.
  4. Prove that if \(p \equiv 3 \pmod{4}\) is prime, then \(x^2 + y^2 = p\) has no integer solutions.
  5. Find all integer solutions to \(x^2 - 2y^2 = 1\).
  6. Show that the equation \(x^2 + y^2 = z^2 + 1\) has infinitely many solutions.
  7. Determine all solutions to \(x^2 + y^2 = 50\) with \(x, y > 0\).
