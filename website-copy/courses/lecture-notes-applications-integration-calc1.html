Applications of Integration

Calculus I - Chapter 6.1-6.5

1. Areas Between Curves

Area Between Curves: If \(f(x) \geq g(x)\) on \([a,b]\), the area between the curves is: \(A = \int_a^b [f(x) - g(x)] \, dx\)
Example: Find the area between \(y = x^2\) and \(y = x\). The curves intersect at \(x = 0, 1\). \(A = \int_0^1 (x - x^2) \, dx = \frac{1}{2} - \frac{1}{3} = \frac{1}{6}\)

2. Volumes

Disk Method: For rotation about the x-axis: \(V = \pi \int_a^b [f(x)]^2 \, dx\)
Shell Method: For rotation about the y-axis: \(V = 2\pi \int_a^b x \cdot f(x) \, dx\)

3. Work

Work Formula: If a force \(F(x)\) moves an object from \(x = a\) to \(x = b\): \(W = \int_a^b F(x) \, dx\)
Example: Work to lift a chain weighing 10 lb/ft from ground to 20 ft: \(W = \int_0^{20} 10x \, dx = 10 \cdot \frac{20^2}{2} = 2000\) foot-pounds

4. Average Value of a Function

Average Value: \(\bar{f} = \frac{1}{b-a} \int_a^b f(x) \, dx\)

5. Differential Equations

Differential Equation: An equation involving derivatives, such as \(\frac{dy}{dx} = f(x)\)
Solution Strategy: Integrate both sides: \(y = \int f(x) \, dx + C\)
