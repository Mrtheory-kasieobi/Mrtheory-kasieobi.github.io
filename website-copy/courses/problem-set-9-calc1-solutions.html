Problem Set 9: Definite Integrals and FTC - SOLUTIONS

Calculus I - Week 8

Solution Guide

Note: Show all work. Use Fundamental Theorem of Calculus where applicable.

Problem 1: \(\int_0^1 (x^2 + 2x + 1) \, dx\)

Solution: \(\int_0^1 x^2 dx + \int_0^1 2x dx + \int_0^1 1 dx = \left[\frac{x^3}{3}\right]_0^1 + \left[x^2\right]_0^1 + [x]_0^1\)
\(= \frac{1}{3} + 1 + 1 = \frac{7}{3}\)

Problem 2: Area between \(y = x^2\) and \(y = x\) on \([0, 1]\)

Solution: On \([0,1]\), \(x \geq x^2\).
\(\text{Area} = \int_0^1 (x - x^2) dx = \left[\frac{x^2}{2} - \frac{x^3}{3}\right]_0^1 = \frac{1}{2} - \frac{1}{3} = \frac{1}{6}\)

Problem 3: \(\int_{-1}^2 (x^3 - 4x) \, dx\)

Solution: \(\left[\frac{x^4}{4} - 2x^2\right]_{-1}^2 = \left(4 - 8\right) - \left(\frac{1}{4} - 2\right) = -4 - \left(-\frac{7}{4}\right) = -\frac{9}{4}\)

Problem 4: Average value of \(f(x) = x^2\) on \([0, 2]\)

Solution: \(f_{\text{avg}} = \frac{1}{2-0}\int_0^2 x^2 dx = \frac{1}{2} \cdot \left[\frac{x^3}{3}\right]_0^2 = \frac{1}{2} \cdot \frac{8}{3} = \frac{4}{3}\)

Problem 5: Riemann sum for \(f(x) = x^2\) on \([0, 2]\) with \(n\) subintervals

Solution: \(\Delta x = \frac{2}{n}\), \(x_i^* = \frac{2i}{n}\).
\(\sum_{i=1}^n f(x_i^*)\Delta x = \sum_{i=1}^n \left(\frac{2i}{n}\right)^2 \cdot \frac{2}{n} = \frac{8}{n^3}\sum_{i=1}^n i^2 = \frac{8}{n^3} \cdot \frac{n(n+1)(2n+1)}{6}\)
\(\lim_{n \to \infty} \frac{4(n+1)(2n+1)}{3n^2} = \frac{8}{3}\)

Problem 6: Linearity of integrals

Solution: \(\int_a^b [cf(x) + dg(x)] dx = c\int_a^b f(x)dx + d\int_a^b g(x)dx\) by FTC.

Problem 7: \(\int_0^{\pi/4} \sin x \cos x \, dx\)

Solution: Substitution \(u = \sin x\), \(du = \cos x dx\).
\(\int_0^{\sqrt{2}/2} u du = \left[\frac{u^2}{2}\right]_0^{\sqrt{2}/2} = \frac{1}{4}\)

Problem 8: \(\int \frac{e^x}{e^x + 1} \, dx\)

Solution: Substitution \(u = e^x + 1\), \(du = e^x dx\).
\(\int \frac{1}{u} du = \ln|u| + C = \ln(e^x + 1) + C\)

Problem 9: Prove \(\int_a^b f(x)dx = -\int_b^a f(x)dx\)

Solution: By FTC, \(\int_a^b f(x)dx = F(b) - F(a)\) and \(\int_b^a f(x)dx = F(a) - F(b) = -[F(b) - F(a)]\)

Problem 10: Total area between \(y = x^3 - x\) and \(y = 0\) on \([-1, 2]\)

Solution: Intersections at \(x = -1, 0, 1, 2\).
\(\text{Area} = \int_{-1}^0 -(x^3-x)dx + \int_0^1 (x^3-x)dx + \int_1^2 (x^3-x)dx\)
\(= \frac{1}{4} + \frac{1}{4} + \frac{5}{4} = \frac{7}{4}\)

Bonus 1: \(\int_0^{\pi/2} \sin^2 x \, dx\)

Solution: Use identity \(\sin^2 x = \frac{1-\cos 2x}{2}\).
\(\int_0^{\pi/2} \sin^2 x dx = \frac{1}{2}[x]_0^{\pi/2} - \frac{1}{4}[\sin 2x]_0^{\pi/2} = \frac{\pi}{4}\)

Bonus 2: \(\int_1^e \frac{\ln x}{x} \, dx\)

Solution: Substitution \(u = \ln x\), \(du = \frac{1}{x}dx\).
\(\int_0^1 u du = \left[\frac{u^2}{2}\right]_0^1 = \frac{1}{2}\)
