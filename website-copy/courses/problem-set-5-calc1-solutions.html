Problem Set 5: Trig Derivatives and Optimization - SOLUTIONS

Calculus I - Week 5

Solution Guide

Note: These are detailed solution outlines. Show all work when completing problems.

Problem 1: Find \(\frac{dy}{dx}\) for \(y = \sin^3(2x)\)

Solution: Chain rule with three layers: \(y = [\sin(2x)]^3\)
\(\frac{dy}{dx} = 3\sin^2(2x) \cdot \cos(2x) \cdot 2 = 6\sin^2(2x)\cos(2x)\)

Problem 2: Find \(\frac{d}{dx}[\tan^{-1}(x^3)]\)

Solution: Chain rule: \(\frac{d}{dx}[\tan^{-1}(u)] = \frac{1}{1+u^2} \cdot u'\)
\(\frac{d}{dx} = \frac{1}{1+x^6} \cdot 3x^2 = \frac{3x^2}{1+x^6}\)

Problem 3: Find critical points of \(f(x) = x + 2\sin x\) on \([0, 2\pi]\)

Solution: \(f'(x) = 1 + 2\cos x = 0 \Rightarrow \cos x = -\frac{1}{2}\)
In \([0, 2\pi]\): \(x = \frac{2\pi}{3}, \frac{4\pi}{3}\). These are critical points.

Problem 4: Rectangle with perimeter 20, maximum area

Solution: Let dimensions be \(x\) and \(y\). Constraint: \(2x + 2y = 20 \Rightarrow y = 10 - x\).
Area: \(A = x(10-x) = 10x - x^2\).
\(A' = 10 - 2x = 0 \Rightarrow x = 5\). Then \(y = 5\).
Maximum area occurs at square with side 5.

Problem 5: Box with square base, volume 1000 cm³, minimum surface area

Solution: Let base side = \(x\), height = \(h\). Volume: \(x^2h = 1000 \Rightarrow h = \frac{1000}{x^2}\)
Surface area: \(S = 2x^2 + 4xh = 2x^2 + \frac{4000}{x}\)
\(S' = 4x - \frac{4000}{x^2} = 0 \Rightarrow 4x^3 = 4000 \Rightarrow x = 10\) cm
Then \(h = 10\) cm. Cube gives minimum surface area.

Problem 6: Find \(\frac{d}{dx}[\sec x \cdot \cot x]\)

Solution: Product rule: \((uv)' = u'v + uv'\)
\(u = \sec x, v = \cot x\). \(u' = \sec x \tan x, v' = -\csc^2 x\)
\(\frac{d}{dx} = \sec x \tan x \cdot \cot x + \sec x \cdot (-\csc^2 x)\) \(= \sec x - \sec x \csc^2 x = \sec x(1 - \csc^2 x)\)

Problem 7: Find local extrema of \(f(x) = \frac{x^2}{x^2 + 1}\)

Solution: \(f'(x) = \frac{2x(x^2+1) - x^2(2x)}{(x^2+1)^2} = \frac{2x}{(x^2+1)^2}\)
\(f'(x) = 0\) when \(x = 0\). For \(x < 0\), \(f' < 0\). For \(x > 0\), \(f' > 0\).
Local minimum at \(x = 0\), value \(f(0) = 0\).

Problem 8: Ladder 15 ft, bottom slides toward wall at 3 ft/s

Solution: \(x^2 + y^2 = 225\). Differentiate: \(2x + 2y\frac{dy}{dx} = 0\)
When \(x = 9\): \(y = 12\). Given \(\frac{dx}{dt} = -3\):
\(2(9)(-3) + 2(12)\frac{dy}{dt} = 0 \Rightarrow \frac{dy}{dt} = \frac{9}{4}\) ft/s (moving up)

Problem 9: Find \(\frac{d}{dx}[\sin^{-1}(x) + \cos^{-1}(x)]\)

Solution: \(\frac{d}{dx}[\sin^{-1}x] = \frac{1}{\sqrt{1-x^2}}\)
\(\frac{d}{dx}[\cos^{-1}x] = -\frac{1}{\sqrt{1-x^2}}\)
Sum: \(\frac{1}{\sqrt{1-x^2}} - \frac{1}{\sqrt{1-x^2}} = 0\)

Problem 10: Prove rectangle with fixed perimeter has max area when square

Solution: Let perimeter = \(P\), sides \(x, y\). \(2x + 2y = P \Rightarrow y = \frac{P}{2} - x\).
Area: \(A = x(\frac{P}{2} - x) = \frac{Px}{2} - x^2\).
\(A' = \frac{P}{2} - 2x = 0 \Rightarrow x = \frac{P}{4}\). Then \(y = \frac{P}{4}\).
Square gives maximum area.

Bonus 1: Find absolute extrema of \(f(x) = x + \frac{2}{x}\) on \([1, 4]\)

Solution: \(f'(x) = 1 - \frac{2}{x^2} = 0 \Rightarrow x = \sqrt{2} \approx 1.414\)
Evaluate: \(f(1) = 3, f(\sqrt{2}) = 2\sqrt{2}, f(4) = 4.5\)
Local min at \(x = \sqrt{2}\), absolute max at \(x = 4\).

Bonus 2: Cylinder volume 1000 cm³, minimize material for can

Solution: Radius \(r\), height \(h\). Volume: \(\pi r^2 h = 1000 \Rightarrow h = \frac{1000}{\pi r^2}\)
Surface area: \(S = 2\pi r^2 + 2\pi rh = 2\pi r^2 + \frac{2000}{r}\)
\(S' = 4\pi r - \frac{2000}{r^2} = 0 \Rightarrow r^3 = \frac{500}{\pi} \Rightarrow r \approx 5.42\) cm
\(h \approx 10.84\) cm.
