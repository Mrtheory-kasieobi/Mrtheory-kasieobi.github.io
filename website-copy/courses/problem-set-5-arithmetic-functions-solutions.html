Solutions: Problem Set 5: Arithmetic Functions

Solutions

Problem 1

Solution: \(\sigma(12) = 1+2+3+4+6+12 = 28\). \(\phi(12) = 12 \cdot (1-\frac{1}{2})(1-\frac{1}{3}) = 4\).

Problem 2

Solution: \(\sigma(15) = 1+3+5+15 = 24\), \(\sigma(16) = 1+2+4+8+16 = 31\), \(\sigma(17) = 1+17 = 18\).

Problem 3

Solution: \(\phi(p) = p-1\) since all integers \(1, 2, \ldots, p-1\) are coprime to \(p\).

Problem 4

Solution: \(\sigma(p^k) = 1 + p + p^2 + \cdots + p^k\) is the sum of a geometric series.

Problem 5

Solution: \(\mu(30) = \mu(2 \cdot 3 \cdot 5) = (-1)^3 = -1\). \(\mu(31) = -1\) (prime). \(\mu(32) = 0\) (has squared factor).

Problem 6

Solution: Möbius inversion: \(f(n) = \sum_{d|n} \mu(d) g(n/d)\)

Problem 7

Solution: Each \(k\) from 1 to \(n\) contributes 1 to exactly \(\gcd(k, n)\) values of \(d\). The total count is \(n\).

Problem 8

Solution: Testing: \(\phi(n) = 10\) gives \(n = 11\) (prime) or \(n = 22\).

Problem 9

Solution: Using multiplicativity of \(\phi\): \(\phi(n) = n \prod(1 - 1/p_i)\)

Problem 10

Solution: \(\sum_{n=1}^{10} \phi(n) = 1+1+2+2+4+2+6+4+6+4 = 32\).

Bonus Problems

Bonus Problem 1

Solution:

Step 1: We need to prove \(\sum_{n \leq x} \phi(n) = \frac{3x^2}{\pi^2} + O(x \log x)\).

Step 2: Use the identity \(\sum_{d|n} \phi(d) = n\).

Step 3: Sum over \(n \leq x\): \(\sum_{n \leq x} \sum_{d|n} \phi(d) = \sum_{n \leq x} n = \frac{x(x+1)}{2}\).

Step 4: Swap summation: \(\sum_{d \leq x} \phi(d) \lfloor \frac{x}{d} \rfloor = \frac{x^2}{2} + O(x)\).

Bonus Problem 2

Solution:

Step 1: The Dirichlet series for \(\mu\) is \(\sum_{n=1}^{\infty} \frac{\mu(n)}{n^s} = \frac{1}{\zeta(s)}\).

Step 2: This follows from the Euler product: \(\zeta(s) = \prod_p (1 - p^{-s})^{-1}\), so \(\frac{1}{\zeta(s)} = \prod_p (1 - p^{-s}) = \sum_n \frac{\mu(n)}{n^s}\).

Bonus Problem 3

Solution:

Step 1: If \(\phi(n) = \frac{n}{2}\), then \(n \prod(1 - \frac{1}{p_i}) = \frac{n}{2}\), giving \(\prod(1 - \frac{1}{p_i}) = \frac{1}{2}\).

Step 2: This gives \(2 \prod(p_i - 1) = \prod p_i\).

Step 3: Since \(p_i - 1 < p_i\) for all \(i\), we need \(k = 1\) and \(2(p-1) = p\), giving \(p = 2\).

Conclusion: All \(n\) with \(\phi(n) = \frac{n}{2}\) are powers of 2.
