Lecture 2: The Euclidean Algorithm and Bézout's Identity

Lecture 2The Euclidean Algorithm and Bézout's Identity

1. The Division Algorithm

Theorem 1.1 (Division Algorithm) Let \(a, b \in \mathbb{Z}\) with \(b > 0\). Then there exist unique integers \(q\) and \(r\) such that \[a = bq + r \quad \text{and} \quad 0 \leq r < b.\] The integers \(q\) and \(r\) are uniquely determined by \(a\) and \(b\).
Proof of Existence:

Consider the set \(S = \{a - bk : k \in \mathbb{Z}\}\). This is the set of all integers of the form \(a - bk\).

By the Well-Ordering Principle, the set \(T = \{s \in S : s \geq 0\}\) has a smallest element \(r = a - bq_0\).

We claim \(r < b\). Suppose for contradiction that \(r \geq b\). Then \(r - b = a - b(q_0 + 1) \in T\), but \(r - b < r\), contradicting minimality. Thus \(r < b\). \(\square\)

2. The Euclidean Algorithm

Definition 2.1 (GCD) Let \(a, b \in \mathbb{Z}\) with not both zero. The greatest common divisor of \(a\) and \(b\), denoted \(\gcd(a,b)\), is the largest positive integer dividing both \(a\) and \(b\).
Theorem 2.1 (Euclidean Algorithm) Let \(a, b \in \mathbb{Z}\) with \(b > 0\). Apply the division algorithm repeatedly. If the last non-zero remainder is \(r_{n-1}\), then \(\gcd(a, b) = r_{n-1}\).
Proof:

By induction, one shows that for each \(k\): \[\gcd(a, b) = \gcd(b, r_1) = \gcd(r_1, r_2) = \cdots = \gcd(r_{k-1}, r_k).\]

When the algorithm terminates with \(r_n = 0\), we have \(\gcd(r_{n-2}, r_{n-1}) = \gcd(r_{n-1}, 0) = r_{n-1}\). \(\square\)

3. Bézout's Identity

Theorem 3.1 (Bézout's Identity) Let \(a, b \in \mathbb{Z}\) with not both zero. Then there exist integers \(x, y\) such that \[\gcd(a, b) = ax + by.\]
Proof:

Consider the set \(S = \{ax + by > 0 : x, y \in \mathbb{Z}\}\). Let \(d\) be the smallest element, say \(d = ax_0 + by_0\).

Claim: \(d = \gcd(a, b)\).

Let \(a = dq + r\) where \(0 \leq r < d\). Then \(r = a - dq = a(1 - qx_0) + b(-qy_0) \in S\) if \(r > 0\).

Since \(r < d\) and \(d\) is minimal in \(S\), we must have \(r = 0\). Thus \(d \mid a\). Similarly \(d \mid b\).

Any common divisor of \(a\) and \(b\) divides \(ax_0 + by_0 = d\), so \(d \geq \gcd(a, b)\). But \(\gcd(a, b) \mid d\) as well. Hence \(d = \gcd(a, b)\). \(\square\)

4. Extended Euclidean Algorithm

Example 4.1 Find \(\gcd(1071, 462)\) and integers \(x, y\) such that \(\gcd(1071, 462) = 1071x + 462y\).

Apply the Euclidean Algorithm: \[1071 = 462 \cdot 2 + 147\] \[462 = 147 \cdot 3 + 21\] \[147 = 21 \cdot 7 + 0\]

Thus \(\gcd(1071, 462) = 21\).

Back-substitution: \[21 = 462 - 147 \cdot 3 = 462 - (1071 - 462 \cdot 2) \cdot 3 = 7 \cdot 462 - 3 \cdot 1071\]

Therefore \(21 = 1071 \cdot (-3) + 462 \cdot 7\), so \(x = -3\) and \(y = 7\). \(\square\)

Exercises:
  1. Find \(\gcd(1980, 1540)\) using the Euclidean Algorithm.
  2. Find integers \(x, y\) such that \(1980x + 1540y = \gcd(1980, 1540)\).
  3. Prove that if \(\gcd(a, b) = 1\) and \(a \mid bc\), then \(a \mid c\).
  4. Show that the set \(\{ax + by : x, y \in \mathbb{Z}\}\) is precisely the set of all multiples of \(\gcd(a, b)\).
