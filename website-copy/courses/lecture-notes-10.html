Lecture 10Applications of Gaussian Integers to Diophantine Equations

1. The Sum of Two Squares Theorem

Theorem 10.1 (Sum of Two Squares) A positive integer \(n\) can be expressed as \(n = x^2 + y^2\) for integers \(x, y\) if and only if in the prime factorization of \(n\), every prime \(p \equiv 3 \pmod{4}\) appears with an even exponent.

Necessity (\(\Rightarrow\)): Suppose \(n = x^2 + y^2\). If a prime \(p \equiv 3 \pmod{4}\) divides \(n\) to an odd power, write \(n = p^{2k+1} m\) where \(p \nmid m\).

Since \(n = x^2 + y^2\), we have \(p^{2k+1} \mid (x^2 + y^2)\).

If \(p \mid x\), then \(p \mid y\) (since \(p \mid x^2 + y^2\)). Write \(x = px', y = py'\). Then \(p^{2k+1} \mid p^2(x'^2 + y'^2)\), so \(p^{2k-1} \mid x'^2 + y'^2\).

Continue until we get \(p \mid (x_0^2 + y_0^2)\) where \(p \nmid x_0\) or \(p \nmid y_0\).

But if \(p \nmid x_0\), then \(x_0^2 + y_0^2 \equiv 0 \pmod{p}\), so \(-y_0^2 \equiv x_0^2 \pmod{p}\), giving \((xy^{-1})^2 \equiv -1 \pmod{p}\).

This contradicts that \(-1\) is not a quadratic residue modulo \(p\) when \(p \equiv 3 \pmod{4}\). \(\square\)

Sufficiency (\(\Leftarrow\)): If \(n\) satisfies the condition, then \(n = x^2 + y^2\).

It suffices to show:

  1. If \(n_1 = x_1^2 + y_1^2\) and \(n_2 = x_2^2 + y_2^2\), then \(n_1 n_2 = x_3^2 + y_3^2\).
  2. \(p^k = x^2 + y^2\) for any prime \(p \equiv 1 \pmod{4}\) and any \(k \geq 1\).
  3. \(2^k = x^2 + y^2\) for any \(k \geq 1\).

Part 1 (Brahmagupta-Fibonacci identity): \[(x_1^2 + y_1^2)(x_2^2 + y_2^2) = (x_1x_2 - y_1y_2)^2 + (x_1y_2 + x_2y_1)^2\]

Verification by expansion is straightforward. \(\square\)

2. The Equation \(x^2 + 1 = py^2\)

Theorem 10.2 The equation \(x^2 + 1 = py^2\) has an integer solution for a prime \(p\) if and only if \(p \equiv 1 \pmod{4}\).

Necessity (\(\Rightarrow\)): If \(x^2 + 1 = py^2\), then \(x^2 \equiv -1 \pmod{p}\). Thus \(-1\) is a quadratic residue modulo \(p\), which happens iff \(p \equiv 1 \pmod{4}\). \(\square\)

Sufficiency (\(\Rightarrow\)): If \(p \equiv 1 \pmod{4}\), then \(-1\) is a quadratic residue, so \(x^2 \equiv -1 \pmod{p}\) has a solution.

Consider the lattice \(L = \{(a, b) \in \mathbb{Z}^2 : a \equiv xb \pmod{p}\}\). By Minkowski's theorem, there exists \((a, b) \neq (0, 0)\) with \(a^2 + b^2 = p \cdot m\) for some \(m\).

Using the division algorithm in \(\mathbb{Z}[i]\), we can find a solution. \(\square\)

Example 10.1 Find a solution to \(x^2 + 1 = 5y^2\).

We need \(x^2 + 1 \equiv 0 \pmod{5}\), so \(x^2 \equiv -1 \equiv 4 \pmod{5}\).

Thus \(x \equiv \pm 2 \pmod{5}\). Try \(x = 2\): \(4 + 1 = 5 = 5 \cdot 1\), so \(y = 1\).

Solution: \((x, y) = (2, 1)\). Check: \(2^2 + 1 = 5 = 5 \cdot 1^2\). \(\square\)

Exercises:
  1. Express 65 as a sum of two squares in all possible ways.
  2. Show that 21 cannot be written as a sum of two squares.
  3. Find all integers \(n \leq 50\) that can be written as \(x^2 + y^2\).
  4. Prove that if \(n = x^2 + y^2\) and \(m = u^2 + v^2\), then \(nm = (xu - yv)^2 + (xv + yu)^2\).
  5. Find a solution to \(x^2 + 1 = 13y^2\).
  6. Show that if \(p \equiv 3 \pmod{4}\) is prime, then \(x^2 + 1 = py^2\) has no integer solutions.
  7. Prove: If \(\gcd(x, y) = 1\) and \(x^2 + y^2 = z^n\), then every prime factor of \(z\) is either 2 or \(\equiv 1 \pmod{4}\).
