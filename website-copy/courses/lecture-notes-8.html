Lecture 8: Gaussian Integers - Definition and Arithmetic

Lecture 8Gaussian Integers - Definition and Arithmetic

1. Definition of Gaussian Integers

Definition 8.1 (Gaussian Integers) The ring of Gaussian integers is: \[\mathbb{Z}[i] = \{a + bi : a, b \in \mathbb{Z}\}\] where \(i = \sqrt{-1}\) is the imaginary unit.
Example 8.1 Some Gaussian integers are: \[0, 1, -1, i, -i, 1+i, 2-i, 3+4i, \ldots\]

Addition: \((1 + 2i) + (3 - i) = 4 + i\)

Multiplication: \((1 + 2i)(3 - i) = 3 - i + 6i - 2i^2 = 3 + 5i + 2 = 5 + 5i\)

2. The Norm Function

Definition 8.2 (Norm) For \(\alpha = a + bi \in \mathbb{Z}[i]\), the norm of \(\alpha\) is: \[N(\alpha) = N(a + bi) = a^2 + b^2 = \alpha \bar{\alpha}\] where \(\bar{\alpha} = a - bi\) is the complex conjugate.
Theorem 8.1 (Properties of the Norm) Let \(\alpha, \beta \in \mathbb{Z}[i]\).
  1. \(N(\alpha) \in \mathbb{Z}_{\geq 0}\) and \(N(\alpha) = 0\) iff \(\alpha = 0\).
  2. \(N(\alpha\beta) = N(\alpha)N(\beta)\).
  3. \(N(\alpha) = |\alpha|^2\) (square of the complex absolute value).
Proof of (1): \(N(a + bi) = a^2 + b^2 \geq 0\) with equality iff \(a = b = 0\). \(\square\)

Proof of (2): \[N(\alpha\beta) = (\alpha\beta)(\overline{\alpha\beta}) = (\alpha\beta)(\bar{\alpha}\bar{\beta}) = (\alpha\bar{\alpha})(\beta\bar{\beta}) = N(\alpha)N(\beta). \square\]

3. Units in \(\mathbb{Z}[i]\)

Definition 8.3 (Unit) A unit in \(\mathbb{Z}[i]\) is an element \(\varepsilon\) such that there exists \(\delta \in \mathbb{Z}[i]\) with \(\varepsilon\delta = 1\).
Theorem 8.2 The units in \(\mathbb{Z}[i]\) are \(\{\pm 1, \pm i\}\).
Proof:

Forward direction: If \(\varepsilon = a + bi\) is a unit, then \(\varepsilon\delta = 1\) for some \(\delta\). Taking norms: \(N(\varepsilon)N(\delta) = N(1) = 1\).

Since \(N(\varepsilon), N(\delta) \in \mathbb{Z}_{\geq 0}\), we must have \(N(\varepsilon) = N(\delta) = 1\).

Thus \(a^2 + b^2 = 1\) with \(a, b \in \mathbb{Z}\). The only solutions are \((a, b) = (\pm 1, 0)\) or \((0, \pm 1)\).

Therefore the units are \(\varepsilon = \pm 1\) and \(\varepsilon = \pm i\).

Reverse direction: Verify: \[1 \cdot 1 = 1, \quad (-1) \cdot (-1) = 1, \quad i \cdot (-i) = 1, \quad (-i) \cdot i = 1\] So all four are units. \(\square\)

4. Division Algorithm in \(\mathbb{Z}[i]\)

Theorem 8.3 (Division Algorithm for \(\mathbb{Z}[i]\)) Let \(\alpha, \beta \in \mathbb{Z}[i]\) with \(\beta \neq 0\). Then there exist \(\gamma, \delta \in \mathbb{Z}[i]\) such that: \[\alpha = \beta\gamma + \delta \quad \text{with} \quad N(\delta) < N(\beta).\]
Proof:

Consider \(\frac{\alpha}{\beta} = x + yi \in \mathbb{Q}(i)\). Choose integers \(m, n\) such that \(|x - m| \leq \frac{1}{2}\) and \(|y - n| \leq \frac{1}{2}\).

Set \(\gamma = m + ni\) and \(\delta = \alpha - \beta\gamma\).

Let \(\frac{\alpha}{\beta} = x + yi\). Then \(\delta = \beta\left(\frac{\alpha}{\beta} - \gamma\right) = \beta\left((x-m) + (y-n)i\right)\).

Therefore: \[N(\delta) = N(\beta) \cdot N\left((x-m) + (y-n)i\right) = N(\beta) \cdot \left((x-m)^2 + (y-n)^2\right)\]

Since \(|x - m| \leq \frac{1}{2}\) and \(|y - n| \leq \frac{1}{2}\): \[(x-m)^2 + (y-n)^2 \leq \frac{1}{4} + \frac{1}{4} = \frac{1}{2} < 1\]

Thus \(N(\delta) < N(\beta)\). \(\square\)

Exercises:
  1. Compute \(N(3+4i)\), \(N(2-i)\), \(N(-1+2i)\).
  2. Show that \(1 + i\) is irreducible in \(\mathbb{Z}[i]\).
  3. Find \(\gcd(2 + 3i, 1 + i)\) in \(\mathbb{Z}[i]\).
  4. Show that 5 is not irreducible in \(\mathbb{Z}[i]\) by finding a non-trivial factorization.
  5. Prove: In \(\mathbb{Z}[i]\), \(N(\alpha)\) is a prime in \(\mathbb{Z}\) iff \(\alpha\) is irreducible.
  6. Determine whether \(2 + i\) is irreducible in \(\mathbb{Z}[i]\).
