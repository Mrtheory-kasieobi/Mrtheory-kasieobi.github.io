Polynomial Functions

Precalculus 12 - Lecture Notes
British Columbia Curriculum | Last Updated: 2026

1. Introduction to Polynomial Functions

1.1 Why Study Polynomials?

Polynomials are among the simplest functions in mathematics, yet they can model incredibly complex phenomena. From the trajectory of a projectile to the growth of populations, polynomials provide a versatile tool for understanding the world around us.

Real-World Applications:

Polynomials are used in physics (projectile motion), economics (cost functions), engineering (stress analysis), and computer graphics (Bezier curves). The Fundamental Theorem of Algebra tells us that every polynomial equation has solutions in the complex numbers.

1.2 Definition and Form

A polynomial function is a function of the form:

\[P(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0\]

where \(n\) is a non-negative integer and the coefficients \(a_i\) are real numbers.

Definition: A polynomial function is a sum of powers of \(x\) multiplied by coefficients. The degree of the polynomial is the highest power of \(x\) with a non-zero coefficient.

1.3 Types of Polynomials

  • Monomial: One term (e.g., \(3x^2\))
  • Binomial: Two terms (e.g., \(x^2 + 1\))
  • Trinomial: Three terms (e.g., \(x^2 + 2x + 1\))

2. Characteristics of Polynomial Functions

2.1 End Behavior and Its Importance

The end behavior of a polynomial function describes what happens to the function values as \(x\) approaches positive or negative infinity. This is crucial for understanding long-term trends in models.

End Behavior Rules:
  • If degree is even and leading coefficient is positive: both ends go up
  • If degree is even and leading coefficient is negative: both ends go down
  • If degree is odd and leading coefficient is positive: left down, right up
  • If degree is odd and leading coefficient is negative: left up, right down
Example 1: Analyzing a Polynomial

Analyze \(f(x) = -x^3 + 2x^2 + 5x - 1\)

Degree: 3 (odd), Leading coefficient: -1 (negative)

End behavior: as \(x \to -\infty\), \(f(x) \to \infty\); as \(x \to \infty\), \(f(x) \to -\infty\)

Maximum turning points: 2

Motivation: This tells us the function will eventually decrease without bound as \(x\) increases, which is important for understanding the long-term behavior of the model.

2.2 Number of Turning Points

A polynomial of degree \(n\) can have at most \(n - 1\) turning points. This limits the complexity of the graph's shape.

2.3 Behavior Near Zeros

The multiplicity of a zero determines how the graph behaves at that x-intercept:

  • Odd multiplicity: graph crosses the x-axis
  • Even multiplicity: graph touches but doesn't cross the x-axis

3. The Remainder Theorem

3.1 Why the Remainder Theorem Works

When we divide a polynomial \(P(x)\) by \((x - a)\), we get \(P(x) = (x - a) \cdot Q(x) + R\) where \(R\) is the remainder. Substituting \(x = a\) gives \(P(a) = 0 \cdot Q(a) + R = R\).

Remainder Theorem: If a polynomial \(P(x)\) is divided by \((x - a)\), the remainder is \(P(a)\).
Example 2: Using the Remainder Theorem

When \(P(x) = x^3 - 2x^2 + 3x - 4\) is divided by \((x - 2)\), find the remainder.

By the Remainder Theorem: \(P(2) = 8 - 8 + 6 - 4 = 2\)

The remainder is 2.

Motivation: This theorem provides a quick way to check if a value is a zero without doing long division.

4. The Factor Theorem

4.1 Connection to the Remainder Theorem

The Factor Theorem is a special case of the Remainder Theorem. If the remainder is zero, then \((x - a)\) is a factor of the polynomial.

Factor Theorem: \((x - a)\) is a factor of polynomial \(P(x)\) if and only if \(P(a) = 0\).
Example 3: Using the Factor Theorem

Determine if \((x - 1)\) is a factor of \(P(x) = x^3 - 3x^2 + 3x - 1\).

Check: \(P(1) = 1 - 3 + 3 - 1 = 0\)

Yes, \((x - 1)\) is a factor.

Motivation: This is the foundation for factoring polynomials and finding all their zeros.

5. Equations and Graphs of Polynomial Functions

5.1 Finding Zeros Using Rational Root Theorem

The Rational Root Theorem helps us find potential rational zeros. If a polynomial has integer coefficients, any rational zero \(\frac{p}{q}\) must have \(p\) dividing the constant term and \(q\) dividing the leading coefficient.

Example 4: Finding Zeros

Find the zeros of \(f(x) = x^3 - 4x^2 + x + 6\).

Potential rational zeros: \(\pm 1, \pm 2, \pm 3, \pm 6\)

Testing \(x = 2\): \(f(2) = 8 - 16 + 2 + 6 = 0\) ✓

Using synthetic division: \(f(x) = (x - 2)(x^2 - 2x - 3) = (x - 2)(x - 3)(x + 1)\)

Zeros: \(x = -1, 2, 3\)

Motivation: Finding zeros is essential for solving optimization problems and understanding where a model changes sign.

5.2 Graphing Polynomial Functions

To graph a polynomial, we identify key features that determine its shape:

Graphing Checklist:
  1. End behavior (degree and leading coefficient)
  2. X-intercepts (zeros and their multiplicities)
  3. Y-intercept (value at \(x = 0\))
  4. Turning points and inflection points
  5. Symmetry (even/odd functions)
Example 5: Graphing a Polynomial

Graph \(f(x) = (x + 1)(x - 1)^2(x - 3)\)

X-intercepts: \(x = -1\) (crosses, odd multiplicity), \(x = 1\) (touches, even multiplicity), \(x = 3\) (crosses)

Y-intercept: \(f(0) = (-1)(1)(3) = -3\)

End behavior: degree 4 (even), positive leading coefficient, both ends up

Motivation: This graph shows how multiplicity affects the shape near zeros, which is important for understanding resonance in physics and engineering.

6. Applications and Modeling

6.1 Real-World Application: Projectile Motion

The height of a projectile follows a polynomial equation. For a ball thrown upward with initial velocity \(v_0\) from height \(h_0\):

\[h(t) = -\frac{1}{2}gt^2 + v_0t + h_0\]
Example 6: Projectile Motion

A ball is thrown upward from 2 meters with velocity 15 m/s. Its height is \(h(t) = -4.9t^2 + 15t + 2\). When does it hit the ground?

Solve: \(-4.9t^2 + 15t + 2 = 0\)

Using quadratic formula: \(t \approx 3.16\) seconds

Motivation: This shows how polynomials model real-world motion, which is fundamental to physics and engineering.

7. Practice Problems

Problem 1

State the end behavior of \(f(x) = -2x^4 + x^3 + 5x - 1\) and explain what it means for the long-term behavior of the function.

Problem 2

Use the Remainder Theorem to find the remainder when \(P(x) = 2x^3 - 5x + 1\) is divided by \((x + 2)\).

Problem 3

Find all zeros of \(f(x) = x^3 - 6x^2 + 11x - 6\) and sketch the graph, indicating behavior near each zero.

Problem 4

A company's profit is modeled by \(P(x) = -0.1x^3 + 2x^2 + 5x - 10\) where \(x\) is thousands of units sold. Find the break-even points and interpret them.
