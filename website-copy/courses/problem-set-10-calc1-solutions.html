Problem Set 10: Applications of Integration - SOLUTIONS

Calculus I - Week 9

Solution Guide

Problem 1: Area between \(y = x^3\) and \(y = x\) on \([-1, 1]\)

Solution: Split at \(x = 0\): \(\int_{-1}^0 (x^3 - x)dx + \int_0^1 (x - x^3)dx = \frac{1}{2}\)

Problem 2: Volume by disk method for \(y = x^2\) from \(x = 0\) to \(x = 2\)

Solution: \(V = \pi \int_0^2 (x^2)^2 dx = \pi \int_0^2 x^4 dx = \pi \cdot \frac{32}{5} = \frac{32\pi}{5}\)

Problem 3: Volume by shell method for same region

Solution: \(V = 2\pi \int_0^2 x \cdot x^2 dx = 2\pi \int_0^2 x^3 dx = 8\pi\)

Problem 4: Volume rotating \(y = \sin x\) from \(0\) to \(\pi\)

Solution: \(V = \pi \int_0^\pi \sin^2 x dx = \pi \cdot \frac{\pi}{2} = \frac{\pi^2}{2}\)

Problem 5: Related rates - tank filling

Solution: For cone: \(V = \frac{1}{3}\pi r^2 h\). When \(h = 5\): \(r = 2\).
\(\frac{dV}{dt} = \frac{\pi r^2}{3}\frac{dh}{dt}\). Solve for \(\frac{dh}{dt}\).

Problem 6: Work to pump water from cylindrical tank

Solution: \(W = \int_0^h \rho g \pi r^2 (h-y) dy = \rho g \pi r^2 \frac{h^2}{2}\)

Problem 7: Center of mass for region bounded by \(y = x^2, y = x\)

Solution: Area = \(\frac{1}{6}\). \(\bar{x} = \frac{\int_0^1 x(x-x^2)dx}{A} = \frac{1}{4}\). \(\bar{y} = \frac{\int_0^1 \frac{1}{2}(x^2 - x^4)dx}{A}\)

Problem 8: Average temperature \(T(t) = 50 + 20\cos t\) on \([0, \pi]\)

Solution: \(\frac{1}{\pi}\int_0^\pi (50 + 20\cos t)dt = \frac{50\pi + 0}{\pi} = 50\)

Problem 9: Arc length of \(y = x^{3/2}\) from \(0\) to \(4\)

Solution: \(y' = \frac{3}{2}x^{1/2}\). \(\int_0^4 \sqrt{1 + \frac{9x}{4}} dx\)

Problem 10: Work for spring

Solution: \(F = kx\), \(k = 20\) N/m. \(W = \int_{0.5}^1 kx dx = \frac{k}{2}(1 - 0.25) = \frac{15}{2}\) J

Bonus 1: Volume of solid with hole

Solution: Washer method: outer radius = 2, inner radius = 1

Bonus 2: Work formula units

Solution: Force × distance = Newton-meters = Joules
