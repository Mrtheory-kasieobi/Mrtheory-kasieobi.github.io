Problem Set 10: Applications of Integration - SOLUTIONS

Calculus I - Week 9

Solution Guide

Note: Show all work. Use appropriate integration techniques.

Problem 1: Area between \(y = x^2\) and \(y = x + 2\)

Solution: Intersections: \(x^2 = x + 2 \Rightarrow x = -1, 2\).
\(\text{Area} = \int_{-1}^2 [(x+2) - x^2]dx = \left[x + x - \frac{x^3}{3}\right]_{-1}^2\)
\(= \frac{8}{3} - \left(-\frac{4}{3}\right) = 4\)

Problem 2: Volume by disk method for \(y = \sqrt{x}\) from \(x = 0\) to \(x = 4\) rotated about x-axis

Solution: \(V = \pi \int_0^4 (\sqrt{x})^2 dx = \pi \int_0^4 x dx = \pi\left[\frac{x^2}{2}\right]_0^4 = 8\pi\)

Problem 3: Volume by washer method for region bounded by \(y = x^2\), \(y = 0\), \(x = 2\) rotated about y-axis

Solution: Using shell method: \(V = 2\pi \int_0^2 x \cdot x^2 dx = 2\pi \int_0^2 x^3 dx = 8\pi\)
Or washer: \(V = \pi \int_0^4 (4 - y) dy = 8\pi\)

Problem 4: Area under \(y = e^{-x}\) from \(x = 0\) to \(x = 1\)

Solution: \(\int_0^1 e^{-x} dx = [-e^{-x}]_0^1 = 1 - \frac{1}{e}\)

Problem 5: Work required to pump water from a cylindrical tank (radius 3m, height 5m) full of water

Solution: \(W = \int_0^5 \rho g \cdot \text{Area} \cdot (5-y) dy\)
\(= \rho g \pi(3^2) \int_0^5 (5-y)dy = 9\pi\rho g \cdot \frac{25}{2}\)

Problem 6: Average value of \(f(x) = \sin x\) on \([0, \pi]\)

Solution: \(f_{\text{avg}} = \frac{1}{\pi}\int_0^\pi \sin x dx = \frac{1}{\pi}[-\cos x]_0^\pi = \frac{2}{\pi}\)

Problem 7: Arc length of \(y = \ln x\) from \(x = 1\) to \(x = e\)

Solution: \(y' = \frac{1}{x}\).
\(L = \int_1^e \sqrt{1 + \frac{1}{x^2}} dx = \int_1^e \frac{\sqrt{x^2+1}}{x} dx\)
Substitute \(x = \tan\theta\) or evaluate numerically.

Problem 8: Surface area of sphere of radius \(r\) by rotating \(y = \sqrt{r^2 - x^2}\) about x-axis from \(-r\) to \(r\)

Solution: \(y' = \frac{-x}{\sqrt{r^2 - x^2}}\).
\(S = 2\pi \int_{-r}^r \sqrt{r^2 - x^2} \sqrt{1 + \frac{x^2}{r^2-x^2}} dx = 2\pi \int_{-r}^r \frac{r}{\sqrt{r^2-x^2}} dx = 4\pi r^2\)

Problem 9: Position function \(s(t) = t^3 - 6t^2 + 9t\). Find displacement from \(t = 1\) to \(t = 3\)

Solution: Displacement = \(s(3) - s(1) = (27-54+27) - (1-6+9) = 0 - 4 = -4\) units

Problem 10: Use the Midpoint Rule with \(n = 4\) to approximate \(\int_0^2 x^2 dx\)

Solution: \(\Delta x = 0.5\), midpoints: \(0.25, 0.75, 1.25, 1.75\).
\(\int_0^2 x^2 dx \approx 0.5[0.0625 + 0.5625 + 1.5625 + 3.0625] = 2.625\)

Bonus 1: Find the volume of the solid obtained by rotating the region bounded by \(y = \frac{1}{x}\), \(y = 0\), \(x = 1\), \(x = 2\) about the x-axis

Solution: \(V = \pi \int_1^2 \frac{1}{x^2} dx = \pi\left[-\frac{1}{x}\right]_1^2 = \pi\left(1 - \frac{1}{2}\right) = \frac{\pi}{2}\)

Bonus 2: Prove that \(\int_a^b f(x)dx \geq 0\) if \(f(x) \geq 0\) for all \(x \in [a,b]\)

Solution: Since \(f(x) \geq 0\), \(f(x) = |f(x)|\).
\(\int_a^b f(x)dx = \int_a^b |f(x)|dx \geq 0\) as area under non-negative function.
