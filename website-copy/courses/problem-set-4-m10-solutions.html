Problem Set 4 Solutions: Roots and Powers

Mathematics 10 - Chapter 4

Solutions

Solution 1

\(x^5 \times x^3 \div x^2 = x^{5+3-2} = x^6\)

Solution 2

\((x^2 y^3)^4 = x^8 y^{12}\), \((x y^2)^2 = x^2 y^4\)

\(x^8 y^{12} \div x^2 y^4 = x^6 y^8\)

Solution 3

\((2a^{-3})^2 = 4a^{-6}\), \((4a^{-1})^2 = 16a^{-2}\)

\(\frac{4a^{-6}}{16a^{-2}} = \frac{1}{4}a^{-4} = \frac{1}{4a^4}\)

Solution 4

\(0.0000456 = 4.56 \times 10^{-5}\)

\(5,400,000 = 5.4 \times 10^6\)

Solution 5

Inside: \(a^{-6}b^4\)

Apply outer exponent: \(a^{12}b^{-8} = \frac{a^{12}}{b^8}\)

Solution 6

\((2.5 \times 10^3) \times (4 \times 10^5) = 10 \times 10^8 = 1 \times 10^9\)

Solution 7

\((3x^2y^{-1})^3 = 27x^6y^{-3}\), \((9xy^2)^2 = 81x^2y^4\)

\(\frac{27x^6y^{-3}}{81x^2y^4} = \frac{1}{3}x^4y^{-7} = \frac{x^4}{3y^7}\)

Solution 8

\(2^n = 0.125 = \frac{1}{8} = 2^{-3}\)

Therefore \(n = -3\)

Bonus Problem Solutions

Bonus Solution 1

Step 1: Express 8 GB in bytes

\(8 \text{ GB} = 8 \times 10^9\) bytes

In scientific notation: \(8 \times 10^9\) bytes

Step 2: Find the number of bits

Each byte = 8 bits, so total bits \(= 8 \times (8 \times 10^9) = 64 \times 10^9\) bits

\(64 \times 10^9 = 6.4 \times 10^{10}\) bits

Answer: \(8 \times 10^9\) bytes \(= 6.4 \times 10^{10}\) bits.

Bonus Solution 2

Step 1: Rewrite all bases as powers of 2

\(4 = 2^2\), so \(4^2 = (2^2)^2 = 2^4\)

\(8 = 2^3\), so \(8^{-1} = (2^3)^{-1} = 2^{-3}\)

Step 2: Substitute into the expression

\(\frac{2^{-3} \times 2^4}{2^{-3}} = \frac{2^{1}}{2^{-3}} = 2^{1-(-3)} = 2^4\)

Step 3: Apply the outer exponent

\((2^4)^2 = 2^8 = 256\)

Answer: The simplified value is \(256\).

Bonus Solution 3

Step 1: Set up the ratio

\(\frac{\text{proton mass}}{\text{electron mass}} = \frac{1.67 \times 10^{-27}}{9.11 \times 10^{-31}}\)

Step 2: Separate the coefficients and powers of 10

\(= \frac{1.67}{9.11} \times \frac{10^{-27}}{10^{-31}}\)

\(= 0.1833... \times 10^{-27-(-31)}\)

\(= 0.1833... \times 10^4\)

Step 3: Convert to proper scientific notation

\(0.1833 \times 10^4 = 1.833 \times 10^3\)

Answer: A proton is approximately \(1.83 \times 10^3\) (about 1833) times heavier than an electron.
