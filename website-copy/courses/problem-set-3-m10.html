Problem Set 3: Factors and Products

Mathematics 10 - Chapter 3 Medium

Problems

Problem 1

Find the prime factorization of \(120\) and use it to list all factors.

Problem 2

Factor completely: \(x^2 + 9x + 20\)

Problem 3

Factor: \(2x^2 + 7x - 15\) (Use AC method: find two numbers that multiply to \(-30\) and add to \(7\))

Problem 4

Factor: \(9x^2 - 16y^2\) (Difference of squares pattern: \(a^2 - b^2 = (a-b)(a+b)\))

Problem 5

Factor: \(x^2 - 10x + 25\) (Perfect square trinomial: \(a^2 - 2ab + b^2 = (a-b)^2\))

Problem 6

Factor: \(3x^3 - 12x\) (First factor out the GCF)

Problem 7

Solve: \(x^2 + 7x + 12 = 0\) by factoring

Problem 8

Factor: \(\frac{1}{2}x^2 + \frac{3}{4}x + \frac{1}{8}\) (Multiply by LCD first)

Bonus Problems

Bonus Problem 1

Challenge: A rectangular garden has area \(x^2 + 12x + 35\) m². The length is \((x + 7)\) m. Find the width, then determine the perimeter of the garden. If \(x = 5\), what are the actual dimensions and perimeter?

Bonus Problem 2

Challenge: A number is called "special" if it can be written as the product of two consecutive integers. Find all special numbers between \(100\) and \(200\). (Hint: If \(n\) is special, then \(n = k(k+1)\) for some integer \(k\). Solve \(k(k+1) \approx 100\) to \(200\).)

Bonus Problem 3

Challenge: A right triangle has area \(150\) cm². If the legs are \(x\) cm and \((x + 5)\) cm, find the value of \(x\) by factoring, then find the actual lengths of the legs and the hypotenuse using the Pythagorean theorem. (Hint: Area \(= \frac{1}{2} \times \text{base} \times \text{height}\), so \(x(x+5) = 300\))
