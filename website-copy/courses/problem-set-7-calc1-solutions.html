Problem Set 7: Integration - SOLUTIONS

Calculus I - Week 7

Solution Guide

Problem 1: \(\int (3x^2 - 2x + 5) \, dx\)

Solution: \(\int 3x^2 dx - \int 2x dx + \int 5 dx = x^3 - x^2 + 5x + C\)

Problem 2: \(\int_0^1 x^3 \, dx\)

Solution: \(\left[\frac{x^4}{4}\right]_0^1 = \frac{1}{4} - 0 = \frac{1}{4}\)

Problem 3: \(\int \frac{1}{x} \, dx\)

Solution: \(\ln|x| + C\)

Problem 4: \(\int_1^e \frac{1}{x} \, dx\)

Solution: \([\ln x]_1^e = \ln e - \ln 1 = 1 - 0 = 1\)

Problem 5: \(\int x e^x \, dx\)

Solution: Integration by parts: \(u = x, dv = e^x dx\). Then \(du = dx, v = e^x\).
\(uv - \int v du = xe^x - e^x + C = e^x(x-1) + C\)

Problem 6: \(\int \frac{\ln x}{x} \, dx\)

Solution: Substitution: \(u = \ln x, du = \frac{1}{x}dx\).
\(\int u du = \frac{u^2}{2} + C = \frac{(\ln x)^2}{2} + C\)

Problem 7: \(\int \sin^2 x \, dx\)

Solution: Use identity: \(\sin^2 x = \frac{1-\cos 2x}{2}\).
\(\int \frac{1}{2} dx - \int \frac{\cos 2x}{2} dx = \frac{x}{2} - \frac{\sin 2x}{4} + C\)

Problem 8: \(\int_0^{\pi/2} \cos^2 x \, dx\)

Solution: Use identity: \(\cos^2 x = \frac{1+\cos 2x}{2}\).
\(\int_0^{\pi/2} \frac{1}{2} dx + \int_0^{\pi/2} \frac{\cos 2x}{2} dx = \frac{\pi}{4} + 0 = \frac{\pi}{4}\)

Problem 9: \(\int \frac{1}{x^2 + 4} \, dx\)

Solution: \(\int \frac{1}{x^2 + 2^2} dx = \frac{1}{2}\tan^{-1}\frac{x}{2} + C\)

Problem 10: \(\int \frac{x}{x^2 + 1} \, dx\)

Solution: Substitution: \(u = x^2 + 1, du = 2x dx\).
\(\frac{1}{2}\int \frac{1}{u} du = \frac{1}{2}\ln|u| + C = \frac{1}{2}\ln(x^2 + 1) + C\)

Bonus 1: \(\int \frac{1}{x \ln x} \, dx\)

Solution: Substitution: \(u = \ln x, du = \frac{1}{x}dx\).
\(\int \frac{1}{u} du = \ln|\ln x| + C\)

Bonus 2: \(\int_0^1 \frac{1}{\sqrt{1-x^2}} \, dx\)

Solution: \(\int_0^1 \frac{1}{\sqrt{1-x^2}} dx = [\sin^{-1} x]_0^1 = \frac{\pi}{2} - 0 = \frac{\pi}{2}\).
This is the arc length of a unit circle from 0 to 90 degrees.
