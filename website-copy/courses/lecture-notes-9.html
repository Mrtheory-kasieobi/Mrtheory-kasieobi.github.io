Lecture 9: Gaussian Primes and Factorization

Lecture 9Gaussian Primes and Factorization

1. Classification of Gaussian Primes

Theorem 9.1 (Classification of Gaussian Primes) Up to associates, the Gaussian primes are:
  1. \(1 + i\) (the prime dividing 2).
  2. For each rational prime \(p \equiv 3 \pmod{4}\), the prime \(p\) itself (as an element of \(\mathbb{Z}[i]\)).
  3. For each rational prime \(p \equiv 1 \pmod{4}\), the Gaussian primes \(\pi\) and \(\bar{\pi}\) where \(p = \pi\bar{\pi}\) (a proper factorization in \(\mathbb{Z}[i]\)).
Proof:

We analyze primes in \(\mathbb{Z}[i]\) by considering the norm \(N(a + bi) = a^2 + b^2\).

Case 1: \(\alpha = a + bi\) with \(a = 0\) or \(b = 0\).

If \(b = 0\), then \(\alpha = a \in \mathbb{Z}\). For \(\alpha\) to be prime in \(\mathbb{Z}[i]\), we need \(N(\alpha) = a^2\) to be a rational prime power.

If \(a^2 = p\) for prime \(p\), then \(p = 2\) and \(a = \pm\sqrt{2} \notin \mathbb{Z}\). Contradiction.

If \(a^2 = p^k\) with \(k \geq 2\), then \(a = \pm p^{k/2}\). For \(k = 2\): \(\alpha = \pm p\), \(N(\alpha) = p^2\). But \(\alpha = p \cdot 1\), so \(p\) is not prime in \(\mathbb{Z}[i]\) unless \(p\) remains prime in \(\mathbb{Z}[i]\).

Case 2: Both \(a, b \neq 0\).

Suppose \(N(\alpha) = a^2 + b^2 = p\) for rational prime \(p\).

If \(p \equiv 3 \pmod{4}\), then by Fermat's theorem on sums of two squares, \(p\) cannot be written as \(a^2 + b^2\) with \(a, b \neq 0\). Contradiction.

If \(p = 2\), then \(a^2 + b^2 = 2\) gives \(a^2 = b^2 = 1\), so \(\alpha = \pm 1 \pm i\). These are associates of \(1 + i\).

If \(p \equiv 1 \pmod{4}\), then by Fermat's theorem, \(p = a^2 + b^2\) for some \(a, b \neq 0\). The Gaussian integers \(a + bi\) and \(a - bi\) have norm \(p\) and are irreducible. \(\square\)

2. Unique Factorization in \(\mathbb{Z}[i]\)

Theorem 9.2 \(\mathbb{Z}[i]\) is a unique factorization domain (UFD). Every non-zero, non-unit Gaussian integer can be written as a product of Gaussian primes, and this factorization is unique up to order and associates.
Proof:

We verify that \(\mathbb{Z}[i]\) satisfies all properties of a UFD:

  1. \(\mathbb{Z}[i]\) is an integral domain (no zero divisors).
  2. The norm is multiplicative: \(N(\alpha\beta) = N(\alpha)N(\beta)\)
  3. Every non-zero, non-unit element has a factorization into irreducibles (by the division algorithm).
  4. Factorization is unique up to associates and order.

The key is that \(\mathbb{Z}[i]\) is a Euclidean domain with the norm as the Euclidean function. This implies unique factorization. \(\square\)

3. Applications to Sums of Two Squares

Theorem 9.3 (Fermat's Two Squares Theorem) An odd prime \(p\) can be expressed as \(p = x^2 + y^2\) for integers \(x, y\) if and only if \(p \equiv 1 \pmod{4}\).

Necessity (\(\Rightarrow\)): If \(p = x^2 + y^2\), then considering modulo 4: \[p = x^2 + y^2 \equiv 0, 1, \text{ or } 2 \pmod{4}\]

If \(p\) is odd and \(p \equiv 0 \pmod{4}\), then \(p\) is even, contradiction.

If \(p \equiv 2 \pmod{4}\), then \(p = 2\), but 2 is not odd. Contradiction.

Therefore \(p \equiv 1 \pmod{4}\). \(\square\)

Sufficiency (\(\Rightarrow\)): If \(p \equiv 1 \pmod{4}\), then \(-1\) is a quadratic residue modulo \(p\).

Let \(x^2 \equiv -1 \pmod{p}\). Consider the lattice \(L = \{(a, b) \in \mathbb{Z}^2 : a \equiv xb \pmod{p}\}\).

Let \(S = \{(a, b) \in L : a^2 + b^2 < 2p\}\). By Minkowski's theorem, there exists \((a, b) \neq (0, 0)\) in \(S \cap L\).

Since \((a, b) \in L\), we have \(a = xb + kp\) for some integer \(k\).

Then \(a^2 + b^2 = b^2(x^2 + 1) + kp(\cdots) = p \cdot m\) for some integer \(m\).

Since \(0 < a^2 + b^2 < 2p\) and \(p \mid (a^2 + b^2)\), we must have \(a^2 + b^2 = p\). \(\square\)

Example 9.1 Express 13 as a sum of two squares.

Since \(13 \equiv 1 \pmod{4}\), we know \(13 = x^2 + y^2\) for some \(x, y\).

Try values: \(3^2 = 9\), \(13 - 9 = 4 = 2^2\).

Thus \(13 = 3^2 + 2^2\).

In Gaussian integers: \(13 = (3 + 2i)(3 - 2i)\), and \(N(3 + 2i) = 13\). \(\square\)

Exercises:
  1. Find the Gaussian prime factorization of 5.
  2. Find the Gaussian prime factorization of 10.
  3. Show that \(2 + i\) is a Gaussian prime.
  4. Prove that if \(p \equiv 3 \pmod{4}\), then \(p\) remains prime in \(\mathbb{Z}[i]\).
  5. Find all Gaussian integers with norm 5.
  6. Show that \(1 + i\) divides every Gaussian integer of even norm.
  7. Prove: If \(\alpha \in \mathbb{Z}[i]\) has prime norm \(p\), then \(p \equiv 1 \pmod{4}\) or \(p = 2\).
