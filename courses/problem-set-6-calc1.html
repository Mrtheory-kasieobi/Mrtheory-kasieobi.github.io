Problem Set 6: Mean Value Theorem and Curve Sketching

Calculus I - Week 6

Instructions

Show all work. No calculators. Write clearly and show each step.

Problems

  • 1. Verify the MVT for \(f(x) = x^3\) on \([1, 3]\)
  • 2. Find all critical points of \(f(x) = \frac{x^2}{x-1}\)
  • 3. Sketch the curve \(y = \frac{x}{\sqrt{x+1}}\) by finding intercepts, asymptotes, and critical points
  • 4. Find the intervals where \(f(x) = x^3 - 3x^2 + 4\) is increasing/decreasing
  • 5. Determine the concavity of \(f(x) = e^x - x^2\)
  • 6. Find the inflection point(s) of \(f(x) = x^4 - 4x^3\)
  • 7. Use the First Derivative Test to classify critical points of \(f(x) = x + \cos x\) on \([0, 2\pi]\)
  • 8. Sketch \(y = \sin x + \cos x\) on \([0, 2\pi]\) using calculus techniques
  • 9. Find the equation of the tangent line to \(y = \ln(x^2 + 1)\) at \(x = 1\)
  • 10. Prove that if \(f\) is differentiable on \((a,b)\) and \(f'(x) = 0\) for all \(x \in (a,b)\), then \(f\) is constant on \((a,b)\)
Bonus Problems (10 points each):
  • B1. Use the Second Derivative Test to classify critical points of \(f(x) = x^4 - 4x^3 + 6x^2 - 4x + 1\)
  • B2. If \(f\) has an inflection point at \(x = a\), prove that \(f'''(a) = 0\) or \(f'''(a)\) does not exist (assuming \(f'''\) exists)
