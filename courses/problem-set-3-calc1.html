Problem Set 3: Derivatives - Definition and Rules

Calculus I - Week 3

Instructions

Show all work. No calculators. Write clearly and show each step.

Problems

  • 1. Find \(\frac{dy}{dx}\) for \(y = x^3 - 6x^2 + 5x - 2\)
  • 2. Find the equation of the tangent line to \(y = x^2\) at \(x = 3\)
  • 3. Use the definition of the derivative to find \(f'(x)\) for \(f(x) = \frac{1}{x}\)
  • 4. Find \(\frac{d}{dx}[e^{2x} \cdot \ln x]\)
  • 5. If \(f(x) = \sin(x^2 + 1)\), find \(f'(x)\)
  • 6. Find \(\frac{dy}{dx}\) for \(y = \frac{x^2 + 1}{x - 3}\)
  • 7. A particle's position is given by \(s(t) = t^3 - 6t^2 + 9t\). Find velocity at \(t = 2\)
  • 8. Find the critical numbers of \(f(x) = x^3 - 3x^2 - 9x + 5\)
  • 9. Find \(\frac{d}{dx}[\tan^{-1}(x^2)]\)
  • 10. Prove that \(\frac{d}{dx}[x^n] = nx^{n-1}\) for \(n = \frac{1}{2}\)
Bonus Problems (10 points each):
  • B1. Find all points where the tangent line to \(y = \sin x\) is horizontal
  • B2. If \(f\) is differentiable and \(f(3) = 5\), \(f'(3) = -2\), find the equation of the tangent line to \(y = f(x)\) at \(x = 3\)
