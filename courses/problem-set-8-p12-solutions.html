Problem Set 8: Rational Functions

Precalculus 12 - Chapter 8 Solutions

Solutions

Problem 1: Find the domain, vertical asymptotes, and horizontal asymptote of \(f(x) = \frac{x^2 - 4}{x^2 - 9}\).
Factor numerator: \(x^2 - 4 = (x-2)(x+2)\)
Factor denominator: \(x^2 - 9 = (x-3)(x+3)\)
Domain: Denominator ≠ 0, so \(x \neq 3, -3\). Domain: \((-\infty, -3) \cup (-3, 3) \cup (3, \infty)\)
Vertical asymptotes: Where denominator = 0 but numerator ≠ 0, at \(x = 3, -3\)
Horizontal asymptote: degrees equal, ratio of leading coefficients: \(y = \frac{1}{1} = 1\)
Answer: Domain: \(\mathbb{R} \setminus \{-3, 3\}\), VA: x = ±3, HA: y = 1
Problem 2: Solve: \(\frac{2}{x-1} + \frac{3}{x+2} = \frac{1}{x^2 + x - 2}\)
Factor denominator: \(x^2 + x - 2 = (x+2)(x-1)\)
Common denominator: \((x-1)(x+2)\)
Multiply through: \(2(x+2) + 3(x-1) = 1\)
Expand: \(2x + 4 + 3x - 3 = 1\)
Simplify: \(5x + 1 = 1\), so \(5x = 0\)
Solution: \(x = 0\)
Check domain: \(x \neq 1, -2\), and \(x = 0\) is valid
Answer: \(x = 0\)
Problem 3: Graph \(f(x) = \frac{1}{x^2 - 4}\) by identifying asymptotes, intercepts, and behavior near asymptotes.
Vertical asymptotes: \(x^2 - 4 = 0\), so \(x = 2, -2\)
Horizontal asymptote: Degree of denominator > numerator, \(y = 0\)
x-intercepts: None (numerator is 1)
y-intercept: \(f(0) = \frac{1}{-4} = -\frac{1}{4}\)
Behavior: Near x = ±2, denominator → 0, function → +∞
Answer: VA x = ±2, HA y = 0, y-intercept -1/4
Problem 4: A rectangular box with volume 100 cm³ has square base. Find the dimensions that minimize surface area.
Let base side = x, height = h
Volume: \(x^2 h = 100\), so \(h = \frac{100}{x^2}\)
Surface area: \(S = 2x^2 + 4xh = 2x^2 + 4x \cdot \frac{100}{x^2} = 2x^2 + \frac{400}{x}\)
Minimize: \(S' = 4x - \frac{400}{x^2} = 0\)
Solve: \(4x = \frac{400}{x^2}\), so \(4x^3 = 400\)
\(x^3 = 100\), so \(x = \sqrt[3]{100}\)
Height: \(h = \frac{100}{(\sqrt[3]{100})^2} = \sqrt[3]{100}\)
Cube is a perfect cube with all edges equal
Answer: x = h = \(\sqrt[3]{100}\) cm ≈ 4.64 cm
Problem 5: Find the inverse of \(f(x) = \frac{2x + 1}{x - 3}\). State the domain and range of both functions.
Let \(y = \frac{2x + 1}{x - 3}\)
Cross multiply: \(y(x - 3) = 2x + 1\)
Expand: \(yx - 3y = 2x + 1\)
Collect x terms: \(yx - 2x = 3y + 1\)
Factor: \(x(y - 2) = 3y + 1\)
Solve: \(x = \frac{3y + 1}{y - 2}\)
Inverse: \(f^{-1}(x) = \frac{3x + 1}{x - 2}\)
Original domain: \(x \neq 3\), range: \(y \neq 2\)
Inverse domain: \(x \neq 2\), range: \(y \neq 3\)
Answer: \(f^{-1}(x) = \frac{3x+1}{x-2}\), Domains excluding ±2,3
Problem 6: Solve: \(\frac{x + 1}{x - 2} = \frac{2x - 1}{x + 3}\)
Cross multiply: \((x + 1)(x + 3) = (2x - 1)(x - 2)\)
Expand LHS: \(x^2 + 4x + 3\)
Expand RHS: \(2x^2 - 4x - x + 2 = 2x^2 - 5x + 2\)
Set equal: \(x^2 + 4x + 3 = 2x^2 - 5x + 2\)
Rearrange: \(0 = x^2 - 9x - 1\)
Quadratic formula: \(x = \frac{9 \pm \sqrt{81 + 4}}{2} = \frac{9 \pm \sqrt{85}}{2}\)
Check domain: \(x \neq 2, -3\). Both solutions valid.
Answer: \(x = \frac{9 \pm \sqrt{85}}{2}\)
Problem 7: Graph \(f(x) = \frac{x^2 - 1}{x^2 - 4}\) and identify any holes, asymptotes, and intercepts.
Factor: Numerator = \((x-1)(x+1)\), Denominator = \((x-2)(x+2)\)
No common factors, so no holes
Vertical asymptotes: x = 2, x = -2
Horizontal asymptote: \(y = 1\) (leading coefficients ratio)
x-intercepts: \(x^2 - 1 = 0\), so \(x = \pm 1\)
y-intercept: \(f(0) = \frac{-1}{-4} = \frac{1}{4}\)
Answer: No holes, VA x = ±2, HA y = 1, x-intercepts x = ±1
Problem 8: A drug concentration is \(C(t) = \frac{10t}{t^2 + 1}\) mg/L. Find the maximum concentration and when it occurs.
Find critical points: \(C'(t) = \frac{10(t^2 + 1) - 10t(2t)}{(t^2 + 1)^2}\)
Simplify numerator: \(10t^2 + 10 - 20t^2 = 10 - 10t^2\)
Set \(C'(t) = 0\): \(10 - 10t^2 = 0\)
Solve: \(t^2 = 1\), so \(t = \pm 1\)
Since t ≥ 0 (time): \(t = 1\) hour
Maximum concentration: \(C(1) = \frac{10(1)}{2} = 5\) mg/L
Answer: Maximum at t = 1 hour, concentration = 5 mg/L

Bonus Solutions

Bonus Problem 1: Find the domain, vertical asymptotes, horizontal asymptotes, and x-intercepts of \(f(x) = \frac{x^3 - 8}{x^2 - 4x + 4}\).
Factor numerator: \(x^3 - 8 = (x - 2)(x^2 + 2x + 4)\)
Factor denominator: \(x^2 - 4x + 4 = (x - 2)^2\)
Common factor: \((x - 2)\)
After canceling: \(f(x) = \frac{x^2 + 2x + 4}{x - 2}\)
There's a hole at x = 2 (not an asymptote since factor is common)
Vertical asymptote: x = 2 (from simplified form after hole)
Actually, original function undefined at x = 2, so it's a hole
Simplified function: \(f(x) = x + 3 + \frac{4}{x-2}\)
Vertical asymptote: x = 2
Horizontal asymptote: None (degree numerator > denominator)
x-intercepts: \(x^2 + 2x + 4 = 0\) has no real roots (discriminant < 0)
Answer: Hole at x = 2, VA x = 2, no x-intercepts
Bonus Problem 2: Solve: \(\frac{x^2 - 5x + 6}{x^2 - 9} = \frac{1}{x - 3}\) and check for extraneous solutions.
Factor numerators: \(\frac{(x-2)(x-3)}{(x-3)(x+3)} = \frac{1}{x-3}\)
Cancel (x-3): \(\frac{x-2}{x+3} = \frac{1}{x-3}\) (valid for x ≠ 3)
Cross multiply: \((x-2)(x-3) = x + 3\)
Expand: \(x^2 - 5x + 6 = x + 3\)
Rearrange: \(x^2 - 6x + 3 = 0\)
Quadratic formula: \(x = \frac{6 \pm \sqrt{36 - 12}}{2} = \frac{6 \pm \sqrt{24}}{2} = 3 \pm \sqrt{6}\)
Check: Neither solution equals 3 or -3, so both valid
Answer: \(x = 3 \pm \sqrt{6}\)
