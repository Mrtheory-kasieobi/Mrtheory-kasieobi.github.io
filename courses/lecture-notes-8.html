Lecture 8: Quadratic Reciprocity Law

Lecture 8Quadratic Reciprocity Law

1. Statement of Quadratic Reciprocity

Definition 8.1 For an odd prime \(p\), define \(\epsilon(p) = (-1)^{\frac{p-1}{2}}\). Note that: \[\epsilon(p) = \begin{cases} 1 & \text{if } p \equiv 1 \pmod{4} \\ -1 & \text{if } p \equiv 3 \pmod{4} \end{cases}\]
Theorem 8.1 (Quadratic Reciprocity Law) Let \(p\) and \(q\) be distinct odd primes. Then: \[\left(\frac{p}{q}\right) = \epsilon(q) \cdot \epsilon(p) \cdot \left(\frac{q}{p}\right)\] Equivalently: \[\left(\frac{p}{q}\right) \left(\frac{q}{p}\right) = (-1)^{\frac{p-1}{2} \cdot \frac{q-1}{2}}\]
Example 8.1 Compute \(\left(\frac{3}{11}\right)\) using Quadratic Reciprocity.
Step 1: Apply Quadratic Reciprocity

Since \(3 \equiv 3 \pmod{4}\) and \(11 \equiv 3 \pmod{4}\):

\[\left(\frac{3}{11}\right) \left(\frac{11}{3}\right) = (-1)^{\frac{3-1}{2} \cdot \frac{11-1}{2}} = (-1)^{1 \cdot 5} = -1\]

Therefore \(\left(\frac{3}{11}\right) = -\left(\frac{11}{3}\right)\).

Step 2: Compute \(\left(\frac{11}{3}\right)\)

Reduce modulo 3: \(11 \equiv 2 \pmod{3}\).

So \(\left(\frac{11}{3}\right) = \left(\frac{2}{3}\right)\).

Step 3: Use the second supplementary law

\(3 \equiv 3 \pmod{8}\), so \(\left(\frac{2}{3}\right) = -1\).

Therefore \(\left(\frac{11}{3}\right) = -1\).

Step 4: Conclude

\(\left(\frac{3}{11}\right) = -\left(\frac{11}{3}\right) = -(-1) = 1\).

Verification: \(5^2 = 25 \equiv 3 \pmod{11}\). ✓

2. Gauss's Lemma

Definition 8.2 (Gauss's Lemma Set) Let \(p\) be an odd prime and \(a\) an integer with \(\gcd(a, p) = 1\). Define the set: \[S = \{a, 2a, 3a, \ldots, \frac{p-1}{2}a\}\] Let \(\mu\) be the number of elements in \(S\) whose least positive residues modulo \(p\) are greater than \(\frac{p}{2}\).
Theorem 8.2 (Gauss's Lemma) With notation as above: \[\left(\frac{a}{p}\right) = (-1)^\mu\]
Example 8.2 Use Gauss's Lemma to compute \(\left(\frac{2}{p}\right)\) for \(p = 7\).
Step 1: Form the set S

\(S = \{1 \cdot 2, 2 \cdot 2\} = \{2, 4\}\) (since \(\frac{p-1}{2} = 3\), but we only go up to \(\frac{p-1}{2} = 3\) elements... wait, let me correct this.)

For \(p = 7\): \(S = \{1 \cdot 2, 2 \cdot 2, 3 \cdot 2\} = \{2, 4, 6\}\).

Step 2: Find residues greater than p/2

\(\frac{p}{2} = \frac{7}{2} = 3.5\)

Residues: 2, 4, 6

Those > 3.5: 4 and 6, so \(\mu = 2\).

Step 3: Compute the Legendre symbol

\(\left(\frac{2}{7}\right) = (-1)^2 = 1\).

Indeed, \(3^2 = 9 \equiv 2 \pmod{7}\). ✓

Proof of the Second Supplementary Law using Gauss's Lemma:
Step 1: Count μ for a = 2

We need to count how many of \(2, 4, 6, \ldots, (p-1)\) are > \(\frac{p}{2}\).

Step 2: Use modular arithmetic

Consider the elements \(2, 4, 6, \ldots, p-1\) modulo \(p\).

An element \(2k\) (for \(1 \leq k \leq \frac{p-1}{2}\)) satisfies \(2k > \frac{p}{2}\) iff \(k > \frac{p}{4}\).

Step 3: Count elements

The number of integers \(k\) with \(\frac{p}{4} < k \leq \frac{p-1}{2}\) depends on \(p \pmod{8}\).

After analysis: \(\mu \equiv \frac{p^2-1}{8} \pmod{2}\).

Therefore \(\left(\frac{2}{p}\right) = (-1)^{\frac{p^2-1}{8}}\).

This gives: \(\left(\frac{2}{p}\right) = 1\) iff \(p \equiv \pm 1 \pmod{8}\). \(\square\)

3. Proof via Eisenstein's Lemma

Theorem 8.3 (Eisenstein's Lemma) Let \(p\) be an odd prime and \(a\) an integer with \(\gcd(a, p) = 1\). Define: \[\mu(a, p) = \#\left\{1 \leq k \leq \frac{p-1}{2} : \lfloor \frac{2ka}{p} \rfloor \text{ is even}\right\}\] Then: \[\left(\frac{a}{p}\right) = (-1)^{\mu(a, p)}\]
Proof sketch:
Step 1: Geometric interpretation

Consider the lattice points \((k, j)\) with \(1 \leq k \leq \frac{p-1}{2}\) and \(1 \leq j \leq \frac{p-1}{2}\).

The line \(y = \frac{2a}{p}x\) passes through this region.

Step 2: Count lattice points

The number of lattice points below the line relates to \(\mu(a, p)\).

Using Pick's Theorem and careful counting, we establish the result.

Step 3: Apply to reciprocity

The symmetry in counting lattice points for \(\left(\frac{p}{q}\right)\) and \(\left(\frac{q}{p}\right)\) yields the reciprocity law.

Specifically: \(\mu(p, q) + \mu(q, p) \equiv \frac{p-1}{2} \cdot \frac{q-1}{2} \pmod{2}\). \(\square\)

4. Detailed Statement and Consequences

Definition 8.3 (Eisenstein Symbol) For distinct odd primes \(p, q\), define: \[\epsilon(p, q) = (-1)^{\frac{p-1}{2} \cdot \frac{q-1}{2}}\] This captures the "correction factor" in quadratic reciprocity.
Example 8.3 Analyze the reciprocity law for specific cases.
Case 1: Both \(p \equiv 1 \pmod{4}\) and \(q \equiv 1 \pmod{4}\)

Then \(\frac{p-1}{2}\) and \(\frac{q-1}{2}\) are both even.

So \(\epsilon(p, q) = (-1)^{\text{even} \cdot \text{even}} = 1\).

Therefore \(\left(\frac{p}{q}\right) = \left(\frac{q}{p}\right)\).

Case 2: Both \(p \equiv 3 \pmod{4}\) and \(q \equiv 3 \pmod{4}\)

Then \(\frac{p-1}{2}\) and \(\frac{q-1}{2}\) are both odd.

So \(\epsilon(p, q) = (-1)^{\text{odd} \cdot \text{odd}} = -1\).

Therefore \(\left(\frac{p}{q}\right) = -\left(\frac{q}{p}\right)\).

Case 3: One is 1 mod 4, the other is 3 mod 4

Then \(\epsilon(p, q) = (-1)^{\text{even} \cdot \text{odd}} = 1\).

Therefore \(\left(\frac{p}{q}\right) = \left(\frac{q}{p}\right)\).

Definition 8.4 (Fermat's Gift) For an odd prime \(p\), let \(g_p\) be the smallest positive integer such that \(g_p^p \equiv 1 \pmod{p}\) (when such a primitive root exists). Then: \[\left(\frac{g_p}{p}\right) = (-1)^{\frac{g_p-1}{2}}\] This provides an alternative formulation of the Legendre symbol.

5. Applications and Examples

Example 8.3 Compute \(\left(\frac{13}{17}\right)\).
Step 1: Apply Quadratic Reciprocity

Since \(13 \equiv 1 \pmod{4}\) and \(17 \equiv 1 \pmod{4}\):

\[\left(\frac{13}{17}\right) = \left(\frac{17}{13}\right)\]
Step 2: Reduce modulo 13

\(17 \equiv 4 \pmod{13}\), so \(\left(\frac{17}{13}\right) = \left(\frac{4}{13}\right)\).

Step 3: Simplify

\(\left(\frac{4}{13}\right) = \left(\frac{2^2}{13}\right) = \left(\frac{2}{13}\right)^2 = 1\).

Therefore \(\left(\frac{13}{17}\right) = 1\).

Example 8.4 Compute \(\left(\frac{5}{23}\right)\).
Step 1: Apply Quadratic Reciprocity

Since \(5 \equiv 1 \pmod{4}\):

\[\left(\frac{5}{23}\right) = \left(\frac{23}{5}\right)\]
Step 2: Reduce modulo 5

\(23 \equiv 3 \pmod{5}\), so \(\left(\frac{23}{5}\right) = \left(\frac{3}{5}\right)\).

Step 3: Apply reciprocity again

Since \(3 \equiv 3 \pmod{4}\) and \(5 \equiv 1 \pmod{4}\):

\[\left(\frac{3}{5}\right) = \left(\frac{5}{3}\right)\]
Step 4: Reduce modulo 3

\(5 \equiv 2 \pmod{3}\), so \(\left(\frac{5}{3}\right) = \left(\frac{2}{3}\right)\).

Step 5: Use supplementary law

\(3 \equiv 3 \pmod{8}\), so \(\left(\frac{2}{3}\right) = -1\).

Therefore \(\left(\frac{5}{23}\right) = -1\).
