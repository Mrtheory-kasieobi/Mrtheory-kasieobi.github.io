Integration Techniques

Calculus I - Week 11

1. Integration by Substitution

1.1 The Substitution Rule

Theorem 1.1 (Substitution Rule): If \(u = g(x)\) is a differentiable function and \(f\) is continuous on the range of \(g\), then: $$\int f(g(x))g'(x) \, dx = \int f(u) \, du$$
Proof: Let \(F\) be an antiderivative of \(f\), so \(F'(u) = f(u)\). Define \(G(x) = F(g(x))\). By the Chain Rule: $$G'(x) = F'(g(x)) \cdot g'(x) = f(g(x)) \cdot g'(x)$$ Therefore: $$\int f(g(x))g'(x) \, dx = G(x) + C = F(g(x)) + C$$ Substituting \(u = g(x)\): $$\int f(g(x))g'(x) \, dx = F(u) + C = \int f(u) \, du$$ ∎
Example 1.1: Evaluate \(\int 2x \cos(x^2) \, dx\).

Let \(u = x^2\), so \(du = 2x \, dx\)

Result: \(\int \cos(u) \, du = \sin(u) + C = \sin(x^2) + C\)

Example 1.2: Evaluate \(\int \frac{1}{x \ln x} \, dx\).

Let \(u = \ln x\), so \(du = \frac{1}{x} \, dx\)

Result: \(\int \frac{1}{u} \, du = \ln|u| + C = \ln|\ln x| + C\)

1.2 Definite Integrals with Substitution

Formula 1.1: For definite integrals: \(\int_a^b f(g(x))g'(x) \, dx = \int_{g(a)}^{g(b)} f(u) \, du\)

Alternative: Evaluate the indefinite integral first, then substitute back before applying the limits.
Example 1.3: Evaluate \(\int_0^1 x \sqrt{x^2 + 1} \, dx\).

Let \(u = x^2 + 1\), so \(du = 2x \, dx\) and \(x \, dx = \frac{du}{2}\)

Change limits: when \(x = 0\), \(u = 1\); when \(x = 1\), \(u = 2\)

Result: \(\int_1^2 \frac{\sqrt{u}}{2} \, du = \frac{1}{2} \cdot \frac{2}{3} u^{3/2}\Big|_1^2 = \frac{1}{3}(2\sqrt{2} - 1)\)

2. Integration by Parts

2.1 The Integration by Parts Formula

Formula 2.1: $$\int u \, dv = uv - \int v \, du$$
Proof: Start with the Product Rule: $$\frac{d}{dx}[u(x)v(x)] = u(x)v'(x) + u'(x)v(x)$$ Integrate both sides: $$u(x)v(x) = \int u(x)v'(x) \, dx + \int u'(x)v(x) \, dx$$ Rearranging: $$\int u(x)v'(x) \, dx = u(x)v(x) - \int u'(x)v(x) \, dx$$ With \(v' = \frac{dv}{dx}\) and \(u' = \frac{du}{dx}\): $$\int u \, dv = uv - \int v \, du$$ ∎

2.2 Choosing u and dv (LIATE Rule)

LIATE Strategy for choosing u:
  1. Logarithms: \(\ln x\)
  2. Ind inverse trig: \(\sin^{-1}x, \tan^{-1}x\)
  3. Algebraic: \(x^n\)
  4. Trigonometric: \(\sin x, \cos x\)
  5. Exponential: \(e^x\)
Choose \(u\) from the first applicable category.
Example 2.1: Evaluate \(\int x e^x \, dx\).

Choose: \(u = x\) (algebraic), \(dv = e^x \, dx\)

Then: \(du = dx\), \(v = e^x\)

Result: \(xe^x - \int e^x \, dx = xe^x - e^x + C = e^x(x-1) + C\)

Example 2.2: Evaluate \(\int \ln x \, dx\).

Write as \(\int 1 \cdot \ln x \, dx\)

Choose: \(u = \ln x\), \(dv = dx\)

Then: \(du = \frac{1}{x}dx\), \(v = x\)

Result: \(x\ln x - \int x \cdot \frac{1}{x} \, dx = x\ln x - x + C\)

Example 2.3 (Repeated Parts): Evaluate \(\int x^2 e^x \, dx\).

First: \(u = x^2\), \(dv = e^x \, dx\) → \(du = 2x \, dx\), \(v = e^x\)

= \(x^2 e^x - \int 2x e^x \, dx\)

For \(\int 2x e^x \, dx\): \(u = 2x\), \(dv = e^x \, dx\) → \(du = 2 \, dx\), \(v = e^x\)

= \(2x e^x - 2\int e^x \, dx = 2x e^x - 2e^x\)

Final result: \(x^2 e^x - 2x e^x + 2e^x + C = e^x(x^2 - 2x + 2) + C\)

3. Integration by Parts for Definite Integrals

Formula 3.1: $$\int_a^b u \, dv = [uv]_a^b - \int_a^b v \, du$$
Example 3.1: Evaluate \(\int_0^{\pi/2} x \sin x \, dx\).

Choose: \(u = x\), \(dv = \sin x \, dx\) → \(du = dx\), \(v = -\cos x\)

Result: \([ -x \cos x ]_0^{\pi/2} - \int_0^{\pi/2} (-\cos x) \, dx\)

= \([ -x \cos x ]_0^{\pi/2} + \int_0^{\pi/2} \cos x \, dx\)

= \(0 - 0 + [\sin x]_0^{\pi/2} = 1\)

4. Partial Fractions

4.1 Decomposition for Linear Factors

Theorem 4.1: If \(Q(x)\) has distinct linear factors: \(Q(x) = (x-a_1)(x-a_2)\cdots(x-a_n)\)

$$ \frac{P(x)}{Q(x)} = \frac{A_1}{x-a_1} + \frac{A_2}{x-a_2} + \cdots + \frac{A_n}{x-a_n} $$ where \(A_i = \frac{P(a_i)}{Q'(a_i)}\).
Example 4.1: Evaluate \(\int \frac{1}{x^2 - 1} \, dx\).

Factor: \(x^2 - 1 = (x-1)(x+1)\)

Decompose: \(\frac{1}{(x-1)(x+1)} = \frac{A}{x-1} + \frac{B}{x+1}\)

Clear denominators: \(1 = A(x+1) + B(x-1)\)

At \(x = 1\): \(1 = 2A\) → \(A = \frac{1}{2}\)

At \(x = -1\): \(1 = -2B\) → \(B = -\frac{1}{2}\)

Result: \(\int \frac{1}{2(x-1)} - \frac{1}{2(x+1)} \, dx = \frac{1}{2}\ln|x-1| - \frac{1}{2}\ln|x+1| + C\)

= \(\frac{1}{2}\ln\left|\frac{x-1}{x+1}\right| + C\)

4.2 Repeated Linear Factors

Theorem 4.2: For factor \((x-a)^n\): $$\frac{P(x)}{(x-a)^n} = \frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \cdots + \frac{A_n}{(x-a)^n}$$
Example 4.2: Evaluate \(\int \frac{x}{(x-1)^2} \, dx\).

Decompose: \(\frac{x}{(x-1)^2} = \frac{A}{x-1} + \frac{B}{(x-1)^2}\)

Clear: \(x = A(x-1) + B\)

At \(x = 1\): \(1 = B\)

Coefficient of \(x\): \(1 = A\)

Result: \(\int \frac{1}{x-1} + \frac{1}{(x-1)^2} \, dx = \ln|x-1| - \frac{1}{x-1} + C\)

4.3 Irreducible Quadratic Factors

Theorem 4.3: For irreducible quadratic \(x^2 + bx + c\): $$\frac{Ax + B}{x^2 + bx + c}$$ Complete the square and use substitution.
Example 4.3: Evaluate \(\int \frac{1}{x^2 + 4} \, dx\).

Complete square: \(x^2 + 4 = x^2 + 2^2\)

Let \(x = 2\tan\theta\), \(dx = 2\sec^2\theta \, d\theta\)

Result: \(\int \frac{2\sec^2\theta}{4\sec^2\theta} \, d\theta = \frac{1}{2}\theta + C = \frac{1}{2}\tan^{-1}\left(\frac{x}{2}\right) + C\)

5. Summary Table of Integration Techniques

Integrand Form Technique
\(f(g(x))g'(x)\) Substitution
\(u \cdot dv\) Integration by Parts
\(\frac{P(x)}{Q(x)}\) with \(\deg P < \deg Q\) Partial Fractions
\(x^n \cdot f(x)\) Integration by Parts (LIATE)
\(\frac{1}{x^2 + a^2}\) Trigonometric Substitution
