Solutions: Problem Set 9: Gaussian Primes and Factorization

Elementary Number Theory - Week 10 Solutions

Key Definitions and Concepts

Gaussian Prime Classification

In \(\mathbb{Z}[i]\), an element \(\pi\) is prime if:

  • \(\pi\) is a unit times a rational prime \(p\) where \(p \equiv 3 \pmod{4}\)
  • \(\pi = a + bi\) where \(a^2 + b^2 = p\) is a rational prime (so \(p \equiv 1 \pmod{4}\))
  • \(\pi = 1 + i\) (up to units) - the prime dividing 2

Solutions

Problem 1: Determine which Gaussian integers are prime among: 2, 3, 1+i, 2+i, 3+3i, 5.

Strategy: Check each using the classification.

2: \(2 = -i(1+i)^2\), so 2 is NOT prime (it ramifies).

But \(1 + i\) IS prime since \(N(1+i) = 2\) is prime.

3: 3 ≡ 3 (mod 4), so 3 remains prime in \(\mathbb{Z}[i]\).
1 + i: \(N(1+i) = 2\) (prime), so 1+i is prime.
2 + i: \(N(2+i) = 5\), and 5 ≡ 1 (mod 4), so 2+i is prime.
3 + 3i = 3(1 + i): Product of two primes, not prime.
5 = (2+i)(2-i): 5 factors, not prime.

Answer: The primes are: 3, 1+i, and 2+i.

Problem 2: Factor 13 in \(\mathbb{Z}[i]\).

Analysis: 13 ≡ 1 (mod 4), so 13 splits (factors) in \(\mathbb{Z}[i]\).

Find Gaussian integers with norm 13.

Solve \(a^2 + b^2 = 13\):

  • \(a = 2\): \(b^2 = 9\), so \(b = \pm 3\)
  • \(a = 3\): \(b^2 = 4\), so \(b = \pm 2\)
So ±(2+3i), ±(3+2i), ±(2-3i), ±(3-2i) have norm 13.

Verify a factorization.
\[(2 + 3i)(2 - 3i) = 4 + 9 = 13\]

Answer: \(13 = (2+3i)(2-3i) = (3+2i)(3-2i)\)

Problem 3: Find the greatest common divisor of 5 and 13 in \(\mathbb{Z}[i]\).

Strategy: Factor both and find common factors.

Factor 5 and 13:
5 = (2+i)(2-i)
13 = (2+3i)(2-3i)
Check if any Gaussian prime divides both.

We need to check if 2+i or 2-i divides 2+3i or 2-3i.

In \(\mathbb{Z}[i]\), primes are non-associated if they are not unit multiples.

2+i and 2+3i are not associates (their ratio is not a unit).

Therefore, gcd(5, 13) = 1.

Answer: \(\gcd(5, 13) = 1\) (they are coprime in \(\mathbb{Z}[i]\)).

Problem 4: Prove that \(\mathbb{Z}[i]\) is a unique factorization domain.

Proof outline:

Step 1: Show \(\mathbb{Z}[i]\) is a Euclidean domain.

Define the Euclidean function: \(\delta(a + bi) = N(a + bi) = a^2 + b^2\).

Given \(\alpha, \beta \in \mathbb{Z}[i]\) with \(\beta \neq 0\), find \(q, r\) such that \(\alpha = \beta q + r\) where \(r = 0\) or \(\delta(r) < \delta(\beta)\).

Step 2: Euclidean domains are UFDs.

This is a standard theorem: every Euclidean domain is a PID, and every PID is a UFD.

Problem 5: Use Gaussian integers to prove that a prime \(p\) can be written as \(x^2 + y^2\) iff \(p = 2\) or \(p \equiv 1 \pmod{4}\).

Proof:

(⇒) If \(p = x^2 + y^2\), then \(p = (x + yi)(x - yi)\):

If \(p\) were prime in \(\mathbb{Z}[i]\), it would be associate to a rational prime ≡ 3 (mod 4).

But \(x + yi\) is not a unit (unless \(p = 2\)) and not a rational prime.

Therefore \(p\) is not a Gaussian prime.

Checking: 2 = 1² + 1², and for \(p > 2\): \(p \equiv 1 \pmod{4}\) iff it splits.

(⇐) If \(p = 2\) or \(p \equiv 1 \pmod{4}\):

We've shown these primes factor in \(\mathbb{Z}[i]\): \(p = \pi \bar{\pi}\) for some prime \(\pi = a + bi\).
Then \(p = N(\pi) = a^2 + b^2\).

Bonus Solutions

Bonus Problem 1: Find the Gaussian primes that divide 65.
Factor 65: \(65 = 5 \times 13\).
5 = (2+i)(2-i)
13 = (2+3i)(2-3i)

Answer: The Gaussian primes dividing 65 are: 2+i, 2-i, 2+3i, 2-3i.

Bonus Problem 2: Solve \(xy = 39\) in \(\mathbb{Z}[i]\).
Factor 39 in \(\mathbb{Z}[i]\):

39 = 3 × 13
3 remains prime (≡ 3 mod 4)
13 = (2+3i)(2-3i)

Answer: Solutions are (up to units): 3·(2+3i) = 6+9i, etc.
