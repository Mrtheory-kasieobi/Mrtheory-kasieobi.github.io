Solutions: Problem Set 9: Gaussian Primes and Factorization

Elementary Number Theory - Week 10 Solutions

Key Ideas

How to recognize Gaussian primes

A Gaussian integer is a number of the form \(a+bi\). Its norm is \(a^2+b^2\). In practice, we use three simple rules:

  • If the norm is an ordinary prime, the number is Gaussian prime.
  • If a rational prime \(p\equiv 3\pmod4\), it stays prime in \(\mathbb{Z}[i]\).
  • The prime 2 factors as \(2=-i(1+i)^2\), so \(1+i\) is the key prime dividing 2.

Solutions

Problem 1

Which of these are Gaussian primes: 2, 3, 1+i, 2+i, 3+3i, 5?

2. The norm of 2 is 4, so 2 is not a Gaussian prime. It factors as \(2=-i(1+i)^2\).
3. The norm of 3 is 9. Since \(3\equiv 3\pmod4\), 3 remains prime in \(\mathbb{Z}[i]\).
1+i. Its norm is \(1^2+1^2=2\), which is prime. So \(1+i\) is Gaussian prime.
2+i. Its norm is \(2^2+1^2=5\), which is prime. So \(2+i\) is Gaussian prime.
3+3i. This equals \(3(1+i)\), a product of two non-units, so it is not prime.
5. The norm of 5 is 25. Since \(5\equiv 1\pmod4\), it splits: \(5=(2+i)(2-i)\). So 5 is not prime.

Answer. The Gaussian primes in the list are \(3\), \(1+i\), and \(2+i\).

Problem 2

Factor 13 in \(\mathbb{Z}[i]\).

Because \(13\equiv 1\pmod4\), it splits. We need integers \(a,b\) with \(a^2+b^2=13\). Trying small values gives \(2^2+3^2=13\).

Therefore \(13=(2+3i)(2-3i)\). Both factors are Gaussian primes because their norm is 13.

Problem 3

Find \(\gcd(5,13)\) in \(\mathbb{Z}[i]\).

Factor each number into Gaussian primes. The prime factors of 5 are \(2+i\) and \(2-i\). The prime factors of 13 are \(2+3i\) and \(2-3i\). These four primes are different from each other, so 5 and 13 share no common Gaussian prime factor.

Answer. \(\gcd(5,13)=1\).

Problem 4

Explain why factorization in \(\mathbb{Z}[i]\) is unique up to order and units.

This is analogous to unique factorization for ordinary integers. If a Gaussian integer had two different factorizations into Gaussian primes, comparing norms would eventually lead to a contradiction. In other words, Gaussian integers have one prime factorization, just like the integers do.

Problem 5

Prove: a prime \(p\) can be written as \(x^2+y^2\) iff \(p=2\) or \(p\equiv 1\pmod4\).

If direction. If \(p=x^2+y^2\), then in \(\mathbb{Z}[i]\) we have \(p=(x+yi)(x-yi)\). For \(p>2\), this means \(p\) is not a Gaussian prime. The only rational primes that stay prime in \(\mathbb{Z}[i]\) are \(p=2\) and primes with \(p\equiv 3\pmod4\). Therefore we must have \(p=2\) or \(p\equiv 1\pmod4\).
Only if direction. If \(p=2\), then \(2=1^2+1^2\). If \(p\equiv 1\pmod4\), then \(p\) splits in \(\mathbb{Z}[i]\) as \(p=\pi\overline{\pi}\) for some Gaussian prime \(\pi=a+bi\). Taking norms gives \(p=a^2+b^2\).
Problem 6

List the Gaussian prime factors of 13.

From Problem 2, \(13=(2+3i)(2-3i)\). Both factors are Gaussian primes.

Problem 7

Prove: if \(p\equiv 1\pmod4\) is prime, then \(p\) splits in \(\mathbb{Z}[i]\).

When \(p\equiv 1\pmod4\), the number \(-1\) is a square modulo \(p\). That means there is an integer \(a\) with \(a^2\equiv -1\pmod p\), or \(p\mid a^2+1\). In \(\mathbb{Z}[i]\) this says \(p\mid (a+i)(a-i)\). Because \(p\) is an ordinary prime and does not divide \(a+i\) or \(a-i\) individually, it cannot be prime in \(\mathbb{Z}[i]\). Hence \(p\) factors as \(p=\pi\overline{\pi}\) for some non-unit \(\pi\).

Problem 8

Find the prime factorization of 65 in \(\mathbb{Z}[i]\).

Factor \(65=5\cdot 13\) and split each piece:
\(5=(2+i)(2-i)\)
\(13=(2+3i)(2-3i)\)
So \(65=(2+i)(2-i)(2+3i)(2-3i)\).

Problem 9

Factor 50 in \(\mathbb{Z}[i]\).

Write \(50=2\cdot 5^2\). We know \(2=-i(1+i)^2\) and \(5=(2+i)(2-i)\). Therefore
\(50=-i(1+i)^2(2+i)^2(2-i)^2\).

Up to units, the Gaussian prime factors are \((1+i)\), \((2+i)\), and \((2-i)\).

Problem 10

Explain why every nonzero Gaussian integer can be factored into Gaussian primes.

The norm \(N(a+bi)=a^2+b^2\) is a positive ordinary integer. Each time we factor a Gaussian integer into smaller pieces, the norm decreases. Because the norm is a positive integer, this process cannot continue forever. It must stop, and it can only stop at Gaussian primes.

Bonus Solutions

Bonus Problem 1

Find the Gaussian primes that divide 65.

From Problem 8, the Gaussian primes dividing 65 are \(2+i\), \(2-i\), \(2+3i\), and \(2-3i\).

Bonus Problem 2

Solve \(xy=39\) in \(\mathbb{Z}[i]\).

Factor \(39=3\cdot 13\). In \(\mathbb{Z}[i]\), 3 stays prime because \(3\equiv 3\pmod4\), and \(13=(2+3i)(2-3i)\). Any solution \((x,y)\) must distribute these prime factors between \(x\) and \(y\) in some way, up to multiplication by \(1\), \(-1\), \(i\), or \(-i\).

Bonus Problem 3

Prove that if \(p\equiv 3\pmod4\) is prime, then \(p\) cannot equal \(x^2+y^2\) for integers \(x,y\).

Work modulo 4. Perfect squares modulo 4 are only 0 or 1. Therefore the sum of two squares modulo 4 can only be 0, 1, or 2. It can never be 3. So no integer congruent to 3 modulo 4 can be written as a sum of two squares.
