Problem Set 11: Diophantine Equations

Elementary Number Theory - Week 12 Medium

Problems

Problem 1

Find all integer solutions to \(15x + 25y = 5\).

Problem 2

Find all integer solutions to \(7x + 11y = 3\).

Problem 3

Show that \(x^2 + y^2 = 3z^2\) has no non-trivial integer solutions.

Problem 4

Find all primitive Pythagorean triples with hypotenuse 25.

Problem 5

Prove: If \((a, b, c)\) is a Pythagorean triple, then \(c\) is odd.

Problem 6

Show that if \(\gcd(a, b) = 1\) and \(a^2 + b^2 = c^2\), then \(c \equiv 1 \pmod{4}\).

Problem 7

Find the smallest positive integer \(y\) such that \(x^2 - 7y^2 = 1\) has a solution.

Problem 8

Prove: In any Pythagorean triple, at least one leg is divisible by 3.

Problem 9

Find all integer solutions to \(x^2 - 2y^2 = 1\) with \(y < 10\).

Problem 10

Show that the equation \(x^2 - 5y^2 = -4\) has an integer solution.

Bonus Problems

Bonus Problem 1

Challenge: Prove that every primitive Pythagorean triple has exactly one even leg.

Bonus Problem 2

Challenge: Find the fundamental solution to \(x^2 - 3y^2 = 1\) and generate the next three solutions.

Bonus Problem 3

Challenge: Show that there are infinitely many Pythagorean triples where the hypotenuse differs from a leg by 1.
