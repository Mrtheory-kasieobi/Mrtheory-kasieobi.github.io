Problem Set 3: Factors and Products

Mathematics 10 - Chapter 3 Solutions

Solutions

Problem 1: Find the prime factorization of \(120\) and use it to list all factors.
Find prime factors: \(120 = 2 \times 60 = 2 \times 2 \times 30 = 2 \times 2 \times 2 \times 15 = 2 \times 2 \times 2 \times 3 \times 5\)
Prime factorization: \(120 = 2^3 \times 3^1 \times 5^1\)
Number of factors: \((3+1)(1+1)(1+1) = 16\) total factors
List all factors: 1, 2, 3, 4, 5, 6, 8, 10, 12, 15, 20, 24, 30, 40, 60, 120
Answer: \(120 = 2^3 \times 3 \times 5\). All factors: 1, 2, 3, 4, 5, 6, 8, 10, 12, 15, 20, 24, 30, 40, 60, 120.
Problem 2: Factor completely: \(x^2 + 9x + 20\)
Find two numbers that multiply to 20 and add to 9: 4 and 5
Factor: \((x + 4)(x + 5)\)
Answer: \((x + 4)(x + 5)\)
Problem 3: Factor: \(2x^2 + 7x - 15\) (Use AC method)
AC = 2 × (-15) = -30. Find two numbers that multiply to -30 and add to 7: 10 and -3
Rewrite middle term: \(2x^2 + 10x - 3x - 15\)
Factor by grouping: \(2x(x + 5) - 3(x + 5)\)
Answer: \((2x - 3)(x + 5)\)
Problem 4: Factor: \(9x^2 - 16y^2\)
Recognize difference of squares: \(a^2 - b^2 = (a - b)(a + b)\)
Here: \(a = 3x\) and \(b = 4y\)
Factor: \((3x - 4y)(3x + 4y)\)
Answer: \((3x - 4y)(3x + 4y)\)
Problem 5: Factor: \(x^2 - 10x + 25\)
Recognize perfect square trinomial: \(a^2 - 2ab + b^2 = (a - b)^2\)
Here: \(a = x\) and \(b = 5\) (since \(2ab = 2 \times x \times 5 = 10x\) and \(b^2 = 25\))
Answer: \((x - 5)^2\)
Problem 6: Factor: \(3x^3 - 12x\)
Factor out GCF: GCF = 3x
Factor: \(3x(x^2 - 4)\)
Recognize difference of squares: \(x^2 - 4 = (x - 2)(x + 2)\)
Answer: \(3x(x - 2)(x + 2)\)
Problem 7: Solve: \(x^2 + 7x + 12 = 0\) by factoring
Factor: Find two numbers that multiply to 12 and add to 7: 3 and 4
Factor: \((x + 3)(x + 4) = 0\)
Set each factor to zero: \(x + 3 = 0\) or \(x + 4 = 0\)
Answer: \(x = -3\) or \(x = -4\)
Problem 8: Factor: \(\frac{1}{2}x^2 + \frac{3}{4}x + \frac{1}{8}\)
Multiply by LCD (8): \(8 \times \frac{1}{2}x^2 = 4x^2\), \(8 \times \frac{3}{4}x = 6x\), \(8 \times \frac{1}{8} = 1\)
Factor \(4x^2 + 6x + 1\): find two numbers that multiply to 4 and add to 3: 2 and 2
Actually find numbers that multiply to 4 and add to 3: use AC method with 4×1 = 4
Rewrite: \(4x^2 + 2x + 4x + 1 = 2x(2x + 1) + 1(2x + 1) = (2x + 1)(2x + 1)\)
Since we multiplied by 8, divide by 8: \(\frac{(2x + 1)^2}{8} = \frac{(2x + 1)(2x + 1)}{8}\)
Alternatively: \(\frac{1}{8}(2x + 1)^2\)
Answer: \(\frac{1}{8}(2x + 1)^2\) or \(\frac{(2x+1)^2}{8}\)

Bonus Solutions

Bonus Problem 1: Factor Frenzy
Factor \(x^4 - 16\): difference of squares twice
\(x^4 - 16 = (x^2 - 4)(x^2 + 4) = (x - 2)(x + 2)(x^2 + 4)\)
For integer dimensions, we need integer factors
If \(x\) is even, say \(x = 2k\), then \(x - 2 = 2k - 2 = 2(k - 1)\), \(x + 2 = 2k + 2 = 2(k + 1)\)
Both are even, giving integer dimensions
When \(x = 6\): factors are \(4, 8, 40\)
Possible dimensions: 4 × 40, 8 × 20
Answer: \((x-2)(x+2)(x^2+4)\). Integer dimensions when x is even. When x=6: 4×40 or 8×20.
Bonus Problem 2: Perfect Square Chain
Consecutive squares: \(k^2\) and \((k+1)^2\)
Gap between them: \((k+1)^2 - k^2 = 2k + 1\)
For three consecutive integers n, n+1, n+2 to all be perfect squares, we need gaps of 1 between each
But minimum gap is 3 (between 1 and 4), and gaps only increase
Therefore, no such integer exists
Answer: No such integer exists. Gaps between consecutive squares are 3, 5, 7, ... all odd and ≥3.
Bonus Problem 3: Triangle Puzzle
Let shorter leg = x, longer leg = x + 3
Area = \(\frac{1}{2} \times x \times (x + 3) = 54 + x^2\)
So: \(\frac{x(x + 3)}{2} = x^2 + 54\)
Multiply by 2: \(x^2 + 3x = 2x^2 + 108\)
Rearrange: \(x^2 - 3x + 108 = 0\)
Discriminant: 9 - 432 < 0, no real solutions
Re-read: area is 54 more than square of shorter leg
So: \(\frac{x(x+3)}{2} = x^2 + 54\)
\(x^2 + 3x = 2x^2 + 108\)
\(x^2 - 3x + 108 = 0\) - still no real solutions
Perhaps: area = 54, and area = shorter leg² + 54?
Or: shorter leg² = area + 54? Let's try: \(x^2 = \frac{x(x+3)}{2} + 54\)
\(2x^2 = x^2 + 3x + 108\)
\(x^2 - 3x - 108 = 0\)
Factor: \((x - 12)(x + 9) = 0\)
So \(x = 12\)
Legs: 12 cm and 15 cm
Hypotenuse: \(\sqrt{144 + 225} = \sqrt{369} = 3\sqrt{41}\) cm
Answer: Shorter leg = 12 cm, longer leg = 15 cm, hypotenuse = \(3\sqrt{41}\) cm.
