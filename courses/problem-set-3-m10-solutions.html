Mathematics 10 - Chapter 3

Solutions

Solution 1

\(120 = 2^3 \times 3 \times 5\)

Factors: 1, 2, 3, 4, 5, 6, 8, 10, 12, 15, 20, 24, 30, 40, 60, 120

Solution 2

\(x^2 + 9x + 20 = (x + 4)(x + 5)\)

Check: \(4 \times 5 = 20\) and \(4 + 5 = 9\) ✓

Solution 3

Find numbers: \(5\) and \(-6\) (since \(5 \times -6 = -30\) and \(5 + (-6) = -1\))

Wait, we need sum \(7\). Try \(-5\) and \(6\): \(-5 \times 6 = -30\), \(-5 + 6 = 1\). Try \(10\) and \(-3\): \(10 \times -3 = -30\), \(10 + (-3) = 7\) ✓

\(2x^2 + 10x - 3x - 15 = 2x(x + 5) - 3(x + 5) = (2x - 3)(x + 5)\)

Solution 4

\(9x^2 - 16y^2 = (3x)^2 - (4y)^2 = (3x - 4y)(3x + 4y)\)

Solution 5

\(x^2 - 10x + 25 = (x - 5)^2\)

Check: \((x - 5)^2 = x^2 - 10x + 25\) ✓

Solution 6

\(3x^3 - 12x = 3x(x^2 - 4) = 3x(x - 2)(x + 2)\)

Solution 7

\(x^2 + 7x + 12 = (x + 3)(x + 4) = 0\)

\(x = -3\) or \(x = -4\)

Solution 8

Multiply by 8: \(4x^2 + 6x + 1\)

Factor: \((2x + 1)(2x + 1) = (2x + 1)^2\)

Divide by 8: \(\frac{1}{8}(2x + 1)^2\)

Bonus Problem Solutions

Bonus Solution 1

Step 1: Factor the area expression to find the width

\(x^2 + 12x + 35 = (x + 7)(x + 5)\)

Since length \(= (x + 7)\), the width \(= (x + 5)\) m

Step 2: Find the perimeter in terms of \(x\)

Perimeter \(= 2(\text{length} + \text{width}) = 2((x + 7) + (x + 5)) = 2(2x + 12) = 4x + 24\) m

Step 3: Substitute \(x = 5\)

Length \(= 5 + 7 = 12\) m

Width \(= 5 + 5 = 10\) m

Perimeter \(= 4(5) + 24 = 20 + 24 = 44\) m

Answer: When \(x = 5\), the garden is \(12\) m × \(10\) m with perimeter \(44\) m.

Bonus Solution 2

Step 1: Set up the equation for special numbers

We need \(k(k+1)\) where \(100 \leq k(k+1) \leq 200\)

Step 2: Estimate the range for \(k\)

If \(k^2 \approx 100\), then \(k \approx 10\)

If \(k^2 \approx 200\), then \(k \approx 14\)

Step 3: Test values of \(k\) from 10 to 14

\(k = 10: 10 \times 11 = 110\) ✓

\(k = 11: 11 \times 12 = 132\) ✓

\(k = 12: 12 \times 13 = 156\) ✓

\(k = 13: 13 \times 14 = 182\) ✓

\(k = 14: 14 \times 15 = 210\) ✗ (too large)

Answer: The special numbers between 100 and 200 are: \(110, 132, 156, 182\).

Bonus Solution 3

Step 1: Use the area formula to find \(x\)

Area \(= \frac{1}{2} \times x \times (x + 5) = 150\)

\(x(x + 5) = 300\)

\(x^2 + 5x = 300\)

Step 2: Rearrange and factor

\(x^2 + 5x - 300 = 0\)

We need two numbers that multiply to \(-300\) and add to \(5\).

Try \(20\) and \(-15\): \(20 \times (-15) = -300\) and \(20 + (-15) = 5\) ✓

\((x + 20)(x - 15) = 0\)

So \(x = -20\) or \(x = 15\). Since length must be positive, \(x = 15\).

Step 3: Find the leg lengths

Leg 1: \(x = 15\) cm

Leg 2: \(x + 5 = 20\) cm

Step 4: Find the hypotenuse

\(c = \sqrt{15^2 + 20^2} = \sqrt{225 + 400} = \sqrt{625} = 25\) cm

Answer: \(x = 15\), legs are \(15\) cm and \(20\) cm, hypotenuse \(= 25\) cm (a 3-4-5 scaled triangle).
