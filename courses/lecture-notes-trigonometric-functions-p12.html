Trigonometric Functions and Graphs

Precalculus 12 - Lecture Notes
British Columbia Curriculum | Last Updated: 2026

1. Graphing Sine and Cosine Functions

1.1 Why Sinusoidal Functions Matter

Sinusoidal functions model periodic phenomena - anything that repeats at regular intervals. From the oscillation of springs to the alternating current in electrical systems, sine and cosine functions are fundamental to understanding waves and cycles in nature and technology.

Real-World Applications:

Sinusoidal functions model sound waves, light waves, tides, seasonal temperature variations, heartbeats, and the motion of pendulums. Understanding these functions is essential for physics, engineering, and signal processing.

1.2 General Forms of Sinusoidal Functions

The general forms of sinusoidal functions are:

General Sine Function:
\[f(x) = a\sin(bx - c) + d\]

General Cosine Function:
\[f(x) = a\cos(bx - c) + d\]

1.3 Key Parameters and Their Meaning

  • Amplitude (\(|a|\)): The maximum displacement from the midline. This represents the peak value in applications like sound volume or wave height.
  • Period (\(\frac{2\pi}{|b|}\)): The length of one complete cycle. This tells us how long it takes for the pattern to repeat.
  • Phase Shift (\(\frac{c}{b}\)): Horizontal shift (right if positive). This represents a time delay or advance in wave phenomena.
  • Vertical Shift (\(d\)): Shifts the midline up or down. This represents the average value in applications.
Example 1: Analyzing a Sine Function

Analyze \(f(x) = 3\sin(2x - \pi) + 1\).

Amplitude: \(|3| = 3\) (the wave oscillates 3 units above and below the midline)

Period: \(\frac{2\pi}{2} = \pi\) (one complete cycle every \(\pi\) units)

Phase shift: \(\frac{\pi}{2}\) (shift right by \(\frac{\pi}{2}\))

Vertical shift: 1 (midline at \(y = 1\))

Motivation: This function could model a sound wave with amplitude 3, period \(\pi\) seconds, starting \(\frac{\pi}{2}\) seconds late, and average value 1.

2. Transformations of Sinusoidal Functions

2.1 Step-by-Step Graphing Process

To graph a transformed sinusoidal function, we follow a systematic approach that helps us understand how each parameter affects the graph:

Graphing Strategy:
  1. Identify the amplitude, period, phase shift, and vertical shift
  2. Draw the midline (horizontal line at \(y = d\))
  3. Mark the maximum and minimum lines at \(d \pm |a|\)
  4. Divide the period into four equal parts to find key points
  5. Apply the phase shift to all x-coordinates
  6. Plot the key points and sketch the smooth curve
Example 2: Graphing a Transformed Cosine

Graph \(f(x) = 2\cos(\frac{1}{2}x) - 1\) for one period.

Amplitude: 2, Period: \(4\pi\), Phase shift: 0, Vertical shift: -1

Midline: \(y = -1\), Max: \(y = 1\), Min: \(y = -3\)

Key points for one period: \(x = 0, \pi, 2\pi, 3\pi, 4\pi\)

Corresponding y-values: \(1, 0, -3, 0, 1\)

Motivation: This slow oscillation (period \(4\pi\)) could model seasonal temperature variations with a 2°C variation around an average of -1°C.

2.2 Understanding Phase Shift

Phase shift represents a horizontal translation. For \(f(x) = a\sin(bx - c) + d\), the phase shift is \(\frac{c}{b}\). This is crucial in applications involving wave interference and signal timing.

Example 3: Phase Shift Interpretation

Two sound waves are modeled by \(f_1(x) = \sin(x)\) and \(f_2(x) = \sin(x - \frac{\pi}{2})\). How do they differ?

\(f_2(x)\) is shifted \(\frac{\pi}{2}\) units to the right compared to \(f_1(x)\). This represents a time delay in the sound wave.

Motivation: Phase differences between waves create interference patterns, which are fundamental to acoustics and optics.

3. The Tangent Function

3.1 Why Study Tangent?

The tangent function completes a full cycle in \(\pi\) instead of \(2\pi\), making it useful for modeling phenomena with shorter periods. It's also essential for understanding slopes and angles in calculus.

3.2 Properties of Tangent

The tangent function has the form \(f(x) = \tan x = \frac{\sin x}{\cos x}\). It has vertical asymptotes where \(\cos x = 0\).

Key Properties of Tangent:
  • Period: \(\pi\) (shorter than sine/cosine)
  • Vertical asymptotes at \(x = \frac{\pi}{2} + \pi n\)
  • Passes through origin with slope 1
  • Range: all real numbers
  • Odd function: \(\tan(-x) = -\tan(x)\)
Transformed Tangent:
\[f(x) = a\tan(bx - c) + d\]
Example 4: Tangent Function Analysis

Analyze \(f(x) = 2\tan(3x) + 1\).

Period: \(\frac{\pi}{3}\), Asymptotes at \(x = \frac{\pi}{6} + \frac{\pi}{3}n\)

Midline: \(y = 1\), Vertical stretch by factor 2

Motivation: The tangent function models the relationship between angle and slope in trigonometry, which is essential for understanding derivatives.

4. Equations and Graphs of Trigonometric Functions

4.1 Finding the Equation from a Graph

To find the equation of a sinusoidal function from its graph, we need to identify the key parameters. This reverse process helps us model real-world data.

Example 5: Finding Equation from Graph

A cosine function has maximum at \((0, 3)\), minimum at \((\pi, -1)\), and period \(2\pi\).

Amplitude: \(\frac{3 - (-1)}{2} = 2\)

Midline: \(\frac{3 + (-1)}{2} = 1\)

Vertical shift: 1

Equation: \(f(x) = 2\cos(x) + 1\)

Motivation: This process is used in data analysis to find mathematical models for periodic phenomena like tides or seasonal sales.

4.2 Solving Trigonometric Equations

To solve equations like \(a\sin(bx + c) = d\), we isolate the trigonometric function and find all solutions. This is essential for finding when periodic phenomena reach specific values.

Example 6: Solving Trigonometric Equations

Solve \(2\sin(x) + 1 = 0\) for \(x \in [0, 2\pi)\).

\(\sin(x) = -\frac{1}{2}\)

\(x = \frac{7\pi}{6}, \frac{11\pi}{6}\)

Motivation: This tells us when a pendulum reaches a specific height below its equilibrium position.

5. Applications of Sinusoidal Functions

5.1 Simple Harmonic Motion

Sinusoidal functions model simple harmonic motion, where a restoring force is proportional to displacement. This is fundamental to understanding springs, pendulums, and waves.

Example 7: Simple Harmonic Motion

A mass on a spring oscillates with position \(x(t) = 0.1\cos(8\pi t)\) where \(t\) is in seconds. Find the amplitude, period, and frequency.

Amplitude: 0.1 m, Period: \(\frac{2\pi}{8\pi} = \frac{1}{4}\) s, Frequency: 4 Hz

Motivation: This models the motion of a guitar string or a car's suspension system.

5.2 Temperature Modeling

Temperature variations throughout the year can be modeled using sinusoidal functions. The phase shift tells us about seasonal timing.

Example 8: Temperature Model

Temperature in Vancouver is modeled by \(T(d) = 8\sin(\frac{2\pi}{365}d) + 10\) where \(d\) is the day of the year. Find the maximum and minimum temperatures.

Maximum: \(10 + 8 = 18°C\), Minimum: \(10 - 8 = 2°C\)

Motivation: This helps us understand climate patterns and design heating/cooling systems.

6. Practice Problems

Problem 1

Find the amplitude, period, and phase shift of \(f(x) = 4\cos(\frac{1}{3}x + \frac{\pi}{2})\). What is the midline?

Problem 2

Graph one period of \(f(x) = -2\sin(\frac{2\pi}{3}x) + 3\). Label the key points and asymptotes.

Problem 3

Solve \(\cos(2x) = \frac{1}{2}\) for \(x \in [0, 2\pi)\). Give the general solution.

Problem 4

A Ferris wheel has radius 20m and completes one revolution every 4 minutes. If you board at the bottom, find a sinusoidal function for your height above ground after \(t\) minutes.
