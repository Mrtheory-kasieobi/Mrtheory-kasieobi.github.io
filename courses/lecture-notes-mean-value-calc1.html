Mean Value Theorem and Curve Sketching

Calculus I - Week 8

1. The Mean Value Theorem

1.1 Statement and Interpretation

Mean Value Theorem (MVT): If \(f\) is continuous on \([a,b]\) and differentiable on \((a,b)\), then there exists at least one number \(c\) in \((a,b)\) such that: $$f'(c) = \frac{f(b) - f(a)}{b - a}$$

Geometrically, this means there is at least one point where the tangent line is parallel to the secant line through \((a, f(a))\) and \((b, f(b))\).

1.2 Proof of the Mean Value Theorem

Proof using Rolle's Theorem: Define \(g(x) = f(x) - \left[f(a) + \frac{f(b)-f(a)}{b-a}(x-a)\right]\) This is the vertical difference between \(f(x)\) and the secant line. Check conditions for Rolle's Theorem:
  • \(g\) is continuous on \([a,b]\) (difference of continuous functions)
  • \(g\) is differentiable on \((a,b)\)
  • \(g(a) = f(a) - f(a) = 0\) and \(g(b) = f(b) - f(b) = 0\)
By Rolle's Theorem, there exists \(c \in (a,b)\) with \(g'(c) = 0\). Compute: \(g'(x) = f'(x) - \frac{f(b)-f(a)}{b-a}\) Therefore: \(g'(c) = 0 \Rightarrow f'(c) = \frac{f(b)-f(a)}{b-a}\) ∎

1.3 Rolle's Theorem

Rolle's Theorem: If \(f\) is continuous on \([a,b]\), differentiable on \((a,b)\), and \(f(a) = f(b)\), then there exists \(c \in (a,b)\) such that \(f'(c) = 0\).
Example 1.1: Verify the MVT for \(f(x) = x^2\) on \([1, 3]\).

Check: \(f\) is continuous and differentiable everywhere.

MVT condition: \(f'(c) = \frac{f(3)-f(1)}{3-1} = \frac{9-1}{2} = 4\)

But \(f'(x) = 2x\), so \(2c = 4 \Rightarrow c = 2 \in (1,3)\) ✓

2. Curve Sketching

2.1 First Derivative Test

First Derivative Test: Let \(f\) be continuous at \(c\) and differentiable on both sides of \(c\).
  • If \(f'\) changes from \(+\) to \(-\) at \(c\), then \(f\) has a local maximum at \(c\)
  • If \(f'\) changes from \(-\) to \(+\) at \(c\), then \(f\) has a local minimum at \(c\)
  • If \(f'\) does not change sign at \(c\), then \(f\) has no local extremum at \(c\)

2.2 Second Derivative Test

Second Derivative Test: Suppose \(f''(c)\) exists and \(f'(c) = 0\).
  • If \(f''(c) > 0\), then \(f\) has a local minimum at \(c\)
  • If \(f''(c) < 0\), then \(f\) has a local maximum at \(c\)
  • If \(f''(c) = 0\), the test is inconclusive

2.3 Concavity and Inflection Points

Definition 2.1 (Concavity):
  • If \(f''(x) > 0\) on an interval, then \(f\) is concave upward on that interval
  • If \(f''(x) < 0\) on an interval, then \(f\) is concave downward on that interval
Inflection Point: A point \((c, f(c))\) where \(f\) changes concavity.
Example 2.1: Sketch the curve \(f(x) = x^3 - 3x^2 + 4\).

Step 1: Domain and Intercepts - Domain: all reals. y-intercept: \(f(0) = 4\). x-intercepts: solve \(x^3 - 3x^2 + 4 = 0\) → \((-1, 0), (2, 0)\) (double)

Step 2: First Derivative \(f'(x) = 3x^2 - 6x = 3x(x-2)\)

Critical points: \(x = 0, 2\).

Sign chart: \(f'\) + on \((-\infty,0)\), - on \((0,2)\), + on \((2,\infty)\)

Local max at \(x = 0\): \(f(0) = 4\). Local min at \(x = 2\): \(f(2) = 0\).

Step 3: Second Derivative \(f''(x) = 6x - 6 = 6(x-1)\)

Inflection point at \(x = 1\): \(f(1) = 2\).

Concave down on \((-\infty, 1)\), concave up on \((1, \infty)\).

3. Asymptotes

3.1 Vertical Asymptotes

Vertical asymptotes occur where \(\lim_{x \to a} f(x) = \pm\infty\).

3.2 Horizontal Asymptotes

Horizontal asymptotes are horizontal lines \(y = L\) where \(\lim_{x \to \pm\infty} f(x) = L\).

Example 3.1: Find asymptotes of \(f(x) = \frac{2x^2 + 3}{x - 1}\)

Vertical: Denominator zero at \(x = 1\). \(\lim_{x \to 1^+} f(x) = +\infty\), so \(x = 1\) is vertical asymptote.

Horizontal: Degree of numerator (2) > degree of denominator (1). No horizontal asymptote.

Oblique: Polynomial division: \(f(x) = 2x + 2 + \frac{4}{x-1}\). Oblique asymptote \(y = 2x + 2\).
