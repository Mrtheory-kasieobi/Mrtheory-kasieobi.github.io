Introduction to Proofs

Level: Undergraduate Status: Near Complete Last Updated: 2026

Course Information

  • Level Undergraduate, first- and second-year
  • Estimated Duration 12 weeks (one lecture and problem set per week)
  • Prerequisites High-school algebra; Calculus I is recommended but not required
  • Recommended Textbooks How to Prove It by Daniel Velleman; Book of Proof by Richard Hammack
  • Software None required; MathJax renders the formulas in the browser

Course Description

This is a self-contained introduction to the language and practice of mathematical proof. The course begins with propositional and predicate logic, where we learn exactly what a statement asserts and how it is negated. It then develops naive set theory, relations, and functions, which supply the vocabulary used throughout advanced mathematics. The middle of the course is devoted to the core proof techniques: direct proof, contrapositive, contradiction, proof by cases, ordinary and strong induction, and the well-ordering principle. These methods are applied to divisibility, congruences, combinatorial identities, and infinite sets. The final week consolidates proof writing with a workshop on strategy, counterexamples, and proof auditing.

Every lecture note states definitions carefully, proves the main results, works through beginner-friendly examples, and identifies common errors. Each lecture has a corresponding problem set with complete worked solutions and a solved bonus problem. Two practice tests with automatic grading, full solutions, and scored bonus problems are provided at the end of the course.

Learning Outcomes

On completing this course, a student should be able to:

  • translate mathematical sentences into logical notation and negate them correctly;
  • prove set identities and reason about relations, equivalence classes, and functions;
  • choose and execute an appropriate proof strategy for an implication, biconditional, existence claim, or uniqueness claim;
  • write correct induction proofs, including strong induction and minimal-counterexample arguments;
  • apply proof techniques to divisibility, modular arithmetic, counting identities, and cardinality;
  • critique a proof, locate logical gaps, and construct counterexamples to false statements.
