Problem Set 7 Solutions

Rational Expressions, Operations, Extraneous Roots | Precalculus 11

Solutions

Problem 1

Solution:

Factor all polynomials:

\[x^2 - 9 = (x-3)(x+3)\]

\[x^2 + 6x + 9 = (x+3)^2\]

\[x^2 + 3x = x(x+3)\]

Multiply:

\[\frac{(x-3)(x+3)}{(x+3)^2} \cdot \frac{x(x+3)}{x-3} = \frac{\cancel{(x-3)}\cancel{(x+3)}}{(x+3)} \cdot \frac{x\cancel{(x+3)}}{\cancel{(x-3)}} = x\]

Non-permissible values: \(x \neq -3, 3\)

Problem 2

Solution:

Factor denominator: \(x^2 - x - 2 = (x+1)(x-2)\)

Multiply both sides by \((x+1)(x-2)\):

\[2(x-2) + 3(x+1) = 5\]

\[2x - 4 + 3x + 3 = 5\]

\[5x - 1 = 5\]

\[x = \frac{6}{5}\]

Check: \(x \neq -1, 2\). Solution \(x = \frac{6}{5}\) is valid.

Problem 3

Solution:

Change division to multiplication:

\[\frac{x^3 - 8}{x^2 + 2x + 4} \times \frac{x^2 - 4}{x - 2}\]

Factor: \(x^3 - 8 = (x-2)(x^2+2x+4)\) and \(x^2 - 4 = (x-2)(x+2)\)

\[\frac{(x-2)(x^2+2x+4)}{x^2 + 2x + 4} \times \frac{(x-2)(x+2)}{x - 2}\]

Cancel common factors:

\[(x-2)(x+2) = x^2 - 4\]

Problem 4

Solution:

Cross multiply:

\[x(x+1) = (x+2)(x-3)\]

\[x^2 + x = x^2 - x - 6\]

\[2x = -6\]

\[x = -3\]

Check: \(x \neq 3\). Solution \(x = -3\) is valid.

Problem 5

Solution:

LCD is \((x+2)(x-1)\):

\[\frac{3(x-1) - 2(x+2) + 1}{(x+2)(x-1)} = \frac{3x - 3 - 2x - 4 + 1}{(x+2)(x-1)}\]

\[= \frac{x - 6}{(x+2)(x-1)}\]

Domain: \(x \neq -2, 1\)

Problem 6

Solution:

Divide by multiplying by reciprocal:

\[\frac{x^2 + 5x + 6}{x^2 - x - 6} \times \frac{x^2 - 4}{x^2 + 4x + 4}\]

Factor:

\[(x+2)(x+3) \quad (x-3)(x+1)\] \[(x-2)(x+2) \quad (x+2)^2\]

\[\frac{(x+2)(x+3)}{(x-3)(x+1)} \times \frac{(x-2)(x+2)}{(x+2)^2} = \frac{(x+3)(x+2)(x-2)}{(x-3)(x+1)(x+2)}\]

Cancel \((x+2)\):

\[\frac{(x+3)(x-2)}{(x-3)(x+1)}\]

Restrictions: \(x \neq -2, 3, -1, 2\)

Problem 7

Solution:

Multiply by \((x^2-16) = (x-4)(x+4)\):

\[(3x+2)(x+4) - (2x-1)(x-4) = 5\]

\[3x^2 + 14x + 8 - 2x^2 + 9x - 4 = 5\]

\[x^2 + 23x - 1 = 5\]

\[x^2 + 23x - 6 = 0\]

Using quadratic formula: \(x = \frac{-23 \pm \sqrt{529+24}}{2} = \frac{-23 \pm \sqrt{553}}{2}\)

Check: \(x \neq 4, -4\). Both solutions are valid.

Problem 8

Solution:

Multiply by \((x-2)\):

\[x + 3 = \frac{2(x-2)}{3} + 1\]

\[3(x+3) = 2(x-2) + 3\]

\[3x + 9 = 2x - 4 + 3\]

\[x = -8\]

Check: \(x \neq 2\). Solution \(x = -8\) is valid.

Problem 9

Solution:

Factor numerator: \(x^4 - 1 = (x^2 - 1)(x^2 + 1)\)

\[\frac{(x^2 - 1)(x^2 + 1)}{x^2 - 1} = x^2 + 1\]

Restrictions: \(x \neq \pm 1\)

Problem 10

Solution:

Multiply by \((x^2-9) = (x-3)(x+3)\):

\[2(x-3) - (x+3) = 6\]

\[2x - 6 - x - 3 = 6\]

\[x = 15\]

Verify: \(x = 15\) satisfies original equation.
