Solutions: Problem Set 7

Rational Expressions - Precalculus 11
Solution 1
Problem: Simplify: \(\frac{x^2 - 9}{x^2 + 6x + 9}\)
Factor numerator: \(x^2 - 9 = (x-3)(x+3)\)
Factor denominator: \(x^2 + 6x + 9 = (x+3)^2\)
Simplify: \(\frac{(x-3)(x+3)}{(x+3)^2} = \frac{x-3}{x+3}\), \(x \neq -3\)
Answer: \(\boxed{\frac{x-3}{x+3}}\)
Solution 2
Problem: Simplify: \(\frac{2x^2 + 8x}{x^2 - 4}\)
Factor numerator: \(2x^2 + 8x = 2x(x+4)\)
Factor denominator: \(x^2 - 4 = (x-2)(x+2)\)
Simplify: \(\frac{2x(x+4)}{(x-2)(x+2)}\), \(x \neq \pm 2\)
Answer: \(\boxed{\frac{2x(x+4)}{(x-2)(x+2)}}\)
Solution 3
Problem: Multiply: \(\frac{x^2 - 4}{x + 2} \cdot \frac{x + 2}{x^2 + 4x + 4}\)
Factor: \(\frac{(x-2)(x+2)}{x + 2} \cdot \frac{x + 2}{(x+2)^2}\)
Multiply: \(\frac{(x-2)(x+2)(x+2)}{(x+2)(x+2)^2}\)
Cancel: \(\frac{x-2}{x+1}\), \(x \neq -2\)
Answer: \(\boxed{\frac{x-2}{x+1}}\)
Solution 4
Problem: Divide: \(\frac{x^2 - x - 6}{\frac{x + 3}{x - 2}}\)
Multiply by reciprocal: \(\frac{x^2 - x - 6}{1} \cdot \frac{x - 2}{x + 3}\)
Factor numerator: \(\frac{(x-3)(x+2)(x-2)}{x+3}\)
Answer: \(\boxed{(x-3)(x-2)}\) where \(x \neq 1, -3\)
Solution 5
Problem: Find the sum: \(\frac{3}{x} + \frac{5}{2x}\)
Common denominator is \(2x\)
\(\frac{3}{x} = \frac{6}{2x}\)
Add: \(\frac{6}{2x} + \frac{5}{2x} = \frac{11}{2x}\)
Answer: \(\boxed{\frac{11}{2x}}\)
Solution 6
Problem: Find the sum: \(\frac{2}{x+1} + \frac{3}{x-1}\)
Common denominator: \((x+1)(x-1) = x^2 - 1\)
\(\frac{2(x-1)}{(x+1)(x-1)} + \frac{3(x+1)}{(x+1)(x-1)}\)
Combine: \(\frac{2x - 2 + 3x + 3}{x^2 - 1} = \frac{5x + 1}{x^2 - 1}\)
Answer: \(\boxed{\frac{5x + 1}{x^2 - 1}}\)
Solution 7
Problem: Solve: \(\frac{2}{x-3} = \frac{5}{x+2}\)
Cross multiply: \(2(x+2) = 5(x-3)\)
Expand: \(2x + 4 = 5x - 15\)
Solve: \(-3x = -19\), so \(x = \frac{19}{3}\)
Check: denominators ≠ 0 ✓
Answer: \(\boxed{x = \frac{19}{3}}\)
Solution 8
Problem: Solve: \(\frac{3}{x+4} + \frac{2}{x-1} = 1\)
Common denominator: \((x+4)(x-1)\)
\(\frac{3(x-1) + 2(x+4)}{(x+4)(x-1)} = 1\)
Numerator: \(3x - 3 + 2x + 8 = 5x + 5\)
Equation: \(\frac{5x + 5}{x^2 + 3x - 4} = 1\)
Cross multiply: \(5x + 5 = x^2 + 3x - 4\)
Rearrange: \(x^2 - 2x - 9 = 0\)
Quadratic formula: \(x = \frac{2 \pm \sqrt{4 + 36}}{2} = \frac{2 \pm \sqrt{40}}{2} = 1 \pm \sqrt{10}\)
Answer: \(\boxed{x = 1 + \sqrt{10}, 1 - \sqrt{10}}\)

Bonus Solutions

Bonus Solution 1
Problem: Simplify: \(\frac{x^2 + x - 2}{x^2 - 1} + \frac{x - 1}{x + 1}\). Hence, if \(x \neq \pm 1\), find the value of \(\frac{x^2 - 1}{x^2 + x - 2} + \frac{x + 1}{x - 1}\)
First part: Factor fractions
\(\frac{(x+2)(x-1)}{(x-1)(x+1)} + \frac{x-1}{x+1} = \frac{x+2}{x+1} + \frac{x-1}{x+1}\)
Add: \(\frac{2x + 1}{x + 1}\)
Second part (reciprocal sum): \(\frac{x^2-1}{x^2+x-2} + \frac{x+1}{x-1}\)
Note: \(\frac{x^2-1}{x^2+x-2} = \frac{(x-1)(x+1)}{(x+2)(x-1)} = \frac{x+1}{x+2}\)
Second expression: \(\frac{x+1}{x+2} + \frac{x+1}{x-1} = (x+1)\left(\frac{1}{x+2} + \frac{1}{x-1}\right)\)
\((x+1)\cdot\frac{2x-1}{x^2+x-2}\)
Answer: \(\boxed{\frac{(x+1)(2x-1)}{(x+2)(x-1)}}\)
Bonus Solution 2
Problem: Solve: \(\frac{x}{x+2} + \frac{x+4}{x-1} = 2\). Then solve \(\frac{1}{y-1} + \frac{1}{y+1} = \frac{3}{2}\) using an appropriate substitution.
First equation: Multiply by \((x+2)(x-1)\)
\(x(x-1) + (x+4)(x+2) = 2(x+2)(x-1)\)
Expand: \(x^2 - x + x^2 + 6x + 8 = 2x^2 + 2x - 4\)
Simplify: \(5x + 8 = 2x - 4\)
\(3x = -12\), so \(x = -4\)
For second equation: Use substitution \(y = z + 1\) or note symmetry
\(\frac{2y}{y^2-1} = \frac{3}{2}\)
Cross multiply: \(4y = 3(y^2 - 1)\)
\(3y^2 - 4y - 3 = 0\)
\(y = \frac{4 \pm \sqrt{16 + 36}}{6} = \frac{4 \pm \sqrt{52}}{6} = \frac{2 \pm \sqrt{13}}{3}\)
Answer: \(\boxed{y = \frac{2 \pm \sqrt{13}}{3}}\)
