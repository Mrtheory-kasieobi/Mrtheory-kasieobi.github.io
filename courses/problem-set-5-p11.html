Problem Set 5: Quadratic Equations

Precalculus 11 · 8 problems Medium

Problems

Problem 1

Solve by factoring: \(x^2 - 7x + 12 = 0\)

Problem 2

Solve by completing the square: \(x^2 + 8x + 10 = 0\)

Problem 3

Solve using the quadratic formula: \(3x^2 - 5x - 2 = 0\). Give exact and approximate answers.

Problem 4

Find the discriminant and determine the nature of roots: \(2x^2 - 4x + 5 = 0\)

Problem 5

Solve by square root method: \(4x^2 = 64\)

Problem 6

A ball is thrown upward with height \(h(t) = -16t^2 + 64t + 5\). Find when it hits the ground.

Problem 7

A rectangular garden has area 84 m². The length is 2 m more than the width. Find the dimensions.

Problem 8

Graph the parabola \(y = x^2 - 4x - 5\). Find the vertex, axis of symmetry, and x-intercepts.

Bonus Problems

Bonus Problem 1 Hard

Find k such that \(x^2 + 6x + k = 0\) has exactly one solution, then use that value to find all real solutions of \(x^2 + 6x + 9 = 0\)

Bonus Problem 2 Hard

A negative number and its reciprocal sum to 2. Find the number. Then solve \(y^2 + 2y - 8 = 0\) using an appropriate substitution.
