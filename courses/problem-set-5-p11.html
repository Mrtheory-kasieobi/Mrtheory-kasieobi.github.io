Problem Set 5: Radical and Rational Expressions

Precalculus 11 · 8 problems Hard

Problems

Problem 1

Simplify: \(\sqrt{72}\)

Problem 2

Solve: \(\sqrt{x + 3} = 5\)

Problem 3

Simplify: \(\frac{x^2 - 9}{x - 3}\), stating any restrictions.

Problem 4

Solve: \(\frac{2}{x} + \frac{3}{x+1} = 1\)

Problem 5

Simplify: \(\sqrt[3]{54x^6}\)

Problem 6

Solve: \(\sqrt{2x - 1} = x - 1\) (check for extraneous roots)

Problem 7

Simplify: \(\frac{x^2 + 5x + 6}{x^2 + 3x + 2}\)

Problem 8

Solve the rational equation: \(\frac{3}{x-2} = \frac{5}{x+1}\)

Bonus Problems

Bonus Problem 1 Medium

Rational Equation Chain: Solve \(\frac{2}{x-1} + \frac{3}{x+1} = \frac{5}{x^2-1}\). Before solving, explain why the denominators suggest a natural domain restriction. Then solve and verify your solution.

Bonus Problem 2 Hard

Nested Radicals: Find all real values of \(x\) such that \(\sqrt{x + \sqrt{2x + 3}} = 3\). Solve by first squaring both sides, then isolating the remaining radical, and squaring again.

Bonus Problem 3 Hard

Rational Function Analysis: The function \(f(x) = \frac{x^2 - 4}{x^2 - 5x + 6}\) can be simplified. Find the domain of the original function, simplify it completely, and determine for which values of \(x\) (if any) the simplified function equals 2.
