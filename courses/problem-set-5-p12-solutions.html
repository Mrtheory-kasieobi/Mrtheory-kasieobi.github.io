Problem Set 5: Trigonometric Functions and Graphs

Precalculus 12 - Chapter 5 Solutions

Solutions

Problem 1: Find the amplitude, period, phase shift, and vertical shift of \(f(x) = 3\cos(2x - \pi) + 2\).
Rewrite: \(f(x) = 3\cos(2(x - \frac{\pi}{2})) + 2\)
Amplitude = |3| = 3
Period = \(\frac{2\pi}{2} = \pi\)
Phase shift = \(\frac{\pi}{2}\) units right
Vertical shift = 2 units up
Answer: Amplitude 3, Period \(\pi\), Phase shift \(\frac{\pi}{2}\) right, Shift 2 up
Problem 2: Graph one period of \(f(x) = -2\sin(\frac{\pi}{2}x) + 1\). Label all key points.
Amplitude = 2, Period = \(\frac{2\pi}{\pi/2} = 4\)
Vertical shift = 1, No phase shift
Start at \(x = 0\): \(f(0) = 1\)
Quarter period = 1: At \(x = 1\): \(f(1) = -2(1) + 1 = -1\)
Half period = 2: At \(x = 2\): \(f(2) = 1\)
Three-quarters: At \(x = 3\): \(f(3) = 3\)
Full period: At \(x = 4\): \(f(4) = 1\)
Key points: (0,1), (1,-1), (2,1), (3,3), (4,1)
Problem 3: A mass on a spring oscillates with position \(x(t) = 0.05\cos(8\pi t)\). Find the amplitude, period, and frequency.
Amplitude = 0.05 meters = 5 cm
Period = \(\frac{2\pi}{8\pi} = \frac{1}{4}\) second
Frequency = \(\frac{1}{\text{period}} = 4\) Hz
Answer: Amplitude = 5 cm, Period = 0.25 s, Frequency = 4 Hz
Problem 4: Find the equation of a sine function with amplitude 4, period \(4\pi\), and phase shift \(\frac{\pi}{2}\).
General form: \(y = A\sin(B(x - C)) + D\)
Amplitude \(A = 4\)
Period = \(\frac{2\pi}{B} = 4\pi\) → \(B = \frac{1}{2}\)
Phase shift \(C = \frac{\pi}{2}\)
Vertical shift = 0 (not specified)
Answer: \(y = 4\sin\left(\frac{1}{2}(x - \frac{\pi}{2})\right)\)
Problem 5: Solve \(2\sin(x) - 1 = 0\) for \(x \in [0, 2\pi)\). Give the general solution.
\(\sin(x) = \frac{1}{2}\)
In \([0, 2\pi)\): \(x = \frac{\pi}{6}, \frac{5\pi}{6}\)
General solution: \(x = \frac{\pi}{6} + 2\pi n\) or \(x = \frac{5\pi}{6} + 2\pi n\) for integer \(n\)
Answer: \(x = \frac{\pi}{6}, \frac{5\pi}{6}\); General: above formulas
Problem 6: Graph \(f(x) = \tan(2x)\) and identify the period, asymptotes, and key points.
Period = \(\frac{\pi}{2}\) (since period of tan(Bx) = \(\frac{\pi}{B}\))
Asymptotes: Where \(2x = \frac{\pi}{2} + \pi n\), so \(x = \frac{\pi}{4} + \frac{\pi n}{2}\)
Within one period \([-\frac{\pi}{4}, \frac{\pi}{4})\): asymptote at \(x = -\frac{\pi}{4}\) and \(x = \frac{\pi}{4}\)
Key point: \(x = 0\), \(f(0) = 0\)
Asymptotes: \(x = \frac{\pi}{4} + \frac{\pi n}{2}\) for integer \(n\)
Answer: Period \(\frac{\pi}{2}\), Asymptotes at \(x = \frac{\pi}{4} + \frac{\pi n}{2}\)
Problem 7: Temperature varies seasonally: \(T(t) = 10\sin(\frac{2\pi}{365}t) + 15\). Find max, min, and period. When is the first maximum after January 1?
Amplitude = 10, Vertical shift = 15
Maximum: \(T = 15 + 10 = 25\)°C
Minimum: \(T = 15 - 10 = 5\)°C
Period = \(\frac{2\pi}{2\pi/365} = 365\) days
First maximum after t = 0: when argument = \(\frac{\pi}{2}\)
\(\frac{2\pi}{365}t = \frac{\pi}{2}\) → \(t = \frac{365}{4} = 91.25\) days ≈ April 1st
Answer: Max = 25°C, Min = 5°C, Period = 365 days, First max at t ≈ 91 days
Problem 8: Two waves \(y_1 = 3\sin(x)\) and \(y_2 = 4\cos(x)\) interfere. Find the amplitude and phase of the resultant wave.
Write as single sine: \(y = R\sin(x + \phi)\)
Expand: \(R\sin(x + \phi) = R\sin x \cos\phi + R\cos x \sin\phi\)
Match coefficients: \(R\cos\phi = 3\) and \(R\sin\phi = 4\)
Find R: \(R^2 = 3^2 + 4^2 = 25\), so \(R = 5\)
Find \(\phi\): \(\tan\phi = \frac{4}{3}\), so \(\phi = \arctan(\frac{4}{3}) \approx 0.93\) rad
Answer: Amplitude = 5, Phase = \(\arctan(\frac{4}{3})\)

Bonus Solutions

Bonus Problem 1: Find the exact value of \(\sin(18°)\) using a pentagon or golden ratio. Hint: Use the fact that \(\sin(5 \times 18°) = \sin(90°) = 1\).
Let \(\theta = 18°\), so \(5\theta = 90°\), meaning \(\sin(5\theta) = 1\)
Use \(\sin(5\theta) = 16\sin^5\theta - 20\sin^3\theta + 5\sin\theta\)
Let \(s = \sin(18°)\): \(16s^5 - 20s^3 + 5s = 1\)
Since this is the golden ratio related: \(s = \frac{\sqrt{5} - 1}{4}\)
Verification: \(\sin(18°) = \frac{\sqrt{5} - 1}{4}\)
Answer: \(\sin(18°) = \frac{\sqrt{5} - 1}{4}\)
Bonus Problem 2: Prove: \(\tan(\theta) + \cot(\theta) = 2\csc(2\theta)\) for all \(\theta\) where the expressions are defined.
Left side: \(\tan\theta + \cot\theta = \frac{\sin\theta}{\cos\theta} + \frac{\cos\theta}{\sin\theta}\)
Combine: \(\frac{\sin^2\theta + \cos^2\theta}{\sin\theta\cos\theta} = \frac{1}{\sin\theta\cos\theta}\)
Use identity: \(\sin(2\theta) = 2\sin\theta\cos\theta\)
So: \(\frac{1}{\sin\theta\cos\theta} = \frac{2}{2\sin\theta\cos\theta} = \frac{2}{\sin(2\theta)}\)
Right side: \(2\csc(2\theta) = \frac{2}{\sin(2\theta)}\)
QED: Both sides equal \(\frac{2}{\sin(2\theta)}\)
