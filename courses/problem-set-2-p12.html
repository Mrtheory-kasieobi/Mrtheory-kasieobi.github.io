Problem Set 2: Radical Functions

Precalculus 12 - Problem Set
Topics: Radical Functions, Transformations, Solving Radical Equations Medium

Problems

Problem 1

Graph \(f(x) = \sqrt{x - 2} + 3\) by hand. Identify the domain, range, and transformations from the parent function \(f(x) = \sqrt{x}\).

Problem 2

Solve: \(\sqrt{2x + 5} = x - 1\). Check for extraneous solutions.

Problem 3

Find the inverse of \(f(x) = \sqrt[3]{x + 4} - 2\). State the domain and range.

Problem 4

A pendulum's period is given by \(T = 2\pi\sqrt{\frac{L}{g}}\) where \(L\) is length in meters and \(g = 9.8\) m/s². If the period is 2 seconds, find the length of the pendulum.

Problem 5

Solve: \(\sqrt{x + 3} + \sqrt{x - 2} = 5\). Show all steps and verify your answer.

Problem 6

Graph \(f(x) = -\sqrt[4]{x} + 1\) and identify the domain, range, and any asymptotes.

Problem 7

Find all solutions to: \(\sqrt{3x - 2} = \sqrt{x + 4} + 1\).

Problem 8

A cylinder's volume is \(V = \pi r^2 h\). If the volume is 100π cm³ and height is 5 cm, find the radius. Then find the surface area.

Bonus Problems

Bonus Problem 1

Solve: \(\sqrt[3]{x + 2} = x - 2\). Check all potential solutions.

Bonus Problem 2

A right triangle has hypotenuse 10 cm. One leg is 2 cm longer than the other. Find the exact lengths of both legs using the quadratic formula.
