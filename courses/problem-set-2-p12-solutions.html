Problem Set 2: Radical Functions

Precalculus 12 - Chapter 2 Solutions

Solutions

Problem 1: Graph \(f(x) = \sqrt{x - 2} + 3\) by hand. Identify the domain, range, and transformations from the parent function \(f(x) = \sqrt{x}\).
Parent function: \(f(x) = \sqrt{x}\) with domain \([0, \infty)\) and range \([0, \infty)\)
Transformations: Horizontal shift right 2 units, vertical shift up 3 units
New domain: \([2, \infty)\)
New range: \([3, \infty)\)
Key point transformations: (0,0) → (2,3), (1,1) → (3,4), (4,2) → (6,5)
Answer: Domain \([2, \infty)\), Range \([3, \infty)\)
Problem 2: Solve: \(\sqrt{2x + 5} = x - 1\). Check for extraneous solutions.
Square both sides: \(2x + 5 = (x - 1)^2\)
Expand: \(2x + 5 = x^2 - 2x + 1\)
Rearrange: \(0 = x^2 - 4x - 4\)
Use quadratic formula: \(x = \frac{4 \pm \sqrt{16 + 16}}{2} = \frac{4 \pm \sqrt{32}}{2} = \frac{4 \pm 4\sqrt{2}}{2} = 2 \pm 2\sqrt{2}\)
Check \(x = 2 + 2\sqrt{2}\): RHS = \(1 + 2\sqrt{2} > 0\), LHS is positive. Valid.
Check \(x = 2 - 2\sqrt{2}\): RHS = \(-1 - 2\sqrt{2} < 0\), but LHS is non-negative. Extraneous.
Answer: \(x = 2 + 2\sqrt{2}\)
Problem 3: Find the inverse of \(f(x) = \sqrt[3]{x + 4} - 2\). State the domain and range.
Let \(y = \sqrt[3]{x + 4} - 2\)
Add 2: \(y + 2 = \sqrt[3]{x + 4}\)
Cube both sides: \((y + 2)^3 = x + 4\)
Subtract 4: \(x = (y + 2)^3 - 4\)
Swap variables: \(y = (x + 2)^3 - 4\)
Inverse: \(f^{-1}(x) = (x + 2)^3 - 4\)
Domain: All real numbers (cuberoot defined everywhere)
Range: All real numbers
Answer: \(f^{-1}(x) = (x + 2)^3 - 4\), Domain: \(\mathbb{R}\), Range: \(\mathbb{R}\)
Problem 4: A pendulum's period is given by \(T = 2\pi\sqrt{\frac{L}{g}}\) where \(L\) is length in meters and \(g = 9.8\) m/s². If the period is 2 seconds, find the length of the pendulum.
Substitute: \(2 = 2\pi\sqrt{\frac{L}{9.8}}\)
Divide by \(2\pi\): \(\frac{1}{\pi} = \sqrt{\frac{L}{9.8}}\)
Square both sides: \(\frac{1}{\pi^2} = \frac{L}{9.8}\)
Solve: \(L = \frac{9.8}{\pi^2} = \frac{9.8}{9.8696...} \approx 0.993\) meters
Answer: Approximately 0.99 meters or exactly \(\frac{49}{5\pi^2}\) meters
Problem 5: Solve: \(\sqrt{x + 3} + \sqrt{x - 2} = 5\). Show all steps and verify your answer.
Isolate one radical: \(\sqrt{x + 3} = 5 - \sqrt{x - 2}\)
Square both sides: \(x + 3 = 25 - 10\sqrt{x - 2} + (x - 2)\)
Simplify: \(x + 3 = 23 - 10\sqrt{x - 2} + x\)
Cancel \(x\): \(3 = 23 - 10\sqrt{x - 2}\)
Solve: \(10\sqrt{x - 2} = 20\), so \(\sqrt{x - 2} = 2\)
Square: \(x - 2 = 4\), so \(x = 6\)
Verify: \(\sqrt{9} + \sqrt{4} = 3 + 2 = 5\) ✓
Answer: \(x = 6\)
Problem 6: Graph \(f(x) = -\sqrt[4]{x} + 1\) and identify the domain, range, and any asymptotes.
Domain: For \(\sqrt[4]{x}\) to be real, we need \(x \geq 0\)
Even root of negative numbers is not real, so domain is \([0, \infty)\)
As \(x \to 0^+\), \(\sqrt[4]{x} \to 0\), so \(f(x) \to 1\)
As \(x \to \infty\), \(\sqrt[4]{x} \to \infty\), so \(f(x) \to -\infty\)
Range: \((-\infty, 1]\)
No vertical or horizontal asymptotes (function is defined for all \(x \geq 0\))
Answer: Domain \([0, \infty)\), Range \((-\infty, 1]\), No asymptotes
Problem 7: Find all solutions to: \(\sqrt{3x - 2} = \sqrt{x + 4} + 1\).
Square both sides: \(3x - 2 = x + 4 + 2\sqrt{x + 4} + 1\)
Simplify: \(3x - 2 = x + 5 + 2\sqrt{x + 4}\)
Isolate radical: \(2x - 7 = 2\sqrt{x + 4}\)
Divide by 2: \(x - \frac{7}{2} = \sqrt{x + 4}\)
Square both sides: \(x^2 - 7x + \frac{49}{4} = x + 4\)
Rearrange: \(x^2 - 8x + \frac{33}{4} = 0\)
Multiply by 4: \(4x^2 - 32x + 33 = 0\)
Use quadratic formula: \(x = \frac{32 \pm \sqrt{1024 - 528}}{8} = \frac{32 \pm \sqrt{496}}{8} = \frac{32 \pm 4\sqrt{31}}{8} = 4 \pm \frac{\sqrt{31}}{2}\)
Check \(x = 4 + \frac{\sqrt{31}}{2}\): Works in original equation
Check \(x = 4 - \frac{\sqrt{31}}{2} \approx 1.21\): LHS ≈ 1.13, RHS ≈ 3.13 - doesn't work
Answer: \(x = 4 + \frac{\sqrt{31}}{2}\)
Problem 8: A cylinder's volume is \(V = \pi r^2 h\). If the volume is 100π cm³ and height is 5 cm, find the radius. Then find the surface area.
Given: \(V = 100\pi\) cm³, \(h = 5\) cm
Substitute: \(100\pi = \pi r^2 (5)\)
Simplify: \(100 = 5r^2\)
Solve: \(r^2 = 20\), so \(r = \sqrt{20} = 2\sqrt{5}\) cm
Surface area: \(SA = 2\pi r^2 + 2\pi rh = 2\pi(20) + 2\pi(2\sqrt{5})(5)\)
\(SA = 40\pi + 20\pi\sqrt{5} = 20\pi(2 + \sqrt{5})\) cm²
Answer: Radius = \(2\sqrt{5}\) cm, Surface Area = \(20\pi(2 + \sqrt{5})\) cm²

Bonus Solutions

Bonus Problem 1: Solve: \(\sqrt[3]{x + 2} = x - 2\). Check all potential solutions.
Cube both sides: \(x + 2 = (x - 2)^3\)
Expand RHS: \(x + 2 = x^3 - 6x^2 + 12x - 8\)
Rearrange: \(0 = x^3 - 6x^2 + 11x - 10\)
Test rational roots: Try \(x = 5\): \(125 - 150 + 55 - 10 = 20 \neq 0\)
Try \(x = 2\): \(8 - 24 + 22 - 10 = -4 \neq 0\)
Try \(x = -2\): \(-8 - 24 - 22 - 10 = -64 \neq 0\)
Let's verify by testing: If \(x = 5\), \(\sqrt[3]{7} \approx 1.91 \neq 3\)
Actually factor: \(x^3 - 6x^2 + 11x - 10 = (x - 5)(x^2 - x + 2)\)
Only real root is \(x = 5\), but doesn't satisfy original
Check \(x = 5\) in original: \(\sqrt[3]{7} \neq 3\), so extraneous
The cubic factors have no other real roots
Answer: No real solutions
Bonus Problem 2: A right triangle has hypotenuse 10 cm. One leg is 2 cm longer than the other. Find the exact lengths of both legs using the quadratic formula.
Let shorter leg = \(x\) cm, longer leg = \(x + 2\) cm
By Pythagorean theorem: \(x^2 + (x + 2)^2 = 10^2\)
Expand: \(x^2 + x^2 + 4x + 4 = 100\)
Simplify: \(2x^2 + 4x - 96 = 0\)
Divide by 2: \(x^2 + 2x - 48 = 0\)
Use quadratic formula: \(x = \frac{-2 \pm \sqrt{4 + 192}}{2} = \frac{-2 \pm \sqrt{196}}{2} = \frac{-2 \pm 14}{2}\)
\(x = 6\) or \(x = -8\) (reject negative)
Legs: 6 cm and 8 cm
Answer: 6 cm and 8 cm (a 6-8-10 right triangle)
