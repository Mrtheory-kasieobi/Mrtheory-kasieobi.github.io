Problem Set 5: Inner Product Spaces

Linear Algebra Course
Based on Axler's "Linear Algebra Done Right"

Instructions

Solve all problems. Show your work clearly. You may use results from previous lectures.

Problem 5.1

Show that \(\langle f, g \rangle = \int_0^1 f(x)g(x) dx\) defines an inner product on \(C[0, 1]\).

Problem 5.2

Find the orthogonal projection of \(f(x) = x\) onto \(\operatorname{span}\{1\}\) in \(C[0, 1]\) with the inner product from Problem 5.1.

Problem 5.3

Apply Gram-Schmidt to \{1, x\}\) in \(C[0, 1]\) with the inner product \(\langle f, g \rangle = \int_0^1 f(x)g(x) dx\) to obtain an orthonormal basis.

Problem 5.4

Verify the Cauchy-Schwarz inequality for \(f(x) = 1\) and \(g(x) = x\) in \(C[0, 1]\).

Problem 5.5

Find the best approximation to \(f(x) = x^2\) in \(\operatorname{span}\{1, x\}\) using the inner product \(\langle f, g \rangle = \int_0^1 f(x)g(x) dx\).
