Problem Set 3: Polynomial Functions

Precalculus 12 - Chapter 3 Solutions

Solutions

Problem 1: Determine the end behavior of \(f(x) = -x^4 + 2x^3 + 5x - 1\). How many turning points can this function have at most?
Leading term: \(-x^4\) with even degree and negative coefficient
As \(x \to \pm\infty\), \(f(x) \to -\infty\)
Maximum turning points = degree - 1 = 4 - 1 = 3
Answer: Both ends go to \(-\infty\), max 3 turning points
Problem 2: Use the Remainder Theorem to find the remainder when \(P(x) = x^4 - 3x^2 + 2x - 5\) is divided by \((x - 2)\).
By Remainder Theorem: remainder = \(P(2)\)
\(P(2) = (2)^4 - 3(2)^2 + 2(2) - 5\)
\(= 16 - 3(4) + 4 - 5\)
\(= 16 - 12 + 4 - 5 = 3\)
Answer: Remainder is 3
Problem 3: Factor completely: \(f(x) = x^3 - 6x^2 + 11x - 6\). Use the Factor Theorem to help you.
Test possible rational roots: \(\pm 1, \pm 2, \pm 3, \pm 6\)
Test \(x = 1\): \(1 - 6 + 11 - 6 = 0\) ✓ So \((x - 1)\) is a factor
Divide: \((x^3 - 6x^2 + 11x - 6) \div (x - 1) = x^2 - 5x + 6\)
Factor quadratic: \(x^2 - 5x + 6 = (x - 2)(x - 3)\)
Complete factorization: \((x - 1)(x - 2)(x - 3)\)
Answer: \(f(x) = (x - 1)(x - 2)(x - 3)\)
Problem 4: Graph \(f(x) = (x + 1)(x - 2)^2(x - 4)\) by identifying key features. What is the behavior near each x-intercept?
x-intercepts: \(x = -1\) (multiplicity 1), \(x = 2\) (multiplicity 2), \(x = 4\) (multiplicity 1)
At \(x = -1\): crosses x-axis (odd multiplicity)
At \(x = 2\): touches and turns (even multiplicity - tangent to x-axis)
At \(x = 4\): crosses x-axis (odd multiplicity)
End behavior: \(x \to -\infty\), \(f(x) \to -\infty\); \(x \to \infty\), \(f(x) \to \infty\) (odd degree, positive leading coeff)
y-intercept: \(f(0) = (1)(4)(-4) = -16\)
Answer: Crosses at x = -1 and x = 4, touches at x = 2
Problem 5: A projectile's height is given by \(h(t) = -4.9t^2 + 25t + 2\). When does it hit the ground? What is the maximum height?
Hits ground when \(h(t) = 0\): \(-4.9t^2 + 25t + 2 = 0\)
Use quadratic formula: \(t = \frac{-25 \pm \sqrt{625 + 39.2}}{-9.8}\)
\(t = \frac{-25 \pm \sqrt{664.2}}{-9.8} = \frac{-25 \pm 25.77}{-9.8}\)
\(t \approx 5.18\) seconds (positive root)
Maximum at vertex: \(t = -\frac{b}{2a} = \frac{25}{9.8} \approx 2.55\) seconds
Maximum height: \(h(2.55) = -4.9(2.55)^2 + 25(2.55) + 2 \approx 32.9\) meters
Answer: Hits ground at \(t \approx 5.18\) sec, Max height \(\approx 32.9\) m
Problem 6: Find all zeros of \(f(x) = x^4 - 5x^2 + 4\) and sketch the graph.
Let \(u = x^2\): \(u^2 - 5u + 4 = 0\)
Factor: \((u - 4)(u - 1) = 0\)
So \(u = 4\) or \(u = 1\), meaning \(x^2 = 4\) or \(x^2 = 1\)
Zeros: \(x = \pm 2, \pm 1\)
Factorization: \((x - 2)(x + 2)(x - 1)(x + 1)\)
End behavior: \(x \to \pm\infty\), \(f(x) \to \infty\)
y-intercept: \(f(0) = 4\)
Answer: Zeros at \(x = -2, -1, 1, 2\)
Problem 7: Using the Rational Root Theorem, find all rational zeros of \(f(x) = 2x^3 - 3x^2 - 11x + 6\).
Possible rational roots: \(\pm 1, \pm 2, \pm 3, \pm 6, \pm \frac{1}{2}, \pm \frac{3}{2}\)
Test \(x = 3\): \(54 - 27 - 33 + 6 = 0\) ✓
Factor: \((x - 3)(2x^2 + 3x - 2)\)
Factor quadratic: \(2x^2 + 3x - 2 = (2x - 1)(x + 2)\)
Complete: \(2x^3 - 3x^2 - 11x + 6 = (x - 3)(2x - 1)(x + 2)\)
Answer: Zeros at \(x = 3, \frac{1}{2}, -2\)
Problem 8: A company's revenue is \(R(x) = -0.1x^3 + 2x^2 + 5x\) and cost is \(C(x) = 0.05x^3 + x + 10\). Find the profit function and break-even points.
Profit: \(P(x) = R(x) - C(x) = -0.1x^3 + 2x^2 + 5x - 0.05x^3 - x - 10\)
Simplify: \(P(x) = -0.15x^3 + 2x^2 + 4x - 10\)
Break-even: \(P(x) = 0\): \(-0.15x^3 + 2x^2 + 4x - 10 = 0\)
Multiply by -20/3: \(x^3 - \frac{40}{3}x^2 - \frac{80}{3}x + \frac{200}{3} = 0\)
Or use numerical methods: approximately \(x \approx 0.8\), \(x \approx 3.7\), \(x \approx 9.2\)
Verify: \(x = 5\): \(P(5) = -0.15(125) + 50 + 20 - 10 = -18.75 + 60 = 41.25 > 0\)
Answer: P(x) = -0.15x³ + 2x² + 4x - 10, Break-even at x ≈ 0.8, 3.7, 9.2 thousand units

Bonus Solutions

Bonus Problem 1: Find all real zeros of \(f(x) = x^4 - 4x^3 + 3x^2 + 4x - 4\) and factor the polynomial completely.
Test rational roots: \(\pm 1, \pm 2, \pm 4\)
Test \(x = 1\): \(1 - 4 + 3 + 4 - 4 = 0\) ✓
Factor: \((x - 1)(x^3 - 3x^2 + 4)\)
Test \(x = -1\) in cubic: \(-1 - 3 - 4 \neq 0\)
Test \(x = 2\): \(8 - 12 + 4 = 0\) ✓
Factor: \((x - 1)(x - 2)(x^2 - x + 2)\)
Quadratic has discriminant: \(1 - 8 = -7 < 0\), no real roots
Answer: Real zeros at x = 1 and x = 2. Complete factorization: \((x-1)(x-2)(x^2-x+2)\)
Bonus Problem 2: A polynomial of degree 4 has zeros at \(x = -1\) (multiplicity 2) and \(x = 2 + i\). Find the polynomial with leading coefficient 1.
Note: \(i\) is the imaginary unit, defined by \(i^2 = -1\)
Complex zeros come in conjugate pairs, so also zero at \(x = 2 - i\)
Factors: \((x + 1)^2\) and \((x - (2+i))\) and \((x - (2-i))\)
Conjugate pair: \((x - 2 - i)(x - 2 + i) = (x-2)^2 + 1 = x^2 - 4x + 5\)
Polynomial: \(f(x) = (x + 1)^2(x^2 - 4x + 5)\)
Expand: \(= (x^2 + 2x + 1)(x^2 - 4x + 5)\)
\(= x^4 - 4x^3 + 5x^2 + 2x^3 - 8x^2 + 10x + x^2 - 4x + 5\)
\(= x^4 - 2x^3 - 2x^2 + 6x + 5\)
Answer: \(f(x) = x^4 - 2x^3 - 2x^2 + 6x + 5\)
