Vector Spaces and Subspaces

Linear Algebra - Lecture 1 • Based on Axler's "Linear Algebra Done Right" and MIT 18.700

1. Vector Spaces: The Foundation

A vector space (or linear space) over a field F is a set V together with:

  1. An addition operation \(+ : V \times V \to V\)
  2. A scalar multiplication operation \(\cdot : F \times V \to V\)

These operations must satisfy the following axioms for all \(u, v, w \in V\) and \(a, b \in F\):

Vector Space Axioms:
  • Associativity of addition: \(u + (v + w) = (u + v) + w\)
  • Commutativity of addition: \(u + v = v + u\)
  • Identity element of addition: \(\exists 0 \in V\) such that \(v + 0 = v\)
  • Inverse elements of addition: \(\forall v \in V, \exists -v \in V: v + (-v) = 0\)
  • Distributivity of scalar multiplication: \(a(u + v) = au + av\)
  • Distributivity of scalar multiplication: \((a + b)v = av + bv\)
  • Compatibility of scalar multiplication: \(a(bv) = (ab)v\)
  • Identity element of scalar multiplication: \(1 \cdot v = v\)

1.2 Examples of Vector Spaces

Example 1: Standard Euclidean Space

\(F^n = \{(x_1, \ldots, x_n) : x_i \in F\}\)

With component-wise addition and scalar multiplication.

Example 2: Space of Polynomials

\(P(F) = \{p : F \to F \mid p \text{ is a polynomial}\}\)

With usual polynomial addition and scalar multiplication.

Example 3: Function Spaces

\(F(\mathbb{R}, F)\) (all functions from ℝ to F)

With pointwise addition and scalar multiplication.

Example 4: Sequence Spaces

\(F^\infty = \{(x_1, x_2, x_3, \ldots) : x_i \in F\}\)

Infinite sequences with component-wise operations.

2. Subspaces

2.1 Definition

A subset \(M \subseteq V\) is a subspace of V if M is a vector space under the same operations as V.

2.2 The Subspace Test

Subspace Test: A subset \(M \subseteq V\) is a subspace if and only if:
  1. \(0 \in M\)
  2. \(u, v \in M \implies u + v \in M\) (closed under addition)
  3. \(u \in M, c \in F \implies cu \in M\) (closed under scalar multiplication)

2.3 Examples of Subspaces

Example 5: Kernel of a Linear Map

If \(T \in L(V, W)\), then \(\ker T = \{v \in V : Tv = 0\}\) is a subspace of V.

Example 6: Column Space and Null Space

For a matrix \(A \in M_{m \times n}(F)\):

  • \(\operatorname{col} A = \{Ax : x \in F^n\}\) is a subspace of \(F^m\)
  • \(\operatorname{null} A = \{x \in F^n : Ax = 0\}\) is a subspace of \(F^n\)

Example 7: Solution Set of Homogeneous System

The set of all solutions to a homogeneous system of linear equations forms a subspace.

2.4 The Zero Subspace and V

Every vector space V has exactly two trivial subspaces:

  • Zero subspace: \{0\} = \{0v : v \in V\}\)
  • Whole space: \(V\)

3. Key Theorems

Theorem 1 (Subspace Intersection): The intersection of any collection of subspaces of V is a subspace of V.
Theorem 2 (Span as Subspace): If \(v_1, \ldots, v_n \in V\), then \(\operatorname{span}(v_1, \ldots, v_n)\) is a subspace of V.
Note from Axler:

This approach emphasizes that vector spaces are fundamental objects, not just collections of tuples. The abstract definition allows us to work with function spaces, polynomial spaces, and many other structures.

4. Practice Problems

Problem 1

Show that the set of all solutions to a homogeneous system \(Ax = 0\) forms a subspace of \(F^n\).

Problem 2

Determine whether the following are subspaces of \(\mathbb{R}^3\):

  • \(S_1 = \{(x, y, z) : x + y + z = 0\}\)
  • \(S_2 = \{(x, y, z) : x \geq 0\}\)
  • \(S_3 = \{(x, y, z) : x^2 + y^2 + z^2 = 1\}\)
Problem 3

Show that \{1, x, x^2\}\) is a basis for \(\mathcal{P}_2(F)\).

Problem 4

Find a basis for the subspace \(W = \{(x, y, z, w) \in \mathbb{R}^4 : x + y + z + w = 0, x - y + z - w = 0\}\).
