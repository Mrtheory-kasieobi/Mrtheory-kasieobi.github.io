Problem Set 7: Integration

Calculus I - Week 7

Instructions

Show all work. No calculators. Write clearly and show each step.

Problems

  • 1. Find \(\int (3x^2 - 2x + 5) \, dx\)
  • 2. Evaluate \(\int_0^1 x^3 \, dx\)
  • 3. Find \(\int \frac{1}{x} \, dx\)
  • 4. Evaluate \(\int_1^e \frac{1}{x} \, dx\)
  • 5. Find \(\int x e^x \, dx\) using integration by parts
  • 6. Evaluate \(\int \frac{\ln x}{x} \, dx\) using substitution
  • 7. Find \(\int \sin^2 x \, dx\) (hint: use identity \(\sin^2 x = \frac{1-\cos 2x}{2}\))
  • 8. Evaluate \(\int_0^{\pi/2} \cos^2 x \, dx\)
  • 9. Find \(\int \frac{1}{x^2 + 4} \, dx\)
  • 10. Use the substitution \(u = x^2\) to evaluate \(\int \frac{x}{x^2 + 1} \, dx\)
Bonus Problems (10 points each):
  • B1. Find \(\int \frac{1}{x \ln x} \, dx\)
  • B2. Evaluate \(\int_0^1 \frac{1}{\sqrt{1-x^2}} \, dx\) and interpret geometrically
