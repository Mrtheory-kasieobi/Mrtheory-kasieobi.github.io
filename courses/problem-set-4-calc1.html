Problem Set 4: Chain Rule and Implicit Differentiation

Calculus I - Week 4

Instructions

Show all work. No calculators. Write clearly and show each step.

Problems

  • 1. Find \(\frac{dy}{dx}\) for \(y = \sin(x^3 + 2x)\)
  • 2. Find \(\frac{d}{dx}[e^{\tan(x^2)}]\)
  • 3. Find \(\frac{d}{dx}[\ln(\sin(x^2))]\)
  • 4. If \(y = \sqrt[3]{x^2 + 1}\), find \(\frac{dy}{dx}\)
  • 5. Find \(\frac{dy}{dx}\) for \(y = (2x^3 - 5)^{-4}\)
  • 6. Use implicit differentiation to find \(\frac{dy}{dx}\) for \(x^2y + y^3 = 6\)
  • 7. Find \(\frac{dy}{dx}\) for \(\sin(x+y) = x + y\) (solve for \(\frac{dy}{dx}\) in terms of \(x\) and \(y\))
  • 8. A spherical balloon is being inflated. If the radius increases at 2 cm/s, how fast is the volume increasing when \(r = 10\) cm?
  • 9. Find the equation of the tangent line to \(y = e^{x^2}\) at \(x = 1\)
  • 10. Find \(\frac{d}{dx}[x^{x}]\) using logarithmic differentiation
Bonus Problems (10 points each):
  • B1. Find \(\frac{dy}{dx}\) for \(y = (\sin x)^{\cos x}\)
  • B2. If \(f(g(x)) = x\) for all \(x\), prove that \(g(f(x)) = x\) for all \(x\) in the appropriate domains
