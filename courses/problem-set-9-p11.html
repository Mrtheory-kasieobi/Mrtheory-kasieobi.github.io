Problem Set 9

Absolute Value Functions and Equations | Precalculus 11

Instructions

Solve each absolute value problem. Show your work and graph where appropriate.

Problem 1

Solve: \(\displaystyle |2x - 3| = 7\)

Problem 2

Solve: \(\displaystyle |x + 5| = |x - 3|\)

Problem 3

Solve: \(\displaystyle |3x + 1| = |2x - 4|\)

Problem 4

Solve: \(\displaystyle 2|x - 4| = x + 2\)

Problem 5

Solve: \(\displaystyle |x - 2| = 3x + 5\)

Check each solution.

Problem 6

Graph \(f(x) = |x + 2| - 3\) and find its vertex and axis of symmetry.

Problem 7

Solve the inequality: \(\displaystyle |2x - 1| < 5\)

Problem 8

Solve: \(\displaystyle |x + 3| \geq 4\)

Problem 9

Find the x-intercepts of \(\displaystyle f(x) = |x - 1| + 2 - 3\)

Problem 10

Write an absolute value equation for the function with vertex at (−2, 3) passing through (0, 7).
