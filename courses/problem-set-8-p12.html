Problem Set 8: Rational Functions

Precalculus 12 - Problem Set
Topics: Asymptotes, Graphing, Solving Rational Equations Medium

Problems

Problem 1

Find the domain, vertical asymptotes, and horizontal asymptote of \(f(x) = \frac{x^2 - 4}{x^2 - 9}\).

Problem 2

Solve: \(\frac{2}{x-1} + \frac{3}{x+2} = \frac{1}{x^2 + x - 2}\)

Problem 3

Graph \(f(x) = \frac{1}{x^2 - 4}\) by identifying asymptotes, intercepts, and behavior near asymptotes.

Problem 4

A rectangular box with volume 100 cm³ has square base. Find the dimensions that minimize surface area.

Problem 5

Find the inverse of \(f(x) = \frac{2x + 1}{x - 3}\). State the domain and range of both functions.

Problem 6

Solve: \(\frac{x + 1}{x - 2} = \frac{2x - 1}{x + 3}\)

Problem 7

Graph \(f(x) = \frac{x^2 - 1}{x^2 - 4}\) and identify any holes, asymptotes, and intercepts.

Problem 8

A drug concentration is \(C(t) = \frac{10t}{t^2 + 1}\) mg/L. Find the maximum concentration and when it occurs.

Bonus Problems

Bonus Problem 1

Find the domain, vertical asymptotes, horizontal asymptotes, and x-intercepts of \(f(x) = \frac{x^3 - 8}{x^2 - 4x + 4}\).

Bonus Problem 2

Solve: \(\frac{x^2 - 5x + 6}{x^2 - 9} = \frac{1}{x - 3}\) and check for extraneous solutions.
