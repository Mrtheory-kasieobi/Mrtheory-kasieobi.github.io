Problem Set 6: Proof by Contradiction

Introduction to Proofs - Lecture 6 Medium

Try each problem before reading the solutions. A proof is judged by the completeness of its logical chain, not by how short it is. State your assumptions, justify every nontrivial step, and verify that the conclusion follows exactly.

Problems

Problem 1

Prove by contradiction that there is no smallest positive rational number.

Problem 2

Prove that \(\sqrt3\) is irrational.

Problem 3

Prove by contradiction: if \(n\in\mathbb{Z}\) and \(n^2\) is odd, then \(n\) is odd.

Problem 4

Prove that \(2+\sqrt3\) is irrational.

Problem 5

Prove by contradiction that if \(a,b\) are integers and \(a^2+b^2=0\), then \(a=b=0\).

Problem 6

Prove that there are infinitely many integers \(n\) for which \(n^2+1\) is not a perfect square.

Problem 7

Prove by contradiction that \(\log_2 3\) is irrational.

Problem 8

Analyse the following "proof": "To prove that \(n^2\) even implies \(n\) even, suppose \(n\) is even, \(n=2k\). Then \(n^2=4k^2\), which is even." Is it valid? If not, what method was actually used?

Bonus Problem

Prove that there is no rational number whose square is \(3\).
