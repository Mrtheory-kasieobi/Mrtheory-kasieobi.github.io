Problem Set 2: Linear Independence and Bases

Linear Algebra Course
Based on Axler's "Linear Algebra Done Right"

Instructions

Solve all problems. Show your work clearly. You may use results from previous lectures.

Problem 2.1

Determine if the vectors \{(1, 2, 3), (4, 5, 6), (7, 8, 9)\}\) in \(\mathbb{R}^3\) are linearly independent.

Problem 2.2

Find a basis for the subspace \(W = \{(x, y, z, w) \in \mathbb{R}^4 : x + y + z + w = 0, x - y + z - w = 0\}\). What is \(\dim W\)?

Problem 2.3

Show that \{1, \cos x, \sin x, \cos 2x, \sin 2x\}\) is linearly independent in \(C[0, 2\pi]\).

Problem 2.4

Prove that in \(\mathbb{R}^n\), any set of more than \(n\) vectors must be linearly dependent.

Problem 2.5

Find the coordinates of \(v = (2, 3, -1)\) relative to the basis \(B = \{(1, 1, 0), (1, 0, 1), (0, 1, 1)\}\) of \(\mathbb{R}^3\).
