Problem Set 8: Gaussian Integers - Definition and Arithmetic

Elementary Number Theory - Week 9 Medium

Problems

Problem 1

Compute \(N(3+4i)\), \(N(2-i)\), and \(N(-1+2i)\) where \(N(a+bi) = a^2 + b^2\).

Problem 2

Show that \((1+i)(1-i) = 2\) and find the norm of \(1+i\).

Problem 3

Verify that \(\mathbb{Z}[i]\) is closed under addition by computing \((2+3i) + (1-2i)\) and \((2+3i)(1-2i)\).

Problem 4

Find the inverse of \(2+i\) in \(\mathbb{Q}(i)\) and show it is not in \(\mathbb{Z}[i]\).

Problem 5

Compute \(\gcd(2+3i, 1+i)\) in \(\mathbb{Z}[i]\) using the Euclidean algorithm.

Problem 6

Show that \(N(\alpha\beta) = N(\alpha)N(\beta)\) for \(\alpha = 1+2i\) and \(\beta = 2-i\).

Problem 7

Prove: In \(\mathbb{Z}[i]\), \(N(\alpha) = 0\) if and only if \(\alpha = 0\).

Problem 8

Find all units in \(\mathbb{Z}[i]\) by solving \(a^2 + b^2 = 1\).

Problem 9

Show that \(1+i\) is irreducible in \(\mathbb{Z}[i]\). Hint: Check its norm.

Problem 10

Prove: If \(\gcd(a, b) = 1\), then \(\gcd(a+bi, a-bi) = 1\) or \(\sqrt{-1}\) in \(\mathbb{Z}[i]\).

Bonus Problems

Bonus Problem 1

Challenge: Prove the division algorithm in \(\mathbb{Z}[i]\): For any \(\alpha, \beta \in \mathbb{Z}[i]\) with \(\beta \neq 0\), there exist \(\gamma, \delta \in \mathbb{Z}[i]\) such that \(\alpha = \beta\gamma + \delta\) with \(N(\delta) < N(\beta)\).

Bonus Problem 2

Challenge: Show that if \(\alpha = a+bi \in \mathbb{Z}[i]\) and \(a^2 + b^2\) is prime in \(\mathbb{Z}\), then \(\alpha\) is irreducible in \(\mathbb{Z}[i]\).

Bonus Problem 3

Challenge: Prove that \(\mathbb{Z}[i]\) is a Euclidean domain with respect to the norm function.
