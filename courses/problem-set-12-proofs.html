Problem Set 12: Review and Proof Writing Workshop

Introduction to Proofs - Lecture 12 Medium

Try each problem before reading the solutions. A proof is judged by the completeness of its logical chain, not by how short it is. State your assumptions, justify every nontrivial step, and verify that the conclusion follows exactly.

Problems

Problem 1

Prove: for every real number \(x\), if \(x^2-3x+2=0\), then \(x=1\) or \(x=2\).

Problem 2

Prove that there is no integer \(n\) with \(n^2\equiv2\pmod3\).

Problem 3

Prove that \(f:\mathbb{R} o\mathbb{R}\), \(f(x)=x^3+x\) is bijective.

Problem 4

Prove that \(\mathcal{P}(A)\subseteq\mathcal{P}(B)\) if and only if \(A\subseteq B\).

Problem 5

Prove that \(\sum_{k=1}^n\frac1{k(k+1)}=\frac{n}{n+1}\) by induction and by telescoping.

Problem 6

Prove that if \(n\ge2\) and \(n\) is not prime, then \(n=ab\) with \(1<a\le b<n\).

Problem 7

Prove that the relation \(R\) on \(\mathbb{Z}\) defined by \(aRb\iff a+b\) is even is an equivalence relation, and describe its classes.

Problem 8

Prove that if \(m,n\) are integers and \(m\) is odd, then \(mn\) is odd if and only if \(n\) is odd.

Problem 9

Prove that there are infinitely many composite positive integers.

Problem 10

Critique this proof: "To show \(\sqrt2\) is irrational, suppose \(\sqrt2=a/b\). Then \(2=a^2/b^2\), so \(2b^2=a^2\). Thus \(a\) is even, say \(a=2k\), and \(b\) is even too. Contradiction."

Bonus Problem

Audit this claim: “If \(x^2\) is rational, then \(x\) is rational. Indeed, if \(x^2=a/b\), then \(x=\sqrt a/\sqrt b\), which is rational.”
