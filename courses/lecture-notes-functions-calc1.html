Functions and Their Representations

Calculus I - Chapter 1.1-1.5 (Detailed Notes)

1. Four Ways to Represent a Function

Definition: Function A function \(f\) is a rule that assigns to each element \(x\) in a set \(D\) (the domain) exactly one element \(f(x)\) in a set \(R\) (the range or codomain). We write \(y = f(x)\) to indicate that \(y\) is the image of \(x\) under \(f\).

Key Terminology:

  • Domain: The set of all possible input values
  • Range (or Codomain): The set of all possible output values
  • Independent Variable: The input variable (usually \(x\))
  • Dependent Variable: The output variable (usually \(y\) or \(f(x)\))

Functions can be represented in four main ways:

1.1 Verbal Representation

Describing the relationship in words. For example: "The area of a circle depends on its radius" or "The temperature decreases by 2 degrees for each meter of altitude."

1.2 Algebraic Representation

Using an explicit formula. For example: \(A(r) = \pi r^2\) for the area of a circle, or \(T(h) = T_0 - 2h\) for temperature at altitude.

1.3 Visual Representation

Using a graph. The graph of a function \(f\) consists of all points \((x, y)\) in the plane such that \(y = f(x)\) and \(x\) is in the domain.

Vertical Line Test: A curve in the \(xy\)-plane is the graph of a function if and only if no vertical line intersects the curve more than once.

1.4 Numerical Representation

Using a table of values. This is useful when the function is defined by experimental data or when an explicit formula is not available.

Example 1.1: The area of a circle with radius \(r\) is given by \(A(r) = \pi r^2\). This is an algebraic representation. The domain is \(r \geq 0\) and the range is \(A \geq 0\).
Example 1.2: The human population of the world as a function of time can be represented:
  • Verbally: "Population increases by about 1.5% per year"
  • Numerically: A table of population counts for each year
  • Visually: A graph showing population growth over time

2. Mathematical Models: A Catalog of Essential Functions

Mathematical models use functions to describe real-world phenomena. Here are the essential types:

2.1 Linear Functions

Linear Function: \(f(x) = mx + b\) where \(m\) is the slope and \(b\) is the y-intercept.

Linear functions model constant rate changes. Examples: distance at constant speed, cost with fixed rate.

2.2 Polynomials

Polynomial Function: \(P(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0\)

Polynomials are used to model smooth curves and approximate other functions. The degree \(n\) determines the shape.

2.3 Rational Functions

Rational Function: \(f(x) = \frac{P(x)}{Q(x)}\) where \(P\) and \(Q\) are polynomials.

Rational functions have vertical asymptotes where \(Q(x) = 0\) and horizontal asymptotes determined by the leading terms.

2.4 Trigonometric Functions

The six basic trigonometric functions: \(\sin x, \cos x, \tan x, \csc x, \sec x, \cot x\). These model periodic phenomena like sound waves, tides, and seasonal variations.

2.5 Exponential Functions

Exponential Function: \(f(x) = a^x\) where \(a > 0, a \neq 1\).

Exponential functions model growth and decay: population growth, radioactive decay, compound interest.

2.6 Logarithmic Functions

Logarithm: \(f(x) = \log_a x\) is the inverse of the exponential function \(a^x\).

Logarithms model phenomena that grow slowly: pH scale, Richter scale, decibel scale.

3. New Functions from Old Functions

Given functions \(f\) and \(g\), we can create new functions through transformations and combinations.

3.1 Transformations

  • Vertical Translation: \(f(x) + c\) shifts the graph up by \(c\) units
  • Horizontal Translation: \(f(x - c)\) shifts the graph right by \(c\) units
  • Vertical Scaling: \(cf(x)\) stretches/compresses vertically by factor \(c\)
  • Horizontal Scaling: \(f(cx)\) stretches/compresses horizontally by factor \(1/c\)
  • Reflection: \(-f(x)\) reflects across x-axis, \(f(-x)\) reflects across y-axis
Example 3.1: If \(f(x) = \sqrt{x}\), then:
  • \(f(x) + 2 = \sqrt{x} + 2\) shifts up 2 units
  • \(f(x - 3) = \sqrt{x - 3}\) shifts right 3 units
  • \(-f(x) = -\sqrt{x}\) reflects across x-axis

3.2 Combinations of Functions

  • Sum: \((f + g)(x) = f(x) + g(x)\)
  • Difference: \((f - g)(x) = f(x) - g(x)\)
  • Product: \((fg)(x) = f(x) \cdot g(x)\)
  • Quotient: \(\left(\frac{f}{g}\right)(x) = \frac{f(x)}{g(x)}\) (where \(g(x) \neq 0\))
  • Composition: \((f \circ g)(x) = f(g(x))\)
Composition Formula: \((f \circ g)(x) = f(g(x))\)
Domain of Composition: The domain of \(f \circ g\) consists of all \(x\) in the domain of \(g\) such that \(g(x)\) is in the domain of \(f\).

4. Exponential Functions

Definition: Exponential Function The exponential function with base \(a\) is \(f(x) = a^x\) where \(a > 0, a \neq 1\).

4.1 Properties of \(a^x\)

  • \(a^0 = 1\) for all \(a > 0\)
  • \(a^1 = a\)
  • \(a^{x+y} = a^x \cdot a^y\)
  • \((a^x)^y = a^{xy}\)
  • \((ab)^x = a^x b^x\)

4.2 The Natural Exponential Function

The Number \(e\): The number \(e \approx 2.71828...\) is defined as: \(e = \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = \sum_{n=0}^{\infty} \frac{1}{n!}\)

The function \(e^x\) is its own derivative: \(\frac{d}{dx}e^x = e^x\). This makes it fundamental in calculus.

4.3 Applications of Exponential Functions

  • Compound Interest: \(A = P\left(1 + \frac{r}{n}\right)^{nt}\)
  • Continuous Compounding: \(A = Pe^{rt}\)
  • Population Growth: \(P(t) = P_0 e^{kt}\)
  • Radioactive Decay: \(N(t) = N_0 e^{-\lambda t}\)
Example 4.1: A population of bacteria doubles every 3 hours. If there are initially 1000 bacteria, find the population after 12 hours.

Solution: \(P(t) = 1000 \cdot 2^{t/3} = 1000 \cdot e^{(t/3)\ln 2}\). After 12 hours: \(P(12) = 1000 \cdot 2^4 = 16000\).

5. Inverse Functions and Logarithms

Definition: Inverse Function Two functions \(f\) and \(g\) are inverses if \(f(g(x)) = x\) and \(g(f(x)) = x\) for all \(x\) in their domains. We write \(g = f^{-1}\).

5.1 Finding Inverse Functions

To find the inverse of \(y = f(x)\):

  1. Swap \(x\) and \(y\): \(x = f(y)\)
  2. Solve for \(y\) in terms of \(x\)
  3. Verify that \(f(f^{-1}(x)) = x\) and \(f^{-1}(f(x)) = x\)
Example 5.1: Find the inverse of \(f(x) = 2x + 3\).

Solution: \(y = 2x + 3\), swap: \(x = 2y + 3\), solve: \(y = \frac{x-3}{2}\). So \(f^{-1}(x) = \frac{x-3}{2}\).

5.2 Horizontal Line Test

Horizontal Line Test: A function \(f\) has an inverse if and only if every horizontal line intersects the graph of \(f\) at most once.

5.3 Logarithm Definition and Properties

Definition: Logarithm The logarithm \(\log_a x\) is the inverse of the exponential function \(a^x\). That is, \(y = \log_a x\) means \(a^y = x\).

Key properties of logarithms:

  • \(\log_a(xy) = \log_a x + \log_a y\)
  • \(\log_a\left(\frac{x}{y}\right) = \log_a x - \log_a y\)
  • \(\log_a(x^r) = r\log_a x\)
  • \(\log_a a = 1\) and \(\log_a 1 = 0\)
  • \(\log_{a^r} x = \frac{1}{r} \log_a x\)

5.4 Natural Logarithm

Natural Logarithm: The natural logarithm \(\ln x = \log_e x\) has derivative \(\frac{d}{dx}\ln x = \frac{1}{x}\).

5.5 Applications of Logarithms

  • pH Scale: \(pH = -\log[H^+]\)
  • Richter Scale: \(M = \log\frac{A}{A_0}\)
  • Decibels: \(dB = 10\log\frac{I}{I_0}\)
