Problem Set 2: Predicate Logic and Quantifiers

Introduction to Proofs - Lecture 2 Medium

Try each problem before reading the solutions. A proof is judged by the completeness of its logical chain, not by how short it is. State your assumptions, justify every nontrivial step, and verify that the conclusion follows exactly.

Problems

Problem 1

Let the domain be \(\mathbb{Z}\). Symbolise and determine the truth value: "For every integer \(n\), there is an integer \(m\) with \(n<m\)."

Problem 2

Negate each statement and simplify: (a) \(\forall x\in\mathbb{R}\,(x^2>0)\); (b) \(\exists n\in\mathbb{N}\,(n^2=2)\); (c) \(\forall x\,\exists y\,(x\cdot y=1)\) over \(\mathbb{R}\).

Problem 3

Write \(\exists!x\in\mathbb{R}\,(x^2=4)\) in fully expanded form and determine whether it is true.

Problem 4

Prove that \( eg\exists x\,P(x)\equiv\forall x\, eg P(x)\) for a nonempty domain.

Problem 5

Show that \(\forall x\,\exists y\,(y>x)\) and \(\exists y\,\forall x\,(y>x)\) have different truth values over \(\mathbb{R}\).

Problem 6

Symbolise: "There is exactly one even prime." Use domain \(\mathbb{Z}\) and justify the symbolic form.

Problem 7

Consider the argument: "Some integers are even. Some integers are odd. Therefore some integer is both even and odd." Identify the fallacy.

Problem 8

Prove \(\forall x\,(P(x) o Q(x))\land\exists x\,P(x) o\exists x\,Q(x)\). Explain each quantifier rule you use.

Bonus Problem

Prove that there is exactly one integer \(n\) satisfying \(n+7=4\).
