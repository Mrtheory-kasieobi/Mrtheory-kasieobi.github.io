Solutions: Problem Set 3

Trigonometry - Precalculus 11
Solution 1

Convert \(240°\) to radians: \(240° \cdot \frac{\pi}{180°} = \frac{4\pi}{3}\)

Solution 2

\(\sin \frac{5\pi}{6} = \frac{1}{2}\), \(\cos \frac{5\pi}{6} = -\frac{\sqrt{3}}{2}\), \(\tan \frac{5\pi}{6} = -\frac{\sqrt{3}}{3}\)

Solution 3

\(\sin \theta = \frac{1}{2}\) at \(\theta = 30°\) and \(150°\)

Solution 4

\(c^2 = 8^2 + 10^2 - 2(8)(10)\cos 60° = 64 + 100 - 80 = 84\)

\(c = \sqrt{84} = 2\sqrt{21}\)

Solution 5

\(\cos C = \frac{7^2 + 10^2 - 5^2}{2(7)(10)} = \frac{49 + 100 - 25}{140} = \frac{124}{140} = \frac{31}{35}\)

\(C = \arccos \frac{31}{35}\)

Solution 6

\(\frac{\sin A}{6} = \frac{\sin 45°}{8}\), so \(\sin A = \frac{6 \sin 45°}{8} = \frac{3\sqrt{2}}{8}\)

\(A = \arcsin \frac{3\sqrt{2}}{8}\)

Solution 7

Area = \(\frac{1}{2}(10)(12)\sin 30° = \frac{1}{2}(120)(\frac{1}{2}) = 30\)

Solution 8

\(\sin^2 \theta + \cos^2 \theta = 1\) and \(\tan \theta \cdot \cot \theta = 1\)

Bonus Solutions

Bonus Solution 1

Use Cosine Law: \(a^2 = b^2 + c^2 - 2bc\cos A\), etc.

Angle A ≈ 44.4°, Angle B ≈ 53.1°, Angle C ≈ 82.5°

Bonus Solution 2

\(\theta = \frac{\pi}{4}, \frac{5\pi}{4}\)
