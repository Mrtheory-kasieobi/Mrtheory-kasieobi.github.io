Problem Set 3: Quadratic Functions

Precalculus 11 - Chapter 3 Solutions

Solutions

Problem 1: Graph \(y = (x - 2)^2 + 3\)
This is in vertex form \(y = a(x - h)^2 + k\)
Vertex: \((h, k) = (2, 3)\)
Axis of symmetry: \(x = 2\)
Since \(a = 1 > 0\), parabola opens upward
Answer: Vertex (2, 3), axis \(x = 2\), opens upward
Problem 2: Convert \(y = x^2 - 6x + 5\) to vertex form
Complete the square: \(y = x^2 - 6x + 5\)
Take half of coefficient of x: \(\frac{-6}{2} = -3\), square it: \((-3)^2 = 9\)
\(y = (x^2 - 6x + 9) - 9 + 5\)
\(y = (x - 3)^2 - 4\)
Answer: \(y = (x - 3)^2 - 4\)
Problem 3: Find intercepts of \(y = x^2 - 5x + 6\)
y-intercept: set \(x = 0\), \(y = 0 - 0 + 6 = 6\), so \((0, 6)\)
x-intercepts: set \(y = 0\), \(x^2 - 5x + 6 = 0\)
Factor: \((x - 2)(x - 3) = 0\)
x-intercepts: \(x = 2\) and \(x = 3\), points \((2, 0)\) and \((3, 0)\)
Answer: y-intercept (0, 6), x-intercepts (2, 0) and (3, 0)
Problem 4: Graph \(y = -2(x + 1)^2 - 4\)
Vertex form: \(y = a(x - h)^2 + k\) with \(a = -2\), \(h = -1\), \(k = -4\)
Vertex: \((-1, -4)\)
Axis of symmetry: \(x = -1\)
Since \(a = -2 < 0\), parabola opens downward
Domain: all real numbers \((-\infty, \infty)\)
Range: since opens downward with vertex at \(y = -4\), range is \((-\infty, -4]\)
Answer: Vertex (-1, -4), opens downward, domain: ℝ, range: y ≤ -4
Problem 5: Parabola with vertex (3, -2) through (1, 6)
Use vertex form: \(y = a(x - 3)^2 - 2\)
Substitute (1, 6): \(6 = a(1 - 3)^2 - 2\)
\(6 = a(4) - 2\)
\(8 = 4a\), so \(a = 2\)
Equation: \(y = 2(x - 3)^2 - 2\)
Answer: \(y = 2(x - 3)^2 - 2\)
Problem 6: x-intercepts of \(y = (x - 4)^2 - 9\)
Set \(y = 0\): \((x - 4)^2 - 9 = 0\)
Add 9: \((x - 4)^2 = 9\)
Take square root: \(x - 4 = \pm 3\)
x = 4 + 3 = 7 or x = 4 - 3 = 1
Answer: x-intercepts at x = 1 and x = 7
Problem 7: Find inverse of \(y = x^2 + 4x + 5\)
Complete the square: \(y = (x + 2)^2 + 1\)
Swap x and y: \(x = (y + 2)^2 + 1\)
Solve for y: \(x - 1 = (y + 2)^2\)
\(y + 2 = \pm\sqrt{x - 1}\)
\(y = -2 \pm \sqrt{x - 1}\)
Domain restriction: original function has vertex at (-2, 1), minimum value 1
For inverse to be a function, restrict domain of original to \(x \geq -2\) (right side of vertex)
Answer: \(f^{-1}(x) = -2 + \sqrt{x - 1}\) (with domain \(x \geq 1\))
Problem 8: Ball height \(h(t) = -16t^2 + 32t + 48\)
Maximum height: occurs at vertex of parabola
t-coordinate of vertex: \(t = \frac{-b}{2a} = \frac{-32}{2(-16)} = 1\)
Maximum height: \(h(1) = -16(1)^2 + 32(1) + 48 = -16 + 32 + 48 = 64\)
Time to hit ground: set \(h = 0\), solve \(-16t^2 + 32t + 48 = 0\)
Divide by -16: \(t^2 - 2t - 3 = 0\)
Factor: \((t - 3)(t + 1) = 0\)
t = 3 or t = -1 (reject negative)
Answer: Maximum height 64 ft at t = 1 sec, hits ground at t = 3 sec

Bonus Solutions

Bonus Problem 1: Parabola with x-intercepts -2 and 5 through (1, 6)
Use factored form: \(y = a(x + 2)(x - 5)\)
Substitute (1, 6): \(6 = a(1 + 2)(1 - 5) = a(3)(-4) = -12a\)
\(a = -\frac{1}{2}\)
Equation: \(y = -\frac{1}{2}(x + 2)(x - 5)\)
Answer: \(y = -\frac{1}{2}(x + 2)(x - 5)\)
Bonus Problem 2: Ball with \(h(t) = -16t^2 + 64t + 80\)
Max height at vertex: \(t = \frac{-64}{2(-16)} = 2\)
Max height: \(h(2) = -16(4) + 64(2) + 80 = -64 + 128 + 80 = 144\) ft
Hit ground: \(-16t^2 + 64t + 80 = 0\)
Divide by -16: \(t^2 - 4t - 5 = 0\)
Factor: \((t - 5)(t + 1) = 0\)
t = 5 seconds (reject t = -1)
Answer: Hits ground at t = 5 sec, max height 144 ft
