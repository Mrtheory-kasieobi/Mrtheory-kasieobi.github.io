Problem Set 3: Linear Maps

Linear Algebra Course
Based on Axler's "Linear Algebra Done Right"

Instructions

Solve all problems. Show your work clearly. You may use results from previous lectures.

Problem 3.1

Let \(T: \mathbb{R}^3 \to \mathbb{R}^3\) be defined by \(T(x, y, z) = (x + y, y + z, x + z)\). Find \(\ker T\) and \(\operatorname{range} T\).

Problem 3.2

Show that if \(T \in L(V, W)\) and \(\dim V < \dim W\), then \(T\) cannot be surjective.

Problem 3.3

Let \(T \in L(\mathcal{P}_2(\mathbb{R}), \mathbb{R}^2)\) be defined by \(T(p) = (p(0), p(1))\). Find a basis for \(\ker T\).

Problem 3.4

Prove that the composition of two injective linear maps is injective.

Problem 3.5

Let \(T: \mathbb{R}^2 \to \mathbb{R}^2\) be the reflection across the line \(y = x\). Find the matrix representation of \(T\) with respect to the standard basis.
