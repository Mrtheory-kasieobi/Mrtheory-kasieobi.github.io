Problem Set 1: Real Numbers and Rational Exponents

Precalculus 11 · 8 problems Medium

Problems

Problem 1

Classify each number as natural, whole, integer, rational, or irrational: (a) \(\sqrt{49}\) (b) \(-\frac{8}{3}\) (c) \(0.\overline{6}\) (d) \(\pi\) (e) \(\sqrt{2}\)

Problem 2

Convert to radical form and simplify: (a) \(8^{2/3}\) (b) \(27^{-1/3}\) (c) \(x^{3/2} \cdot x^{1/2}\)

Problem 3

Evaluate: (a) \(\sqrt[3]{125}\) (b) \(16^{3/4}\) (c) \(\frac{1}{\sqrt{8}}\)

Problem 4

Simplify using exponent laws: (a) \(x^{2/3} \cdot x^{1/6}\) (b) \((y^{3/4})^2\) (c) \(\frac{a^{5/2}}{a^{1/2}}\)

Problem 5

Find the domain of \(f(x) = \frac{1}{\sqrt[3]{x-2}}\). Express your answer in interval notation.

Problem 6

Solve for \(x\): \(\sqrt{x + 5} = 3\)

Problem 7

Simplify: \(\frac{x^2 - 25}{x - 5}\) and state the restriction.

Problem 8

Simplify: \(\frac{8^{2/3} \cdot 9^{1/2}}{27^{1/3}}\)

Bonus Problems

Bonus Problem 1 Hard

Simplify the expression \(\frac{\sqrt{18} \cdot \sqrt{2}}{\sqrt{8}}\) using properties of radicals.

Bonus Problem 2 Hard

Find all real values of \(x\) such that \(x^{2/3} = 4\).
