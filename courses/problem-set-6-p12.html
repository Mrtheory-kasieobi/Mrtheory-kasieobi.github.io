Problem Set 6: Trigonometric Identities

Precalculus 12 - Problem Set
Topics: Pythagorean, Sum/Difference, Double-Angle Identities Medium

Problems

Problem 1

Prove: \(\frac{\sin\theta}{1 - \cos\theta} + \frac{1 - \cos\theta}{\sin\theta} = \frac{2}{\sin\theta \csc\theta - \cos\theta \sec\theta}\)

Problem 2

Find \(\cos(15°)\) exactly using difference identities.

Problem 3

If \(\sin(2\theta) = \frac{3}{4}\) and \(\cos(2\theta) = \frac{\sqrt{7}}{4}\), find \(\sin\theta\) and \(\cos\theta\).

Problem 4

Simplify: \(\frac{\sin^2 x - \cos^2 x}{\sin x}\)

Problem 5

Prove: \(\sin(3\theta) = 3\sin\theta - 4\sin^3\theta\) using sum and double angle identities.

Problem 6

Find the exact value of \(\sin(22.5°)\) using half angle identities.

Problem 7

Two waves interfere: \(y_1 = 3\sin(x)\) and \(y_2 = 4\cos(x)\). Find the amplitude and phase of the resultant wave.

Problem 8

Prove: \(\frac{1 + \tan^2\theta}{1 + \cot^2\theta} = \tan^2\theta\)

Bonus Problems

Bonus Problem 1

Find all values of \(\theta\) for which \(\sin(3\theta) = \cos(3\theta)\) in the interval \([0, 2\pi)\).

Bonus Problem 2

Prove: \(\cos(5\theta) = 16\cos^5\theta - 20\cos^3\theta + 5\cos\theta\) using De Moivre's theorem.
