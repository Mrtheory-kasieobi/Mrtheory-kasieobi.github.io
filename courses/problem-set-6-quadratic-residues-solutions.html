Solutions: Problem Set 6: Quadratic Residues and the Legendre Symbol

Elementary Number Theory - Week 7 Solutions

Key Definitions and Concepts

Quadratic Residue

For prime \(p\), an integer \(a\) is a quadratic residue mod \(p\) if \(x^2 \equiv a \pmod{p}\) has a solution.

Notation: \(\left(\frac{a}{p}\right) = 1\) if \(a\) is a QR mod \(p\), \(-1\) if not, \(0\) if \(p \mid a\).

Legendre Symbol Properties

\(\left(\frac{a}{p}\right) = \left(\frac{b}{p}\right)\) if \(a \equiv b \pmod{p}\)

\(\left(\frac{ab}{p}\right) = \left(\frac{a}{p}\right)\left(\frac{b}{p}\right)\)

\(\left(\frac{a^2}{p}\right) = 1\) for \(p \nmid a\)

Problem 2: Compute \(\left(\frac{2}{p}\right)\) for odd prime \(p\).

Theorem (First Supplement to Quadratic Reciprocity):

\[\left(\frac{2}{p}\right) = (-1)^{\frac{p^2-1}{8}} = \begin{cases} 1 & p \equiv \pm 1 \pmod{8} \\ -1 & p \equiv \pm 3 \pmod{8} \end{cases}\]

Answer: 2 is a QR mod \(p\) iff \(p \equiv 1\) or \(7 \pmod{8}\).

Problem 3: Compute \(\left(\frac{3}{17}\right)\) using the Legendre symbol properties.

Step 1: Apply Quadratic Reciprocity.

Since \(3 \equiv 3 \pmod{4}\) and \(17 \equiv 1 \pmod{4}\):
\[\left(\frac{3}{17}\right) = \left(\frac{17}{3}\right)\]

Step 2: Reduce 17 mod 3.
\[17 \equiv 2 \pmod{3}\]
\[\left(\frac{17}{3}\right) = \left(\frac{2}{3}\right)\]

Step 3: Apply the supplement for 2.

Since \(3 \equiv 3 \pmod{8}\): \(\left(\frac{2}{3}\right) = -1\)

Answer: \(\left(\frac{3}{17}\right) = -1\), so 3 is a quadratic non-residue mod 17.

Problem 4: Prove: \(\left(\frac{-1}{p}\right) = (-1)^{\frac{p-1}{2}}\) for odd prime \(p\).

Proof:

By Euler's criterion: \(\left(\frac{-1}{p}\right) \equiv (-1)^{\frac{p-1}{2}} \pmod{p}\).

Using Euler's criterion directly:

\[(-1)^{\frac{p-1}{2}} \equiv \left(\frac{-1}{p}\right) \pmod{p}\]

Since both sides are \(\pm 1\) and \(p > 2\), we have equality.

Geometric interpretation: \(\left(\frac{-1}{p}\right) = 1\) iff \((-1)\) is a square mod \(p\).

This happens iff there exists \(x\) with \(x^2 \equiv -1 \pmod{p}\), which requires \(p \equiv 1 \pmod{4}\).

Bonus Solutions

Bonus Problem 1: Prove Euler's Criterion: \(\left(\frac{a}{p}\right) \equiv a^{\frac{p-1}{2}} \pmod{p}\).

Proof:

Case 1: \(p \mid a\).

Then \(\left(\frac{a}{p}\right) = 0 = a^{\frac{p-1}{2}} \pmod{p}\).

Case 2: \(a\) is a quadratic residue.

So \(x^2 \equiv a \pmod{p}\) has a solution \(x\).
\[a^{\frac{p-1}{2}} \equiv (x^2)^{\frac{p-1}{2}} = x^{p-1} \equiv 1 \pmod{p}\]
Thus \(\left(\frac{a}{p}\right) = 1\).

Case 3: \(a\) is a quadratic non-residue.

The polynomial \(x^2 - a\) has no roots mod \(p\), so it's a product of irreducible polynomials.

In \(\mathbb{F}_p[x]\), every element of \(\mathbb{F}_p^*\) is a square or non-square.
For non-residues, \(a^{\frac{p-1}{2}} \equiv -1 \pmod{p}\), so \(\left(\frac{a}{p}\right) = -1\).

Bonus Problem 2: Use the law of quadratic reciprocity to determine if 41 is a quadratic residue mod 73.
Compute \(\left(\frac{41}{73}\right)\):

Both 41 and 73 are primes, and both are \(\equiv 1 \pmod{4}\), so:
\[\left(\frac{41}{73}\right) = \left(\frac{73}{41}\right)\]
\[73 \equiv 73 - 41 \times 1 = 32 \not\equiv 73 \pmod{41}\]
Actually \(73 = 41 \times 1 + 32\), and \(32 = 41 - 9\), but let's compute directly:
\[73 \div 41 = 1 \text{ remainder } 32\]
\[\left(\frac{73}{41}\right) = \left(\frac{32}{41}\right) = \left(\frac{2}{41}\right)^5\]

Compute \(\left(\frac{2}{41}\right)\):

41 ≡ 1 (mod 8), so \(\left(\frac{2}{41}\right) = 1\).
Thus \(\left(\frac{32}{41}\right) = 1^5 = 1\).

Answer: 41 is a quadratic residue mod 73.
