Solutions: Problem Set 6: Quadratic Residues

Solutions

Problem 1

Solution: Compute \(1^2, 2^2, \ldots, 5^2 \pmod{11}\): 1, 4, 9, 5, 3. So 3 is a quadratic residue.

Problem 2

Solution: By Euler's criterion: \(\left(\frac{5}{7}\right) \equiv 5^3 = 125 \equiv 6 \pmod{7}\), so the symbol equals -1.

Problem 3

Solution: Compute \(1^2, 2^2, \ldots, 6^2 \pmod{13}\): 1, 4, 9, 3, 12, 10. Residues are 1, 3, 4, 9, 10, 12.

Problem 4

Solution: \(\left(\frac{-1}{p}\right) = (-1)^{\frac{p-1}{2}}\). Equals 1 if \(p \equiv 1 \pmod{4}\), -1 if \(p \equiv 3 \pmod{4}\).

Problem 5

Solution: If \(p \equiv 1 \pmod{4}\), then \(\frac{p-1}{2}\) is even, so \(\left(\frac{-1}{p}\right) = 1\).

Problem 6

Solution: \(\left(\frac{2}{p}\right) = (-1)^{\frac{p^2-1}{8}}\). Equals 1 when \(p \equiv \pm 1 \pmod{8}\), -1 when \(p \equiv \pm 3 \pmod{8}\).

Problem 7

Solution: \(6^2 = 36 \equiv 7 \pmod{29}\). Solutions: \(x \equiv \pm 6 \pmod{29}\).

Problem 8

Solution: By Euler's criterion: \(\left(\frac{ab}{p}\right) \equiv (ab)^{\frac{p-1}{2}} = a^{\frac{p-1}{2}} b^{\frac{p-1}{2}} \equiv \left(\frac{a}{p}\right)\left(\frac{b}{p}\right) \pmod{p}\).

Problem 9

Solution: \(\left(\frac{3}{17}\right) = -\left(\frac{17}{3}\right) = -\left(\frac{2}{3}\right) = -(-1) = 1\).

Problem 10

Solution: \(\left(\frac{a^2}{p}\right) = \left(\frac{a}{p}\right)^2 = 1\) since the Legendre symbol is \(\pm 1\).

Bonus Problems

Bonus Problem 1

Solution:

Step 1: We want the last two digits of \(7^{100}\), i.e., compute \(7^{100} \pmod{100}\).

Step 2: Note that \(100 = 4 \cdot 25\). Use CRT.

Step 3: \(7^{100} \equiv 1 \pmod{4}\) (since \(7 \equiv 3 \pmod{4}\), \(3^2 \equiv 1\)).

Step 4: \(\phi(25) = 20\), so \(7^{20} \equiv 1 \pmod{25}\), thus \(7^{100} \equiv 1 \pmod{25}\).

Step 5: By CRT, \(7^{100} \equiv 1 \pmod{100}\). Last two digits: 01.

Bonus Problem 2

Solution:

Step 1: Prove by induction on \(n\).

Step 2: Base case \(n=1\): \(a^1 \equiv b^1 \pmod{m}\).

Step 3: Inductive step: Assume \(a^n \equiv b^n\). Then \(a^{n+1} = a^n \cdot a \equiv b^n \cdot b = b^{n+1} \pmod{m}\).

Bonus Problem 3

Solution:

Step 1: Suppose \(x^2 \equiv a \pmod{p}\) has solution \(r\).

Step 2: Then \(x^2 - r^2 \equiv 0 \pmod{p}\), so \((x-r)(x+r) \equiv 0 \pmod{p}\).

Step 3: Since \(p\) is prime, \(x \equiv \pm r \pmod{p}\). At most 2 solutions.
