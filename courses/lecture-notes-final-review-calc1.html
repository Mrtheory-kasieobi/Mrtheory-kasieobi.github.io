1. Derivative Formulas (Memorize)

\(\frac{d}{dx}[x^n] = nx^{n-1}\) \(\frac{d}{dx}[\sin x] = \cos x\) \(\frac{d}{dx}[\cos x] = -\sin x\)
\(\frac{d}{dx}[e^x] = e^x\) \(\frac{d}{dx}[\ln x] = \frac{1}{x}\) \(\frac{d}{dx}[\tan x] = \sec^2 x\)
\(\frac{d}{dx}[\sin^{-1}x] = \frac{1}{\sqrt{1-x^2}}\) \(\frac{d}{dx}[\tan^{-1}x] = \frac{1}{1+x^2}\) \(\frac{d}{dx}[a^x] = a^x \ln a\)

2. Integration Formulas (Memorize)

\(\int x^n \, dx = \frac{x^{n+1}}{n+1} + C\) \(\int \frac{1}{x} \, dx = \ln|x| + C\) \(\int e^x \, dx = e^x + C\)
\(\int \sin x \, dx = -\cos x + C\) \(\int \cos x \, dx = \sin x + C\) \(\int \sec^2 x \, dx = \tan x + C\)
\(\int \frac{1}{\sqrt{1-x^2}} \, dx = \sin^{-1}x + C\) \(\int \frac{1}{1+x^2} \, dx = \tan^{-1}x + C\) \(\int a^x \, dx = \frac{a^x}{\ln a} + C\)

3. Problem-Solving Strategy

General Approach for Word Problems:
  1. Draw a diagram and label all quantities
  2. Identify variables and determine which are changing
  3. Write an equation relating the variables
  4. Differentiate with respect to time (for related rates)
  5. Substitute known values and solve for the unknown
Check units and verify your answer makes sense.

4. Practice Problems

Problem 1: A ladder 10 ft long leans against a wall. If the bottom slides away at 2 ft/s, how fast is the top sliding down when the bottom is 6 ft from the wall?

Solution: \(x^2 + y^2 = 100\). Differentiate: \(2x\frac{dx}{dt} + 2y\frac{dy}{dt} = 0\)

When \(x = 6\), \(y = 8\). \(\frac{dy}{dt} = -\frac{x}{y}\frac{dx}{dt} = -\frac{6}{8}(2) = -\frac{3}{2}\) ft/s

Problem 2: Find the area between \(y = x^3\) and \(y = x\).

Intersections: \(x^3 = x \Rightarrow x = -1, 0, 1\)

Area = \(\int_{-1}^0 (x - x^3) \, dx + \int_0^1 (x^3 - x) \, dx\)

= \(\left[\frac{x^2}{2} - \frac{x^4}{4}\right]_{-1}^0 + \left[\frac{x^4}{4} - \frac{x^2}{2}\right]_0^1\)

= \(-\frac{1}{4} + \frac{1}{4} = \frac{1}{2}\)

Problem 3: Evaluate \(\int_0^{\pi/4} \frac{\tan x}{\cos^2 x} \, dx\).

Rewrite: \(\int_0^{\pi/4} \tan x \sec^2 x \, dx\)

Let \(u = \tan x\), \(du = \sec^2 x \, dx\)

When \(x = 0\), \(u = 0\); when \(x = \pi/4\), \(u = 1\)

Result: \(\int_0^1 u \, du = \frac{1}{2}\)

5. Final Exam Tips

Exam Strategy:
  • Time management: Spend ~2-3 min per problem on multiple choice, ~10-15 min per free response
  • Show all work: Partial credit is given for correct setup even if arithmetic is wrong
  • Check your work: Differentiate antiderivatives to verify; check that related rates make sense
  • Use calculator wisely: Only for checking, not for solving
  • Read carefully: Pay attention to what is asked for

6. Key Theorems to Know

Extreme Value Theorem: Continuous function on closed interval has max and min.
Fermat's Theorem: Local extrema occur at critical points.
Mean Value Theorem: \(\exists c\) with \(f'(c) = \frac{f(b)-f(a)}{b-a}\).
Intermediate Value Theorem: Continuous function takes all values between \(f(a)\) and \(f(b)\).
Fundamental Theorem of Calculus: \(\int_a^b f = F(b) - F(a)\) where \(F' = f\).
