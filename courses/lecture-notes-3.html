Lecture 3: Introduction to Congruences

Lecture 3Introduction to Congruences

1. Definition and Basic Properties

Definition 3.1 (Congruence) Let \(a, b, n\) be integers with \(n > 0\). We say that \(a\) is congruent to \(b\) modulo \(n\), written: \[a \equiv b \pmod{n}\] if \(n \mid (a - b)\), i.e., if \(a - b = kn\) for some integer \(k\).
Example 3.1 Verify the following congruences:
  • \(17 \equiv 5 \pmod{12}\) since \(17 - 5 = 12 = 1 \cdot 12\) ✓
  • \(-7 \equiv 5 \pmod{12}\) since \(-7 - 5 = -12 = -1 \cdot 12\) ✓
  • \(100 \equiv 1 \pmod{99}\) since \(100 - 1 = 99 = 1 \cdot 99\) ✓
Theorem 3.1 (Equivalence Relation) Congruence modulo \(n\) is an equivalence relation on \(\mathbb{Z}\).
Proof:
Reflexivity: For any \(a\), we have \(a - a = 0 = 0 \cdot n\), so \(a \equiv a \pmod{n}\).
Symmetry: If \(a \equiv b \pmod{n}\), then \(n \mid (a - b)\). Thus \(a - b = kn\) for some \(k\), so \(b - a = -kn\), meaning \(n \mid (b - a)\). Therefore \(b \equiv a \pmod{n}\).
Transitivity: If \(a \equiv b \pmod{n}\) and \(b \equiv c \pmod{n}\), then \(n \mid (a - b)\) and \(n \mid (b - c)\). Thus \(a - b = kn\) and \(b - c = \ell n\). Adding: \((a - b) + (b - c) = a - c = (k + \ell)n\), so \(n \mid (a - c)\). Therefore \(a \equiv c \pmod{n}\).

2. Residue Classes and Modular Arithmetic

Definition 3.2 (Residue Class) For a fixed positive integer \(n\), the residue class of \(a\) modulo \(n\) is the set: \[[a]_n = \{x \in \mathbb{Z} : x \equiv a \pmod{n}\} = \{a + kn : k \in \mathbb{Z}\}\]
Definition 3.3 (Reduced Residue System) A set \(\{r_1, r_2, \ldots, r_{\phi(n)}\}\) of integers is called a reduced residue system modulo \(n\) if:
  1. \(\gcd(r_i, n) = 1\) for all \(i\)
  2. Every integer coprime to \(n\) is congruent to exactly one \(r_i\) modulo \(n\)
Example 3.2 Find a reduced residue system modulo 8.

The integers coprime to 8 are those not divisible by 2. A reduced residue system is: \(\{1, 3, 5, 7\}\).

We verify: \(\phi(8) = 4\) and each element is coprime to 8. ✓

3. Properties of Congruences

Theorem 3.2 (Properties of Congruences) Let \(a \equiv b \pmod{n}\) and \(c \equiv d \pmod{n}\). Then:
  1. \(a + c \equiv b + d \pmod{n}\)
  2. \(ac \equiv bd \pmod{n}\)
  3. \(a^k \equiv b^k \pmod{n}\) for any positive integer \(k\)
Proof of (2):
Setup: We have \(a \equiv b \pmod{n}\) and \(c \equiv d \pmod{n}\).
Step 1: From \(a \equiv b \pmod{n}\), we have \(a - b = kn\) for some integer \(k\).
Step 2: From \(c \equiv d \pmod{n}\), we have \(c - d = \ell n\) for some integer \(\ell\).
Step 3: Consider \(ac - bd\): \[ac - bd = ac - bc + bc - bd = c(a - b) + b(c - d) = c(kn) + b(\ell n) = (ck + b\ell)n\]

Therefore \(n \mid (ac - bd)\), so \(ac \equiv bd \pmod{n}\). \(\square\)

4. The Division Algorithm in Modular Arithmetic

Theorem 3.3 (Division Algorithm) For any integers \(a\) and \(n\) with \(n > 0\), there exist unique integers \(q\) and \(r\) such that: \[a = qn + r \quad \text{where} \quad 0 \leq r < n\] In modular arithmetic, this means \(a \equiv r \pmod{n}\).
Definition 3.4 (Least Nonnegative Residue) For any integer \(a\) and positive integer \(n\), the unique integer \(r\) with \(0 \leq r < n\) and \(a \equiv r \pmod{n}\) is called the least nonnegative residue of \(a\) modulo \(n\). We write \(r = a \mod n\).
Example 3.3 Find the least nonnegative residue of:
  • \(1234 \mod 7\): Divide \(1234 = 176 \cdot 7 + 2\), so \(1234 \equiv 2 \pmod{7}\)
  • \(-45 \mod 8\): We need \(r\) such that \(-45 \equiv r \pmod{8}\) with \(0 \leq r < 8\). Since \(-45 = -6 \cdot 8 + 3\), we have \(-45 \equiv 3 \pmod{8}\)
  • \(2^{10} \mod 7\): Using repeated squaring: \(2^2 \equiv 4\), \(2^4 \equiv 16 \equiv 2\), \(2^8 \equiv 4\), so \(2^{10} = 2^8 \cdot 2^2 \equiv 4 \cdot 4 = 16 \equiv 2 \pmod{7}\)

5. Linear Congruences

Definition 3.5 (Linear Congruence) A linear congruence in the unknown \(x\) has the form: \[ax \equiv b \pmod{n}\] where \(a, b, n\) are given integers with \(n > 0\).
Theorem 3.4 (Solution of Linear Congruence) The linear congruence \(ax \equiv b \pmod{n}\) has:
  • No solutions if \(\gcd(a, n) \nmid b\)
  • Exactly \(\gcd(a, n)\) solutions modulo \(n\) if \(\gcd(a, n) \mid b\)
Example 3.4 Solve \(6x \equiv 9 \pmod{15}\).
Step 1: Check solvability

\(\gcd(6, 15) = 3\) and \(3 \mid 9\), so solutions exist.

Step 2: Simplify

Divide the congruence by 3: \(2x \equiv 3 \pmod{5}\)

Step 3: Find multiplicative inverse

We need \(2^{-1} \pmod{5}\). Since \(2 \cdot 3 = 6 \equiv 1 \pmod{5}\), we have \(2^{-1} \equiv 3 \pmod{5}\).

Step 4: Solve

\(x \equiv 3 \cdot 3 = 9 \equiv 4 \pmod{5}\)

The solutions modulo 15 are: \(x \equiv 4, 9, 14 \pmod{15}\)

Exercises:
  1. Verify that \(23 \equiv 5 \pmod{9}\) and \(5 \equiv 23 \pmod{9}\)
  2. Find the least nonnegative residue of \(7^{50} \mod 10\)
  3. Solve the congruence \(5x \equiv 3 \pmod{7}\)
  4. Show that if \(a \equiv b \pmod{n}\) then \(a^k \equiv b^k \pmod{n}\) for all \(k \geq 1\)
  5. Find all solutions to \(8x \equiv 12 \pmod{20}\)
  6. Prove that if \(a \equiv b \pmod{n}\) and \(c \equiv d \pmod{n}\), then \(a + c \equiv b + d \pmod{n}\)
  7. Determine which of the following are valid congruences: \(15 \equiv 3 \pmod{6}\), \(20 \equiv 8 \pmod{4}\), \(-5 \equiv 3 \pmod{4}\)
  8. Find a reduced residue system modulo 12
