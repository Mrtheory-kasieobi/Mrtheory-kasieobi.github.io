Linear Algebra Course
Based on Axler's "Linear Algebra Done Right"

Problem Set 1: Vector Spaces and Subspaces

Problem Set 1

Easy

Topics: Vector spaces, subspaces, subspace test

Problem 1.1: Show that the set of all solutions to a homogeneous system of linear equations forms a subspace of \(\mathbb{R}^n\).

Problem 1.2: Determine whether the following sets are subspaces of \(\mathbb{R}^3\):

  • \(S_1 = \{(x, y, z) : x + y + z = 0\}\)
  • \(S_2 = \{(x, y, z) : x \geq 0\}\)
  • \(S_3 = \{(x, y, z) : x^2 + y^2 + z^2 = 1\}\)

Problem 1.3: Show that the set of all polynomials \(p \in \mathcal{P}(\mathbb{R})\) such that \(p(0) = 0\) is a subspace.

Problem Set 2: Linear Independence and Bases

Problem Set 2

Easy

Topics: Linear independence, span, basis

Problem 2.1: Determine if the vectors \{(1, 2, 3), (4, 5, 6), (7, 8, 9)\}\) in \(\mathbb{R}^3\) are linearly independent.

Problem 2.2: Find a basis for the subspace \(W = \{(x, y, z) \in \mathbb{R}^3 : 2x - y + 3z = 0\}\).

Problem 2.3: Show that \{1, x, x^2, x^3\}\) is a basis for \(\mathcal{P}_3(\mathbb{R})\).

Problem Set 3: Linear Maps

Problem Set 3

Easy

Topics: Linear maps, null space, range

Problem 3.1: Let \(T: \mathbb{R}^3 \to \mathbb{R}^2\) be defined by \(T(x, y, z) = (x + y, y + z)\). Find \(\ker T\) and \(\operatorname{range} T\).

Problem 3.2: Show that the composition of two linear maps is linear.

Problem 3.3: Find the matrix representation of the derivative operator \(D: \mathcal{P}_2(\mathbb{R}) \to \mathcal{P}_1(\mathbb{R})\) with respect to standard bases.

Problem Set 4: Eigenvalues and Eigenvectors

Problem Set 4

Medium

Topics: Eigenvalues, eigenvectors, diagonalization

Problem 4.1: Find all eigenvalues and eigenvectors of \(A = \begin{pmatrix} 3 & 1 \\ 0 & 3 \end{pmatrix}\).

Problem 4.2: Determine if \(A = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}\) is diagonalizable.

Problem 4.3: Find an invertible matrix \(P\) such that \(P^{-1} \begin{pmatrix} 4 & -2 \\ 1 & 1 \end{pmatrix} P\) is diagonal.

Problem Set 5: Inner Product Spaces

Problem Set 5

Medium

Topics: Inner products, orthogonality, projections

Problem 5.1: Verify that \(\langle f, g \rangle = \int_0^1 f(x)g(x) dx\) is an inner product on \(C[0, 1]\).

Problem 5.2: Find the orthogonal projection of \(f(x) = x\) onto \(\operatorname{span}\{1\}\) in \(C[0, 1]\).

Problem 5.3: Apply Gram-Schmidt to \{1, x\}\) in \(C[0, 1]\) to obtain an orthonormal basis.
