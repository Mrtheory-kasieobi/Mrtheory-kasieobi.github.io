Lecture 7: Systems of Linear Equations

Mathematics 10 - Chapter 7

7.1 Solving Systems by Graphing

A system of linear equations is a pair (or more) of linear equations using the same variables. Each equation graphs as a straight line, and every point on that line is a solution of that equation.

What the intersection means: The solution of the system is the point that lies on both lines at once. Its coordinates make both equations true at the same time, and no other point does.

Vocabulary: The pair of equations is called a system. An ordered pair \((x, y)\) that makes every equation true is a solution. Finding all such pairs is called solving the system.

Checking a proposed solution: Substitute the coordinates into both equations. For \(x + y = 6\) and \(x - y = -2\), test \((2, 4)\):

First equation: \(2 + 4 = 6\) ✓. Second equation: \(2 - 4 = -2\) ✓. Both statements are true, so \((2, 4)\) is a solution.

Why Systems Matter: Many real-world problems have two conditions to satisfy at once. If you have $100 to spend on two types of items, your choice must fit both your budget and your needs. That is a system of equations.

Making a table for each line: Pick a few \(x\)-values, compute \(y\) from each equation, and record the pairs in a table. Plot each line through its own points. Where the two tables give the same \(y\) for the same \(x\), you have found the intersection.

Types of Solutions

One solution: The lines cross once. Their slopes are different, so exactly one point works in both equations.

No solution: The lines are parallel. They have the same slope but different \(y\)-intercepts, so they never meet.

Infinitely many solutions: The two equations describe the same line. Every point on that line works in both.

Connecting tables to these cases: If the two tables never share a \(y\) for the same \(x\), the lines are parallel and there is no solution. If the tables match for every \(x\), the lines are the same and there are infinitely many solutions.

Example 1: Graphing a System

Solve by graphing: \(y = 2x + 1\) and \(y = -x + 4\)

First line: Start at the \(y\)-intercept \((0, 1)\). A slope of \(2\) means "up 2, right 1," which lands on \((1, 3)\).

Second line: Start at \((0, 4)\). A slope of \(-1\) means "down 1, right 1," which also lands on \((1, 3)\).

Both lines pass through \((1, 3)\), so that is their intersection.

Check the first equation: \(2(1) + 1 = 3\) ✓

Check the second: \(-(1) + 4 = 3\) ✓

The solution is \((1, 3)\): it satisfies both equations at the same time.

Motivation: If one line shows revenue and the other shows cost, their intersection is the break-even point.

7.2 Solving Systems by Substitution

Substitution means replacing a variable with an equal expression. If \(y = 3x - 2\), then anywhere you see \(y\) in the other equation you may write \(3x - 2\) instead. The pair of equations becomes one equation with only \(x\), which you already know how to solve.

When to Use Substitution: Use it when one equation is already solved for a variable, or when a coefficient is \(1\) or \(-1\) so solving for that variable is easy.

Substitution Method Steps
  1. Solve one equation for one variable, if needed
  2. Substitute that expression into the other equation
  3. Solve the new equation for the single variable
  4. Substitute back to find the first variable
  5. Check the pair in both original equations
Example 2: Substitution Method

Solve: \(y = 3x - 2\) and \(2x + y = 8\)

Replace \(y\) in the second equation: \(2x + (3x - 2) = 8\)

Combine like terms: \(5x - 2 = 8\)

Add 2 to both sides: \(5x = 10\), so \(x = 2\)

Substitute back: \(y = 3(2) - 2 = 4\)

The solution is \((2, 4)\)

Check: \(3(2) - 2 = 4\) ✓ and \(2(2) + 4 = 8\) ✓

Motivation: This is handy for mixtures: two amounts are linked by a total amount and a total value, so one quantity can replace the other.

Example: Substitution with \(x\) Already Isolated

Solve: \(x = y + 1\) and \(2x + y = 8\)

Substitute \(y + 1\) for \(x\) in the second equation: \(2(y + 1) + y = 8\)

Distribute: \(2y + 2 + y = 8\), so \(3y + 2 = 8\)

Subtract 2: \(3y = 6\), so \(y = 2\)

Substitute back: \(x = 2 + 1 = 3\)

The solution is \((3, 2)\)

Check: \(3 = 2 + 1\) ✓ and \(2(3) + 2 = 8\) ✓

7.3 Solving Systems by Elimination

Elimination means adding (or subtracting) two equations so that one variable cancels. You can also multiply an entire equation by a number first, because multiplying both sides by the same number keeps the equality true.

Why Elimination Works: If \(a = b\) and \(c = d\), then \(a + c = b + d\). Choosing equations whose coefficients are opposites makes one variable disappear when you add.

Elimination Method Steps
  1. Multiply one or both equations to make one pair of coefficients opposite
  2. Add the equations so that variable cancels
  3. Solve the remaining one-variable equation
  4. Substitute back to find the other variable
  5. Check the pair in both original equations
Example 3: Elimination Method

Solve: \(3x + 2y = 12\) and \(5x - 2y = 8\)

The \(+2y\) and \(-2y\) are opposites, so add the equations:

\((3x + 2y) + (5x - 2y) = 12 + 8\)

\(8x = 20\), so \(x = \frac{20}{8} = 2.5\)

Substitute into the first equation: \(3(2.5) + 2y = 12\)

\(7.5 + 2y = 12\), so \(2y = 4.5\) and \(y = 2.25\)

The solution is \((2.5, 2.25)\)

Check: \(3(2.5) + 2(2.25) = 12\) ✓

Also \(5(2.5) - 2(2.25) = 8\) ✓

Motivation: Use elimination whenever two amounts combine into totals — for example, finding two prices from the cost of two different purchases.

Example: Elimination After Multiplying

Solve: \(2x + 3y = 7\) and \(3x - 2y = 4\)

No coefficients match, so multiply to make the \(y\)-terms opposites.

Multiply the first equation by \(2\): \(4x + 6y = 14\)

Multiply the second equation by \(3\): \(9x - 6y = 12\)

Add: \(13x = 26\), so \(x = 2\)

Substitute into \(2x + 3y = 7\): \(2(2) + 3y = 7\), so \(3y = 3\) and \(y = 1\)

The solution is \((2, 1)\)

Verify: \(2(2) + 3(1) = 7\) ✓ and \(3(2) - 2(1) = 4\) ✓

7.4 Solving Systems with Fractions and Decimals

Fractions and decimals make arithmetic messy, but you can remove them. Multiply every term of an equation by the same nonzero number and the equation keeps exactly the same solutions.

Strategy: For fractions, multiply by the lowest common denominator (LCD) of the fractions in that equation. For decimals, multiply by \(10\), \(100\), and so on. Then solve the integer system with substitution or elimination.

Clear denominators first: Before using substitution or elimination, multiply each equation by a nonzero number that removes its fractions or decimals. Multiply every term, including the constant on the right, or the equation changes. Use the lowest common denominator for fractions and a power of \(10\) for decimals.

Example 4: Clearing Fractions

Solve: \(\frac{1}{2}x + \frac{1}{3}y = 2\) and \(\frac{1}{4}x - y = -1\)

The first equation has denominators 2 and 3, so multiply every term by \(6\):

\(6 \times \frac{1}{2}x = 3x\) and \(6 \times \frac{1}{3}y = 2y\), giving \(3x + 2y = 12\)

Multiply the second equation by \(4\): \(x - 4y = -4\)

From \(x - 4y = -4\), we get \(x = 4y - 4\)

Substitute: \(3(4y - 4) + 2y = 12\)

\(12y - 12 + 2y = 12\), so \(14y = 24\) and \(y = \frac{24}{14} = \frac{12}{7}\)

Then \(x = 4\left(\frac{12}{7}\right) - 4 = \frac{48}{7} - \frac{28}{7} = \frac{20}{7}\)

The solution is \(\left(\frac{20}{7}, \frac{12}{7}\right)\)

Check in the first original equation: \(\frac{1}{2}\left(\frac{20}{7}\right) = \frac{10}{7}\) and \(\frac{1}{3}\left(\frac{12}{7}\right) = \frac{4}{7}\)

They add to \(\frac{14}{7} = 2\) ✓

Check in the second original equation: \(\frac{1}{4}\left(\frac{20}{7}\right) - \frac{12}{7} = \frac{5}{7} - \frac{12}{7} = -1\) ✓

Motivation: Problems described in halves, thirds, or percentages become much easier once the fractions are cleared first.

7.5 Real-World Applications of Systems

Real situations often give two facts about the same two unknown quantities. Each fact becomes an equation, and the solution gives the pair of values that satisfies both facts.

Common Applications:

  • Mixture Problems: Finding how much of each solution to mix, using total volume and total amount of solute
  • Investment Problems: Finding amounts invested at different rates, using total invested and total interest
  • Distance Problems: Finding speeds or times using distance = speed \(\times\) time
  • Break-Even Analysis: Finding when revenue equals cost
Example 5: Investment Problem

$5000 is invested in two accounts paying 3% and 5% interest. The total interest is $210. How much is in each account?

Let \(x\) be the amount at 3% and \(y\) the amount at 5%

Total invested: \(x + y = 5000\)

Total interest: \(0.03x + 0.05y = 210\)

Clear decimals by multiplying by \(100\): \(3x + 5y = 21000\)

From \(x + y = 5000\), \(y = 5000 - x\)

Substitute: \(3x + 5(5000 - x) = 21000\)

\(3x + 25000 - 5x = 21000\), so \(-2x = -4000\) and \(x = 2000\)

Then \(y = 5000 - 2000 = 3000\)

So $2000 is at 3% and $3000 is at 5%

Check: \(0.03(2000) + 0.05(3000) = 60 + 150 = 210\) ✓

Motivation: This is how anyone compares options when a total amount and a total return are both fixed.

Break-even means revenue equals cost. Suppose selling \(x\) items brings in \(R = 15x\) dollars, while costs are \(C = 100 + 10x\) dollars (a $100 setup fee plus $10 per item). Setting revenue equal to cost gives \(15x = 100 + 10x\).

Subtract \(10x\): \(5x = 100\), so \(x = 20\). At 20 items, \(R = 15(20) = 300\) and \(C = 100 + 10(20) = 300\). Below 20 items you lose money; above 20 you make a profit.

Common Mistakes:

  • Forgetting to check the solution in both equations; it must satisfy both
  • Sign errors in elimination, such as adding when coefficients are equal instead of opposite
  • Distributing mistakes, such as writing \(2(y + 1) = 2y + 1\) instead of \(2y + 2\)
  • Treating parallel lines as one solution when they have no solution at all

7.6 Comparing Systems by Their Slopes

Changing the coefficients of a system shows what happens to the intersection.

Key Insights: The slopes decide how many solutions exist. Different slopes give one crossing point; equal slopes with different intercepts give no solution; equal slopes and equal intercepts give the same line and infinitely many solutions. Changing a coefficient changes where the lines intersect.

Beginner comparison guide: Write each line as \(y = mx + b\), where \(m\) is the slope and \(b\) is the \(y\)-intercept.

Comparing Slopes and Intercepts

Different slopes (\(m_1 \neq m_2\)): The lines cross exactly once, so there is one solution.

Same slope, different intercepts (\(m_1 = m_2\), \(b_1 \neq b_2\)): Parallel lines never meet, so there is no solution.

Same slope, same intercept (\(m_1 = m_2\), \(b_1 = b_2\)): The lines are identical, so there are infinitely many solutions.

Quick check: Compare \(m\) first, then compare \(b\) only if the slopes match.

7.7 Solving Systems with Three Variables

Extension (beyond Math 10): You will not need this on the Math 10 exam, but the same elimination idea works with three unknowns \(x\), \(y\), and \(z\). The trick is to combine pairs of equations to cancel one variable, leaving a two-variable system you already know how to solve.

Where it appears: Any situation with three linked amounts can be modelled this way, such as combining three ingredients to reach a target total amount, value, and weight. We keep the numbers small so every step stays visible.

Example 6: Three-Variable System (Extension)

Solve this extension system:

\(x + y + z = 6\)

\(2x - y + z = 3\)

\(x + 2y - z = 2\)

Add the first and third equations to cancel \(z\): \(2x + 3y = 8\)

Add the second and third to cancel \(z\): \(3x + y = 5\)

From \(3x + y = 5\), \(y = 5 - 3x\). Substitute into \(2x + 3y = 8\):

\(2x + 3(5 - 3x) = 8\), so \(2x + 15 - 9x = 8\)

\(-7x = -7\), so \(x = 1\) and \(y = 5 - 3(1) = 2\)

Now \(1 + 2 + z = 6\), so \(z = 3\). The solution is \((1, 2, 3)\)

Check the first two: \(1 + 2 + 3 = 6\) ✓ and \(2(1) - 2 + 3 = 3\) ✓

Check the third: \(1 + 2(2) - 3 = 2\) ✓

The method simply repeats: cancel one variable at a time until only one is left.

7.8 Check Your Understanding

Work on a separate page first, then compare your answers below.

  1. Solve \(x + y = 5\) and \(x - y = 1\) by elimination.
  2. Solve \(y = 2x\) and \(x + y = 9\) by substitution.
  3. How many solutions do \(y = 3x + 1\) and \(y = 3x - 2\) have?

Worked answers:

  1. Add the equations: \(2x = 6\), so \(x = 3\). Then \(3 + y = 5\), so \(y = 2\). Check: \(3 + 2 = 5\) ✓ and \(3 - 2 = 1\) ✓.
  2. Replace \(y\): \(x + 2x = 9\), so \(3x = 9\) and \(x = 3\). Then \(y = 2(3) = 6\). Check: \(3 + 6 = 9\) ✓.
  3. The slopes are both \(3\), but the intercepts are \(1\) and \(-2\). The lines are parallel, so there is no solution.

Bonus: Choosing an Efficient Method

Before You Start Solving

Compare the slopes first. Different slopes mean one intersection; matching slopes mean either no solution or infinitely many, depending on the intercepts.

Otherwise, substitute when a variable is already alone, and eliminate when coefficients match or are opposites.

Every method should end at the same point, so check your answer in both equations.
