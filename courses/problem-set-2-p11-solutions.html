Problem Set 1: Sequences and Series

Precalculus 11 - Chapter 1 Solutions

Solutions

Problem 1: Find the 15th term of the arithmetic sequence: 3, 7, 11, 15, ...
First term \(a_1 = 3\), common difference \(d = 7 - 3 = 4\)
Use formula: \(a_n = a_1 + (n-1)d\)
\(a_{15} = 3 + (15-1)(4) = 3 + 14(4) = 3 + 56 = 59\)
Answer: 59
Problem 2: Find the sum of the first 20 terms of the arithmetic sequence: 5, 9, 13, 17, ...
First term \(a_1 = 5\), common difference \(d = 4\), number of terms \(n = 20\)
Use formula: \(S_n = \frac{n}{2}(a_1 + a_n)\)
First find \(a_{20} = 5 + (20-1)(4) = 5 + 76 = 81\)
\(S_{20} = \frac{20}{2}(5 + 81) = 10(86) = 860\)
Answer: 860
Problem 3: Find the 8th term of the geometric sequence: 2, 6, 18, 54, ...
First term \(a_1 = 2\), common ratio \(r = \frac{6}{2} = 3\)
Use formula: \(a_n = a_1 \cdot r^{n-1}\)
\(a_8 = 2 \cdot 3^{8-1} = 2 \cdot 3^7 = 2 \cdot 2187 = 4374\)
Answer: 4374
Problem 4: Find the sum of the first 6 terms of the geometric sequence: 4, 12, 36, 108, ...
First term \(a_1 = 4\), common ratio \(r = 3\), number of terms \(n = 6\)
Use formula: \(S_n = \frac{a_1(r^n - 1)}{r - 1}\) (for \(r \neq 1\))
\(S_6 = \frac{4(3^6 - 1)}{3 - 1} = \frac{4(729 - 1)}{2} = \frac{4(728)}{2} = \frac{2912}{2} = 1456\)
Answer: 1456
Problem 5: Write the first 5 terms of the sequence defined by \(a_n = 2n + 3\). Is this arithmetic or geometric?
\(a_1 = 2(1) + 3 = 5\)
\(a_2 = 2(2) + 3 = 7\)
\(a_3 = 2(3) + 3 = 9\)
\(a_4 = 2(4) + 3 = 11\)
\(a_5 = 2(5) + 3 = 13\)
First 5 terms: 5, 7, 9, 11, 13
Check if arithmetic: \(d = 7-5 = 2\), \(9-7 = 2\), \(11-9 = 2\) - common difference exists
Answer: 5, 7, 9, 11, 13. It is an arithmetic sequence.
Problem 6: Express the sum using sigma notation: \(5 + 10 + 15 + 20 + 25 + 30\)
Notice each term is a multiple of 5: \(5(1), 5(2), 5(3), 5(4), 5(5), 5(6)\)
The pattern is \(5k\) where \(k\) goes from 1 to 6
Answer: \(\sum_{k=1}^{6} 5k\)
Problem 7: Find the sum: \(\sum_{i=1}^{10} (3i - 2)\)
Expand: \((3(1)-2) + (3(2)-2) + ... + (3(10)-2)\)
= \((1) + (4) + (7) + (10) + (13) + (16) + (19) + (22) + (25) + (28)\)
This is arithmetic with \(a_1 = 1\), \(d = 3\), \(n = 10\)
Use formula: \(S_n = \frac{n}{2}(2a_1 + (n-1)d)\)
\(S_{10} = \frac{10}{2}(2(1) + 9(3)) = 5(2 + 27) = 5(29) = 145\)
Answer: 145
Problem 8: An infinite geometric series has first term 8 and common ratio \(\frac{1}{4}\). Find the sum of the series.
For infinite geometric series with \(|r| < 1\): \(S_\infty = \frac{a_1}{1-r}\)
Here \(a_1 = 8\), \(r = \frac{1}{4}\), and \(|r| = \frac{1}{4} < 1\) so the series converges
\(S_\infty = \frac{8}{1 - \frac{1}{4}} = \frac{8}{\frac{3}{4}} = 8 \cdot \frac{4}{3} = \frac{32}{3}\)
Answer: \(\frac{32}{3}\) or approximately 10.67

Bonus Solutions

Bonus Problem 1: Ball distance before 5th bounce
Initial drop: 100 m
Bounce 1 up & down: \(2 \times 100 \times \frac{3}{5} = 120\) m
Bounce 2 up & down: \(2 \times 100 \times (\frac{3}{5})^2 = 72\) m
Bounce 3 up & down: \(2 \times 100 \times (\frac{3}{5})^3 = 43.2\) m
Bounce 4 up & down: \(2 \times 100 \times (\frac{3}{5})^4 = 25.92\) m
Total = 100 + 120 + 72 + 43.2 + 25.92 = 361.12 m
Answer: 361.12 meters
Bonus Problem 2: Find geometric sequence
Given: \(a_4 = ar^3 = 16\) and \(S_4 = a\frac{r^4 - 1}{r - 1} = 30\)
From first: \(a = \frac{16}{r^3}\)
Substitute: \(\frac{16}{r^3} \cdot \frac{r^4 - 1}{r - 1} = 30\)
Simplify: \(\frac{16(r^4 - 1)}{r^3(r - 1)} = 30\)
Factor: \(r^4 - 1 = (r^2 - 1)(r^2 + 1) = (r-1)(r+1)(r^2 + 1)\)
\(\frac{16(r+1)(r^2 + 1)}{r^3} = 30\)
Trial: \(r = 2\) gives \(a = 2\), sequence: 2, 4, 8, 16
Check: \(S_4 = 2 + 4 + 8 + 16 = 30\) ✓
Answer: 2, 4, 8, 16 (with \(a = 2\), \(r = 2\))
