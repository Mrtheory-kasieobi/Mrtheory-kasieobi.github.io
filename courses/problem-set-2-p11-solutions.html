Problem Set 2: Trigonometry

Precalculus 11 - Chapter 2 Solutions

Solutions

Problem 1: Convert \(240°\) to radians
Use conversion: \(180° = \pi\) radians
\(240° = 240° \times \frac{\pi}{180°} = \frac{240\pi}{180} = \frac{4\pi}{3}\)
Answer: \(\frac{4\pi}{3}\) radians
Problem 2: Find \(\sin \frac{5\pi}{6}\), \(\cos \frac{5\pi}{6}\), and \(\tan \frac{5\pi}{6}\)
\(\frac{5\pi}{6}\) is in quadrant II (between \(\frac{\pi}{2}\) and \(\pi\))
Reference angle: \(\pi - \frac{5\pi}{6} = \frac{\pi}{6}\)
\(\sin \frac{5\pi}{6} = \sin \frac{\pi}{6} = \frac{1}{2}\) (positive in QII)
\(\cos \frac{5\pi}{6} = -\cos \frac{\pi}{6} = -\frac{\sqrt{3}}{2}\) (negative in QII)
\(\tan \frac{5\pi}{6} = \frac{\sin}{\cos} = \frac{1/2}{-\sqrt{3}/2} = -\frac{1}{\sqrt{3}} = -\frac{\sqrt{3}}{3}\)
Answer: \(\sin = \frac{1}{2}\), \(\cos = -\frac{\sqrt{3}}{2}\), \(\tan = -\frac{\sqrt{3}}{3}\)
Problem 3: Find all angles \(\theta\) in \([0°, 360°]\) where \(\sin \theta = \frac{1}{2}\)
\(\sin \theta = \frac{1}{2}\) occurs at reference angle \(30°\)
In \([0°, 360°]\), sine is positive in quadrants I and II
Angles: \(\theta = 30°\) (Q I) and \(\theta = 180° - 30° = 150°\) (Q II)
Answer: \(\theta = 30°\) or \(\theta = 150°\)
Problem 4: Find side \(c\) with \(a = 8\), \(b = 10\), \(C = 60°\)
Use Cosine Law: \(c^2 = a^2 + b^2 - 2ab\cos C\)
\(c^2 = 8^2 + 10^2 - 2(8)(10)\cos 60°\)
\(c^2 = 64 + 100 - 160(\frac{1}{2}) = 164 - 80 = 84\)
\(c = \sqrt{84} = \sqrt{4 \times 21} = 2\sqrt{21}\)
Answer: \(c = 2\sqrt{21}\) or approximately 9.17
Problem 5: Find angle \(C\) with \(a = 7\), \(b = 10\), \(c = 5\)
Use Cosine Law: \(c^2 = a^2 + b^2 - 2ab\cos C\)
Solve for \(\cos C\): \(\cos C = \frac{a^2 + b^2 - c^2}{2ab}\)
\(\cos C = \frac{7^2 + 10^2 - 5^2}{2(7)(10)} = \frac{49 + 100 - 25}{140} = \frac{124}{140} = \frac{31}{35}\)
\(C = \arccos(\frac{31}{35}) \approx 26.39°\)
Answer: \(C \approx 26.4°\)
Problem 6: Find angle \(A\) with \(a = 6\), \(b = 8\), \(C = 45°\)
Use Sine Law: \(\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}\)
First find \(c\) using Cosine Law: \(c^2 = 6^2 + 8^2 - 2(6)(8)\cos 45°\)
\(c^2 = 36 + 64 - 96(\frac{\sqrt{2}}{2}) = 100 - 48\sqrt{2}\)
\(c = \sqrt{100 - 48\sqrt{2}} \approx 5.74\)
Use Sine Law: \(\frac{\sin A}{6} = \frac{\sin 45°}{c}\)
\(\sin A = \frac{6 \sin 45°}{c} = \frac{6 \times \frac{\sqrt{2}}{2}}{\sqrt{100 - 48\sqrt{2}}}\)
\(A = \arcsin(\frac{3\sqrt{2}}{\sqrt{100 - 48\sqrt{2}}}) \approx 36.87°\)
Answer: \(A \approx 36.9°\)
Problem 7: Find area with \(a = 10\), \(b = 12\), \(C = 30°\)
Use formula: \(\text{Area} = \frac{1}{2}ab\sin C\)
\(\text{Area} = \frac{1}{2}(10)(12)\sin 30°\)
\(\text{Area} = 60 \times \frac{1}{2} = 30\)
Answer: 30 square units
Problem 8: Simplify trigonometric expressions
First: \(\sin^2 \theta + \cos^2 \theta = 1\) (Pythagorean identity)
Second: \(\tan \theta \cdot \cot \theta = \tan \theta \cdot \frac{1}{\tan \theta} = 1\)
Answer: \(\sin^2 \theta + \cos^2 \theta = 1\) and \(\tan \theta \cdot \cot \theta = 1\)

Bonus Solutions

Bonus Problem 1: Find all angles of triangle with sides 7, 8, 9
Use Cosine Law for each angle
For angle opposite side 7: \(\cos A = \frac{8^2 + 9^2 - 7^2}{2(8)(9)} = \frac{64 + 81 - 49}{144} = \frac{96}{144} = \frac{2}{3}\)
\(A = \arccos(\frac{2}{3}) \approx 48.19°\)
For angle opposite side 8: \(\cos B = \frac{7^2 + 9^2 - 8^2}{2(7)(9)} = \frac{49 + 81 - 64}{126} = \frac{66}{126} = \frac{11}{21}\)
\(B = \arccos(\frac{11}{21}) \approx 58.41°\)
For angle opposite side 9: \(\cos C = \frac{7^2 + 8^2 - 9^2}{2(7)(8)} = \frac{49 + 64 - 81}{112} = \frac{32}{112} = \frac{2}{7}\)
\(C = \arccos(\frac{2}{7}) \approx 73.40°\)
Check: \(48.19° + 58.41° + 73.40° \approx 180°\) ✓
Answer: \(A \approx 48.2°\), \(B \approx 58.4°\), \(C \approx 73.4°\)
Bonus Problem 2: Find \(\theta\) where \(\sin \theta = \cos \theta\) in \([0, 2\pi)\)
Divide both sides by \(\cos \theta\) (assuming \(\cos \theta \neq 0\)): \(\tan \theta = 1\)
\(\theta = \frac{\pi}{4}\) or \(\theta = \frac{5\pi}{4}\) in \([0, 2\pi)\)
Check if \(\cos \theta = 0\) gives solutions: at \(\theta = \frac{\pi}{2}, \frac{3\pi}{2}\), \(\sin \theta = \pm 1\), \(\cos \theta = 0\), so \(\sin \neq \cos\)
Answer: \(\theta = \frac{\pi}{4}, \frac{5\pi}{4}\)
