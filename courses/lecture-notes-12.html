Lecture 12: Linear Diophantine Equations

Lecture 12Linear Diophantine Equations

1. Definition and Basic Theory

Definition 12.1 (Linear Diophantine Equation) An equation of the form: \[ax + by = c\] where \(a, b, c \in \mathbb{Z}\) and we seek integer solutions \((x, y)\), is called a linear Diophantine equation.
Theorem 12.1 (Existence of Solutions) The linear Diophantine equation \(ax + by = c\) has integer solutions if and only if \(\gcd(a, b) \mid c\).
Proof:
(⇒) If solutions exist, then gcd(a,b) | c:

Suppose \(x_0, y_0\) satisfy \(ax_0 + by_0 = c\).

Let \(d = \gcd(a, b)\). Then \(d \mid a\) and \(d \mid b\).

Therefore \(d \mid (ax_0 + by_0) = c\).

(⇐) If gcd(a,b) | c, then solutions exist:

Suppose \(d = \gcd(a, b)\) and \(d \mid c\).

By Bézout's identity (Lecture 2), there exist \(u, v\) such that \(au + bv = d\).

Since \(d \mid c\), we have \(c = dk\) for some integer \(k\).

Multiply both sides: \(a(uk) + b(vk) = dk = c\).

So \(x = uk\) and \(y = vk\) are solutions. \(\square\)

2. General Solution Formula

Theorem 12.2 (General Solution) If \((x_0, y_0)\) is a particular solution to \(ax + by = c\), then all solutions are given by: \[x = x_0 + \frac{b}{\gcd(a,b)} \cdot t, \quad y = y_0 - \frac{a}{\gcd(a,b)} \cdot t\] where \(t \in \mathbb{Z}\).
Step 1: Verify the formula gives solutions

Let \(d = \gcd(a, b)\). We need to check that \(a(x_0 + \frac{b}{d}t) + b(y_0 - \frac{a}{d}t) = c\).

LHS = \(ax_0 + \frac{abl}{d}t + by_0 - \frac{ab}{d}t = ax_0 + by_0 = c\). ✓

Step 2: Show all solutions have this form

If \((x, y)\) is any solution, then \(ax + by = ax_0 + by_0\).

Therefore \(a(x - x_0) + b(y - y_0) = 0\), so \(a(x - x_0) = -b(y - y_0)\).

Since \(d = \gcd(a, b)\), write \(a = da'\), \(b = db'\). Then \(a'(x - x_0) = -b'(y - y_0)\)

Since \(\gcd(a', b') = 1\), we have \(b' \mid (x - x_0)\), so \(x - x_0 = b't\) for some integer \(t\).

Then \(y - y_0 = -a't\), giving the formula. \(\square\)

Example 12.1 Find all solutions to \(12x + 18y = 6\).
Step 1: Check existence

\(\gcd(12, 18) = 6\) and \(6 \mid 6\). Solutions exist.

Step 2: Find particular solution

Using Extended Euclidean Algorithm: \(18 = 12 \cdot 1 + 6\) \(12 = 6 \cdot 2 + 0\) Back-substitution: \(6 = 18 - 12 \cdot 1\) So \(12(-1) + 18(1) = 6\). Particular solution: \(x_0 = -1, y_0 = 1\).

Step 3: Write general solution

General solution: \[x = -1 + \frac{18}{6}t = -1 + 3t\] \[y = 1 - \frac{12}{6}t = 1 - 2t\] where \(t \in \mathbb{Z}\). \(\square\)

3. Pythagorean Triples

Definition 12.2 (Pythagorean Triple) A Pythagorean triple is a triple \((a, b, c)\) of positive integers satisfying: \[a^2 + b^2 = c^2\] We call it primitive if \(\gcd(a, b, c) = 1\).
Theorem 12.3 (Parametrization of Primitive Pythagorean Triples) Every primitive Pythagorean triple \((a, b, c)\) with \(a < b\) can be written as: \[a = m^2 - n^2, \quad b = 2mn, \quad c = m^2 + n^2\] where \(m > n > 0\), \(\gcd(m, n) = 1\), and exactly one of \(m, n\) is even.
Step 1: Verify the formula works

\((m^2 - n^2)^2 + (2mn)^2 = m^4 - 2m^2n^2 + n^4 + 4m^2n^2\) \[= m^4 + 2m^2n^2 + n^4 = (m^2 + n^2)^2\)

So \(a^2 + b^2 = c^2\). \(\square\)

Step 2: Show all primitive triples arise this way

Start with \(a^2 + b^2 = c^2\) with \(\gcd(a, b, c) = 1\).

Assume \(a\) is odd and \(b\) is even. Rewrite: \(b^2 = c^2 - a^2 = (c-a)(c+a)\)

Let \(u = \frac{c-a}{2}\) and \(v = \frac{c+a}{2}\). Then \(uv = \frac{b^2}{4}\): \[c = u + v, \quad a = v - u, \quad b = 2\sqrt{uv}\]

Step 3: Conclude u and v are squares

Since \(\gcd(u, v) = 1\) and \(uv\) is a perfect square, both \(u\) and \(v\) are perfect squares.

Write \(u = n^2\) and \(v = m^2\) with \(m > n > 0\). Then \(a = m^2 - n^2\), \(b = 2mn\), \(c = m^2 + n^2\). \(\square\)

Example 12.4 Find all primitive Pythagorean triples with hypotenuse \(c = 65\).
Step 1: Factor 65

\(65 = 5 \cdot 13\). Both are primes ≡ 1 (mod 4).

Step 2: Find representations as sums of squares

\(5 = 1^2 + 2^2\) \(13 = 2^2 + 3^2\)

Step 3: Use Brahmagupta-Fibonacci identity

\((1^2 + 2^2)(2^2 + 3^2) = (1 \cdot 2 - 2 \cdot 3)^2 + (1 \cdot 3 + 2 \cdot 2)^2 = (-4)^2 + 7^2 = 16 + 49 = 65\)

Also: \((1^2 + 2^2)(3^2 + 2^2) = (1 \cdot 3 - 2 \cdot 2)^2 + (1 \cdot 2 + 3 \cdot 2)^2 = (-1)^2 + 8^2 = 1 + 64 = 65\)

Conclusion:

The primitive Pythagorean triples with \(c = 65\) are: \((7, 24, 25)\) and \((16, 63, 65)\)

Exercises:
  1. Find all integer solutions to \(15x + 25y = 5\).
  2. Find all integer solutions to \(7x + 11y = 3\).
  3. Show that \(x^2 + y^2 = 3z^2\) has no non-trivial integer solutions.
  4. Find all primitive Pythagorean triples with hypotenuse 25.
  5. Prove: If \((a, b, c)\) is a Pythagorean triple, then \(c\) is odd.
  6. Show that if \(\gcd(a, b) = 1\) and \(a^2 + b^2 = c^2\), then \(c \equiv 1 \pmod{4}\).
  7. Find the smallest positive integer \(y\) such that \(x^2 - 7y^2 = 1\) has a solution.
  8. Prove: In any Pythagorean triple, at least one leg is divisible by 3.
