Lecture 12Diophantine Equations

1. Definition and Examples

Definition 12.1 (Diophantine Equation) A Diophantine equation is a polynomial equation where we seek integer solutions.
Examples:
  • Linear: \(ax + by = c\)
  • Quadratic: \(x^2 + y^2 = z^2\) (Pythagorean triples)
  • Quadratic: \(x^2 - Dy^2 = 1\) (Pell's equation)
  • Higher degree: \(x^3 + y^3 = z^3\)

2. Linear Diophantine Equations

Definition 12.2 (Linear Diophantine Equation) An equation of the form: \[ax + by = c\] where \(a, b, c \in \mathbb{Z}\) and we seek integer solutions \((x, y)\), is called a linear Diophantine equation.
Theorem 12.1 (Existence of Solutions) The linear Diophantine equation \(ax + by = c\) has integer solutions if and only if \(\gcd(a, b) \mid c\).
(⇒) If solutions exist, then gcd(a,b) | c:

Suppose \(x_0, y_0\) satisfy \(ax_0 + by_0 = c\). Let \(d = \gcd(a, b)\). Then \(d \mid a\) and \(d \mid b\). Therefore \(d \mid (ax_0 + by_0) = c\).

(⇐) If gcd(a,b) | c, then solutions exist:

By Bézout's identity, there exist \(u, v\) such that \(au + bv = \gcd(a, b)\). If \(d = \gcd(a, b) \mid c\), write \(c = dk\). Then \(a(uk) + b(vk) = c\), giving solutions \(x = uk, y = vk\). \(\square\)

3. General Solution Formula

Theorem 12.2 (General Solution) If \((x_0, y_0)\) is a particular solution to \(ax + by = c\), then all solutions are given by: \[x = x_0 + \frac{b}{\gcd(a,b)} \cdot t, \quad y = y_0 - \frac{a}{\gcd(a,b)} \cdot t\] where \(t \in \mathbb{Z}\).
Example 12.1 Find all solutions to \(12x + 18y = 6\).

\(\gcd(12, 18) = 6\) and \(6 \mid 6\). Solutions exist. Using Extended Euclidean: \(6 = 18 - 12 \cdot 1\), so \(x_0 = -1, y_0 = 1\).

General solution: \(x = -1 + 3t, y = 1 - 2t\) for \(t \in \mathbb{Z}\).

4. Pythagorean Triples

Definition 12.3 (Pythagorean Triple) A Pythagorean triple is a triple \((a, b, c)\) of positive integers satisfying \(a^2 + b^2 = c^2\). It is primitive if \(\gcd(a, b, c) = 1\).
Theorem 12.3 (Parametrization of Primitive Pythagorean Triples) Every primitive Pythagorean triple \((a, b, c)\) with \(a < b\) can be written as: \[a = m^2 - n^2, \quad b = 2mn, \quad c = m^2 + n^2\] where \(m > n > 0\), \(\gcd(m, n) = 1\), and exactly one of \(m, n\) is even.
Example 12.2 Find all primitive Pythagorean triples with hypotenuse \(c = 65\).

\(65 = 5 \cdot 13 = (1^2 + 2^2)(2^2 + 3^2)\)

Using Brahmagupta-Fibonacci: \(65 = 7^2 + 4^2\) and \(65 = 8^2 + 1^2\)

So the triples are \((7, 24, 25)\) and \((16, 63, 65)\) (using the parametrization formulas).

5. Pell's Equation

Definition 12.4 (Pell's Equation) An equation of the form \(x^2 - Dy^2 = 1\) where \(D\) is a positive non-square integer is called Pell's equation.
Theorem 12.4 Pell's equation \(x^2 - Dy^2 = 1\) always has a non-trivial solution when \(D\) is a positive non-square integer.
Example 12.3 Find the fundamental solution to \(x^2 - 2y^2 = 1\).

Try small values: \(y = 1\) gives \(x^2 = 3\) (no), \(y = 2\) gives \(x^2 = 9\), so \(x = 3\).

Fundamental solution: \((3, 2)\). All solutions are given by \((3 + 2\sqrt{2})^n\).

Exercises:
  1. Find all integer solutions to \(15x + 25y = 5\).
  2. Find all integer solutions to \(7x + 11y = 3\).
  3. Show that \(x^2 + y^2 = 3z^2\) has no non-trivial integer solutions.
  4. Find all primitive Pythagorean triples with hypotenuse 25.
  5. Prove: If \((a, b, c)\) is a Pythagorean triple, then \(c\) is odd.
  6. Show that if \(\gcd(a, b) = 1\) and \(a^2 + b^2 = c^2\), then \(c \equiv 1 \pmod{4}\).
  7. Find the smallest positive integer \(y\) such that \(x^2 - 7y^2 = 1\) has a solution.
  8. Prove: In any Pythagorean triple, at least one leg is divisible by 3.
