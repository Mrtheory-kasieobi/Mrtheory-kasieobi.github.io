Problem Set 3: Congruences and Modular Arithmetic

Elementary Number Theory - Week 3 Medium

Problems

Problem 1

Solve the congruence \(3x \equiv 7 \pmod{11}\).

Problem 2

Find all solutions to \(x^2 \equiv 1 \pmod{8}\).

Problem 3

Prove: If \(a \equiv b \pmod{m}\) and \(c \equiv d \pmod{m}\), then \(a + c \equiv b + d \pmod{m}\).

Problem 4

Find the remainder when \(2^{100}\) is divided by 7.

Problem 5

Determine if 3 has a multiplicative inverse modulo 14. If so, find it.

Problem 6

Solve the system: \(x \equiv 2 \pmod{3}\) and \(x \equiv 3 \pmod{5}\).

Problem 7

Prove: If \(p\) is prime and \(a \not\equiv 0 \pmod{p}\), then \(a^{p-1} \equiv 1 \pmod{p}\).

Problem 8

Find a number \(x\) such that \(x \equiv 1 \pmod{2}\), \(x \equiv 2 \pmod{3}\), and \(x \equiv 3 \pmod{5}\).

Problem 9

Prove Wilson's theorem: \((p-1)! \equiv -1 \pmod{p}\) for prime \(p\).

Problem 10

Show that \(n^3 - n\) is divisible by 6 for all integers \(n\).

Bonus Problems

Bonus Problem 1

Challenge: Find the last two digits of \(7^{100}\).

Bonus Problem 2

Challenge: Prove: If \(a \equiv b \pmod{m}\), then \(a^n \equiv b^n \pmod{m}\) for all \(n \geq 1\).

Bonus Problem 3

Challenge: Show that the congruence \(x^2 \equiv a \pmod{p}\) has at most 2 solutions for odd prime \(p\).
