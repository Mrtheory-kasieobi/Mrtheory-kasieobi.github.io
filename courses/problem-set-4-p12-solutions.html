Problem Set 4: Trigonometry and Unit Circle

Precalculus 12 - Chapter 4 Solutions

Solutions

Problem 1: Convert \(120°\) to radians. Find the reference angle and determine the sign of sine, cosine, and tangent in this quadrant.
Convert: \(120° \times \frac{\pi}{180°} = \frac{2\pi}{3}\) radians
Reference angle: \(180° - 120° = 60° = \frac{\pi}{3}\)
120° is in Quadrant II
Signs in QII: sine positive, cosine negative, tangent negative
Answer: \(\frac{2\pi}{3}\) rad, reference angle \(60°\), sin(+), cos(-), tan(-)
Problem 2: Find all six trigonometric values for \(\theta = \frac{5\pi}{6}\). Explain the sign of each in quadrant II.
Reference angle: \(2\pi - \frac{5\pi}{6} = \frac{7\pi}{6}\) → actually, reference angle for QII is \(\pi - \frac{5\pi}{6} = \frac{\pi}{6}\)
\(\sin(\frac{5\pi}{6}) = \sin(\frac{\pi}{6}) = \frac{1}{2}\) (positive in QII)
\(\cos(\frac{5\pi}{6}) = -\cos(\frac{\pi}{6}) = -\frac{\sqrt{3}}{2}\) (negative in QII)
\(\tan(\frac{5\pi}{6}) = -\tan(\frac{\pi}{6}) = -\frac{1}{\sqrt{3}} = -\frac{\sqrt{3}}{3}\)
\(\csc(\frac{5\pi}{6}) = \frac{1}{\sin(\frac{5\pi}{6})} = 2\)
\(\sec(\frac{5\pi}{6}) = \frac{1}{\cos(\frac{5\pi}{6})} = -\frac{2}{\sqrt{3}} = -\frac{2\sqrt{3}}{3}\)
\(\cot(\frac{5\pi}{6}) = \frac{1}{\tan(\frac{5\pi}{6})} = -\sqrt{3}\)
Answer: \(\sin = \frac{1}{2}\), \(\cos = -\frac{\sqrt{3}}{2}\), \(\tan = -\frac{\sqrt{3}}{3}\), and reciprocals
Problem 3: Solve \(\sin\theta = \frac{1}{2}\) for \(\theta \in [0, 2\pi)\) and give the general solution.
In \([0, 2\pi)\), \(\sin\theta = \frac{1}{2}\) at \(\theta = \frac{\pi}{6}\) and \(\theta = \pi - \frac{\pi}{6} = \frac{5\pi}{6}\)
General solution: \(\theta = \frac{\pi}{6} + 2\pi n\) or \(\theta = \frac{5\pi}{6} + 2\pi n\) for any integer \(n\)
Answer: \(\theta = \frac{\pi}{6}, \frac{5\pi}{6}\) in \([0, 2\pi)\); General: above formulas
Problem 4: A lighthouse is 2 km from point P on shore. The light rotates at 5 rev/min. Find the speed of the beam along the shore when it is 1 km from P.
Angular speed: \(\omega = 5 \frac{\text{rev}}{\text{min}} \times \frac{2\pi \text{ rad}}{1 \text{ rev}} = 10\pi\) rad/min
Use: \(v = r\omega\) where \(r\) is distance from lighthouse
When beam is 1 km from P, use right triangle: \(r = \frac{2}{\cos\theta}\) where \(\cos\theta = \frac{1}{r}\)
Actually, when foot of perpendicular to shore is 1 km from P: \(r = \frac{2}{\cos\theta}\) and 1 = \(2\tan\theta\), so \(\tan\theta = \frac{1}{2}\)
\(\cos\theta = \frac{2}{\sqrt{5}}\), so \(r = \frac{2\sqrt{5}}{2} = \sqrt{5}\) km
Speed: \(v = \sqrt{5} \times 10\pi = 10\pi\sqrt{5}\) km/min ≈ 22.4 km/min
Answer: \(10\pi\sqrt{5}\) km/min ≈ 22.4 km/min
Problem 5: Find the arc length and sector area of a circle with radius 5 cm and central angle \(2.5\) radians.
Arc length: \(s = r\theta = 5 \times 2.5 = 12.5\) cm
Sector area: \(A = \frac{1}{2}r^2\theta = \frac{1}{2}(25)(2.5) = 31.25\) cm²
Answer: Arc length = 12.5 cm, Sector area = 31.25 cm²
Problem 6: If \(\cos\theta = -\frac{4}{5}\) and \(\theta\) is in quadrant III, find \(\sin\theta\) and \(\tan\theta\).
Use Pythagorean identity: \(\sin^2\theta + \cos^2\theta = 1\)
\(\sin^2\theta = 1 - \frac{16}{25} = \frac{9}{25}\)
\(\sin\theta = \pm\frac{3}{5}\)
In QIII, sine is negative: \(\sin\theta = -\frac{3}{5}\)
\(\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{-3/5}{-4/5} = \frac{3}{4}\)
Answer: \(\sin\theta = -\frac{3}{5}\), \(\tan\theta = \frac{3}{4}\)
Problem 7: Find the exact value of \(\sin(105°)\) using sum identities.
\(\sin(105°) = \sin(60° + 45°)\)
Use: \(\sin(A + B) = \sin A \cos B + \cos A \sin B\)
\(= \sin(60°)\cos(45°) + \cos(60°)\sin(45°)\)
\(= \frac{\sqrt{3}}{2} \times \frac{\sqrt{2}}{2} + \frac{1}{2} \times \frac{\sqrt{2}}{2}\)
\(= \frac{\sqrt{6}}{4} + \frac{\sqrt{2}}{4} = \frac{\sqrt{6} + \sqrt{2}}{4}\)
Answer: \(\frac{\sqrt{6} + \sqrt{2}}{4}\)
Problem 8: A wheel with radius 10 cm rotates through an angle of \(75°\). Find the arc length traveled by a point on the rim.
Convert angle to radians: \(75° \times \frac{\pi}{180°} = \frac{5\pi}{12}\) radians
Arc length: \(s = r\theta = 10 \times \frac{5\pi}{12} = \frac{50\pi}{12} = \frac{25\pi}{6}\) cm
Answer: \(\frac{25\pi}{6}\) cm ≈ 13.1 cm

Bonus Solutions

Bonus Problem 1: Find all solutions to \(\sin(2\theta) = \cos\theta\) in the interval \([0, 2\pi)\).
Use identity: \(\sin(2\theta) = 2\sin\theta\cos\theta\)
Equation: \(2\sin\theta\cos\theta = \cos\theta\)
Rearrange: \(2\sin\theta\cos\theta - \cos\theta = 0\)
Factor: \(\cos\theta(2\sin\theta - 1) = 0\)
Case 1: \(\cos\theta = 0\) → \(\theta = \frac{\pi}{2}, \frac{3\pi}{2}\)
Case 2: \(2\sin\theta - 1 = 0\) → \(\sin\theta = \frac{1}{2}\)
→ \(\theta = \frac{\pi}{6}, \frac{5\pi}{6}\)
Answer: \(\theta = \frac{\pi}{6}, \frac{\pi}{2}, \frac{5\pi}{6}, \frac{3\pi}{2}\)
Bonus Problem 2: A ladder leaning against a wall makes a \(60°\) angle with the ground. If the foot of the ladder is 2 ft from the wall, how far up the wall does the ladder reach? What angle would give the same height with one-third the distance from the wall?
Given: distance from wall = 2 ft, angle = 60°
Let ladder length = \(L\). Then \(L\cos(60°) = 2\)
\(L = \frac{2}{\cos(60°)} = \frac{2}{0.5} = 4\) ft
Height on wall: \(h = L\sin(60°) = 4 \times \frac{\sqrt{3}}{2} = 2\sqrt{3}\) ft
New setup: same height, distance = \(\frac{2}{3}\) ft
New ladder length same = 4 ft
New angle: \(\cos\phi = \frac{2/3}{4} = \frac{1}{6}\), so \(\phi = \arccos(\frac{1}{6})\)
\(\sin\phi = \sqrt{1 - \frac{1}{36}} = \frac{\sqrt{35}}{6}\)
Answer: Height = \(2\sqrt{3}\) ft, New angle = \(\arccos(\frac{1}{6})\) ≈ 80.4°
