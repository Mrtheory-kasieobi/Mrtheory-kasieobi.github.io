Problem Set 9: Function Operations

Precalculus 12 - Problem Set
Topics: Sums, Products, Compositions, Inverses Medium

Problems

Problem 1

Given \(f(x) = x^2 - 1\) and \(g(x) = 2x + 3\), find \(f + g\), \(f - g\), \(fg\), and \(\frac{f}{g}\). State the domain of each.

Problem 2

Find \(f(g(x))\) and \(g(f(x))\) for \(f(x) = \sqrt{x}\) and \(g(x) = x - 4\). State the domain of each composition.

Problem 3

Find the inverse of \(f(x) = \frac{3x - 2}{x + 1}\). Verify by showing \(f^{-1}(f(x)) = x\).

Problem 4

Graph \(h(x) = |f(x)| - 2\) where \(f(x) = x^2 - 4\). Describe the transformation from the original function.

Problem 5

Given \(f(x) = e^x\) and \(g(x) = \ln(x)\), find \(f \circ g\) and \(g \circ f\). What do you notice?

Problem 6

Find all functions that are their own inverse. That is, find \(f(x)\) such that \(f(f(x)) = x\).

Problem 7

If \(f(x) = 2x + 1\) and \(g(x) = x^2\), find \(f(g(f(x)))\). Simplify completely.

Problem 8

A function is defined as \(h(x) = f(x) \cdot g(x)\) where \(f(x) = x - 2\) and \(g(x) = x + 3\). Find the zeros of h and interpret them.

Bonus Problems

Bonus Problem 1

If \(f(x) = \frac{1}{x}\) and \(g(x) = x + 1\), find a formula for \(h(x) = f(g(f(x)))\). State the domain of \(h\).

Bonus Problem 2

Prove that if \(f\) and \(g\) are both one-to-one functions, then \(f \circ g\) is also one-to-one. What can you say about \((f \circ g)^{-1}\)?
