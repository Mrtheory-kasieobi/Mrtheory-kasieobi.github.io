Problem Set 6: MVT and Curve Sketching - SOLUTIONS

Calculus I - Week 6

Solution Guide

Note: These are detailed solutions showing all steps and reasoning. Each step is clearly justified.

Problem 1: Verify MVT for \(f(x) = x^3\) on \([1, 3]\)

Solution:
Step 1: Check hypotheses of MVT
MVT requires: (1) f continuous on [1,3], (2) f differentiable on (1,3)
Step 2: Verify conditions
\(f(x) = x^3\) is a polynomial, continuous and differentiable everywhere ✓
Step 3: Find f(1) and f(3)
\(f(1) = 1\), \(f(3) = 27\)
Step 4: Compute average rate of change
\(\frac{f(3)-f(1)}{3-1} = \frac{27-1}{2} = 13\)
Step 5: Find f'(x)
\(f'(x) = 3x^2\)
Step 6: Find c where f'(c) = 13
\(3c^2 = 13 \Rightarrow c^2 = \frac{13}{3} \Rightarrow c = \sqrt{\frac{13}{3}}\)
Step 7: Verify c is in (1,3)
\(\sqrt{\frac{13}{3}} \approx 2.08\), which is in (1,3) ✓
Final Answer:
\(\boxed{c = \sqrt{\frac{13}{3}} \text{ verifies MVT}}\)

Problem 2: Find \(\frac{dy}{dx}\) for \(y = \sin(x^2)\)

Solution:
Step 1: Apply chain rule
Outer: \(\sin(u)\), Inner: \(u = x^2\)
Step 2: Differentiate
\(\frac{dy}{dx} = \cos(x^2) \cdot 2x\)
Final Answer:
\(\boxed{2x\cos(x^2)}\)

Problem 3: Find critical points of \(f(x) = x^3 - 3x + 1\)

Solution:
Step 1: Find derivative
\(f'(x) = 3x^2 - 3\)
Step 2: Set equal to zero
\(3x^2 - 3 = 0 \Rightarrow x^2 = 1 \Rightarrow x = \pm 1\)
Final Answer:
\(\boxed{x = -1, 1}\)

Problem 4: Find \(\lim_{x \to 0} \frac{e^x - 1 - x}{x^2}\)

Solution:
Step 1: Check direct substitution
Gives \(\frac{0}{0}\), apply L'Hôpital's Rule
Step 2: First application
\(\lim_{x \to 0} \frac{e^x - 1}{2x}\)
Step 3: Apply L'Hôpital's again
\(\lim_{x \to 0} \frac{e^x}{2} = \frac{1}{2}\)
Final Answer:
\(\boxed{\frac{1}{2}}\)

Problem 5: Find equation of tangent to \(y = \ln x\) at \(x = 1\)

Solution:
Step 1: Find point
\(y = \ln 1 = 0\), point is \((1, 0)\)
Step 2: Find slope
\(\frac{dy}{dx} = \frac{1}{x}\), at \(x = 1\): slope = 1
Step 3: Use point-slope form
\(y - 0 = 1(x - 1)\)
Final Answer:
\(\boxed{y = x - 1}\)

Problem 6: Evaluate \(\int_0^{\pi/2} \cos^2 x \, dx\)

Solution:
Step 1: Use half-angle identity
\(\cos^2 x = \frac{1 + \cos 2x}{2}\)
Step 2: Integrate
\(\int_0^{\pi/2} \frac{1 + \cos 2x}{2} dx = \frac{1}{2}[x + \frac{\sin 2x}{2}]_0^{\pi/2}\)
Step 3: Evaluate
\(\frac{1}{2}[\frac{\pi}{2} + 0] - \frac{1}{2}[0 + 0] = \frac{\pi}{4}\)
Final Answer:
\(\boxed{\frac{\pi}{4}}\)

Problem 7: Find where \(f(x) = \frac{x}{x+1}\) is increasing/decreasing

Solution:
Step 1: Find derivative
\(f'(x) = \frac{1 \cdot (x+1) - x \cdot 1}{(x+1)^2} = \frac{1}{(x+1)^2}\)
Step 2: Analyze sign
\(f'(x) > 0\) for all \(x \neq -1\) (denominator always positive)
Final Answer:
\(\boxed{\text{Increasing on } (-\infty, -1) \text{ and } (-1, \infty)}\)

Problem 8: Find inflection point of \(f(x) = x^3 - 3x^2\)

Solution:
Step 1: Find second derivative
\(f'(x) = 3x^2 - 6x\), \(f''(x) = 6x - 6\)
Step 2: Find where f'' = 0
\(6x - 6 = 0 \Rightarrow x = 1\)
Step 3: Check concavity change
For \(x < 1\): \(f'' < 0\) (concave down)
For \(x > 1\): \(f'' > 0\) (concave up)
Step 4: Find y-coordinate
\(f(1) = 1 - 3 = -2\)
Final Answer:
\(\boxed{(1, -2) \text{ is inflection point}}\)

Problem 9: Evaluate \(\int \frac{dx}{x \ln x}\)

Solution:
Step 1: Use substitution
Let \(u = \ln x\), then \(du = \frac{1}{x}dx\)
Step 2: Rewrite integral
\(\int \frac{1}{u} du\)
Step 3: Integrate
\(\ln|u| + C\)
Step 4: Substitute back
\(\ln|\ln x| + C\)
Final Answer:
\(\boxed{\ln|\ln x| + C}\)

Problem 10: Find average value of \(f(x) = x^2\) on \([0, 2]\)

Solution:
Step 1: Use average value formula
\(f_{avg} = \frac{1}{b-a}\int_a^b f(x)dx\)
Step 2: Set up integral
\(f_{avg} = \frac{1}{2}\int_0^2 x^2 dx\)
Step 3: Evaluate
\(\frac{1}{2} \cdot \frac{x^3}{3}\Big|_0^2 = \frac{1}{2} \cdot \frac{8}{3} = \frac{4}{3}\)
Final Answer:
\(\boxed{\frac{4}{3}}\)

Bonus 1: Find \(\int \frac{dx}{x^2 + 2x + 2}\)

Solution:
Step 1: Complete the square
\(x^2 + 2x + 2 = (x+1)^2 + 1\)
Step 2: Use arctangent formula
\(\int \frac{dx}{(x+1)^2 + 1} = \tan^{-1}(x+1) + C\)
Final Answer:
\(\boxed{\tan^{-1}(x+1) + C}\)

Bonus 2: If \(f'(x) = x^2 - 4x + 3\) and \(f(0) = 5\), find \(f(x)\)

Solution:
Step 1: Integrate f'(x)
\(f(x) = \int (x^2 - 4x + 3)dx = \frac{x^3}{3} - 2x^2 + 3x + C\)
Step 2: Use initial condition
\(f(0) = 5 \Rightarrow 0 - 0 + 0 + C = 5 \Rightarrow C = 5\)
Final Answer:
\(\boxed{f(x) = \frac{x^3}{3} - 2x^2 + 3x + 5}\)
