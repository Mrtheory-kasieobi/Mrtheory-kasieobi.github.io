Problem Set 6: MVT and Curve Sketching - SOLUTIONS

Calculus I - Week 6

Solution Guide

Note: These are detailed solution outlines. Show all work when completing problems.

Problem 1: Verify MVT for \(f(x) = x^3\) on \([1, 3]\)

Solution: \(f\) is continuous and differentiable everywhere. Find \(c\) such that \(f'(c) = \frac{f(3)-f(1)}{3-1}\)
\(f'(x) = 3x^2\). Right side: \(\frac{27-1}{2} = 13\).
Solve \(3c^2 = 13 \Rightarrow c = \sqrt{\frac{13}{3}}\). Since \(1 < c < 3\), MVT verified.

Problem 2: Find critical points of \(f(x) = \frac{x^2}{x-1}\)

Solution: \(f'(x) = \frac{2x(x-1) - x^2}{(x-1)^2} = \frac{x(x-2)}{(x-1)^2}\).
\(f'(x) = 0\) when \(x = 0\) or \(x = 2\). Note: \(x \neq 1\) (undefined).

Problem 3: Sketch \(y = \frac{x}{\sqrt{x+1}}\)

Solution: Domain: \(x > -1\). X-intercept: \(x = 0\). Y-intercept: \(y = 0\).
Vertical asymptote: \(x \to -1^+\), \(y \to -\infty\).
\(f'(x) = \frac{\sqrt{x+1} - \frac{x}{2\sqrt{x+1}}}{x+1} = \frac{x+2}{2(x+1)^{3/2}}\).
Increasing on \((-1, \infty)\). No local extrema.

Problem 4: Find intervals of increase/decrease for \(f(x) = x^3 - 3x^2 + 4\)

Solution: \(f'(x) = 3x^2 - 6x = 3x(x-2)\).
Critical points: \(x = 0, 2\).
\(f' > 0\) on \((-\infty, 0)\) and \((2, \infty)\) → increasing.
\(f' < 0\) on \((0, 2)\) → decreasing.

Problem 5: Determine concavity of \(f(x) = e^x - x^2\)

Solution: \(f''(x) = e^x - 2\).
\(f''(x) = 0\) when \(e^x = 2 \Rightarrow x = \ln 2\).
\(f'' < 0\) on \((-\infty, \ln 2)\) → concave down.
\(f'' > 0\) on \((\ln 2, \infty)\) → concave up.
Inflection point at \(x = \ln 2\).

Problem 6: Find inflection points of \(f(x) = x^4 - 4x^3\)

Solution: \(f'(x) = 4x^3 - 12x^2 = 4x^2(x-3)\).
\(f''(x) = 12x^2 - 24x = 12x(x-2)\).
\(f'' = 0\) at \(x = 0, 2\).
Inflection points at \((0, 0)\) and \((2, -16)\).

Problem 7: Use First Derivative Test for \(f(x) = x + \cos x\) on \([0, 2\pi]\)

Solution: \(f'(x) = 1 - \sin x = 0 \Rightarrow \sin x = 1 \Rightarrow x = \frac{\pi}{2}\)
For \(x \in [0, \frac{\pi}{2})\): \(f' > 0\) (increasing).
For \(x \in (\frac{\pi}{2}, 2\pi]\): \(f' > 0\) (increasing).
No local extrema (horizontal tangent but no sign change).

Problem 8: Sketch \(y = \sin x + \cos x\) on \([0, 2\pi]\)

Solution: Rewrite: \(y = \sqrt{2}\sin(x + \frac{\pi}{4})\).
Amplitude: \(\sqrt{2}\). Period: \(2\pi\).
Max: \(\sqrt{2}\) at \(x = \frac{\pi}{4}\). Min: \(-\sqrt{2}\) at \(x = \frac{5\pi}{4}\).
Zeros at \(x = \frac{3\pi}{4}, \frac{7\pi}{4}\).

Problem 9: Tangent line to \(y = \ln(x^2 + 1)\) at \(x = 1\)

Solution: \(y' = \frac{2x}{x^2+1}\). At \(x = 1\): \(y' = 1\). Point: \((1, \ln 2)\).
Tangent line: \(y - \ln 2 = 1(x - 1)\) or \(y = x + \ln 2 - 1\).

Problem 10: If \(f\) differentiable and \(f'(x) = 0\), prove \(f\) constant

Solution: By Mean Value Theorem, for any \(a, b\): there exists \(c\) between them with \(f'(c) = \frac{f(b)-f(a)}{b-a}\).
Since \(f'(c) = 0\), we have \(f(b) = f(a)\) for all \(a, b\). Thus \(f\) is constant.

Bonus 1: Classify critical points of \(f(x) = x^4 - 4x^3 + 6x^2 - 4x + 1\)

Solution: \(f'(x) = 4x^3 - 12x^2 + 12x - 4 = 4(x-1)^3\).
Critical point: \(x = 1\).
\(f''(x) = 12(x-1)^2\). At \(x = 1\): \(f'' = 0\).
Use first derivative test: \(f' < 0\) for \(x < 1\), \(f' > 0\) for \(x > 1\).
Local minimum at \(x = 1\).

Bonus 2: If \(f'''(a) = 0\), must \(f'''(a) = 0\)?

Solution: No. Consider \(f(x) = x^4\). Then \(f'(x) = 4x^3, f''(x) = 12x^2, f'''(x) = 24x\).
At \(x = 0\): \(f'''(0) = 0\). But this is not necessarily an inflection point.
The third derivative being zero doesn't guarantee inflection - need sign change in \(f''\).
