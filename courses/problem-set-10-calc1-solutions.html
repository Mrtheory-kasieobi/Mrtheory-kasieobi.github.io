Problem Set 10: Applications of Integration - SOLUTIONS

Calculus I - Week 10

Solution Guide

Note: These are detailed solutions showing all steps and reasoning. Each step is clearly justified.

Problem 1: Area between \(y = x^2\) and \(y = 2x\)

Solution:
Step 1: Find intersection points
\(x^2 = 2x \Rightarrow x(x-2) = 0 \Rightarrow x = 0, 2\)
Step 2: Determine which curve is on top
At \(x = 1\): \(2(1) = 2 > 1 = 1^2\), so \(y = 2x\) is on top
Step 3: Set up integral
\(\text{Area} = \int_0^2 (2x - x^2) dx\)
Step 4: Integrate
\(\left[x^2 - \frac{x^3}{3}\right]_0^2\)
Step 5: Evaluate
\((4 - \frac{8}{3}) - 0 = \frac{12-8}{3} = \frac{4}{3}\)
Final Answer:
\(\boxed{\frac{4}{3}}\)

Problem 2: Area between \(y = x^3\) and \(y = x\) on \([-1, 1]\)

Solution:
Step 1: Find which function is greater
\(x^3 \leq x\) on \([-1, 1]\) (since \(x - x^3 = x(1-x^2) \geq 0\) for \(x \in [-1,1]\))
Step 2: Set up integral
\(\text{Area} = \int_{-1}^1 (x - x^3) dx\)
Step 3: Integrate
\(\left[\frac{x^2}{2} - \frac{x^4}{4}\right]_{-1}^1\)
Step 4: Evaluate
\((\frac{1}{2} - \frac{1}{4}) - (\frac{1}{2} - \frac{1}{4}) = 0\)... wait, need to reconsider
Step 5: Correct approach - split at origin
On \([-1, 0]\): \(x^3 \geq x\), on \([0, 1]\): \(x \geq x^3\)
\(\text{Area} = \int_{-1}^0 (x^3 - x)dx + \int_0^1 (x - x^3)dx\)
Step 6: Compute
\(2 \cdot \int_0^1 (x - x^3)dx = 2 \cdot \frac{1}{6} = \frac{1}{3}\)
Final Answer:
\(\boxed{\frac{1}{3}}\)

Problem 3: Area under \(y = e^{-x}\) from \(x = 0\) to \(x = 1\)

Solution:
Step 1: Set up definite integral
\(\text{Area} = \int_0^1 e^{-x} dx\)
Step 2: Use substitution
Let \(u = -x\), \(du = -dx\), \(dx = -du\)
Step 3: Integrate
\(-\int_1^{e^{-1}} e^u du = -[e^u]_1^{1/e} = -(e^{1/e} - e) = e - e^{1/e}\)
Alternative (direct)
\(\int e^{-x} dx = -e^{-x}\)
\([-e^{-x}]_0^1 = -e^{-1} - (-e^0) = 1 - \frac{1}{e}\)
Final Answer:
\(\boxed{1 - \frac{1}{e}}\)

Problem 4: Volume of solid with base bounded by \(y = x^2\) and \(y = 4\) with square cross-sections

Solution:
Step 1: Find bounds
Intersections: \(x^2 = 4 \Rightarrow x = \pm 2\)
Step 2: Side length of square
At position \(x\), side = \(4 - x^2\)
Step 3: Cross-sectional area
\(A(x) = (4 - x^2)^2\)
Step 4: Set up volume integral
\(V = \int_{-2}^2 (4 - x^2)^2 dx\)
Step 5: Expand and integrate
\((4-x^2)^2 = 16 - 8x^2 + x^4\)
\(\int (16 - 8x^2 + x^4)dx = 16x - \frac{8x^3}{3} + \frac{x^5}{5}\)
Step 6: Evaluate
\(\left[16x - \frac{8x^3}{3} + \frac{x^5}{5}\right]_{-2}^2 = 2\left(32 - \frac{64}{3} + \frac{32}{5}\right) = \frac{256}{15}\)
Final Answer:
\(\boxed{\frac{256}{15}}\)

Problem 5: Volume of solid obtained by rotating \(y = x^2\) about x-axis from \(x = 0\) to \(x = 2\)

Solution:
Step 1: Use disk method
Radius at \(x\) is \(y = x^2\)
Step 2: Set up integral
\(V = \pi \int_0^2 (x^2)^2 dx = \pi \int_0^2 x^4 dx\)
Step 3: Integrate
\(\pi \left[\frac{x^5}{5}\right]_0^2 = \pi \cdot \frac{32}{5}\)
Final Answer:
\(\boxed{\frac{32\pi}{5}}\)

Problem 6: Work to lift a 10 lb weight 5 feet

Solution:
Step 1: Use work formula
\(W = F \cdot d\) where \(F\) is force, \(d\) is distance
Step 2: Substitute values
\(F = 10\) lb, \(d = 5\) ft
Step 3: Calculate
\(W = 10 \times 5 = 50\)
Final Answer:
\(\boxed{50 \text{ ft-lb}}\)

Problem 7: Average value of \(f(x) = x^2\) on \([0, 3]\)

Solution:
Step 1: Use average value formula
\(f_{avg} = \frac{1}{3-0}\int_0^3 x^2 dx\)
Step 2: Integrate
\(\frac{1}{3} \cdot \frac{x^3}{3}\Big|_0^3\)
Step 3: Evaluate
\(\frac{1}{3} \cdot \frac{27}{3} = 3\)
Final Answer:
\(\boxed{3}\)

Problem 8: Integral representing arc length of \(y = x^2\) from \(x = 0\) to \(x = 1\)

Solution:
Step 1: Recall arc length formula
\(L = \int_a^b \sqrt{1 + (f'(x))^2} dx\)
Step 2: Find derivative
\(f'(x) = 2x\)
Step 3: Set up integral
\(L = \int_0^1 \sqrt{1 + (2x)^2} dx = \int_0^1 \sqrt{1 + 4x^2} dx\)
Final Answer:
\(\boxed{\int_0^1 \sqrt{1 + 4x^2} \, dx}\)

Problem 9: Area between \(y = \sin x\) and \(y = \cos x\) from \(x = 0\) to \(x = \frac{\pi}{4}\)

Solution:
Step 1: Determine which is greater
At \(x = 0\): \(\sin 0 = 0 < 1 = \cos 0\)
At \(x = \frac{\pi}{4}\): \(\sin\frac{\pi}{4} = \cos\frac{\pi}{4}\)
On \([0, \frac{\pi}{4}]\): \(\cos x \geq \sin x\)
Step 2: Set up integral
\(\text{Area} = \int_0^{\pi/4} (\cos x - \sin x) dx\)
Step 3: Integrate
\(\left[\sin x + \cos x\right]_0^{\pi/4}\)
Step 4: Evaluate
\(\left(\frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2}\right) - (0 + 1) = \sqrt{2} - 1\)
Final Answer:
\(\boxed{\sqrt{2} - 1}\)

Problem 10: Volume by shells: region bounded by \(y = x^2\), \(y = 0\), \(x = 2\) rotated about y-axis

Solution:
Step 1: Use shell method
Radius = \(x\), Height = \(y = x^2\)
Step 2: Set up integral
\(V = 2\pi \int_0^2 x \cdot x^2 dx = 2\pi \int_0^2 x^3 dx\)
Step 3: Integrate
\(2\pi \left[\frac{x^4}{4}\right]_0^2 = 2\pi \cdot 4 = 8\pi\)
Final Answer:
\(\boxed{8\pi}\)

Bonus 1: Water tank shape is cylinder radius 3 ft, height 8 ft. Work to empty if water depth 6 ft

Solution:
Step 1: Set up coordinate system
Origin at bottom, y-axis upward
Step 2: Water extends from y = 0 to y = 6
Thickness of layer: \(dy\)
Step 3: Volume of layer
\(dV = \pi r^2 dy = 9\pi dy\)
Step 4: Weight of layer
\(dF = 62.4 \cdot 9\pi dy = 561.6\pi dy\) (water weighs 62.4 lb/ft³)
Step 5: Distance to lift
Layer at height \(y\) must be lifted distance \((8-y)\)
Step 6: Work for layer
\(dW = 561.6\pi (8-y) dy\)
Step 7: Integrate
\(W = 561.6\pi \int_0^6 (8-y) dy = 561.6\pi[8y - \frac{y^2}{2}]_0^6\)
Step 8: Evaluate
\(561.6\pi(48 - 18) = 561.6\pi \cdot 30 = 16848\pi\)
Final Answer:
\(\boxed{16848\pi \text{ ft-lb}}\)

Bonus 2: Length of curve \(y = \ln(\cos x)\) from \(x = 0\) to \(x = \frac{\pi}{4}\)

Solution:
Step 1: Find derivative
\(\frac{dy}{dx} = \frac{1}{\cos x} \cdot (-\sin x) = -\tan x\)
Step 2: Set up arc length integral
\(L = \int_0^{\pi/4} \sqrt{1 + \tan^2 x} dx = \int_0^{\pi/4} \sec x \, dx\)
Step 3: Integrate sec x
\(\int \sec x \, dx = \ln|\sec x + \tan x| + C\)
Step 4: Evaluate
\(\ln|\sec\frac{\pi}{4} + \tan\frac{\pi}{4}| - \ln|\sec 0 + \tan 0|\)
\(= \ln(\sqrt{2} + 1) - \ln(1 + 0) = \ln(\sqrt{2} + 1)\)
Final Answer:
\(\boxed{\ln(\sqrt{2} + 1)}\)
