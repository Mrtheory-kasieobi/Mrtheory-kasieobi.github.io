Problem Set 14: Partitions

Elementary Number Theory - Week 15 Medium

Problems

Problem 1

Find all partitions of 6 and verify \(p(6) = 11\).

Problem 2

Compute \(p(10)\) using the pentagonal number recurrence.

Problem 3

Find all partitions of 5 into distinct parts.

Problem 4

Find all partitions of 7 into odd parts.

Problem 5

Prove that \(p(n) \geq p(n-1)\) for all \(n \geq 1\).

Problem 6

Show that the number of partitions of \(n\) into at most 2 parts equals \(\lfloor \frac{n+2}{2} \rfloor\).

Problem 7

Find the generating function for partitions into parts of size at most 3.

Problem 8

Prove: if \(n\) is a triangular number, then \(p(n)\) is odd.

Problem 9

Use Euler's generating function to compute \(p(5)\).

Problem 10

Verify Euler's theorem for \(n=6\): the number of partitions into distinct parts equals the number of partitions into odd parts.

Bonus Problems

Bonus Problem 1

Challenge: Verify Ramanujan's congruence modulo 5 for \(n=4, 9, 14\).

Bonus Problem 2

Challenge: Estimate \(p(100)\) using the Hardy-Ramanujan asymptotic formula and compare with the exact value 190569292.

Bonus Problem 3

Challenge: Show that the number of partitions of \(n\) into exactly 3 parts equals the nearest integer to \(\frac{n^2}{12}\).
