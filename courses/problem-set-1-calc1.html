Problem Set 1: Functions

Calculus I - Week 1

Instructions

Show all work. No calculators. Write clearly and show each step.

Problems

  • 1. Find the domain of \(f(x) = \frac{\sqrt{x-3}}{x^2 - 4}\)
  • 2. Determine if the graph represents a function using the vertical line test.
  • 3. Express the area of a circle as a function of its circumference.
  • 4. Find the composition \(f \circ g\) where \(f(x) = x^2 + 1\) and \(g(x) = \frac{1}{x}\).
  • 5. Find the domain of \(f(x) = \ln(x^2 - 4)\).
  • 6. If \(f(x) = 2x - 3\) and \(g(x) = x^2\), find \((f \circ g)(x)\) and \((g \circ f)(x)\).
  • 7. Sketch a graph of a function that is even and has domain all real numbers.
  • 8. Find the inverse function of \(f(x) = \frac{2x + 1}{x - 3}\).
  • 9. Express the perimeter of a square as a function of its area.
  • 10. Determine whether \(f(x) = x^3\) is one-to-one. If so, find its inverse.
Bonus Problems (10 points each):
  • B1. A function \(f\) has domain \((-4, 5]\) and range \([-2, 3]\). Find the domain and range of \(f(x) + 1\) and \(f(2x)\).
  • B2. Prove that if \(f\) is a linear function, then \(f^{-1}\) exists if and only if the slope is non-zero.
