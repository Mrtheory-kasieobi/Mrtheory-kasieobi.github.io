Problem Set 8: Absolute Value

Precalculus 11 · 8 problems Medium

Problems

Problem 1

Evaluate: \(|5 - 9|\)

Problem 2

Solve: \(|x| = 7\)

Problem 3

Solve: \(|2x - 3| = 5\)

Problem 4

Solve: \(|x + 4| = |x - 2|\)

Problem 5

Graph \(y = |x - 3| + 2\). State the vertex.

Problem 6

Graph \(y = -2|x + 1|\). State the domain, range, and vertex.

Problem 7

Solve by graphing: \(|x - 5| = x + 1\)

Problem 8

Write an absolute value function with vertex at \((-2, 3)\) that opens downward.

Bonus Problems

Bonus Problem 1 Hard

Solve: \(|2x + 1| = |x - 3| + 4\). Then graph the solution set of \(|x - 2| \leq 3\) on a number line.

Bonus Problem 2 Hard

Find the x-intercept(s) of \(y = |x^2 - 4|\). Hence, determine all x for which \(|x^2 - 4| = x + 2\)
