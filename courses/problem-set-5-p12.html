Problem Set 5: Trigonometric Functions and Graphs

Precalculus 12 - Problem Set
Topics: Sine, Cosine, Tangent Functions, Graphing Medium

Problems

Problem 1

Find the amplitude, period, phase shift, and vertical shift of \(f(x) = 3\cos(2x - \pi) + 2\).

Problem 2

Graph one period of \(f(x) = -2\sin(\frac{\pi}{2}x) + 1\). Label all key points.

Problem 3

A mass on a spring oscillates with position \(x(t) = 0.05\cos(8\pi t)\). Find the amplitude, period, and frequency.

Problem 4

Find the equation of a sine function with amplitude 4, period \(4\pi\), and phase shift \(\frac{\pi}{2}\).

Problem 5

Solve \(2\sin(x) - 1 = 0\) for \(x \in [0, 2\pi)\). Give the general solution.

Problem 6

Graph \(f(x) = \tan(2x)\) and identify the period, asymptotes, and key points.

Problem 7

Temperature varies seasonally: \(T(t) = 10\sin(\frac{2\pi}{365}t) + 15\). Find max, min, and period. When is the first maximum after January 1?

Problem 8

Two waves \(y_1 = 3\sin(x)\) and \(y_2 = 4\cos(x)\) interfere. Find the amplitude and phase of the resultant wave.

Bonus Problems

Bonus Problem 1

Find the exact value of \(\sin(18°)\) using a pentagon or golden ratio. Hint: Use the fact that \(\sin(5 \times 18°) = \sin(90°) = 1\).

Bonus Problem 2

Prove that \(\tan(\theta) + \cot(\theta) = 2\csc(2\theta)\) for all \(\theta\) where the expressions are defined.
