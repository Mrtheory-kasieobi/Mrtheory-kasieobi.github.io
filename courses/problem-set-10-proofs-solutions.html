Solutions: Problem Set 10

Introduction to Proofs - Lecture 10

Key ideas used in these solutions

  • The sum principle counts disjoint classes; the product principle counts independent choices.
  • Binomial coefficients count subsets, which turns algebraic identities into counting arguments.
  • Double counting equates two descriptions of the same finite set.
  • The pigeonhole principle is proved by contradiction and guarantees existence without locating the object.

Worked solutions

Problem 1: Prove Pascal's identity \(\binom nk=\binom{n-1}{k-1}+\binom{n-1}k\) in two ways: combinatorially and algebraically.
Combinatorial. Count \(k\)-subsets of \(\{1,\ldots,n\}\) by whether they contain \(n\): those that do correspond to \((k-1)\)-subsets of \(\{1,\ldots,n-1\}\), and those that do not are \(k\)-subsets of \(\{1,\ldots,n-1\}\). Disjointness and exhaustiveness give the sum.
Algebraic. \[\binom{n-1}{k-1}+\binom{n-1}k=\frac{(n-1)!}{(k-1)!(n-k)!}+\frac{(n-1)!}{k!(n-1-k)!}\] \[=\frac{(n-1)!\big(k+(n-k)\big)}{k!(n-k)!}=\frac{n!}{k!(n-k)!}=\binom nk.\]

Both proofs establish the same identity; the combinatorial one makes the meaning of the terms transparent.

Problem 2: Prove that a set with \(n\) elements has \(2^n\) subsets by induction, and explain how this relates to Theorem 10.5.
Base case. The empty set has exactly one subset, itself, and \(2^0=1\).
Step. Let \(X\) have \(n+1\) elements and choose \(x\in X\). Subsets not containing \(x\) are exactly the subsets of \(X\setminus\{x\}\), of which there are \(2^n\) by hypothesis. Each such subset \(S\) gives exactly one subset containing \(x\), namely \(S\cup\{x\}\). Hence there are \(2\cdot2^n=2^{n+1}\) subsets.

Theorem 10.5 groups these subsets by size, giving the same total as \(\sum_{k=0}^n\binom nk\).

Problem 3: Prove that \(\sum_{k=0}^n k^2\binom nk=n(n+1)2^{n-2}\) for \(n\ge2\). (Hint: count triples \((S,a,b)\) with \(a,b\in S\subseteq X\).)

Count ordered pairs \((a,b)\) chosen from a subset \(S\subseteq X\), where \(|X|=n\). For a fixed subset of size \(k\), there are \(k^2\) ordered pairs, so the total is \(\sum_k k^2\binom nk\).

Count instead by choosing \(a,b\in X\): there are \(n^2\) ordered pairs \((a,b)\). If \(a\ne b\), there are \(n(n-1)\) such pairs and \(2^{n-2}\) subsets containing both; if \(a=b\), there are \(n\) pairs and \(2^{n-1}\) subsets containing \(a\). Hence the total is \[n(n-1)2^{n-2}+n2^{n-1}=n2^{n-2}\big((n-1)+2\big)=n(n+1)2^{n-2}.\] Equating the two counts proves the identity.

Problem 4: Prove that in any group of \(n\) people there are at least two people with the same number of acquaintances within the group.

Assume acquaintance is mutual. Each person has between \(0\) and \(n-1\) acquaintances. The values \(0\) and \(n-1\) cannot both occur: if someone knows everyone, no one can know zero people. Thus the \(n\) people have acquaintance counts drawn from at most \(n-1\) possible values. By the pigeonhole principle, two people share a count.

Problem 5: Prove that \(\binom n0+\binom n1+\cdots+\binom nn=2^n\) using the binomial theorem, and compare with the combinatorial proof.

Set \(x=y=1\) in \((x+y)^n=\sum_{k=0}^n\binom nk x^{n-k}y^k\). The left side is \(2^n\) and the right side is the sum of the binomial coefficients. The algebraic route is one line, while the combinatorial route explains each term as the number of subsets of a given size. Both are valid; the second gives insight into the meaning of the identity.

Problem 6: Prove that \(\binom{2n}{n}=\sum_{k=0}^n\binom{n}{k}^2\) by double counting.

Let \(A,B\) be disjoint \(n\)-element sets and count the \(n\)-element subsets of \(A\cup B\). The total number is \(\binom{2n}{n}\). Alternatively, a subset with exactly \(k\) elements from \(A\) must have \(n-k\) from \(B\); there are \(\binom nk\binom n{n-k}=\binom{n}{k}^2\) such subsets. Summing over \(k=0,\ldots,n\) gives the right-hand side. Since both counts describe the same collection, the identity follows.

Problem 7: Prove that \(\binom n2+\binom{n+1}2=n^2\) for \(n\ge1\) by a counting argument.

Count ordered pairs \((i,j)\) with \(1\le i,j\le n\) and \(i\ne j\). There are \(n^2-n=n(n-1)\) such pairs, which is \(2\binom n2\), not \(\binom n2+\binom{n+1}2\) in general. Compute the proposed identity directly: \[\binom n2+\binom{n+1}2=\frac{n(n-1)}2+\frac{n(n+1)}2=n^2.\] So the identity is true algebraically. A counting interpretation: \(n^2\) counts all pairs \((i,j)\) in an \(n\times n\) grid. Split them into those with \(i<j\) and those with \(i\ge j\). The first class has \(\binom n2\) elements. The second has \(\binom n2+n=\binom{n+1}2\) elements, since it consists of the \(\binom n2\) pairs with \(i>j\) plus the \(n\) diagonal pairs. Thus the identity counts the grid by a diagonal split.

Problem 8: Use the pigeonhole principle to prove that every sequence of \(n^2+1\) distinct real numbers contains a subsequence of length \(n+1\) that is strictly increasing or strictly decreasing.

For each position \(i\), let \(a_i\) be the length of the longest increasing subsequence ending at that term and \(b_i\) the length of the longest decreasing subsequence ending there. If both \(a_i\le n\) and \(b_i\le n\) for all \(i\), then each term gets a pair \((a_i,b_i)\) from an \(n\times n\) grid of \(n^2\) possible pairs. With \(n^2+1\) terms, two terms share the same pair by the pigeonhole principle. For an earlier term \(i<j\), if the values increase then \(a_j>a_i\), and if they decrease then \(b_j>b_i\); both contradict equality of the pairs. Hence some term has \(a_i>n\) or \(b_i>n\), giving the required subsequence.

Problem 9: Prove that the number of ways to distribute \(n\) identical objects into \(k\) distinct boxes is \(\binom{n+k-1}{k-1}\).

Represent a distribution by a string of \(n\) stars and \(k-1\) bars: the number of stars before the first bar is the contents of box \(1\), between bars the contents of the next box, and after the last bar the contents of box \(k\). Every distribution corresponds to exactly one such string and conversely. The string has \(n+k-1\) positions; choosing which \(k-1\) positions hold bars determines it, giving \(\binom{n+k-1}{k-1}\) possibilities.

Bonus Problem: Give a double-counting proof that \(\sum_{k=0}^n\binom nk^2=\binom{2n}n\).
Split a \(2n\)-element set into two halves \(X\) and \(Y\), each of size \(n\). The right side counts \(n\)-element subsets of \(X\cup Y\). The left side counts the same subsets by choosing \(k\) elements from \(X\) and \(n-k\) elements from \(Y\), giving \(\binom nk\binom n{n-k}=\binom nk^2\) choices for each \(k\). Summing over \(k\) gives the identity.
