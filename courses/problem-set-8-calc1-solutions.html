Problem Set 8: Definite Integrals - SOLUTIONS

Calculus I - Week 8

Solution Guide

Note: These are detailed solutions showing all steps and reasoning. Each step is clearly justified.

Problem 1: \(\int_0^1 (x^2 + 2x + 1) \, dx\)

Solution:
Step 1: Integrate term by term
\(\int_0^1 x^2 dx + \int_0^1 2x dx + \int_0^1 1 dx\)
Step 2: Find antiderivatives
\(\frac{x^3}{3} + x^2 + x\)
Step 3: Apply FTC
\(\left[\frac{x^3}{3} + x^2 + x\right]_0^1 = \frac{1}{3} + 1 + 1 - 0 = \frac{7}{3}\)
Final Answer:
\(\boxed{\frac{7}{3}}\)

Problem 2: Area between \(y = x^2\) and \(y = x\) on \([0, 1]\)

Solution:
Step 1: Determine which function is greater
On \([0,1]\): \(x \geq x^2\) (since \(x - x^2 = x(1-x) \geq 0\))
Step 2: Set up integral
\(\text{Area} = \int_0^1 (x - x^2) dx\)
Step 3: Integrate
\(\left[\frac{x^2}{2} - \frac{x^3}{3}\right]_0^1\)
Step 4: Evaluate
\(\frac{1}{2} - \frac{1}{3} = \frac{3-2}{6} = \frac{1}{6}\)
Final Answer:
\(\boxed{\frac{1}{6}}\)

Problem 3: \(\int_{-1}^2 (x^3 - 4x) \, dx\)

Solution:
Step 1: Find antiderivative
\(\frac{x^4}{4} - 2x^2\)
Step 2: Apply FTC
\(\left[\frac{x^4}{4} - 2x^2\right]_{-1}^2\)
Step 3: Evaluate at upper limit
\(\frac{16}{4} - 8 = 4 - 8 = -4\)
Step 4: Evaluate at lower limit
\(\frac{1}{4} - 2 = -\frac{7}{4}\)
Step 5: Subtract
\(-4 - (-\frac{7}{4}) = -4 + \frac{7}{4} = -\frac{9}{4}\)
Final Answer:
\(\boxed{-\frac{9}{4}}\)

Problem 4: Average value of \(f(x) = x^2\) on \([0, 2]\)

Solution:
Step 1: Use average value formula
\(f_{avg} = \frac{1}{b-a}\int_a^b f(x)dx\)
Step 2: Set up
\(f_{avg} = \frac{1}{2}\int_0^2 x^2 dx\)
Step 3: Integrate
\(\frac{1}{2} \cdot \frac{x^3}{3}\Big|_0^2\)
Step 4: Evaluate
\(\frac{1}{2} \cdot \frac{8}{3} = \frac{4}{3}\)
Final Answer:
\(\boxed{\frac{4}{3}}\)

Problem 5: \(\int \frac{e^x}{e^x + 1} \, dx\)

Solution:
Step 1: Use substitution
Let \(u = e^x + 1\), then \(du = e^x dx\)
Step 2: Rewrite integral
\(\int \frac{1}{u} du\)
Step 3: Integrate
\(\ln|u| + C\)
Step 4: Substitute back
\(\ln(e^x + 1) + C\)
Final Answer:
\(\boxed{\ln(e^x + 1) + C}\)

Problem 6: \(\int_0^{\pi/4} \sin x \cos x \, dx\)

Solution:
Step 1: Use substitution
Let \(u = \sin x\), \(du = \cos x \, dx\)
Step 2: Change limits
When \(x = 0\): \(u = 0\). When \(x = \pi/4\): \(u = \frac{\sqrt{2}}{2}\)
Step 3: Integrate
\(\int_0^{\sqrt{2}/2} u \, du = \frac{u^2}{2}\Big|_0^{\sqrt{2}/2} = \frac{1}{4}\)
Final Answer:
\(\boxed{\frac{1}{4}}\)

Problem 7: \(\int \frac{x}{x^2 + 1} \, dx\)

Solution:
Step 1: Use substitution
Let \(u = x^2 + 1\), \(du = 2x \, dx\), so \(x \, dx = \frac{du}{2}\)
Step 2: Rewrite integral
\(\frac{1}{2}\int \frac{1}{u} du\)
Step 3: Integrate
\(\frac{1}{2}\ln|u| + C\)
Step 4: Substitute back
\(\frac{1}{2}\ln(x^2 + 1) + C\)
Final Answer:
\(\boxed{\frac{1}{2}\ln(x^2 + 1) + C}\)

Problem 8: \(\int_0^1 \frac{1}{x^2 + 1} \, dx\)

Solution:
Step 1: Recognize arctangent form
\(\int \frac{dx}{x^2 + 1} = \tan^{-1}x\)
Step 2: Apply FTC
\([\tan^{-1}x]_0^1 = \tan^{-1}(1) - \tan^{-1}(0)\)
Step 3: Evaluate
\(\frac{\pi}{4} - 0 = \frac{\pi}{4}\)
Final Answer:
\(\boxed{\frac{\pi}{4}}\)

Problem 9: Prove \(\int_a^b f(x)dx = -\int_b^a f(x)dx\)

Solution:
Step 1: Apply FTC to both integrals
\(\int_a^b f(x)dx = F(b) - F(a)\)
Step 2: Apply FTC to reversed integral
\(\int_b^a f(x)dx = F(a) - F(b)\)
Step 3: Compare
\(F(a) - F(b) = -[F(b) - F(a)]\)
Conclusion:
\(\int_b^a f(x)dx = -\int_a^b f(x)dx\)
Final Answer:
\(\boxed{\int_a^b f(x)dx = -\int_b^a f(x)dx}\)

Problem 10: Total area between \(y = x^3\) and \(y = x\) on \([-1, 1]\)

Solution:
Step 1: Find intersection points
\(x^3 = x \Rightarrow x(x^2 - 1) = 0 \Rightarrow x = -1, 0, 1\)
Step 2: Determine which function is greater in each region
On \([-1, 0]\): \(x^3 \geq x\)
On \([0, 1]\): \(x \geq x^3\)
Step 3: Set up integrals
\(\text{Area} = \int_{-1}^0 (x^3 - x)dx + \int_0^1 (x - x^3)dx\)
Step 4: Integrate
\(\left[\frac{x^4}{4} - \frac{x^2}{2}\right]_{-1}^0 + \left[\frac{x^2}{2} - \frac{x^4}{4}\right]_0^1\)
Step 5: Evaluate
\(0 - (\frac{1}{4} - \frac{1}{2}) + (\frac{1}{2} - \frac{1}{4}) - 0 = \frac{1}{4} + \frac{1}{4} = \frac{1}{2}\)
Final Answer:
\(\boxed{\frac{1}{2}}\)

Bonus 1: \(\int_0^{\pi/2} \sin^2 x \, dx\)

Solution:
Step 1: Use half-angle identity
\(\sin^2 x = \frac{1 - \cos 2x}{2}\)
Step 2: Integrate
\(\int_0^{\pi/2} \frac{1 - \cos 2x}{2} dx = \frac{1}{2}[x - \frac{\sin 2x}{2}]_0^{\pi/2}\)
Step 3: Evaluate
\(\frac{1}{2}[\frac{\pi}{2} - 0] = \frac{\pi}{4}\)
Final Answer:
\(\boxed{\frac{\pi}{4}}\)

Bonus 2: \(\int_1^e \frac{\ln x}{x} \, dx\)

Solution:
Step 1: Use substitution
Let \(u = \ln x\), \(du = \frac{1}{x}dx\)
Step 2: Change limits
When \(x = 1\): \(u = 0\). When \(x = e\): \(u = 1\)
Step 3: Integrate
\(\int_0^1 u \, du = \frac{u^2}{2}\Big|_0^1 = \frac{1}{2}\)
Final Answer:
\(\boxed{\frac{1}{2}}\)
