Problem Set 6: Linear Functions

Mathematics 10 - Chapter 6 Solutions

Solutions

Problem 1: Find the slope and y-intercept of \(y = 3x - 7\)
This is in slope-intercept form \(y = mx + b\)
Slope \(m = 3\)
y-intercept \(b = -7\) (the point is \((0, -7)\))
Answer: Slope = 3, y-intercept = -7
Problem 2: Find the equation of a line passing through \((2, 5)\) and \((6, 13)\)
First find slope: \(m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{13 - 5}{6 - 2} = \frac{8}{4} = 2\)
Use point-slope form with point \((2, 5)\): \(y - 5 = 2(x - 2)\)
Simplify: \(y - 5 = 2x - 4\)
\(y = 2x + 1\)
Answer: \(y = 2x + 1\)
Problem 3: Graph \(2x + 3y \leq 6\) and shade the correct region
First graph the boundary line \(2x + 3y = 6\)
Find intercepts: x-intercept when \(y = 0\): \(x = 3\); y-intercept when \(x = 0\): \(y = 2\)
Draw line through (3, 0) and (0, 2) - solid line because of ≤
Test point (0, 0): \(2(0) + 3(0) = 0 \leq 6\) ✓
Shade the region containing (0, 0) - below the line
Answer: Region below and including the line through (3, 0) and (0, 2).
Problem 4: Solve: \(4(x - 3) + 2 = 3x + 5\)
Expand left side: \(4x - 12 + 2 = 3x + 5\)
Simplify: \(4x - 10 = 3x + 5\)
Subtract \(3x\) from both sides: \(x - 10 = 5\)
Add 10 to both sides: \(x = 15\)
Check: \(4(15-3) + 2 = 4(12) + 2 = 50\), \(3(15) + 5 = 50\) ✓
Answer: \(x = 15\)
Problem 5: Find \(f(2)\), \(f(-1)\), and \(f(0)\) for \(f(x) = -2x + 5\)
\(f(2) = -2(2) + 5 = -4 + 5 = 1\)
\(f(-1) = -2(-1) + 5 = 2 + 5 = 7\)
\(f(0) = -2(0) + 5 = 5\)
Answer: \(f(2) = 1\), \(f(-1) = 7\), \(f(0) = 5\)
Problem 6: Write in point-slope form: slope 4 through \((-1, 3)\)
Point-slope form: \(y - y_1 = m(x - x_1)\)
Substitute: \(y - 3 = 4(x - (-1))\)
Simplify: \(y - 3 = 4(x + 1)\)
Answer: \(y - 3 = 4(x + 1)\)
Problem 7: Find the x-intercept and y-intercept of \(3x - 4y = 12\)
x-intercept: set \(y = 0\): \(3x = 12\), so \(x = 4\). Point: \((4, 0)\)
y-intercept: set \(x = 0\): \(-4y = 12\), so \(y = -3\). Point: \((0, -3)\)
Answer: x-intercept = 4 (point \((4, 0)\)), y-intercept = -3 (point \((0, -3)\))
Problem 8: Lines with slopes \(m_1 = 2\) and \(m_2 = -3\) - parallel, perpendicular, or neither?
Parallel lines have equal slopes: \(2 \neq -3\), so not parallel
Perpendicular lines have slopes that are negative reciprocals: \(m_1 \times m_2 = 2 \times (-3) = -6 \neq -1\)
Since the product is not -1, they are not perpendicular
Answer: Neither parallel nor perpendicular

Bonus Solutions

Bonus Problem 1: Slope Detective
If a line passes through (x₁, y₁) and (x₂, y₂), slope = (y₂-y₁)/(x₂-x₁)
If both points are lattice points, numerator and denominator are integers
Therefore slope is a ratio of integers = rational number
Find line with slope 3/4 and rational y-intercept:
Use point (0, 1): slope = rise/run = 3/4
Equation: y = (3/4)x + 1
y-intercept = 1 (rational) ✓
Answer: Slope must be rational. Example: \(y = \frac{3}{4}x + 1\).
Bonus Problem 2: Intersection and Distance Puzzle
Find intersection: \(2x + 3 = -x + 9\)
\(3x = 6\), so \(x = 2\)
\(y = 2(2) + 3 = 7\). Intersection: (2, 7)
Distance from origin to Line A: \(d = \frac{|2(0) - 1(0) + 3|}{\sqrt{2^2 + (-1)^2}} = \frac{3}{\sqrt{5}}\)
Distance from origin to Line B: \(d = \frac{|-1(0) - 1(0) + 9|}{\sqrt{(-1)^2 + (-1)^2}} = \frac{9}{\sqrt{2}}\)
Compare: \(\frac{3}{\sqrt{5}} \approx 1.34\) vs \(\frac{9}{\sqrt{2}} \approx 6.36\)
Answer: Intersection at (2, 7). Line A is closer to origin with distance \(\frac{3}{\sqrt{5}}\).
Bonus Problem 3: System Challenge
System: \(y = 2x + 1\) and \(y^2 = 4x + 1\)
Substitute \(y = 2x + 1\) into \(y^2 = 4x + 1\):
\((2x + 1)^2 = 4x + 1\)
Expand: \(4x^2 + 4x + 1 = 4x + 1\)
Subtract \(4x + 1\) from both sides:
\(4x^2 = 0\)
\(x = 0\)
Substitute back: \(y = 2(0) + 1 = 1\)
So the only solution is \((0, 1)\).
Verification:
Check in first equation: \(y = 2(0) + 1 = 1\) ✓
Check in second equation: \(y^2 = 1^2 = 1\) and \(4x + 1 = 4(0) + 1 = 1\) ✓
Both equations are satisfied.
Why exactly one solution?
The equation \(4x^2 = 0\) has a double root at \(x = 0\) (discriminant \(= 0\)). This means the line \(y = 2x + 1\) is tangent to the parabola \(y^2 = 4x + 1\), touching it at exactly one point.
Answer: The system has exactly one solution: \((0, 1)\).
