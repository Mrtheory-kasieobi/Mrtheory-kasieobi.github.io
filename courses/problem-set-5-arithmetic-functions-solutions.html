Solutions: Problem Set 5: Arithmetic Functions and Möbius Inversion

Elementary Number Theory - Week 6 Solutions

Key Definitions and Concepts

Divisor Function \(d(n)\)

The number of positive divisors of \(n\).

If \(n = p_1^{a_1} \cdots p_k^{a_k}\), then \(d(n) = (a_1 + 1) \cdots (a_k + 1)\).

Euler's Totient Function \(\phi(n)\)

The number of positive integers \(\leq n\) that are coprime to \(n\).

Formula: \(\phi(n) = n \prod_{p|n} \left(1 - \frac{1}{p}\right)\)

Möbius Function \(\mu(n)\)

\[\mu(n) = \begin{cases} 1 & n = 1 \\ (-1)^k & n = p_1 p_2 \cdots p_k \text{ (distinct primes)} \\ 0 & n \text{ has a squared prime factor} \end{cases}\]

Solutions

Problem 1: Find \(\sigma(12)\), where \(\sigma(n)\) is the sum of all positive divisors of \(n\).

Step 1: Find the prime factorization of 12.
\[12 = 2^2 \times 3\]

Step 2: Use the formula for \(\sigma\) with prime powers.

\[\sigma(p^k) = 1 + p + p^2 + \cdots + p^k = \frac{p^{k+1} - 1}{p - 1}\]

\[\sigma(12) = \sigma(2^2) \times \sigma(3) \quad \text{(since }\sigma\text{ is multiplicative)}\]
\[\sigma(2^2) = 1 + 2 + 4 = 7\]
\[\sigma(3) = 1 + 3 = 4\]
\[\sigma(12) = 7 \times 4 = 28\]

Verification: Divisors of 12 are 1, 2, 3, 4, 6, 12. Sum = 1+2+3+4+6+12 = 28.

Problem 2: Compute \(\phi(36)\) and \(\sigma(36)\).

Step 1: Prime factorization.
\[36 = 2^2 \times 3^2\]

Step 2: Compute \(\phi(36)\).

\[\phi(36) = 36 \times \left(1 - \frac{1}{2}\right) \times \left(1 - \frac{1}{3}\right) = 36 \times \frac{1}{2} \times \frac{2}{3} = 12\]

Or using \(\phi(p^k) = p^k - p^{k-1}\):
\[\phi(36) = \phi(2^2) \times \phi(3^2) = (4 - 2) \times (9 - 3) = 2 \times 6 = 12\]

Step 3: Compute \(\sigma(36)\).

\[\sigma(36) = \sigma(2^2) \times \sigma(3^2) = (1 + 2 + 4) \times (1 + 3 + 9) = 7 \times 13 = 91\]

Answer: \(\phi(36) = 12\), \(\sigma(36) = 91\)

Problem 3: Find \(\mu(30)\) and \(\mu(36)\).

Understanding: \(\mu(n) = 0\) if \(n\) has a squared prime factor, otherwise \((-1)^{\text{number of prime factors}}\).

For \(\mu(30)\):

\[30 = 2 \times 3 \times 5\] (three distinct primes, no squares)
\[\mu(30) = (-1)^3 = -1\]

For \(\mu(36)\):

\[36 = 2^2 \times 3^2\] (has squared primes)
\[\mu(36) = 0\]

Answer: \(\mu(30) = -1\), \(\mu(36) = 0\)

Problem 4: State and prove Möbius Inversion Formula.

Möbius Inversion Formula:

If for all positive integers \(n\):
\[g(n) = \sum_{d|n} f(d)\]

then
\[f(n) = \sum_{d|n} \mu(d) g\left(\frac{n}{d}\right)\]

Proof:

Step 1: Substitute the expression for \(g\).

\[\sum_{d|n} \mu(d) g\left(\frac{n}{d}\right) = \sum_{d|n} \mu(d) \sum_{e|(n/d)} f(e)\]

Let \(k = \frac{n}{de}\), so \(e = \frac{n}{dk}\) and the inner sum becomes:

Step 2: Change variables and use the key identity.

\[\sum_{d|n} \mu(d) \sum_{k|n/d} f\left(\frac{n}{dk}\right) = \sum_{m|n} f\left(\frac{n}{m}\right) \sum_{d|m} \mu(d)\]

The key identity: \[\sum_{d|m} \mu(d) = \begin{cases} 1 & m = 1 \\ 0 & m > 1 \end{cases}\]

Step 3: Conclude.

Only the term \(m = 1\) contributes, giving \(f(n)\).

Problem 5: Prove that \(\sum_{d|n} \phi(d) = n\) for all positive integers \(n\).

Understanding: This identity connects Euler's totient function to all positive integers.

Proof using group theory:

Step 1: Consider the cyclic group \(C_n\) of order \(n\).

An element of \(C_n\) has order \(d\) (where \(d \mid n\)) if and only if it generates a subgroup of order \(d\).

Step 2: Count elements by order.

The number of elements of order exactly \(d\) in \(C_n\) equals the number of generators of the unique subgroup of order \(d\).

This number is \(\phi(d)\):

Step 3: Sum over all divisors.

Every element has order \(d\) for some divisor \(d\) of \(n\).
\[n = |C_n| = \sum_{d|n} (\text{number of elements of order } d) = \sum_{d|n} \phi(d)\]

Combinatorial proof: List fractions \(\frac{a}{n}\) in lowest terms with \(1 \leq a \leq n\). Group by denominator \(d\) where \(d \mid n\).

Bonus Solutions

Bonus Problem 1: Prove \(\sum_{d|n} \mu(d) = 0\) for all \(n > 1\).

Proof:

If \(n = 1\): \(\sum_{d|1} \mu(d) = \mu(1) = 1\).
If \(n > 1\) with prime factorization \(n = p_1^{a_1} \cdots p_k^{a_k}\):

The divisors with \(\mu(d) \neq 0\) are the square-free products of distinct primes dividing \(n\).
\[\sum_{d|n} \mu(d) = \sum_{S \subseteq \{p_1,\ldots,p_k\}} (-1)^{|S|}\]
This equals \((1 - 1)^k = 0^k = 0\) for \(k \geq 1\).

Bonus Problem 2: Show that if \(n = p_1^{a_1} \cdots p_k^{a_k}\), then \(\frac{\phi(n)}{n} = \prod_{i=1}^{k} \frac{p_i - 1}{p_i}\).

Proof:

From the formula \(\phi(n) = n \prod_{p|n} \left(1 - \frac{1}{p}\right)\):
\[\frac{\phi(n)}{n} = \prod_{p|n} \left(1 - \frac{1}{p}\right) = \prod_{i=1}^{k} \left(1 - \frac{1}{p_i}\right) = \prod_{i=1}^{k} \frac{p_i - 1}{p_i}\]

Example verification: For \(n = 12 = 2^2 \times 3\):
\[\frac{\phi(12)}{12} = \frac{4}{12} = \frac{1}{3} = \frac{1}{2} \times \frac{2}{3} = \frac{1 \times 2}{2 \times 3} = \frac{2}{6} = \frac{1}{3} \checkmark\]
