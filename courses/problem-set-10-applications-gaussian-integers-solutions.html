Solutions: Problem Set 10: Applications of Gaussian Integers

Elementary Number Theory - Week 11 Solutions

Key Definitions and Concepts

Fermat's Two Squares Theorem

A prime \(p > 2\) can be written as \(p = x^2 + y^2\) with integers \(x, y\) iff \(p \equiv 1 \pmod{4}\).

Connection to Gaussian integers: This is equivalent to \(p\) splitting in \(\mathbb{Z}[i]\).

Solutions

Problem 1: Express 17 as a sum of two squares.

Solution:

Factor 17 in \(\mathbb{Z}[i]\):

We know 17 ≡ 1 (mod 4), so it factors.
Need \(a^2 + b^2 = 17\) with integers \(a, b\).

Try small values:

1² + 4² = 1 + 16 = 17 ✓

Answer: \(17 = 1^2 + 4^2\)

Problem 2: Show that 61 can be expressed as a sum of two squares and find the representation.

Solution:

Step 1: Verify 61 ≡ 1 (mod 4).
61 = 15 × 4 + 1, so the theorem applies.
Step 2: Find Gaussian integers with norm 61.

Solve \(a^2 + b^2 = 61\):

  • \(a = 5\): \(b^2 = 36\), \(b = \pm 6\)
  • \(a = 6\): \(b^2 = 25\), \(b = \pm 5\)
So \(5 + 6i\) and \(6 + 5i\) have norm 61.

Answer: \(61 = 5^2 + 6^2 = 25 + 36\)

Problem 3: Solve \(x^2 + y^2 = 89\) for integers \(x, y\).

Solution:

Step 1: Check if 89 is prime and ≡ 1 (mod 4).

89 is prime, 89 = 22 × 4 + 1, so it should be expressible.

Step 2: Find representations.

Trial values: \(8^2 = 64\), \(89 - 64 = 25 = 5^2\)
So \(89 = 8^2 + 5^2\)

Answer: \((x, y) = (\pm 8, \pm 5)\) and \((\pm 5, \pm 8)\)

Problem 4: Prove that a prime \(p\) can be written as \(x^2 + y^2\) iff \(p = 2\) or \(p \equiv 1 \pmod{4}\).

Proof: (See Problem Set 9, Problem 5 - this is a fundamental application)

(⇒) Direction: If \(p = x^2 + y^2 = (x+yi)(x-yi)\) in \(\mathbb{Z}[i]\), then \(p\) is not a Gaussian prime (unless it's 1+i up to units, giving \(p=2\)). So \(p\) splits, meaning \(p \equiv 1 \pmod{4}\).

(⇐) Direction: If \(p = 2\) or \(p \equiv 1 \pmod{4}\), then \(p\) factors as \(\pi\bar{\pi}\) in \(\mathbb{Z}[i]\), and \(p = N(\pi) = a^2 + b^2\).

Problem 5: Find the number of representations of 50 as a sum of two squares (counting signs and order).

Solution:

Step 1: Factor 50.
50 = 2 × 25 = 2 × 5²
Step 2: Factor in \(\mathbb{Z}[i]\).
2 = -i(1+i)²
5 = (2+i)(2-i)
50 = -i(1+i)²(2+i)²(2-i)²
Step 3: Find all ways to write 50 as norm.

The representations correspond to \(z \in \mathbb{Z}[i]\) with \(N(z) = 50\).
Method: \(50 = 1^2 + 7^2\) and \(50 = 5^2 + 5^2\) (checking: 1+49=50, 25+25=50)
Also \(50 = 7^2 + 1^2\) (same, different order)

Answer: 50 = 1² + 7² and 5² + 5². Counting all sign/order variations: 4 + 4 = 8 representations.

Problem 6: Show that if \(p \equiv 3 \pmod{4}\) is prime, then \(x^2 + y^2 = p\) has no integer solutions.

Proof:

Theorem: If \(p \equiv 3 \pmod{4}\) is prime, then \(p\) is a Gaussian prime.
Result: If \(p\) is a Gaussian prime, it cannot be written as \(N(a + bi) = a^2 + b^2\) unless \(p\) is a unit times 1 or \(p\) itself.

But \(N(a + bi) = p\) would require \(a + bi\) to be prime in \(\mathbb{Z}[i]\) with norm \(p\).

For \(p \equiv 3 \pmod{4}\), no such Gaussian integer exists (as shown in PS8).

Alternatively: if \(x^2 + y^2 = p\), then in \(\mathbb{Z}[i]\): \((x+yi)(x-yi) = p\).

If \(p\) were prime in \(\mathbb{Z}[i]\), one factor would be a unit, implying \(|x+yi|^2 = 1\), so \(p = 1\), contradiction.

Problem 7: Find integer solutions to \(x^2 + 2y^2 = 17\).

Understanding: This involves the ring \(\mathbb{Z}[\sqrt{-2}]\) or direct search.

Try small values of y:
  • y = 0: \(x^2 = 17\), no integer solution
  • y = 1: \(x^2 = 15\), no integer solution
  • y = 2: \(x^2 = 17 - 8 = 9\), so \(x = \pm 3\)
  • y = 3: \(x^2 = 17 - 18 < 0\), no solution

Answer: \((x, y) = (\pm 3, 2)\)

Problem 8: Prove that if \(p \equiv 1 \pmod{4}\) is prime, then \(p\) divides \(x^2 + 1\) for some integer \(x\).

Proof:

From the theory of Gaussian integers:

If \(p \equiv 1 \pmod{4}\), then \(p = \pi\bar{\pi}\) in \(\mathbb{Z}[i]\) for some prime \(\pi = a + bi\).
Hence \(p = N(\pi) = a^2 + b^2\) for some integers \(a, b\).
In particular, taking \(x = a\): \(p \mid (a^2 + 1)\)... wait, that's not quite right.

Better approach using Wilson's Theorem modification:

For \(p \equiv 1 \pmod{4}\): \(\left(\frac{-1}{p}\right) = 1\)

By Euler's criterion: \((-1)^{\frac{p-1}{2}} \equiv 1 \pmod{p}\)

This means there exists \(x\) with \(x^2 \equiv -1 \pmod{p}\), i.e., \(p \mid (x^2 + 1)\)

Bonus Solutions

Bonus Problem 1: Find the number of ways to write 25 as a sum of two squares.

Solution:

Factor: 25 = 5² = (2+i)²(2-i)²

Finding all \(a+bi\) with norm 25:

Direct search: \(0^2 + 5^2 = 25\), \(3^2 + 4^2 = 9 + 16 = 25\)
So: ±5² + 0² and 0² + ±5² give 4 representations
And: ±3² + ±4² and ±4² + ±3² give 8 representations
Total: 12 representations (counting signs and order)

Bonus Problem 2: Prove: If every prime \(p \equiv 1 \pmod{4}\) can be written as \(x^2 + y^2\), then every integer with all prime factors \(q \equiv 3 \pmod{4}\) appearing to even power can be written as \(x^2 + y^2\).

Proof:

If \(n = 2^a \prod_{p_i \equiv 1} p_i^{e_i} \prod_{q_j \equiv 3} q_j^{2f_j}\), then by the theorem each \(p_i = a_i^2 + b_i^2\) and \(q_j^{2f_j} = (q_j^{f_j})^2 + 0^2\).

Using the identity \((a^2+b^2)(c^2+d^2) = (ac-bd)^2 + (ad+bc)^2\) repeatedly, the product can be written as a sum of two squares.
