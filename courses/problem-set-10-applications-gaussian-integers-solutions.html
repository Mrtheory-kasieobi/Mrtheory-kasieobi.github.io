Solutions: Problem Set 10: Applications of Gaussian Integers

Elementary Number Theory - Week 11 Solutions

Key Ideas

Sums of two squares and Gaussian integers

The main tool is the norm: \(N(a+bi)=a^2+b^2\). If a number factors in \(\mathbb{Z}[i]\), its norm factors in the ordinary integers. This connects prime factorization in \(\mathbb{Z}[i]\) to writing numbers as sums of two squares.

Solutions

Problem 1

Express 17 as a sum of two squares.

Because \(17\equiv 1\pmod4\), it should be possible. Try small values: \(1^2+4^2=1+16=17\).

Answer. \(17=1^2+4^2\).

Problem 2

Show that 61 can be expressed as a sum of two squares and find the representation.

Because \(61\equiv 1\pmod4\), it can be written as a sum of two squares. Solving \(a^2+b^2=61\) by trial gives \(5^2+6^2=25+36=61\).

Answer. \(61=5^2+6^2\).

Problem 3

Solve \(x^2+y^2=89\) for integers \(x,y\).

Because 89 is prime and \(89\equiv 1\pmod4\), it is a sum of two squares. Trial gives \(8^2+5^2=64+25=89\).

Answer. \((x,y)=(\pm8,\pm5)\) and \((\pm5,\pm8)\).

Problem 4

Prove that a prime \(p\) can be written as \(x^2+y^2\) iff \(p=2\) or \(p\equiv 1\pmod4\).

If direction. If \(p=x^2+y^2\), then \(p=(x+yi)(x-yi)\) in \(\mathbb{Z}[i]\). For \(p>2\), this means \(p\) is not a Gaussian prime. The only rational primes that stay prime in \(\mathbb{Z}[i]\) are \(p=2\) and primes with \(p\equiv 3\pmod4\). Therefore we must have \(p=2\) or \(p\equiv 1\pmod4\).
Only if direction. If \(p=2\), then \(2=1^2+1^2\). If \(p\equiv 1\pmod4\), then \(p\) splits in \(\mathbb{Z}[i]\) as \(p=\pi\overline{\pi}\) for some Gaussian prime \(\pi=a+bi\). Taking norms gives \(p=a^2+b^2\).
Problem 5

Find the number of representations of 50 as a sum of two squares, counting signs and order.

Factor \(50=2\cdot 5^2\). In \(\mathbb{Z}[i]\):
\(2=-i(1+i)^2\)
\(5=(2+i)(2-i)\)

To count representations, find all Gaussian integers with norm 50. Direct search shows \(50=1^2+7^2\) and \(50=5^2+5^2\).

For \(1^2+7^2\): there are 8 signed/ordered variations.
For \(5^2+5^2\): there are 4 signed/ordered variations.

Answer. 12 representations in total.

Problem 6

Show that if \(p\equiv 3\pmod4\) is prime, then \(x^2+y^2=p\) has no integer solutions.

Work modulo 4. Perfect squares modulo 4 are only 0 or 1. So the sum of two squares modulo 4 can only be 0, 1, or 2. It can never be 3. Therefore no integer congruent to 3 modulo 4 can equal \(x^2+y^2\).

Problem 7

Find integer solutions to \(x^2+2y^2=17\).

Try small values of \(y\):
\(y=0\): \(x^2=17\), not a square.
\(y=1\): \(x^2=15\), not a square.
\(y=2\): \(x^2=17-8=9\), so \(x=\pm3\).

Answer. \((x,y)=(\pm3,2)\).

Problem 8

Prove that if \(p\equiv 1\pmod4\) is prime, then \(p\mid x^2+1\) for some integer \(x\).

Because \(p\equiv 1\pmod4\), we know \(-1\) is a quadratic residue modulo \(p\). By Euler's criterion, \((-1)^{(p-1)/2}\equiv 1\pmod p\). This means there exists an integer \(x\) with \(x^2\equiv -1\pmod p\), or equivalently \(p\mid x^2+1\).

Problem 9

If \(m\) and \(n\) are both sums of two squares, show that \(mn\) is also a sum of two squares.

Write \(m=a^2+b^2\) and \(n=c^2+d^2\). Use the identity
\((a^2+b^2)(c^2+d^2)=(ac-bd)^2+(ad+bc)^2\).

Therefore \(mn=(ac-bd)^2+(ad+bc)^2\) is a sum of two squares.

Problem 10

Use Gaussian integers to find a solution to \(x^2+y^2=125\).

Factor \(125=5^3\). Since \(5=(2+i)(2-i)\), we can use \((1+2i)^3\) because \(N(1+2i)=5\). Compute:
\((1+2i)^2=-3+4i\)
\((1+2i)^3=(-3+4i)(1+2i)=-11-2i\)

Answer. \((-11)^2+(-2)^2=125\).

Bonus Solutions

Bonus Problem 1

Find the number of ways to write 25 as a sum of two squares, counting signs and order.

Direct search gives \(0^2+5^2=25\) and \(3^2+4^2=25\).
For \(0^2+5^2\): 4 signed/ordered variations.
For \(3^2+4^2\): 8 signed/ordered variations.

Answer. 12 representations.

Bonus Problem 2

Prove: if every prime \(p\equiv 1\pmod4\) can be written as \(x^2+y^2\), then every integer whose prime factors \(q\equiv 3\pmod4\) all appear to even power can be written as \(x^2+y^2\).

Write \(n=2^a\prod_{p_i\equiv 1}p_i^{e_i}\prod_{q_j\equiv 3}q_j^{2f_j}\). Each prime \(p_i\equiv 1\pmod4\) equals \(a_i^2+b_i^2\). Each \(q_j^{2f_j}=(q_j^{f_j})^2+0^2\). Using the identity \((a^2+b^2)(c^2+d^2)=(ac-bd)^2+(ad+bc)^2\) repeatedly, the whole product can be written as a sum of two squares.

Bonus Problem 3

Find all integer solutions to \(x^2+5y^2=41\).

Try small values of \(y\):
\(y=0\): \(x^2=41\), not a square.
\(y=\pm1\): \(x^2=36\), so \(x=\pm6\).
\(y=\pm2\): \(x^2=21\), not a square.
\(y=\pm3\): \(x^2=-4\), impossible.

Answer. \((x,y)=(\pm6,\pm1)\).
