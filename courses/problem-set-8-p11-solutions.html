Solutions: Problem Set 8

Absolute Value - Precalculus 11
Solution 1
Problem: Evaluate: \(|5 - 9|\)
Compute inside: \(5 - 9 = -4\)
Absolute value: \(|-4| = 4\)
Answer: \(\boxed{4}\)
Solution 2
Problem: Solve: \(|x| = 7\)
By definition of absolute value: \(x = 7\) or \(x = -7\)
Answer: \(\boxed{x = 7 \text{ or } x = -7}\)
Solution 3
Problem: Solve: \(|2x - 3| = 5\)
Case 1: \(2x - 3 = 5\) → \(2x = 8\) → \(x = 4\)
Case 2: \(2x - 3 = -5\) → \(2x = -2\) → \(x = -1\)
Answer: \(\boxed{x = 4 \text{ or } x = -1}\)
Solution 4
Problem: Solve: \(|x + 4| = |x - 2|\)
Square both sides: \((x+4)^2 = (x-2)^2\)
Expand: \(x^2 + 8x + 16 = x^2 - 4x + 4\)
Cancel \(x^2\): \(8x + 16 = -4x + 4\)
Combine: \(12x = -12\) → \(x = -1\)
Answer: \(\boxed{x = -1}\)
Solution 5
Problem: Graph \(y = |x - 3| + 2\). State the vertex.
The parent function \(y = |x|\) has vertex at \((0, 0)\)
Transformations: right 3, up 2
Vertex: \((3, 2)\)
Answer: \(\boxed{\text{Vertex: } (3, 2)}\)
Solution 6
Problem: Graph \(y = -2|x + 1|\). State the domain, range, and vertex.
Parent: \(y = |x|\) with vertex at \((-1, 0)\)
Transformations: reflected over x-axis, vertically stretched by 2
Vertex: \((-1, 0)\)
Domain: \((-\infty, \infty)\)
Range: \((-\infty, 0]\)
Answer: \(\boxed{\text{Vertex: } (-1, 0), \text{Domain: } (-\infty, \infty), \text{Range: } (-\infty, 0]}\)
Solution 7
Problem: Solve by graphing: \(|x - 5| = x + 1\)
Case 1 (x ≥ 5): \(x - 5 = x + 1\) → \(-5 = 1\) ✗
Case 2 (x < 5): \(-(x - 5) = x + 1\) → \(-x + 5 = x + 1\) → \(4 = 2x\) → \(x = 2\)
Verify: \(|2 - 5| = 3 = 2 + 1\) ✓
Answer: \(\boxed{x = 2}\)
Solution 8
Problem: Write an absolute value function with vertex at \((-2, 3)\) that opens downward.
Standard form: \(y = a|x - h| + k\) with vertex \((h, k)\)
Plug in vertex: \(y = a|x + 2| + 3\)
For downward opening: \(a < 0\), let \(a = -1\)
Answer: \(\boxed{y = -|x + 2| + 3}\)

Bonus Solutions

Bonus Solution 1
Problem: Solve: \(|2x + 1| = |x - 3| + 4\). Then graph the solution set of \(|x - 2| \leq 3\) on a number line.
Case 1: \(x \geq 3\) → \(2x + 1 = x - 3 + 4\) → \(x = 0\) (not in domain)
Case 2: \(x < 3\) and \(x \geq -0.5\) → \(2x + 1 = -(x-3) + 4 = -x + 7\) → \(3x = 6\) → \(x = 2\)
Case 3: \(x < -0.5\) → \(-(2x + 1) = x - 3 + 4 = x + 1\) → \(-2x - 1 = x + 1\) → \(x = -2/3\)
Verify case 3: \(|-4/3 + 1| = 1/3\), \(|-2/3 - 3| + 4 = 19/3 + 4 \neq 1/3\) ✗
Solution: \(x = 2\)
Inequality: \(|x - 2| \leq 3\) → \(-3 \leq x - 2 \leq 3\) → \(-1 \leq x \leq 5\)
Answer: \(\boxed{x = 2}\) and graph: closed interval \([-1, 5]\)
Bonus Solution 2
Problem: Find the x-intercept(s) of \(y = |x^2 - 4|\). Hence, determine all x for which \(|x^2 - 4| = x + 2\)
x-intercepts: \(|x^2 - 4| = 0\) → \(x^2 - 4 = 0\) → \(x = \pm 2\)
For equation: Consider cases
Case 1: \(x^2 \geq 4\) → \(x^2 - 4 = x + 2\) → \(x^2 - x - 6 = 0\) → \((x-3)(x+2) = 0\)
Solutions: \(x = 3, -2\). Need \(|x| \geq 2\) → both valid
Case 2: \(x^2 < 4\) → \(-(x^2 - 4) = x + 2\) → \(-x^2 + 4 = x + 2\) → \(x^2 + x - 2 = 0\) → \((x+2)(x-1) = 0\)
Solutions: \(x = -2, 1\). Need \(|x| < 2\) → only \(x = 1\) valid
Answer: \(\boxed{x = 3, -2, \text{ and } 1}\)
