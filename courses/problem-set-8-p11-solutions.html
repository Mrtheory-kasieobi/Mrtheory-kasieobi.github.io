Problem Set 8 Solutions

Rational Equations and Extraneous Solutions | Precalculus 11

Solutions

Problem 1

Solution:

Multiply by \((x)(x+4)(x+2)\):

\[(x+4)(x+2) + x(x+2) = 2x(x+4)\]

\[x^2 + 6x + 8 + x^2 + 2x = 2x^2 + 8x\]

\[2x^2 + 8x + 8 = 2x^2 + 8x\]

\[8 = 0 \quad \text{(contradiction)}\]

Solution: No solution.

Check: Exclude \(x = 0, -4, -2\)

Problem 2

Solution:

Multiply by \((x-1)(x+1)\):

\[3(x+1) - 2(x-1) = 5\]

\[3x + 3 - 2x + 2 = 5\]

\[x + 5 = 5\]

\[x = 0\]

Check: \(x \neq 1, -1\). Solution \(x = 0\) is valid.

Problem 3

Solution:

Multiply by \((x^2-9) = (x-3)(x+3)\):

\[x(x+3) + 2(x-3) = 3\]

\[x^2 + 3x + 2x - 6 = 3\]

\[x^2 + 5x - 9 = 0\]

Using quadratic formula: \(x = \frac{-5 \pm \sqrt{25 + 36}}{2} = \frac{-5 \pm \sqrt{61}}{2}\)

Check: \(x \neq 3, -3\). Both solutions valid.

Problem 4

Solution:

Cross multiply: \(x + 2 = 2(x-2)\)

\[x + 2 = 2x - 4\]

\[x = 6\]

Check: \(x \neq 2\). Solution \(x = 6\) is valid.

Problem 5

Solution:

Multiply by \((x^2-1) = (x-1)(x+1)\):

\[(x+1) + (x-1) = 4\]

\[2x = 4\]

\[x = 2\]

Check: \(x \neq 1, -1\). Solution \(x = 2\) is valid.

Problem 6

Solution:

\(2|x - 4| = x + 2\)

Let \(u = x - 4\), so \(x = u + 4\)

\[2|u| = u + 6\]

Case 1: \(u \geq 0\): \(2u = u + 6 \Rightarrow u = 6 \Rightarrow x = 10\)

Check: \(2|6| = 12 = 10 + 2 = 12 \checkmark\)

Case 2: \(u < 0\): \(-2u = u + 6 \Rightarrow -3u = 6 \Rightarrow u = -2 \Rightarrow x = 2\)

Check: \(2|-2| = 4 = 2 + 2 = 4 \checkmark\)

Solutions: \(x = 2, 10\)

Problem 7

Solution:

Multiply by \((x^2-4) = (x-2)(x+2)\):

\[(3x+2)(x+2) = 2(x-2)(x+2) + (x-2)\]

\[3x^2 + 8x + 4 = 2(x^2-4) + x - 2\]

\[3x^2 + 8x + 4 = 2x^2 - 8 + x - 2\]

\[x^2 + 7x + 14 = x - 10\]

\[x^2 + 6x + 24 = 0\]

Discriminant: \(36 - 96 = -60 < 0\)

Solution: No real solutions.

Problem 8

Solution:

Cross multiply: \(x(x-5) = (x-3)(x+5)\]

\[x^2 - 5x = x^2 + 2x - 15\]

\[-7x = -15\]

\[x = \frac{15}{7}\]

Check: \(x \neq 5, -5\). Solution valid.

Problem 9

Solution:

Multiply by \((x^2-1)\):

\[2(x+1) + 3(x-1) = 5x\]

\[2x + 2 + 3x - 3 = 5x\]

\[5x - 1 = 5x\]

\[-1 = 0 \quad \text{(contradiction)}\]

Solution: No solution.

Problem 10

Solution:

Multiply by \((x^2-9)\):

\[(x+2)(x+3) - (x-2)(x+3) = 10(x+3)\]

Wait, let me recalculate using correct LCD.

\[(x+2)(x-3) - (x-2)(x+3) = 10\]

\[(x^2 - x - 6) - (x^2 + x - 6) = 10\]

\[-2x = 10\]

\[x = -5\]

Check: \(x \neq 3, -3, 2, -2\). Solution \(x = -5\) valid.
