Problem Set 13: Final Review

Calculus I - Final Exam Review

Instructions

Show all work. No calculators. Time limit: 120 minutes.

Problems

  • 1. Find the domain and range of \(f(x) = \frac{x^2 - 4}{x - 2}\)
  • 2. Evaluate \(\lim_{x \to 0} \frac{\sin(3x) - 3\sin x}{x^3}\) using L'Hôpital's Rule
  • 3. Find \(\frac{d}{dx}[(x^2 + 1)^{10}]\)
  • 4. Find the equation of the tangent line to \(y = e^{x^2}\) at \(x = 1\)
  • 5. Use implicit differentiation to find \(\frac{dy}{dx}\) for \(x^2 + xy + y^2 = 3\)
  • 6. A rectangular box with square base is to have volume 2000 cm³. Find dimensions for minimum surface area
  • 7. Find the local and absolute extrema of \(f(x) = x + \frac{2}{x}\) on \([1, 4]\)
  • 8. Find the intervals of increase/decrease and concavity for \(f(x) = \frac{x}{x^2 + 1}\)
  • 9. Evaluate \(\int_0^1 (3x^2 + 2x + 1) \, dx\) using the FTC
  • 10. Find the area between \(y = x^3\) and \(y = x\) on \([-1, 2]\)
  • 11. Find the volume of the solid obtained by rotating the region bounded by \(y = \sqrt{x}\), \(y = 0\), \(x = 4\) about the x-axis
  • 12. Find \(\int \frac{1}{x \ln^2 x} \, dx\)
  • 13. Evaluate \(\int_0^{\pi/2} x \sin x \, dx\) using integration by parts
  • 14. Find the average value of \(f(x) = e^x\) on \([0, 1]\)
  • 15. Find the work required to pump all water out of a cylindrical tank (radius 2 m, height 5 m)
Bonus Problems (10 points each):
  • B1. Prove that \(\frac{d}{dx}[\sin^{-1} x] = \frac{1}{\sqrt{1-x^2}}\)
  • B2. Find \(\int \frac{1}{\sqrt{1-x^2}} \, dx\) and interpret geometrically
