Solutions: Problem Set 8: Gaussian Integers - Definition and Arithmetic

Elementary Number Theory - Week 9 Solutions

Key Definitions and Concepts

Gaussian Integers

\(\mathbb{Z}[i] = \{a + bi : a, b \in \mathbb{Z}\}\), where \(i = \sqrt{-1}\).

They form an integral domain - we can add, subtract, multiply, but division requires care.

Norm Function

For \(z = a + bi \in \mathbb{Z}[i]\), the norm is \(N(z) = a^2 + b^2 = z \cdot \bar{z}\).

Key property: \(N(zw) = N(z) \cdot N(w)\)

Solutions

Problem 1: Compute \((2 + 3i)(1 - 2i)\).

Solution:

\[(2 + 3i)(1 - 2i) = 2(1) + 2(-2i) + 3i(1) + 3i(-2i)\]
\[= 2 - 4i + 3i - 6i^2\]
\[= 2 - 4i + 3i + 6 \quad (i^2 = -1)\]
\[= 8 - i\]

Verification: \(N(2+3i) = 13\), \(N(1-2i) = 5\), \(N(8-i) = 65 = 13 \times 5\) ✓

Problem 2: Find the inverse of \(1 + i\) in \(\mathbb{Z}[i]\).

Solution:

The inverse of \(z\) is \(\frac{\bar{z}}{N(z)}\).

Compute conjugate and norm:
\(\bar{1+i} = 1 - i\)
\[N(1+i) = 1^2 + 1^2 = 2\]
Find the inverse:
\[(1+i)^{-1} = \frac{1-i}{2} = \frac{1}{2} - \frac{1}{2}i\]

This is NOT in \(\mathbb{Z}[i]\) (fractions don't work). But we can find which Gaussian integers have inverses in \(\mathbb{Z}[i]\): only units!

Answer: The inverse is \(\frac{1}{2} - \frac{1}{2}i\), which is not a Gaussian integer. Only units \((1, -1, i, -i)\) have inverses in \(\mathbb{Z}[i]\).

Problem 3: Find all units in \(\mathbb{Z}[i]\).

Understanding: A unit is an element with a multiplicative inverse in the ring.

Solution:

Let \(u = a + bi\) be a unit.

Then there exists \(v = c + di \in \mathbb{Z}[i]\) with \(uv = 1\).

Take norms:
\[N(uv) = N(1) = 1\]
\[N(u) \cdot N(v) = 1\]
Since norms are non-negative integers, \(N(u) = N(v) = 1\).
Solve \(a^2 + b^2 = 1\):

Integer solutions: \((a,b) = (1,0), (-1,0), (0,1), (0,-1)\)

Answer: The units are \(1, -1, i, -i\).

Problem 4: Determine if \(3 + 2i\) is a Gaussian integer prime.

Strategy: Check if \(N(3+2i)\) is prime in \(\mathbb{Z}\), or if it can be factored.

Step 1: Compute the norm.
\[N(3+2i) = 9 + 4 = 13\]
Step 2: Check if 13 is prime in \(\mathbb{Z}\).

Yes, 13 is prime.

Step 3: Conclusion.

Theorem: If \(N(z)\) is prime in \(\mathbb{Z}\), then \(z\) is prime in \(\mathbb{Z}[i]\).

Therefore, \(3 + 2i\) is a Gaussian prime.

Problem 5: Factor 5 in \(\mathbb{Z}[i]\).

Solution:

Step 1: Check if 5 is a Gaussian prime.

Try to write \(5 = (a+bi)(c+di)\). Taking norms:
\[N(5) = 25 = N(a+bi) \cdot N(c+di)\]

If both factors are non-units, then \(N(a+bi) = N(c+di) = 5\).

Find Gaussian integers with norm 5.

Solve \(a^2 + b^2 = 5\):

  • \(a = 1\): \(1 + b^2 = 5 \Rightarrow b^2 = 4 \Rightarrow b = \pm 2\)
  • \(a = 2\): \(4 + b^2 = 5 \Rightarrow b^2 = 1 \Rightarrow b = \pm 1\)
So \(\pm 1 \pm 2i\) and \(\pm 2 \pm i\) have norm 5.

Step 2: Factor 5.
\[5 = (1 + 2i)(1 - 2i) = (2 + i)(2 - i)\]

Check: \((1+2i)(1-2i) = 1 - 4i^2 = 1 + 4 = 5\) ✓

Answer: \(5 = (1+2i)(1-2i)\) with \(1+2i\) and \(1-2i\) both Gaussian primes.

Problem 6: Prove: If \(p \equiv 3 \pmod{4}\) is prime, then \(p\) remains prime in \(\mathbb{Z}[i]\).

Proof:

Suppose \(p = \alpha\beta\) in \(\mathbb{Z}[i]\).

Then \(N(p) = N(\alpha)N(\beta) = p^2\).

Since \(p\) is prime in \(\mathbb{Z}\), either \(N(\alpha) = 1\) and \(N(\beta) = p^2\), or vice versa.

Case 1: \(N(\alpha) = 1\)

Then \(\alpha\) is a unit, so \(p\) is irreducible (hence prime, since \(\mathbb{Z}[i]\) is a UFD).

Case 2: \(N(\alpha) = p\)

This requires solving \(a^2 + b^2 = p\).

We need \(-1\) to be a quadratic residue mod \(p\).

But \(p \equiv 3 \pmod{4}\) means \(\left(\frac{-1}{p}\right) = -1\), so \(-1\) is not a QR.

Therefore, no Gaussian integer has norm \(p\).

Conclusion: \(p\) is irreducible in \(\mathbb{Z}[i]\), hence prime.

Bonus Solutions

Bonus Problem 1: Prove that 2 ramifies in \(\mathbb{Z}[i]\): \(2 = -i(1+i)^2\).

Solution:

We know \(N(1+i) = 2\), so \(1+i\) divides 2.
\[(1+i)^2 = 1 + 2i + i^2 = 1 + 2i - 1 = 2i\]
\[2 = -i(2i) = -i(1+i)^2\]

Interpretation: The prime 2 "ramifies" - it's (up to units) the square of a Gaussian prime.

Bonus Problem 2: Prove that if \(\gcd(a,b) = 1\), then \(\gcd(a, c) = \gcd(b, c) = 1\) implies \(\gcd(ab, c) = 1\).

Proof: (This is actually Problem 7 from PS4)

Let \(d = \gcd(ab, c)\). Any prime dividing \(d\) divides both \(ab\) and \(c\).

If prime \(p \mid d\), then \(p \mid ab\), so \(p \mid a\) or \(p \mid b\). Also \(p \mid c\).

If \(p \mid a\) and \(p \mid c\), then \(p \mid \gcd(a, c) = 1\) - contradiction.

If \(p \mid b\) and \(p \mid c\), then \(p \mid \gcd(b, c) = 1\) - contradiction.

Therefore, no prime divides \(d\), so \(d = 1\).
