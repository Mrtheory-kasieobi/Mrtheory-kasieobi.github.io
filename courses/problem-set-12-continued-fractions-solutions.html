Solutions: Problem Set 12: Continued Fractions

Elementary Number Theory - Week 13 Solutions

Key Ideas

Continued fractions and convergents

A finite continued fraction gives a rational number. An infinite continued fraction can represent an irrational number. The convergents are the best rational approximations, and they satisfy simple recurrence relations.

Solutions

Problem 1

Find the continued fraction expansion of \(\frac{19}{7}\) and compute its convergents.

Apply the Euclidean algorithm:
\(19 = 2\cdot 7 + 5\)
\(7 = 1\cdot 5 + 2\)
\(5 = 2\cdot 2 + 1\)
\(2 = 2\cdot 1 + 0\)

The quotients give \([2;1,2,2]\). The convergents are
\(\frac{2}{1},\; \frac{3}{1},\; \frac{8}{3},\; \frac{19}{7}\).

Problem 2

Find the continued fraction expansion of \(\sqrt{7}\) and determine its period length.

Use the standard algorithm for square roots:
\(\sqrt{7}=2+(\sqrt{7}-2)\)
\(\frac{1}{\sqrt{7}-2}=\frac{\sqrt{7}+2}{3}=1+\frac{\sqrt{7}-1}{2}\)
\(\frac{2}{\sqrt{7}-1}=\frac{\sqrt{7}+1}{3}=1+\frac{\sqrt{7}-2}{1}\)
\(\frac{1}{\sqrt{7}-2}=\sqrt{7}+2=4+(\sqrt{7}-2)\)

The pattern repeats, so \(\sqrt{7}=[2;\overline{1,1,1,4}]\). The period length is 4.

Problem 3

Find the fundamental solution to \(x^2 - 2y^2 = 1\) using continued fractions.

The continued fraction of \(\sqrt{2}\) is \([1;\overline{2}]\), so the period length is \(k=1\). The convergents are
\(\frac{p_0}{q_0}=1,\quad \frac{p_1}{q_1}=\frac{3}{2}\).

Since \(k\) is odd, the fundamental solution comes from the convergent just before the period repeats: \((x_1,y_1)=(3,2)\). Check: \(3^2-2\cdot 2^2=9-8=1\).

Problem 4

Find the continued fraction expansion of \(\sqrt{13}\) and its period length.

Apply the algorithm:
\(\sqrt{13}=3+(\sqrt{13}-3)\)
\(\frac{1}{\sqrt{13}-3}=\frac{\sqrt{13}+3}{4}=1+\frac{\sqrt{13}-1}{4}\)
\(\frac{4}{\sqrt{13}-1}=\frac{\sqrt{13}+1}{3}=1+\frac{\sqrt{13}-2}{3}\)
\(\frac{3}{\sqrt{13}-2}=\frac{\sqrt{13}+2}{3}=1+\frac{\sqrt{13}-1}{3}\)
\(\frac{3}{\sqrt{13}-1}=\frac{\sqrt{13}+1}{4}=1+\frac{\sqrt{13}-3}{4}\)

The sequence repeats with period 5. So \(\sqrt{13}=[3;\overline{1,1,1,1,6}]\).

Problem 5

Find the fundamental solution to \(x^2 - 13y^2 = 1\).

The period length of \(\sqrt{13}\) is 5, which is odd. Compute convergents up to the end of the first full period. The convergent \(\frac{p_4}{q_4}\) gives \(p_4=649\) and \(q_4=180\). Check: \(649^2-13\cdot 180^2=421201-421200=1\).

Answer. The fundamental solution is \((649,180)\).

Problem 6

Show that every rational number has a finite continued fraction expansion.

Apply the Euclidean algorithm to the numerator and denominator. At each step we get a quotient and a smaller remainder. Because the remainders are non-negative integers and strictly decrease, the process must stop after finitely many steps. The recorded quotients form a finite continued fraction.

Problem 7

Prove: if \(\frac{p}{q}\) is a convergent to \(\alpha\), then \(|q\alpha - p| < 1\).

By definition, a convergent is obtained by truncating a continued fraction. The error after truncation is less than the next term, which is at most 1 in absolute value. More precisely, the difference between \(\alpha\) and the convergent \(\frac{p_n}{q_n}\) is smaller than \(\frac{1}{q_n q_{n+1}}\). Multiplying by \(q_n\) gives \(|q_n\alpha - p_n| < \frac{1}{q_{n+1}} \le 1\).

Problem 8

Find all solutions to \(x^2 - 3y^2 = 1\) with \(x, y < 100\).

The fundamental solution is \((2,1)\). All solutions are generated by \((2+\sqrt{3})^n\):
\(n=1\): \((2,1)\)
\(n=2\): \((7,4)\)
\(n=3\): \((26,15)\)
\(n=4\): \((97,56)\)

The next solution would have \(y>100\).

Answer. \((2,1)\), \((7,4)\), \((26,15)\), \((97,56)\).

Problem 9

Prove that consecutive convergents satisfy \(|p_n q_{n+1} - p_{n+1} q_n| = 1\).

Use the recurrence relations for convergents:
\(p_{n+1}=a_{n+1}p_n+p_{n-1}\)
\(q_{n+1}=a_{n+1}q_n+q_{n-1}\).

Compute:
\(p_{n+1}q_n - p_n q_{n+1} = (a_{n+1}p_n+p_{n-1})q_n - p_n(a_{n+1}q_n+q_{n-1}) = p_{n-1}q_n - p_n q_{n-1}\).

By induction, this alternating determinant is always \(\pm1\).

Problem 10

Show that the convergents of an irrational number are all in lowest terms.

From Problem 9, consecutive convergents satisfy \(|p_n q_{n+1} - p_{n+1} q_n| = 1\). If a convergent \(\frac{p_n}{q_n}\) had a common factor \(d>1\), then \(d\) would divide the left-hand side for any \(n\), including \(n-1\) and \(n\). That would force \(d\mid 1\), a contradiction. Hence each convergent is in lowest terms.

Bonus Solutions

Bonus Problem 1

Find the continued fraction expansion of \(\frac{1+\sqrt{5}}{2}\) and verify it is \([1; \overline{1}]\).

Let \(\alpha=\frac{1+\sqrt{5}}{2}\). Then \(\alpha=1+\frac{1}{\alpha}\), so the continued fraction repeats immediately: \([1;\overline{1}]\). This is the golden ratio.

Bonus Problem 2

Compute the first 5 convergents of \(\sqrt{3}\) using the recurrence relations.

The continued fraction of \(\sqrt{3}\) is \([1;\overline{1,2}]\). The partial quotients are \(a_0=1, a_1=1, a_2=2, a_3=1, a_4=2\). Using the recurrences
\(p_n=a_n p_{n-1}+p_{n-2},\quad q_n=a_n q_{n-1}+q_{n-2}\)
with \(p_{-2}=0, p_{-1}=1, q_{-2}=1, q_{-1}=0\), we get
\(\frac{p_0}{q_0}=\frac{1}{1},\; \frac{p_1}{q_1}=\frac{2}{1},\; \frac{p_2}{q_2}=\frac{5}{3},\; \frac{p_3}{q_3}=\frac{7}{4},\; \frac{p_4}{q_4}=\frac{19}{11}\).

Bonus Problem 3

Prove that if \(\frac{p_n}{q_n}\) and \(\frac{p_{n+1}}{q_{n+1}}\) are consecutive convergents, then \(\left|\alpha - \frac{p_n}{q_n}\right| < \frac{1}{q_n q_{n+1}}\).

Write \(\alpha\) as \([a_0;a_1,\dots,a_n,\theta]\) where \(\theta>1\). Then \(\alpha = \frac{\theta p_n + p_{n-1}}{\theta q_n + q_{n-1}}\). Subtracting \(\frac{p_n}{q_n}\) gives
\(\alpha - \frac{p_n}{q_n} = \frac{(-1)^n}{\theta q_n^2 + q_n q_{n-1}}\).

Since \(\theta>1\) and \(q_{n+1}=\theta q_n+q_{n-1}\), the denominator exceeds \(q_n q_{n+1}\). Therefore
\(\left|\alpha - \frac{p_n}{q_n}\right| < \frac{1}{q_n q_{n+1}}\).
