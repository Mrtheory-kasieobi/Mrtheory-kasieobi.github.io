Solutions: Problem Set 12: Continued Fractions

Elementary Number Theory - Week 13 Solutions

Key Definitions and Concepts

Simple Continued Fraction

[a₀; a₁, a₂, a₃, ...] = a₀ + 1/(a₁ + 1/(a₂ + 1/(a₃ + ...)))

where a₀ ≥ 0 and a₁, a₂, ... ≥ 1.

Convergents: pₙ/qₙ are the rational approximations.

Solutions

Problem 1: Find the continued fraction expansion of 22/7.

Solution using Euclidean Algorithm:

22 = 7 × 3 + 1, so a₀ = 3
1/7 = 1/(7 × 1 + 0), so a₁ = 7

Answer: \([3; 7] = 3 + \frac{1}{7} = \frac{22}{7}\)

Problem 2: Find the continued fraction for √2 and show it is periodic.

Solution:

Step 1: a₀ = ⌊√2⌋ = 1, remainder = √2 - 1
\[\frac{1}{\sqrt{2}-1} = \frac{\sqrt{2}+1}{(\sqrt{2}-1)(\sqrt{2}+1)} = \frac{\sqrt{2}+1}{1} = \sqrt{2} + 1\]
Step 2: a₁ = ⌊√2 + 1⌋ = 2, remainder = (√2 + 1) - 2 = √2 - 1
This is the same as the original remainder!

Answer: √2 = [1; 2, 2, 2, ...] = [1; 2̄], a purely periodic continued fraction.

Problem 3: Find the first four convergents of π ≈ 3.14159....

Solution:

π ≈ [3; 7, 15, 1, 292, ...]

Convergent 0 (p₀/q₀):
3/1 = 3
Convergent 1 (p₁/q₁):
3 + 1/7 = 22/7 ≈ 3.14285...
Convergent 2 (p₂/q₂):
3 + 1/(7 + 1/15) = 3 + 15/106 = 333/106 ≈ 3.14151...

Answer: Convergents: 3/1, 22/7, 333/106, 355/113, ...

Bonus Solutions

Bonus Problem 1: Prove that every rational number has a finite continued fraction expansion.

Proof: Apply the Euclidean algorithm to a/b. The process terminates when remainder is 0, giving a finite expansion.
