Basis and Dimension

Linear Algebra - Lecture 3 • Based on Axler's "Linear Algebra Done Right" and MIT 18.700

1. Bases

1.1 Definition

A list \(v_1, \ldots, v_n\) of vectors in a vector space V is a basis of V if:

  1. \(v_1, \ldots, v_n\) is linearly independent
  2. \(F(v_1, \ldots, v_n) = V\)

1.2 Existence and Uniqueness

Theorem 1: Every finite-dimensional vector space has a basis.
Theorem 2 (Basis Extension): If \(v_1, \ldots, v_m\) is linearly independent in a finite-dimensional vector space V, then it can be extended to a basis of V.

1.3 Examples of Bases

Example 1: Standard Basis of F^n

The standard basis of \(F^n\) is:

\(e_1 = (1, 0, \ldots, 0), e_2 = (0, 1, 0, \ldots, 0), \ldots, e_n = (0, \ldots, 0, 1)\)

Every vector \(v = (v_1, \ldots, v_n) = v_1 e_1 + \cdots + v_n e_n\)

Example 2: Basis for P_{n-1}(F)

A basis for polynomials of degree ≤ 2 is:

\{1, x, x^2\}\)

Every polynomial \(p(x) = a_0 + a_1 x + a_2 x^2\)

Example 3: Standard Basis for M_{2×2}(F)

A basis for 2×2 matrices:

\(E_{11} = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}, E_{12} = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}, E_{21} = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}, E_{22} = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}\)

2. Dimension

2.1 Definition

If V is a vector space and \(v_1, \ldots, v_n\) is a basis of V, then the dimension of V, denoted \(dim V\), is n.

If V has no finite basis, then V is infinite-dimensional.

2.2 Fundamental Theorems

Theorem 3 (Invariance of Dimension): Any two bases of a finite-dimensional vector space have the same number of vectors.
Theorem 4 (Dimension Formula): If \(M\) is a subspace of a finite-dimensional vector space V, then \(dim M \leq dim V\).

2.3 Computing Dimensions

Example 4: Dimension of a Subspace

Find the dimension of \(W = \{(x, y, z) \in F^3 : x + 2y + 3z = 0\}\):

Solution: \(W = F\{(-2, 1, 0), (-3, 0, 1)\}\)

A basis is \{(-2, 1, 0), (-3, 0, 1)\}\), so \(dim W = 2\)

3. Coordinate Systems

3.1 Coordinates Relative to a Basis

Given a basis \(B = \{v_1, \ldots, v_n\}\) of V, every vector \(v \in V\) can be uniquely written as:

\[v = a_1 v_1 + \cdots + a_n v_n\]

The scalars \(a_1, \ldots, a_n\) are the coordinates of \(v\) relative to B.

3.2 Coordinate Map

The map \(C_B: V \to F^n\) given by \(v \mapsto (a_1, \ldots, a_n)\) is an isomorphism.

Example 5: Coordinate Vector

In \(F^2\) with basis \(B = \{(1, 1), (1, -1)\}\):

Find coordinates of \(v = (3, 1)\):

Solve: \(a(1, 1) + b(1, -1) = (3, 1)\)

\(a + b = 3, a - b = 1 \implies a = 2, b = 1\)

Coordinates: \[v]_B = (2, 1)\)

4. Change of Basis

4.1 Change of Basis Matrix

Let \(B = \{v_1, \ldots, v_n\}\) and \(C = \{w_1, \ldots, w_n\}\) be two bases.

The change of basis matrix from B to C is the matrix P whose columns are the coordinate vectors of \(v_1, \ldots, v_n\) relative to C.

\[v]_C = P [v]_B

4.2 Example

Example 6: Change of Basis

Let \(B = \{(1, 0), (0, 1)\}\) (standard) and \(C = \{(1, 1), (1, -1)\}\) in \(F^2\).

Find the change of basis matrix from B to C:

\(P = \begin{pmatrix} [e_1]_C & [e_2]_C \end{pmatrix} = \begin{pmatrix} 1/2 & 1/2 \\ 1/2 & -1/2 \end{pmatrix}\)

Key Insight:

The dimension of a vector space is an intrinsic property - it doesn't depend on the choice of basis. All bases of a finite-dimensional space have the same cardinality.

5. Practice Problems

Problem 1

Find a basis for the subspace \(W = \{(x, y, z, w) \in F^4 : x + y + z + w = 0, x - y + z - w = 0\}\). What is \(dim W\)?

Problem 2

Show that \{1, \cos x, \sin x, \cos 2x, \sin 2x\}\) is linearly independent in \(C[0, 2\pi]\).

Problem 3

Find the coordinate vector of \(v = (2, 3, -1)\) relative to the basis \(B = \{(1, 1, 0), (1, 0, 1), (0, 1, 1)\}\) of \(F^3\).

Problem 4

Let \(V = P_3(F)\). Show that \{1 + x, x + x^2, x^2 + x^3\}\) can be extended to a basis of V.

Problem 5

Prove that in \(F^n\), any set of more than \(n\) vectors must be linearly dependent.
