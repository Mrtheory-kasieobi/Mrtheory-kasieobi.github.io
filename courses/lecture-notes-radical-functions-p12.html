Radical Functions

Precalculus 12 - Lecture Notes
British Columbia Curriculum | Last Updated: 2026

1. Introduction to Radical Functions

A radical function is a function that contains a radical (root) expression. The most common radical functions involve square roots, but they can also involve cube roots, fourth roots, and so on.

Definition: A radical function is a function of the form \(f(x) = \sqrt[n]{g(x)}\) where \(n\) is a positive integer and \(g(x)\) is a polynomial or rational function.

1.1 Domain Analysis for Square Root Functions

For functions with even roots (square root, fourth root, etc.), the expression under the radical must be non-negative for real outputs.

Domain Condition:
\[f(x) = \sqrt{g(x)} \text{ requires } g(x) \geq 0\]
Remember:

The domain of a square root function is determined by solving \(g(x) \geq 0\), where \(g(x)\) is the expression under the radical.

1.2 Range Analysis for Square Root Functions

The range of \(\sqrt{g(x)}\) depends on the domain and the sign of transformations:

  • Basic \(f(x) = \sqrt{x}\): Range is \([0, \infty)\)
  • With vertical shift \(f(x) = \sqrt{x} + k\): Range is \([k, \infty)\)
  • With vertical reflection \(f(x) = -\sqrt{x}\): Range is \((-\infty, 0]\)

1.3 Endpoint Behavior

The "endpoint" is where the square root function begins on the x-axis (the left boundary of the domain).

Definition: The endpoint is the leftmost point of the domain where the radical function starts. It occurs when the expression under the radical equals zero.
Example 1: Finding Endpoint, Domain, and Range

For \(f(x) = \sqrt{x - 4} + 1\):

Endpoint: At \(x = 4\): \(f(4) = \sqrt{0} + 1 = 1\), so endpoint is \((4, 1)\)

Domain: \([4, \infty)\)

Range: \([1, \infty)\)

2. Cube Root Functions

2.1 Properties of Cube Root Functions

The cube root function \(f(x) = \sqrt[3]{x}\) has important differences from square root functions:

Property Square Root (\(\sqrt{x}\)) Cube Root (\(\sqrt[3]{x}\))
Domain \([0, \infty)\) \(\mathbb{R}\)
Range \([0, \infty)\) \(\mathbb{R}\)
Symmetry None Odd function (origin symmetric)
Example 2: Comparing Square Root and Cube Root

Graph \(f(x) = \sqrt{x}\) and \(g(x) = \sqrt[3]{x}\) on the same axes:

Both pass through the origin

\(\sqrt{x}\) only exists for \(x \geq 0\) and increases gradually

\(\sqrt[3]{x}\) exists for all real \(x\), decreasing for \(x < 0\)

2.2 Domain and Range of Cube Root Functions

For cube root functions, the domain is typically all real numbers unless there are restrictions from transformations.

Example 3: Cube Root Function Analysis

For \(f(x) = \sqrt[3]{x + 2} - 1\):

Domain: All real numbers (cube root accepts any input)

Range: All real numbers

Key Point: \(x + 2 = 0\) when \(x = -2\), giving \(f(-2) = -1\)

3. Radical Functions and Transformations

2.1 Parent Function: \(f(x) = \sqrt{x}\)

The parent square root function has the following characteristics:

  • Domain: \([0, \infty)\)
  • Range: \([0, \infty)\)
  • Intercept: \((0, 0)\)
  • Shape: Starts at origin and increases slowly
Example 1: Basic Radical Function

Graph \(f(x) = \sqrt{x}\) and identify its key features.

Key points: \((0, 0)\), \((1, 1)\), \((4, 2)\), \((9, 3)\)

The graph passes the vertical line test, confirming it is a function.

2.2 Transformations of Radical Functions

Radical functions follow the same transformation rules as other functions.

Transformed Radical Function:
\[f(x) = a\sqrt{x - h} + k\]
Example 2: Transformed Radical Function

Graph \(f(x) = -2\sqrt{x - 1} + 3\)

Starting from \(g(x) = \sqrt{x}\):

  1. Shift right 1 unit: \(\sqrt{x - 1}\)
  2. Vertical stretch by 2: \(2\sqrt{x - 1}\)
  3. Reflect across x-axis: \(-2\sqrt{x - 1}\)
  4. Shift up 3 units: \(-2\sqrt{x - 1} + 3\)

Domain: \([1, \infty)\), Range: \((-\infty, 3]\)

3. Square Root of a Function

3.1 Understanding \(f(\sqrt{x})\)

The function \(f(\sqrt{x})\) involves taking the square root of the input before applying the function. This creates a different type of transformation.

Example 3: Square Root of a Function

Given \(f(x) = x^2 + 2x - 3\), find \(f(\sqrt{x})\).

\[f(\sqrt{x}) = (\sqrt{x})^2 + 2\sqrt{x} - 3 = x + 2\sqrt{x} - 3\]

Domain: \([0, \infty)\) since we need \(\sqrt{x}\) to be defined.

3.2 Graphing \(f(\sqrt{x})\)

To graph \(f(\sqrt{x})\), we can substitute \(u = \sqrt{x}\) (so \(x = u^2\)) and use the graph of \(f(u)\) for \(u \geq 0\).

Example 4: Graphing \(f(\sqrt{x})\)

Graph \(f(x) = \sqrt{x^2 + 2x - 3}\)

Let \(u = \sqrt{x}\), so we need \(u^2 + 2u - 3 \geq 0\)

\((u + 3)(u - 1) \geq 0\) gives \(u \leq -3\) or \(u \geq 1\)

Since \(u = \sqrt{x} \geq 0\), we need \(\sqrt{x} \geq 1\), so \(x \geq 1\)

Domain: \([1, \infty)\)

4. Solving Radical Equations Graphically

4.1 Method of Graphing

To solve a radical equation, we can graph both sides and find their intersection points.

Example 5: Solving Graphically

Solve \(\sqrt{x + 2} = x - 1\) graphically.

Graph \(y = \sqrt{x + 2}\) and \(y = x - 1\) on the same axes.

The intersection point gives the solution. From the graph, we see \(x = 3\) is the solution.

Verification: \(\sqrt{3 + 2} = \sqrt{5} \approx 2.24\) and \(3 - 1 = 2\) (close, need algebraic check)

4.2 Algebraic Solution

After finding potential solutions graphically, we verify algebraically by squaring both sides.

Example 6: Algebraic Verification

Solve \(\sqrt{x + 2} = x - 1\) algebraically.

Square both sides: \(x + 2 = (x - 1)^2 = x^2 - 2x + 1\)

Rearrange: \(x^2 - 3x - 1 = 0\)

Using quadratic formula: \(x = \frac{3 \pm \sqrt{13}}{2}\)

Check: \(x = \frac{3 + \sqrt{13}}{2} \approx 3.3\) (valid)

\(x = \frac{3 - \sqrt{13}}{2} \approx -0.3\) (extraneous - negative)

5. Key Properties and Applications

Function Domain Range
\(f(x) = \sqrt{x}\) \([0, \infty)\) \([0, \infty)\)
\(f(x) = \sqrt[3]{x}\) \(\mathbb{R}\) \(\mathbb{R}\)
\(f(x) = \sqrt{x - h} + k\) \([h, \infty)\) \([k, \infty)\)
\(f(x) = -\sqrt{x - h} + k\) \([h, \infty)\) \((-\infty, k]\)

5. Connections to Inverse Functions

Radical functions often have inverse relationships with power functions. Understanding these connections helps with both graphing and solving equations.

Key Connection:

The square root function \(f(x) = \sqrt{x}\) is the inverse of \(g(x) = x^2\) for \(x \geq 0\).

The cube root function \(f(x) = \sqrt[3]{x}\) is the inverse of \(g(x) = x^3\) for all real numbers.

Example 7: Inverse Relationship Verification

Verify that \(f(x) = \sqrt{x - 2}\) and \(g(x) = x^2 + 2\) (for \(x \geq 0\)) are inverses:

\(f(g(x)) = f(x^2 + 2) = \sqrt{(x^2 + 2) - 2} = \sqrt{x^2} = |x| = x\) (since \(x \geq 0\))

\(g(f(x)) = g(\sqrt{x - 2}) = (\sqrt{x - 2})^2 + 2 = x - 2 + 2 = x\)
