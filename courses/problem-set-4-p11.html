Problem Set 4: Quadratic Functions

Precalculus 11 · 8 problems Medium

Problems

Problem 1

Graph \(y = (x - 2)^2 + 3\). State the vertex, axis of symmetry, and direction of opening.

Problem 2

Convert to vertex form by completing the square: \(y = x^2 - 6x + 5\)

Problem 3

Find the x-intercepts and y-intercept of \(y = x^2 - 5x + 6\).

Problem 4

Graph \(y = -2(x + 1)^2 - 4\). State the domain and range.

Problem 5

Find the equation of a parabola with vertex \((3, -2)\) and passing through \((1, 6)\).

Problem 6

Given \(y = (x - 4)^2 - 9\), find the x-intercepts using the quadratic formula.

Problem 7

Graph the transformed function: \(y = -3(x + 2)^2 + 1\). Identify all key features.

Problem 8

A ball is thrown upward. Its height is modeled by \(h(t) = -16t^2 + 32t + 48\). Find the maximum height and when it hits the ground.

Bonus Problems

Bonus Problem 1 Hard

Find the equation of a parabola with x-intercepts at \(x = -2\) and \(x = 5\) that passes through \((1, 6)\).

Bonus Problem 2 Hard

A ball is thrown upward with height modeled by \(h(t) = -16t^2 + 64t + 80\). Find when it hits the ground and its maximum height.
