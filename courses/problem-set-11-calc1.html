Problem Set 11: Integration Techniques

Calculus I - Week 10

Instructions

Show all work. No calculators. Write clearly and show each step.

Problems

  • 1. Evaluate \(\int \frac{x}{x^2 + 1} \, dx\)
  • 2. Find \(\int x \ln x \, dx\) using integration by parts
  • 3. Evaluate \(\int \frac{1}{x^2 - 1} \, dx\) using partial fractions
  • 4. Find \(\int e^x \cos x \, dx\) using integration by parts twice
  • 5. Evaluate \(\int \frac{x^2 + 1}{x} \, dx\)
  • 6. Find \(\int \frac{1}{x \ln x} \, dx\)
  • 7. Evaluate \(\int \tan x \, dx\)
  • 8. Find \(\int x \sqrt{x + 1} \, dx\) using substitution
  • 9. Evaluate \(\int \frac{2x + 3}{x^2 + x} \, dx\) using partial fractions
  • 10. Find \(\int \sec x \, dx\)
Bonus Problems (10 points each):
  • B1. Evaluate \(\int \frac{1}{x \sqrt{x^2 - 1}} \, dx\)
  • B2. Find \(\int \frac{\arctan x}{1 + x^2} \, dx\) using substitution
