Derivatives of Trigonometric Functions

Calculus I - Week 6

1. Fundamental Trigonometric Derivatives

1.1 Basic Formulas

Theorem 1.1: The derivatives of the six trigonometric functions are:
  • \(\frac{d}{dx}[\sin x] = \cos x\)
  • \(\frac{d}{dx}[\cos x] = -\sin x\)
  • \(\frac{d}{dx}[\tan x] = \sec^2 x\)
  • \(\frac{d}{dx}[\cot x] = -\csc^2 x\)
  • \(\frac{d}{dx}[\sec x] = \sec x \tan x\)
  • \(\frac{d}{dx}[\csc x] = -\csc x \cot x\)

1.2 Proof of \(\frac{d}{dx}[\sin x] = \cos x\)

Proof using the Limit Definition: We compute: $$\frac{d}{dx}[\sin x] = \lim_{h \to 0} \frac{\sin(x+h) - \sin x}{h}$$ Using the sine addition formula: \(\sin(x+h) = \sin x \cos h + \cos x \sin h\) $$\frac{d}{dx}[\sin x] = \lim_{h \to 0} \frac{\sin x \cos h + \cos x \sin h - \sin x}{h}$$ $$= \lim_{h \to 0} \left[\sin x \cdot \frac{\cos h - 1}{h} + \cos x \cdot \frac{\sin h}{h}\right]$$ Using the standard limits \(\lim_{h \to 0} \frac{\sin h}{h} = 1\) and \(\lim_{h \to 0} \frac{\cos h - 1}{h} = 0\): $$= \sin x \cdot 0 + \cos x \cdot 1 = \cos x$$ ∎

1.3 Proof of \(\frac{d}{dx}[\cos x] = -\sin x\)

Proof using the Limit Definition: $$\frac{d}{dx}[\cos x] = \lim_{h \to 0} \frac{\cos(x+h) - \cos x}{h}$$ Using the cosine addition formula: \(\cos(x+h) = \cos x \cos h - \sin x \sin h\) $$= \lim_{h \to 0} \frac{\cos x \cos h - \sin x \sin h - \cos x}{h}$$ $$= \lim_{h \to 0} \left[\cos x \cdot \frac{\cos h - 1}{h} - \sin x \cdot \frac{\sin h}{h}\right]$$ $$= \cos x \cdot 0 - \sin x \cdot 1 = -\sin x$$ ∎

1.4 Proof of \(\frac{d}{dx}[\tan x] = \sec^2 x\)

Proof using Quotient Rule: Since \(\tan x = \frac{\sin x}{\cos x}\), we apply the quotient rule: $$\frac{d}{dx}\left[\frac{\sin x}{\cos x}\right] = \frac{\cos x \cdot \cos x - \sin x \cdot (-\sin x)}{\cos^2 x}$$ $$= \frac{\cos^2 x + \sin^2 x}{\cos^2 x} = \frac{1}{\cos^2 x} = \sec^2 x$$ ∎
\(\frac{d}{dx}[\sin x] = \cos x\)
\(\frac{d}{dx}[\cos x] = -\sin x\)
\(\frac{d}{dx}[\tan x] = \sec^2 x\)
\(\frac{d}{dx}[\cot x] = -\csc^2 x\)
\(\frac{d}{dx}[\sec x] = \sec x \tan x\)
\(\frac{d}{dx}[\csc x] = -\csc x \cot x\)

2. Differentiation Techniques with Trig Functions

2.1 Combined Differentiation Rules

Example 2.1: Find \(\frac{d}{dx}[x^2 \sin x]\)

Using the product rule: \(\frac{d}{dx}[uv] = u'v + uv'\)

Let \(u = x^2\) and \(v = \sin x\). Then \(u' = 2x\) and \(v' = \cos x\).

Result: \(\frac{d}{dx}[x^2 \sin x] = 2x \sin x + x^2 \cos x\)

Example 2.2: Find \(\frac{d}{dx}[\sin^2(x)]\)

Using the chain rule with \(f(u) = u^2\) and \(u = \sin x\):

\(\frac{d}{dx}[\sin^2 x] = 2\sin x \cdot \cos x = \sin(2x)\)

Example 2.3: Find \(\frac{d}{dx}[\frac{\cos x}{x}]\)

Using the quotient rule:

\(\frac{d}{dx}\left[\frac{\cos x}{x}\right] = \frac{x(-\sin x) - \cos x \cdot 1}{x^2} = \frac{-x\sin x - \cos x}{x^2}\)

2.2 Trigonometric Equations

Example 2.4: Find critical points of \(f(x) = \sin x + \cos x\) on \([0, 2\pi]\)

Set \(f'(x) = 0\): \(\cos x - \sin x = 0\)

So \(\cos x = \sin x\), which gives \(\tan x = 1\).

Critical points: \(x = \frac{\pi}{4}, \frac{5\pi}{4}\)

3. Inverse Trigonometric Functions

3.1 Derivatives of Inverse Trig Functions

Theorem 3.1:
  • \(\frac{d}{dx}[\arcsin x] = \frac{1}{\sqrt{1-x^2}}\) for \(|x| < 1\)
  • \(\frac{d}{dx}[\arccos x] = -\frac{1}{\sqrt{1-x^2}}\) for \(|x| < 1\)
  • \(\frac{d}{dx}[\arctan x] = \frac{1}{1+x^2}\)
  • \(\frac{d}{dx}[\operatorname{arccot} x] = -\frac{1}{1+x^2}\)
  • \(\frac{d}{dx}[\operatorname{arcsec} x] = \frac{1}{|x|\sqrt{x^2-1}}\) for \(|x| > 1\)
  • \(\frac{d}{dx}[\operatorname{arccsc} x] = -\frac{1}{|x|\sqrt{x^2-1}}\) for \(|x| > 1\)
Example 3.1: Find \(\frac{d}{dx}[\arctan(x^2)]\)

Using the chain rule with \(\frac{d}{du}[\arctan u] = \frac{1}{1+u^2}\):

\(\frac{d}{dx}[\arctan(x^2)] = \frac{1}{1+(x^2)^2} \cdot 2x = \frac{2x}{1+x^4}\)

4. Applications

4.1 Related Trigonometric Rates

Example 4.1: A ladder 10 ft long rests against a wall. If the bottom slides away from the wall at 2 ft/s, how fast is the top sliding down when the bottom is 6 ft from the wall?

Let \(x\) = distance from wall to bottom, \(y\) = height of top. Then \(x^2 + y^2 = 100\).

Differentiating: \(2x\frac{dx}{dt} + 2y\frac{dy}{dt} = 0\)

When \(x = 6\), \(y = 8\). Given \(\frac{dx}{dt} = 2\):

\(2(6)(2) + 2(8)\frac{dy}{dt} = 0 \Rightarrow \frac{dy}{dt} = -\frac{24}{16} = -\frac{3}{2}\)

The top slides down at 1.5 ft/s.
