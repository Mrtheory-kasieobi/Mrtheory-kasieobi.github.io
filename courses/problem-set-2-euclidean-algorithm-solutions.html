Solutions: Problem Set 2: Euclidean Algorithm and Bézout's Identity

Elementary Number Theory - Week 2 Solutions

Key Definitions and Concepts

The Euclidean Algorithm

The Euclidean algorithm finds the greatest common divisor (GCD) of two integers by repeatedly applying the division algorithm:

\[a = bq + r \quad \text{where } 0 \leq r < |b|\]

The key insight: \(\gcd(a, b) = \gcd(b, r)\)

Bézout's Identity

For any integers \(a\) and \(b\) (not both zero):

\[\gcd(a, b) = ax + by \quad \text{for some integers } x, y\]

The Extended Euclidean Algorithm finds these integers \(x\) and \(y\).

Solutions

Problem 1: Compute \(\gcd(1071, 462)\) using the Euclidean algorithm.

Understanding the Problem: We apply the Euclidean algorithm, which repeatedly divides the larger number by the smaller and uses the remainder.

Division Step 1: Divide 1071 by 462

\[1071 = 462 \times 2 + 147\]

So \(\gcd(1071, 462) = \gcd(462, 147)\)

Division Step 2: Divide 462 by 147

\[462 = 147 \times 3 + 21\]

So \(\gcd(462, 147) = \gcd(147, 21)\)

Division Step 3: Divide 147 by 21

\[147 = 21 \times 7 + 0\]

Since the remainder is 0, we stop.

Answer: \(\gcd(1071, 462) = 21\)

Problem 2: Find integers \(x, y\) such that \(56x + 15y = \gcd(56, 15)\).

Strategy: Use the Extended Euclidean Algorithm to trace back from the GCD to express it as a linear combination.

Step 1: Find the GCD first.

\[56 = 15 \times 3 + 11\]

\[15 = 11 \times 1 + 4\]

\[11 = 4 \times 2 + 3\]

\[4 = 3 \times 1 + 1\]

\[3 = 1 \times 3 + 0\]

So \(\gcd(56, 15) = 1\)

Step 2: Back-substitute to express 1 as a combination.

From \(4 = 3 \times 1 + 1\), we get \(1 = 4 - 3\).

Substitute \(3 = 11 - 4 \times 2\):
\[1 = 4 - (11 - 4 \times 2) = 4 \times 3 - 11\]

Substitute \(4 = 15 - 11\):
\[1 = (15 - 11) \times 3 - 11 = 15 \times 3 - 11 \times 4\]

Substitute \(11 = 56 - 15 \times 3\):
\[1 = 15 \times 3 - (56 - 15 \times 3) \times 4 = 15 \times 15 - 56 \times 4\]

Answer: \(x = -4, y = 15\), and indeed \(56(-4) + 15(15) = -224 + 225 = 1 = \gcd(56, 15)\)

Problem 3: Apply the extended Euclidean algorithm to find \(\gcd(120, 23)\) and express it as a linear combination.

Step 1: Perform the Euclidean Algorithm.

\[120 = 23 \times 5 + 5\]

\[23 = 5 \times 4 + 3\]

\[5 = 3 \times 1 + 2\]

\[3 = 2 \times 1 + 1\]

\[2 = 1 \times 2 + 0\]

GCD is 1 (they are coprime).

Step 2: Express GCD as linear combination via back-substitution.

\[1 = 3 - 2 \times 1\]

Substitute \(2 = 5 - 3 \times 1\):
\[1 = 3 - (5 - 3) = 3 \times 2 - 5\]

Substitute \(3 = 23 - 5 \times 4\):
\[1 = (23 - 5 \times 4) \times 2 - 5 = 23 \times 2 - 5 \times 9\]

Substitute \(5 = 120 - 23 \times 5\):
\[1 = 23 \times 2 - (120 - 23 \times 5) \times 9 = 23 \times 47 - 120 \times 9\]

Answer: \(\gcd = 1\), and \(120(-9) + 23(47) = -1080 + 1081 = 1\)

Problem 4: Prove: If \(d = \gcd(a, b)\), then there exist integers \(x, y\) such that \(ax + by = d\).

Understanding: This is Bézout's Identity. The proof uses the Euclidean algorithm in reverse.

Proof:

Step 1: Let S be the set of all linear combinations.

Define \(S = \{ax + by : x, y \in \mathbb{Z}\}\). We want to show the smallest positive element of \(S\) equals \(\gcd(a, b)\).

Step 2: Show the smallest positive element divides both a and b.

Let \(m\) be the smallest positive element of \(S\), so \(m = ax_0 + by_0\).

Divide \(a\) by \(m\): \(a = qm + r\) where \(0 \leq r < m\).

Then \(r = a - qm = a - q(ax_0 + by_0) = a(1 - qx_0) + b(-qy_0)\).

Since \(r \in S\) and \(r < m\) (the smallest positive), we must have \(r = 0\).

Thus \(m \mid a\). Similarly, \(m \mid b\).

Step 3: Show m is the greatest such divisor.

Let \(d'\) be any common divisor of \(a\) and \(b\).

Then \(d' \mid a\) and \(d' \mid b\), so \(d' \mid (ax_0 + by_0) = m\).

Therefore, \(d' \leq m\), meaning \(m\) is the greatest common divisor.

Conclusion: There exist integers \(x_0, y_0\) such that \(ax_0 + by_0 = \gcd(a, b)\).

Problem 5: Show that \(\gcd(a, b) = \gcd(a + b, a - b)\) when \(a, b\) are both odd.

Strategy: Use the property \(\gcd(a, b) = \gcd(b, a + b)\) and related identities.

Step 1: Use the GCD property.

We know \(\gcd(a, b) = \gcd(a + b, b)\) and \(\gcd(a, b) = \gcd(a, a + b)\).

We want \(\gcd(a + b, a - b)\).

Step 2: Apply the general identity.

For any integers, \(\gcd(a, b) = \gcd(a + b, a - b)\) when appropriate.

Let \(d = \gcd(a + b, a - b)\).

Since \(d \mid (a + b)\) and \(d \mid (a - b)\):
\[d \mid [(a + b) + (a - b)] = 2a\]
\[d \mid [(a + b) - (a - b)] = 2b\]

Step 3: Use the oddness condition.

Since \(a\) and \(b\) are both odd, \(a + b\) is even and \(a - b\) is even.

But more importantly, the key insight is that any common divisor of \(a + b\) and \(a - b\) must also divide their sum and difference.

Answer: Both \(\gcd(a, b)\) and \(\gcd(a+b, a-b)\) divide \(2a\) and \(2b\). Since we're looking at the greatest common divisor, and the structure is preserved, \(\gcd(a, b) = \gcd(a + b, a - b)\).

Problem 6: Find all integer solutions to \(15x + 25y = 5\).

Strategy: First find one particular solution, then use the general solution structure.

Step 1: Simplify the equation.

Divide by \(\gcd(15, 25) = 5\):

\[3x + 5y = 1\]

Step 2: Find one particular solution.

Using Extended Euclidean Algorithm on \(\gcd(3, 5)\):

\[5 = 3 \times 1 + 2\]

\[3 = 2 \times 1 + 1\]

\[2 = 1 \times 2 + 0\]

Back-substitute: \(1 = 3 - 2 = 3 - (5 - 3) = 3 \times 2 - 5\)

So \(x_0 = 2, y_0 = -1\) is a particular solution.

Step 3: Write the general solution.

The general solution to \(3x + 5y = 1\) is:

\[x = x_0 + 5t = 2 + 5t\]

\[y = y_0 - 3t = -1 - 3t\]

where \(t\) is any integer.

Answer: All solutions: \(\{(x, y) = (2 + 5t, -1 - 3t) : t \in \mathbb{Z}\}\)

Problem 7: Prove: If \(ax + by = c\) has integer solutions, then \(\gcd(a, b) \mid c\).

Understanding: This is a necessary condition for the existence of solutions to linear Diophantine equations.

Proof:

Assume there exist integers \(x_0, y_0\) with \(ax_0 + by_0 = c\).
Let \(d = \gcd(a, b)\); by definition, \(d \mid a\) and \(d \mid b\).
Since \(d \mid a\) and \(d \mid b\), we have \(a = da'\) and \(b = db'\) for integers \(a', b'\).
Then \(c = ax_0 + by_0 = da'x_0 + db'y_0 = d(a'x_0 + b'y_0)\)

and \(a'x_0 + b'y_0\) is an integer.

Conclusion: \(d \mid c\), meaning \(\gcd(a, b) \mid c\).

Problem 8: Find the multiplicative inverse of 17 modulo 31.

Understanding: The multiplicative inverse of \(a\) modulo \(m\) is an integer \(x\) such that \(ax \equiv 1 \pmod{m}\). This exists iff \(\gcd(a, m) = 1\).

Step 1: Find \(\gcd(17, 31)\) using the Euclidean Algorithm.

\[31 = 17 \times 1 + 14\]

\[17 = 14 \times 1 + 3\]

\[14 = 3 \times 4 + 2\]

\[3 = 2 \times 1 + 1\]

\[2 = 1 \times 2 + 0\]

Indeed, \(\gcd(17, 31) = 1\), so the inverse exists.

Step 2: Use Extended Euclidean Algorithm backward.

From \(3 - 2 \times 1 = 1\):
\[1 = 3 - 2\]

Substitute \(2 = 14 - 3 \times 4\):
\[1 = 3 - (14 - 3 \times 4) = 3 \times 5 - 14\]

Substitute \(3 = 17 - 14\):
\[1 = (17 - 14) \times 5 - 14 = 17 \times 5 - 14 \times 6\]

Substitute \(14 = 31 - 17\):
\[1 = 17 \times 5 - (31 - 17) \times 6 = 17 \times 11 - 31 \times 6\]

Answer: \(17 \times 11 = 187 \equiv 187 - 6 \times 31 = 187 - 186 = 1 \pmod{31}\)
Thus \(17^{-1} \equiv 11 \pmod{31}\)

Problem 9: Show that if \(\gcd(a, b) = 1\), there are infinitely many solutions to \(ax + by = 1\).

Understanding: Bézout's identity guarantees at least one solution. We prove there are infinitely many.

Proof:

Step 1: There exists at least one solution.

By Bézout's identity, since \(\gcd(a, b) = 1\), there exist integers \(x_0, y_0\) with \(ax_0 + by_0 = 1\).

Step 2: Generate infinitely many new solutions.

Consider \(x_n = x_0 + nb\) and \(y_n = y_0 - na\) for any integer \(n\).

Check: \(a(x_0 + nb) + b(y_0 - na) = ax_0 + anb + by_0 - bna = ax_0 + by_0 = 1\)

Step 3: Show they are distinct.

If \(n_1 \neq n_2\), then \(x_{n_1} = x_0 + n_1b \neq x_0 + n_2b = x_{n_2}\) (since \(b \neq 0\) unless one of \(a, b\) is zero, which contradicts coprime).

Conclusion: There are infinitely many integer solutions.

Bonus Solutions

Bonus Problem 1: Prove that if \(ax + by = c\) and \(ax' + by' = c'\), then any linear combination of these solutions is also a solution to a related equation.

Understanding: The set of solutions to a linear Diophantine equation forms a coset of the solution set to the associated homogeneous equation.

Result: If \((x, y)\) satisfies \(ax + by = c\) and \((x', y')\) satisfies \(ax' + by' = c'\), then for any integers \(m, n\):

\[a(mx + nx') + b(my + ny') = m(ax + by) + n(ax' + by') = mc + nc'\]

Conclusion: A linear combination of solutions gives a solution to the equation with constant \(mc + nc'\).

Bonus Problem 2: Find the smallest positive integer that can be written as \(17x + 29y\) for integers \(x, y\).

Understanding: By Bézout's identity, the smallest positive integer expressible as a linear combination of 17 and 29 is \(\gcd(17, 29)\).

Since 17 and 29 are both prime, they are coprime.

Therefore, \(\gcd(17, 29) = 1\).

Answer: The smallest positive integer is 1. Indeed, we found \(17 \times 11 + 29 \times (-6) = 187 - 174 = 1\).

Bonus Problem 3: Prove that if \(\gcd(a, b) = d\), then \(\gcd(\frac{a}{d}, \frac{b}{d}) = 1\).

Understanding: When we divide both numbers by their GCD, the result should be coprime.

Proof:

Let \(a' = \frac{a}{d}\) and \(b' = \frac{b}{d}\).

Note that \(a'\) and \(b'\) are integers since \(d \mid a\) and \(d \mid b\).

Suppose \(\gcd(a', b') = g > 1\).

Then \(g \mid a'\) and \(g \mid b'\), so \(a' = ga''\) and \(b' = gb''\) for some integers \(a'', b''\).

Then:

\[a = da' = dga''\]

\[b = db' = dgb''\]

This means \(dg\) is a common divisor of \(a\) and \(b\).

But this contradicts that \(d\) is the GREATEST common divisor.

Since \(dg > d\), we have a common divisor larger than \(d\), contradiction.

Conclusion: \(\gcd(a', b') = 1\).
