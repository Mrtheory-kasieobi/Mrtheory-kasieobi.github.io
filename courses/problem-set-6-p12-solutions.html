Problem Set 6: Trigonometric Identities

Precalculus 12 - Chapter 6 Solutions

Solutions

Problem 1: Prove: \(\frac{\sin\theta}{1 - \cos\theta} + \frac{1 - \cos\theta}{\sin\theta} = \frac{2}{\sin\theta \csc\theta - \cos\theta \sec\theta}\)
Let's simplify the left side first.
Common denominator: \(\frac{\sin^2\theta + (1 - \cos\theta)^2}{\sin\theta(1 - \cos\theta)}\)
Expand numerator: \(\sin^2\theta + 1 - 2\cos\theta + \cos^2\theta = 2 - 2\cos\theta\)
Left side: \(\frac{2(1 - \cos\theta)}{\sin\theta(1 - \cos\theta)} = \frac{2}{\sin\theta}\)
Right side: \(\sin\theta \csc\theta - \cos\theta \sec\theta = 1 - 1 = 0\)
There appears to be an issue with the original identity. Let's verify.
Likely intended: prove equal to \(2\csc\theta\) or similar
Answer: Left side simplifies to \(2\csc\theta\). The given RHS appears incorrect.
Problem 2: Find \(\cos(15°)\) exactly using difference identities.
\(\cos(15°) = \cos(45° - 30°)\)
Use: \(\cos(A - B) = \cos A \cos B + \sin A \sin B\)
\(= \cos(45°)\cos(30°) + \sin(45°)\sin(30°)\)
\(= \frac{\sqrt{2}}{2} \times \frac{\sqrt{3}}{2} + \frac{\sqrt{2}}{2} \times \frac{1}{2}\)
\(= \frac{\sqrt{6}}{4} + \frac{\sqrt{2}}{4} = \frac{\sqrt{6} + \sqrt{2}}{4}\)
Answer: \(\cos(15°) = \frac{\sqrt{6} + \sqrt{2}}{4}\)
Problem 3: If \(\sin(2\theta) = \frac{3}{4}\) and \(\cos(2\theta) = \frac{\sqrt{7}}{4}\), find \(\sin\theta\) and \(\cos\theta\).
Use half-angle formulas:
\(\sin\theta = \pm\sqrt{\frac{1 - \cos(2\theta)}{2}} = \pm\sqrt{\frac{1 - \frac{\sqrt{7}}{4}}{2}} = \pm\sqrt{\frac{4 - \sqrt{7}}{8}}\)
\(\cos\theta = \pm\sqrt{\frac{1 + \cos(2\theta)}{2}} = \pm\sqrt{\frac{1 + \frac{\sqrt{7}}{4}}{2}} = \pm\sqrt{\frac{4 + \sqrt{7}}{8}}\)
Since \(\sin^2(2\theta) + \cos^2(2\theta) = \frac{9}{16} + \frac{7}{16} = 1\) ✓
We need additional info about quadrant of \(2\theta\) or \(\theta\)
Assuming \(2\theta\) in QI: both sinθ and cosθ positive
Answer: \(\sin\theta = \sqrt{\frac{4 - \sqrt{7}}{8}}\), \(\cos\theta = \sqrt{\frac{4 + \sqrt{7}}{8}}\)
Problem 4: Simplify: \(\frac{\sin^2 x - \cos^2 x}{\sin x}\)
Numerator: \(\sin^2 x - \cos^2 x = -(\cos^2 x - \sin^2 x) = -\cos(2x)\)
Expression: \(\frac{-\cos(2x)}{\sin x}\)
Alternatively: \(\frac{\sin^2 x}{\sin x} - \frac{\cos^2 x}{\sin x} = \sin x - \cot x \cos x\)
Or: \(\frac{\sin^2 x - \cos^2 x}{\sin x} = \sin x - \cot x \cos x\)
Answer: \(\sin x - \cot x \cos x\) or \(-\frac{\cos(2x)}{\sin x}\)
Problem 5: Prove: \(\sin(3\theta) = 3\sin\theta - 4\sin^3\theta\) using sum and double angle identities.
Write: \(\sin(3\theta) = \sin(2\theta + \theta)\)
Use sum identity: \(\sin(2\theta + \theta) = \sin(2\theta)\cos\theta + \cos(2\theta)\sin\theta\)
Substitute: \(= 2\sin\theta\cos\theta \cdot \cos\theta + (1 - 2\sin^2\theta) \cdot \sin\theta\)
\(= 2\sin\theta\cos^2\theta + \sin\theta - 2\sin^3\theta\)
Use \(\cos^2\theta = 1 - \sin^2\theta\):
\(= 2\sin\theta(1 - \sin^2\theta) + \sin\theta - 2\sin^3\theta\)
\(= 2\sin\theta - 2\sin^3\theta + \sin\theta - 2\sin^3\theta\)
\(= 3\sin\theta - 4\sin^3\theta\)
QED: Identity proven
Problem 6: Find the exact value of \(\sin(22.5°)\) using half angle identities.
\(22.5° = \frac{45°}{2}\), so use half-angle formula
\(\sin\left(\frac{\theta}{2}\right) = \pm\sqrt{\frac{1 - \cos\theta}{2}}\) where \(\theta = 45°\)
\(\cos(45°) = \frac{\sqrt{2}}{2}\)
\(\sin(22.5°) = \sqrt{\frac{1 - \frac{\sqrt{2}}{2}}{2}} = \sqrt{\frac{2 - \sqrt{2}}{4}} = \frac{\sqrt{2 - \sqrt{2}}}{2}\)
Positive since \(22.5°\) in QI
Answer: \(\sin(22.5°) = \frac{\sqrt{2 - \sqrt{2}}}{2}\)
Problem 7: Two waves interfere: \(y_1 = 3\sin(x)\) and \(y_2 = 4\cos(x)\). Find the amplitude and phase of the resultant wave.
Combine: \(y = 3\sin x + 4\cos x\)
Write as single wave: \(y = R\sin(x + \phi)\)
Expand: \(R\sin x \cos\phi + R\cos x \sin\phi\)
Match: \(R\cos\phi = 3\), \(R\sin\phi = 4\)
\(R^2 = 3^2 + 4^2 = 25\), so \(R = 5\)
\(\tan\phi = \frac{4}{3}\), so \(\phi = \arctan\left(\frac{4}{3}\right)\)
Answer: Amplitude = 5, Phase angle = \(\arctan\left(\frac{4}{3}\right)\)
Problem 8: Prove: \(\frac{1 + \tan^2\theta}{1 + \cot^2\theta} = \tan^2\theta\)
Left side: \(\frac{1 + \tan^2\theta}{1 + \cot^2\theta}\)
Recall: \(1 + \tan^2\theta = \sec^2\theta\) and \(1 + \cot^2\theta = \csc^2\theta\)
So left side = \(\frac{\sec^2\theta}{\csc^2\theta} = \frac{1/\cos^2\theta}{1/\sin^2\theta} = \frac{\sin^2\theta}{\cos^2\theta} = \tan^2\theta\)
QED: Identity proven

Bonus Solutions

Bonus Problem 1: Find all values of \(\theta\) for which \(\sin(3\theta) = \cos(3\theta)\) in the interval \([0, 2\pi)\).
\(\sin(3\theta) = \cos(3\theta)\) means \(\tan(3\theta) = 1\)
\(3\theta = \frac{\pi}{4} + \pi n\) for integer \(n\)
\(\theta = \frac{\pi}{12} + \frac{\pi n}{3}\)
Find all values in \([0, 2\pi)\):
\(n = 0\): \(\theta = \frac{\pi}{12}\)
\(n = 1\): \(\theta = \frac{\pi}{12} + \frac{\pi}{3} = \frac{5\pi}{12}\)
\(n = 2\): \(\theta = \frac{\pi}{12} + \frac{2\pi}{3} = \frac{3\pi}{4}\)
\(n = 3\): \(\theta = \frac{\pi}{12} + \pi = \frac{13\pi}{12}\)
\(n = 4\): \(\theta = \frac{\pi}{12} + \frac{4\pi}{3} = \frac{17\pi}{12}\)
\(n = 5\): \(\theta = \frac{\pi}{12} + \frac{5\pi}{3} = \frac{7\pi}{4}\)
Answer: \(\theta = \frac{\pi}{12}, \frac{5\pi}{12}, \frac{3\pi}{4}, \frac{13\pi}{12}, \frac{17\pi}{12}, \frac{7\pi}{4}\)
Bonus Problem 2: Prove: \(\cos(5\theta) = 16\cos^5\theta - 20\cos^3\theta + 5\cos\theta\) using De Moivre's theorem.
De Moivre: \((\cos\theta + i\sin\theta)^5 = \cos(5\theta) + i\sin(5\theta)\)
Expand LHS using binomial theorem:
\(\cos^5\theta + 5i\cos^4\theta\sin\theta - 10\cos^3\theta\sin^2\theta - 10i\cos^2\theta\sin^3\theta + 5\cos\theta\sin^4\theta + i\sin^5\theta\)
Real part: \(\cos^5\theta - 10\cos^3\theta\sin^2\theta + 5\cos\theta\sin^4\theta\)
Substitute \(\sin^2\theta = 1 - \cos^2\theta\):
\(= \cos^5\theta - 10\cos^3\theta(1 - \cos^2\theta) + 5\cos\theta(1 - \cos^2\theta)^2\)
\(= \cos^5\theta - 10\cos^3\theta + 10\cos^5\theta + 5\cos\theta(1 - 2\cos^2\theta + \cos^4\theta)\)
\(= 11\cos^5\theta - 10\cos^3\theta + 5\cos\theta - 10\cos^3\theta + 5\cos^5\theta\)
\(= 16\cos^5\theta - 20\cos^3\theta + 5\cos\theta\)
QED: Identity proven
