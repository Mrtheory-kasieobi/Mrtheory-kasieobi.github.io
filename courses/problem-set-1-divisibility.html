Problem Set 1: Divisibility and Primes

Elementary Number Theory - Week 1 Medium

Problems

Problem 1

Prove that if \(a \mid b\) and \(b \mid c\), then \(a \mid c\).

Problem 2

Find all integers \(n\) such that \(n \mid (n+5)\).

Problem 3

Prove: If \(a \mid b\) and \(a \mid c\), then \(a \mid (bx + cy)\) for all integers \(x, y\).

Problem 4

Show that if \(\gcd(a, b) = 1\) and \(a \mid bc\), then \(a \mid c\).

Problem 5

Prove that there are infinitely many prime numbers.

Problem 6

Find the prime factorization of 360.

Problem 7

Prove: If \(p\) is prime and \(p \mid ab\), then \(p \mid a\) or \(p \mid b\).

Problem 8

Find \(\gcd(144, 84)\) using the Euclidean algorithm.

Problem 9

Show that if \(n \mid m\) and \(m \mid n\), then \(|n| = |m|\).

Problem 10

Prove: \(\gcd(a, b) = \gcd(b, a - bq)\) for any integer \(q\).

Bonus Problems

Bonus Problem 1

Challenge: Prove that \(\gcd(a, b) = \min\{ax + by : x, y \in \mathbb{Z}\}\).

Bonus Problem 2

Challenge: Show that if \(p\) is prime, then \(\sqrt{p}\) is irrational.

Bonus Problem 3

Challenge: Prove that if \(n = p_1^{a_1} \cdots p_k^{a_k}\), then the number of positive divisors is \((a_1+1)\cdots(a_k+1)\).
