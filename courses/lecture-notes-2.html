Lecture 2: The Euclidean Algorithm and Bézout's Identity

Lecture 2The Euclidean Algorithm and Bézout's Identity

1. The Greatest Common Divisor

Definition 1.1 (Greatest Common Divisor) Let \(a, b \in \mathbb{Z}\) with \((a, b) \neq (0, 0)\). The greatest common divisor of \(a\) and \(b\), denoted \(\gcd(a, b)\), is the largest positive integer that divides both \(a\) and \(b\).
Example 2.1 Computing \(\gcd(a, b)\) for various pairs:
  • \(\gcd(12, 18) = 6\) because 6 is the largest integer dividing both 12 and 18
  • \(\gcd(7, 11) = 1\) because 7 and 11 are both prime and different
  • \(\gcd(100, 25) = 25\) because 25 divides 100 (100 = 25·4)
  • \(\gcd(0, 5) = 5\) because 5 divides 0 (0 = 5·0) and 5 divides 5
Definition 1.2 (Relatively Prime) Two integers \(a\) and \(b\) are called relatively prime (or coprime) if \(\gcd(a, b) = 1\).

2. The Euclidean Algorithm

Definition 2.1 (Euclidean Division) Given integers \(a\) and \(b\) with \(b > 0\), there exist unique integers \(q\) (quotient) and \(r\) (remainder) such that:

\[a = bq + r \quad \text{with} \quad 0 \leq r < b\]
Theorem 2.1 (Euclidean Algorithm) Given integers \(a\) and \(b\) with \(b > 0\), we can compute \(\gcd(a, b)\) by the following procedure:
  1. Divide \(a\) by \(b\) to get \(a = bq_1 + r_1\) with \(0 \leq r_1 < b\)
  2. If \(r_1 = 0\), then \(\gcd(a, b) = b\). Stop.
  3. Otherwise, divide \(b\) by \(r_1\) to get \(b = r_1 q_2 + r_2\) with \(0 \leq r_2 < r_1\)
  4. Continue until a remainder of 0 is obtained.
  5. The last non-zero remainder is \(\gcd(a, b)\).
Example 2.2 Find \(\gcd(252, 198)\) using the Euclidean Algorithm:
Iteration 1:

Divide 252 by 198:

\[252 = 198 \cdot 1 + 54\]

Remainder \(r_1 = 54 \neq 0\), so continue.

Iteration 2:

Divide 198 by 54:

\[198 = 54 \cdot 3 + 36\]

Remainder \(r_2 = 36 \neq 0\), so continue.

Iteration 3:

Divide 54 by 36:

\[54 = 36 \cdot 1 + 18\]

Remainder \(r_3 = 18 \neq 0\), so continue.

Iteration 4:

Divide 36 by 18:

\[36 = 18 \cdot 2 + 0\]

Remainder \(r_4 = 0\). Stop!

Conclusion:

The last non-zero remainder is 18, so \(\gcd(252, 198) = 18\).

Check: \(252 = 18 \cdot 14\) and \(198 = 18 \cdot 11\). ✓

3. Extended Euclidean Algorithm and Bézout's Identity

Theorem 3.1 (Bézout's Identity) Let \(a, b \in \mathbb{Z}\) with \((a, b) \neq (0, 0)\). Then there exist integers \(x, y \in \mathbb{Z}\) such that:

\[\gcd(a, b) = ax + by\]

Note: The integers \(x\) and \(y\) are not unique. There are infinitely many solutions once one pair is found.

Proof of Bézout's Identity:
Step 1: Consider the set S

Define the set:

\[S = \{ax + by : x, y \in \mathbb{Z}\}\]

This is the set of all integer linear combinations of \(a\) and \(b\).

Step 2: S contains positive integers (unless a = b = 0)

Since \((a, b) \neq (0, 0)\), at least one of \(a\) or \(b\) is non-zero.

If \(a \neq 0\), then \(a = a \cdot 1 + b \cdot 0 \in S\) and \(|a| \in S\).

So \(S\) contains positive integers.

Step 3: Let d be the smallest positive element of S

By the well-ordering principle (every non-empty set of positive integers has a smallest element), \(S\) has a smallest positive element. Call it \(d\).

So \(d = ax_0 + by_0\) for some integers \(x_0, y_0\).

Step 4: Show d divides both a and b

We'll show \(d \mid a\). The proof for \(b\) is identical.

By Euclidean division: \(a = dq + r\) where \(0 \leq r < d\).

Then \(r = a - dq = a - (ax_0 + by_0)q = a(1 - qx_0) + b(-qy_0)\)

So \(r \in S\). But \(r < d\) and \(d\) is the smallest positive element of \(S\).

Therefore \(r = 0\), meaning \(d \mid a\).

Similarly, \(d \mid b\).

Step 5: Show d is the greatest common divisor

Let \(g = \gcd(a, b)\). We know \(g \mid a\) and \(g \mid b\).

Therefore \(g \mid (ax_0 + by_0) = d\).

Since \(g > 0\) and \(d > 0\), we have \(g \leq d\).

But we also showed \(d \mid a\) and \(d \mid b\), so \(d \leq g\).

Therefore \(d = g\). \(\square\)

Example 3.1 Find integers \(x, y\) such that \(\gcd(252, 198) = 252x + 198y\).
Step 1: Run Euclidean Algorithm (backwards)

From earlier: \(252 = 198 \cdot 1 + 54\)

So \(54 = 252 - 198 \cdot 1\)

Step 2: Express each remainder in terms of 252 and 198

Continue: \(198 = 54 \cdot 3 + 36\)

So \(36 = 198 - 54 \cdot 3 = 198 - (252 - 198) \cdot 3 = 198 - 252 \cdot 3 + 198 \cdot 3 = 198 \cdot 4 - 252 \cdot 3\)

Step 3: Continue backwards

Continue: \(54 = 36 \cdot 1 + 18\)

So \(18 = 54 - 36 \cdot 1 = (252 - 198) - (198 \cdot 4 - 252 \cdot 3) = 252 - 198 - 198 \cdot 4 + 252 \cdot 3 = 252 \cdot 4 - 198 \cdot 5\)

Conclusion:

We found: \(18 = 252 \cdot 4 + 198 \cdot (-5)\)

Therefore \(x = 4\) and \(y = -5\) satisfy Bézout's identity.

Check: \(252 \cdot 4 + 198 \cdot (-5) = 1008 - 990 = 18 = \gcd(252, 198)\). ✓

4. Properties of GCD

Theorem 4.1 (Properties of GCD) Let \(a, b, c \in \mathbb{Z}\).
  1. Commutativity: \(\gcd(a, b) = \gcd(b, a)\)
  2. Associativity: \(\gcd(\gcd(a, b), c) = \gcd(a, \gcd(b, c))\)
  3. Multiplication: If \(\gcd(a, c) = 1\), then \(\gcd(ab, c) = \gcd(a, c) \cdot \gcd(b, c)\)
  4. Division: If \(d \mid a\) and \(d \mid b\), then \(\gcd(a/d, b/d) = \gcd(a, b)/d\)
Proof of Property 4.1(1) - Commutativity:
Step 1: Let d = gcd(a, b)

Then \(d \mid a\) and \(d \mid b\), and \(d\) is the largest such integer.

Step 2: Show d also divides gcd(b, a)

Since \(d \mid b\) and \(d \mid a\), \(d\) is a common divisor of \(b\) and \(a\).

Therefore \(d \leq \gcd(b, a)\).

Step 3: Symmetrically, gcd(b, a) ≤ d

By the same reasoning, \(\gcd(b, a) \leq \gcd(a, b) = d\).

Conclusion:

Since \(d \leq \gcd(b, a)\) and \(\gcd(b, a) \leq d\), we have \(d = \gcd(b, a)\). \(\square\)

5. Applications and Connections

Theorem 5.1 (Connection to Linear Diophantine Equations) The linear equation \(ax + by = c\) has integer solutions if and only if \(\gcd(a, b) \mid c\).
Proof:
(⇒) If solutions exist, then gcd(a,b) | c:

Suppose \(x_0, y_0\) satisfy \(ax_0 + by_0 = c\).

Let \(d = \gcd(a, b)\). Then \(d \mid a\) and \(d \mid b\).

Therefore \(d \mid (ax_0 + by_0) = c\).

(⇐) If gcd(a,b) | c, then solutions exist:

Suppose \(d = \gcd(a, b)\) and \(d \mid c\).

By Bézout's identity, there exist \(x_0, y_0\) such that \(ax_0 + by_0 = d\).

Since \(d \mid c\), we have \(c = dk\) for some integer \(k\).

Multiplying both sides by \(k\): \(a(x_0 k) + b(y_0 k) = dk = c\).

So \(x = x_0 k\) and \(y = y_0 k\) are solutions. \(\square\)

Exercises:
  1. Use the Euclidean Algorithm to find \(\gcd(1234, 567)\).
  2. Find integers \(x, y\) such that \(1234x + 567y = \gcd(1234, 567)\).
  3. Show that if \(\gcd(a, b) = d\), then \(\gcd(a/d, b/d) = 1\).
  4. Prove: \(\gcd(ab, ac) = a \gcd(b, c)\) for \(a, b, c > 0\).
  5. Determine whether \(17x + 23y = 1\) has integer solutions.
  6. Determine whether \(17x + 23y = 2\) has integer solutions.
  7. Find all solutions to \(12x + 18y = 6\) given one particular solution.
  8. Prove: If \(\gcd(a, b) = 1\) and \(a \mid bc\), then \(a \mid c\).
