Problem Set 3: Polynomial Functions

Precalculus 12 - Problem Set
Topics: Polynomial Functions, Remainder/Factor Theorems, Graphing Medium

Problems

Problem 1

Determine the end behavior of \(f(x) = -x^4 + 2x^3 + 5x - 1\). How many turning points can this function have at most?

Problem 2

Use the Remainder Theorem to find the remainder when \(P(x) = x^4 - 3x^2 + 2x - 5\) is divided by \((x - 2)\).

Problem 3

Factor completely: \(f(x) = x^3 - 6x^2 + 11x - 6\). Use the Factor Theorem to help you.

Problem 4

Graph \(f(x) = (x + 1)(x - 2)^2(x - 4)\) by identifying key features. What is the behavior near each x-intercept?

Problem 5

A projectile's height is given by \(h(t) = -4.9t^2 + 25t + 2\). When does it hit the ground? What is the maximum height?

Problem 6

Find all zeros of \(f(x) = x^4 - 5x^2 + 4\) and sketch the graph.

Problem 7

Using the Rational Root Theorem, find all rational zeros of \(f(x) = 2x^3 - 3x^2 - 11x + 6\).

Problem 8

A company's revenue is \(R(x) = -0.1x^3 + 2x^2 + 5x\) and cost is \(C(x) = 0.05x^3 + x + 10\). Find the profit function and break-even points.

Bonus Problems

Bonus Problem 1

Find all real zeros of \(f(x) = x^4 - 4x^3 + 3x^2 + 4x - 4\) and factor the polynomial completely.

Bonus Problem 2

A polynomial of degree 4 has zeros at \(x = -1\) (multiplicity 2) and \(x = 2 + i\) (where \(i\) is the imaginary unit with \(i^2 = -1\)). Find the polynomial with leading coefficient 1.
