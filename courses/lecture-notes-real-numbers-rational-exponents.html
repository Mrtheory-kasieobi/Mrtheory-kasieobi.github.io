Real Numbers and Rational Exponents

Precalculus 11 - Lecture Notes
British Columbia Curriculum | Week 1-2

1. The Real Number System

Understanding the classification of numbers is fundamental to algebra. The real number system is organized into nested subsets.

Definition: The real numbers are all rational and irrational numbers. They can be represented on the number line.

1.1 Classification of Real Numbers

Real numbers are classified as follows:

Set Definition Examples
Natural Numbers (\(\mathbb{N}\)) Positive counting numbers \(1, 2, 3, 4, \ldots\)
Whole Numbers Natural numbers plus zero \(0, 1, 2, 3, \ldots\)
Integers (\(\mathbb{Z}\)) Positive and negative whole numbers \(\ldots, -3, -2, -1, 0, 1, 2, 3, \ldots\)
Rational Numbers (\(\mathbb{Q}\)) Numbers that can be expressed as a fraction \(\frac{a}{b}\) where \(a, b\) are integers and \(b \neq 0\) \(\frac{1}{2}, -\frac{3}{4}, 5, 0.75, 0.\overline{33}\)
Irrational Numbers Numbers that cannot be expressed as fractions; non-repeating, non-terminating decimals \(\sqrt{2}, \pi, \sqrt{3}, e\)
Example 1: Classifying Numbers

Classify each number: (a) 5 (b) \(-\frac{3}{7}\) (c) \(\sqrt{16}\) (d) \(0.25\overline{25}\) (e) \(\pi\)

Solution:

(a) 5 is a natural number, whole number, integer, and rational

(b) \(-\frac{3}{7}\) is rational

(c) \(\sqrt{16} = 4\) is rational (it's an integer)

(d) \(0.25\overline{25} = \frac{25}{99}\) is rational (repeating decimal)

(e) \(\pi\) is irrational

1.2 Properties of Real Numbers

The following properties are essential for algebraic manipulation:

For all real numbers \(a\), \(b\), and \(c\):
Commutative: \(a + b = b + a\); \(ab = ba\)
Associative: \((a + b) + c = a + (b + c)\); \((ab)c = a(bc)\)
Distributive: \(a(b + c) = ab + ac\)
Identity: \(a + 0 = a\); \(a \cdot 1 = a\)
Inverse: \(a + (-a) = 0\); \(a^{-1} \cdot \frac{1}{a} = 1\) (where \(a \neq 0\))

2. Rational Exponents

2.1 Definition and Relationship to Radicals

Rational exponents provide an alternative notation for radicals.

Definition: For any real number \(a \geq 0\) and integers \(m, n\) with \(n > 0\):
\(a^{1/n} = \sqrt[n]{a}\) (n-th root)
\(a^{m/n} = (\sqrt[n]{a})^{m} = \sqrt[n]{a^{m}}\)
Example 2: Converting Between Radicals and Exponents

Express as radicals and evaluate:
(a) \(8^{1/3}\) (b) \(16^{3/4}\) (c) \(25^{-1/2}\)

Solution:

(a) \(8^{1/3} = \sqrt[3]{8} = 2\)

(b) \(16^{3/4} = (\sqrt[4]{16})^{3} = 2^{3} = 8\)

(c) \(25^{-1/2} = \frac{1}{25^{1/2}} = \frac{1}{\sqrt{25}} = \frac{1}{5}\)

2.2 When are Rational Exponents Defined?

The domain depends on whether the denominator (index) is even or odd:

  • Even index (n even): \(a^{m/n}\) requires \(a \geq 0\) (or \(a > 0\) for \(m > 0\))
  • Odd index (n odd): \(a^{m/n}\) is defined for all real \(a\)
Key Point:

For even roots in the denominator, the base must be non-negative to stay in real numbers. For example, \((-8)^{1/3} = -2\) (odd root), but \((-4)^{1/2}\) is not real.

3. Exponent Laws with Rational Exponents

The same exponent laws that apply to integer exponents also apply to rational exponents.

For rational exponents where expressions are defined:

1. Product Law: \(a^{m/n} \cdot a^{p/q} = a^{m/n + p/q}\)
2. Quotient Law: \(a^{m/n} / a^{p/q} = a^{m/n - p/q}\)
3. Power Law: \((a^{m/n})^{p/q} = a^{mp/nq}\)
4. Power Rule: \((ab)^{m/n} = a^{m/n} \cdot b^{m/n}\)
5. Quotient Rule: \((a/b)^{m/n} = a^{m/n} / b^{m/n}\)

3.1 Simplifying Expressions with Rational Exponents

Example 3: Using Exponent Laws

Simplify: \((x^{2/3} \cdot x^{1/6}) / (x^{1/2})\)

Solution:

Apply product law in numerator: \(x^{2/3 + 1/6} = x^{4/6 + 1/6} = x^{5/6}\)

Apply quotient law: \(x^{5/6 - 1/2} = x^{5/6 - 3/6} = x^{2/6} = x^{1/3}\)

Example 4: Power of a Power

Simplify: \((\sqrt[3]{x^{3}})^{2/5}\)

Solution:

Convert to exponent form: \((x^{3})^{2/5} = x^{3 \cdot 2/5} = x^{6/5} = \sqrt[5]{x^{6}} = x\sqrt[5]{x}\)

4. Evaluating Expressions with Rational Exponents

4.1 Evaluating with Numerical Bases

Example 5: Evaluating Numerical Expressions

Evaluate: (a) \(64^{1/3}\) (b) \(32^{3/5}\) (c) \(125^{-2/3}\)

Solution:

(a) \(64 = 4^{3}\), so \(64^{1/3} = (4^{3})^{1/3} = 4\)

(b) \(32 = 2^{5}\), so \(32^{3/5} = (2^{5})^{3/5} = 2^{3} = 8\)

(c) \(125^{-2/3} = \frac{1}{125^{2/3}} = \frac{1}{\sqrt[3]{125^{2}}} = \frac{1}{5^{2}} = \frac{1}{25}\)

4.2 Evaluating with Variable Bases

Example 6: Evaluating Variable Expressions

Evaluate: \((x^{2}y^{3})^{1/2}\) for \(x = 4, y = 3\)

Solution:

Algebraic simplification first:
\((x^{2}y^{3})^{1/2} = x^{2 \cdot 1/2} y^{3 \cdot 1/2} = x^{1} y^{3/2} = xy^{3/2}\)

Substitute:
\(xy^{3/2} = 4 \cdot 3^{3/2} = 4 \cdot (\sqrt{3})^{3} = 4 \cdot 3\sqrt{3} = 12\sqrt{3}\)

5. Connections Between Rational Exponents and Radicals

Every radical can be written as a rational exponent and vice versa. This connection is essential for solving equations.

Key Relationships:
\(\sqrt{a} = a^{1/2}\) (square root)
\(\sqrt[3]{a} = a^{1/3}\) (cube root)
\(\sqrt[3]{a^{n}} = a^{n/3}\)
\(\sqrt[n]{a^{m}} = a^{m/n}\)
Example 7: Solving Radical Equations

Solve: \(\sqrt{x + 1} = 5\)

Solution:

Rewrite using rational exponent: \((x + 1)^{1/2} = 5\)

Square both sides: \(x + 1 = 25\)

Solve: \(x = 24\)

Check: \(\sqrt{24 + 1} = \sqrt{25} = 5\) ✓

Important:

When solving equations involving radicals or rational exponents, always check for extraneous solutions by substituting back into the original equation.

6. Summary of Key Formulas

Concept Formula/Definition
Rational Exponent Definition \(a^{m/n} = (\sqrt[n]{a})^{m} = \sqrt[n]{a^{m}}\)
Negative Rational Exponent \(a^{-m/n} = \frac{1}{a^{m/n}}\)
Product of Powers \(a^{m} \cdot a^{n} = a^{m+n}\)
Quotient of Powers \(\frac{a^{m}}{a^{n}} = a^{m-n}\)
Power of a Power \((a^{m})^{n} = a^{mn}\)
