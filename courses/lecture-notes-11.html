Lecture 11: Applications of Gaussian Integers

Lecture 11Applications of Gaussian Integers

1. Sum of Two Squares Theorem

Theorem 11.1 (Fermat's Two Squares Theorem) A positive integer \(n\) can be expressed as \(n = x^2 + y^2\) for integers \(x, y\) if and only if in the prime factorization of \(n\), every prime \(p \equiv 3 \pmod{4}\) appears with an even exponent.
Proof:
Step 1: Necessity - if n = x² + y², then primes p ≡ 3 (mod 4) have even exponent

Suppose \(n = x^2 + y^2\). If a prime \(p \equiv 3 \pmod{4}\) divides \(n\) to an odd power, write \(n = p^{2k+1} m\) where \(p \nmid m\).

Since \(n = x^2 + y^2\), we have \(p^{2k+1} \mid (x^2 + y^2)\).

Step 2: Use infinite descent

If \(p \mid x\), then \(p \mid y\) (since \(p \mid x^2 + y^2\)). Write \(x = px', y = py'\). Then \(p^{2k+1} \mid p^2(x'^2 + y'^2)\), so \(p^{2k-1} \mid x'^2 + y'^2\).

Continue until we get \(p \mid (x_0^2 + y_0^2)\) where \(p \nmid x_0\) or \(p \nmid y_0\).

Step 3: Contradiction using quadratic residues

If \(p \nmid x_0\), then \(x_0^2 + y_0^2 \equiv 0 \pmod{p}\), so \(-y_0^2 \equiv x_0^2 \pmod{p}\), giving \((x_0y_0^{-1})^2 \equiv -1 \pmod{p}\).

This contradicts that \(-1\) is not a quadratic residue modulo \(p\) when \(p \equiv 3 \pmod{4}\). \(\square\)

Proof of Sufficiency:
Step 1: Brahmagupta-Fibonacci identity

It suffices to show:

  1. If \(n_1 = x_1^2 + y_1^2\) and \(n_2 = x_2^2 + y_2^2\), then \(n_1 n_2 = x_3^2 + y_3^2\).
  2. \(p^k = x^2 + y^2\) for any prime \(p \equiv 1 \pmod{4}\) and any \(k \geq 1\).
  3. \(2^k = x^2 + y^2\) for any \(k \geq 1\).

The Brahmagupta-Fibonacci identity gives: \[(x_1^2 + y_1^2)(x_2^2 + y_2^2) = (x_1x_2 - y_1y_2)^2 + (x_1y_2 + x_2y_1)^2\]

Step 2: Apply to prime factorizations

Since the property is multiplicative, we only need to check it for prime powers.

For \(p \equiv 1 \pmod{4}\): By Theorem 9.1 (Lecture 9), \(p = \pi\bar{\pi}\) in \(\mathbb{Z}[i]\) where \(\pi = a + bi\). Then \(p = a^2 + b^2\).

For \(p \equiv 3 \pmod{4}\): By Theorem 8.1 (Lecture 8), \(p\) remains prime in \(\mathbb{Z}[i]\), so \(p^k = x^2 + y^2\) only if \(k\) is even.

For \(p = 2\): \(2 = 1^2 + 1^2\), and \(2^k = (1+i)^k(1-i)^k\). \(\square\)

2. Pell's Equation via Gaussian Integers

Definition 11.1 (Pell's Equation) An equation of the form: \[x^2 - Dy^2 = 1\] where \(D\) is a positive non-square integer, is called Pell's equation.
Example 11.1 Find solutions to \(x^2 - 2y^2 = 1\).
Step 1: Find minimal solution

Try small values of \(y\):

  • \(y = 1\): \(x^2 = 1 + 2 = 3\), not a square
  • \(y = 2\): \(x^2 = 1 + 8 = 9\), so \(x = 3\)
Minimal solution: \((x, y) = (3, 2)\)

Step 2: Generate more solutions

In \(\mathbb{Z}[i\sqrt{2}]\), if \(x + y\sqrt{2}\) is a solution, then \((x + y\sqrt{2})^n\) gives another solution.

\((3 + 2\sqrt{2})^2 = 9 + 12\sqrt{2} + 8 = 17 + 12\sqrt{2}\)

So \((x_2, y_2) = (17, 12)\): Check \(17^2 - 2 \cdot 12^2 = 289 - 288 = 1\) ✓

3. Applications to Diophantine Equations

Theorem 11.2 The equation \(x^2 + y^2 = z^n\) has integer solutions for any \(n \geq 1\).
Step 1: Use Gaussian integers

Write \(x + yi = (a + bi)^n\) for some Gaussian integer \(a + bi\).

Then \(x^2 + y^2 = N(x + yi) = N(a + bi)^n = (a^2 + b^2)^n\).

Step 2: Find a suitable base

Choose \(a + bi\) such that \(a^2 + b^2\) has the desired form for \(z\).

For example, if \(z = 5\), use \(1 + 2i\) since \(N(1 + 2i) = 5\).

Then \((1 + 2i)^n = x + yi\) gives \(x^2 + y^2 = 5^n\). \(\square\)

Example 11.2 Find integers \(x, y\) such that \(x^2 + y^2 = 125\).
Step 1: Factor 125

\(125 = 5^3\). Use \(1 + 2i\) since \(N(1 + 2i) = 5\).

Step 2: Compute (1 + 2i)³

\((1 + 2i)^2 = 1 + 4i + 4i^2 = 1 + 4i - 4 = -3 + 4i\)

\((1 + 2i)^3 = (-3 + 4i)(1 + 2i) = -3 - 6i + 4i + 8i^2 = -3 - 2i - 8 = -11 - 2i\)

Step 3: Conclude

\((-11)^2 + (-2)^2 = 121 + 4 = 125\) ✓

Exercises:
  1. Express 50 as a sum of two squares in all possible ways.
  2. Show that 21 cannot be written as a sum of two squares.
  3. Find a solution to \(x^2 - 3y^2 = 1\).
  4. Find integers \(x, y\) such that \(x^2 + y^2 = 343\).
  5. Prove: If \(n = x^2 + y^2\) and \(\gcd(x, y) = 1\), then no prime \(p \equiv 3 \pmod{4}\) divides \(n\).
  6. Show that \(x^2 + y^2 = 2^n\) has solutions for all \(n \geq 1\).
  7. Find the smallest positive integer \(y\) such that \(x^2 - 5y^2 = 1\) for some integer \(x\).
  8. Prove: If \(p \equiv 1 \pmod{4}\) is prime, then \(x^2 + y^2 = p\) has exactly 8 solutions (counting signs and order).
