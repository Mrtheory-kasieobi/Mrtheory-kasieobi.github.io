Solutions: Problem Set 7: Quadratic Reciprocity Law

Elementary Number Theory - Week 8 Solutions

Key Definitions and Concepts

Law of Quadratic Reciprocity

For distinct odd primes \(p\) and \(q\):
\[\left(\frac{p}{q}\right)\left(\frac{q}{p}\right) = (-1)^{\frac{(p-1)(q-1)}{4}}\]

This means \(\left(\frac{p}{q}\right) = \left(\frac{q}{p}\right)\) unless both \(p\) and \(q\) are \(\equiv 3 \pmod{4}\).

Computational Rule

\(\left(\frac{p}{q}\right) = \left(\frac{q}{p}\right)\) if at least one of \(p, q \equiv 1 \pmod{4}\),
\(\left(\frac{p}{q}\right) = -\left(\frac{q}{p}\right)\) if both \(p, q \equiv 3 \pmod{4}\)

Solutions

Problem 1: Compute \(\left(\frac{3}{11}\right)\) using quadratic reciprocity.

Step 1: Check the conditions.
3 ≡ 3 (mod 4), 11 ≡ 3 (mod 4), so we need the negative sign.
\[\left(\frac{3}{11}\right) = -\left(\frac{11}{3}\right)\]

Step 2: Reduce 11 mod 3.
\[11 = 3 \times 3 + 2\]
\[11 \equiv 2 \pmod{3}\]
So \(\left(\frac{11}{3}\right) = \left(\frac{2}{3}\right)\)

Step 3: Apply the supplement for 2.

3 ≡ 3 (mod 8), so \(\left(\frac{2}{3}\right) = -1\)

Answer: \(\left(\frac{3}{11}\right) = -(-1) = 1\)

Problem 2: Compute \(\left(\frac{5}{13}\right)\) using quadratic reciprocity.

Step 1: Determine the sign.
5 ≡ 1 (mod 4), so \(\left(\frac{5}{13}\right) = \left(\frac{13}{5}\right)\)

Step 2: Reduce 13 mod 5.
\[13 \equiv 3 \pmod{5}\]
\[\left(\frac{13}{5}\right) = \left(\frac{3}{5}\right)\]

Step 3: Apply reciprocity again.
3 ≡ 3 (mod 4), 5 ≡ 1 (mod 4), so:
\[\left(\frac{3}{5}\right) = \left(\frac{5}{3}\right)\]
5 ≡ 2 (mod 3), so \(\left(\frac{5}{3}\right) = \left(\frac{2}{3}\right)\)

Step 4: Apply supplement for 2.

3 ≡ 3 (mod 8), so \(\left(\frac{2}{3}\right) = -1\)

Answer: \(\left(\frac{5}{13}\right) = -1\)

Problem 3: Compute \(\left(\frac{7}{23}\right)\) using quadratic reciprocity.

Step 1: Check conditions.
7 ≡ 3 (mod 4), 23 ≡ 3 (mod 4), so:
\[\left(\frac{7}{23}\right) = -\left(\frac{23}{7}\right)\]

Step 2: Reduce 23 mod 7.
\[23 = 7 \times 3 + 2\]
\[23 \equiv 2 \pmod{7}\]
\[\left(\frac{23}{7}\right) = \left(\frac{2}{7}\right)\]

Step 3: Apply supplement for 2.

7 ≡ 7 (mod 8), so \(\left(\frac{2}{7}\right) = -1\)

Answer: \(\left(\frac{7}{23}\right) = -(-1) = 1\)

Problem 4: Find \(\left(\frac{11}{17}\right)\) and \(\left(\frac{17}{11}\right)\). Verify they are equal.

Part 1: Compute \(\left(\frac{11}{17}\right)\):

11 ≡ 3 (mod 4), 17 ≡ 1 (mod 4), so \(\left(\frac{11}{17}\right) = \left(\frac{17}{11}\right)\)

Reduce 17 mod 11: \(17 \equiv 6 \pmod{11}\)
\[\left(\frac{17}{11}\right) = \left(\frac{6}{11}\right) = \left(\frac{2}{11}\right)\left(\frac{3}{11}\right)\]

Compute each factor:

\(\left(\frac{2}{11}\right)\): 11 ≡ 3 (mod 8), so = -1.

\(\left(\frac{3}{11}\right)\): From Problem 1, this equals 1.
Therefore \(\left(\frac{17}{11}\right) = (-1)(1) = -1\)

Answer: Both equal -1, verifying reciprocity.

Problem 5: Compute \(\left(\frac{13}{29}\right)\) using quadratic reciprocity.

Step 1: Check conditions.
13 ≡ 1 (mod 4), 29 ≡ 1 (mod 4), so \(\left(\frac{13}{29}\right) = \left(\frac{29}{13}\right)\)

Step 2: Reduce 29 mod 13.
\[29 = 13 \times 2 + 3\]
\[29 \equiv 3 \pmod{13}\]
\[\left(\frac{29}{13}\right) = \left(\frac{3}{13}\right)\]

Step 3: Apply reciprocity.
3 ≡ 3 (mod 4), 13 ≡ 1 (mod 4), so:
\[\left(\frac{3}{13}\right) = \left(\frac{13}{3}\right)\]
13 ≡ 1 (mod 3), so \(\left(\frac{13}{3}\right) = \left(\frac{1}{3}\right) = 1\)

Answer: \(\left(\frac{13}{29}\right) = 1\)

Bonus Solutions

Bonus Problem 1: Prove \(\left(\frac{-1}{p}\right) = (-1)^{\frac{p-1}{2}}\).

Proof: By Euler's criterion:
\[\left(\frac{-1}{p}\right) \equiv (-1)^{\frac{p-1}{2}} \pmod{p}\]

Since both sides are ±1 and \(p \geq 3\), equality holds.

Alternative proof: There exists \(x\) with \(x^2 \equiv -1 \pmod{p}\) iff \(p \equiv 1 \pmod{4}\).

When \(p = 4k + 1\): \(\frac{p-1}{2} = 2k\), so \((-1)^{2k} = 1\).

When \(p = 4k + 3\): \(\frac{p-1}{2} = 2k + 1\), so \((-1)^{2k+1} = -1\).

Bonus Problem 2: Show \(\left(\frac{2}{p}\right) = (-1)^{\frac{p^2-1}{8}}\).

Verification for each residue class mod 8:

p mod 8(p²-1)/8 mod 2(2/p)
101
31-1
51-1
701

These match the known values, proving the formula.

Bonus Problem 3: If \(p \equiv 3 \pmod{4}\) is prime, show \(\left(\frac{-1}{p}\right) = -1\).

Proof: Write \(p = 4k + 3\) for some integer \(k \geq 0\).
\[\frac{p-1}{2} = \frac{4k + 2}{2} = 2k + 1\]
\[\left(\frac{-1}{p}\right) = (-1)^{2k + 1} = -1\]

Alternative: From Bonus Problem 1, if \(p \equiv 3 \pmod{4}\), then \(\left(\frac{-1}{p}\right) = -1\).
