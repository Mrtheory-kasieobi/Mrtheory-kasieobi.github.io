Lecture 7: Quadratic Residues and the Legendre Symbol

Lecture 7Quadratic Residues and the Legendre Symbol

1. Quadratic Residues

Definition 7.1 (Quadratic Residue) Let \(p\) be an odd prime and \(a \in \mathbb{Z}\) with \(p \nmid a\). We say that \(a\) is a quadratic residue modulo \(p\)** if there exists an integer \(x\) such that: \[x^2 \equiv a \pmod{p}\] Otherwise, \(a\) is called a quadratic non-residue modulo \(p\).
Example 7.1 Determine which elements of \(\mathbb{Z}_7\) are quadratic residues.

We check each \(a \in \{1, 2, 3, 4, 5, 6\}\):

  • \(1^2 \equiv 1 \pmod{7}\) - so 1 is a QR
  • \(2^2 \equiv 4 \pmod{7}\) - so 4 is a QR
  • \(3^2 \equiv 9 \equiv 2 \pmod{7}\) - so 2 is a QR
  • \(4^2 \equiv 16 \equiv 2 \pmod{7}\) - confirms 2 is a QR
  • \(5^2 \equiv 25 \equiv 4 \pmod{7}\) - confirms 4 is a QR
  • \(6^2 \equiv 36 \equiv 1 \pmod{7}\) - confirms 1 is a QR

Therefore, the quadratic residues modulo 7 are: \(\{1, 2, 4\}\)

The quadratic non-residues are: \(\{3, 5, 6\}\)

Theorem 7.1 (Count of Quadratic Residues) For an odd prime \(p\), there are exactly \(\frac{p-1}{2}\) quadratic residues and \(\frac{p-1}{2}\) quadratic non-residues in \(\mathbb{Z}_p^*\).
Proof: Note that \(x^2 \equiv (-x)^2 \pmod{p}\), so each nonzero square has at least two square roots. The only elements with exactly one square root are those satisfying \(x \equiv -x \pmod{p}\), i.e., \(x \equiv 0 \pmod{p}\), which is not in \(\mathbb{Z}_p^*\). Thus each quadratic residue has exactly two square roots among \(\{1, 2, \ldots, p-1\}\). Since there are \(p-1\) elements total and they pair up as \(\{x, -x\}\) with the same square, there are exactly \(\frac{p-1}{2}\) distinct quadratic residues. \(\square\)

2. The Legendre Symbol

Definition 7.2 (Legendre Symbol) For an odd prime \(p\) and integer \(a\) with \(p \nmid a\), the Legendre symbol \(\left(\frac{a}{p}\right)\) is defined by: \[\left(\frac{a}{p}\right) = \begin{cases} 1 & \text{if } a \text{ is a quadratic residue modulo } p \\ -1 & \text{if } a \text{ is a quadratic non-residue modulo } p \end{cases}\] We also define \(\left(\frac{a}{p}\right) = 0\) if \(p \mid a\).
Example 7.2 Compute the Legendre symbols \(\left(\frac{2}{7}\right)\) and \(\left(\frac{3}{7}\right)\).
Step 1: Compute \(\left(\frac{2}{7}\right)\)

From Example 7.1, we found that 2 is a quadratic residue modulo 7.

Therefore \(\left(\frac{2}{7}\right) = 1\).

Step 2: Compute \(\left(\frac{3}{7}\right)\)

We found that 3 is not a quadratic residue modulo 7.

Therefore \(\left(\frac{3}{7}\right) = -1\).

Theorem 7.2 (Properties of the Legendre Symbol) Let \(p\) be an odd prime and \(a, b \in \mathbb{Z}\).
  1. \(\left(\frac{a}{p}\right) \in \{-1, 0, 1\}\)
  2. \(\left(\frac{ab}{p}\right) = \left(\frac{a}{p}\right)\left(\frac{b}{p}\right)\)
  3. \(\left(\frac{a^2}{p}\right) = 1\) for \(p \nmid a\)
  4. \(\left(\frac{-1}{p}\right) = (-1)^{\frac{p-1}{2}}\)
  5. \(\left(\frac{2}{p}\right) = (-1)^{\frac{p^2-1}{8}}\)
Proof of (4): \(\left(\frac{-1}{p}\right) = (-1)^{\frac{p-1}{2}}\)
Step 1: Use Euler's Criterion

We will show that \((-1)^{\frac{p-1}{2}} \equiv \left(\frac{-1}{p}\right) \pmod{p}\).

Step 2: Consider the two cases for p

Case 1: \(p \equiv 1 \pmod{4}\), so \(\frac{p-1}{2}\) is even.

Then \((-1)^{\frac{p-1}{2}} = 1\).

We need to show \(-1\) is a quadratic residue modulo \(p\).

By Wilson's Theorem: \((p-1)! \equiv -1 \pmod{p}\).

Since \(p \equiv 1 \pmod{4}\), we have \(\frac{p-1}{2}\) is even.

Pairing up elements in \((p-1)!\): each pair \((a, a^{-1})\) with \(a \neq a^{-1}\) contributes 1.

The self-inverse elements are 1 and \(p-1\), contributing \(1 \cdot (p-1) \equiv -1 \pmod{p}\).

Since \(\frac{p-1}{2}\) is even, we can pair the elements differently to show \(-1\) is a square.

Step 3: Verify the result

When \(p \equiv 1 \pmod{4}\): \(\left(\frac{-1}{p}\right) = 1 = (-1)^{\frac{p-1}{2}}\)

When \(p \equiv 3 \pmod{4}\): we need \(\left(\frac{-1}{p}\right) = -1 = (-1)^{\frac{p-1}{2}}\)

This completes the proof. \(\square\)

3. Euler's Criterion

Theorem 7.3 (Euler's Criterion) Let \(p\) be an odd prime and \(a\) with \(p \nmid a\). Then: \[\left(\frac{a}{p}\right) \equiv a^{\frac{p-1}{2}} \pmod{p}\] Equivalently, \(\left(\frac{a}{p}\right) = a^{\frac{p-1}{2}}\) (where the right side is interpreted as \(\pm 1\)).
Proof:
Step 1: Use Fermat's Little Theorem

By Fermat's Little Theorem, \(a^{p-1} \equiv 1 \pmod{p}\).

Therefore \((a^{\frac{p-1}{2}})^2 \equiv 1 \pmod{p}\), so \(a^{\frac{p-1}{2}} \equiv \pm 1 \pmod{p}\).

Step 2: Show \(a^{\frac{p-1}{2}} \equiv 1\) iff \(a\) is a QR

We need to show that \(a^{\frac{p-1}{2}} \equiv 1 \pmod{p}\) if and only if \(a\) is a quadratic residue.

Step 3: Forward direction - if \(a\) is a QR

Suppose \(a \equiv x^2 \pmod{p}\) for some \(x\).

Then \(a^{\frac{p-1}{2}} \equiv x^{p-1} \equiv 1 \pmod{p}\) by Fermat's Little Theorem applied to \(x\).

Step 4: Reverse direction - if \(a^{\frac{p-1}{2}} \equiv 1\)

We need to show \(a\) is a quadratic residue.

Consider the polynomial \(f(x) = x^{\frac{p-1}{2}} - a^{\frac{p-1}{2}}\) over \(\mathbb{Z}_p\).

Wait, let's use a different approach using the fact that the multiplicative group is cyclic.

Let \(g\) be a primitive root modulo \(p\). Write \(a \equiv g^k \pmod{p}\).

Then \(a^{\frac{p-1}{2}} \equiv g^{k \cdot \frac{p-1}{2}} \pmod{p}\).

This equals 1 iff \(p-1 \mid k \cdot \frac{p-1}{2}\), i.e., iff \(2 \mid k\).

If \(k\) is even, then \(a \equiv g^k \equiv (g^{k/2})^2 \pmod{p}\), so \(a\) is a QR.

If \(k\) is odd, then \(a^{\frac{p-1}{2}} \equiv -1 \pmod{p}\).

This proves Euler's Criterion. \(\square\)

4. Supplementary Laws

Definition 7.3 (Congruence Classes) For an odd prime \(p\): \[p \equiv 1 \pmod{4} \implies p = 4k + 1\] \[p \equiv 3 \pmod{4} \implies p = 4k + 3\]
Theorem 7.4 (Supplementary Laws)
  1. First Supplementary Law: \(\left(\frac{-1}{p}\right) = 1\) iff \(p \equiv 1 \pmod{4}\)
  2. Second Supplementary Law: \(\left(\frac{2}{p}\right) = 1\) iff \(p \equiv \pm 1 \pmod{8}\)
Example 7.3 Verify the supplementary laws for \(p = 17\) and \(p = 13\).
Step 1: Check \(p = 17\)

\(17 \equiv 1 \pmod{4}\), so \(\left(\frac{-1}{17}\right) = 1\).

Indeed, \(4^2 = 16 \equiv -1 \pmod{17}\). ✓

\(17 \equiv 1 \pmod{8}\), so \(\left(\frac{2}{17}\right) = 1\).

We verify: \(6^2 = 36 \equiv 2 \pmod{17}\). ✓

Step 2: Check \(p = 13\)

\(13 \equiv 1 \pmod{4}\), so \(\left(\frac{-1}{13}\right) = 1\).

We verify: \(5^2 = 25 \equiv -1 \pmod{13}\). ✓

\(13 \equiv 5 \pmod{8}\), so \(\left(\frac{2}{13}\right) = -1\).

The quadratic residues mod 13 are: \(\{1, 3, 4, 9, 10, 12\}\). Note that 2 is not in this set. ✓

Exercises:
  1. Find all quadratic residues modulo 11.
  2. Compute \(\left(\frac{3}{11}\right)\) using Euler's Criterion.
  3. Compute \(\left(\frac{5}{13}\right)\) using Euler's Criterion.
  4. Verify that \(\left(\frac{-1}{p}\right) = 1\) when \(p \equiv 1 \pmod{4}\) for \(p = 5, 13, 17\).
  5. Show that \(\left(\frac{2}{p}\right) = 1\) iff \(p \equiv \pm 1 \pmod{8}\).
  6. Find all solutions to \(x^2 \equiv 17 \pmod{29}\).
  7. Prove: If \(p \equiv 1 \pmod{4}\), then \(\left(\frac{-1}{p}\right) = 1\).
  8. Compute \(\left(\frac{11}{43}\right)\) using Euler's Criterion.
