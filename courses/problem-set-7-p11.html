Problem Set 7: Rational Expressions

Precalculus 11 · 8 problems Medium

Problems

Problem 1

Simplify: \(\frac{x^2 - 9}{x^2 + 6x + 9}\)

Problem 2

Simplify: \(\frac{2x^2 + 8x}{x^2 - 4}\)

Problem 3

Multiply: \(\frac{x^2 - 4}{x + 2} \cdot \frac{x + 2}{x^2 + 4x + 4}\)

Problem 4

Divide: \(\frac{x^2 - x - 6}{\frac{x + 3}{x - 2}}\)

Problem 5

Find the sum: \(\frac{3}{x} + \frac{5}{2x}\)

Problem 6

Find the sum: \(\frac{2}{x+1} + \frac{3}{x-1}\)

Problem 7

Solve: \(\frac{2}{x-3} = \frac{5}{x+2}\)

Problem 8

Solve: \(\frac{3}{x+4} + \frac{2}{x-1} = 1\)

Bonus Problems

Bonus Problem 1 Hard

Simplify: \(\frac{x^2 + x - 2}{x^2 - 1} + \frac{x - 1}{x + 1}\). Hence, if \(x \neq \pm 1\), find the value of \(\frac{x^2 - 1}{x^2 + x - 2} + \frac{x + 1}{x - 1}\)

Bonus Problem 2 Hard

Solve: \(\frac{x}{x+2} + \frac{x+4}{x-1} = 2\). Then solve \(\frac{1}{y-1} + \frac{1}{y+1} = \frac{3}{2}\) using an appropriate substitution.
