Solutions: Problem Set 15: Pythagorean Triples and Congruent Numbers

Elementary Number Theory - Week 13 Solutions

Key Definitions and Concepts

Pythagorean Triple

A triple (a, b, c) of positive integers with a² + b² = c².

Primitive: gcd(a, b, c) = 1.

Parameterization: All primitive triples: a = m² - n², b = 2mn, c = m² + n² (m > n, coprime, opposite parity).

Solutions

Problem 2: Find a Pythagorean triple where one leg is 12.

Solution:

Case 1: b = 12 (even leg). Then 2mn = 12, so mn = 6.

(m, n) = (6, 1): a = 36-1 = 35, b = 12, c = 37. Triple: (35, 12, 37)

(m, n) = (3, 2): a = 9-4 = 5, b = 12, c = 13. Triple: (5, 12, 13)

Case 2: a = 12 (odd leg). Then m² - n² = 12 = (m-n)(m+n).

Factors of 12: (1,12), (2,6), (3,4)

m - n = 1, m + n = 12 → m = 6.5 (not integer)

m - n = 2, m + n = 6 → m = 4, n = 2. Then b = 16, c = 20. Triple: (12, 16, 20) = 4×(3,4,5)

Answer: Primitive: (5, 12, 13) and (35, 12, 37). Non-primitive: (12, 16, 20)

Problem 3: Prove the parameterization of primitive Pythagorean triples.

Proof:

Let (a, b, c) be primitive with a² + b² = c² and a odd, b even.

Step 1: Rewrite as b² = c² - a² = (c-a)(c+a).

Step 2: gcd(c-a, c+a) = gcd(c-a, 2c) = 2 (since gcd(a,c) = 1 and a is odd).

So c - a = 2s² and c + a = 2t² for coprime s, t of opposite parity.

Step 3: Solving,
a = t² - s², c = t² + s², and b = 2st.

Setting m = t, n = s gives the parameterization.

Problem 4: Show that 5 is a congruent number.

Understanding: A congruent number n is the area of a right triangle with rational sides.

Proof:

Find a rational right triangle with area 5.

Consider (3/2, 20/3, 41/6):
Area = (1/2)(3/2)(20/3) = 5 ✓
Check: (3/2)² + (20/3)² = 9/4 + 400/9 = (81 + 1600)/36 = 1681/36 = (41/6)² ✓

Answer: Triangle with sides (3/2, 20/3, 41/6) has area 5, so 5 is congruent.

Minimal solution: corresponds to elliptic curve y² = x³ - 25x with rational point.

Bonus Solutions

Bonus Problem 1: Find all Pythagorean triples with leg difference 1.

Condition: |a - b| = 1 where a² + b² = c².

Case b = a + 1:
a² + (a+1)² = c²
2a² + 2a + 1 = c²
(2a + 1)² - 2c² = -1 (Pell equation)
Solutions: a = 0, 3, 20, 119, ...
Triples: (0,1,1) degenerate, (3,4,5), (20,21,29), (119,120,169), ...

Answer: Infinitely many via Pell equation solutions.

Bonus Problem 2: Prove Fermat's theorem on sum of two squares (if p ≡ 1 mod 4, then p = x² + y²).

Proof using Gaussian integers (already shown in PS8-10):

If p ≡ 1 (mod 4), then p splits in \(\mathbb{Z}[i]\): p = ππ̄ for some Gaussian prime π = a + bi.

Thus p = N(π) = a² + b² with integers a, b.

Constructive proof: Find x with x² ≡ -1 (mod p), then use lattice point argument to find a solution to x² + y² = p.
