Linear Independence and Span

Linear Algebra - Lecture 2 • Based on Axler's "Linear Algebra Done Right" and MIT 18.700

1. Linear Independence

1.1 Definition

A list \(v_1, v_2, \ldots, v_n\) of vectors in a vector space V is linearly independent if for every scalars \(a_1, a_2, \ldots, a_n \in F\):

\(a_1 v_1 + a_2 v_2 + \cdots + a_n v_n = 0\) implies \(a_1 = a_2 = \cdots = a_n = 0\)

If this condition fails, the vectors are linearly dependent.

1.2 Examples

Example 1: Standard Basis in F^n

The vectors \(e_1 = (1, 0, \ldots, 0)\), \(e_2 = (0, 1, 0, \ldots, 0)\), \ldots, \(e_n = (0, \ldots, 0, 1)\) are linearly independent.

Example 2: Polynomial Basis

The polynomials \{1, x, x^2, \ldots, x^{n-1}\}\) are linearly independent in \(P_{n-1}(F)\).

2. Span

2.1 Definition

The span of vectors \(v_1, \ldots, v_n \in V\) is:

\(F(v_1, \ldots, v_n) = \{a_1 v_1 + \cdots + a_n v_n : a_i \in F\}\)

2.2 Key Properties

Theorem 1: \(F(v_1, \ldots, v_n)\) is a subspace of V.
Theorem 2 (Span as Subspace): The span of any finite set of vectors is always a subspace.

3. Linear Independence and Span

A list of vectors is linearly independent if and only if none of them is in the span of the others.

Key Insight:

Linear independence means no vector in the list can be written as a linear combination of the others. Span is the set of all possible linear combinations.

4. Practice Problems

Problem 1

Determine if the vectors \{(1, 2, 3), (4, 5, 6), (7, 8, 9)\}\) in \(F^3\) are linearly independent.

Problem 2

Show that any two vectors in \(F^2\) are linearly dependent if and only if one is a scalar multiple of the other.

Problem 3

Find the span of \{ (1, 2), (3, 4) \}\) in \(F^2\).
