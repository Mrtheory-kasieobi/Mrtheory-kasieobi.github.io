Lecture 11: Infinite Sets and Cardinality

Introduction to Proofs · Week 11

Lecture 11Infinite Sets and Cardinality

Learning objectives

By the end of this lecture you should be able to:

  • Define equinumerosity and compare the sizes of finite and infinite sets.
  • Prove that \(\mathbb{Z}\) and \(\mathbb{Q}\) are countable.
  • Prove Cantor's diagonal argument that \(\mathbb{R}\) is uncountable.
  • State and prove Cantor's theorem about power sets.
  • Use injections, surjections and the Schröder-Bernstein idea to compare cardinalities.
Beginner's bridge

For finite sets, size is a number. For infinite sets, size is compared by pairings. A bijection pairs every element of \(A\) with exactly one element of \(B\) and leaves none unpaired, so \(A\) and \(B\) have the same cardinality. An injection embeds \(A\) into \(B\); a surjection covers all of \(B\).

The even natural numbers are countably infinite despite being a proper subset of \(\mathbb{N}\), because \(n\mapsto2n\) is a bijection from \(\mathbb{N}\) to the even naturals. Infinite sets can have the same size as proper subsets.

1. Equinumerosity

Definition 11.1 Sets \(A\) and \(B\) have the same cardinality, written \(|A|=|B|\) or \(A\sim B\), if there is a bijection \(f:A\to B\). We write \(|A|\le|B|\) if there is an injection \(A\to B\), and \(|A|<|B|\) if \(|A|\le|B|\) but \(|A|\ne|B|\).

For finite sets this agrees with counting elements. For infinite sets it leads to surprising results: the even integers are equinumerous with all integers via \(n\mapsto2n\), even though they form a proper subset. Indeed, a set is often defined to be infinite if it is equinumerous with a proper subset of itself (Dedekind-infinite); for ordinary sets this agrees with "not finite".

Theorem 11.2 The relation \(\sim\) is an equivalence relation on any collection of sets.
Proof. Reflexivity: the identity map is a bijection. Symmetry: the inverse of a bijection is a bijection. Transitivity: if \(f:A\to B\) and \(g:B\to C\) are bijections, then \(g\circ f:A\to C\) is a bijection by Theorem 4.12. \(\square\)

2. Countable sets

Definition 11.3 A set is countably infinite if it is equinumerous with \(\mathbb{N}\), and countable if it is finite or countably infinite. An infinite set that is not countable is uncountable.
Theorem 11.4 \(\mathbb{Z}\) is countable.
Proof. Define \(f:\mathbb{N}\to\mathbb{Z}\) by \[f(1)=0,\quad f(2)=1,\quad f(3)=-1,\quad f(4)=2,\quad f(5)=-2,\ldots\] In general, \(f(2k)=-k\) and \(f(2k+1)=k\) for \(k\ge1\). Every integer is hit exactly once: \(0\) by \(1\), positive \(k\) by \(2k+1\), negative \(-k\) by \(2k\). Hence \(f\) is a bijection and \(|\mathbb{Z}|=|\mathbb{N}|\). \(\square\)
Theorem 11.5 \(\mathbb{N}\times\mathbb{N}\) is countable.
Proof. List pairs by increasing sum \(a+b\), and within each diagonal by increasing \(a\): \[(0,0),(0,1),(1,0),(0,2),(1,1),(2,0),(0,3),\ldots\] Every pair \((a,b)\) occurs at the finite stage determined by the sum \(a+b\), and occurs once. This enumeration gives a bijection \(\mathbb{N}\to\mathbb{N}\times\mathbb{N}\); equivalently, the map \((a,b)\mapsto2^a(2b+1)-1\) is an injection into \(\mathbb{N}\). \(\square\)

To prove \(\mathbb{Q}\) countable, map each rational \(q\) to a pair of integers \((a,b)\) with \(b>0\) and \(\gcd(a,b)=1\). This is an injection \(\mathbb{Q}\to\mathbb{Z}\times\mathbb{N}\). Since \(\mathbb{Z}\) and \(\mathbb{N}\) are countable, their product is countable (list pairs by the sum of their indices), so \(\mathbb{Q}\) is countable. More generally: a subset of a countable set is countable, and a countable union of countable sets is countable.

3. Uncountability of the reals

Theorem 11.6 (Cantor's diagonal argument) The interval \((0,1)\) is uncountable.
Proof. Suppose \((0,1)\) were countable, listed as \(x_1,x_2,x_3,\ldots\). Write each in decimal form \(x_i=0.d_{i1}d_{i2}d_{i3}\ldots\), choosing the expansion without trailing nines to ensure uniqueness. Construct \(y=0.e_1e_2e_3\ldots\) by \[e_i=\begin{cases}1,&d_{ii}\ne1,\\2,&d_{ii}=1.\end{cases}\] Then \(y\in(0,1)\), and \(y\) differs from \(x_i\) in the \(i\)-th decimal place for every \(i\). Hence \(y\) is not on the supposed complete list, a contradiction. Therefore \((0,1)\) is uncountable.
Why avoid trailing nines? The decimal \(0.1999\ldots\) equals \(0.2000\ldots\), so a number can have two expansions. Choosing the expansion with no trailing nines makes the diagonal construction unambiguous; using only digits \(1\) and \(2\) also avoids creating a terminating or eventually-nine expansion for \(y\).

Since \((0,1)\subseteq\mathbb{R}\), the real numbers are uncountable. Cantor's diagonal method is a proof by contradiction combined with an explicit construction of a missing object.

4. Cantor's theorem

Theorem 11.7 (Cantor) For every set \(A\), \(|A|<|\mathcal{P}(A)|\).
Proof. The map \(a\mapsto\{a\}\) is an injection \(A\to\mathcal{P}(A)\), so \(|A|\le|\mathcal{P}(A)|\). Suppose there were a bijection \(f:A\to\mathcal{P}(A)\), and define the diagonal set \[D=\{a\in A:a\notin f(a)\}.\] Since \(f\) is surjective, \(D=f(a_0)\) for some \(a_0\in A\). If \(a_0\in D\), then by definition \(a_0\notin f(a_0)=D\), a contradiction. If \(a_0\notin D\), then \(a_0\notin f(a_0)\), so \(a_0\in D\), again a contradiction. Hence no such bijection exists, so \(|A|\ne|\mathcal{P}(A)|\) and therefore \(|A|<|\mathcal{P}(A)|\). \(\square\)

For finite sets this says \(n<2^n\). For \(A=\mathbb{N}\) it says there are strictly more sets of natural numbers than natural numbers. Repeatedly taking power sets produces an unbounded hierarchy of infinite cardinalities.

5. Comparing cardinalities

Theorem 11.8 (Schröder-Bernstein) If there exist injections \(f:A\to B\) and \(g:B\to A\), then \(|A|=|B|\).

We state this fundamental theorem without proof; its proof constructs a bijection by partitioning the sets according to the ancestry of their elements under \(f\) and \(g\). It is the set-theoretic analogue of the familiar fact that \(a\le b\) and \(b\le a\) imply \(a=b\), but for cardinalities the conclusion requires a genuine construction of a bijection.

Example 11.9 \(|(0,1)|=|\mathbb{R}|\). Injections in both directions are easy: \((0,1)\to\mathbb{R}\) is the inclusion, and \(\mathbb{R}\to(0,1)\) can be given by \(x\mapsto\frac12+\frac1\pi\arctan x\), whose values lie in \((0,1)\) and which is injective. Schröder-Bernstein gives a bijection. An explicit bijection also exists, e.g. a suitable rescaling of \(\tan\) on \((0,1)\).

When building an injection or bijection, verify both properties explicitly: injectivity by starting from equal outputs, surjectivity by constructing a preimage. The same techniques from Lecture 4 apply even when the sets are infinite.

6. Extra detail: the diagonal construction

Theorem 11.10 (Cantor) There is no surjection from a set \(A\) onto \(\mathcal{P}(A)\).
Proof. Let \(f:A\to\mathcal{P}(A)\) be any function and define \(D=\{a\in A:a\notin f(a)\}\). If \(D=f(a_0)\), then \(a_0\in D\) implies \(a_0\notin f(a_0)=D\), while \(a_0\notin D\) implies \(a_0\in f(a_0)=D\). Both are contradictions, so \(D\) is not in the image of \(f\). \(\square\)

The same idea proves that \((0,1)\) is uncountable: after listing decimals \(x_i\), construct a new decimal whose \(i\)-th digit differs from the \(i\)-th digit of \(x_i\). Use digits \(1\) and \(2\) and avoid trailing nines so the new decimal is unambiguous.

Exercises
  1. Give an explicit bijection \(\mathbb{N} o 2\mathbb{N}\) (the positive even integers).
  2. Prove that a subset of a countable set is countable.
  3. Show that \(\mathbb{Q} imes\mathbb{Q}\) is countable.
  4. Explain why the decimal expansion convention in Theorem 11.6 is necessary.
  5. Prove that the set of finite binary strings is countable.
  6. Use Cantor's theorem to show there is no set of all sets.
  7. Give injections both ways between \((0,1)\) and \((0,2)\) and conclude they have equal cardinality.
  8. Prove that the set of algebraic real numbers is countable. (A real is algebraic if it solves a nonzero polynomial with integer coefficients.)
