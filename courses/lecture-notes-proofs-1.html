Lecture 1: Propositional Logic and Truth Tables

Introduction to Proofs · Week 1

Lecture 1Propositional Logic and Truth Tables

Learning objectives

By the end of this lecture you should be able to:

  • Recognise which sentences are propositions and assign them truth values.
  • Translate ordinary mathematical sentences into formulas using logical connectives.
  • Construct and read truth tables, and distinguish tautologies from contradictions.
  • Use logical equivalences, including De Morgan laws and the contrapositive identity.
  • Identify valid argument forms and common fallacies.
Beginner's bridge

Logic is the grammar of mathematics. A proposition is like a switch with exactly one of two positions: true or false. The connectives combine switches: \(\land\) asks for both, \(\lor\) asks for at least one, \(\neg\) flips, and \(p\to q\) is false only in the single case \(p=T, q=F\). Read \(p\to q\) as a promise: if the hypothesis \(p\) is delivered, the conclusion \(q\) must also be delivered. If \(p\) never happens, the promise has not been broken.

Example: let \(p\) be “\(n\) is divisible by \(4\)” and \(q\) be “\(n\) is even”. Then \(p\to q\) is true for every integer \(n\). The reverse \(q\to p\) is false, since \(n=6\) is even but not divisible by \(4\).

1. Propositions and truth values

Definition 1.1 (Proposition) A proposition is a declarative statement that is either true or false, but not both. Its truth value is denoted \(T\) (true) or \(F\) (false).

Questions ("Is 17 prime?"), commands ("Prove the theorem"), opinions ("Analysis is interesting"), and sentences with unresolved variables ("\(x\) is even") are not propositions. The last one becomes a proposition once \(x\) is specified or quantified: "for every integer \(x\), \(x\) is even" is a false proposition.

Example 1.1
  • "\(7\) is prime" is a proposition with truth value \(T\).
  • "\(2+2=5\)" is a proposition with truth value \(F\).
  • "This sentence has three words" is a proposition with truth value \(F\).
  • "\(n+1\) is prime" is not a proposition until \(n\) is fixed or quantified.

We use lowercase letters \(p,q,r,\ldots\), called propositional variables, to stand for propositions. A compound proposition is built from simpler propositions using connectives.

2. The five basic connectives

Definition 1.2 (Connectives) Let \(p\) and \(q\) be propositions.
  • Negation: \(\neg p\), "not \(p\)", true exactly when \(p\) is false.
  • Conjunction: \(p\land q\), "\(p\) and \(q\)", true exactly when both are true.
  • Disjunction: \(p\lor q\), "\(p\) or \(q\)", the inclusive or: true when at least one of \(p,q\) is true.
  • Conditional: \(p\to q\), "if \(p\), then \(q\)"; \(p\) is the antecedent and \(q\) the consequent.
  • Biconditional: \(p\leftrightarrow q\), "\(p\) if and only if \(q\)".

The conditional is the subtle one. It is false only in the single row \(p=T, q=F\); in particular, when \(p\) is false the statement \(p\to q\) is true regardless of \(q\). This is called vacuous truth. For example, "if \(n\) is a prime divisible by \(4\), then \(n=2\)" is true because no prime is divisible by \(4\). Vacuous truth is not a quirk: it makes universal statements such as "every element of the empty set is positive" true, which is exactly what we need for set theory.

Theorem 1.3 (Equivalent forms of the conditional) The formula \(p\to q\) is logically equivalent to \(\neg p\lor q\), and to its contrapositive \(\neg q\to\neg p\). It is not equivalent to its converse \(q\to p\) or its inverse \(\neg p\to\neg q\).
Proof. Compare truth values. The formula \(\neg p\lor q\) is false only when \(\neg p=F\) and \(q=F\), i.e. when \(p=T\) and \(q=F\): the same unique false row as \(p\to q\). For the contrapositive, \(\neg q\to\neg p\) is false only when \(\neg q=T\) and \(\neg p=F\), again the row \(p=T,q=F\). For the converse, take \(p=F,q=T\): then \(p\to q\) is true but \(q\to p\) is false. The inverse fails on the same row. \(\square\)

"Only if" reverses the arrow: "\(p\) only if \(q\)" means \(p\to q\). "\(p\) if \(q\)" means \(q\to p\). Thus "\(n\) is divisible by \(6\) only if \(n\) is even" says \(\text{divisible by }6\to\text{even}\); the converse is false. "\(p\) is sufficient for \(q\)" means \(p\to q\), while "\(p\) is necessary for \(q\)" means \(q\to p\).

3. Truth tables and logical equivalence

A truth table lists the truth value of a formula for every assignment of truth values to its variables. With \(n\) variables there are \(2^n\) rows. The basic tables are:

\[\begin{array}{c|c|c} p & \neg p & p\land p \\ \hline T & F & T \\ F & T & F \end{array}\qquad \begin{array}{c|c|c|c|c|c} p&q&p\land q&p\lor q&p\to q&p\leftrightarrow q\\ \hline T&T&T&T&T&T\\ T&F&F&T&F&F\\ F&T&F&T&T&F\\ F&F&F&F&T&T \end{array}\]
Definition 1.4 A formula is a tautology if it is true in every row, a contradiction if false in every row, and contingent otherwise. Two formulas \(A\) and \(B\) are logically equivalent, written \(A\equiv B\), if \(A\leftrightarrow B\) is a tautology; equivalently, their truth-table columns agree.
Theorem 1.5 (Core logical equivalences) For all propositions \(p,q,r\):
  1. Double negation: \(\neg(\neg p)\equiv p\).
  2. De Morgan: \(\neg(p\land q)\equiv\neg p\lor\neg q\) and \(\neg(p\lor q)\equiv\neg p\land\neg q\).
  3. Commutativity, associativity and distributivity of \(\land\) and \(\lor\).
  4. Idempotence: \(p\land p\equiv p\), \(p\lor p\equiv p\).
  5. Absorption: \(p\land(p\lor q)\equiv p\), \(p\lor(p\land q)\equiv p\).
  6. Implication: \(p\to q\equiv\neg p\lor q\equiv\neg q\to\neg p\).
  7. Negated conditional: \(\neg(p\to q)\equiv p\land\neg q\).
Proof of the first De Morgan law. The formula \(\neg(p\land q)\) is false exactly when \(p\land q\) is true, i.e. on the row \(p=T,q=T\). The formula \(\neg p\lor\neg q\) is false exactly when both \(\neg p\) and \(\neg q\) are false, i.e. on the same row \(p=T,q=T\). Since the two columns agree in all four rows, the formulas are equivalent. The second law and the negated conditional are checked the same way. \(\square\)
Example 1.6 Simplify \(\neg\big((p\to q)\land\neg r\big)\).
Step 1. De Morgan: \(\neg(p\to q)\lor\neg(\neg r)\).
Step 2. Negated conditional and double negation: \((p\land\neg q)\lor r\).

This final form is convenient because it shows the formula is true whenever \(r\) is true.

4. Valid arguments

Definition 1.7 An argument is a sequence of premises \(p_1,\ldots,p_k\) and a conclusion \(q\). The argument is valid if \(q\) is true whenever all premises are true; equivalently, \((p_1\land\cdots\land p_k)\to q\) is a tautology. Validity concerns form, not the actual truth of the premises; an argument with true premises and valid form is sound.
Theorem 1.8 (Standard valid forms)
  • Modus ponens: from \(p\to q\) and \(p\), infer \(q\).
  • Modus tollens: from \(p\to q\) and \(\neg q\), infer \(\neg p\).
  • Hypothetical syllogism: from \(p\to q\) and \(q\to r\), infer \(p\to r\).
  • Disjunctive syllogism: from \(p\lor q\) and \(\neg p\), infer \(q\).
  • Proof by cases: from \(p\lor q\), \(p\to r\), and \(q\to r\), infer \(r\).

Two famous invalid forms are affirming the consequent (from \(p\to q\) and \(q\), infer \(p\)) and denying the antecedent (from \(p\to q\) and \(\neg p\), infer \(\neg q\)). To disprove validity, give a single counterexample assignment: for affirming the consequent take \(p=F,q=T\); both premises hold but the conclusion fails.

Example 1.9 If a number is divisible by \(4\), it is even. The number \(6\) is even. Conclude that \(6\) is divisible by \(4\). This is affirming the consequent: the premise "even" is true, but the conclusion is false, so the argument is invalid even though all the individual statements are true.

5. Proof writing begins with logic

Every direct proof of an implication \(p\to q\) has the shape: assume \(p\), derive \(q\). A proof of a biconditional \(p\leftrightarrow q\) has two parts: prove \(p\to q\) and prove \(q\to p\), sometimes written "\(\Rightarrow\)" and "\(\Leftarrow\)". A proof by contradiction of \(q\) assumes \(\neg q\) and derives a contradiction such as \(r\land\neg r\); by Theorem 1.5 this establishes \(q\) because \(\neg(\neg q)\equiv q\).

Writing principle A proof is a chain of implications, not a chain of equivalences unless every step really is reversible. When you write \(A=B\), check that equality (or logical equivalence) holds; when you write \(A\implies B\), only one direction is claimed.

Finally, be careful with the word "or" in mathematics: it is inclusive unless explicitly stated otherwise. "\(n\) is divisible by \(2\) or by \(3\)" includes numbers divisible by \(6\). When the exclusive or is intended, say "exactly one of".

6. Extra detail: equivalence versus implication

Theorem 1.10 \(p\to q\equiv\neg p\lor q\), and \(p\to q\not\equiv q\to p\).
Proof. Compare truth values. The formula \(p\to q\) is false only when \(p\) is true and \(q\) is false. The formula \(\neg p\lor q\) is also false only in that row. Hence they agree in every row. The converse \(q\to p\) differs from \(p\to q\) whenever \(p\) and \(q\) have different truth values, so the two are not equivalent. \(\square\)

This distinction explains why a proof of \(q\to p\) does not prove \(p\to q\). It also explains vacuous truth: a universal statement \(\forall x\in\varnothing\,P(x)\) is true because there is no element that could violate \(P\).

Proof-writing habit. Before writing a proof, write the logical skeleton. For an implication, begin “Assume \(p\).” For a biconditional, write two separated proofs for \(\Rightarrow\) and \(\Leftarrow\). For a universal statement, begin “Let \(x\) be arbitrary.”
Exercises
  1. Classify each sentence as a proposition or not: (a) \(3^2=9\); (b) "close the door"; (c) \(x^2\ge 0\); (d) "for all real \(x\), \(x^2\ge 0\)".
  2. Construct truth tables for \( eg(p\lor q)\) and \( eg p\land eg q\), and confirm they agree.
  3. Show that \((p o q)\land(p o eg q)\equiv eg p\).
  4. Show that \(p o(q o p)\) is a tautology.
  5. Write the converse, inverse and contrapositive of "if \(n^2\) is even, then \(n\) is even". Which are logically equivalent to the original?
  6. Determine whether the argument is valid: "If \(f\) is differentiable then \(f\) is continuous. This function is not differentiable. Therefore it is not continuous."
  7. Express "\(p\) is necessary and sufficient for \(q\)" using a biconditional and explain which direction is the sufficiency claim.
  8. Prove that \(p\lor(q\land r)\equiv(p\lor q)\land(p\lor r)\) using a truth table.
