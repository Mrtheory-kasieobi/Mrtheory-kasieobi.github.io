Solutions: Problem Set 3: Congruences and Modular Arithmetic

Elementary Number Theory - Week 3 Solutions

Key Definitions and Concepts

Modular Congruence

For integers \(a, b, m\) with \(m > 0\), we say \(a \equiv b \pmod{m}\) (read "a is congruent to b modulo m") if \(m \mid (a - b)\).

Example: \(17 \equiv 5 \pmod{12}\) because \(17 - 5 = 12\) and \(12 \mid 12\).

Properties of Congruence

1. Reflexive: \(a \equiv a \pmod{m}\)

2. Symmetric: If \(a \equiv b \pmod{m}\), then \(b \equiv a \pmod{m}\)

3. Transitive: If \(a \equiv b \pmod{m}\) and \(b \equiv c \pmod{m}\), then \(a \equiv c \pmod{m}\)

4. If \(a \equiv b \pmod{m}\) and \(c \equiv d \pmod{m}\), then:

  • \(a + c \equiv b + d \pmod{m}\)
  • \(ac \equiv bd \pmod{m}\)

Solutions

Problem 1: Prove that if \(a \equiv b \pmod{m}\) and \(c \equiv d \pmod{m}\), then \(a + c \equiv b + d \pmod{m}\).

Understanding: Congruence preserves addition. This allows us to add congruences term by term.

Proof:

Step 1: Write out what the given congruences mean.

Since \(a \equiv b \pmod{m}\), we have \(m \mid (a - b)\), so \(a - b = mk\) for some integer \(k\).

Since \(c \equiv d \pmod{m}\), we have \(m \mid (c - d)\), so \(c - d = m\ell\) for some integer \(\ell\).

Step 2: Consider the difference of the sums.

\[(a + c) - (b + d) = (a - b) + (c - d) = mk + m\ell = m(k + \ell)\]

Step 3: Conclude.

Since \(m \mid (a + c) - (b + d)\), we have \(a + c \equiv b + d \pmod{m}\).

Problem 2: Solve the congruence: \(3x \equiv 7 \pmod{11}\).

Understanding: We need to find all integers \(x\) such that \(3x\) leaves remainder 7 when divided by 11.

Step 1: Check if a solution exists.

A linear congruence \(ax \equiv b \pmod{m}\) has a solution if and only if \(\gcd(a, m) \mid b\).

\(\gcd(3, 11) = 1\) and \(1 \mid 7\), so a unique solution exists modulo 11.

Step 2: Find the multiplicative inverse of 3 modulo 11.

Using Extended Euclidean Algorithm:
\[11 = 3 \times 3 + 2\]
\[3 = 2 \times 1 + 1\]
\[2 = 1 \times 2 + 0\]
Back-substitute: \(1 = 3 - 2 = 3 - (11 - 3 \times 3) = 3 \times 4 - 11\)
So \(3 \times 4 \equiv 1 \pmod{11}\), meaning \(3^{-1} \equiv 4 \pmod{11}\).

Step 3: Multiply both sides by the inverse.

\[x \equiv 4 \times 7 \equiv 28 \equiv 6 \pmod{11}\]

Answer: \(x \equiv 6 \pmod{11}\), meaning all solutions are \(x = 6 + 11k\) for integers \(k\).

Problem 3: Find all solutions to \(x^2 \equiv 1 \pmod{8}\).

Strategy: Check each residue class modulo 8, since there are only 8 possibilities.

Check each value:
\(x \mod 8\)\(x^2 \mod 8\)
00
11
24
39 ≡ 1
416 ≡ 0
525 ≡ 1
636 ≡ 4
749 ≡ 1

Answer: The solutions are \(x \equiv 1, 3, 5, 7 \pmod{8}\), i.e., all odd numbers not divisible by 2.

Problem 4: Prove that if \(a \equiv b \pmod{m}\), then \(a^n \equiv b^n \pmod{m}\) for any positive integer \(n\).

Understanding: Congruence is preserved under exponentiation - a fundamental property.

Proof by Induction:

Base case (\(n = 1\)): Trivially true: \(a^1 \equiv b^1 \pmod{m}\).
Inductive step: Assume \(a^n \equiv b^n \pmod{m}\). We show \(a^{n+1} \equiv b^{n+1} \pmod{m}\).

\[a^{n+1} = a^n \cdot a \equiv b^n \cdot b = b^{n+1} \pmod{m}\]

This uses the fact that if \(x \equiv x'\) and \(y \equiv y'\), then \(xy \equiv x'y'\) (multiplication property of congruences).

Conclusion: By mathematical induction, \(a^n \equiv b^n \pmod{m}\) for all \(n \geq 1\).

Problem 5: Solve the system of congruences:
\(x \equiv 2 \pmod{3}\)
\(x \equiv 3 \pmod{5}\)

Understanding: This is a system of simultaneous congruences. We solve it step by step.

Step 1: Express x from the first congruence.

From \(x \equiv 2 \pmod{3}\): \(x = 3k + 2\) for some integer \(k\).

Step 2: Substitute into the second congruence.

\[3k + 2 \equiv 3 \pmod{5}\]

\[3k \equiv 1 \pmod{5}\]

Step 3: Solve for k.

Multiply by \(3^{-1} \pmod{5}\) (which is 2, since \(3 \times 2 = 6 \equiv 1\)):
\[k \equiv 2 \pmod{5}\]

So \(k = 5j + 2\) for some integer \(j\).

Step 4: Find x.

\[x = 3(5j + 2) + 2 = 15j + 8\]

So \(x \equiv 8 \pmod{15}\).

Answer: \(x \equiv 8 \pmod{15}\), or \(x = 8 + 15j\) for integers \(j\).

Problem 6: Prove Fermat's Little Theorem: If \(p\) is prime and \(p \nmid a\), then \(a^{p-1} \equiv 1 \pmod{p}\).

Understanding: This fundamental theorem relates exponentiation to modular arithmetic for primes.

Proof Sketch:

Step 1: Consider the multiples of a.

Let \(S = \{a, 2a, 3a, \ldots, (p-1)a\}\) (all taken mod \(p\)).

We claim all elements of \(S\) are distinct and non-zero mod \(p\).

Step 2: Show distinctness.

If \(ia \equiv ja \pmod{p}\) for \(1 \leq i < j \leq p-1\), then \(p \mid (j-i)a\). Since \(p \nmid a\), we must have \(p \mid (j-i)\), meaning \(p \mid |j-i|\). But \(|j-i| < p\), contradiction. So all elements are distinct.

Step 3: Conclude.

The set \(S\) is actually a permutation of \(\{1, 2, \ldots, p-1\}\) modulo \(p\).

Therefore: \(a \times 2a \times 3a \times \cdots \times (p-1)a \equiv 1 \times 2 \times \cdots \times (p-1) \pmod{p}\)

\[(p-1)! \times a^{p-1} \equiv (p-1)! \pmod{p}\]

Since \((p-1)! \not\equiv 0 \pmod{p}\), we can cancel to get \(a^{p-1} \equiv 1 \pmod{p}\).

Problem 7: Compute \(7^{100} \pmod{13}\).

Strategy: Use Fermat's Little Theorem to reduce the exponent.

Step 1: Apply Fermat's Little Theorem.

Since 13 is prime and \(\gcd(7, 13) = 1\):
\[7^{12} \equiv 1 \pmod{13}\]

Step 2: Reduce the exponent.

\[7^{100} = 7^{12 \times 8 + 4} = (7^{12})^8 \times 7^4 \equiv 1^8 \times 7^4 \pmod{13}\]
\[7^4 = 2401\]

Step 3: Compute \(7^4 \mod 13\).

\[7^2 = 49 \equiv 10 \pmod{13}\]
\[7^4 = (7^2)^2 \equiv 10^2 = 100 \equiv 9 \pmod{13}\]

Answer: \(7^{100} \equiv 9 \pmod{13}\)

Problem 8: Find the remainder when \(2^{2023}\) is divided by 17.

Strategy: Use Fermat's Little Theorem since 17 is prime.

Step 1: Apply Fermat's Little Theorem.

\[2^{16} \equiv 1 \pmod{17}\]

Because \(\gcd(2, 17) = 1\) and 17 is prime.

Step 2: Reduce the exponent modulo 16.

\[2023 = 16 \times 126 + 7\]
\[2^{2023} = 2^{16 \times 126 + 7} = (2^{16})^{126} \times 2^7 \equiv 1^{126} \times 2^7 \pmod{17}\]

Step 3: Compute \(2^7\).

\[2^7 = 128\]
\[128 = 17 \times 7 + 9\]
\[128 \equiv 9 \pmod{17}\]

Answer: The remainder is 9.

Bonus Solutions

Bonus Problem 1: Prove that if \(a \equiv b \pmod{m}\) and \(n \in \mathbb{Z}\), then \(a^n \equiv b^n \pmod{m}\).

This is a generalization of Problem 4, allowing negative exponents when the base is invertible.

Proof outline:

  • For positive exponents: use induction (same as Problem 4)
  • For \(n = 0\): \(a^0 = b^0 = 1\) when defined
  • For negative exponents: if \(a\) is invertible mod \(m\), use \((a^{-1})^n = (a^n)^{-1}\)
Bonus Problem 2: Solve: Find the last two digits of \(7^{2023}\).

Understanding: The last two digits of a number are its remainder modulo 100.

Solution:

Step 1: Use Chinese Remainder Theorem with 100 = 4 × 25.

We find \(7^{2023} \pmod{4}\) and \(7^{2023} \pmod{25}\), then combine.

Step 2: Compute modulo 4.

\[7 \equiv 3 \pmod{4}\]

\[7^2 = 49 \equiv 1 \pmod{4}\]

\[7^{2023} = (7^2)^{1011} \times 7 \equiv 1^{1011} \times 3 \equiv 3 \pmod{4}\]

Step 3: Compute modulo 25.

By Euler's theorem (or Fermat's Little Theorem for prime 5): \(\phi(25) = 20\), so \(7^{20} \equiv 1 \pmod{25}\).
\[2023 = 20 \times 101 + 3\]
\[7^{2023} = (7^{20})^{101} \times 7^3 \equiv 1 \times 343 \equiv 343 \pmod{25}\]
\[343 = 25 \times 13 + 18 \equiv 18 \pmod{25}\]

Step 4: Combine using CRT.

Find \(x\) such that \(x \equiv 3 \pmod{4}\) and \(x \equiv 18 \pmod{25}\).

From the second: \(x = 25k + 18\).

Substitute: \(25k + 18 \equiv 3 \pmod{4}\)
\[k + 2 \equiv 3 \pmod{4}\]
\[k \equiv 1 \pmod{4}\]
So \(k = 4j + 1\) and \(x = 25(4j + 1) + 18 = 100j + 43\).

Answer: The last two digits are 43.
