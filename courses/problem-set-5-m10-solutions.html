Problem Set 5: Relations and Functions

Mathematics 10 - Chapter 5 Solutions

Solutions

Problem 1: Determine if the relation \(\{(1,2), (2,3), (3,4), (4,5)\}\) is a function.
A relation is a function if each input (first element) maps to exactly one output (second element)
Check inputs: 1, 2, 3, 4 - all distinct
Each input has exactly one output
Answer: Yes, it is a function.
Problem 2: Find the domain and range of \(f(x) = \sqrt{x-3}\)
Domain: The expression under the square root must be non-negative: \(x - 3 \geq 0\)
So: \(x \geq 3\), meaning domain is \([3, \infty)\)
Range: The square root function outputs non-negative values
Minimum value is \(\sqrt{3-3} = 0\), and it can grow arbitrarily large
Answer: Domain: \([3, \infty)\), Range: \([0, \infty)\)
Problem 3: If \(g(x) = 2x^2 - 5x + 1\), find \(g(-1)\) and \(g(0)\)
For \(g(-1)\): \(g(-1) = 2(-1)^2 - 5(-1) + 1 = 2(1) + 5 + 1 = 8\)
For \(g(0)\): \(g(0) = 2(0)^2 - 5(0) + 1 = 0 - 0 + 1 = 1\)
Answer: \(g(-1) = 8\), \(g(0) = 1\)
Problem 4: Find the distance between \((2, 3)\) and \((7, 11)\)
Use distance formula: \(d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}\)
Substitute: \(d = \sqrt{(7-2)^2 + (11-3)^2}\)
Calculate: \(d = \sqrt{5^2 + 8^2} = \sqrt{25 + 64} = \sqrt{89}\)
Answer: \(\sqrt{89}\)
Problem 5: Find the domain of \(f(x) = \frac{1}{x+2} + \sqrt{2x-4}\)
First condition (denominator): \(x + 2 \neq 0\), so \(x \neq -2\)
Second condition (square root): \(2x - 4 \geq 0\), so \(x \geq 2\)
Both conditions must be satisfied: \(x \geq 2\) (which automatically satisfies \(x \neq -2\))
Answer: Domain: \([2, \infty)\)
Problem 6: Given table \(x: -2, 0, 1, 3, 5\) and \(y: 5, 2, 1, 3, 7\)
Is it a function? Each x-value maps to exactly one y-value: Yes
Domain: set of all x-values = \(\{-2, 0, 1, 3, 5\}\)
Range: set of all y-values = \(\{5, 2, 1, 3, 7\} = \{1, 2, 3, 5, 7\}\)
Answer: Yes, it is a function. Domain: \(\{-2, 0, 1, 3, 5\}\), Range: \(\{1, 2, 3, 5, 7\}\)
Problem 7: Find the midpoint of the line segment joining \((4, -2)\) and \((-6, 8)\)
Use midpoint formula: \(\left(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}\right)\)
Substitute: \(\left(\frac{4+(-6)}{2}, \frac{-2+8}{2}\right)\)
Calculate: \(\left(\frac{-2}{2}, \frac{6}{2}\right) = (-1, 3)\)
Answer: \((-1, 3)\)
Problem 8: Determine if \(f(x) = x^2 + 3x - 2\) is even, odd, or neither
Test for even: \(f(-x) = f(x)\)?
\(f(-x) = (-x)^2 + 3(-x) - 2 = x^2 - 3x - 2\)
Compare to \(f(x) = x^2 + 3x - 2\): Not equal (different middle term)
Test for odd: \(f(-x) = -f(x)\)?
\(-f(x) = -(x^2 + 3x - 2) = -x^2 - 3x + 2\)
Compare to \(f(-x) = x^2 - 3x - 2\): Not equal
Answer: Neither even nor odd

Bonus Solutions

Bonus Problem 1: Domain Detective
For \(f(x) = \sqrt{9 - x^2}\), need \(9 - x^2 \geq 0\)
So: \(x^2 \leq 9\), meaning \(-3 \leq x \leq 3\)
Maximum output: when \(x^2 = 0\), \(f(0) = \sqrt{9} = 3\)
The equation \(x^2 + y^2 = 9\) is a circle centered at origin with radius 3
Answer: Maximum output is 3. The graph is a circle of radius 3.
Bonus Problem 2: Composite Function Puzzle
Find x where \(f(g(x)) = g(f(x))\)
\(f(g(x)) = f(x+3) = (x+3)^2 = x^2 + 6x + 9\)
\(g(f(x)) = g(x^2) = x^2 + 3\)
Set equal: \(x^2 + 6x + 9 = x^2 + 3\)
Cancel \(x^2\): \(6x + 9 = 3\)
\(6x = -6\), so \(x = -1\)
Now find \(f(g(h(x)))\):
\(h(x) = 2x - 1\)
\(g(h(x)) = g(2x - 1) = (2x - 1) + 3 = 2x + 2\)
\(f(g(h(x))) = f(2x + 2) = (2x + 2)^2 = 4x^2 + 8x + 4\)
Answer: \(x = -1\). \(f(g(h(x))) = 4x^2 + 8x + 4\).
Bonus Problem 3: Distance Mystery
Point equidistant from (2, 3) and (6, -1)
This is the perpendicular bisector of the segment joining the two points
Midpoint: \(\left(\frac{2+6}{2}, \frac{3+(-1)}{2}\right) = (4, 1)\)
Slope of segment: \(\frac{-1-3}{6-2} = \frac{-4}{4} = -1\)
Perpendicular slope: 1 (negative reciprocal)
Line equation: \(y - 1 = 1(x - 4)\)
Simplify: \(y = x - 3\)
Answer: \(y = x - 3\). This is the perpendicular bisector of the segment.
