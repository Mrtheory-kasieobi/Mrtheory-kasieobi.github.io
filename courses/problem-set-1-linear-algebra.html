Problem Set 1: Vector Spaces and Subspaces

Linear Algebra Course
Based on Axler's "Linear Algebra Done Right"

Instructions

Solve all problems. Show your work clearly. You may use results from previous lectures.

Problem 1.1

Show that the set of all solutions to a homogeneous system of linear equations forms a subspace of \(\mathbb{R}^n\).

Problem 1.2

Determine whether the following sets are subspaces of \(\mathbb{R}^3\):

  • \(S_1 = \{(x, y, z) : x + y + z = 0\}\)
  • \(S_2 = \{(x, y, z) : x \geq 0\}\)
  • \(S_3 = \{(x, y, z) : x^2 + y^2 + z^2 = 1\}\)
Problem 1.3

Show that the set of all polynomials \(p \in \mathcal{P}(\mathbb{R})\) such that \(p(0) = 0\) is a subspace.

Problem 1.4

Let \(V = \mathbb{R}^3\). Find a basis for the subspace \(W = \{(x, y, z) : 2x - y + 3z = 0\}\) and determine its dimension.

Problem 1.5

Prove that the intersection of two subspaces is also a subspace.
