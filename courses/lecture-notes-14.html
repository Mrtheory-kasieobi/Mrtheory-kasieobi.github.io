Lecture 14: Pythagorean Triples and Related Equations

Lecture 14Pythagorean Triples and Related Equations

1. Review of Pythagorean Triples

Definition 14.1 (Pythagorean Triple) A Pythagorean triple is a triple \((a, b, c)\) of positive integers satisfying: \[a^2 + b^2 = c^2\]
Theorem 14.1 (Parametrization) Every primitive Pythagorean triple with \(a < b\) is given by: \[a = m^2 - n^2, \quad b = 2mn, \quad c = m^2 + n^2\] where \(m > n > 0\), \(\gcd(m, n) = 1\), and exactly one of \(m, n\) is even.
Example 14.1 Find all primitive Pythagorean triples with \(c \leq 20\).
Step 1: List possible (m, n) pairs

We need \(m^2 + n^2 \leq 20\), so \(m^2 \leq 19\), giving \(m \leq 4\).

Possible pairs \((m, n)\) with \(m > n\), \(\gcd(m, n) = 1\), one even:

  • \((2, 1)\): \(a = 3, b = 4, c = 5\)
  • \((3, 2)\): \(a = 5, b = 12, c = 13\)
  • \((4, 1)\): \(a = 15, b = 8, c = 17\)
  • \((4, 3)\): \(a = 7, b = 24, c = 25\) (exceeds 20)
Step 2: List the triples

Primitive triples with \(c \leq 20\):

  • \((3, 4, 5)\)
  • \((5, 12, 13)\)
  • \((8, 15, 17)\)

2. Fermat's Right Triangle Theorem

Theorem 14.2 (Fermat's Right Triangle Theorem) A right triangle with integer sides cannot have an integer area.
Step 1: Set up the problem

Suppose \((a, b, c)\) is a Pythagorean triple. The area is \(A = \frac{ab}{2}\).

We want to show \(A\) cannot be an integer.

Step 2: Use the parametrization

For a primitive triple: \[a = m^2 - n^2, \quad b = 2mn, \quad c = m^2 + n^2\]

Area: \(A = \frac{ab}{2} = \frac{(m^2 - n^2)(2mn)}{2} = mn(m^2 - n^2)\)

Step 3: Show A cannot be a square

Suppose \(A = k^2\) for some integer \(k\).

Then \(mn(m^2 - n^2) = k^2\).

Since \(\gcd(m, n) = 1\) and exactly one of \(m, n\) is even, we have \(\gcd(mn, m^2 - n^2) = 1\).

Thus each factor must be a perfect square: \(m = a^2\), \(n = b^2\), \(m^2 - n^2 = c^2\).

So \(a^4 - b^4 = c^2\), contradicting Fermat's Last Theorem for n = 4. \(\square\)

3. Congruent Numbers

Definition 14.2 (Congruent Number) A positive integer \(n\) is called a congruent number if there exists a right triangle with rational side lengths and area \(n\).
Theorem 14.3 A positive integer \(n\) is congruent if and only if the elliptic curve \(y^2 = x^3 - n^2x\) has a non-trivial rational point.
Example 14.2 Show that 5 is a congruent number.

Step 1: Find a rational right triangle with area 5

Consider the triangle with sides \(\frac{20}{3}, \frac{3}{2}, \frac{41}{6}\).

Check: \((\frac{20}{3})^2 + (\frac{3}{2})^2 = \frac{400}{9} + \frac{9}{4} = \frac{1600 + 81}{36} = \frac{1681}{36} = (\frac{41}{6})^2\) ✓

Area = \(\frac{1}{2} \cdot \frac{20}{3} \cdot \frac{3}{2} = 5\) ✓

Exercises:
  1. Find all primitive Pythagorean triples with hypotenuse ≤ 50.
  2. Show that 6 is a congruent number.
  3. Prove: In any Pythagorean triple, at least one leg is divisible by 3.
  4. Prove: In any Pythagorean triple, at least one leg is divisible by 4.
  5. Prove: In any Pythagorean triple, at least one leg is divisible by 5.
  6. Find a right triangle with integer sides and area 210.
  7. Show that if \(n\) is a congruent number, then so is \(kn^2\) for any integer \(k\).
  8. Prove: A primitive Pythagorean triple \((a, b, c)\) has \(c \equiv 1 \pmod{4}\) or \(c \equiv 1 \pmod{4}\).
