Lecture 14: Irrational Numbers and Approximation

Lecture 14Irrational Numbers and Approximation

1. Classification of Numbers

Definition 14.1 (Irrational Number) A real number is irrational if it is not rational, i.e., it cannot be expressed as \(\frac{p}{q}\) for integers \(p, q\) with \(q \neq 0\).
Theorem 14.1 \(\sqrt{2}\) is irrational.

Proof by contradiction: Assume \(\sqrt{2} = \frac{p}{q}\) in lowest terms. Then \(2q^2 = p^2\), so \(p^2\) is even, hence \(p\) is even. Write \(p = 2k\). Then \(2q^2 = 4k^2\), so \(q^2 = 2k^2\), making \(q\) even. This contradicts \(\gcd(p, q) = 1\). \(\square\)

Definition 14.2 (Algebraic Number) A real number \(\alpha\) is algebraic if it is a root of a non-zero polynomial with integer coefficients.
Definition 14.3 (Transcendental Number) A real number is transcendental if it is not algebraic.

2. Liouville's Theorem on Approximation

Theorem 14.2 (Liouville's Theorem) If \(\alpha\) is an algebraic number of degree \(n \geq 2\), then there exists a constant \(c > 0\) such that for all rational numbers \(\frac{p}{q}\), \[\left|\alpha - \frac{p}{q}\right| > \frac{c}{q^n}\]
Definition 14.4 (Liouville Number) A Liouville number is a transcendental number \(\alpha\) such that for every positive integer \(n\), there exist integers \(p, q\) with \(q > 1\) satisfying: \[\left|\alpha - \frac{p}{q}\right| < \frac{1}{q^n}\]
Example 14.1 The number \(\sum_{k=1}^{\infty} 10^{-k!}\) is a Liouville number and hence transcendental.

3. Dirichlet's Approximation Theorem

Theorem 14.3 (Dirichlet's Approximation Theorem) For any irrational number \(\alpha\) and any positive integer \(N\), there exist integers \(p, q\) with \(1 \leq q \leq N\) such that: \[\left|q\alpha - p\right| < \frac{1}{N}\] Equivalently, \(\left|\alpha - \frac{p}{q}\right| < \frac{1}{qN} < \frac{1}{q^2}\).

Proof using the pigeonhole principle: Consider the fractional parts \(\{0\alpha\}, \{1\alpha\}, \ldots, \{N\alpha\}\). There are \(N+1\) such fractional parts in \([0, 1)\). Divide \([0, 1)\) into \(N\) intervals of length \(\frac{1}{N}\). By the pigeonhole principle, two fractional parts fall in the same interval, say \(\{i\alpha\}\) and \(\{j\alpha\}\) with \(i > j\). Then \(|(i-j)\alpha - (\lfloor i\alpha \rfloor - \lfloor j\alpha \rfloor)| < \frac{1}{N}\), giving the result with \(q = i-j \leq N\). \(\square\)

4. Hurwitz's Theorem

Theorem 14.4 (Hurwitz's Theorem) For any irrational number \(\alpha\), there exist infinitely many rational numbers \(\frac{p}{q}\) such that: \[\left|\alpha - \frac{p}{q}\right| < \frac{1}{\sqrt{5}q^2}\]

Proof sketch: Using the theory of continued fractions, the convergents satisfy \(\left|\alpha - \frac{p_n}{q_n}\right| < \frac{1}{q_n q_{n+1}}\). For the golden ratio \(\phi = \frac{1+\sqrt{5}}{2}\), the constant \(\frac{1}{\sqrt{5}}\) is optimal. \(\square\)

Example 14.2 The golden ratio \(\phi = \frac{1+\sqrt{5}}{2}\) has convergents \(\frac{F_{n+1}}{F_n}\) where \(F_n\) are Fibonacci numbers, satisfying the bound in Hurwitz's theorem.

5. Transcendence Results

Theorem 14.5 (Lindemann-Weierstrass) If \(\alpha_1, \ldots, \alpha_n\) are distinct algebraic numbers, then \(e^{\alpha_1}, \ldots, e^{\alpha_n}\) are linearly independent over the algebraic numbers.
Corollary 14.1 The numbers \(e\) and \(\pi\) are transcendental.
Example 14.3 Since \(e\) is transcendental, \(\ln 2\) is also transcendental (as it is algebraic only if \(e^{\ln 2} = 2\) is transcendental, which it is not).
Exercises:
  1. Prove that \(\sqrt{3}\) is irrational.
  2. Show that \(\log_{10} 2\) is irrational.
  3. Apply Dirichlet's theorem to find a rational approximation to \(\sqrt{2}\) with denominator at most 10.
  4. Show that any rational number \(\frac{p}{q}\) (in lowest terms) satisfies \(\left|\sqrt{2} - \frac{p}{q}\right| > \frac{1}{2q^2}\).
  5. Prove that Liouville numbers are transcendental.
  6. Find the continued fraction expansion of \(\sqrt{7}\) and use it to approximate \(\sqrt{7}\).
  7. Show that the set of irrational numbers is uncountable.
  8. Prove: If \(\alpha\) is irrational, the set \(\{\{n\alpha\} : n \in \mathbb{Z}^+\}\) is dense in \([0, 1]\).
