Problem Set 5: Trig Derivatives and Optimization - SOLUTIONS

Calculus I - Week 5

Solution Guide

Note: These are detailed solutions showing all steps and reasoning. Each step is clearly justified.

Problem 1: Find \(\frac{dy}{dx}\) for \(y = \sin(x^2 + 2x)\)

Solution:
Step 1: Identify the outer function
Outer: \(\sin(u)\) where \(u = x^2 + 2x\)
Step 2: Apply chain rule
\(\frac{dy}{dx} = \cos(u) \cdot \frac{du}{dx}\)
Step 3: Differentiate inner function
\(\frac{du}{dx} = 2x + 2\)
Step 4: Combine
\(\frac{dy}{dx} = \cos(x^2 + 2x)(2x + 2)\)
Final Answer:
\(\boxed{(2x + 2)\cos(x^2 + 2x)}\)

Problem 2: Find \(\frac{d}{dx}[\tan^{-1}(x^3)]\)

Solution:
Step 1: Recall derivative of arctangent
\(\frac{d}{du}[\tan^{-1}(u)] = \frac{1}{1+u^2}\)
Step 2: Apply chain rule with \(u = x^3\)
\(\frac{d}{dx}[\tan^{-1}(x^3)] = \frac{1}{1+(x^3)^2} \cdot \frac{d}{dx}[x^3]\)
Step 3: Compute derivative
\(\frac{d}{dx}[x^3] = 3x^2\)
Step 4: Combine
\(\frac{d}{dx} = \frac{3x^2}{1+x^6}\)
Final Answer:
\(\boxed{\frac{3x^2}{1+x^6}}\)

Problem 3: Find critical points of \(f(x) = x + 2\sin x\) on \([0, 2\pi]\)

Solution:
Step 1: Find the derivative
\(f'(x) = \frac{d}{dx}[x] + \frac{d}{dx}[2\sin x] = 1 + 2\cos x\)
Step 2: Set derivative equal to zero
\(1 + 2\cos x = 0 \Rightarrow \cos x = -\frac{1}{2}\)
Step 3: Find solutions in interval
In \([0, 2\pi]\): \(\cos x = -\frac{1}{2}\) at \(x = \frac{2\pi}{3}\) and \(x = \frac{4\pi}{3}\)
Step 4: Verify these are in domain
Both \(\frac{2\pi}{3} \approx 2.09\) and \(\frac{4\pi}{3} \approx 4.19\) are in \([0, 2\pi]\)
Final Answer:
\(\boxed{x = \frac{2\pi}{3}, \frac{4\pi}{3}}\)

Problem 4: Rectangle with perimeter 20, maximum area

Solution:
Step 1: Set up variables
Let length = \(l\), width = \(w\). Perimeter = \(2l + 2w = 20\), so \(l + w = 10\) and \(w = 10 - l\)
Step 2: Write area function
\(A = l \cdot w = l(10 - l) = 10l - l^2\)
Step 3: Find critical point
\(\frac{dA}{dl} = 10 - 2l = 0 \Rightarrow l = 5\)
Step 4: Find corresponding width
\(w = 10 - 5 = 5\)
Step 5: Verify maximum
\(\frac{d^2A}{dl^2} = -2 < 0\), so this is a maximum
Step 6: Find maximum area
\(A_{max} = 5 \times 5 = 25\)
Final Answer:
\(\boxed{\text{Square with sides } 5 \text{ units, area } 25 \text{ square units}}\)

Problem 5: Box with square base, volume 1000 cm³, minimum surface area

Solution:
Step 1: Define variables
Let base side = \(x\), height = \(h\). Square base.
Step 2: Write volume constraint
\(V = x^2 h = 1000 \Rightarrow h = \frac{1000}{x^2}\)
Step 3: Write surface area function
\(S = 2x^2 + 4xh = 2x^2 + 4x \cdot \frac{1000}{x^2} = 2x^2 + \frac{4000}{x}\)
Step 4: Find critical point
\(\frac{dS}{dx} = 4x - \frac{4000}{x^2} = 0\)
\(4x = \frac{4000}{x^2} \Rightarrow 4x^3 = 4000 \Rightarrow x^3 = 1000 \Rightarrow x = 10\)
Step 5: Find height
\(h = \frac{1000}{100} = 10\)
Step 6: Verify minimum
\(\frac{d^2S}{dx^2} = 4 + \frac{8000}{x^3} > 0\) for \(x > 0\)
Final Answer:
\(\boxed{x = 10 \text{ cm}, h = 10 \text{ cm (a cube)}}\)

Problem 6: Find \(\frac{d}{dx}[\sec x \cdot \cot x]\)

Solution:
Step 1: Apply product rule
\(\frac{d}{dx}[uv] = u'v + uv'\) where \(u = \sec x\), \(v = \cot x\)
Step 2: Find derivatives
\(u' = \sec x \tan x\), \(v' = -\csc^2 x\)
Step 3: Apply product rule
\(\frac{d}{dx} = \sec x \tan x \cdot \cot x + \sec x \cdot (-\csc^2 x)\)
Step 4: Simplify
\(= \sec x \tan x \cot x - \sec x \csc^2 x\)
\(= \sec x - \sec x \csc^2 x\)
\(= \sec x(1 - \csc^2 x)\)
Final Answer:
\(\boxed{\sec x(1 - \csc^2 x)}\)

Problem 7: Find local extrema of \(f(x) = \frac{x^2}{x^2 + 1}\)

Solution:
Step 1: Find the derivative using quotient rule
\(f'(x) = \frac{2x(x^2+1) - x^2(2x)}{(x^2+1)^2} = \frac{2x^3 + 2x - 2x^3}{(x^2+1)^2} = \frac{2x}{(x^2+1)^2}\)
Step 2: Find critical points
\(f'(x) = 0\) when \(2x = 0\), i.e., \(x = 0\)
Step 3: Apply first derivative test
For \(x < 0\): \(f'(x) < 0\) (decreasing)
For \(x > 0\): \(f'(x) > 0\) (increasing)
Step 4: Conclude
Function changes from decreasing to increasing at \(x = 0\), so local minimum at \(x = 0\).
Final Answer:
\(\boxed{\text{Local minimum at } x = 0, f(0) = 0}\)

Problem 8: Ladder 15 ft, bottom slides toward wall at 3 ft/s

Solution:
Step 1: Set up related rates
Let \(x\) = distance from wall to bottom, \(y\) = height on wall.
Pythagorean theorem: \(x^2 + y^2 = 225\)
Step 2: Differentiate with respect to time
\(2x\frac{dx}{dt} + 2y\frac{dy}{dt} = 0\)
Step 3: Substitute known values
When \(x = 9\): \(y = \sqrt{225-81} = 12\)
\(\frac{dx}{dt} = -3\) (negative since x is decreasing)
Step 4: Solve for \(\frac{dy}{dt}\)
\(2(9)(-3) + 2(12)\frac{dy}{dt} = 0\)
\(-54 + 24\frac{dy}{dt} = 0\)
\(\frac{dy}{dt} = \frac{54}{24} = \frac{9}{4}\)
Final Answer:
\(\boxed{\frac{9}{4} \text{ ft/s (moving upward)}}\)

Problem 9: Find \(\frac{d}{dx}[\tan^{-1}(x)]\)

Solution:
Step 1: Recall the standard derivative
\(\frac{d}{dx}[\tan^{-1}(x)] = \frac{1}{1+x^2}\)
Verification using inverse function theorem
If \(y = \tan^{-1}(x)\), then \(\tan y = x\).
Differentiating: \(\sec^2 y \cdot \frac{dy}{dx} = 1\)
\(\frac{dy}{dx} = \frac{1}{\sec^2 y} = \cos^2 y\)
Since \(\cos^2 y = \frac{1}{1+\tan^2 y} = \frac{1}{1+x^2}\)
Final Answer:
\(\boxed{\frac{1}{1+x^2}}\)

Problem 10: Prove rectangle with fixed perimeter has max area when square

Solution:
Step 1: Set up the problem
Let perimeter = \(P\) (constant). Dimensions: \(x\) and \(y\).
Constraint: \(2x + 2y = P \Rightarrow y = \frac{P}{2} - x\)
Step 2: Write area function
\(A = xy = x\left(\frac{P}{2} - x\right) = \frac{Px}{2} - x^2\)
Step 3: Find critical point
\(\frac{dA}{dx} = \frac{P}{2} - 2x = 0 \Rightarrow x = \frac{P}{4}\)
Step 4: Find corresponding y
\(y = \frac{P}{2} - \frac{P}{4} = \frac{P}{4}\)
Step 5: Verify maximum
\(\frac{d^2A}{dx^2} = -2 < 0\)
Conclusion:
When \(x = y = \frac{P}{4}\), the rectangle is a square and has maximum area.
Final Answer:
\(\boxed{\text{Square with side } \frac{P}{4} \text{ gives maximum area}}\)

Bonus 1: Find absolute extrema of \(f(x) = x + \frac{2}{x}\) on \([1, 4]\)

Solution:
Step 1: Find critical points
\(f'(x) = 1 - \frac{2}{x^2} = 0 \Rightarrow 1 = \frac{2}{x^2} \Rightarrow x^2 = 2 \Rightarrow x = \sqrt{2}\)
Step 2: Check if critical point is in domain
\(\sqrt{2} \approx 1.414\) is in \([1, 4]\)
Step 3: Evaluate at critical point and endpoints
\(f(1) = 1 + 2 = 3\)
\(f(\sqrt{2}) = \sqrt{2} + \frac{2}{\sqrt{2}} = \sqrt{2} + \sqrt{2} = 2\sqrt{2} \approx 2.83\)
\(f(4) = 4 + \frac{2}{4} = 4.5\)
Step 4: Conclude
Absolute minimum: \(f(\sqrt{2}) = 2\sqrt{2}\)
Absolute maximum: \(f(4) = 4.5\)
Final Answer:
\(\boxed{\text{Abs. min at } x = \sqrt{2}, \text{ abs. max at } x = 4}\)

Bonus 2: Cylinder volume 1000 cm³, minimize material

Solution:
Step 1: Define variables
Radius \(r\), height \(h\). Volume constraint: \(\pi r^2 h = 1000\)
Step 2: Express h in terms of r
\(h = \frac{1000}{\pi r^2}\)
Step 3: Write surface area function
\(S = 2\pi r^2 + 2\pi rh = 2\pi r^2 + 2\pi r \cdot \frac{1000}{\pi r^2} = 2\pi r^2 + \frac{2000}{r}\)
Step 4: Find critical point
\(\frac{dS}{dr} = 4\pi r - \frac{2000}{r^2} = 0\)
\(4\pi r^3 = 2000 \Rightarrow r^3 = \frac{500}{\pi} \Rightarrow r = \sqrt[3]{\frac{500}{\pi}}\)
Step 5: Find height
\(h = \frac{1000}{\pi r^2} = \frac{1000}{\pi \cdot \left(\frac{500}{\pi}\right)^{2/3}} = 2\sqrt[3]{\frac{500}{\pi}} = 2r\)
Final Answer:
\(\boxed{r = \sqrt[3]{\frac{500}{\pi}} \text{ cm}, h = 2r}\)
