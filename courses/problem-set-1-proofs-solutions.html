Solutions: Problem Set 1

Introduction to Proofs - Lecture 1

Key ideas used in these solutions

  • The conditional \(p o q\) is false only on the row \(p=T, q=F\).
  • Logical equivalence means identical truth-table columns.
  • Contrapositives are equivalent; converses and inverses are not.
  • Validity is a tautology about the argument form, not a claim that the premises are true.

Worked solutions

Problem 1: Determine whether each is a proposition, and if so give its truth value: (a) \(11\) is prime; (b) \(x+1=4\); (c) every even integer greater than \(2\) is a sum of two primes; (d) "watch out!".
(a) Yes; \(11\) has no divisors other than \(1,11\), so the proposition is true.
(b) No. The truth value depends on the free variable \(x\). It becomes a proposition after \(x\) is specified or quantified.
(c) Yes. This is Goldbach's conjecture; it has a definite truth value even though no proof is known. Propositionhood does not require us to know the truth value.
(d) No; it is an exclamation, not a declarative statement with a truth value.
Problem 2: Construct a truth table for \((p o q)\lor(p o r)\) and decide whether it is a tautology.

There are eight rows for \(p,q,r\). The conditional \(p\to q\) is false only when \(p=T,q=F\); similarly for \(p\to r\). When \(p=F\), both conditionals are true, so their disjunction is true. When \(p=T\), the formula becomes \(q\lor r\), which is false only when \(q=F,r=F\). Hence the only false row of the whole formula is \(p=T,q=F,r=F\), so the formula is not a tautology; it is contingent.

\[\begin{array}{c|c|c|c|c|c}p&q&r&p\to q&p\to r&(p\to q)\lor(p\to r)\\ \hline T&T&T&T&T&T\\ T&T&F&T&F&T\\ T&F&T&F&T&T\\ T&F&F&F&F&F\\ F&T&T&T&T&T\\ F&T&F&T&T&T\\ F&F&T&T&T&T\\ F&F&F&T&T&T\end{array}\]
Problem 3: Prove \( eg(p\lor q)\equiv eg p\land eg q\) by truth tables.

List the four assignments and compare the last two columns:

\[\begin{array}{c|c|c|c|c}p&q&p\lor q&\neg(p\lor q)&\neg p\land\neg q\\ \hline T&T&T&F&F\\ T&F&T&F&F\\ F&T&T&F&F\\ F&F&F&T&T\end{array}\]

The columns agree in every row, so the formulas are logically equivalent by Definition 1.4.

Problem 4: Show that \((p o q)\equiv( eg q o eg p)\) without writing a truth table.
Step 1. Rewrite \(p\to q\) using Theorem 1.5: \(p\to q\equiv\neg p\lor q\).
Step 2. Rewrite the contrapositive: \(\neg q\to\neg p\equiv\neg(\neg q)\lor\neg p\equiv q\lor\neg p\).
Step 3. Commutativity of \(\lor\) gives \(q\lor\neg p\equiv\neg p\lor q\). Both formulas are therefore equivalent to the same expression, hence to each other.
Problem 5: Prove or disprove: \((p o q)\lor(q o p)\) is a tautology.

It is a tautology. Suppose for contradiction that the disjunction is false. Then both \(p\to q\) and \(q\to p\) are false. But \(p\to q\) is false only when \(p=T,q=F\), while \(q\to p\) is false only when \(q=T,p=F\). These requirements contradict each other, so no assignment makes the formula false.

Alternate route: \((p\to q)\lor(q\to p)\equiv(\neg p\lor q)\lor(\neg q\lor p)\), which contains \(p\lor\neg p\), a tautology.

Problem 6: Translate into logical symbols and state the converse: "If \(n\) is divisible by \(6\), then \(n\) is divisible by \(2\) and by \(3\)."

Let \(A\) be "\(\:n\) is divisible by \(6\)", \(B\) be "\(\:n\) is divisible by \(2\)", and \(C\) be "\(\:n\) is divisible by \(3\)". The statement is \(A\to(B\land C)\). Its converse is \((B\land C)\to A\): if \(n\) is divisible by \(2\) and by \(3\), then \(n\) is divisible by \(6\). The converse is true because \(2\) and \(3\) are coprime, so \(2\mid n\) and \(3\mid n\) imply \(6\mid n\). The original and its converse together give \(A\leftrightarrow(B\land C)\).

Problem 7: Analyse the argument: "If the series converges absolutely, it converges. This series converges. Therefore it converges absolutely." Name the form and determine validity.

Write \(p\) for "converges absolutely" and \(q\) for "converges". The argument has premises \(p\to q\) and \(q\), and conclusion \(p\). This is affirming the consequent, which is invalid. A concrete counterexample: the alternating harmonic series \(\sum_{n=1}^\infty (-1)^{n+1}/n\) converges but not absolutely.

Problem 8: Determine whether \( eg\big(p\land(q o eg p)\big)\) is a tautology, a contradiction, or contingent.
Step 1. Rewrite the inner conditional: \(q\to\neg p\equiv\neg q\lor\neg p\), so the formula is \(\neg\big(p\land(\neg q\lor\neg p)\big)\).
Step 2. Distribute: \(p\land(\neg q\lor\neg p)\equiv(p\land\neg q)\lor(p\land\neg p)\).
Step 3. Since \(p\land\neg p\equiv F\), the inside is equivalent to \(p\land\neg q\).
Step 4. Negating gives \(\neg p\lor q\). This is not a tautology: it is false when \(p=T,q=F\). Therefore the original claim is false; the formula is contingent.

The point of this problem is that a confident-looking simplification can still lead to a counterexample. Always check the final form against a truth assignment.

Bonus Problem: Determine whether the following argument is valid: “If \(n\) is divisible by \(6\), then \(n\) is even. The integer \(14\) is even. Therefore \(14\) is divisible by \(6\).”
The argument is invalid. It has the form \(P\to Q\), \(Q\), therefore \(P\), which is affirming the consequent. The counterexample \(n=14\) has \(Q\) true (14 is even) and \(P\) false (6 does not divide 14), so the premises do not force the conclusion.
