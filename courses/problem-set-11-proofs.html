Problem Set 11: Infinite Sets and Cardinality

Introduction to Proofs - Lecture 11 Medium

Try each problem before reading the solutions. A proof is judged by the completeness of its logical chain, not by how short it is. State your assumptions, justify every nontrivial step, and verify that the conclusion follows exactly.

Problems

Problem 1

Prove that the set of all finite sequences of natural numbers is countable.

Problem 2

Prove that the interval \((0,1)\) is uncountable using binary expansions, taking care of the non-uniqueness of expansions.

Problem 3

Prove that there is no surjection from a set \(A\) onto \(\mathcal{P}(A)\).

Problem 4

Prove that \(\mathbb{Q}\) is countable by constructing an explicit enumeration strategy.

Problem 5

Show that the set of real numbers in \([0,1]\) that have a decimal expansion containing only digits \(0\) and \(1\) is uncountable.

Problem 6

Prove that if \(A\) is countably infinite and \(B\) is finite, then \(A\cup B\) is countably infinite.

Problem 7

Explain why \(|\mathbb{N} imes\mathbb{N}|=|\mathbb{N}|\) does not contradict the fact that \(\mathbb{N}\) is a proper subset of \(\mathbb{N} imes\mathbb{N}\) via \(n\mapsto(n,0)\).

Problem 8

Prove that the set of all algebraic real numbers is countable.

Bonus Problem

Prove that the set of finite binary strings is countable.
