Solutions: Problem Set 11: Diophantine Equations

Elementary Number Theory - Week 12 Solutions

Key Ideas

Linear Diophantine equations

The equation \(ax+by=c\) has integer solutions exactly when \(\gcd(a,b)\) divides \(c\). When one solution exists, all solutions are obtained by shifting by multiples of \(\frac{b}{\gcd(a,b)}\) and \(\frac{a}{\gcd(a,b)}\).

Solutions

Problem 1

Find all integer solutions to \(15x + 25y = 5\).

First, \(\gcd(15,25)=5\) and \(5\mid 5\), so solutions exist. Divide by 5: \(3x+5y=1\). A particular solution is \(x=2,\; y=-1\) because \(3\cdot 2+5\cdot(-1)=1\). The general solution is
\(x = 2 + 5t,\quad y = -1 - 3t,\qquad t\in\mathbb{Z}\).

Problem 2

Find all integer solutions to \(7x + 11y = 3\).

Here \(\gcd(7,11)=1\) and \(1\mid 3\). Using the extended Euclidean algorithm:
\(11 = 7\cdot 1 + 4\)
\(7 = 4\cdot 1 + 3\)
\(4 = 3\cdot 1 + 1\)
Back-substituting gives \(1 = 4\cdot 7 - 3\cdot 11\). Multiply by 3: \(3 = 12\cdot 7 - 9\cdot 11\). So a particular solution is \(x_0=12,\; y_0=-9\).

General solution:
\(x = 12 + 11t,\quad y = -9 - 7t,\qquad t\in\mathbb{Z}\).

Problem 3

Show that \(x^2 + y^2 = 3z^2\) has no non-trivial integer solutions.

Work modulo 3. Perfect squares modulo 3 are 0 or 1. So \(x^2+y^2\) modulo 3 can be 0, 1, or 2. Meanwhile \(3z^2\equiv 0\pmod3\). If \(x^2+y^2\equiv 0\pmod3\), then both \(x\) and \(y\) must be divisible by 3. Write \(x=3x_1\) and \(y=3y_1\). Then \(9x_1^2+9y_1^2=3z^2\), so \(3(x_1^2+y_1^2)=z^2\), which again forces \(z\) to be divisible by 3. This infinite descent shows the only solution is \(x=y=z=0\).

Problem 4

Find all primitive Pythagorean triples with hypotenuse 25.

Use the formula \(a=m^2-n^2,\; b=2mn,\; c=m^2+n^2\) with \(m>n>0\), \(\gcd(m,n)=1\), and exactly one of \(m,n\) even. We need \(m^2+n^2=25\). The possibilities are \((m,n)=(4,3)\) and \((5,0)\), but \(n>0\), so only \((4,3)\) works. This gives
\(a=4^2-3^2=7,\quad b=2\cdot 4\cdot 3=24,\quad c=25\).

Answer. The primitive triple is \((7,24,25)\).

Problem 5

Prove: If \((a,b,c)\) is a Pythagorean triple, then \(c\) is odd.

Work modulo 2. Perfect squares modulo 2 are 0 or 1. If \(c\) were even, then \(c^2\equiv 0\pmod4\). The sum \(a^2+b^2\) modulo 4 can be 0, 1, or 2. For a primitive triple, \(a\) and \(b\) cannot both be even. In fact, one leg is even and the other is odd, so \(a^2+b^2\equiv 1+0\equiv 1\pmod4\). Therefore \(c^2\equiv 1\pmod4\), so \(c\) is odd.

Problem 6

Show that if \(\gcd(a,b)=1\) and \(a^2+b^2=c^2\), then \(c\equiv 1\pmod4\).

From Problem 5, \(c\) is odd. Reduce the equation modulo 4. Since \(c\) is odd, \(c^2\equiv 1\pmod4\). The squares modulo 4 are 0 and 1. Because \(\gcd(a,b)=1\), \(a\) and \(b\) cannot both be even. In a primitive triple, exactly one of \(a,b\) is even and the other is odd, so \(a^2+b^2\equiv 0+1\equiv 1\pmod4\). Therefore \(c^2\equiv 1\pmod4\), which means \(c\equiv 1\pmod4\) because \(c\) is odd.

Problem 7

Find the smallest positive integer \(y\) such that \(x^2 - 7y^2 = 1\) has a solution.

Try small values:
\(y=1\): \(x^2=8\), not a square.
\(y=2\): \(x^2=29\), not a square.
\(y=3\): \(x^2=64\), so \(x=8\).

Answer. The smallest positive \(y\) is 3, giving the solution \((x,y)=(8,3)\).

Problem 8

Prove: In any Pythagorean triple, at least one leg is divisible by 3.

Work modulo 3. Perfect squares modulo 3 are 0 or 1. If neither leg were divisible by 3, then both \(a^2\) and \(b^2\) would be congruent to 1 modulo 3, so \(a^2+b^2\equiv 2\pmod3\). But \(c^2\) modulo 3 can only be 0 or 1, never 2. Therefore at least one of \(a\) or \(b\) must be divisible by 3.

Problem 9

Find all integer solutions to \(x^2 - 2y^2 = 1\) with \(y < 10\).

The fundamental solution is \((3,2)\). All solutions are generated by \((3+2\sqrt{2})^n\). Computing:
\(n=1\): \((3,2)\)
\(n=2\): \((3+2\sqrt{2})^2 = 17+12\sqrt{2}\), so \((17,12)\) but \(12\not<10\).

Answer. The only solution with \(y<10\) is \((3,2)\).

Problem 10

Show that \(x^2 - 5y^2 = -4\) has an integer solution.

Try small values:
\(y=1\): \(x^2=1\), so \(x=\pm1\).
Check: \(1^2 - 5\cdot 1^2 = 1-5 = -4\).

Answer. \((x,y)=(\pm1,1)\) are solutions.

Bonus Solutions

Bonus Problem 1

Prove that every primitive Pythagorean triple has exactly one even leg.

If both legs were even, then the triple would not be primitive because 2 would divide all three numbers. If both legs were odd, then \(a^2\equiv 1\pmod4\) and \(b^2\equiv 1\pmod4\), so \(a^2+b^2\equiv 2\pmod4\). But a perfect square is never congruent to 2 modulo 4. Therefore exactly one leg is even.

Bonus Problem 2

Find the fundamental solution to \(x^2 - 3y^2 = 1\) and generate the next three solutions.

The continued fraction of \(\sqrt{3}\) is \([1;\overline{1,2}]\), with period length 2. The convergents are \(1, 2, \frac{5}{3}, \frac{7}{4}, \frac{19}{11},\dots\). The first convergent giving a solution is \((2,1)\) because \(2^2-3\cdot 1^2=1\).

All solutions are generated by \((2+\sqrt{3})^n\):
\(n=1\): \((2,1)\)
\(n=2\): \((7,4)\) because \((2+\sqrt{3})^2=7+4\sqrt{3}\)
\(n=3\): \((26,15)\) because \((2+\sqrt{3})^3=26+15\sqrt{3}\)
\(n=4\): \((97,56)\) because \((2+\sqrt{3})^4=97+56\sqrt{3}\)

Bonus Problem 3

Show that there are infinitely many Pythagorean triples where the hypotenuse differs from a leg by 1.

Use the Pell equation \(x^2 - 2y^2 = 1\). If \((x,y)\) is a solution, set \(c=x^2\) and \(a=2xy\). Then \(c-a = x^2-2xy = x(x-2y)\). For the fundamental solution \((3,2)\), \(c=9\) and \(a=12\), but that does not quite fit the desired form. Instead, use the identity
\((\frac{m^2-n^2}{2mn})^2 + 1 = (\frac{m^2+n^2}{2mn})^2\).

A cleaner argument: from the parametrization, take \(m=n+1\) with \(n\) odd. Then
\(c = m^2+n^2 = (n+1)^2+n^2 = 2n^2+2n+1\)
\(b = 2mn = 2n(n+1)\)
\(a = m^2-n^2 = 2n+1\).

Then \(c-a = 2n^2+2n+1-(2n+1)=2n^2\), which grows with \(n\). To get difference 1, solve Pell's equation \(x^2-2y^2=1\); its infinitely many solutions produce infinitely many triples with the desired property.
