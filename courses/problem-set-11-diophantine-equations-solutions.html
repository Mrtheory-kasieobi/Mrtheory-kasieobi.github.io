Solutions: Problem Set 11: Diophantine Equations

Elementary Number Theory - Week 12 Solutions

Key Definitions and Concepts

Linear Diophantine Equation

An equation of the form \(ax + by = c\) where \(a, b, c \in \mathbb{Z}\) and we seek integer solutions.

Necessary condition: \(\gcd(a, b) \mid c\).

General solution: If \((x_0, y_0)\) is a particular solution, then all solutions are:
x = x₀ + (b/d)t, y = y₀ - (a/d)t, where d = gcd(a,b) and t ∈ ℤ.

Solutions

Problem 1: Find all integer solutions to \(7x + 11y = 3\).

Step 1: Check solvability.
\(\gcd(7, 11) = 1\) and \(1 \mid 3\), so solutions exist.

Step 2: Find a particular solution.

Using Extended Euclidean Algorithm:
11 = 7 × 1 + 4
7 = 4 × 1 + 3
4 = 3 × 1 + 1
Back-substitute: 1 = 4 - 3 = 4 - (7-4) = 2×4 - 7 = 2(11-7) - 7 = 2×11 - 3×7
So \(7(-3) + 11(2) = 3\) gives \(x_0 = -3, y_0 = 2\).

General Solution: x = -3 + 11t, y = 2 - 7t for t ∈ ℤ.

Problem 2: Prove that \(x^2 - 2y^2 = 1\) has infinitely many integer solutions.

Understanding: This is Pell's equation. The solutions are called Pell numbers.

All Solutions:

Fundamental solution: \(x = 3, y = 2\) since \(9 - 8 = 1\).
Generating all solutions:

If \((x_n, y_n)\) is a solution, then:
\[(x_{n+1} + y_{n+1}\sqrt{2}) = (x_n + y_n\sqrt{2})(3 + 2\sqrt{2})\]

This gives recurrence: \(x_{n+1} = 3x_n + 4y_n\), \(y_{n+1} = 2x_n + 3y_n\).

Infinity: The infinitely many solutions are \((x_n, y_n)\) for n = 1, 2, 3, ...

Problem 3: Find a Pythagorean triple with \(y = z - x\) (where x² + y² = z²).

Solution:

Pythagorean triples are parameterized as:
\(x = m^2 - n^2, y = 2mn, z = m^2 + n^2\) for coprime m, n of opposite parity.

Require y = z - x:
\[2mn = (m^2 + n^2) - (m^2 - n^2) = 2n^2\]
\[m = n\]

But m and n must be coprime and different! Let's reconsider.

Alternative approach:

We need \(2mn = 2n^2\), so \(m = n\).
This doesn't work with the standard parameterization.
Direct search: Try small values:

  • (3, 4, 5): 4 = 5 - 3 ✓

Answer: The triple (3, 4, 5) satisfies y = z - x.

Problem 4: Show that \(x^2 + 2y^2 = z^2\) has primitive solutions.

Understanding: A primitive solution has \(\gcd(x, y, z) = 1\).

Solution:

Find a primitive solution by direct search:
  • y = 1: x² + 2 = z² → z² - x² = 2 → (z-x)(z+x) = 2
  • Try x = 1: 1 + 2y² = z² → z² - 2y² = 1 (Pell equation!)

The fundamental solution: y = 2, x = 2, z = √8? No, z must be integer.

Actually: y = 2, x = 2 gives 4 + 8 = 12, not a perfect square.

Try x = 1, y = 2: 1 + 8 = 9 = 3² ✓

Answer: (x, y, z) = (1, 2, 3) is a primitive solution: 1² + 2(2)² = 1 + 8 = 9 = 3².

Problem 5: Find all integer solutions to \(x^2 + y^2 = 2z^2\).

Strategy: Look for patterns and use homogeneity.

Observe: if (x, y, z) is a solution, so is (kx, ky, kz).

So we seek primitive solutions with \(\gcd(x, y, z) = 1\).

Rewrite:

\[x^2 + y^2 = 2z^2\]

This can be viewed as \(x^2 + y^2 = z^2 + z^2\). Geometrically, sum of two squares equals twice a square.

Try small values:
  • z = 1: x² + y² = 2 → (1, 1)
  • z = 5: x² + y² = 50 → (5, 5)

It appears x = y = z gives solutions, but that's infinite family.

Actually: x² + y² = 2z² ⟺ (x-y)² + (x+y)² = 4z², not simpler.

All solutions: Primitive solutions include (1, 1, 1), (7, 1, 5), etc.

Bonus Solutions

Bonus Problem 1: Prove that if x² - 2y² = 1, then x is odd and y is even.

Proof:

If x is even: x = 2k, so 4k² - 2y² = 1, meaning 2y² = 4k² - 1.

The RHS is odd, so y² is not an integer - contradiction.

Therefore x is odd. Then x² ≡ 1 (mod 4), and 1 - 2y² = x² ≡ 1 (mod 4), so y² ≡ 0 (mod 2), meaning y is even.

Bonus Problem 2: Find the smallest positive integer that cannot be written as ax + by for integers x, y where gcd(a,b)=d.

This is the Frobenius coin problem for two coins.

Answer: For coprime a, b, the largest non-representable integer is ab - a - b.

General: for a, b with gcd = d, the answer is scaled by d.
