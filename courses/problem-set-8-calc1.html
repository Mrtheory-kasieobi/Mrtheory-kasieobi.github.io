Problem Set 8: Definite Integrals and FTC

Calculus I - Week 8

Instructions

Show all work. No calculators. Write clearly and show each step.

Problems

  • 1. Evaluate \(\int_0^1 (x^2 + 2x + 1) \, dx\)
  • 2. Find the area between \(y = x^2\) and \(y = x\) from \(x = 0\) to \(x = 1\)
  • 3. Evaluate \(\int_{-1}^2 (x^3 - 4x) \, dx\)
  • 4. Find the average value of \(f(x) = x^2\) on \([0, 2]\)
  • 5. Use the definition of the definite integral as a limit to evaluate \(\int_0^2 x \, dx\)
  • 6. If \(\int_1^5 f(x) \, dx = 10\) and \(\int_1^5 g(x) \, dx = 3\), find \(\int_1^5 [2f(x) - 3g(x)] \, dx\)
  • 7. Evaluate \(\int_0^{\pi/4} \sin x \cos x \, dx\) using substitution
  • 8. Find \(\int \frac{e^x}{e^x + 1} \, dx\)
  • 9. Prove that \(\int_a^b f(x) \, dx = -\int_b^a f(x) \, dx\) using the FTC
  • 10. Find the total area between \(y = x^3\) and \(y = x\) on \([-1, 1]\)
Bonus Problems (10 points each):
  • B1. Evaluate \(\int_0^{\pi/2} \sin^2 x \, dx\) and \(\int_0^{\pi/2} \cos^2 x \, dx\) and compare
  • B2. Prove that \(\int_a^a f(x) \, dx = 0\) for any integrable function \(f\)
