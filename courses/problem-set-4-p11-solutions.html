Problem Set 4: Quadratic Equations

Precalculus 11 - Chapter 4 Solutions

Solutions

Problem 1: Factor \(x^2 - 7x + 12\)
Find two numbers that multiply to 12 and add to -7: -3 and -4
Factor: \((x - 3)(x - 4)\)
Answer: \((x - 3)(x - 4)\)
Problem 2: Solve \(2x^2 + 3x - 2 = 0\) using quadratic formula
Quadratic formula: \(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\)
Here \(a = 2\), \(b = 3\), \(c = -2\)
Discriminant: \(b^2 - 4ac = 9 - 4(2)(-2) = 9 + 16 = 25\)
\(x = \frac{-3 \pm \sqrt{25}}{4} = \frac{-3 \pm 5}{4}\)
\(x = \frac{2}{4} = \frac{1}{2}\) or \(x = \frac{-8}{4} = -2\)
Answer: \(x = \frac{1}{2}\) or \(x = -2\)
Problem 3: Solve \(x^2 + 6x - 7 = 0\) by completing the square
Move constant: \(x^2 + 6x = 7\)
Complete the square: \((\frac{6}{2})^2 = 9\)
Add to both sides: \(x^2 + 6x + 9 = 7 + 9 = 16\)
Factor: \((x + 3)^2 = 16\)
Take square root: \(x + 3 = \pm 4\)
\(x = -3 \pm 4\), so \(x = 1\) or \(x = -7\)
Answer: \(x = 1\) or \(x = -7\)
Problem 4: Discriminant of \(3x^2 - 4x + 5 = 0\)
Discriminant: \(D = b^2 - 4ac = (-4)^2 - 4(3)(5) = 16 - 60 = -44\)
Since \(D < 0\), there are no real roots (two complex conjugate roots)
Answer: Discriminant = -44, no real roots
Problem 5: Solve \(x^4 - 13x^2 + 36 = 0\)
Let \(u = x^2\), then: \(u^2 - 13u + 36 = 0\)
Factor: \((u - 4)(u - 9) = 0\)
So \(u = 4\) or \(u = 9\)
Substitute back: \(x^2 = 4\) gives \(x = \pm 2\)
\(x^2 = 9\) gives \(x = \pm 3\)
Answer: \(x = -3, -2, 2, 3\)
Problem 6: Exact and approximate solutions of \(x^2 - 5x + 1 = 0\)
Quadratic formula: \(x = \frac{5 \pm \sqrt{25 - 4}}{2} = \frac{5 \pm \sqrt{21}}{2}\)
Exact: \(x = \frac{5 \pm \sqrt{21}}{2}\)
Approximate: \(\sqrt{21} \approx 4.583\)
\(x \approx \frac{5 + 4.583}{2} \approx 4.79\) and \(x \approx \frac{5 - 4.583}{2} \approx 0.21\)
Answer: Exact: \(x = \frac{5 \pm \sqrt{21}}{2}\), Approx: \(x \approx 0.21, 4.79\)
Problem 7: Rectangle dimensions
Let width = \(w\), length = \(2w + 3\)
Area = length × width: \(w(2w + 3) = 35\)
\(2w^2 + 3w - 35 = 0\)
Use quadratic formula: \(w = \frac{-3 \pm \sqrt{9 + 280}}{4} = \frac{-3 \pm \sqrt{289}}{4} = \frac{-3 \pm 17}{4}\)
\(w = \frac{14}{4} = 3.5\) (positive) or \(w = \frac{-20}{4} = -5\) (reject)
Width = 3.5 m, Length = \(2(3.5) + 3 = 10\) m
Answer: Width = 3.5 m, Length = 10 m
Problem 8: Vertex and x-intercepts of \(y = 2x^2 - 8x + 5\)
Vertex x-coordinate: \(x = \frac{-b}{2a} = \frac{8}{4} = 2\)
Vertex y-coordinate: \(y = 2(2)^2 - 8(2) + 5 = 8 - 16 + 5 = -3\)
Vertex: \((2, -3)\)
x-intercepts: solve \(2x^2 - 8x + 5 = 0\)
\(x = \frac{8 \pm \sqrt{64 - 40}}{4} = \frac{8 \pm \sqrt{24}}{4} = \frac{8 \pm 2\sqrt{6}}{4} = 2 \pm \frac{\sqrt{6}}{2}\)
\(x \approx 2 \pm 1.225\), so \(x \approx 0.77\) and \(x \approx 3.23\)
Answer: Vertex (2, -3), x-intercepts at \(x = 2 \pm \frac{\sqrt{6}}{2}\) (approx 0.77 and 3.23)

Bonus Solutions

Bonus Problem 1: Vertex Insight
For \(y = -2x^2 + 12x - 5\), vertex x = \(-\frac{b}{2a} = -\frac{12}{2(-2)} = 3\)
Vertex y = \(-2(3)^2 + 12(3) - 5 = -18 + 36 - 5 = 13\)
Vertex: \((3, 13)\)
Since a = -2 < 0, parabola opens down, so range is \(y \leq 13\)
New equation with vertex up 3: vertex moves from (3, 13) to (3, 16)
New equation: \(y = -2(x - 3)^2 + 16\)
Expand: \(y = -2(x^2 - 6x + 9) + 16 = -2x^2 + 12x - 18 + 16 = -2x^2 + 12x - 2\)
Answer: Vertex (3, 13), Range: \(y \leq 13\). New equation: \(y = -2x^2 + 12x - 2\).
Bonus Problem 2: Discriminant Detective
Discriminant of \(x^2 + px + q = 0\): \(D_1 = p^2 - 4q\)
Discriminant of \(x^2 + qx + p = 0\): \(D_2 = q^2 - 4p\)
Set equal: \(p^2 - 4q = q^2 - 4p\)
Rearrange: \(p^2 - q^2 + 4p - 4q = 0\)
Factor: \((p-q)(p+q) + 4(p-q) = 0\)
Factor: \((p-q)(p+q+4) = 0\)
Since \(p \neq q\), we need \(p + q + 4 = 0\)
So: \(p + q = -4\)
For discriminants to be non-negative: \(p^2 \geq 4q\) and \(q^2 \geq 4p\)
With \(q = -4 - p\): \(p^2 \geq 4(-4-p) = -16 - 4p\)
\(p^2 + 4p + 16 \geq 0\) (always true)
Answer: \(p + q = -4\)
Bonus Problem 3: Quadratic Chain
Let \(n = a^2\) and \(n + 2025 = b^2\) for integers \(a, b\)
Then: \(b^2 - a^2 = 2025\)
Factor: \((b-a)(b+a) = 2025\)
Factor 2025: \(2025 = 3^4 \times 5^2 = 81 \times 25\)
Find factor pairs where both factors have same parity (both odd or both even)
Since 2025 is odd, all factor pairs are odd
Factor pairs: (1, 2025), (3, 675), (5, 405), (9, 225), (15, 135), (25, 81), (27, 75), (45, 45)
For each pair (d, e) where d < e: \(b - a = d\), \(b + a = e\)
Then: \(b = \frac{d+e}{2}\), \(a = \frac{e-d}{2}\)
For (45, 45): \(a = 0\), \(n = 0\) (not positive)
For (27, 75): \(a = 24\), \(n = 576\)
Answer: \(n = 576\) (since \(576 = 24^2\) and \(771 = 27.77^2\)... wait, let me recalculate)
Actually: \(n + 2025 = 576 + 2025 = 2601 = 51^2\)
So \(n = 576\) is quadratic-perfect
Answer: \(n = 576\)
