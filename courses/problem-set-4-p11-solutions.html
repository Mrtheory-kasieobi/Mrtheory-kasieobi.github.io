Solutions: Problem Set 4

Quadratic Functions - Precalculus 11
Solution 1

Vertex: \((2, 3)\), Axis of symmetry: \(x = 2\), Opens upward (a > 0)

Solution 2

\(y = x^2 - 6x + 9 - 9 + 5 = (x - 3)^2 - 4\)

Solution 3

x-intercepts: \((6, 0)\) and \((1, 0)\), y-intercept: \((0, 6)\)

Solution 4

Domain: all real numbers. Range: \(y \leq -4\)

Solution 5

\(y = 4(x - 3)^2 - 2\), passes through \((1, 6)\): \(6 = 4(1-3)^2 - 2 = 4(4) - 2 = 14\) ✗

Correction: \(y = a(x-3)^2 - 2\). Using \((1, 6)\): \(6 = a(4) - 2\), so \(a = 2\). Final: \(y = 2(x-3)^2 - 2\)

Solution 6

x-intercepts: \((x-4)^2 = 9\), so \(x = 7\) or \(x = 1\)

Solution 7

Vertex: \((-2, 1)\). Opens downward. Axis: \(x = -2\). y-intercept: \(y = -11\)

Solution 8

Maximum: \(t = 1\) sec, height = 64 ft. Hits ground: \(t = 4\) sec

Bonus Solutions

Bonus Solution 1

\(y = a(x+2)(x-5)\). Passes through \((1, 6)\): \(6 = a(3)(-4)\), so \(a = -\frac{1}{2}\)

Equation: \(y = -\frac{1}{2}(x+2)(x-5)\)

Bonus Solution 2

Maximum at \(t = 2\) sec (vertex of parabola). Height at t=2: \(h(2) = 144\) ft

Hits ground: solve \(-16t^2 + 64t + 80 = 0\) → \(t = 5\) sec
