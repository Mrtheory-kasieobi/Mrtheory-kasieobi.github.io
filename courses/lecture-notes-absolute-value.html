Absolute Value and Reciprocal Functions

Precalculus 11 - Lecture Notes
British Columbia Curriculum | Last Updated: 2026

1. Absolute Value

The absolute value of a number is its distance from zero on the number line, regardless of direction.

Definition: The absolute value of \(x\) is denoted \(|x|\) and is defined as: \[|x| = \begin{cases} x & \text{if } x \geq 0 \\ -x & \text{if } x < 0 \end{cases}\]

1.1 Properties of Absolute Value

  • \(|x| \geq 0\) for all real numbers \(x\)
  • \(|x| = 0\) if and only if \(x = 0\)
  • \(|-x| = |x|\)
  • \(|xy| = |x| \cdot |y|\)
  • \(|\frac{x}{y}| = \frac{|x|}{|y|}\) (where \(y \neq 0\))

2. Absolute Value Functions

An absolute value function has the form \(f(x) = |x|\) or transformations thereof.

General Form:
\[f(x) = a|x - h| + k\]

Where \((h, k)\) is the vertex of the V-shaped graph.

2.1 Graph of Absolute Value Function

The basic absolute value function \(f(x) = |x|\) has:

  • Vertex: \((0, 0)\)
  • Shape: V-shaped
  • Direction: Opens upward
  • Slope: 1 on the right, -1 on the left
Example 1: Graphing Absolute Value Functions

Graph \(f(x) = 2|x - 3| + 1\)

Solution:

Vertex: \((3, 1)\)

Transformation: Shift right 3, up 1, vertical stretch by 2

Opening: Upward (since \(a = 2 > 0\))

2.2 Transformations of Absolute Value Functions

  • Vertical stretch/compression: \(|a| > 1\) stretches, \(0 < |a| < 1\) compresses
  • Reflection: If \(a < 0\), reflects across x-axis (opens downward)
  • Horizontal shift: \(h\) units right if \(h > 0\), left if \(h < 0\)
  • Vertical shift: \(k\) units up if \(k > 0\), down if \(k < 0\)

3. Absolute Value Equations

An absolute value equation is an equation that contains an absolute value expression.

General Approach:
If \(|x| = a\) where \(a \geq 0\), then \(x = a\) or \(x = -a\)

3.1 Solving Absolute Value Equations

To solve \(|expression| = value\):

  1. Isolate the absolute value
  2. Set up two equations: one positive, one negative
  3. Solve each equation
  4. Check solutions in the original equation
Example 2: Solving Absolute Value Equations

Solve: \(|2x - 3| = 7\)

Solution:

Case 1: \(2x - 3 = 7\)

\(2x = 10\)

\(x = 5\)

Case 2: \(2x - 3 = -7\)

\(2x = -4\)

\(x = -2\)

Solutions: \(x = 5\) or \(x = -2\)

3.2 No Solution Cases

If the absolute value is set equal to a negative number, there is no solution:

Example 3: No Solution

Solve: \(|x + 2| = -5\)

Solution:

Since absolute value is always non-negative, \(|x + 2| \geq 0\)

No solution

4. Reciprocal Functions

A reciprocal function is a function of the form \(f(x) = \frac{1}{x}\) or transformations thereof.

Definition: The reciprocal function \(f(x) = \frac{1}{x}\) has a vertical asymptote at \(x = 0\) and a horizontal asymptote at \(y = 0\).

4.1 General Form of Reciprocal Functions

\[f(x) = \frac{a}{x - h} + k\]

Where:

  • Vertical asymptote: \(x = h\)
  • Horizontal asymptote: \(y = k\)

4.2 Transformations of Reciprocal Functions

The basic reciprocal function \(f(x) = \frac{1}{x}\) can be transformed:

  • Vertical stretch/compression: \(|a| > 1\) stretches, \(0 < |a| < 1\) compresses
  • Reflection: If \(a < 0\), reflects across x-axis
  • Horizontal shift: \(h\) units right if \(h > 0\), left if \(h < 0\)
  • Vertical shift: \(k\) units up if \(k > 0\), down if \(k < 0\)
Example 4: Analyzing Reciprocal Functions

For \(f(x) = \frac{2}{x + 1} - 3\):

Vertical asymptote: \(x = -1\)

Horizontal asymptote: \(y = -3\)

Transformations: Shift left 1, down 3, vertical stretch by 2

4.3 Graphing Reciprocal Functions

To graph a reciprocal function:

  1. Identify the asymptotes
  2. Plot points in each quadrant separated by asymptotes
  3. Sketch the hyperbola branches

5. Summary of Key Concepts

Concept Formula/Definition
Absolute Value \(|x| = x\) if \(x \geq 0\), \(-x\) if \(x < 0\)
Absolute Value Function \(f(x) = a|x - h| + k\)
Solving \(|E| = k\) \(E = k\) or \(E = -k\) (if \(k \geq 0\))
Reciprocal Function \(f(x) = \frac{a}{x - h} + k\)
Vertical Asymptote \(x = h\)
Horizontal Asymptote \(y = k\)

6. Practice Problems

Problem 1

Solve: \(|x - 4| = 9\)

Problem 2

Solve: \(|3x + 2| \leq 8\)

Problem 3

Graph \(f(x) = -|x + 2| + 3\) and identify the vertex and transformations.

Problem 4

For \(f(x) = \frac{3}{x - 2} + 1\), find the asymptotes and describe the transformations from \(y = \frac{1}{x}\).
