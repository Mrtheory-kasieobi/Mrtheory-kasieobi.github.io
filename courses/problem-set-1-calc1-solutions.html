Problem Set 1: Functions - SOLUTIONS

Calculus I - Week 1

Solution Guide

Note: These are detailed solution outlines. Show all work when completing problems.

Problem 1: Find the domain of \(f(x) = \frac{\sqrt{x-3}}{x^2 - 4}\)

Solution:
  1. Denominator cannot be zero: \(x^2 - 4 \neq 0 \Rightarrow x \neq \pm 2\)
  2. Radical requires non-negative: \(x - 3 \geq 0 \Rightarrow x \geq 3\)
  3. Combining: \(x \geq 3\) and \(x \neq 2\) (but 2 is already excluded)
  4. Domain: \([3, \infty)\)

Problem 2: Determine if the graph represents a function

Solution:

Apply the vertical line test: a curve is a function if every vertical line intersects it at most once. If a vertical line crosses the graph more than once, it is NOT a function.

Problem 3: Express the area of a circle as a function of its circumference

Solution:

Given: \(A = \pi r^2\) and \(C = 2\pi r\)

Solve for \(r\): \(r = \frac{C}{2\pi}\)

Substitute: \(A = \pi \left(\frac{C}{2\pi}\right)^2 = \frac{C^2}{4\pi}\)

Therefore: \(A(C) = \frac{C^2}{4\pi}\)

Problem 4: Find the composition \(f \circ g\) where \(f(x) = x^2 + 1\) and \(g(x) = \frac{1}{x}\)

Solution:

\((f \circ g)(x) = f(g(x)) = f\left(\frac{1}{x}\right) = \left(\frac{1}{x}\right)^2 + 1 = \frac{1}{x^2} + 1 = \frac{1 + x^2}{x^2}\)

Problem 5: Find the domain of \(f(x) = \ln(x^2 - 4)\)

Solution:

Logarithm requires positive argument: \(x^2 - 4 > 0\)

\((x-2)(x+2) > 0\)

Solution: \(x < -2\) or \(x > 2\)

Domain: \((-\infty, -2) \cup (2, \infty)\)

Problem 6: If \(f(x) = 2x - 3\) and \(g(x) = x^2\), find \((f \circ g)(x)\) and \((g \circ f)(x)\)

Solution:

\((f \circ g)(x) = f(g(x)) = f(x^2) = 2(x^2) - 3 = 2x^2 - 3\)

\((g \circ f)(x) = g(f(x)) = g(2x-3) = (2x-3)^2 = 4x^2 - 12x + 9\)

Problem 7: Sketch a graph of a function that is even and has domain all real numbers

Solution:

An even function satisfies \(f(-x) = f(x)\). Examples include:

  • \(f(x) = x^2\) (parabola opening upward)
  • \(f(x) = \cos x\) (cosine wave)
  • \(f(x) = |x|\) (absolute value function)

Problem 8: Find the inverse function of \(f(x) = \frac{2x + 1}{x - 3}\)

Solution:

Step 1: Write \(y = \frac{2x + 1}{x - 3}\)

Step 2: Swap \(x\) and \(y\): \(x = \frac{2y + 1}{y - 3}\)

Step 3: Solve for \(y\):

\(x(y - 3) = 2y + 1\)

\(xy - 3x = 2y + 1\)

\(xy - 2y = 3x + 1\)

\(y(x - 2) = 3x + 1\)

\(y = \frac{3x + 1}{x - 2}\)

Therefore: \(f^{-1}(x) = \frac{3x + 1}{x - 2}\)

Problem 9: Express the perimeter of a square as a function of its area

Solution:

Given: \(A = s^2\) and \(P = 4s\)

Solve for \(s\): \(s = \sqrt{A}\)

Substitute: \(P = 4\sqrt{A}\)

Therefore: \(P(A) = 4\sqrt{A}\)

Problem 10: Determine whether \(f(x) = x^3\) is one-to-one. If so, find its inverse

Solution:

Use the Horizontal Line Test: \(f(x) = x^3\) passes (every horizontal line crosses at most once)

Alternatively, show: if \(f(a) = f(b)\), then \(a^3 = b^3 \Rightarrow a = b\)

Since it's one-to-one, find inverse:

\(y = x^3 \Rightarrow x = y^{1/3}\)

Therefore: \(f^{-1}(x) = \sqrt[3]{x}\)

Bonus Problem 1: Function domain and range transformation

Solution:

For \(f(x) = \frac{\sqrt{x-3}}{x^2 - 4}\):

Domain of \(f\): \([3, \infty)\)

Range of \(f\): \((0, \infty)\)

For transformations:

  • \(f(x) + 1\) has domain \([3, \infty)\) and range \((1, \infty)\)
  • \(f(2x)\) has domain \([1.5, \infty)\) and range \((0, \infty)\)

Bonus Problem 2: Prove that if \(f\) is a linear function, then \(f^{-1}\) exists iff slope is non-zero

Solution:

\(f(x) = mx + b\) where \(m, b \in \mathbb{R}\)

If \(m \neq 0\): \(f\) is one-to-one (strictly monotonic), so inverse exists

If \(m = 0\): \(f(x) = b\) (constant function), not one-to-one, no inverse

Therefore: \(f^{-1}\) exists \(\Leftrightarrow\) \(m \neq 0\)
