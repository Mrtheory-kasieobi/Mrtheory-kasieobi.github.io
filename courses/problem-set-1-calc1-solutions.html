Problem Set 1: Functions - SOLUTIONS

Calculus I - Week 1

Solution Guide

Note: These are detailed solutions showing all steps and reasoning. Each step is clearly justified.

Problem 1: Find the domain of \(f(x) = \frac{\sqrt{x-3}}{x^2 - 4}\)

Solution: To find the domain, we need to identify all values of \(x\) for which the function is defined.
Step 1: Analyze the numerator
The numerator contains \(\sqrt{x-3}\). For a square root to be defined in the real numbers, the radicand must be non-negative:
\(x - 3 \geq 0 \Rightarrow x \geq 3\)
Step 2: Analyze the denominator
The denominator \(x^2 - 4\) cannot equal zero because division by zero is undefined.
\(x^2 - 4 = 0 \Rightarrow x^2 = 4 \Rightarrow x = \pm 2\)
Therefore, \(x \neq 2\) and \(x \neq -2\).
Step 3: Combine the constraints
We need both conditions to be satisfied simultaneously:
- From the numerator: \(x \geq 3\)
- From the denominator: \(x \neq 2\) and \(x \neq -2\)
Since \(x \geq 3\) already excludes both \(x = 2\) and \(x = -2\) (as \(2 < 3\) and \(-2 < 3\)), the only constraint is \(x \geq 3\).
Final Answer:
The domain is \([3, \infty)\), written in interval notation.

Problem 2: Determine if the graph represents a function

Solution:
Step 1: Apply the Vertical Line Test
A set of points in the plane represents the graph of a function if and only if every vertical line intersects the graph in at most one point.
Step 2: Reasoning
If a vertical line \(x = a\) intersects the graph at two or more points \((a, y_1), (a, y_2), \ldots\) with \(y_1 \neq y_2\), then the relation assigns multiple outputs to the same input \(a\), which violates the definition of a function.
Step 3: Conclusion
- If every vertical line crosses the graph at most once: the graph represents a function.
- If some vertical line crosses at two or more points: the graph does NOT represent a function.

Problem 3: Express the area of a circle as a function of its circumference

Solution:
Step 1: Write the known formulas
Area of a circle: \(A = \pi r^2\)
Circumference of a circle: \(C = 2\pi r\)
Step 2: Solve for \(r\) in terms of \(C\)
From \(C = 2\pi r\), we get:
\(r = \frac{C}{2\pi}\)
Step 3: Substitute into the area formula
\(A = \pi r^2 = \pi \left(\frac{C}{2\pi}\right)^2 = \pi \cdot \frac{C^2}{4\pi^2} = \frac{C^2}{4\pi}\)
Step 4: State the function
The area as a function of the circumference is:
\(A(C) = \frac{C^2}{4\pi}\)

Problem 4: Find the composition \(f \circ g\) where \(f(x) = x^2 + 1\) and \(g(x) = \frac{1}{x}\)

Solution:
Step 1: Understand composition notation
\((f \circ g)(x) = f(g(x))\) means we substitute \(g(x)\) into \(f\).
Step 2: Substitute \(g(x)\) into \(f\)
\(f(g(x)) = f\left(\frac{1}{x}\right) = \left(\frac{1}{x}\right)^2 + 1\)
Step 3: Simplify
\(\left(\frac{1}{x}\right)^2 + 1 = \frac{1}{x^2} + 1 = \frac{1 + x^2}{x^2}\)
Final Answer:
\((f \circ g)(x) = \frac{1 + x^2}{x^2}\), with domain \(x \neq 0\).

Problem 5: Find the domain of \(f(x) = \ln(x^2 - 4)\)

Solution:
Step 1: Condition for logarithm
The natural logarithm \(\ln(u)\) is defined only when \(u > 0\) (the argument must be strictly positive).
Step 2: Set up the inequality
We need \(x^2 - 4 > 0\).
Step 3: Factor and solve
\(x^2 - 4 = (x-2)(x+2)\)
We need \((x-2)(x+2) > 0\).
The product of two factors is positive when both are positive or both are negative.
Step 4: Create sign chart
| Interval | \(x+2\) | \(x-2\) | Product | |----------|---------|---------|---------| | \(x < -2\) | \(-\) | \(-\) | \(+\) | | \(-2 < x < 2\) | \(+\) | \(-\) | \(-\) | | \(x > 2\) | \(+\) | \(+\) | \(+\) |
Step 5: State the domain
The inequality \((x-2)(x+2) > 0\) is satisfied when \(x < -2\) or \(x > 2\).
Domain: \((-\infty, -2) \cup (2, \infty)\)

Problem 6: If \(f(x) = 2x - 3\) and \(g(x) = x^2\), find \((f \circ g)(x)\) and \((g \circ f)(x)\)

Solution:
Step 1: Find \((f \circ g)(x) = f(g(x))\)
Substitute \(g(x) = x^2\) into \(f\):
\(f(g(x)) = f(x^2) = 2(x^2) - 3 = 2x^2 - 3\)
Step 2: Find \((g \circ f)(x) = g(f(x))\)
Substitute \(f(x) = 2x - 3\) into \(g\):
\(g(f(x)) = g(2x - 3) = (2x - 3)^2\)
Expand: \((2x - 3)^2 = 4x^2 - 12x + 9\)
Step 3: Compare the results
\((f \circ g)(x) = 2x^2 - 3\)
\((g \circ f)(x) = 4x^2 - 12x + 9\)
Since the results are different, function composition is NOT commutative.

Problem 7: Sketch a graph of a function that is even and has domain all real numbers

Solution:
Step 1: Recall the definition of an even function
A function \(f\) is even if \(f(-x) = f(x)\) for all \(x\) in the domain.
Step 2: Properties of even functions
- The graph is symmetric with respect to the y-axis.
- If \((a, b)\) is on the graph, then \((-a, b)\) is also on the graph.
Step 3: Provide examples
Common examples of even functions with domain \(\mathbb{R}\):
1. \(f(x) = x^2\) (parabola opening upward)
2. \(f(x) = \cos x\) (cosine wave)
3. \(f(x) = |x|\) (absolute value function)
4. \(f(x) = x^4 - 2x^2 + 1\) (even polynomial)

Problem 8: Find \(f^{-1}(x)\) for \(f(x) = \frac{2x + 1}{x - 3}\)

Solution:
Step 1: Replace \(f(x)\) with \(y\)
\(y = \frac{2x + 1}{x - 3}\)
Step 2: Swap \(x\) and \(y\)
\(x = \frac{2y + 1}{y - 3}\)
This step is valid because if \(y = f(x)\), then \(x = f^{-1}(y)\), and we're solving for the inverse.
Step 3: Solve for \(y\)
Multiply both sides by \((y - 3)\):
\(x(y - 3) = 2y + 1\)
Expand: \(xy - 3x = 2y + 1\)
Collect terms with \(y\): \(xy - 2y = 3x + 1\)
Factor: \(y(x - 2) = 3x + 1\)
Divide: \(y = \frac{3x + 1}{x - 2}\)
Step 4: Write the inverse function
\(f^{-1}(x) = \frac{3x + 1}{x - 2}\)

Problem 9: Express the perimeter of a square as a function of its area

Solution:
Step 1: Define variables and formulas
Let \(s\) = side length of the square.
Area: \(A = s^2\)
Perimeter: \(P = 4s\)
Step 2: Solve for \(s\) in terms of \(A\)
From \(A = s^2\), we get \(s = \sqrt{A}\) (taking the positive root since length is non-negative).
Step 3: Substitute into perimeter formula
\(P = 4s = 4\sqrt{A}\)
Step 4: State the function
\(P(A) = 4\sqrt{A}\), valid for \(A > 0\).

Problem 10: Determine whether \(f(x) = x^3\) is one-to-one. If so, find its inverse

Solution:
Step 1: Apply the Horizontal Line Test
A function is one-to-one if every horizontal line intersects its graph at most once.
Step 2: Algebraic verification
A function \(f\) is one-to-one if \(f(a) = f(b)\) implies \(a = b\).
Suppose \(f(a) = f(b)\), i.e., \(a^3 = b^3\).
Taking cube roots: \(a = b\). Therefore, \(f\) is one-to-one.
Step 3: Find the inverse function
Set \(y = x^3\) and solve for \(x\):
\(y = x^3 \Rightarrow x = y^{1/3} = \sqrt[3]{y}\)
Therefore: \(f^{-1}(x) = \sqrt[3]{x}\)
Step 4: Verify (optional)
Check: \(f(f^{-1}(x)) = f(\sqrt[3]{x}) = (\sqrt[3]{x})^3 = x\) ✓
Check: \(f^{-1}(f(x)) = f^{-1}(x^3) = \sqrt[3]{x^3} = x\) ✓

Bonus Problem 1: Find the domain and range of \(f(x) = \frac{\sqrt{x-3}}{x^2 - 4}\)

Solution:
Step 1: Domain (from Problem 1)
Domain: \([3, \infty)\)
Step 2: Find the range
For \(x \in [3, \infty)\):
- \(\sqrt{x-3} \geq 0\) and increases from 0 to \(\infty\)
- \(x^2 - 4 > 0\) and increases from 5 to \(\infty\)
- The function \(f(x) = \frac{\sqrt{x-3}}{x^2-4}\) is continuous on \([3, \infty)\).
Step 3: Evaluate at endpoints
- At \(x = 3\): \(f(3) = \frac{0}{5} = 0\)
- As \(x \to \infty\): Both numerator and denominator grow without bound, but the denominator grows faster (quadratically vs. square root). Thus \(f(x) \to 0\).
Step 4: Find maximum value
Using calculus or numerical methods, the function reaches a maximum at approximately \(x \approx 4.3\) with \(f(x) \approx 0.18\).
Therefore, the range is \((0, \text{maximum value}]\).

Bonus Problem 2: Prove that if \(f\) is differentiable, then \(f\) is continuous

Solution:
Step 1: Recall definitions
- \(f\) is differentiable at \(a\) if \(\lim_{h \to 0} \frac{f(a+h) - f(a)}{h}\) exists.
- \(f\) is continuous at \(a\) if \(\lim_{x \to a} f(x) = f(a)\).
Step 2: Show continuity using the derivative definition
We want to show: \(\lim_{x \to a} f(x) = f(a)\).
Let \(x = a + h\). As \(x \to a\), we have \(h \to 0\).
\(f(x) = f(a+h) = f(a) + [f(a+h) - f(a)]\)
\(= f(a) + h \cdot \frac{f(a+h) - f(a)}{h}\)
Step 3: Take the limit
\(\lim_{x \to a} f(x) = \lim_{h \to 0} \left[f(a) + h \cdot \frac{f(a+h) - f(a)}{h}\right]\)
\(= f(a) + \lim_{h \to 0} \left[h \cdot \frac{f(a+h) - f(a)}{h}\right]\)
\(= f(a) + \lim_{h \to 0} h \cdot \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}\)
\(= f(a) + 0 \cdot f'(a) = f(a)\)
Conclusion:
Since \(\lim_{x \to a} f(x) = f(a)\), the function \(f\) is continuous at \(a\).
