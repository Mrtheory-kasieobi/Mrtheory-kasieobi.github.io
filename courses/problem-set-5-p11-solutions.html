Solutions: Problem Set 5

Quadratic Equations - Precalculus 11
Solution 1
Problem: Solve by factoring: \(x^2 - 7x + 12 = 0\)
Factor: \((x - 3)(x - 4) = 0\)
Set each factor to zero: \(x - 3 = 0\) or \(x - 4 = 0\)
Solutions: \(x = 3\) or \(x = 4\): Check: \(3^2 - 7(3) + 12 = 0\) ✓ and \(4^2 - 7(4) + 12 = 0\) ✓
Solution 2
Problem: Solve by completing the square: \(x^2 + 8x + 10 = 0\)
Move constant: \(x^2 + 8x = -10\)
Complete the square: \(x^2 + 8x + 16 = -10 + 16\)
\((x + 4)^2 = 6\)
Take square root: \(x + 4 = \pm\sqrt{6}\)
Solution: \(x = -4 \pm \sqrt{6}\)
Solution 3
Problem: Solve using the quadratic formula: \(3x^2 - 5x - 2 = 0\). Give exact and approximate answers.
Identify: \(a = 3, b = -5, c = -2\)
Apply quadratic formula: \(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\)
Calculate discriminant: \(b^2 - 4ac = 25 + 24 = 49\)
\(x = \frac{5 \pm \sqrt{49}}{6} = \frac{5 \pm 7}{6}\)
Exact: \(x = 2\) or \(x = -\frac{1}{3}\)
Approximate: \(x = 2.000\) or \(x = -0.333\)
Solution 4
Problem: Find the discriminant and determine the nature of roots: \(2x^2 - 4x + 5 = 0\)
Identify: \(a = 2, b = -4, c = 5\)
Discriminant: \(D = b^2 - 4ac = 16 - 40 = -24\)
Since \(D < 0\), there are two complex conjugate roots (no real solutions)
\(\text{Roots: } x = \frac{4 \pm i\sqrt{24}}{4} = 1 \pm \frac{i\sqrt{6}}{2}\)
Solution 5
Problem: Solve by square root method: \(4x^2 = 64\)
Divide by 4: \(x^2 = 16\)
Take square root: \(x = \pm\sqrt{16}\)
Solution: \(x = \pm 4\)
Check: \(4(\pm 4)^2 = 64\) ✓
Solution 6
Problem: A ball is thrown upward with height \(h(t) = -16t^2 + 64t + 5\). Find when it hits the ground.
Set height to zero: \(-16t^2 + 64t + 5 = 0\)
Solve using quadratic formula with \(a = -16, b = 64, c = 5\)
\(t = \frac{-64 \pm \sqrt{4096 + 320}}{-32} = \frac{-64 \pm \sqrt{4416}}{-32}\)
\(\sqrt{4416} \approx 66.45\)
\(t \approx \frac{-64 + 66.45}{-32} \approx -0.076\) (not valid) or \(t \approx \frac{-64 - 66.45}{-32} \approx 4.08\) seconds
\(\boxed{t \approx 4.1 \text{ seconds}}\)
Solution 7
Problem: A rectangular garden has area 84 m². The length is 2 m more than the width. Find the dimensions.
Let width = \(w\), length = \(w + 2\)
Area equation: \(w(w + 2) = 84\)
Expand: \(w^2 + 2w - 84 = 0\)
Factor: \((w + 10)(w - 8) = 0\)
\(w = -10\) (reject) or \(w = 8\)
Dimensions: width = 8 m, length = 10 m
Check: \(8 \times 10 = 80\) ✗ - Re-check: \(w = -10\): \(w^2 + 2w - 84 = 100 - 20 - 84 = -4 \neq 0\)
Correct factoring: \(w^2 + 2w - 84 = (w + 10)(w - 8)\)
Answer: width = 8 m, length = 10 m
Solution 8
Problem: Graph the parabola \(y = x^2 - 4x - 5\). Find the vertex, axis of symmetry, and x-intercepts.
Complete square for vertex: \(y = x^2 - 4x + 4 - 4 - 5 = (x-2)^2 - 9\)
Vertex: \((2, -9)\)
Axis of symmetry: \(x = 2\)
x-intercepts: set \(y = 0\): \(x^2 - 4x - 5 = 0\)
Factor: \((x-5)(x+1) = 0\)
x-intercepts: \((5, 0)\) and \((-1, 0)\)

Bonus Solutions

Bonus Solution 1
Problem: Find k such that \(x^2 + 6x + k = 0\) has exactly one solution, then use that value to find all real solutions of \(x^2 + 6x + 9 = 0\)
For one solution: discriminant = 0
\(b^2 - 4ac = 0\) → \(36 - 4k = 0\)
Solve: \(k = 9\)
Now solve \(x^2 + 6x + 9 = 0\) with \(k = 9\)
Factor: \((x + 3)^2 = 0\)
Solution: \(x = -3\) (double root)
Bonus Solution 2
Problem: A negative number and its reciprocal sum to 2. Find the number. Then solve \(y^2 + 2y - 8 = 0\) using an appropriate substitution.
Let the number be \(x\) (negative)
Set up equation: \(x + \frac{1}{x} = 2\)
Multiply by \(x\): \(x^2 + 1 = 2x\)
Rearrange: \(x^2 - 2x + 1 = 0\)
Factor: \((x-1)^2 = 0\)
Solution: \(x = 1\), but this is positive - we need negative, so no valid solution in reals
For second part: substitute \(y = z - 1\) in \(y^2 + 2y - 8 = 0\)
Get \(z^2 - 9 = 0\), so \(z = \pm 3\)
Thus \(y = 2\) or \(y = -4\)
