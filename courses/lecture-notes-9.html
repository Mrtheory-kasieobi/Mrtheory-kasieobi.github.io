Lecture 9: Gaussian Integers - Definition and Arithmetic

Lecture 9Gaussian Integers - Definition and Arithmetic

1. Definition of Gaussian Integers

Definition 9.1 (Gaussian Integers) The ring of Gaussian integers is: \[\mathbb{Z}[i] = \{a + bi : a, b \in \mathbb{Z}\}\] where \(i = \sqrt{-1}\) is the imaginary unit.
Example 9.1 Some Gaussian integers are: \[0, 1, -1, i, -i, 1+i, 2-i, 3+4i, \ldots\]

Addition: \((1 + 2i) + (3 - i) = 4 + i\)

Multiplication: \((1 + 2i)(3 - i) = 3 - i + 6i - 2i^2 = 3 + 5i + 2 = 5 + 5i\)

2. The Norm Function

Definition 9.2 (Norm) For \(\alpha = a + bi \in \mathbb{Z}[i]\), the norm of \(\alpha\) is: \[N(\alpha) = N(a + bi) = a^2 + b^2 = \alpha \bar{\alpha}\] where \(\bar{\alpha} = a - bi\) is the complex conjugate.
Theorem 9.1 (Properties of the Norm) Let \(\alpha, \beta \in \mathbb{Z}[i]\).
  1. \(N(\alpha) \in \mathbb{Z}_{\geq 0}\) and \(N(\alpha) = 0\) iff \(\alpha = 0\).
  2. \(N(\alpha\beta) = N(\alpha)N(\beta)\).
  3. \(N(\alpha) = |\alpha|^2\) (square of the complex absolute value).
Proof of (1):
Step 1: Check non-negativity

\(N(a + bi) = a^2 + b^2 \geq 0\) since squares are non-negative. \(\square\)

Step 2: Check when norm is zero

\(N(a + bi) = 0\) iff \(a^2 + b^2 = 0\) iff \(a = b = 0\) (since \(a^2, b^2 \geq 0\)).

Thus \(N(\alpha) = 0\) iff \(\alpha = 0\). \(\square\)

Proof of (2):
Step 1: Use the definition of norm

\(N(\alpha\beta) = (\alpha\beta)(\overline{\alpha\beta}) = (\alpha\beta)(\bar{\alpha}\bar{\beta})\)

Step 2: Rearrange the product

\((\alpha\beta)(\bar{\alpha}\bar{\beta}) = (\alpha\bar{\alpha})(\beta\bar{\beta}) = N(\alpha)N(\beta)\). \(\square\)

3. Units in \(\mathbb{Z}[i]\)

Definition 9.3 (Unit) A unit in \(\mathbb{Z}[i]\) is an element \(\varepsilon\) such that there exists \(\delta \in \mathbb{Z}[i]\) with \(\varepsilon\delta = 1\).
Theorem 9.2 The units in \(\mathbb{Z}[i]\) are \(\{\pm 1, \pm i\}\).
Proof:
Step 1: Forward direction - if ε is a unit, then N(ε) = 1

If \(\varepsilon = a + bi\) is a unit, then \(\varepsilon\delta = 1\) for some \(\delta\).

Taking norms: \(N(\varepsilon)N(\delta) = N(1) = 1\).

Since \(N(\varepsilon), N(\delta) \in \mathbb{Z}_{\geq 0}\), we must have \(N(\varepsilon) = N(\delta) = 1\).

Step 2: Find all elements with norm 1

Thus \(a^2 + b^2 = 1\) with \(a, b \in \mathbb{Z}\).

Since \(a^2 \geq 0\) and \(b^2 \geq 0\), we need:

  • \(a^2 = 1, b^2 = 0\): gives \(a = \pm 1, b = 0\), so \(\varepsilon = \pm 1\)
  • \(a^2 = 0, b^2 = 1\): gives \(a = 0, b = \pm 1\), so \(\varepsilon = \pm i\)

Therefore the units are \(\varepsilon = \pm 1\) and \(\varepsilon = \pm i\).

Step 3: Reverse direction - verify these are units

Verify: \[1 \cdot 1 = 1, \quad (-1) \cdot (-1) = 1, \quad i \cdot (-i) = 1, \quad (-i) \cdot i = 1\] So all four are units. \(\square\)

4. Division Algorithm in \(\mathbb{Z}[i]\)

Theorem 9.3 (Division Algorithm for \(\mathbb{Z}[i]\)) Let \(\alpha, \beta \in \mathbb{Z}[i]\) with \(\beta \neq 0\). Then there exist \(\gamma, \delta \in \mathbb{Z}[i]\) such that: \[\alpha = \beta\gamma + \delta \quad \text{with} \quad N(\delta) < N(\beta).\]
Proof:
Step 1: Work in the complex numbers

Consider \(\frac{\alpha}{\beta} = x + yi \in \mathbb{Q}(i)\) for some \(x, y \in \mathbb{Q}\).

Step 2: Round to nearest Gaussian integer

Choose integers \(m, n\) such that \(|x - m| \leq \frac{1}{2}\) and \(|y - n| \leq \frac{1}{2}\). Set \(\gamma = m + ni \in \mathbb{Z}[i]\).

Step 3: Define the remainder

Define \(\delta = \alpha - \beta\gamma\). We need to show \(N(\delta) < N(\beta)\).

Step 4: Express δ in terms of the norm

Let \(\frac{\alpha}{\beta} = x + yi\). Then: \[\delta = \beta\left(\frac{\alpha}{\beta} - \gamma\right) = \beta\left((x-m) + (y-n)i\right)\] Therefore: \[N(\delta) = N(\beta) \cdot N\left((x-m) + (y-n)i\right) = N(\beta) \cdot \left((x-m)^2 + (y-n)^2\right)\]

Step 5: Bound the error term

Since \(|x - m| \leq \frac{1}{2}\) and \(|y - n| \leq \frac{1}{2}\): \[(x-m)^2 + (y-n)^2 \leq \frac{1}{4} + \frac{1}{4} = \frac{1}{2} < 1\]

Step 6: Conclude

Thus \(N(\delta) < N(\beta)\). \(\square\)

5. Arithmetic in \(\mathbb{Z}[i]\)

Example 9.2 Compute \((2 + 3i)(1 - i)\).

\((2 + 3i)(1 - i) = 2 - 2i + 3i - 3i^2 = 2 + i + 3 = 5 + i\)

\(N(5 + i) = 25 + 1 = 26\).

Example 9.3 Find the inverse of \(2 + i\) in \(\mathbb{Z}[i]\) (if it exists).
Step 1: Check if inverse exists

An inverse exists in \(\mathbb{Q}(i)\) for any non-zero element.

Step 2: Compute the inverse

\(\frac{1}{2+i} = \frac{2-i}{(2+i)(2-i)} = \frac{2-i}{4+1} = \frac{2-i}{5} = \frac{2}{5} - \frac{1}{5}i\)

This is not in \(\mathbb{Z}[i]\), so \(2 + i\) is not a unit.

Example 9.4 Find \(\gcd(2 + 3i, 1 + i)\) in \(\mathbb{Z}[i]\).
Step 1: Apply Euclidean algorithm

Divide \(2 + 3i\) by \(1 + i\): \[\frac{2 + 3i}{1 + i} = \frac{(2 + 3i)(1 - i)}{(1 + i)(1 - i)} = \frac{2 - 2i + 3i + 3}{2} = \frac{5 + i}{2} = \frac{5}{2} + \frac{1}{2}i\]

Step 2: Round to nearest Gaussian integer

Nearest Gaussian integer to \(\frac{5}{2} + \frac{1}{2}i\) is \(2 + 0i = 2\).

Step 3: Compute remainder

\((2 + 3i) - 2(1 + i) = 2 + 3i - 2 - 2i = i\)

Step 4: Continue with (1+i) and i

\(\frac{1+i}{i} = \frac{(1+i)(-i)}{i(-i)} = \frac{-i - i^2}{1} = -i + 1 = 1 - i\)

So \((1 + i) = (1 - i) \cdot i + 0\)

Therefore \(\gcd(2 + 3i, 1 + i) = i\) (or any associate).

Exercises:
  1. Compute \(N(3+4i)\), \(N(2-i)\), \(N(-1+2i)\).
  2. Show that \(1 + i\) is irreducible in \(\mathbb{Z}[i]\).
  3. Find \(\gcd(2 + 3i, 1 + i)\) in \(\mathbb{Z}[i]\).
  4. Show that 5 is not irreducible in \(\mathbb{Z}[i]\) by finding a non-trivial factorization.
  5. Prove: In \(\mathbb{Z}[i]\), \(N(\alpha)\) is a prime in \(\mathbb{Z}\) iff \(\alpha\) is irreducible.
  6. Determine whether \(2 + i\) is irreducible in \(\mathbb{Z}[i]\).
  7. Verify that \(\mathbb{Z}[i]\) is closed under addition, subtraction, and multiplication.
  8. Find all units in \(\mathbb{Z}[i]\) with norm 1.
