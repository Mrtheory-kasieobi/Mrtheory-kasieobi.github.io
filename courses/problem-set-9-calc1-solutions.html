Problem Set 9: Integration Techniques - SOLUTIONS

Calculus I - Week 9

Solution Guide

Note: These are detailed solutions showing all steps and reasoning. Each step is clearly justified.

Problem 1: \(\int \frac{1}{3x + 2} \, dx\)

Solution:
Step 1: Use substitution
Let \(u = 3x + 2\), then \(du = 3dx\) and \(dx = \frac{du}{3}\)
Step 2: Rewrite integral
\(\int \frac{1}{u} \cdot \frac{du}{3} = \frac{1}{3}\int \frac{1}{u} du\)
Step 3: Integrate
\(\frac{1}{3}\ln|u| + C\)
Step 4: Substitute back
\(\frac{1}{3}\ln|3x + 2| + C\)
Final Answer:
\(\boxed{\frac{1}{3}\ln|3x + 2| + C}\)

Problem 2: \(\int x \ln x \, dx\)

Solution:
Step 1: Set up integration by parts
\(u = \ln x\), \(dv = x \, dx\)
Step 2: Find du and v
\(du = \frac{1}{x}dx\), \(v = \frac{x^2}{2}\)
Step 3: Apply formula
\(\int u \, dv = uv - \int v \, du\)
Step 4: Compute
\(\frac{x^2}{2}\ln x - \int \frac{x^2}{2} \cdot \frac{1}{x}dx = \frac{x^2}{2}\ln x - \frac{1}{2}\int x \, dx\)
Step 5: Finish
\(\frac{x^2}{2}\ln x - \frac{x^2}{4} + C = \frac{x^2}{4}(2\ln x - 1) + C\)
Final Answer:
\(\boxed{\frac{x^2}{2}\ln x - \frac{x^2}{4} + C}\)

Problem 3: \(\int \frac{dx}{(x+1)^2}\)

Solution:
Step 1: Use substitution
Let \(u = x + 1\), \(du = dx\)
Step 2: Rewrite integral
\(\int u^{-2} du\)
Step 3: Apply power rule
\(\frac{u^{-1}}{-1} + C = -\frac{1}{u} + C\)
Step 4: Substitute back
\(-\frac{1}{x+1} + C\)
Final Answer:
\(\boxed{-\frac{1}{x+1} + C}\)

Problem 4: \(\int_0^1 \frac{1}{\sqrt{x}} \, dx\)

Solution:
Step 1: Rewrite integrand
\(\frac{1}{\sqrt{x}} = x^{-1/2}\)
Step 2: Integrate
\(\int_0^1 x^{-1/2} dx = \left[\frac{x^{1/2}}{1/2}\right]_0^1 = [2\sqrt{x}]_0^1\)
Step 3: Evaluate
\(2\sqrt{1} - 2\sqrt{0} = 2\)
Final Answer:
\(\boxed{2}\)

Problem 5: \(\int \frac{x}{x^2 + 4} \, dx\)

Solution:
Step 1: Use substitution
Let \(u = x^2 + 4\), \(du = 2x \, dx\), so \(x \, dx = \frac{du}{2}\)
Step 2: Rewrite integral
\(\frac{1}{2}\int \frac{1}{u} du\)
Step 3: Integrate
\(\frac{1}{2}\ln|u| + C\)
Step 4: Substitute back
\(\frac{1}{2}\ln(x^2 + 4) + C\)
Final Answer:
\(\boxed{\frac{1}{2}\ln(x^2 + 4) + C}\)

Problem 6: \(\int_1^e \frac{\ln x}{x} \, dx\)

Solution:
Step 1: Use substitution
Let \(u = \ln x\), \(du = \frac{1}{x}dx\)
Step 2: Change limits
When \(x = 1\): \(u = 0\). When \(x = e\): \(u = 1\)
Step 3: Integrate
\(\int_0^1 u \, du = \frac{u^2}{2}\Big|_0^1 = \frac{1}{2}\)
Final Answer:
\(\boxed{\frac{1}{2}}\)

Problem 7: \(\int \sin^3 x \cos x \, dx\)

Solution:
Step 1: Use substitution
Let \(u = \sin x\), \(du = \cos x \, dx\)
Step 2: Rewrite integral
\(\int u^3 du\)
Step 3: Integrate
\(\frac{u^4}{4} + C\)
Step 4: Substitute back
\(\frac{\sin^4 x}{4} + C\)
Final Answer:
\(\boxed{\frac{\sin^4 x}{4} + C}\)

Problem 8: \(\int \frac{dx}{x \ln x}\) for \(x > 1\)

Solution:
Step 1: Use substitution
Let \(u = \ln x\), \(du = \frac{1}{x}dx\)
Step 2: Rewrite integral
\(\int \frac{1}{u} du\)
Step 3: Integrate
\(\ln|u| + C\)
Step 4: Substitute back
\(\ln(\ln x) + C\) (since \(\ln x > 0\) for \(x > 1\))
Final Answer:
\(\boxed{\ln(\ln x) + C}\)

Problem 9: \(\int_0^{\pi/2} \cos^3 x \, dx\)

Solution:
Step 1: Use identity
\(\cos^3 x = \cos x(1 - \sin^2 x)\)
Step 2: Split integral
\(\int_0^{\pi/2} \cos x \, dx - \int_0^{\pi/2} \cos x \sin^2 x \, dx\)
Step 3: First integral
\([\sin x]_0^{\pi/2} = 1 - 0 = 1\)
Step 4: Second integral with substitution
Let \(u = \sin x\), \(du = \cos x \, dx\)
\(\int_0^1 u^2 du = \frac{u^3}{3}\Big|_0^1 = \frac{1}{3}\)
Step 5: Combine
\(1 - \frac{1}{3} = \frac{2}{3}\)
Final Answer:
\(\boxed{\frac{2}{3}}\)

Problem 10: \(\int \frac{e^x}{e^{2x} + 1} \, dx\)

Solution:
Step 1: Use substitution
Let \(u = e^x\), \(du = e^x dx\)
Step 2: Rewrite integral
\(\int \frac{1}{u^2 + 1} du\)
Step 3: Recognize arctangent form
\(\tan^{-1}u + C\)
Step 4: Substitute back
\(\tan^{-1}(e^x) + C\)
Final Answer:
\(\boxed{\tan^{-1}(e^x) + C}\)

Bonus 1: \(\int \frac{dx}{x \sqrt{x}}\)

Solution:
Step 1: Rewrite integrand
\(\frac{1}{x\sqrt{x}} = \frac{1}{x \cdot x^{1/2}} = x^{-3/2}\)
Step 2: Integrate
\(\int x^{-3/2} dx = \frac{x^{-1/2}}{-1/2} + C = -2x^{-1/2} + C\)
Step 3: Simplify
\(-\frac{2}{\sqrt{x}} + C\)
Final Answer:
\(\boxed{-\frac{2}{\sqrt{x}} + C}\)

Bonus 2: \(\int \frac{dx}{\sqrt{1-x^2}}\)

Solution:
Step 1: Recognize standard form
\(\int \frac{dx}{\sqrt{1-x^2}} = \sin^{-1}x + C\)
Final Answer:
\(\boxed{\sin^{-1}x + C}\)
