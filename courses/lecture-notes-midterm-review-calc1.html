Midterm Review

Calculus I - Week 13

Comprehensive Review Sheet

1. Limits and Continuity

Key Formulas:
  • Limit Laws: \(\lim[f(x) \pm g(x)] = \lim f(x) \pm \lim g(x)\)
  • \(\lim_{x \to a} \frac{f(x)}{g(x)} = \frac{\lim f(x)}{\lim g(x)}\) if \(\lim g(x) \neq 0\)
  • \(\lim_{x \to 0} \frac{\sin x}{x} = 1\)
  • \(\lim_{x \to 0} \frac{1-\cos x}{x} = 0\)
  • \(\lim_{x \to \infty} \frac{\sin x}{x} = 0\)
  • \(\lim_{x \to \infty} (1 + \frac{1}{x})^x = e\)
Example 1.1: Evaluate \(\lim_{x \to 0} \frac{e^x - 1}{x}\).

Using L'Hôpital's Rule (or definition of derivative): \(\lim_{x \to 0} \frac{e^x}{1} = 1\)

2. Derivatives

Basic Derivatives:
  • \(\frac{d}{dx}[x^n] = nx^{n-1}\)
  • \(\frac{d}{dx}[\sin x] = \cos x\)
  • \(\frac{d}{dx}[\cos x] = -\sin x\)
  • \(\frac{d}{dx}[\tan x] = \sec^2 x\)
  • \(\frac{d}{dx}[e^x] = e^x\)
  • \(\frac{d}{dx}[\ln x] = \frac{1}{x}\)
  • \(\frac{d}{dx}[\sin^{-1}x] = \frac{1}{\sqrt{1-x^2}}\)
  • \(\frac{d}{dx}[\tan^{-1}x] = \frac{1}{1+x^2}\)
Example 2.1: Find the derivative of \(f(x) = x^3 \sin(x^2)\).

Using product and chain rules: \(f'(x) = 3x^2 \sin(x^2) + x^3 \cos(x^2) \cdot 2x\)

= \(3x^2 \sin(x^2) + 2x^4 \cos(x^2)\)

3. Chain Rule

Formula 3.1: If \(y = f(g(x))\), then \(\frac{dy}{dx} = f'(g(x)) \cdot g'(x)\)
Example 3.1: Differentiate \(\frac{d}{dx}[\ln(\sin(x^2))]\).

= \(\frac{1}{\sin(x^2)} \cdot \cos(x^2) \cdot 2x = \frac{2x \cos(x^2)}{\sin(x^2)} = 2x \cot(x^2)\)

4. Implicit Differentiation

Formula 4.1: For \(F(x, y) = 0\): \(\frac{dy}{dx} = -\frac{\partial F/\partial x}{\partial F/\partial y}\)
Example 4.1: Find \(\frac{dy}{dx}\) for \(x^2 + y^2 = 25\).

Differentiate: \(2x + 2y\frac{dy}{dx} = 0\)

Result: \(\frac{dy}{dx} = -\frac{x}{y}\)

5. Mean Value Theorem

MVT Statement: If \(f\) is continuous on \([a,b]\) and differentiable on \((a,b)\), then \(\exists c \in (a,b)\) such that: $$f'(c) = \frac{f(b) - f(a)}{b - a}$$

6. Curve Sketching Checklist

Curve Sketching Procedure:
  1. Domain: Where is \(f(x)\) defined?
  2. Intercepts: \(f(0)\) and solve \(f(x) = 0\)
  3. Symmetry: \(f(-x) = f(x)\) (even), \(f(-x) = -f(x)\) (odd)
  4. Asymptotes: Vertical and horizontal/slant
  5. First Derivative: Find critical points, increasing/decreasing
  6. Second Derivative: Concavity, inflection points
  7. Sketch: Combine all information

7. Integration Formulas

Basic Integrals:
  • \(\int x^n \, dx = \frac{x^{n+1}}{n+1} + C\) (for \(n \neq -1\))
  • \(\int \frac{1}{x} \, dx = \ln|x| + C\)
  • \(\int e^x \, dx = e^x + C\)
  • \(\int a^x \, dx = \frac{a^x}{\ln a} + C\)
  • \(\int \sin x \, dx = -\cos x + C\)
  • \(\int \cos x \, dx = \sin x + C\)
  • \(\int \sec^2 x \, dx = \tan x + C\)
  • \(\int \frac{1}{\sqrt{1-x^2}} \, dx = \sin^{-1}x + C\)

8. Fundamental Theorem of Calculus

FTC Part 2: $$\int_a^b f(x) \, dx = F(b) - F(a)$$ where \(F'(x) = f(x)\).

9. Applications of Integration

Area Between Curves: \(\int_a^b |f(x) - g(x)| \, dx\)

Volume (Disk): \(\pi \int_a^b [f(x)]^2 \, dx\)

Volume (Washer): \(\pi \int_a^b ([f(x)]^2 - [g(x)]^2) \, dx\)

Volume (Shell): \(2\pi \int_a^b x \cdot f(x) \, dx\)

Work: \(W = \int_a^b F(x) \, dx\)

10. Common Mistakes to Avoid

Warning Points:
  • Dont forget the chain rule when differentiating composite functions
  • Always check for continuity before applying MVT
  • Don't mix up integration formulas - \(\int \frac{1}{x} = \ln|x| + C\), not \(\ln x\)
  • Remember absolute value in \(\int \frac{1}{x} \, dx\)
  • Don't forget \(dx\) in integration
  • Check your work by differentiating antiderivatives
  • For curve sketching, verify all conditions before stating conclusions
