Problem Set 9: Function Operations

Precalculus 12 - Chapter 9 Solutions

Solutions

Problem 1: Given \(f(x) = x^2 - 1\) and \(g(x) = 2x + 3\), find \(f + g\), \(f - g\), \(fg\), and \(\frac{f}{g}\). State the domain of each.
\(f + g = (x^2 - 1) + (2x + 3) = x^2 + 2x + 2\)
\(f - g = (x^2 - 1) - (2x + 3) = x^2 - 2x - 4\)
\(fg = (x^2 - 1)(2x + 3) = 2x^3 + 3x^2 - 2x - 3\)
\(\frac{f}{g} = \frac{x^2 - 1}{2x + 3}\)
Domain: \(f+g\), \(f-g\), \(fg\) all have domain \(\mathbb{R}\)
\(\frac{f}{g}\): Domain is \(\mathbb{R} \setminus \{-\frac{3}{2}\}\)
Answer: All sums/products above, with domain noted
Problem 2: Find \(f(g(x))\) and \(g(f(x))\) for \(f(x) = \sqrt{x}\) and \(g(x) = x - 4\). State the domain of each composition.
\(f(g(x)) = f(x - 4) = \sqrt{x - 4}\)
Domain of \(f \circ g\): Need \(x - 4 \geq 0\), so \(x \geq 4\)
\(g(f(x)) = g(\sqrt{x}) = \sqrt{x} - 4\)
Domain of \(g \circ f\): Need \(x \geq 0\)
Answer: \(f(g(x)) = \sqrt{x-4}, x \geq 4\); \(g(f(x)) = \sqrt{x}-4, x \geq 0\)
Problem 3: Find the inverse of \(f(x) = \frac{3x - 2}{x + 1}\). Verify by showing \(f^{-1}(f(x)) = x\).
Let \(y = \frac{3x - 2}{x + 1}\)
Cross multiply: \(y(x + 1) = 3x - 2\)
Expand: \(yx + y = 3x - 2\)
Collect: \(yx - 3x = -2 - y\)
Factor: \(x(y - 3) = -2 - y\)
Solve: \(x = \frac{-2 - y}{y - 3} = \frac{2 + y}{3 - y}\)
Inverse: \(f^{-1}(x) = \frac{2 + x}{3 - x}\)
Verification: \(f^{-1}(f(x)) = \frac{2 + \frac{3x-2}{x+1}}{3 - \frac{3x-2}{x+1}} = \frac{\frac{2(x+1) + 3x-2}{x+1}}{\frac{3(x+1) - 3x + 2}{x+1}} = \frac{5x}{5} = x\) ✓
Answer: \(f^{-1}(x) = \frac{x + 2}{3 - x}\)
Problem 4: Graph \(h(x) = |f(x)| - 2\) where \(f(x) = x^2 - 4\). Describe the transformation from the original function.
Original: \(f(x) = x^2 - 4\) is parabola with vertex (0, -4)
Take absolute value: Where \(f(x) < 0\), reflect upward
Find where \(f(x) = 0\): \(x^2 - 4 = 0\), so \(x = \pm 2\)
For \(|x| < 2\): \(f(x) < 0\), so \(|f(x)| = -(x^2 - 4) = 4 - x^2\)
For \(|x| \geq 2\): \(f(x) \geq 0\), so \(|f(x)| = x^2 - 4\)
Then shift down 2: \(h(x) = |f(x)| - 2\)
Answer: V-shaped transformation at x = ±2, shifted down 2 units
Problem 5: Given \(f(x) = e^x\) and \(g(x) = \ln(x)\), find \(f \circ g\) and \(g \circ f\). What do you notice?
\(f \circ g(x) = f(g(x)) = f(\ln(x)) = e^{\ln(x)} = x\) for \(x > 0\)
\(g \circ f(x) = g(f(x)) = g(e^x) = \ln(e^x) = x\) for all real \(x\)
Both compositions equal the identity function!
\(\ln(x)\) and \(e^x\) are inverse functions
Answer: Both equal x. Functions are inverses of each other.
Problem 6: Find all functions that are their own inverse. That is, find \(f(x)\) such that \(f(f(x)) = x\).
Requirement: \(f(f(x)) = x\) for all valid x
Examples:
• \(f(x) = x\) (identity)
• \(f(x) = -x\) (reflection)
• \(f(x) = \frac{1}{x}\) for \(x \neq 0\)
• \(f(x) = c - x\) for constant c
• \(f(x) = \frac{ax + b}{cx - a}\) for appropriate constants
Answer: Identity, negation, reciprocal, and more generally rational functions of form \(\frac{ax+b}{cx-a}\)
Problem 7: If \(f(x) = 2x + 1\) and \(g(x) = x^2\), find \(f(g(f(x)))\). Simplify completely.
Innermost: \(f(x) = 2x + 1\)
Next: \(g(f(x)) = g(2x + 1) = (2x + 1)^2 = 4x^2 + 4x + 1\)
Outermost: \(f(g(f(x))) = f(4x^2 + 4x + 1) = 2(4x^2 + 4x + 1) + 1\)
Expand: \(= 8x^2 + 8x + 2 + 1 = 8x^2 + 8x + 3\)
Answer: \(f(g(f(x))) = 8x^2 + 8x + 3\)
Problem 8: A function is defined as \(h(x) = f(x) \cdot g(x)\) where \(f(x) = x - 2\) and \(g(x) = x + 3\). Find the zeros of h and interpret them.
\(h(x) = (x - 2)(x + 3)\)
Zeros: \(h(x) = 0\) when \(x - 2 = 0\) or \(x + 3 = 0\)
Zeros: \(x = 2\) and \(x = -3\)
Interpretation: These are the x-intercepts of the product function
Also the zeros of the individual functions f and g
Answer: Zeros at x = 2 and x = -3, where either f or g equals zero

Bonus Solutions

Bonus Problem 1: If \(f(x) = \frac{1}{x}\) and \(g(x) = x - 4\), find a formula for \(h(x) = f(g(f(x)))\). State the domain of \(h\).
Innermost: \(f(x) = \frac{1}{x}\)
Next: \(g(f(x)) = g\left(\frac{1}{x}\right) = \frac{1}{x} - 4\)
Outermost: \(f(g(f(x))) = f\left(\frac{1}{x} - 4\right) = \frac{1}{\frac{1}{x} - 4}\)
Simplify: \(= \frac{1}{\frac{1 - 4x}{x}} = \frac{x}{1 - 4x}\)
Domain: Need \(x \neq 0\) (for inner f) and \(\frac{1}{x} - 4 \neq 0\) (for outer f)
Second condition: \(\frac{1}{x} \neq 4\), so \(x \neq \frac{1}{4}\)
Answer: \(h(x) = \frac{x}{1 - 4x}\), Domain: \(\mathbb{R} \setminus \{0, \frac{1}{4}\}\)
Bonus Problem 2: Prove that if \(f\) and \(g\) are both one-to-one functions, then \(f \circ g\) is also one-to-one. What can you say about \((f \circ g)^{-1}\)?
To prove one-to-one: if \(f(g(a)) = f(g(b))\), then \(a = b\)
Given: \(f(g(a)) = f(g(b))\)
Since \(f\) is one-to-one: \(g(a) = g(b)\)
Since \(g\) is one-to-one: \(a = b\)
Therefore, \(f \circ g\) is one-to-one
For inverse: \((f \circ g)^{-1} = g^{-1} \circ f^{-1}\)
Answer: \(f \circ g\) is one-to-one, \((f \circ g)^{-1} = g^{-1} \circ f^{-1}\)
