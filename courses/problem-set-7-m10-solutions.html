Problem Set 7 Solutions: Systems of Linear Equations

Mathematics 10 - Chapter 7

Solutions

Solution 1

Substitute: \(3x + (2x + 1) = 10\)

\(5x = 9\), so \(x = \frac{9}{5}\)

\(y = 2(\frac{9}{5}) + 1 = \frac{19}{5}\)

Solution: \((\frac{9}{5}, \frac{19}{5})\)

Solution 2

Add equations: \(6x = 18\), so \(x = 3\)

Substitute: \(2(3) + 3y = 12\), so \(y = 2\)

Solution: \((3, 2)\)

Solution 3

From equations 1 and 2: \(x + 2y = 4\)

From equations 1 and 3: \(2x + y = 10\)

Solve: \(x = 4\), \(y = 3\), \(z = -1\)

Solution 4

Let \(x\) = amount at 4%, \(y\) = amount at 6%

\(x + y = 3000\) and \(0.04x + 0.06y = 150\)

Multiply second by 100: \(4x + 6y = 15000\)

Simplify: \(2x + 3y = 7500\)

Solve: \(x = 1200\), \(y = 1800\)

Solution 5

Set equal: \(x + 2 = -2x + 10\)

\(3x = 8\), so \(x = \frac{8}{3}\)

\(y = \frac{8}{3} + 2 = \frac{14}{3}\)

Intersection: \((\frac{8}{3}, \frac{14}{3})\)

Solution 6

Second equation is 2 times the first, so they represent the same line.

Infinitely many solutions (consistent, dependent).

Solution 7

Multiply first by 6: \(3x + 2y = 12\)

Multiply second by 4: \(x - 4y = -4\)

From second: \(x = 4y - 4\)

Substitute: \(3(4y - 4) + 2y = 12\)

\(14y = 24\), so \(y = \frac{12}{7}\)

\(x = \frac{20}{7}\)

Solution 8

Let \(x + y = 15\) and \(x - y = 3\)

Add: \(2x = 18\), so \(x = 9\)

Substitute: \(9 + y = 15\), so \(y = 6\)

The numbers are 9 and 6.

Bonus Solutions

Bonus Solution 1

Step 1: For a magic square, all rows, columns, and diagonals sum to the same value.

Step 2: If the solution is (1, 2, 3), then substituting into the system gives the sum of each row of coefficients equals the corresponding constant.

Step 3: The sum of all three equations gives: (sum of all coefficients) × (1, 2, 3) = 15

Step 4: For a 3×3 magic square with center c, the sum of all entries is 3c, and the magic sum is 3c.

Step 5: The center coefficient is 5 (using a standard magic square: 2, 7, 6, 9, 5, 1, 4, 3, 8).

Bonus Solution 2

Step 1: Find equations of both lines

Line 1: slope = \(\frac{8-2}{4-1} = 2\), equation: \(y - 2 = 2(x - 1)\) → \(y = 2x\)

Line 2: slope = \(\frac{10-3}{5-2} = \frac{7}{3}\), equation: \(y - 3 = \frac{7}{3}(x - 2)\) → \(y = \frac{7}{3}x - \frac{5}{3}\)

Step 2: Find intersection P: \(2x = \frac{7}{3}x - \frac{5}{3}\)

\(\frac{13}{3}x = -\frac{5}{3}\), so \(x = -\frac{5}{13}\)

\(y = 2(-\frac{5}{13}) = -\frac{10}{13}\)

Intersection P: \((-\frac{5}{13}, -\frac{10}{13})\)

Step 3: Find distances from P to each point and identify closest points

Distance to (1,2): \(\sqrt{(1+\frac{5}{13})^2 + (2+\frac{10}{13})^2} = \sqrt{(\frac{18}{13})^2 + (\frac{36}{13})^2} = \frac{6\sqrt{10}}{13}\)

Distance to (4,8): \(\sqrt{(4+\frac{5}{13})^2 + (8+\frac{10}{13})^2} = \frac{107}{13}\)

Distance to (2,3): \(\sqrt{(2+\frac{5}{13})^2 + (3+\frac{10}{13})^2} = \frac{17}{13}\sqrt{5}\)

Distance to (5,10): \(\sqrt{(5+\frac{5}{13})^2 + (10+\frac{10}{13})^2} = \frac{135}{13}\)

Step 4: The closest points are (1,2) on Line 1 and (2,3) on Line 2

Step 5: Area of triangle = \(\frac{1}{2} \times \text{base} \times \text{height}\)

Using the distance from P to the line through (1,2) and (2,3): Area = \(\frac{1}{2} \times \frac{17\sqrt{5}}{13} \times \frac{6\sqrt{10}}{13} = \frac{51\sqrt{2}}{169}\)
