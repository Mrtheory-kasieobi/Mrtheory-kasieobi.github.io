Problem Set 3: Set Theory: Operations and Identities

Introduction to Proofs - Lecture 3 Medium

Try each problem before reading the solutions. A proof is judged by the completeness of its logical chain, not by how short it is. State your assumptions, justify every nontrivial step, and verify that the conclusion follows exactly.

Problems

Problem 1

Prove that \(A\subseteq B\) if and only if \(\mathcal{P}(A)\subseteq\mathcal{P}(B)\).

Problem 2

Prove \((A\cup B)^c=A^c\cap B^c\) using two inclusions rather than a chain of equivalences.

Problem 3

Let \(A,B,C\) be sets. Prove \(A\cap(B\setminus C)=(A\cap B)\setminus C\).

Problem 4

Find a counterexample to each false claim: (a) \(A\cup B=A\cup C\implies B=C\); (b) \(A imes B=A imes C\implies B=C\) when \(A e\varnothing\).

Problem 5

Let \(A_n=[0,1/n]\) for \(n\in\mathbb{N}=\{1,2,3,\ldots\}\). Compute \(\bigcup_{n=1}^\infty A_n\) and \(\bigcap_{n=1}^\infty A_n\), and justify both answers.

Problem 6

Prove that \(A riangle B=(A\cup B)\setminus(A\cap B)\).

Problem 7

Show that \(A\setminus(B\cap C)=(A\setminus B)\cup(A\setminus C)\) by proving both inclusions.

Problem 8

Let \(I\) be a nonempty index set. Prove \(\bigcap_{i\in I}A_i\subseteq\bigcup_{i\in I}A_i\). What happens if \(I=\varnothing\)?

Bonus Problem

Prove that \(A\times(B\cap C)=(A\times B)\cap(A\times C)\).
