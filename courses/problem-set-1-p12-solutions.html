Problem Set 1: Function Transformations

Precalculus 12 - Chapter 1 Solutions

Solutions

Problem 1: Describe the transformations that map \(f(x) = x^2\) to \(g(x) = -2(x - 3)^2 + 4\). Then find the domain, range, and vertex of \(g(x)\).
Rewrite in vertex form: \(g(x) = -2(x - 3)^2 + 4\)
Transformations from \(f(x) = x^2\): Horizontal shift right 3 units, vertical stretch by factor 2, reflection across x-axis, vertical shift up 4 units
Vertex: \((3, 4)\)
Domain: All real numbers, \(\mathbb{R}\) or \((-\infty, \infty)\)
Range: Since parabola opens downward, \(y \leq 4\), so \((-\infty, 4]\)
Answer: Vertex (3, 4), Domain: \(\mathbb{R}\), Range: \((-\infty, 4]\)
Problem 2: Write the equation of a function that is obtained by reflecting \(f(x) = \sqrt{x}\) across the y-axis, then shifting 2 units up and 3 units to the right.
Reflect across y-axis: \(f(-x) = \sqrt{-x}\)
Shift 3 units right: \(\sqrt{-(x-3)} = \sqrt{3-x}\)
Shift 2 units up: \(\sqrt{3-x} + 2\)
Domain consideration: We need \(3 - x \geq 0\), so \(x \leq 3\)
Answer: \(g(x) = \sqrt{3-x} + 2\) for \(x \leq 3\)
Problem 3: Find the inverse of \(f(x) = \frac{2x - 1}{x + 3}\). State the domain and range of both functions.
Let \(y = \frac{2x - 1}{x + 3}\)
Swap \(x\) and \(y\): \(x = \frac{2y - 1}{y + 3}\)
Solve for \(y\): \(x(y + 3) = 2y - 1\)
Expand: \(xy + 3x = 2y - 1\)
Collect \(y\) terms: \(xy - 2y = -1 - 3x\)
Factor: \(y(x - 2) = -1 - 3x\)
Solve: \(y = \frac{-1 - 3x}{x - 2} = \frac{3x + 1}{2 - x}\)
Original function domain: \(x \neq -3\), range: \(y \neq 2\)
Inverse function domain: \(x \neq 2\), range: \(y \neq 3\)
Answer: \(f^{-1}(x) = \frac{3x + 1}{2 - x}\), Domain of \(f\): \(\mathbb{R} \setminus \{-3\}\), Range of \(f\): \(\mathbb{R} \setminus \{2\}\)
Problem 4: A Ferris wheel has height modeled by \(h(t) = 25\sin(0.2t) + 27\) where \(t\) is in minutes. Find the maximum and minimum heights, and the time for one complete revolution.
Amplitude = 25, vertical shift = 27
Maximum height: \(27 + 25 = 52\) meters
Minimum height: \(27 - 25 = 2\) meters
Period = \(\frac{2\pi}{0.2} = 10\pi\) minutes
Answer: Max = 52m, Min = 2m, Period = \(10\pi\) minutes ≈ 31.4 minutes
Problem 5: Graph \(f(x) = |x - 2| + 1\) by hand. Identify the vertex, domain, range, and any transformations from the parent function \(f(x) = |x|\).
Parent function: \(f(x) = |x|\) has vertex at (0, 0)
Transformations: Horizontal shift right 2 units, vertical shift up 1 unit
New vertex: \((2, 1)\)
Domain: All real numbers, \(\mathbb{R}\)
Range: Since absolute value is non-negative, \(y \geq 1\), so \([1, \infty)\)
Answer: Vertex (2, 1), Domain: \(\mathbb{R}\), Range: \([1, \infty)\)
Problem 6: Given \(f(x) = 3x - 2\) and \(g(x) = x^2 - 1\), find \(f(g(x))\) and \(g(f(x))\). Determine which composition represents a vertical stretch of the original function.
Find \(f(g(x))\): \(f(g(x)) = f(x^2 - 1) = 3(x^2 - 1) - 2 = 3x^2 - 3 - 2 = 3x^2 - 5\)
Find \(g(f(x))\): \(g(f(x)) = g(3x - 2) = (3x - 2)^2 - 1 = 9x^2 - 12x + 4 - 1 = 9x^2 - 12x + 3\)
The composition \(g(f(x)) = 9x^2 - 12x + 3\) has a coefficient of \(x^2\) equal to 9
This represents a vertical stretch by factor 9 compared to \(f(x) = x^2 - 1\)
Answer: \(f(g(x)) = 3x^2 - 5\), \(g(f(x)) = 9x^2 - 12x + 3\). The second composition applies a vertical stretch.
Problem 7: A company's profit is modeled by \(P(x) = -x^3 + 6x^2 - 9x + 4\) where \(x\) is thousands of units. Find the break-even points and interpret them in context.
Break-even occurs when \(P(x) = 0\): \(-x^3 + 6x^2 - 9x + 4 = 0\)
Try rational roots: test \(x = 1\): \(-1 + 6 - 9 + 4 = 0\) ✓
Factor: \((x - 1)(x^2 + 5x - 4) = 0\)? Let's verify: \((x - 1)(-x^2 + 5x - 4)\)
Actually, factor by grouping: \(-x^3 + 6x^2 - 9x + 4 = -(x^3 - 6x^2 + 9x - 4)\)
\(x = 1\) is a root: \((x - 1)(x^2 - 5x + 4) = (x - 1)(x - 1)(x - 4)\)
So \(P(x) = -(x - 1)^2(x - 4)\)
Break-even points: \(x = 1\) (double root) and \(x = 4\) (thousands of units)
Interpretation: The company breaks even at 1,000 units and 4,000 units produced
Answer: Break-even at 1,000 and 4,000 units
Problem 8: Find the domain and range of \(f(x) = \frac{1}{\sqrt{x - 2}} + 3\). Explain why the domain is restricted.
For the square root to be defined: \(x - 2 > 0\), so \(x > 2\)
For the denominator to be non-zero: \(\sqrt{x - 2} \neq 0\), which means \(x \neq 2\)
Combined with first condition: \(x > 2\)
Domain: \((2, \infty)\)
For range: As \(x \to 2^+\), \(\sqrt{x-2} \to 0^+\), so \(f(x) \to +\infty\)
As \(x \to \infty\), \(\sqrt{x-2} \to \infty\), so \(f(x) \to 3^+\)
Range: \((3, \infty)\)
Answer: Domain \((2, \infty)\), Range \((3, \infty)\)

Bonus Solutions

Bonus Problem 1: Given \(f(x) = 2x + 1\) and \(g(x) = x^2 - 3\), find all values of \(a\) such that \(f(g(a)) = g(f(a))\).
Compute \(f(g(a)) = f(a^2 - 3) = 2(a^2 - 3) + 1 = 2a^2 - 6 + 1 = 2a^2 - 5\)
Compute \(g(f(a)) = g(2a + 1) = (2a + 1)^2 - 3 = 4a^2 + 4a + 1 - 3 = 4a^2 + 4a - 2\)
Set equal: \(2a^2 - 5 = 4a^2 + 4a - 2\)
Rearrange: \(0 = 2a^2 + 4a + 3\)
Use quadratic formula: \(a = \frac{-4 \pm \sqrt{16 - 24}}{4} = \frac{-4 \pm \sqrt{-8}}{4}\)
No real solutions since discriminant is negative
Answer: No real values of \(a\) satisfy the equation
Bonus Problem 2: A function has the property that \(f(f(x)) = x\) for all \(x\) in its domain. If \(f(2) = 5\), find \(f(5)\) and \(f(f(2))\). Can you find a general form for such functions?
Given \(f(2) = 5\) and \(f(f(x)) = x\)
Apply \(f\) to both sides of \(f(2) = 5\): \(f(f(2)) = f(5)\)
But \(f(f(2)) = 2\) (by the given property)
Therefore, \(f(5) = 2\)
Such functions are called involutions. Examples include:
• \(f(x) = x\) (identity)
• \(f(x) = -x\) (reflection through origin)
• \(f(x) = \frac{1}{x}\) for \(x \neq 0\)
• \(f(x) = c - x\) for any constant \(c\)
Answer: \(f(5) = 2\). Such functions are called involutions.
