Problem Set 6: Radical Expressions

Precalculus 11 · 8 problems Medium

Problems

Problem 1

Simplify: \(\sqrt{72}\)

Problem 2

Simplify: \(\sqrt[3]{162}\)

Problem 3

Simplify: \(\sqrt{50x^3y^2}\) where \(x, y \geq 0\)

Problem 4

Rationalize the denominator: \(\frac{5}{\sqrt{3}}\)

Problem 5

Solve: \(\sqrt{2x + 3} = 5\)

Problem 6

Solve: \(\sqrt{x + 7} + 2 = 5\)

Problem 7

Expand: \((\sqrt{5} + \sqrt{2})^2\)

Problem 8

Find the perimeter of a square with area 49.

Bonus Problems

Bonus Problem 1 Hard

Solve: \(\sqrt{3x - 2} \cdot \sqrt{x + 4} = 6\). Then simplify \(\sqrt{7 + 4\sqrt{3}} - \sqrt{7 - 4\sqrt{3}}\).

Bonus Problem 2 Hard

Simplify: \(\frac{\sqrt{18} - \sqrt{8}}{\sqrt{2}}\). Hence, find the value of \(\sqrt{12} - \sqrt{3} - \sqrt{2} + \sqrt{6}\).
