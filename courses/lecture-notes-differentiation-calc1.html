Differentiation Rules

Calculus I - Chapter 3.1-3.11

1. Derivatives of Polynomials and Exponential Functions

Basic Differentiation Rules:
  • \(\frac{d}{dx}[c] = 0\) (constant rule)
  • \(\frac{d}{dx}[x^n] = nx^{n-1}\) (power rule)
  • \(\frac{d}{dx}[e^x] = e^x\) (natural exponential)
  • \(\frac{d}{dx}[a^x] = a^x \ln a\) (general exponential)
Example: If \(f(x) = 3x^4 - 2x^2 + 5x - 1\), then \(f'(x) = 12x^3 - 4x + 5\).

2. The Product and Quotient Rules

Product Rule: \((fg)'(x) = f'(x)g(x) + f(x)g'(x)\)
Quotient Rule: \(\left(\frac{f}{g}\right)'(x) = \frac{f'(x)g(x) - f(x)g'(x)}{[g(x)]^2}\)

3. Derivatives of Trigonometric Functions

Trigonometric Derivatives:
  • \(\frac{d}{dx}[\sin x] = \cos x\)
  • \(\frac{d}{dx}[\cos x] = -\sin x\)
  • \(\frac{d}{dx}[\tan x] = \sec^2 x\)
  • \(\frac{d}{dx}[\csc x] = -\csc x \cot x\)
  • \(\frac{d}{dx}[\sec x] = \sec x \tan x\)
  • \(\frac{d}{dx}[\cot x] = -\csc^2 x\)

4. The Chain Rule

Chain Rule: If \(F(x) = f(g(x))\), then \(F'(x) = f'(g(x)) \cdot g'(x)\)
Example: \(\frac{d}{dx}[\sin(3x^2)] = \cos(3x^2) \cdot 6x\)

5. Implicit Differentiation

Implicit Differentiation: When a curve is given by \(F(x,y) = 0\), we differentiate both sides with respect to \(x\), treating \(y\) as a function of \(x\).
Example: For \(x^2 + y^2 = 25\), differentiating gives \(2x + 2y\frac{dy}{dx} = 0\), so \(\frac{dy}{dx} = -\frac{x}{y}\).

6. Related Rates

Related Rates Strategy:
  1. Identify the variables and given rates
  2. Write an equation relating the variables
  3. Differentiate with respect to time
  4. Substitute known values and solve

7. Optimization

Optimization Strategy:
  1. Identify the quantity to maximize/minimize
  2. Express it as a function of one variable
  3. Find critical numbers where \(f'(x) = 0\) or \(f'(x)\) is undefined
  4. Use first or second derivative test to classify
