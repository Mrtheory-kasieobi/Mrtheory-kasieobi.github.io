Derivatives: Definition and Rules

Calculus I - Chapter 3.1-3.4 (Detailed Notes)

1. The Definition of the Derivative

1.1 What is a Derivative?

Derivative at a Point: The derivative of \(f\) at \(a\), denoted \(f'(a)\), is: $$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$ provided this limit exists. Alternative Form: $$f'(a) = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}$$
Geometric Interpretation: The derivative \(f'(a)\) is the slope of the tangent line to the curve \(y = f(x)\) at the point \((a, f(a))\). Physical Interpretation: If \(s(t)\) is position, then \(s'(t)\) is velocity. If \(v(t)\) is velocity, then \(v'(t)\) is acceleration.

1.2 Why the Limit Definition?

Deriving the Definition from the Slope Formula: The slope of a line through two points \((x_1, y_1)\) and \((x_2, y_2)\) is: $$m = \frac{y_2 - y_1}{x_2 - x_1}$$ For a curve \(y = f(x)\) and two points on the curve: - Point 1: \((a, f(a))\) - Point 2: \((a+h, f(a+h))\) for some small \(h\) The slope of the secant line is: $$m_{secant} = \frac{f(a+h) - f(a)}{(a+h) - a} = \frac{f(a+h) - f(a)}{h}$$ As \(h \to 0\), the secant line approaches the tangent line, so: $$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$ ∎

1.3 Differentiability vs Continuity

Theorem: Differentiability Implies Continuity If \(f\) is differentiable at \(a\), then \(f\) is continuous at \(a\).
Proof: Assume \(f\) is differentiable at \(a\), so \(f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}\) exists. We need to show: \(\lim_{x \to a} f(x) = f(a)\) Let \(x = a + h\). As \(x \to a\), \(h \to 0\). We can write: $$f(a+h) - f(a) = \frac{f(a+h) - f(a)}{h} \cdot h$$ Taking limits: $$\lim_{h \to 0} [f(a+h) - f(a)] = \lim_{h \to 0} \left[\frac{f(a+h) - f(a)}{h} \cdot h\right]$$ By the product rule for limits: $$= \lim_{h \to 0} \frac{f(a+h) - f(a)}{h} \cdot \lim_{h \to 0} h = f'(a) \cdot 0 = 0$$ So \(\lim_{h \to 0} f(a+h) = f(a)\), which means \(\lim_{x \to a} f(x) = f(a)\). ∎ Important Note: The converse is FALSE! A function can be continuous but not differentiable.
Example 1.1 - Proof that \(f(x) = x^2\) is differentiable: $$f'(a) = \lim_{h \to 0} \frac{(a+h)^2 - a^2}{h}$$ Expand: \(= \lim_{h \to 0} \frac{a^2 + 2ah + h^2 - a^2}{h}\) Simplify: \(= \lim_{h \to 0} \frac{2ah + h^2}{h}\) Factor: \(= \lim_{h \to 0} \frac{h(2a + h)}{h}\) Cancel: \(= \lim_{h \to 0} (2a + h)\) Evaluate: \(= 2a\) Therefore, \(f'(x) = 2x\) exists for all real \(x\). ∎

2. Basic Differentiation Rules

2.1 Constant Rule

Constant Rule: If \(f(x) = c\) (a constant), then \(f'(x) = 0\).
Proof: $$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h} = \lim_{h \to 0} \frac{c - c}{h} = \lim_{h \to 0} \frac{0}{h} = 0$$ ∎

2.2 Power Rule

Power Rule: If \(f(x) = x^n\) where \(n\) is any real number, then \(f'(x) = nx^{n-1}\).
Proof for positive integer \(n\) (using binomial theorem): $$f'(x) = \lim_{h \to 0} \frac{(x+h)^n - x^n}{h}$$ By the binomial theorem: \((x+h)^n = \sum_{k=0}^{n} \binom{n}{k} x^{n-k} h^k\) So: \((x+h)^n - x^n = \sum_{k=1}^{n} \binom{n}{k} x^{n-k} h^k\) Therefore: $$\frac{(x+h)^n - x^n}{h} = \sum_{k=1}^{n} \binom{n}{k} x^{n-k} h^{k-1}$$ Taking the limit as \(h \to 0\): All terms with \(k > 1\) vanish, leaving only \(k = 1\): $$= \binom{n}{1} x^{n-1} h^0 = nx^{n-1}$$ ∎
Example 2.1 - Using the Power Rule:
  • \(\frac{d}{dx}[x^3] = 3x^2\)
  • \(\frac{d}{dx}[x^5] = 5x^4\)
  • \(\frac{d}{dx}[x^{-2}] = -2x^{-3}\)
  • \(\frac{d}{dx}[\sqrt{x}] = \frac{d}{dx}[x^{1/2}] = \frac{1}{2}x^{-1/2} = \frac{1}{2\sqrt{x}}\)

2.3 Constant Multiple Rule

Constant Multiple Rule: If \(c\) is a constant and \(f\) is differentiable, then: $$\frac{d}{dx}[cf(x)] = c \cdot f'(x)$$
Proof: $$\frac{d}{dx}[cf(x)] = \lim_{h \to 0} \frac{cf(x+h) - cf(x)}{h} = c \lim_{h \to 0} \frac{f(x+h) - f(x)}{h} = c \cdot f'(x)$$ ∎

2.4 Sum and Difference Rules

Sum Rule: $$\frac{d}{dx}[f(x) + g(x)] = f'(x) + g'(x)$$ Difference Rule: $$\frac{d}{dx}[f(x) - g(x)] = f'(x) - g'(x)$$
Proof of Sum Rule: $$\frac{d}{dx}[f(x) + g(x)] = \lim_{h \to 0} \frac{[f(x+h) + g(x+h)] - [f(x) + g(x)]}{h}$$ $$= \lim_{h \to 0} \frac{[f(x+h) - f(x)] + [g(x+h) - g(x)]}{h}$$ $$= \lim_{h \to 0} \left[\frac{f(x+h) - f(x)}{h} + \frac{g(x+h) - g(x)}{h}\right]$$ By the sum law for limits: $$= \lim_{h \to 0} \frac{f(x+h) - f(x)}{h} + \lim_{h \to 0} \frac{g(x+h) - g(x)}{h} = f'(x) + g'(x)$$ ∎

3. Product and Quotient Rules

3.1 Product Rule

Product Rule: $$\frac{d}{dx}[f(x) \cdot g(x)] = f'(x)g(x) + f(x)g'(x)$$

Or in Leibniz notation: \((uv)' = u'v + uv'\)

Proof of the Product Rule: We want to find the derivative of \(f(x)g(x)\). $$[f(x)g(x)]' = \lim_{h \to 0} \frac{f(x+h)g(x+h) - f(x)g(x)}{h}$$ The key trick: Add and subtract \(f(x+h)g(x)\) in the numerator: $$= \lim_{h \to 0} \frac{f(x+h)g(x+h) - f(x+h)g(x) + f(x+h)g(x) - f(x)g(x)}{h}$$ Factor by grouping: $$= \lim_{h \to 0} \left[ f(x+h)\frac{g(x+h) - g(x)}{h} + g(x)\frac{f(x+h) - f(x)}{h} \right]$$ Take the limit: $$= f(x)g'(x) + g(x)f'(x) = f'(x)g(x) + f(x)g'(x)$$ ∎
Example 3.1 - Using the Product Rule: Find \(\frac{d}{dx}[x^2 \sin x]\) Let \(f(x) = x^2\) and \(g(x) = \sin x\) Then \(f'(x) = 2x\) and \(g'(x) = \cos x\) By the product rule: $$\frac{d}{dx}[x^2 \sin x] = 2x \cdot \sin x + x^2 \cdot \cos x = 2x\sin x + x^2\cos x$$

3.2 Quotient Rule

Quotient Rule: $$\frac{d}{dx}\left[\frac{f(x)}{g(x)}\right] = \frac{f'(x)g(x) - f(x)g'(x)}{[g(x)]^2}$$

Memory aid: "Low d-high minus high d-low, over low squared"

where "low" = denominator, "high" = numerator

Proof of the Quotient Rule: Write \(\frac{f}{g} = f \cdot g^{-1}\). We'll use the product rule and chain rule. Let \(h(x) = g(x)^{-1}\). Then \(h'(x) = -g(x)^{-2} \cdot g'(x)\) by the chain rule. Now: \(\frac{d}{dx}[f \cdot g^{-1}] = f' \cdot g^{-1} + f \cdot (g^{-1})'\) $$= f' \cdot \frac{1}{g} + f \cdot \left(-\frac{1}{g^2} \cdot g'\right)$$ $$= \frac{f'}{g} - \frac{f \cdot g'}{g^2} = \frac{f'g - fg'}{g^2}$$ ∎
Example 3.2 - Using the Quotient Rule: Find \(\frac{d}{dx}\left[\frac{x^2}{\sin x}\right]\) Using quotient rule with \(f(x) = x^2\), \(g(x) = \sin x\): $$= \frac{2x \cdot \sin x - x^2 \cdot \cos x}{\sin^2 x} = \frac{2x\sin x - x^2\cos x}{\sin^2 x}$$

4. Notation for Derivatives

Common Notations for the Derivative:
  • \(f'(x)\) - Lagrange notation
  • \(\frac{dy}{dx}\) - Leibniz notation
  • \(\frac{d}{dx}f(x)\) - Operator notation
  • \(Df(x)\) - Euler notation
  • \(y'\) - Newton notation (for time derivatives)
