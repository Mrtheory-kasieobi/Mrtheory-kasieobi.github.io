Solutions: Problem Set 12

Introduction to Proofs - Lecture 12

Key ideas used in these solutions

  • The logical form of a statement dictates the first line of its proof.
  • Existence requires a witness; uniqueness requires comparing two witnesses.
  • Counterexamples disprove universal claims with one concrete case.
  • Proof audits check quantifiers, reversibility of steps, and completeness of cases.

Worked solutions

Problem 1: Prove: for every real number \(x\), if \(x^2-3x+2=0\), then \(x=1\) or \(x=2\).

Let \(x\in\mathbb{R}\) satisfy \(x^2-3x+2=0\). Factoring gives \((x-1)(x-2)=0\). By the zero-product property of \(\mathbb{R}\), \(x-1=0\) or \(x-2=0\), so \(x=1\) or \(x=2\).

Problem 2: Prove that there is no integer \(n\) with \(n^2\equiv2\pmod3\).

Every integer is congruent to \(0,1\), or \(2\) modulo \(3\). Squaring gives residues \(0,1,1\). Thus \(2\) never occurs as a square modulo \(3\), so no such integer exists.

Problem 3: Prove that \(f:\mathbb{R} o\mathbb{R}\), \(f(x)=x^3+x\) is bijective.
Injectivity. If \(a^3+a=b^3+b\), then \((a-b)(a^2+ab+b^2+1)=0\). The second factor equals \((a+b/2)^2+3b^2/4+1>0\), so \(a=b\).
Surjectivity. Let \(y\in\mathbb{R}\). The polynomial \(g(x)=x^3+x-y\) satisfies \(\lim_{x\to-\infty}g(x)=-\infty\) and \(\lim_{x\to+\infty}g(x)=+\infty\). Since polynomials are continuous, the intermediate value theorem gives some \(c\) with \(g(c)=0\), i.e. \(f(c)=y\).

Alternatively, surjectivity can be proved by solving the cubic explicitly, but the continuity argument avoids a complicated formula.

Problem 4: Prove that \(\mathcal{P}(A)\subseteq\mathcal{P}(B)\) if and only if \(A\subseteq B\).
Forward direction. If \(X\in\mathcal{P}(A)\), then \(X\subseteq A\subseteq B\), so \(X\in\mathcal{P}(B)\).
Reverse direction. Assume \(\mathcal{P}(A)\subseteq\mathcal{P}(B)\). Since \(A\subseteq A\), we have \(A\in\mathcal{P}(A)\), hence \(A\in\mathcal{P}(B)\), which means \(A\subseteq B\).

The reverse direction is short but easy to overlook: the set \(A\) itself is one of its own subsets, so it must belong to \(\mathcal{P}(B)\).

Problem 5: Prove that \(\sum_{k=1}^n\frac1{k(k+1)}=\frac{n}{n+1}\) by induction and by telescoping.
Induction. The base case \(n=1\) gives \(1/2=1/2\). Assuming the formula at \(k\), add \(1/((k+1)(k+2))\): \[\frac{k}{k+1}+\frac1{(k+1)(k+2)}=\frac{k(k+2)+1}{(k+1)(k+2)}=\frac{k+1}{k+2}.\]
Telescoping. Since \(\frac1{k(k+1)}=\frac1k-\frac1{k+1}\), the sum is \[\left(1-\frac12\right)+\left(\frac12-\frac13\right)+\cdots+\left(\frac1n-\frac1{n+1}\right)=1-\frac1{n+1}=\frac{n}{n+1}.\]

Two methods can prove the same result; telescoping reveals the structure behind the induction.

Problem 6: Prove that if \(n\ge2\) and \(n\) is not prime, then \(n=ab\) with \(1<a\le b<n\).

Since \(n\) is not prime and \(n\ge2\), there exist integers \(a,b\) with \(n=ab\), \(1<a<n\), and \(1<b<n\). If \(a\le b\), we are done. Otherwise swap the names of \(a\) and \(b\). Then \(1<a\le b<n\), as required.

Problem 7: Prove that the relation \(R\) on \(\mathbb{Z}\) defined by \(aRb\iff a+b\) is even is an equivalence relation, and describe its classes.
Reflexivity. \(a+a=2a\) is even.
Symmetry. \(a+b=b+a\), so evenness is unchanged.
Transitivity. If \(a+b\) and \(b+c\) are even, then \((a+b)+(b+c)=a+c+2b\) is even. Since \(2b\) is even, \(a+c\) is even.
Classes. \(aRb\) holds exactly when \(a\) and \(b\) have the same parity. Hence there are two classes: the even integers and the odd integers.
Problem 8: Prove that if \(m,n\) are integers and \(m\) is odd, then \(mn\) is odd if and only if \(n\) is odd.
Forward (\(\Rightarrow\)). Prove the contrapositive: if \(n\) is even, \(n=2k\), then \(mn=2(mk)\) is even, so \(mn\) cannot be odd.
Reverse (\(\Leftarrow\)). If \(m=2a+1\) and \(n=2b+1\), then \(mn=4ab+2a+2b+1=2(2ab+a+b)+1\), which is odd.

Both directions are necessary for the biconditional; note the different methods used for each.

Problem 9: Prove that there are infinitely many composite positive integers.

For each integer \(n\ge2\), the number \(4n\) is composite because \(4n=2\cdot(2n)\) with both factors greater than \(1\) and less than \(4n\). The map \(n\mapsto4n\) is injective from \(\{2,3,4,\ldots\}\) into the set of composites, so there are infinitely many composites.

Problem 10: Critique this proof: "To show \(\sqrt2\) is irrational, suppose \(\sqrt2=a/b\). Then \(2=a^2/b^2\), so \(2b^2=a^2\). Thus \(a\) is even, say \(a=2k\), and \(b\) is even too. Contradiction."

The proof is incomplete. It does not state that \(a/b\) may be assumed in lowest terms, so "both even" is not yet a contradiction; it only shows that one representation leads to another with a common factor. It also does not justify why \(a\) even forces \(b\) even: substituting \(a=2k\) gives \(2b^2=4k^2\), hence \(b^2=2k^2\), so \(b^2\) and therefore \(b\) are even. With the coprimality assumption stated explicitly and this substitution included, the proof is correct.

Bonus Problem: Audit this claim: “If \(x^2\) is rational, then \(x\) is rational. Indeed, if \(x^2=a/b\), then \(x=\sqrt a/\sqrt b\), which is rational.”
The claim is false. A counterexample is \(x=\sqrt2\): \(x^2=2\) is rational, but \(x\) is irrational. The proof's error is the assertion that \(\sqrt a/\sqrt b\) is rational; square roots of integers need not be rational.
