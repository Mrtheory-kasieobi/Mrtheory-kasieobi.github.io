1. Introduction to Systems of Equations

A system of equations consists of two or more equations with the same variables. The solution is the set of values that satisfy all equations simultaneously.

Definition: A system of linear equations in two variables can have: one unique solution (intersecting lines), no solution (parallel lines), or infinitely many solutions (coincident lines).

2. Solving Systems Graphically

Graphical solution involves plotting both equations on the same coordinate plane and finding the intersection point(s).

2.1 Steps for Graphical Solution

  1. Rewrite each equation in slope-intercept form (\(y = mx + b\))
  2. Graph both lines on the same coordinate plane
  3. Identify the intersection point(s)
  4. Verify the solution in both original equations
Example 1: Graphical Solution

Solve the system: \(\begin{cases} y = 2x + 1 \\ y = -x + 4 \end{cases}\)

Solution:

Graph both lines. They intersect at the point \((1, 3)\).

Check: For \(x = 1\): \(y = 2(1) + 1 = 3\) ✓ and \(y = -1 + 4 = 3\) ✓

Solution: \((1, 3)\)

2.2 Types of Solutions

  • One solution: Lines intersect at one point (different slopes)
  • No solution: Lines are parallel (same slope, different y-intercepts)
  • Infinitely many solutions: Lines are coincident (same slope and y-intercept)

3. Solving Systems Algebraically

3.1 Substitution Method

Solve one equation for one variable, then substitute into the other equation.

Steps:
1. Solve one equation for one variable
2. Substitute into the other equation
3. Solve for the remaining variable
4. Substitute back to find the other variable
5. Check the solution
Example 2: Substitution Method

Solve: \(\begin{cases} x + y = 5 \\ 2x - y = 1 \end{cases}\)

Solution:

Step 1: From equation 1: \(y = 5 - x\)

Step 2: Substitute into equation 2: \(2x - (5 - x) = 1\)

Step 3: Solve: \(2x - 5 + x = 1\)

\(3x = 6\)

\(x = 2\)

Step 4: Substitute back: \(y = 5 - 2 = 3\)

Solution: \((2, 3)\)

3.2 Elimination Method

Add or subtract equations to eliminate one variable.

Steps:
1. Align the equations
2. Multiply if necessary to get opposite coefficients
3. Add or subtract to eliminate one variable
4. Solve for the remaining variable
5. Substitute back to find the other variable
Example 3: Elimination Method

Solve: \(\begin{cases} 3x + 2y = 12 \\ 2x - 2y = 4 \end{cases}\)

Solution:

Add the equations to eliminate \(y\):

\((3x + 2y) + (2x - 2y) = 12 + 4\)

\(5x = 16\)

\(x = \frac{16}{5} = 3.2\)

Substitute back: \(3(3.2) + 2y = 12\)

\(9.6 + 2y = 12\)

\(2y = 2.4\)

\(y = 1.2\)

Solution: \((3.2, 1.2)\)

4. Systems of Linear Equations in Three Variables

A system of three equations in three variables can be solved using substitution or elimination methods extended to three variables.

General Form:
\(\begin{cases} a_1x + b_1y + c_1z = d_1 \\ a_2x + b_2y + c_2z = d_2 \\ a_3x + b_3y + c_3z = d_3 \end{cases}\)
Example 4: Three-Variable System

Solve: \(\begin{cases} x + y + z = 6 \\ 2x - y + z = 3 \\ x + 2y - z = 2 \end{cases}\)

Solution:

Use elimination to reduce to two variables, then solve.

Solution: \((x, y, z) = (1, 2, 3)\)

5. Applications of Systems of Equations

5.1 Word Problems

To solve word problems using systems of equations:

  1. Define variables
  2. Set up equations based on the problem
  3. Solve the system
  4. Interpret the solution in context
Example 5: Mixture Problem

A chemist needs to mix a 20% acid solution with a 40% acid solution to obtain 100 mL of a 30% acid solution. How much of each should be used?

Solution:

Let \(x\) = amount of 20% solution, \(y\) = amount of 40% solution

Equation 1 (total volume): \(x + y = 100\)

Equation 2 (acid content): \(0.20x + 0.40y = 0.30(100)\)

Solving: \(x = 50\) mL, \(y = 50\) mL

6. Summary of Key Concepts

Method When to Use
Graphical To visualize solutions or when approximate answers are acceptable
Substitution When one equation is easily solved for one variable
Elimination When coefficients can be easily eliminated
