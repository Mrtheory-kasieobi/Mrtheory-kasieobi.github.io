Limits and Continuity

Calculus I - Limits, Continuity, Asymptotes, and the Intermediate Value Theorem (Detailed Notes)

Big picture

A limit describes where function values head as the input approaches a point, regardless of what happens at that point itself. This single idea makes precise the notions of "approaching," "continuous," "tangent," and "instantaneous rate of change." Everything that follows in calculus rests on it, so we build it in three layers: intuition, one-sided limits, and the exact epsilon-delta definition.

Road map and prerequisites

Prerequisites: functions, domains, inequalities, and graph reading from the previous note. We will cover:

  1. Intuitive limits and one-sided limits (with the interior-point condition)
  2. The epsilon-delta definition, including a nonlinear example
  3. Limit laws, with precise hypotheses
  4. The squeeze theorem and the fundamental trigonometric limits
  5. Techniques for indeterminate forms; limits at infinity and asymptotes
  6. Continuity, its composition theorem, the Intermediate Value Theorem, and the Extreme Value Theorem
  7. Bonus: the sequential characterization of limits

1. The intuitive idea of a limit

1.1 Approaching a point

We write "the limit of \(f(x)\) as \(x\) approaches \(a\) equals \(L\)" when we can force \(f(x)\) as close to \(L\) as we please by taking \(x\) sufficiently close to \(a\), with \(x \ne a\). The value \(f(a)\) is irrelevant; the input never actually equals \(a\) in the limiting process.

Working definition (informal). \(\lim_{x \to a} f(x) = L\) means the values of \(f(x)\) tend toward \(L\) as \(x\) tends toward \(a\) from either side, without \(x\) ever needing to equal \(a\).
Example 1.1 - A hole in the graph. Let \(f(x) = \frac{x^2 - 1}{x - 1}\).
  1. For \(x \ne 1\), factor: \(f(x) = \frac{(x - 1)(x + 1)}{x - 1} = x + 1\).
  2. As \(x\) approaches \(1\), the values of \(x + 1\) approach \(2\), so \(\lim_{x \to 1} f(x) = 2\).
  3. But \(f(1)\) is undefined, because the original denominator is zero. The limit exists even though the function has a hole at \((1, 2)\).

2. One-sided limits

2.1 Intuition and definitions

Sometimes we care about the approach from just one side. This is essential at endpoints and at jump discontinuities.

Definitions. \[\lim_{x \to a^-} f(x) = L\] means \(f(x)\) tends to \(L\) as \(x\) approaches \(a\) through values with \(x \lt a\). \[\lim_{x \to a^+} f(x) = L\] means \(f(x)\) tends to \(L\) as \(x\) approaches \(a\) through values with \(x \gt a\).
Theorem (two-sided limit and one-sided limits). If \(a\) is an interior point of the domain of \(f\) (that is, \(f\) is defined on an open interval containing \(a\), possibly except at \(a\) itself), then \[\lim_{x \to a} f(x) = L \quad \text{if and only if} \quad \lim_{x \to a^-} f(x) = L \text{ and } \lim_{x \to a^+} f(x) = L.\] Both one-sided limits must exist and be equal. The interior-point hypothesis matters: at an endpoint of the domain only the appropriate one-sided limit can be formed, so the two-sided statement is not meaningful there.
Why the theorem holds. If the two-sided limit is \(L\), then restricting \(x\) to values with \(x \lt a\) or with \(x \gt a\) cannot destroy convergence, so both one-sided limits equal \(L\). Conversely, given \(\varepsilon \gt 0\), the left-hand limit supplies a \(\delta_1 \gt 0\) controlling \(a - \delta_1 \lt x \lt a\), and the right-hand limit supplies a \(\delta_2 \gt 0\) controlling \(a \lt x \lt a + \delta_2\). Taking \(\delta = \min(\delta_1, \delta_2)\) controls every \(x\) with \(0 \lt |x - a| \lt \delta\), which is exactly the two-sided definition.
Example 2.1 - One-sided limits of \(|x|\). \[ |x| = \begin{cases} -x \quad\text{if } x \lt 0,\\ x \quad\text{if } x \ge 0. \end{cases} \]
  1. For \(x \to 0^-\) we have \(x \lt 0\), so \(|x| = -x\) and \(\lim_{x \to 0^-} |x| = 0\).
  2. For \(x \to 0^+\) we have \(x \gt 0\), so \(|x| = x\) and \(\lim_{x \to 0^+} |x| = 0\).
  3. Both one-sided limits equal \(0\), so \(\lim_{x \to 0} |x| = 0\).
Example 2.2 - A jump. Let \(g(x) = \frac{|x|}{x}\) for \(x \ne 0\).
  1. For \(x \gt 0\), \(|x| = x\), so \(g(x) = 1\) and \(\lim_{x \to 0^+} g(x) = 1\).
  2. For \(x \lt 0\), \(|x| = -x\), so \(g(x) = -1\) and \(\lim_{x \to 0^-} g(x) = -1\).
  3. The one-sided limits differ, so \(\lim_{x \to 0} g(x)\) does not exist.

3. The precise definition of a limit

3.1 The epsilon-delta definition

Definition. We say \(\lim_{x \to a} f(x) = L\) if for every \(\varepsilon \gt 0\) there exists a \(\delta \gt 0\) such that \[0 \lt |x - a| \lt \delta \quad \text{implies} \quad |f(x) - L| \lt \varepsilon.\] Here \(\varepsilon\) measures how close we demand \(f(x)\) be to \(L\), and \(\delta\) measures how close \(x\) must be to \(a\). The strict inequality \(0 \lt |x - a|\) excludes \(x = a\), as it must.

3.2 A linear example

Claim: \(\lim_{x \to 2} (3x - 1) = 5\).

Given \(\varepsilon \gt 0\), choose \(\delta = \frac{\varepsilon}{3} \gt 0\). If \(0 \lt |x - 2| \lt \delta\), then

\[|(3x - 1) - 5| = |3x - 6| = 3|x - 2| \lt 3\delta = 3 \cdot \frac{\varepsilon}{3} = \varepsilon.\]

This is exactly the required implication, so the limit is \(5\).

3.3 A nonlinear example

Claim: \(\lim_{x \to 2} x^2 = 4\).

Scratch work. We want \(|x^2 - 4| = |x - 2|\,|x + 2| \lt \varepsilon\). The factor \(|x + 2|\) is troublesome, so we first bound it. Require \(\delta \le 1\). Then \(|x - 2| \lt 1\) gives \(1 \lt x \lt 3\), hence \(|x + 2| \lt 5\). Therefore \(|x^2 - 4| \lt 5|x - 2|\), and it suffices to have \(|x - 2| \lt \frac{\varepsilon}{5}\).

Formal proof. Given \(\varepsilon \gt 0\), set \(\delta = \min\left(1, \frac{\varepsilon}{5}\right) \gt 0\). If \(0 \lt |x - 2| \lt \delta\), then \(|x - 2| \lt 1\), so \(|x + 2| \lt 5\), and also \(|x - 2| \lt \frac{\varepsilon}{5}\). Hence

\[|x^2 - 4| = |x - 2|\,|x + 2| \lt \frac{\varepsilon}{5} \cdot 5 = \varepsilon.\]

Thus \(\lim_{x \to 2} x^2 = 4\). The trick of first imposing \(\delta \le 1\) to control the extra factor is standard for nonlinear limits.

3.4 One-sided epsilon-delta definitions

Definitions.
  • \(\lim_{x \to a^-} f(x) = L\) if for every \(\varepsilon \gt 0\) there is \(\delta \gt 0\) with \(a - \delta \lt x \lt a \implies |f(x) - L| \lt \varepsilon\).
  • \(\lim_{x \to a^+} f(x) = L\) if for every \(\varepsilon \gt 0\) there is \(\delta \gt 0\) with \(a \lt x \lt a + \delta \implies |f(x) - L| \lt \varepsilon\).
Example: a right-hand limit at a square root. Claim: \(\lim_{x \to 0^+} \sqrt{x} = 0\). Given \(\varepsilon \gt 0\), choose \(\delta = \varepsilon^2\). If \(0 \lt x \lt \delta = \varepsilon^2\), then \(|\sqrt{x} - 0| = \sqrt{x} \lt \sqrt{\varepsilon^2} = \varepsilon\). Only the right-hand approach is possible because \(\sqrt{x}\) is defined only for \(x \ge 0\).

4. Limit laws

4.1 Statements with precise hypotheses

Theorem (limit laws). Suppose \(\lim_{x \to a} f(x) = L\) and \(\lim_{x \to a} g(x) = M\), with \(c\) a constant. Then:
  • Constant: \(\lim_{x \to a} c = c\).
  • Identity: \(\lim_{x \to a} x = a\).
  • Sum/difference: \(\lim_{x \to a} \bigl(f(x) \pm g(x)\bigr) = L \pm M\).
  • Product: \(\lim_{x \to a} \bigl(f(x)\,g(x)\bigr) = L M\).
  • Quotient: \(\displaystyle \lim_{x \to a} \frac{f(x)}{g(x)} = \frac{L}{M}\), provided \(M = \lim_{x \to a} g(x) \ne 0\).
  • Integer power: \(\lim_{x \to a} [f(x)]^n = L^n\) for every positive integer \(n\).
  • Integer root: \(\lim_{x \to a} \sqrt[n]{f(x)} = \sqrt[n]{L}\) for a positive integer \(n\), assuming \(L \gt 0\) when \(n\) is even (and \(f(x) \ge 0\) near \(a\) in that case).

The condition \(M \ne 0\) in the quotient law is essential: dividing by a quantity tending to zero is not covered by this law. The root law needs \(L \gt 0\) for even roots because \(\sqrt{L}\) is not real when \(L \lt 0\). For a general real exponent \(p\), the formula \(\lim [f(x)]^p = L^p\) additionally requires \(L \gt 0\) (so the power is defined by \(L^p = e^{p \ln L}\)); that case is justified later with logarithms.

Proof of the sum law. Let \(\varepsilon \gt 0\). From \(\lim f = L\), choose \(\delta_1 \gt 0\) so that \(0 \lt |x - a| \lt \delta_1\) implies \(|f(x) - L| \lt \frac{\varepsilon}{2}\). From \(\lim g = M\), choose \(\delta_2 \gt 0\) so that \(0 \lt |x - a| \lt \delta_2\) implies \(|g(x) - M| \lt \frac{\varepsilon}{2}\). Put \(\delta = \min(\delta_1, \delta_2)\). Then for \(0 \lt |x - a| \lt \delta\), \[|(f(x) + g(x)) - (L + M)| = |(f(x) - L) + (g(x) - M)| \le |f(x) - L| + |g(x) - M| \lt \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon.\] Hence \(\lim_{x \to a} (f(x) + g(x)) = L + M\). The other laws have similar epsilon-delta proofs (the product law first bounds one factor near \(a\)).
Example 4.1 - Using the laws directly. Evaluate \(\lim_{x \to 3} \frac{x^2 + 1}{x - 1}\).
  1. The numerator limit: \(\lim (x^2 + 1) = 3^2 + 1 = 10\).
  2. The denominator limit: \(\lim (x - 1) = 3 - 1 = 2\), which is nonzero, so the quotient law applies.
  3. Therefore \(\lim_{x \to 3} \frac{x^2 + 1}{x - 1} = \frac{10}{2} = 5\).

4.2 Quick check

Quick check 1.
  1. When may the quotient law not be used? When the denominator's limit is zero.
  2. What extra assumption is needed for \(\lim \sqrt{f(x)} = \sqrt{\lim f(x)}\) with a square root? The limit \(L\) must be positive and \(f(x)\) non-negative near the point.
  3. Compute \(\lim_{x \to 1} (2x^3 - x + 4)\). \(2 - 1 + 4 = 5\).

5. The squeeze theorem and trigonometric limits

5.1 Intuition and statement

If a function is trapped between two functions that both approach the same limit, it must approach that limit too. This is the squeeze (or sandwich) theorem, and it is the tool that proves the fundamental trigonometric limits.

Theorem (squeeze theorem). Suppose \(g(x) \le f(x) \le h(x)\) for all \(x\) near \(a\), with \(x \ne a\), and suppose \[\lim_{x \to a} g(x) = \lim_{x \to a} h(x) = L.\] Then \(\lim_{x \to a} f(x) = L\). The same result holds for one-sided limits with the obvious changes.
Proof. Let \(\varepsilon \gt 0\). Since \(g \to L\), there is \(\delta_1 \gt 0\) with \(0 \lt |x - a| \lt \delta_1 \implies |g(x) - L| \lt \varepsilon\), i.e. \(L - \varepsilon \lt g(x)\). Since \(h \to L\), there is \(\delta_2 \gt 0\) with \(0 \lt |x - a| \lt \delta_2 \implies h(x) \lt L + \varepsilon\). Let \(\delta = \min(\delta_1, \delta_2)\), small enough also that the trapping inequalities hold. Then for \(0 \lt |x - a| \lt \delta\), \[L - \varepsilon \lt g(x) \le f(x) \le h(x) \lt L + \varepsilon,\] so \(|f(x) - L| \lt \varepsilon\). Hence \(f \to L\).

5.2 The fundamental trigonometric limits

Radian measure is essential. All these limits assume angles are measured in radians. The geometric inequality below uses the sector area \(\frac{1}{2}x\), which is valid only in radians; in degrees the limits would carry an extra factor of \(\frac{\pi}{180}\).
Proof that \(\displaystyle \lim_{x \to 0} \frac{\sin x}{x} = 1\). For \(0 \lt x \lt \frac{\pi}{2}\), compare areas in the unit circle: the triangle with vertices at the center and two points on the circle has area \(\frac{1}{2}\sin x\), the circular sector has area \(\frac{1}{2}x\), and the larger tangent triangle has area \(\frac{1}{2}\tan x\). Thus \[\tfrac{1}{2}\sin x \le \tfrac{1}{2}x \le \tfrac{1}{2}\tan x.\] Multiplying by \(2\) and dividing by \(\sin x \gt 0\) gives \(1 \le \frac{x}{\sin x} \le \frac{1}{\cos x}\), hence \[\cos x \le \frac{\sin x}{x} \le 1.\] As \(x \to 0^+\), \(\cos x \to 1\) and the constant upper bound is \(1\), so the squeeze theorem gives \(\lim_{x \to 0^+} \frac{\sin x}{x} = 1\). Since \(\frac{\sin(-x)}{-x} = \frac{-\sin x}{-x} = \frac{\sin x}{x}\), the function is even, so the left-hand limit is also \(1\). Therefore the two-sided limit is \(1\).
Derivation of \(\displaystyle \lim_{x \to 0} \frac{1 - \cos x}{x} = 0\). Multiply by the conjugate: \[\frac{1 - \cos x}{x} \cdot \frac{1 + \cos x}{1 + \cos x} = \frac{1 - \cos^2 x}{x(1 + \cos x)} = \frac{\sin^2 x}{x(1 + \cos x)} = \frac{\sin x}{x} \cdot \frac{\sin x}{1 + \cos x}.\] The first factor tends to \(1\); the second tends to \(\frac{0}{1 + 1} = 0\) by the quotient law (the denominator tends to \(2 \ne 0\)). Hence the product tends to \(1 \cdot 0 = 0\).
Example 5.1 - A scaled sine limit. Evaluate \(\lim_{x \to 0} \frac{\sin(3x)}{x}\).
  1. Multiply and divide by \(3\): \(\frac{\sin(3x)}{x} = 3 \cdot \frac{\sin(3x)}{3x}\).
  2. Let \(u = 3x\). As \(x \to 0\), \(u \to 0\), so \(\lim_{x \to 0} \frac{\sin(3x)}{3x} = \lim_{u \to 0} \frac{\sin u}{u} = 1\).
  3. Therefore the limit is \(3 \cdot 1 = 3\). Both angles are in radians.

6. Evaluating limits: indeterminate forms

6.1 Direct substitution after the limit laws

Because the limit laws hold for polynomials and rational functions (with nonzero denominator at the point), we may evaluate their limits by substitution. This is not an appeal to the undefined word "nice"; it is a consequence of the constant, identity, sum, product, and quotient laws proved above. If \(a\) is in the natural domain of a polynomial or rational function, then \(\lim_{x \to a} f(x) = f(a)\). Continuity, defined later, will give the same conclusion for a much wider class.

6.2 What indeterminate means

Indeterminate forms. Substituting the limiting behavior of numerator and denominator sometimes yields a pattern that does not determine the answer. The basic forms are \(\frac{0}{0}\), \(\frac{\infty}{\infty}\), \(\infty - \infty\), \(0 \cdot \infty\), \(\frac{0}{\infty}\) is not indeterminate (it is \(0\)), while the exponential forms \(1^{\infty}\), \(0^0\), and \(\infty^0\) are indeterminate.
Common mistakes: not every indeterminate form is algebraic. The forms \(\frac{0}{0}\) and \(\frac{\infty}{\infty}\) often yield to factoring, rationalizing, or dividing by the highest power. But exponential forms such as \(1^{\infty}\) generally require logarithms or L'Hôpital's rule, which are developed later. Do not assume "indeterminate" always means "factor and cancel." Also note that writing \(\frac{0}{0}\) is shorthand for a limiting pattern; it is not a number, and we never treat it as one.
Example 6.1 - Factoring. Evaluate \(\lim_{x \to 2} \frac{x^2 - 4}{x - 2}\).
  1. Substitution gives \(\frac{4 - 4}{2 - 2} = \frac{0}{0}\), indeterminate.
  2. Factor: \(x^2 - 4 = (x - 2)(x + 2)\).
  3. For \(x \ne 2\), cancel: \(\frac{(x - 2)(x + 2)}{x - 2} = x + 2\).
  4. Now \(\lim_{x \to 2} (x + 2) = 4\). Cancellation is legitimate because the limit ignores \(x = 2\).
Example 6.2 - Rationalizing. Evaluate \(\lim_{x \to 0} \frac{\sqrt{x + 4} - 2}{x}\).
  1. Substitution gives \(\frac{0}{0}\). Multiply by the conjugate: \[\frac{\sqrt{x + 4} - 2}{x} \cdot \frac{\sqrt{x + 4} + 2}{\sqrt{x + 4} + 2} = \frac{(x + 4) - 4}{x(\sqrt{x + 4} + 2)}.\]
  2. Simplify: \(\frac{x}{x(\sqrt{x + 4} + 2)} = \frac{1}{\sqrt{x + 4} + 2}\) for \(x \ne 0\).
  3. Take the limit: \(\frac{1}{\sqrt{4} + 2} = \frac{1}{4}\).

6.3 Quick check

Quick check 2.
  1. Evaluate \(\lim_{x \to 1} \frac{x^2 - 1}{x - 1}\). Factor to \(x + 1\), so the limit is \(2\).
  2. Evaluate \(\lim_{x \to 0} \frac{\sin(5x)}{x}\). \(5\).
  3. Is \(\frac{0}{\infty}\) indeterminate? No; it tends to \(0\).

7. Limits at infinity, infinite limits, and asymptotes

7.1 Definitions

Definitions. \[\lim_{x \to \infty} f(x) = L\] means that for every \(\varepsilon \gt 0\) there is \(N \gt 0\) with \(x \gt N \implies |f(x) - L| \lt \varepsilon\). Similarly \(\lim_{x \to -\infty} f(x) = L\) uses \(x \lt -N\). \[\lim_{x \to a} f(x) = \infty\] means that for every \(M \gt 0\) there is \(\delta \gt 0\) with \(0 \lt |x - a| \lt \delta \implies f(x) \gt M\). One-sided versions use \(a \lt x \lt a + \delta\) or \(a - \delta \lt x \lt a\).
Asymptotes. If \(\lim_{x \to \infty} f(x) = L\) or \(\lim_{x \to -\infty} f(x) = L\), the line \(y = L\) is a horizontal asymptote. If one of the one-sided limits as \(x \to a\) is \(\pm \infty\), the vertical line \(x = a\) is a vertical asymptote.

7.2 Rational functions at infinity

Method and justification. For \(R(x) = \frac{a_m x^m + \cdots + a_0}{b_n x^n + \cdots + b_0}\) with \(a_m, b_n \ne 0\), divide numerator and denominator by \(x^n\), where \(n\) is the denominator's degree. Since \(\lim_{x \to \infty} \frac{1}{x^k} = 0\) for \(k \gt 0\), every lower-order term vanishes. If \(m \lt n\) the limit is \(0\); if \(m = n\) the limit is \(\frac{a_m}{b_n}\); if \(m \gt n\) the quotient grows without bound in magnitude, so the limit is \(\pm \infty\), with the sign determined by leading coefficients and the direction of approach.
Example 7.1 - A horizontal asymptote. Evaluate \(\lim_{x \to \infty} \frac{3x^2 + 1}{2x^2 - x + 5}\).
  1. Divide by \(x^2\): \(\frac{3 + \frac{1}{x^2}}{2 - \frac{1}{x} + \frac{5}{x^2}}\).
  2. As \(x \to \infty\), the reciprocal powers tend to \(0\).
  3. The limit is \(\frac{3}{2}\), so \(y = \frac{3}{2}\) is a horizontal asymptote.
Example 7.2 - A vertical asymptote. For \(f(x) = \frac{1}{(x - 2)^2}\), examine \(x \to 2\).
  1. For \(x \ne 2\), \((x - 2)^2 \gt 0\), and it can be made arbitrarily small.
  2. Given \(M \gt 0\), choose \(\delta = \frac{1}{\sqrt{M}}\). Then \(0 \lt |x - 2| \lt \delta\) gives \((x - 2)^2 \lt \delta^2 = \frac{1}{M}\), so \(f(x) \gt M\).
  3. Thus \(\lim_{x \to 2} f(x) = \infty\) from both sides, and \(x = 2\) is a vertical asymptote.

8. Continuity

8.1 Definition and intuition

Continuity means there is no break in the graph: the limit exists and matches the function's value. This is the precise version of "you can draw it without lifting your pencil."

Definition. A function \(f\) is continuous at \(a\) if
  1. \(f(a)\) is defined,
  2. \(\lim_{x \to a} f(x)\) exists, and
  3. \(\lim_{x \to a} f(x) = f(a)\).
At a left endpoint we use the right-hand limit; at a right endpoint we use the left-hand limit.
Continuity on an interval. \(f\) is continuous on \((a, b)\) if it is continuous at every point there. It is continuous on \([a, b]\) if it is continuous on \((a, b)\), right-continuous at \(a\), and left-continuous at \(b\). Mixed intervals are handled analogously.
Example 8.1 - A removable discontinuity. Let \(f(x) = \frac{x^2 - 1}{x - 1}\) for \(x \ne 1\).
  1. \(f(1)\) is undefined, so \(f\) is not continuous at \(1\).
  2. But \(\lim_{x \to 1} f(x) = \lim_{x \to 1} (x + 1) = 2\) exists.
  3. Defining \(f(1) = 2\) removes the break; this is a removable discontinuity.
Example 8.2 - A piecewise jump. Let \(g\) be the piecewise function \[ g(x) = \begin{cases} x + 1 \quad\text{if } x \lt 0,\\ x^2 \quad\text{if } x \ge 0. \end{cases} \]
  1. Left limit: \(\lim_{x \to 0^-} g(x) = 0 + 1 = 1\).
  2. Right limit: \(\lim_{x \to 0^+} g(x) = 0^2 = 0\).
  3. They differ, so the two-sided limit does not exist and \(g\) has a jump at \(0\), even though \(g(0) = 0\).
Example 8.3 - A piecewise function that is continuous. Let \(h\) be the piecewise function \[ h(x) = \begin{cases} 2x \quad\text{if } x \lt 1,\\ x + 1 \quad\text{if } x \ge 1. \end{cases} \]
  1. Left limit: \(\lim_{x \to 1^-} h(x) = 2\). Right limit: \(\lim_{x \to 1^+} h(x) = 2\).
  2. So the limit exists and equals \(2\); also \(h(1) = 1 + 1 = 2\).
  3. All three conditions hold, so \(h\) is continuous at \(1\).

8.2 Types of discontinuities

Classification at \(x = a\).
  • Removable: the limit exists but differs from \(f(a)\), or \(f(a)\) is undefined.
  • Jump: the one-sided limits exist but are unequal.
  • Infinite: one of the one-sided limits is \(\pm \infty\), as with \(\frac{1}{x - a}\) or \(\frac{1}{(x - a)^2}\) at \(a\).
  • Oscillating: values fail to settle, as with \(\sin\left(\frac{1}{x}\right)\) at \(0\).

8.3 Building continuous functions

Theorem (algebra of continuity). If \(f\) and \(g\) are continuous at \(a\), then so are \(f + g\), \(f - g\), \(fg\), and \(\frac{f}{g}\) provided \(g(a) \ne 0\). In particular, polynomials are continuous everywhere, and rational functions are continuous wherever their denominators are nonzero.
Theorem (continuity of compositions). If \(g\) is continuous at \(a\) and \(f\) is continuous at \(g(a)\), then the composition \(f \circ g\) is continuous at \(a\); that is, \[\lim_{x \to a} f(g(x)) = f\!\left(\lim_{x \to a} g(x)\right) = f(g(a)).\]
Proof of the composition theorem. Let \(\varepsilon \gt 0\). Continuity of \(f\) at \(g(a)\) gives \(\eta \gt 0\) such that \(|y - g(a)| \lt \eta \implies |f(y) - f(g(a))| \lt \varepsilon\). Continuity of \(g\) at \(a\) gives \(\delta \gt 0\) such that \(|x - a| \lt \delta \implies |g(x) - g(a)| \lt \eta\). Combining, \(|x - a| \lt \delta\) implies \(|f(g(x)) - f(g(a))| \lt \varepsilon\), which is continuity of \(f \circ g\) at \(a\).

8.4 The Intermediate Value Theorem

Theorem (Intermediate Value Theorem, IVT). If \(f\) is continuous on \([a, b]\) and \(N\) is any number with \(\min(f(a), f(b)) \le N \le \max(f(a), f(b))\), then there exists \(c \in [a, b]\) with \(f(c) = N\). If moreover \(N\) lies strictly between \(f(a)\) and \(f(b)\), then \(c\) may be chosen in the open interval \((a, b)\).
Proof sketch for the case \(f(a) \lt N \lt f(b)\). Let \(S = \{x \in [a, b] \mid f(x) \le N\}\). Then \(a \in S\), since \(f(a) \lt N\), so \(S\) is nonempty; and \(S\) is bounded above by \(b\). Let \(c = \sup S\), so \(a \le c \le b\). Because \(f(b) \gt N\), continuity at \(b\) gives a neighborhood on which \(f \gt N\); hence \(b \notin S\) and, more strongly, \(c \lt b\). Now we rule out the two alternatives.
  • If \(f(c) \lt N\), continuity at \(c\) gives \(f \lt N\) on an interval to the right of \(c\); since \(c \lt b\), we can pick \(x \gt c\) with \(x \in S\), contradicting that \(c\) is an upper bound.
  • If \(f(c) \gt N\), continuity gives \(f \gt N\) on \((c - \eta, c + \eta)\), so no point of \(S\) lies there; then \(c - \eta\) is a smaller upper bound for \(S\), contradicting that \(c\) is the least upper bound.
Therefore \(f(c) = N\). Since \(f(a) \lt N = f(c)\) we have \(c \ne a\), and we already showed \(c \lt b\), so \(c \in (a, b)\). The case \(f(b) \lt N \lt f(a)\) is symmetric.
Example 8.4 - Locating a root with the IVT. Show that \(f(x) = x^3 - 3x + 1\) has a zero in \((0, 1)\).
  1. \(f\) is a polynomial, hence continuous on \([0, 1]\).
  2. Evaluate the endpoints: \(f(0) = 1 \gt 0\) and \(f(1) = 1 - 3 + 1 = -1 \lt 0\).
  3. Take \(N = 0\), which lies strictly between \(f(0)\) and \(f(1)\).
  4. By the IVT there is \(c \in (0, 1)\) with \(f(c) = 0\). So a root exists in \((0, 1)\); the theorem guarantees existence, not uniqueness or the value of \(c\).

8.5 The Extreme Value Theorem

Theorem (Extreme Value Theorem, EVT). If \(f\) is continuous on the closed, bounded interval \([a, b]\), then \(f\) attains an absolute maximum and an absolute minimum on \([a, b]\). That is, there exist \(c, d \in [a, b]\) with \(f(c) \le f(x) \le f(d)\) for all \(x \in [a, b]\).
Why the hypotheses matter. On an open interval a continuous function need not attain its extremes: \(f(x) = \frac{1}{x}\) on \((0, 1)\) is unbounded above. Continuity alone is not enough either: a function with a vertical asymptote on \([a, b]\) may be unbounded. Both closedness and continuity are required.

8.6 Common mistakes

  • Confusing \(\lim_{x \to a} f(x)\) with \(f(a)\); the limit can exist when \(f(a)\) is undefined or different.
  • Applying the quotient law when the denominator's limit is zero; this always requires separate analysis.
  • Forgetting that the two-sided limit criterion needs both one-sided limits and an interior point of the domain.
  • Using trigonometric limits with angles in degrees.
  • Claiming the IVT gives a point in \((a, b)\) when \(N\) equals an endpoint value; in that inclusive case only \(c \in [a, b]\) is guaranteed.

Bonus: the sequential characterization of limits

There is an equivalent way to phrase limits using sequences. It is often the cleanest tool for proving that a limit does not exist.

Theorem. Let \(f\) be defined on an open interval containing \(a\), except possibly at \(a\). Then \(\lim_{x \to a} f(x) = L\) if and only if for every sequence \((x_n)\) with \(x_n \ne a\) and \(x_n \to a\), we have \(f(x_n) \to L\).
Proof. Suppose first that \(\lim_{x \to a} f(x) = L\), and let \(x_n \to a\) with \(x_n \ne a\). Given \(\varepsilon \gt 0\), choose \(\delta \gt 0\) from the epsilon-delta definition. Since \(x_n \to a\), there is \(N\) with \(n \gt N \implies |x_n - a| \lt \delta\); combined with \(x_n \ne a\) this gives \(|f(x_n) - L| \lt \varepsilon\). Hence \(f(x_n) \to L\).

Conversely, suppose the sequential condition holds but the limit is not \(L\). Then there is \(\varepsilon_0 \gt 0\) such that for every \(\delta \gt 0\) some \(x\) with \(0 \lt |x - a| \lt \delta\) satisfies \(|f(x) - L| \ge \varepsilon_0\). Choosing \(\delta = \frac{1}{n}\) for each positive integer \(n\) produces points \(x_n\) with \(0 \lt |x_n - a| \lt \frac{1}{n}\) and \(|f(x_n) - L| \ge \varepsilon_0\). Then \(x_n \to a\) and \(x_n \ne a\), but \(f(x_n)\) cannot converge to \(L\), contradicting the hypothesis. Hence the limit must be \(L\).

Example Bonus.1 - Showing a limit fails. For \(\sin\left(\frac{1}{x}\right)\) at \(0\), choose \(x_n = \frac{1}{\frac{\pi}{2} + 2\pi n}\), so \(x_n \to 0\) but \(\sin\left(\frac{1}{x_n}\right) = 1\) for all \(n\). Choose \(y_n = \frac{1}{\frac{3\pi}{2} + 2\pi n}\), so \(y_n \to 0\) but \(\sin\left(\frac{1}{y_n}\right) = -1\). Two sequences approaching \(0\) give different limiting values, so \(\lim_{x \to 0} \sin\left(\frac{1}{x}\right)\) does not exist.

Summary

  • Limits describe approach, not the value at the point; one-sided limits must agree at interior points.
  • The epsilon-delta definition makes "arbitrarily close" exact; nonlinear cases use a bound like \(\delta = \min(1, \varepsilon/5)\).
  • Limit laws require the denominator's limit to be nonzero; root and real-power laws require positivity conditions.
  • The squeeze theorem proves \(\frac{\sin x}{x} \to 1\) in radians and \(\frac{1 - \cos x}{x} \to 0\).
  • Continuity means limit equals value; compositions of continuous functions are continuous.
  • The IVT guarantees intermediate values on \([a, b]\), and the EVT guarantees extrema on closed bounded intervals.

Practice Problems

  1. Using epsilon-delta, prove \(\lim_{x \to 4} (2x + 1) = 9\).
  2. Using epsilon-delta, prove \(\lim_{x \to 3} x^2 = 9\) with \(\delta = \min(1, \varepsilon/7)\).
  3. Evaluate \(\lim_{x \to 2} \frac{x^2 - 4}{x - 2}\).
  4. Evaluate \(\lim_{x \to 0} \frac{\sqrt{x + 9} - 3}{x}\).
  5. Evaluate \(\lim_{x \to 0} \frac{\sin(4x)}{x}\).
  6. Evaluate \(\lim_{x \to \infty} \frac{5x^3 - 2x}{x^3 + x^2 + 1}\).
  7. Find \(\lim_{x \to 0^-} \frac{|x|}{x}\) and \(\lim_{x \to 0^+} \frac{|x|}{x}\). Does the two-sided limit exist?
  8. Let \(f\) be the piecewise function \[ f(x) = \begin{cases} x^2 \quad\text{if } x \le 2,\\ mx + 1 \quad\text{if } x \gt 2. \end{cases} \] Find \(m\) so that \(f\) is continuous at \(2\).
  9. Show that \(x^4 + x - 3 = 0\) has a solution in \((1, 2)\).
  10. State the hypothesis on \(\lim_{x \to a} g(x)\) needed for \(\lim \frac{f}{g} = \frac{\lim f}{\lim g}\), and explain why it is needed.
  11. Use the sequential criterion to show \(\lim_{x \to 0} \cos\left(\frac{1}{x}\right)\) does not exist.
  12. Find the vertical and horizontal asymptotes of \(f(x) = \frac{x + 1}{x - 2}\), justifying each with a limit.

Practice Problems - Worked Answer Key

Answers 1-4.
  1. Given \(\varepsilon \gt 0\), take \(\delta = \varepsilon/2\). Then \(0 \lt |x - 4| \lt \delta\) gives \(|(2x + 1) - 9| = 2|x - 4| \lt 2\delta = \varepsilon\).
  2. First require \(\delta \le 1\), so \(|x - 3| \lt 1\) gives \(2 \lt x \lt 4\) and \(|x + 3| \lt 7\). Take \(\delta = \min(1, \varepsilon/7)\). Then \(|x^2 - 9| = |x - 3|\,|x + 3| \lt (\varepsilon/7)\cdot 7 = \varepsilon\).
  3. Factor: \(\frac{(x - 2)(x + 2)}{x - 2} = x + 2\) for \(x \ne 2\), so the limit is \(4\).
  4. Multiply by \(\frac{\sqrt{x + 9} + 3}{\sqrt{x + 9} + 3}\) to get \(\frac{x}{x(\sqrt{x + 9} + 3)} = \frac{1}{\sqrt{x + 9} + 3}\), which tends to \(\frac{1}{6}\).
Answers 5-8.
  1. Write \(4 \cdot \frac{\sin(4x)}{4x} \to 4 \cdot 1 = 4\).
  2. Divide by \(x^3\): \(\frac{5 - \frac{2}{x^2}}{1 + \frac{1}{x} + \frac{1}{x^3}} \to 5\).
  3. Left limit is \(-1\), right limit is \(1\); they differ, so the two-sided limit does not exist.
  4. Continuity at \(2\) requires \(\lim_{x \to 2^-} x^2 = 4\) to equal \(\lim_{x \to 2^+} (mx + 1) = 2m + 1\) and \(f(2) = 4\). So \(2m + 1 = 4\), giving \(m = \frac{3}{2}\).
Answers 9-12.
  1. Let \(p(x) = x^4 + x - 3\), continuous on \([1, 2]\). Then \(p(1) = -1 \lt 0\) and \(p(2) = 16 + 2 - 3 = 15 \gt 0\); with \(N = 0\) strictly between them, the IVT gives \(c \in (1, 2)\) with \(p(c) = 0\).
  2. We need \(\lim_{x \to a} g(x) \ne 0\), otherwise the denominator could shrink to zero and the quotient need not have a finite limit.
  3. Take \(x_n = \frac{1}{2\pi n}\), so \(x_n \to 0\) and \(\cos(1/x_n) \to 1\); take \(y_n = \frac{1}{(2n+1)\pi}\), so \(y_n \to 0\) and \(\cos(1/y_n) \to -1\). Different subsequential limits mean the limit does not exist.
  4. Vertical asymptote \(x = 2\) because \(\lim_{x \to 2^-} \frac{x+1}{x-2} = -\infty\) and \(\lim_{x \to 2^+} \frac{x+1}{x-2} = \infty\). Horizontal asymptote \(y = 1\) because \(\lim_{x \to \pm\infty} \frac{x+1}{x-2} = 1\) after dividing by \(x\).
