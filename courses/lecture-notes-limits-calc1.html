Limits and Continuity

Calculus I - Chapter 2.1-2.5 (Detailed Notes)

1. The Intuitive Idea of a Limit

1.1 What is a Limit?

We say "the limit of \(f(x)\) as \(x\) approaches \(a\) equals \(L\)" when we can make \(f(x)\) arbitrarily close to \(L\) by taking \(x\) sufficiently close to \(a\) (but not equal to \(a\)).

Key Intuition: Think of watching a movie frame by frame as we approach a specific point. The limit is what the function values are "heading toward" as we get closer and closer to the input. Important: The value \(f(a)\) itself may or may not equal the limit!
Example 1.1 - Graphical Understanding: Consider \(f(x) = \frac{x^2 - 1}{x - 1}\)

For \(x \neq 1\): \(f(x) = \frac{(x-1)(x+1)}{x-1} = x + 1\)

Graphically: A line with a hole at \((1, 2)\)

The limit as \(x \to 1\) is 2 (we approach the hole)

But \(f(1)\) is undefined (the hole is there!)

2. One-Sided Limits

2.1 Left-Hand and Right-Hand Limits

Left-Hand Limit: \(\lim_{x \to a^-} f(x) = L\) means: as \(x\) approaches \(a\) from values less than \(a\), \(f(x)\) approaches \(L\). Right-Hand Limit: \(\lim_{x \to a^+} f(x) = L\) means: as \(x\) approaches \(a\) from values greater than \(a\), \(f(x)\) approaches \(L\).
Two-Sided Limit Exists: \(\lim_{x \to a} f(x) = L\) if and only if:
  • \(\lim_{x \to a^-} f(x) = L\) AND
  • \(\lim_{x \to a^+} f(x) = L\)
Both one-sided limits must exist AND be equal!
Example 2.1 - One-Sided Limits: For \(f(x) = |x|\) at \(x = 0\):

Left-hand limit: As \(x \to 0^-\), \(|x| = -x\), so \(\lim_{x \to 0^-} |x| = 0\)

Right-hand limit: As \(x \to 0^+\), \(|x| = x\), so \(\lim_{x \to 0^+} |x| = 0\)

Since both equal 0: \(\lim_{x \to 0} |x| = 0\)

3. The Precise Definition of a Limit (Epsilon-Delta)

3.1 Formal Definition

Epsilon-Delta Definition: \(\lim_{x \to a} f(x) = L\) means: For every \(\varepsilon > 0\) (no matter how small), there exists a \(\delta > 0\) such that: if \(0 < |x - a| < \delta\), then \(|f(x) - L| < \varepsilon\)
Understanding the Definition:
  • \(\varepsilon\) (epsilon): How close we want \(f(x)\) to be to \(L\)
  • \(\delta\) (delta): How close \(x\) must be to \(a\)
  • The definition says: we can always find a \(\delta\) that works!
Think of it as a game: You pick \(\varepsilon\), I must find \(\delta\). If I can always win, the limit exists!

3.2 Proof Example

Proof that \(\lim_{x \to 2} (3x - 1) = 5\) We need to show: For every \(\varepsilon > 0\), there exists \(\delta > 0\) such that if \(0 < |x - 2| < \delta\), then \(|(3x-1) - 5| < \varepsilon\). Work backwards:

We want: \(|(3x-1) - 5| < \varepsilon\)

Simplify: \(|3x - 6| < \varepsilon\)

Factor: \(|3(x - 2)| < \varepsilon\)

Simplify: \(3|x - 2| < \varepsilon\)

Therefore: \(|x - 2| < \frac{\varepsilon}{3}\)

Choose \(\delta = \frac{\varepsilon}{3}\) Now verify:

Assume \(0 < |x - 2| < \delta = \frac{\varepsilon}{3}\)

Then \(|x - 2| < \frac{\varepsilon}{3}\)

Multiply by 3: \(3|x - 2| < \varepsilon\)

Factor: \(|3(x - 2)| < \varepsilon\)

Simplify: \(|3x - 6| < \varepsilon\)

Rewrite: \(|(3x - 1) - 5| < \varepsilon\)

Therefore: \(|(3x-1) - 5| < \varepsilon\) ✓

Since we found such a \(\delta\) for any \(\varepsilon\), the limit is proven. ∎

4. Limit Laws

4.1 Basic Limit Laws

Limit Laws (assuming all limits exist):
  • Sum Law: \(\lim_{x \to a} [f(x) + g(x)] = \lim_{x \to a} f(x) + \lim_{x \to a} g(x)\)
  • Difference Law: \(\lim_{x \to a} [f(x) - g(x)] = \lim_{x \to a} f(x) - \lim_{x \to a} g(x)\)
  • Product Law: \(\lim_{x \to a} [f(x) \cdot g(x)] = \lim_{x \to a} f(x) \cdot \lim_{x \to a} g(x)\)
  • Quotient Law: \(\lim_{x \to a} \frac{f(x)}{g(x)} = \frac{\lim_{x \to a} f(x)}{\lim_{x \to a} g(x)}\) (if denominator ≠ 0)
  • Power Law: \(\lim_{x \to a} [f(x)]^n = [\lim_{x \to a} f(x)]^n\)
Proof of Sum Law (Sketch): Let \(\lim_{x \to a} f(x) = L\) and \(\lim_{x \to a} g(x) = M\) We want to show: \(\lim_{x \to a} [f(x) + g(x)] = L + M\) By definition, for any \(\varepsilon > 0\):
  • There exists \(\delta_1 > 0\) such that if \(0 < |x-a| < \delta_1\), then \(|f(x) - L| < \frac{\varepsilon}{2}\)
  • There exists \(\delta_2 > 0\) such that if \(0 < |x-a| < \delta_2\), then \(|g(x) - M| < \frac{\varepsilon}{2}\)
Let \(\delta = \min(\delta_1, \delta_2)\) Then if \(0 < |x-a| < \delta\):

\(|[f(x) + g(x)] - [L + M]| = |[f(x) - L] + [g(x) - M]| \leq |f(x) - L| + |g(x) - M| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon\)

Therefore, \(\lim_{x \to a} [f(x) + g(x)] = L + M\) ∎

4.2 Special Limits

Important Limits to Know:
  • \(\lim_{x \to a} c = c\) (constant function)
  • \(\lim_{x \to a} x = a\) (identity function)
  • \(\lim_{x \to 0} \frac{\sin x}{x} = 1\) (squeeze theorem proof required)
  • \(\lim_{x \to 0} \frac{1 - \cos x}{x} = 0\) (can be derived from above)
  • \(\lim_{x \to \infty} \frac{1}{x} = 0\)

5. Evaluating Limits

5.1 Direct Substitution

When Direct Substitution Works: If \(f\) is a polynomial, rational function, or "nice" function and \(a\) is in the domain, then: \(\lim_{x \to a} f(x) = f(a)\) Why this works: Most functions we work with are continuous, meaning the limit equals the function value.

5.2 Indeterminate Forms

Indeterminate Forms: When direct substitution gives:
  • \(\frac{0}{0}\)
  • \(\frac{\infty}{\infty}\)
  • \(\infty - \infty\)
  • \(0 \cdot \infty\)
  • \(\frac{0}{0}\)
  • \(1^{\infty}\)
  • \(0^0\)
  • \(\infty^0\)
These require further algebraic manipulation!

5.3 Techniques for Evaluating Limits

Example 5.1 - Factoring (0/0 form): \(\lim_{x \to 2} \frac{x^2 - 4}{x - 2}\)

Direct substitution: \(\frac{4-4}{2-2} = \frac{0}{0}\) - indeterminate!

Factor numerator: \(\frac{(x-2)(x+2)}{x-2}\)

Cancel (valid for \(x \neq 2\)): \(x + 2\)

Now take limit: \(\lim_{x \to 2} (x + 2) = 4\)

Example 5.2 - Rationalizing (0/0 form with radicals): \(\lim_{x \to 0} \frac{\sqrt{x+4} - 2}{x}\)

Multiply by conjugate: \(\frac{\sqrt{x+4} - 2}{x} \cdot \frac{\sqrt{x+4} + 2}{\sqrt{x+4} + 2}\)

Simplify numerator: \(= \frac{(x+4) - 4}{x(\sqrt{x+4} + 2)} = \frac{x}{x(\sqrt{x+4} + 2)}\)

Cancel: \(= \frac{1}{\sqrt{x+4} + 2}\)

Take limit: \(\frac{1}{\sqrt{4} + 2} = \frac{1}{4}\)

Example 5.3 - Special Trigonometric Limit: \(\lim_{x \to 0} \frac{\sin(3x)}{x}\)

We know \(\lim_{u \to 0} \frac{\sin u}{u} = 1\)

Rewrite: \(\frac{\sin(3x)}{x} = 3 \cdot \frac{\sin(3x)}{3x}\)

Let \(u = 3x\). As \(x \to 0\), \(u \to 0\)

Therefore: \(\lim_{x \to 0} \frac{\sin(3x)}{x} = 3 \cdot \lim_{u \to 0} \frac{\sin u}{u} = 3 \cdot 1 = 3\)

6. Continuity

6.1 Definition of Continuity

Definition: A function \(f\) is continuous at \(a\) if and only if:
  1. \(f(a)\) is defined
  2. \(\lim_{x \to a} f(x)\) exists
  3. \(\lim_{x \to a} f(x) = f(a)\)
Intuitive Meaning: You can draw the graph without lifting your pencil! There are no holes, jumps, or vertical asymptotes.

6.2 Types of Discontinuities

Types of Discontinuities at \(x = a\):
  • Removable discontinuity: Limit exists but ≠ function value or function is undefined
  • Jump discontinuity: Left and right limits exist but are different
  • Infinite discontinuity: Function approaches ±∞ from at least one side
  • Oscillating discontinuity: Function oscillates infinitely (e.g., \(\sin(1/x)\) at \(x = 0\))
Example 6.1 - Removable Discontinuity: \(f(x) = \frac{x^2 - 1}{x - 1}\)

At \(x = 1\): \(f(1)\) is undefined (0/0)

But \(\lim_{x \to 1} f(x) = \lim_{x \to 1} (x+1) = 2\) exists

We can "remove" the discontinuity by defining \(f(1) = 2\)

6.3 Continuity on an Interval

Continuity on an Interval:**
  • On \((a, b)\): \(f\) is continuous at every point in \((a, b)\)
  • On \([a, b)\): \(f\) is continuous on \((a, b)\) AND continuous at \(a\) from the right
  • On \((a, b]\): \(f\) is continuous on \((a, b)\) AND continuous at \(b\) from the left
  • On \([a, b]\): \(f\) is continuous on \((a, b)\), at \(a\) from the right, and at \(b\) from the left

6.4 Important Theorems about Continuous Functions

Intermediate Value Theorem (IVT): If \(f\) is continuous on \([a, b]\) and \(N\) is any number between \(f(a)\) and \(f(b)\), then there exists at least one \(c \in (a, b)\) such that \(f(c) = N\).
Proof of IVT (Sketch): Let \(f\) be continuous on \([a, b]\) and suppose \(f(a) < N < f(b)\). Define \(S = \{x \in [a, b] : f(x) < N\}\) Let \(c = \sup S\) (the least upper bound of S) By continuity:
  • If \(f(c) < N\), then by continuity, \(f(x) < N\) for \(x\) near \(c\), contradicting \(c = \sup S\)
  • If \(f(c) > N\), then by continuity, \(f(x) > N\) for \(x\) near \(c\), contradicting definition of sup
  • Therefore \(f(c) = N\)
∎
Example 6.2 - Using IVT: Show that \(x^3 - 3x + 1 = 0\) has a solution in \((0, 2)\).

Let \(f(x) = x^3 - 3x + 1\). This is a polynomial, so it's continuous everywhere.

Evaluate: \(f(0) = 1 > 0\) and \(f(2) = 8 - 6 + 1 = 3 > 0\)

Wait - both are positive! Let's try \(f(1) = 1 - 3 + 1 = -1 < 0\)

Now: \(f(0) = 1 > 0\) and \(f(1) = -1 < 0\)

By IVT, there exists \(c \in (0, 1)\) such that \(f(c) = 0\)

So there's at least one root in \((0, 1)\), which is in \((0, 2)\). ✓
