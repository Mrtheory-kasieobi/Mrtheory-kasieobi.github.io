Problem Set 3: Derivatives - SOLUTIONS

Calculus I - Week 3

Solution Guide

Note: These are detailed solution outlines. Show all work when completing problems.

Problem 1: Find \(\frac{dy}{dx}\) for \(y = x^3 - 6x^2 + 5x - 2\)

Solution: Apply power rule: \(\frac{dy}{dx} = 3x^2 - 12x + 5\)

Problem 2: Find equation of tangent line to \(y = x^2\) at \(x = 3\)

Solution: \(y' = 2x\), slope at \(x=3\) is 6. Point: \((3, 9)\). Line: \(y - 9 = 6(x - 3)\) or \(y = 6x - 9\)

Problem 3: Use definition to find \(f'(x)\) for \(f(x) = \frac{1}{x}\)

Solution: \(f'(x) = \lim_{h \to 0} \frac{\frac{1}{x+h} - \frac{1}{x}}{h} = \lim_{h \to 0} \frac{-h}{hx(x+h)} = \frac{-1}{x^2}\)

Problem 4: Find \(\frac{d}{dx}[e^{2x} \cdot \ln x]\)

Solution: Product rule: \(e^{2x} \cdot \frac{1}{x} + e^{2x} \cdot 2\ln x = \frac{e^{2x}}{x}(1 + 2x\ln x)\)

Problem 5: If \(y = \sin(x^2 + 1)\), find \(\frac{dy}{dx}\)

Solution: Chain rule: \(\cos(x^2 + 1) \cdot 2x = 2x\cos(x^2 + 1)\)

Problem 6: Find \(\frac{dy}{dx}\) for \(y = \frac{x^2 + 1}{x - 3}\)

Solution: Quotient rule: \(\frac{(2x)(x-3) - (x^2+1)(1)}{(x-3)^2} = \frac{x^2 - 6x - 1}{(x-3)^2}\)

Problem 7: Position \(s(t) = t^3 - 6t^2 + 9t\). Find velocity at \(t = 2\)

Solution: \(v(t) = s'(t) = 3t^2 - 12t + 9\). At \(t=2\): \(v(2) = 12 - 24 + 9 = -3\)

Problem 8: Find critical numbers of \(f(x) = x^3 - 3x^2 - 9x + 5\)

Solution: \(f'(x) = 3x^2 - 6x - 9 = 3(x-3)(x+1)\). Critical points: \(x = -1, 3\)

Problem 9: Find \(\frac{d}{dx}[\tan^{-1}(x^2)]\)

Solution: Chain rule: \(\frac{1}{1+(x^2)^2} \cdot 2x = \frac{2x}{1+x^4}\)

Problem 10: Prove \(\frac{d}{dx}[x^n] = nx^{n-1}\) for \(n = \frac{1}{2}\)

Solution: \(f(x) = x^{1/2}\). \(f'(x) = \frac{1}{2}x^{-1/2} = \frac{1}{2\sqrt{x}}\)

Bonus 1: Find tangent line to \(y = x^2\) horizontal

Solution: \(y' = 2x = 0 \Rightarrow x = 0\). Point: \((0, 0)\)

Bonus 2: If \(f\) differentiable, \(f(3) = 5\), \(f'(3) = -2\), find tangent line

Solution: \(y - 5 = -2(x - 3)\) or \(y = -2x + 11\)
