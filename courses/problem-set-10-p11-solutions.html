Problem Set 10 Solutions

Inequalities and Systems of Equations | Precalculus 11

Solutions

Problem 1

Solution:

\(\frac{x + 2}{x - 3} > 0\)

Zeros: \(x = -2\)

Undefined: \(x = 3\)

Test intervals:

\[x < -2: \frac{(-)}{(-)} = (+) \quad \checkmark\]

\[-2 < x < 3: \frac{(+)}{(-)} = (-) \quad \times\]

\[x > 3: \frac{(+)}{(+)} = (+) \quad \checkmark\]

Solution: \(x \in (-\infty, -2) \cup (3, \infty)\)

Problem 2

Solution:

\[|x - 4| \leq 3\]

\[-3 \leq x - 4 \leq 3\]

\[1 \leq x \leq 7\]

Solution: \([1, 7]\)

Problem 3

Solution:

From second equation: \(x = y + 1\)

Substitute into first: \(2(y+1) + 3y = 12\)

\[2y + 2 + 3y = 12\]

\[5y = 10\]

\[y = 2\]

\[x = 3\]

Solution: \((3, 2)\)

Problem 4

Solution:

\(x^2 - x - 6 = (x-3)(x+2)\)

\[(x-3)(x+2) \leq 0\]

Zeros at \(x = 3, -2\)

Parabola opens upward, so negative between roots.

Solution: \(x \in [-2, 3]\)

Problem 5

Solution:

Set: \(x^2 - 4 = 2x + 1\)

\[x^2 - 2x - 5 = 0\]

Quadratic formula: \(x = \frac{2 \pm \sqrt{4 + 20}}{2} = \frac{2 \pm \sqrt{8}}{2} = 1 \pm \sqrt{2}\)

Find y: \(y = 2x + 1\)

Intersection points: \((1 + \sqrt{2}, 3 + 2\sqrt{2})\) and \((1 - \sqrt{2}, 3 - 2\sqrt{2})\)

Problem 6

Solution:

\(\frac{x - 1}{x + 2} \leq 2\)

\(\frac{x - 1}{x + 2} - 2 \leq 0\)

\(\frac{x - 1 - 2(x + 2)}{x + 2} \leq 0\)

\(\frac{x - 1 - 2x - 4}{x + 2} \leq 0\)

\(\frac{-x - 5}{x + 2} \leq 0\)

\(\frac{x + 5}{x + 2} \geq 0\) (multiply by -1, flip inequality)

Zeros: \(x = -5\), Undefined: \(x = -2\)

Solution: \(x \in (-\infty, -5] \cup (-2, \infty)\)

Problem 7

Solution:

Let \(a\) = adult tickets, \(c\) = child tickets

System: \(\begin{cases} a + c = 150 \\ 12a + 8c = 1520 \end{cases}\)

From first: \(a = 150 - c\)

Substitute: \(12(150 - c) + 8c = 1520\)

\[1800 - 12c + 8c = 1520\]

\[-4c = -280\]

\[c = 70\]

\[a = 80\]

Solution: 80 adult tickets, 70 child tickets

Problem 8

Solution:

Graph \(y > x + 1\): dashed line through (0,1) and (-1,0), shade above.

Graph \(y \leq -2x + 5\): solid line through (0,5) and (2.5, 0), shade below.

The solution region is where the two shadings overlap.

Problem 9

Solution:

Factor numerator: \(x^2 - 5x + 6 = (x-2)(x-3)\)

\(\frac{(x-2)(x-3)}{x - 2} > 0\)

Note: \(x \neq 2\)

Cancel: \(x - 3 > 0\)

So: \(x > 3\) and \(x \neq 2\)

Solution: \(x \in (3, \infty)\)

Restriction: \(x \neq 2\)

Problem 10

Solution:

Let \(w\) = width, \(l\) = length

System: \(\begin{cases} l = 2w + 3 \\ 2l + 2w = 42 \end{cases}\)

Substitute: \(2(2w + 3) + 2w = 42\)

\[4w + 6 + 2w = 42\]

\[6w = 36\]

\[w = 6 \text{ cm}\]

\[l = 15 \text{ cm}\]\]

Solution: Width = 6 cm, Length = 15 cm
