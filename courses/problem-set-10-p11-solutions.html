Solutions: Problem Set 10

Linear and Quadratic Inequalities - Precalculus 11
Solution 1
Problem: Solve: \(2x + 5 > 11\)
Subtract 5: \(2x > 6\)
Divide by 2: \(x > 3\)
Answer: \(\boxed{x \in (3, \infty)}\)
Solution 2
Problem: Solve: \(-3x \leq 9\)
Divide by -3 (flip inequality): \(x \geq -3\)
Answer: \(\boxed{x \in [-3, \infty)}\)
Solution 3
Problem: Solve the compound inequality: \(-2 < 3x + 1 < 10\)
Subtract 1: \(-3 < 3x < 9\)
Divide by 3: \(-1 < x < 3\)
Answer: \(\boxed{x \in (-1, 3)}\)
Solution 4
Problem: Solve: \(x^2 - 5x + 6 > 0\)
Factor: \((x-2)(x-3) > 0\)
Test intervals: x < 2, between 2 and 3, x > 3
Positive when: \(x < 2\) or \(x > 3\)
Answer: \(\boxed{x \in (-\infty, 2) \cup (3, \infty)}\)
Solution 5
Problem: Solve: \(x^2 + 4x + 3 \leq 0\)
Factor: \((x+1)(x+3) \leq 0\)
Roots: \(x = -1, -3\)
Parabola opens up, negative between roots
Answer: \(\boxed{x \in [-3, -1]}\)
Solution 6
Problem: Find the intersection of \(x^2 - 4 \geq 0\) and \(x < 3\)
First inequality: \((x-2)(x+2) \geq 0\)
Solution: \(x \leq -2\) or \(x \geq 2\)
Second inequality: \(x < 3\)
Intersection: \(x \leq -2\) or \(2 \leq x < 3\)
Answer: \(\boxed{x \in (-\infty, -2] \cup [2, 3)}\)
Solution 7
Problem: Graph the solution to \(y \leq 2x - 3\) on a coordinate plane.
Boundary line: \(y = 2x - 3\) (dashed because ≤)
Test point (0,0): \(0 \leq -3\) is false
Shade below the line
Answer: Region below and including (dashed) line \(y = 2x - 3\)
Solution 8
Problem: Solve: \(\frac{x - 1}{x + 2} > 0\)
Find critical points: numerator zero at \(x = 1\), denominator zero at \(x = -2\)
Test intervals: \(x < -2\), \(-2 < x < 1\), \(x > 1\)
Positive when: \(-2 < x < 1\)
Answer: \(\boxed{x \in (-2, 1)}\)

Bonus Solutions

Bonus Solution 1
Problem: Solve: \(\frac{x^2 - 1}{x^2 - 9} \leq 0\). Then find the range of \(k\) for which \(\frac{x^2 - kx + 4}{(x-1)(x-2)} > 0\) has no solution.
Factor: \(\frac{(x-1)(x+1)}{(x-3)(x+3)} \leq 0\)
Critical points: \(x = -3, -1, 1, 3\)
Sign analysis: Solution is \([-3, -1] \cup (1, 3)\)
Second part: For no solution, numerator must always be non-positive when denominator is positive
This requires \(k \geq 4\) for discriminant \(k^2 - 16 \leq 0\)
Answer: \(\boxed{k \in (-\infty, -4] \cup [4, \infty)}\) for no solution
Bonus Solution 2
Problem: Find all x such that \(|x - 3| > 5\). Then solve \(|2x + 1| - |x - 3| \leq 4\)
First: \(|x - 3| > 5\) → \(x - 3 > 5\) or \(x - 3 < -5\)
Solution: \(x > 8\) or \(x < -2\)
Second: Consider cases for \(|2x+1|\) and \(|x-3|\)
Case 1: \(x \geq -0.5, x \geq 3\): \((2x+1) - (x-3) \leq 4\) → \(x \leq 6\)
Case 2: \(x \geq -0.5, x < 3\): \((2x+1) - (3-x) \leq 4\) → \(x \leq 2\)
Case 3: \(x < -0.5, x \geq 3\): impossible
Case 4: \(x < -0.5, x < 3\): \(-(2x+1) - (3-x) \leq 4\) → \(x \geq -6\)
Union of all valid intervals: \([-6, 2]\)
Answer: \(\boxed{x \in [-6, 2]}\)
