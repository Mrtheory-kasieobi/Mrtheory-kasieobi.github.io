Problem Set 1: Function Transformations

Precalculus 12 - Problem Set
Topics: Function Transformations, Inverses Medium

Problems

Problem 1

Describe the transformations that map \(f(x) = x^2\) to \(g(x) = -2(x - 3)^2 + 4\). Then find the domain, range, and vertex of \(g(x)\).

Problem 2

Write the equation of a function that is obtained by reflecting \(f(x) = \sqrt{x}\) across the y-axis, then shifting 2 units up and 3 units to the right.

Problem 3

Find the inverse of \(f(x) = \frac{2x - 1}{x + 3}\). State the domain and range of both functions.

Problem 4

A Ferris wheel has height modeled by \(h(t) = 25\sin(0.2t) + 27\) where \(t\) is in minutes. Find the maximum and minimum heights, and the time for one complete revolution.

Problem 5

Graph \(f(x) = |x - 2| + 1\) by hand. Identify the vertex, domain, range, and any transformations from the parent function \(f(x) = |x|\).

Problem 6

Given \(f(x) = 3x - 2\) and \(g(x) = x^2 - 1\), find \(f(g(x))\) and \(g(f(x))\). Determine which composition represents a vertical stretch of the original function.

Problem 7

A company's profit is modeled by \(P(x) = -x^3 + 6x^2 - 9x + 4\) where \(x\) is thousands of units. Find the break-even points and interpret them in context.

Problem 8

Find the domain and range of \(f(x) = \frac{1}{\sqrt{x - 2}} + 3\). Explain why the domain is restricted.

Bonus Problems

Bonus Problem 1

Given \(f(x) = 2x + 1\) and \(g(x) = x^2 - 3\), find all values of \(a\) such that \(f(g(a)) = g(f(a))\).

Bonus Problem 2

A function has the property that \(f(f(x)) = x\) for all \(x\) in its domain. If \(f(2) = 5\), find \(f(5)\) and \(f(f(2))\). Can you find a general form for such functions?
