Problem Set 6: Systems and Inequalities

Precalculus 11 - Chapter 7 Solutions

Solutions

Problem 1: Solve by elimination: \(2x + y = 7\) and \(3x - y = 5\)
Add equations to eliminate \(y\): \((2x + y) + (3x - y) = 7 + 5\)
\(5x = 12\)
\(x = \frac{12}{5}\)
Substitute into first equation: \(2(\frac{12}{5}) + y = 7\)
\(\frac{24}{5} + y = 7\)
\(y = 7 - \frac{24}{5} = \frac{35 - 24}{5} = \frac{11}{5}\)
Answer: \((\frac{12}{5}, \frac{11}{5})\)
Problem 2: Solve by substitution: \(y = x^2 - 4\) and \(y = 2x + 1\)
Set equations equal: \(x^2 - 4 = 2x + 1\)
Rearrange: \(x^2 - 2x - 5 = 0\)
Use quadratic formula: \(x = \frac{2 \pm \sqrt{4 + 20}}{2} = \frac{2 \pm \sqrt{24}}{2} = 1 \pm \sqrt{6}\)
Find \(y\) for each \(x\) using \(y = 2x + 1\)
For \(x = 1 + \sqrt{6}\): \(y = 2(1 + \sqrt{6}) + 1 = 3 + 2\sqrt{6}\)
For \(x = 1 - \sqrt{6}\): \(y = 2(1 - \sqrt{6}) + 1 = 3 - 2\sqrt{6}\)
Answer: \((1 + \sqrt{6}, 3 + 2\sqrt{6})\) and \((1 - \sqrt{6}, 3 - 2\sqrt{6})\)
Problem 3: Graph \(y > 2x - 3\)
Graph the boundary line \(y = 2x - 3\) as a dashed line (strict inequality)
The line has slope 2 and y-intercept -3
Test point (0, 0): \(0 > 2(0) - 3 = -3\) ✓
Shade the region containing (0, 0) - above the line
Answer: Region above the dashed line \(y = 2x - 3\)
Problem 4: Graph the system: \(y \leq x + 2\) and \(y > -x + 1\)
First inequality: \(y \leq x + 2\) - solid line, shade below
Second inequality: \(y > -x + 1\) - dashed line, shade above
Find intersection: \(x + 2 = -x + 1\), so \(2x = -1\), \(x = -\frac{1}{2}\)
At \(x = -\frac{1}{2}\): \(y = \frac{3}{2}\)
Solution region is the overlapping shaded area
Answer: Bounded region between the two lines from \(x = -\frac{1}{2}\) to infinity
Problem 5: Solve the system of 3 equations with 2 unknowns
Check if system is consistent. Use first two equations:
From equations 1 and 2: \(2x + 3y = 12\) and \(x - y = 1\)
From \(x - y = 1\): \(x = y + 1\)
Substitute into first: \(2(y+1) + 3y = 12\)
\(2y + 2 + 3y = 12\), so \(5y = 10\), \(y = 2\)
\(x = 3\)
Check with third equation: \(3(3) + 2 = 11 \neq 14\) - inconsistent!
Answer: No solution - the system is inconsistent
Problem 6: Rectangle perimeter inequality
Let width = \(w\), length = \(2w + 5\)
Perimeter: \(P = 2(w + 2w + 5) = 2(3w + 5) = 6w + 10\)
Inequality: \(6w + 10 \leq 50\)
Solve: \(6w \leq 40\), so \(w \leq \frac{40}{6} = \frac{20}{3}\)
Also: \(w > 0\) (positive width)
Answer: \(0 < w \leq \frac{20}{3}\) (or approximately 0 < w ≤ 6.67)

Bonus Solutions

Bonus Problem 1: Parabola Point
Point on parabola: \(y = x^2 - 4x + 3\)
Distance from (x, y) to (2, 3) is 5:
\(\sqrt{(x-2)^2 + (y-3)^2} = 5\)
Square: \((x-2)^2 + (y-3)^2 = 25\)
Substitute y: \((x-2)^2 + (x^2 - 4x + 3 - 3)^2 = 25\)
Simplify: \((x-2)^2 + (x^2 - 4x)^2 = 25\)
Note: \(x^2 - 4x = x(x-4)\)
Let \(u = x - 2\), then \(x = u + 2\)
\((u)^2 + ((u+2)^2 - 4(u+2))^2 = 25\)
\(u^2 + (u^2 + 4u + 4 - 4u - 8)^2 = 25\)
\(u^2 + (u^2 - 4)^2 = 25\)
\(u^2 + u^4 - 8u^2 + 16 = 25\)
\(u^4 - 7u^2 - 9 = 0\)
Let \(v = u^2\): \(v^2 - 7v - 9 = 0\)
\(v = \frac{7 \pm \sqrt{49 + 36}}{2} = \frac{7 \pm \sqrt{85}}{2}\)
Since v = u² ≥ 0, we take the positive root
\(v = \frac{7 + \sqrt{85}}{2}\)
\(u = \pm\sqrt{v}\), so \(x = 2 \pm \sqrt{v}\)
Answer: Two points on the parabola at distance 5 from (2, 3).
Bonus Problem 2: Inequality Chain
First inequality: \(x^2 - 3x + 2 \leq 4\)
Rearrange: \(x^2 - 3x - 2 \leq 0\)
Find roots: \(x = \frac{3 \pm \sqrt{9 + 8}}{2} = \frac{3 \pm \sqrt{17}}{2}\)
Approximately: \(x \approx -0.56\) and \(x \approx 4.56\)
Since parabola opens up: \(x \in [\frac{3-\sqrt{17}}{2}, \frac{3+\sqrt{17}}{2}]\)
Second inequality: \(x^2 + x - 6 > 0\)
Factor: \((x + 3)(x - 2) > 0\)
Solution: \(x < -3\) or \(x > 2\)
Intersection: Need values in both solution sets
First set: approximately [-0.56, 4.56]
Second set: (-∞, -3) ∪ (2, ∞)
Intersection: \((2, \frac{3+\sqrt{17}}{2}]\)
Answer: \(x \in (2, \frac{3+\sqrt{17}}{2}]\)
Bonus Problem 3: Function Composition
Given \(f(x) = x^2 - 2x\)
Find \(f(f(x)) = f(x)\)
\(f(f(x)) = f(x^2 - 2x) = (x^2 - 2x)^2 - 2(x^2 - 2x)\)
Set equal to \(f(x)\):
\((x^2 - 2x)^2 - 2(x^2 - 2x) = x^2 - 2x\)
Let \(u = x^2 - 2x\). Then: \(u^2 - 2u = u\)
Rearrange: \(u^2 - 3u = 0\)
Factor: \(u(u - 3) = 0\)
So \(u = 0\) or \(u = 3\)
Case 1: \(x^2 - 2x = 0\), so \(x(x-2) = 0\), \(x = 0\) or \(x = 2\)
Case 2: \(x^2 - 2x = 3\), so \(x^2 - 2x - 3 = 0\)
Factor: \((x-3)(x+1) = 0\), \(x = 3\) or \(x = -1\)
Answer: \(x = -1, 0, 2, 3\)
