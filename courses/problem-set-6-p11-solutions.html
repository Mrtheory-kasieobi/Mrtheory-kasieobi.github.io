Solutions: Problem Set 6

Radical Expressions - Precalculus 11
Solution 1
Problem: Simplify: \(\sqrt{72}\)
Factor 72: \(\sqrt{36 \cdot 2}\)
Simplify: \(\sqrt{36} \cdot \sqrt{2} = 6\sqrt{2}\)
Answer: \(\boxed{6\sqrt{2}}\)
Solution 2
Problem: Simplify: \(\sqrt[3]{162}\)
Factor 162: \(\sqrt[3]{27 \cdot 6}\)
Simplify: \(\sqrt[3]{27} \cdot \sqrt[3]{6} = 3\sqrt[3]{6}\)
Answer: \(\boxed{3\sqrt[3]{6}}\)
Solution 3
Problem: Simplify: \(\sqrt{50x^3y^2}\) where \(x, y \geq 0\)
Factor: \(\sqrt{25x^2y^2 \cdot 2x}\)
Simplify: \(\sqrt{25x^2y^2} \cdot \sqrt{2x} = 5xy\sqrt{2x}\)
Answer: \(\boxed{5xy\sqrt{2x}}\)
Solution 4
Problem: Rationalize the denominator: \(\frac{5}{\sqrt{3}}\)
Multiply numerator and denominator by \(\sqrt{3}\)
\(\frac{5}{\sqrt{3}} \cdot \frac{\sqrt{3}}{\sqrt{3}} = \frac{5\sqrt{3}}{3}\)
Answer: \(\boxed{\frac{5\sqrt{3}}{3}}\)
Solution 5
Problem: Solve: \(\sqrt{2x + 3} = 5\)
Square both sides: \(2x + 3 = 25\)
Subtract 3: \(2x = 22\)
Divide: \(x = 11\)
Check: \(\sqrt{2(11)+3} = \sqrt{25} = 5\) ✓
Answer: \(\boxed{x = 11}\)
Solution 6
Problem: Solve: \(\sqrt{x + 7} + 2 = 5\)
Isolate radical: \(\sqrt{x + 7} = 3\)
Square both sides: \(x + 7 = 9\)
Solve: \(x = 2\)
Check: \(\sqrt{2+7} + 2 = 3 + 2 = 5\) ✓
Answer: \(\boxed{x = 2}\)
Solution 7
Problem: Expand: \((\sqrt{5} + \sqrt{2})^2\)
Use binomial formula: \((a+b)^2 = a^2 + 2ab + b^2\)
Substitute: \((\sqrt{5})^2 + 2(\sqrt{5})(\sqrt{2}) + (\sqrt{2})^2\)
Simplify: \(5 + 2\sqrt{10} + 2\)
Answer: \(\boxed{7 + 2\sqrt{10}}\)
Solution 8
Problem: Find the perimeter of a square with area 49.
Find side length: \(s^2 = 49\), so \(s = 7\)
Perimeter: \(P = 4s = 4 \cdot 7 = 28\)
Answer: \(\boxed{28 \text{ units}}\)

Bonus Solutions

Bonus Solution 1
Problem: Solve: \(\sqrt{3x - 2} \cdot \sqrt{x + 4} = 6\). Then simplify \(\sqrt{7 + 4\sqrt{3}} - \sqrt{7 - 4\sqrt{3}}\).
First: \(\sqrt{(3x-2)(x+4)} = 6\)
Square: \((3x-2)(x+4) = 36\)
Expand: \(3x^2 + 10x - 8 = 36\)
Solve: \(3x^2 + 10x - 44 = 0\)
Use quadratic formula or factor: \((3x+22)(x-2) = 0\)
Solutions: \(x = 2\) (valid) or \(x = -\frac{22}{3}\) (invalid - makes radical negative)
Second part: Recognize \(7 + 4\sqrt{3} = (2+\sqrt{3})^2\)
So \(\sqrt{7 + 4\sqrt{3}} = 2 + \sqrt{3}\)
Similarly \(\sqrt{7 - 4\sqrt{3}} = |2-\sqrt{3}| = 2 - \sqrt{3}\)
Answer: \((2+\sqrt{3}) - (2-\sqrt{3}) = 2\sqrt{3}\)
Bonus Solution 2
Problem: Simplify: \(\frac{\sqrt{18} - \sqrt{8}}{\sqrt{2}}\). Hence, find the value of \(\sqrt{12} - \sqrt{3} - \sqrt{2} + \sqrt{6}\).
Simplify numerator: \(\sqrt{18} = 3\sqrt{2}\), \(\sqrt{8} = 2\sqrt{2}\)
Fraction: \(\frac{3\sqrt{2} - 2\sqrt{2}}{\sqrt{2}} = \frac{\sqrt{2}}{\sqrt{2}} = 1\)
Now find: \(\sqrt{12} - \sqrt{3} - \sqrt{2} + \sqrt{6}\)
Simplify: \(2\sqrt{3} - \sqrt{3} - \sqrt{2} + \sqrt{6}\)
Combine: \(\sqrt{3} - \sqrt{2} + \sqrt{6}\)
Factor: \(\sqrt{3} + \sqrt{6} - \sqrt{2} = \sqrt{3}(1 + \sqrt{2}) - \sqrt{2}\)
Answer: \(\boxed{\sqrt{3} + \sqrt{6} - \sqrt{2}}\)
