Problem Set 5 Solutions: Radical, Rational, Absolute Value

Precalculus 11 - Solutions
Topics: Radical Expressions, Rational Expressions, Absolute Value

Solutions

Problem 1

Simplify: \(\sqrt{48} + \sqrt{27}\)

Solution:

\(\sqrt{48} = \sqrt{16 \times 3} = 4\sqrt{3}\)

\(\sqrt{27} = \sqrt{9 \times 3} = 3\sqrt{3}\)

\(\sqrt{48} + \sqrt{27} = 4\sqrt{3} + 3\sqrt{3} = 7\sqrt{3}\)

Problem 2

Rationalize the denominator: \(\frac{5}{\sqrt{3} + 1}\)

Solution:

Multiply by conjugate: \(\frac{5}{\sqrt{3} + 1} \cdot \frac{\sqrt{3} - 1}{\sqrt{3} - 1}\)

\(= \frac{5(\sqrt{3} - 1)}{3 - 1} = \frac{5(\sqrt{3} - 1)}{2}\)

Problem 3

Solve: \(\sqrt{2x + 5} = 7\)

Solution:

Square both sides: \(2x + 5 = 49\)

\(2x = 44\)

\(x = 22\)

Check: \(\sqrt{2(22) + 5} = \sqrt{49} = 7\) ✓

Problem 4

Solve: \(\sqrt{x + 4} + 2 = x\)

Solution:

Isolate: \(\sqrt{x + 4} = x - 2\)

Square: \(x + 4 = (x - 2)^2 = x^2 - 4x + 4\)

\(x^2 - 5x = 0\)

\(x(x - 5) = 0\)

Check: \(x = 0\) gives \(\sqrt{4} + 2 = 4 \neq 0\) ✗

Check: \(x = 5\) gives \(\sqrt{9} + 2 = 5\) ✓

Solution: \(x = 5\)

Problem 5

Simplify: \(\frac{x^2 - 9}{x^2 - 5x + 4}\)

Solution:

Numerator: \(x^2 - 9 = (x + 3)(x - 3)\)

Denominator: \(x^2 - 5x + 4 = (x - 1)(x - 4)\)

\(\frac{x^2 - 9}{x^2 - 5x + 4} = \frac{(x + 3)(x - 3)}{(x - 1)(x - 4)}\)

Restrictions: \(x \neq 1, 4\)

Problem 6

Multiply: \(\frac{x + 3}{x - 2} \cdot \frac{x^2 - 4}{x^2 + 6x + 9}\)

Solution:

Factor: \(\frac{x + 3}{x - 2} \cdot \frac{(x + 2)(x - 2)}{(x + 3)^2}\)

Cancel: \(\frac{1}{x - 2} \cdot \frac{x + 2}{x + 3} = \frac{x + 2}{(x - 2)(x + 3)}\)

Problem 7

Solve: \(\frac{2}{x} + \frac{3}{x - 1} = 1\)

Solution:

LCD = \(x(x - 1)\)

\(\frac{2(x - 1) + 3x}{x(x - 1)} = 1\)

\(2x - 2 + 3x = x^2 - x\)

\(x^2 - 6x + 2 = 0\)

\(x = \frac{6 \pm \sqrt{36 - 8}}{2} = 3 \pm \sqrt{2}\)

Problem 8

Solve: \(|2x - 3| = 7\)

Solution:

Case 1: \(2x - 3 = 7\) → \(x = 5\)

Case 2: \(2x - 3 = -7\) → \(x = -2\)

Solutions: \(x = 5\) or \(x = -2\)

Problem 9

Solve: \(|3x + 2| \leq 8\)

Solution:

\(-8 \leq 3x + 2 \leq 8\)

\(-10 \leq 3x \leq 6\)

\(-\frac{10}{3} \leq x \leq 2\)

Problem 10

Graph \(f(x) = -|x + 2| + 3\) and identify the vertex and transformations.

Solution:

Vertex: \((-2, 3)\)

Transformations: Shift left 2, up 3, reflect across x-axis

Maximum value: 3 (opens downward)

Bonus Solutions

Bonus Solution 1

Solution:

\(\frac{\sqrt{18} + \sqrt{8}}{\sqrt{2}} = \frac{3\sqrt{2} + 2\sqrt{2}}{\sqrt{2}} = \frac{5\sqrt{2}}{\sqrt{2}} = 5\)

Bonus Solution 2

Solution:

\(x^2 - 1 = (x-1)(x+1)\), so \(\frac{1}{x-1} + \frac{2}{x+1} = \frac{3}{(x-1)(x+1)}\)

Multiply both sides by \(x^2 - 1\): \(1(x+1) + 2(x-1) = 3\)

\(x + 1 + 2x - 2 = 3\), so \(3x = 4\), giving \(x = \frac{4}{3}\)
