Trigonometry and the Unit Circle

Precalculus 12 - Lecture Notes
British Columbia Curriculum | Last Updated: 2026

1. Angle Measurement

Angles are fundamental to understanding periodic phenomena. We measure angles in degrees or radians, each with its place in mathematics.

1.1 Degrees and Radians

The degree system divides a circle into 360 equal parts. The radian system is based on the radius of a circle.

Key Relationships:
360° = 2π radians
180° = π radians
90° = π/2 radians
Conversion:
\(\text{radians} = \text{degrees} \times \frac{\pi}{180}\)
\(\text{degrees} = \text{radians} \times \frac{180}{\pi}\)

1.2 Coterminal Angles

Two angles are coterminal if they share the same terminal side. Coterminal angles differ by multiples of 2π radians (or 360°).

Example 1: Finding Coterminal Angles

Find an angle coterminal to \(\frac{5\pi}{3}\):

\(\frac{5\pi}{3} + 2\pi = \frac{5\pi}{3} + \frac{6\pi}{3} = \frac{11\pi}{3}\)

1.3 Reference Angles

The reference angle is the acute angle to the x-axis. It's always positive and between 0 and π/2 (0° and 90°).

Quadrant Reference Angle Formula
I (0 to π/2) θ
II (π/2 to π) π - θ
III (π to 3π/2) θ - π
IV (3π/2 to 2π) 2π - θ

2. Special Angles and Exact Values

2.1 30-60-90 and 45-45-90 Triangles

The unit circle values come from two special right triangles.

30-60-90 Triangle:

Sides are in ratio 1 : √3 : 2

Correct trig values: sin 30° = 1/2, cos 30° = √3/2

45-45-90 Triangle:

Sides are in ratio 1 : 1 : √2

Correct trig values: sin 45° = cos 45° = √2/2

2.2 The Complete Unit Circle

Angle (rad) Angle (°) \(\cos\theta\) \(\sin\theta\) \(\tan\theta\)
0 0° 1 0 0
π/6 30° √3/2 1/2 √3/3
π/4 45° √2/2 √2/2 1
π/3 60° 1/2 √3/2 √3
π/2 90° 0 1 ∞

2.3 Where Do These Values Come From?

Consider a 30-60-90 triangle inscribed in the unit circle. If the hypotenuse is 1 (the radius), the side opposite 30° is 1/2, and the side adjacent is √3/2. The coordinates on the unit circle are (cos θ, sin θ).

3. The Trigonometric Functions

3.1 Definitions on the Unit Circle

For an angle θ in standard position on the unit circle:

Primary Functions:
\(\sin\theta = y\) (y-coordinate)
\(\cos\theta = x\) (x-coordinate)
\(\tan\theta = \frac{y}{x}\) (where x ≠ 0)

3.2 Domain, Range, Zeros, and Asymptotes

Function Domain Range X-Intercepts Vertical Asymptotes
\(\sin x\) All real numbers \([-1, 1]\) \(x = n\pi\) None
\(\cos x\) All real numbers \([-1, 1]\) \(x = \frac{\pi}{2} + n\pi\) None
\(\tan x\) All real numbers except \(\frac{\pi}{2} + n\pi\) All real numbers \(x = n\pi\) \(x = \frac{\pi}{2} + n\pi\)

3.3 Amplitude and Period

For transformed functions \(y = a \sin(bx + c) + d\) and \(y = a \cos(bx + c) + d\):

  • Amplitude = |a| (distance from midline to maximum)
  • Period = \(\frac{2\pi}{|b|}\) (one complete cycle)
  • Phase shift = \(-\frac{c}{b}\) (horizontal shift)
  • Vertical shift = d (midline: y = d)
Example 4: Identifying Parameters

For \(f(x) = -3\sin(2x - \pi) + 1\):

Amplitude = 3, Period = π, Phase shift = π/2, Vertical shift = 1, Midline: y = 1

4. Transformations of Trigonometric Functions

Sine Transformation:
\(y = a \sin(b(x - h)) + k\)

Cosine Transformation:
\(y = a \cos(b(x - h)) + k\)

Tangent Transformation:
\(y = a \tan(b(x - h)) + k\)
Parameter Effect on Sine/Cosine Effect on Tangent
\(a\) Vertical stretch by |a|, reflection if a < 0 Vertical stretch by |a|, reflection if a < 0
\(b\) Horiz. compression by 1/|b|, period = 2π/|b| Horiz. compression by 1/|b|, period = π/|b|
\(h\) Horizontal shift by h units Horizontal shift by h units
\(k\) Vertical shift (midline) Vertical shift ( asymptote at y = k )
Example 5: Graphing a Transformed Sine Function

Graph \(y = 2\sin(x + \frac{\pi}{3}) - 1\):

Amplitude = 2, Period = 2π, Phase shift = -π/3, Vertical shift = -1

5. Trigonometric Equations

5.1 Solving Basic Equations

Equations of the form \(\sin x = a\), \(\cos x = a\), or \(\tan x = a\) are solved using reference angles and quadrant analysis.

5.2 Solving Equations with Transformations

For equations like \(a \sin(bx + c) + d = 0\), isolate the trigonometric function and apply inverse functions.

Example 6: Solving with Transformations

Solve \(2\sin(x) - 1 = 0\) for \(x \in [0, 2\pi)\):

\(\sin x = \frac{1}{2}\)

Reference angle: π/6

Solutions: \(x = \frac{\pi}{6}, \frac{5\pi}{6}\)

6. Trigonometric Identities

6.1 Pythagorean Identities

Derived from the Pythagorean theorem applied to the unit circle:

\(\sin^2\theta + \cos^2\theta = 1\)
\(1 + \tan^2\theta = \sec^2\theta\)
\(1 + \cot^2\theta = \csc^2\theta\)

6.2 Reciprocal Identities

\(\csc\theta = \frac{1}{\sin\theta}, \quad \sec\theta = \frac{1}{\cos\theta}, \quad \cot\theta = \frac{1}{\tan\theta}\)

6.3 Quotient Identities

\(\tan\theta = \frac{\sin\theta}{\cos\theta}, \quad \cot\theta = \frac{\cos\theta}{\sin\theta}\)

7. Practice Problems

Problem 1

Convert \(240°\) to radians and find the reference angle. Determine the values of \(\sin 240°\) and \(\cos 240°\) without a calculator.

Problem 2

Graph \(y = -\frac{3}{2}\cos(2x + \pi) + 1\) and state the amplitude, period, and phase shift.

Problem 3

Solve \(2\cos x + \sqrt{3} = 0\) for \(x \in [0, 2\pi)\). Give all solutions in radians.

Problem 4

Verify the identity: \(\frac{\sin\theta}{1 + \cos\theta} = \frac{1 - \cos\theta}{\sin\theta}\)
