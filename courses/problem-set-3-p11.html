Problem Set 3: Trigonometry

Precalculus 11 · 8 problems Medium

Problems

Problem 1

Convert \(240°\) to radians.

Problem 2

Find \(\sin \frac{5\pi}{6}\), \(\cos \frac{5\pi}{6}\), and \(\tan \frac{5\pi}{6}\) using the unit circle.

Problem 3

Find all angles \(\theta\) in \([0°, 360°]\) such that \(\sin \theta = \frac{1}{2}\).

Problem 4

A triangle has sides \(a = 8\), \(b = 10\), and included angle \(C = 60°\). Find side \(c\) using the Cosine Law.

Problem 5

In triangle ABC, \(a = 7\), \(b = 10\), \(c = 5\). Find angle \(C\) using the Cosine Law.

Problem 6

In triangle ABC, \(a = 6\), \(b = 8\), angle \(C = 45°\). Find angle \(A\) using the Sine Law.

Problem 7

Find the area of a triangle with sides \(a = 10\), \(b = 12\), included angle \(C = 30°\).

Problem 8

Simplify: \(\sin^2 \theta + \cos^2 \theta\) and \(\tan \theta \cdot \cot \theta\).

Bonus Problems

Bonus Problem 1 Hard

A triangle has sides 7, 8, and 9. Find all three angles using the Cosine Law.

Bonus Problem 2 Hard

Find all angles \(\theta\) in \([0, 2\pi)\) where \(\sin \theta = \cos \theta\).
