Problem Set 1 Solutions: Sequences and Series

Precalculus 11 - Solutions
Topics: Sequences, Series, Sigma Notation

Solutions

Problem 1

Find the 15th term of the arithmetic sequence: \(7, 11, 15, 19, \ldots\)

Solution:

Identify: \(a_1 = 7\), \(d = 4\)

Using the formula: \(a_n = a_1 + (n-1)d\)

\(a_{15} = 7 + (15-1)(4) = 7 + 56 = 63\)

Problem 2

Find the sum of the first 12 terms of the geometric sequence: \(5, 10, 20, 40, \ldots\)

Solution:

Identify: \(a_1 = 5\), \(r = 2\), \(n = 12\)

Using the formula: \(S_n = \frac{a_1(1 - r^n)}{1 - r}\)

\(S_{12} = \frac{5(1 - 2^{12})}{1 - 2} = \frac{5(1 - 4096)}{-1} = 5(4095) = 20475\)

Problem 3

Evaluate: \(\sum_{k=1}^{10} (4k - 3)\)

Solution:

\(\sum_{k=1}^{10} (4k - 3) = 4\sum_{k=1}^{10} k - \sum_{k=1}^{10} 3\)

\(= 4 \cdot \frac{10(11)}{2} - 3(10) = 4(55) - 30 = 220 - 30 = 190\)

Problem 4

Find the sum of the infinite geometric series: \(1 + \frac{1}{3} + \frac{1}{9} + \frac{1}{27} + \ldots\)

Solution:

Identify: \(a_1 = 1\), \(r = \frac{1}{3}\) (converges since \(|r| < 1\))

Using the formula: \(S_\infty = \frac{a_1}{1 - r}\)

\(S_\infty = \frac{1}{1 - \frac{1}{3}} = \frac{1}{\frac{2}{3}} = \frac{3}{2}\)

Problem 5

A ball is dropped from a height of 100 meters. On each bounce, it rebounds to 75% of its previous height. Find the total vertical distance traveled by the ball after 10 bounces.

Solution:

Initial drop: 100 m

Each bounce: down and up, so total = \(100 + 2 \sum_{i=1}^{10} 100(0.75)^i\)

\(\sum_{i=1}^{10} 100(0.75)^i = 100 \cdot \frac{0.75(1 - 0.75^{10})}{1 - 0.75} = 100 \cdot \frac{0.75(1 - 0.075)}{0.25} \approx 281.25\)

Total distance: \(100 + 2(281.25) = 662.5\) m

Problem 6

Find the 20th term of the geometric sequence where the first term is 3 and the common ratio is \(\frac{1}{2}\).

Solution:

Using the formula: \(a_n = a_1 \cdot r^{n-1}\)

\(a_{20} = 3 \cdot \left(\frac{1}{2}\right)^{19} = \frac{3}{524288} \approx 0.0000057\)

Problem 7

Evaluate: \(\sum_{i=1}^{8} (2i^2 - i)\)

Solution:

\(\sum_{i=1}^{8} (2i^2 - i) = 2\sum_{i=1}^{8} i^2 - \sum_{i=1}^{8} i\)

\(= 2 \cdot \frac{8(9)(17)}{6} - \frac{8(9)}{2} = 2(204) - 36 = 408 - 36 = 372\)

Problem 8

A savings account starts with $500 and earns 5% interest compounded monthly. Find the balance after 3 years.

Solution:

Using compound interest formula: \(A = P\left(1 + \frac{r}{n}\right)^{nt}\)

\(A = 500\left(1 + \frac{0.05}{12}\right)^{12 \cdot 3} = 500(1.004167)^{36} \approx 584.16\)

Units digit: 5 (since \(2^{20}\) ends in 6, and \(6 - 1 = 5\))

Bonus Solution 2

Solution:

Let first term = \(a\). Arithmetic: \(a + d = 4\), \(a + 2d = 7\) → \(d = 3\), \(a = 1\)

Geometric: \(a + r = 6\), \(a + r^2 = 12\) → \(r = 5\), \(a = 1\)

Check: Both have first term 1. Arithmetic 10th term: \(a_{10} = 1 + 9(3) = 28\)
