Function Transformations

Precalculus 12 - Lecture Notes
British Columbia Curriculum | Last Updated: 2026

1. Introduction to Function Transformations

Function transformations allow us to modify the graph of a function by shifting, stretching, compressing, or reflecting it. Understanding transformations systematically helps us graph complex functions and analyze their behavior. The general form combines all transformations:

General Form:
\[f(x) = a \cdot f(x - h) + k\]
where each parameter controls a different transformation.

2. Horizontal and Vertical Translations

2.1 Vertical Translations

Vertical translations shift a function up or down by adding or subtracting a constant to the function output.

Vertical Translation:
\[f(x) \pm k \text{ shifts the graph } k \text{ units up (or down if negative)}\]
Example 1: Vertical Translation

Given \(f(x) = x^2\), compare \(f(x) = x^2\) and \(g(x) = x^2 + 3\).

The graph of \(g(x)\) is the graph of \(f(x)\) shifted 3 units upward.

Key points: \((0,0) \to (0,3)\), \((1,1) \to (1,4)\), \((-1,1) \to (-1,4)\)

2.2 Horizontal Translations

Horizontal translations shift a function left or right by adding or subtracting a constant to the input.

Important Note:

For horizontal translations, the direction is opposite to the sign! \(f(x + k)\) shifts left, \(f(x - k)\) shifts right.

Horizontal Translation:
\[f(x \pm k) \text{ shifts the graph } k \text{ units right (or left if negative)}\]
Example 2: Horizontal Translation

Given \(f(x) = \sqrt{x}\), compare \(f(x) = \sqrt{x}\) and \(g(x) = \sqrt{x - 2}\).

The graph of \(g(x)\) is the graph of \(f(x)\) shifted 2 units to the right.

Domain changes from \([0, \infty)\) to \([2, \infty)\)

3. Reflections and Stretches

3.1 Reflections

Reflections flip the graph across the x-axis or y-axis.

Reflections:
\[-f(x) \text{ reflects across the x-axis}\]
\[f(-x) \text{ reflects across the y-axis}\]
Example 3: Reflections

Given \(f(x) = x^3\), compare:

\(g(x) = -x^3\) (reflection across x-axis)

\(h(x) = (-x)^3 = -x^3\) (reflection across y-axis)

3.2 Vertical Stretches and Compressions

Multiplying the function by a constant stretches or compresses it vertically.

Vertical Transformations:
\[a \cdot f(x) \text{ where } |a| > 1 \text{ stretches vertically}\]
\[a \cdot f(x) \text{ where } 0 < |a| < 1 \text{ compresses vertically}\]
Example 4: Vertical Stretch

Given \(f(x) = x^2\), compare \(g(x) = 2x^2\) and \(h(x) = 0.5x^2\).

\(g(x)\) is stretched vertically by factor 2

\(h(x)\) is compressed vertically by factor 0.5

3.3 Horizontal Stretches and Compressions

Multiplying the input by a constant stretches or compresses the graph horizontally.

Important Note:

For horizontal transformations, the factor is inverted! \(f(bx)\) where \(b > 1\) compresses, \(0 < b < 1\) stretches.

Horizontal Transformations:
\[f(bx) \text{ where } b > 1 \text{ compresses horizontally by factor } 1/b\]
\[f(bx) \text{ where } 0 < b < 1 \text{ stretches horizontally by factor } 1/b\]

4. Combining Transformations

When multiple transformations are applied, the order matters. The standard form is:

General Form:
\[f(x) = a \cdot f(x - h) + k\]
where:
  • \(h\) = horizontal shift (right if positive)
  • \(k\) = vertical shift (up if positive)
  • \(a\) = vertical stretch/compression and reflection
Example 5: Combining Transformations

Analyze \(f(x) = -2(x - 3)^2 + 4\)

Starting from \(g(x) = x^2\):

  1. Shift right 3 units: \((x - 3)^2\)
  2. Vertical stretch by 2: \(2(x - 3)^2\)
  3. Reflect across x-axis: \(-2(x - 3)^2\)
  4. Shift up 4 units: \(-2(x - 3)^2 + 4\)

Vertex: \((3, 4)\)

5. Transformations of Absolute Value Functions

The absolute value function \(f(x) = |x|\) has a characteristic V-shape. Its transformations follow the same rules.

Absolute Value Transformations:
\[f(x) = a|x - h| + k\]
Example 6: Absolute Value Transformation

Graph \(f(x) = -|x + 2| + 3\)

Starting from \(g(x) = |x|\):

  1. Shift left 2 units: \(|x + 2|\)
  2. Reflect across x-axis: \(-|x + 2|\)
  3. Shift up 3 units: \(-|x + 2| + 3\)

Vertex: \((-2, 3)\)

6. Inverse of a Relation

The inverse of a function reverses the input and output. Understanding inverse relationships is fundamental to many areas of mathematics.

6.1 Inverse Relations

Definition: Given a relation \(R\) with ordered pairs \((x, y)\), the inverse relation \(R^{-1}\) consists of the ordered pairs \((y, x)\).

For a function \(f\), the inverse notation \(f^{-1}\) represents a relation where if \(f(x) = y\), then \(f^{-1}(y) = x\).

6.2 One-to-One Functions

Definition: A function is one-to-one (injective) if each output corresponds to exactly one input. Formally, if \(f(a) = f(b)\), then \(a = b\).
Importance Note:

Only one-to-one functions have inverse functions. If a function is not one-to-one, we can restrict its domain to make it one-to-one.

6.3 Horizontal-Line Test

A function has an inverse that is also a function if and only if no horizontal line intersects its graph more than once.

Example: Applying the Horizontal-Line Test

Test the function \(f(x) = x^2\):

A horizontal line at \(y = 4\) intersects \(f(x) = x^2\) at both \((-2, 4)\) and \((2, 4)\)

Therefore, \(f(x) = x^2\) is NOT one-to-one over its entire domain.

However, if we restrict the domain to \(x \geq 0\), then \(f(x) = x^2\) IS one-to-one.

6.4 Finding Inverses Algebraically

Steps to Find Inverse Algebraically:
  1. Replace \(f(x)\) with \(y\)
  2. Swap \(x\) and \(y\)
  3. Solve for \(y\)
  4. Replace \(y\) with \(f^{-1}(x)\)
  5. State the domain restriction if necessary
Example 7: Linear Function Inverse

Find the inverse of \(f(x) = 3x - 4\)

Step 1: \(y = 3x - 4\)

Step 2: \(x = 3y - 4\)

Step 3: \(x + 4 = 3y\), so \(y = \frac{x + 4}{3}\)

Step 4: \(f^{-1}(x) = \frac{x + 4}{3}\)

Domain of \(f^{-1}\): All real numbers

Example 8: Square Root Function Inverse

Find the inverse of \(f(x) = \sqrt{x - 2} + 1\) for \(x \geq 2\)

Step 1: \(y = \sqrt{x - 2} + 1\)

Step 2: \(x = \sqrt{y - 2} + 1\)

Step 3: \(x - 1 = \sqrt{y - 2}\)

Step 4: \((x - 1)^2 = y - 2\)

Step 5: \(y = (x - 1)^2 + 2\)

Step 6: \(f^{-1}(x) = (x - 1)^2 + 2\)

Domain of \(f^{-1}\): \(x \geq 1\) (output of \(f\) starts at 1)

6.5 Graphing Inverses

To graph the inverse of a function, reflect the original graph across the line \(y = x\). This is because points \((a, b)\) on \(f\) correspond to points \((b, a)\) on \(f^{-1}\)

Important Note:

The graph of \(f^{-1}\) is the reflection of the graph of \(f\) across the line \(y = x\).

Example 9: Graphing an Inverse

Given \(f(x) = 2x + 1\), graph \(f\) and \(f^{-1}\):

The point \((0, 1)\) on \(f\) corresponds to \((1, 0)\) on \(f^{-1}\)

The point \((1, 3)\) on \(f\) corresponds to \((3, 1)\) on \(f^{-1}\)

Draw the line \(y = x\) as a guide for reflection

7. Summary of Transformation Rules

Transformation Effect on Graph
\(f(x) + k\) Shift up \(k\) units
\(f(x) - k\) Shift down \(k\) units
\(f(x + h)\) Shift left \(h\) units
\(f(x - h)\) Shift right \(h\) units
\(-f(x)\) Reflect across x-axis
\(f(-x)\) Reflect across y-axis
\(a \cdot f(x), a > 1\) Vertical stretch by factor \(a\)
\(a \cdot f(x), 0 < a < 1\) Vertical compression by factor \(a\)
\(f(bx), b > 1\) Horizontal compression by factor \(1/b\)
\(f(bx), 0 < b < 1\) Horizontal stretch by factor \(1/b\)

8. Practice Problems

Problem 1

Describe the transformations applied to \(f(x) = x^2\) to obtain \(g(x) = -2(x + 3)^2 - 1\).

Problem 2

Find the inverse of \(f(x) = \sqrt{x + 4} - 2\) for the appropriate domain.

Problem 3

Write the equation of an absolute value function with vertex at \((-1, 3)\) that is reflected across the y-axis and vertically stretched by factor 2.
