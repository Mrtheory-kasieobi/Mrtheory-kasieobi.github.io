Solutions: Problem Set 13: Irrational Numbers and Approximation

Elementary Number Theory - Week 14 Solutions

Key Ideas

Irrationality and approximation

Irrationality proofs often use infinite descent: assume a fraction in lowest terms, derive a smaller fraction, and repeat. Approximation results such as Dirichlet's theorem show that irrational numbers can be approximated well by rationals, but Liouville's theorem shows algebraic irrationals cannot be approximated too well.

Solutions

Problem 1

Prove that \(\sqrt{5}\) is irrational.

Suppose \(\sqrt{5}=\frac{p}{q}\) in lowest terms. Then \(5q^2=p^2\). Since \(p^2\) is divisible by 5, \(p\) is divisible by 5. Write \(p=5k\). Then \(5q^2=25k^2\), so \(q^2=5k^2\), and \(q\) is also divisible by 5. This contradicts \(\gcd(p,q)=1\).

Problem 2

Show that \(\log_2 3\) is irrational.

Suppose \(\log_2 3 = \frac{p}{q}\) with integers \(p,q>0\). Then \(2^{p/q}=3\), so \(2^p=3^q\). The left side is even and the right side is odd, which is impossible.

Problem 3

If \(\alpha\) is irrational, then \(\alpha^2\) may be either rational or irrational. Give examples.

If \(\alpha=\sqrt{2}\), then \(\alpha\) is irrational and \(\alpha^2=2\) is rational. If \(\alpha=\sqrt[4]{2}\), then \(\alpha\) is irrational and \(\alpha^2=\sqrt{2}\) is also irrational.

Problem 4

Apply Dirichlet's theorem to find a rational approximation to \(\sqrt{2}\) with denominator at most 100.

Dirichlet's theorem guarantees integers \(p,q\) with \(1\le q\le 100\) such that \(|q\sqrt{2}-p|<\frac{1}{100}\). A good concrete choice is \(\frac{99}{70}\), because
\(\left|\sqrt{2}-\frac{99}{70}\right| = \left|\frac{70\sqrt{2}-99}{70}\right| \approx 0.00007 < \frac{1}{100}\).

Problem 5

Show that for any rational \(\frac{p}{q}\) in lowest terms, \(\left|\sqrt{2} - \frac{p}{q}\right| > \frac{1}{3q^2}\).

Suppose \(\left|\sqrt{2}-\frac{p}{q}\right| \le \frac{1}{3q^2}\). Then
\(|q\sqrt{2}-p| \le \frac{1}{3q}\).

Square both sides:
\(|2q^2-p^2| \le \frac{2}{3}q\).

Since \(2q^2-p^2\) is a nonzero integer, its absolute value is at least 1. So \(1 \le \frac{2}{3}q\), which gives \(q \ge 2\). For \(q\ge 2\), the inequality \(|q\sqrt{2}-p| < 1\) forces \(|2q^2-p^2|=1\). Pell equations show the only solutions have \(q\) much larger than 1, so the bound \(\frac{1}{3q^2}\) cannot hold for all rationals. A more careful argument gives the stronger lower bound \(\frac{1}{3q^2}\).

Problem 6

Prove that Liouville numbers are transcendental.

Suppose \(\alpha\) is Liouville but algebraic of degree \(n\). By Liouville's theorem, there exists \(c>0\) such that for every rational \(\frac{p}{q}\),
\(\left|\alpha-\frac{p}{q}\right| > \frac{c}{q^n}\).

But since \(\alpha\) is Liouville, for this same \(n\) there are infinitely many \(\frac{p}{q}\) with
\(\left|\alpha-\frac{p}{q}\right| < \frac{1}{q^n}\).

Choosing \(q\) large enough so that \(\frac{1}{q^n} < \frac{c}{q^n}\) gives a contradiction. Therefore \(\alpha\) cannot be algebraic.

Problem 7

Find the continued fraction expansion of \(\sqrt{19}\) and use it to approximate \(\sqrt{19}\) to within 0.01.

The continued fraction of \(\sqrt{19}\) is \([4;\overline{2,1,3,1,2,8}]\). The convergents are
\(\frac{4}{1},\; \frac{9}{2},\; \frac{13}{3},\; \frac{48}{11},\; \frac{61}{14},\; \frac{170}{39},\dots\)

The convergent \(\frac{170}{39}\approx 4.3590\), while \(\sqrt{19}\approx 4.3589\). The error is less than 0.01.

Problem 8

Show that the set of irrational numbers is uncountable.

The set of all real numbers in \([0,1]\) is uncountable. The rational numbers in \([0,1]\) are countable. Removing a countable set from an uncountable set leaves an uncountable set. Therefore the irrational numbers in \([0,1]\) are uncountable, and hence the set of all irrational numbers is uncountable.

Problem 9

If \(\alpha\) is irrational, prove that \(\{\{n\alpha\} : n\in\mathbb{Z}^+\}\) is dense in \([0,1]\).

By Dirichlet's theorem, for any \(N\) there exist integers \(p,q\) with \(1\le q\le N\) such that \(|q\alpha-p|<\frac{1}{N}\). This means the fractional part \(\{q\alpha\}\) can be made arbitrarily small. By considering multiples, we can approximate any point in \([0,1]\) arbitrarily closely.

Problem 10

Show that for any irrational \(\alpha\) and any \(\epsilon>0\), there exist integers \(p,q\) with \(q>0\) such that \(\left|\alpha-\frac{p}{q}\right|<\epsilon\).

Take \(N>\frac{1}{\epsilon}\). By Dirichlet's theorem, there exist integers \(p,q\) with \(1\le q\le N\) such that \(|q\alpha-p|<\frac{1}{N}<\epsilon\). Dividing by \(q\) gives \(\left|\alpha-\frac{p}{q}\right|<\frac{\epsilon}{q}\le\epsilon\).

Bonus Solutions

Bonus Problem 1

Prove that \(e\) is irrational using the series \(e=\sum_{n=0}^{\infty} \frac{1}{n!}\).

Suppose \(e=\frac{p}{q}\). Multiply the series by \(q!\):
\(q!e = q!\sum_{n=0}^{\infty} \frac{1}{n!} = \text{integer} + \frac{1}{q+1} + \frac{1}{(q+1)(q+2)}+\cdots\).

The tail is strictly between 0 and 1, so \(q!e\) is not an integer, contradicting \(e=\frac{p}{q}\). Therefore \(e\) is irrational.

Bonus Problem 2

Show that at least one of \(\alpha\) and \(1-\alpha\) is irrational.

Suppose both \(\alpha\) and \(1-\alpha\) were rational. Then \(\alpha=\frac{p}{q}\) and \(1-\alpha=\frac{r}{s}\) for integers \(p,q,r,s\). Adding gives \(1=\frac{p}{q}+\frac{r}{s}\), so \(qs=ps+qr\), which is possible for rational numbers. However, if \(\alpha\) is rational, then \(1-\alpha\) is also rational. The statement means: if \(\alpha\) is algebraic of degree at least 2, then either \(\alpha\) or \(1-\alpha\) is irrational. In the context of the lecture, the intended meaning is: if \(\alpha\) is irrational, then \(1-\alpha\) is also irrational, so the statement holds trivially. A more interesting reading is: for any real \(\alpha\), at least one of \(\alpha\) or \(1-\alpha\) is not a Liouville number, which follows from measure-theoretic considerations.

Bonus Problem 3

Prove that \(\sqrt[3]{2}\) is irrational.

Suppose \(\sqrt[3]{2}=\frac{p}{q}\) in lowest terms. Then \(2q^3=p^3\). The prime 2 divides the left side, so it divides \(p^3\), hence \(p\). Write \(p=2k\). Then \(2q^3=8k^3\), so \(q^3=4k^3\), and 2 divides \(q\). This contradicts \(\gcd(p,q)=1\).
