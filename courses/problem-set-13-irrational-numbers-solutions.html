Solutions: Problem Set 13: Irrational Numbers and Approximation

Elementary Number Theory - Week 14 Solutions

Key Definitions and Concepts

Irrational Number

A number that cannot be written as p/q for integers p, q with q ≠ 0.

Example: √2, √3, ..., e, π are irrational.

Solutions

Problem 1: Prove that √3 is irrational.

Proof by contradiction:

Assume √3 = a/b where a, b are coprime integers.
Then 3b² = a², so 3 | a².
Since 3 is prime: 3 | a. Write a = 3c.
3b² = 9c² → b² = 3c²
Thus 3 | b², so 3 | b.

We have 3 | a and 3 | b, contradicting gcd(a,b) = 1.

Conclusion: √3 is irrational.

Problem 2: Prove √5 is irrational using the prime factorization method.

Proof:

Assume √5 = a/b in lowest terms. Then a² = 5b².

In prime factorization: 5 divides a² an even number of times.

If a = ∏pᵢ^(eᵢ), then a² = ∏pᵢ^(2eᵢ), and 5 | a² means 5^(2e₅) appears.

Thus in a² = 5b², the factor 5 appears odd times on LHS (from RHS), even on LHS - contradiction.

Problem 4: Prove that e is irrational.

Proof (sketch): Use the series e = ∑(1/n!).

Assume e = a/b for integers a, b.

Consider N = b! × e = b! × ∑(1/n!) for n = 0 to ∞
N = b! × (1 + 1 + 1/2! + ... + 1/b! + 1/(b+1)! + 1/(b+2)! + ...)

Separate the terms:
N = b! × (sum up to 1/b!) + (1/(b+1) + 1/(b+1)(b+2) + ...)
The first part is an integer M.
The remainder R satisfies: 0 < R < 1/b + 1/b² + 1/b³ + ... = 1/(b-1) < 1

Contradiction: N is an integer, so N = M + R where M is integer and 0 < R < 1.

Bonus Solutions

Bonus Problem 1: Prove that log₂(3) is irrational.

Proof: Assume log₂(3) = p/q for coprime integers p, q.

Then 2^(p/q) = 3, so 2^p = 3^q.

LHS is a power of 2, RHS is a power of 3. They can only be equal if both are 1, requiring p = q = 0.

Contradiction. Therefore log₂(3) is irrational.
