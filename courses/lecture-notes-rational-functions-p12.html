Rational Functions

Precalculus 12 - Lecture Notes
British Columbia Curriculum | Last Updated: 2026

1. Introduction to Rational Functions

A rational function is a ratio of two polynomial functions.

Definition: A rational function is a function of the form \(f(x) = \frac{P(x)}{Q(x)}\) where \(P(x)\) and \(Q(x)\) are polynomials and \(Q(x) \neq 0\).

1.1 Domain and Asymptotes

The domain excludes values where the denominator equals zero. These zeros create vertical asymptotes.

Example 1: Finding Domain and Asymptotes

For \(f(x) = \frac{x + 1}{x - 2}\):

Domain: all real numbers except \(x = 2\)

Vertical asymptote: \(x = 2\)

Horizontal asymptote: \(y = 0\) (degree of numerator < degree of denominator)

2. Analysing Rational Functions

2.1 Finding Asymptotes

To find horizontal asymptotes, compare the degrees of numerator and denominator.

Horizontal Asymptotes:
  • If degree(numerator) < degree(denominator): \(y = 0\)
  • If degree(numerator) = degree(denominator): \(y = \frac{a_n}{b_m}\)
  • If degree(numerator) > degree(denominator): no horizontal asymptote

2.2 Oblique Asymptotes

When the degree of numerator is exactly one more than the denominator, there is an oblique (slant) asymptote found by polynomial long division.

Example 2: Oblique Asymptote

Find the asymptote of \(f(x) = \frac{x^2 + 3x + 2}{x - 1}\).

Perform long division: \(f(x) = x + 4 + \frac{6}{x - 1}\)

Oblique asymptote: \(y = x + 4\)

Vertical asymptote: \(x = 1\)

3. Connecting Graphs and Rational Equations

3.1 Solving Rational Equations

To solve rational equations, multiply both sides by the LCD to eliminate denominators.

Example 3: Solving Rational Equations

Solve \(\frac{2}{x} + \frac{3}{x + 1} = 1\).

Multiply by LCD \(x(x + 1)\):

\(2(x + 1) + 3x = x(x + 1)\)

\(2x + 2 + 3x = x^2 + x\)

\(5x + 2 = x^2 + x\)

\(x^2 - 4x - 2 = 0\)

\(x = 2 \pm \sqrt{6}\) (check: \(x \neq 0, -1\))

4. Key Features Summary

Feature Description
Vertical Asymptotes Values where denominator = 0 (and numerator ≠ 0)
Horizontal Asymptotes Determined by comparing degrees of numerator and denominator
X-intercepts Values where numerator = 0 (and denominator ≠ 0)
Holes Values that make both numerator and denominator = 0
Domain All real numbers except where denominator = 0

5. Practice Problems

Problem 1

Find the domain, vertical asymptotes, and horizontal asymptotes of \(f(x) = \frac{2x^2 - 5x + 1}{x^2 - 4}\).

Problem 2

Solve \(\frac{x + 2}{x - 3} = \frac{2x - 1}{x + 4}\) and check for extraneous solutions.

Problem 3

Find the oblique asymptote of \(f(x) = \frac{x^3 - 2x}{x^2 + 1}\).
