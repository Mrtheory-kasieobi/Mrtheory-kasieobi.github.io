Problem Set 10: Linear and Quadratic Inequalities

Precalculus 11 · 8 problems Medium

Problems

Problem 1

Solve: \(2x + 5 > 11\)

Problem 2

Solve: \(-3x \leq 9\)

Problem 3

Solve the compound inequality: \(-2 < 3x + 1 < 10\)

Problem 4

Solve: \(x^2 - 5x + 6 > 0\)

Problem 5

Solve: \(x^2 + 4x + 3 \leq 0\)

Problem 6

Find the intersection of \(x^2 - 4 \geq 0\) and \(x < 3\)

Problem 7

Graph the solution to \(y \leq 2x - 3\) on a coordinate plane.

Problem 8

Solve: \(\frac{x - 1}{x + 2} > 0\)

Bonus Problems

Bonus Problem 1 Hard

Solve: \(\frac{x^2 - 1}{x^2 - 9} \leq 0\). Then find the range of \(k\) for which \(\frac{x^2 - kx + 4}{(x-1)(x-2)} > 0\) has no solution.

Bonus Problem 2 Hard

Find all x such that \(|x - 3| > 5\). Then solve \(|2x + 1| - |x - 3| \leq 4\)
