Lecture 13: Fermat's Last Theorem for n = 4

Lecture 13Fermat's Last Theorem for n = 4

1. Statement of the Theorem

Theorem 13.1 (Fermat's Last Theorem for n = 4) The equation \(x^4 + y^4 = z^4\) has no non-trivial integer solutions.

Equivalently, \(x^4 + y^4 = z^2\) has no non-trivial integer solutions.

Definition 13.1 (Primitive Solution) A solution \((x, y, z)\) is called primitive if \(\gcd(x, y, z) = 1\).

2. Proof by Infinite Descent

Theorem 13.2 If \(x^4 + y^4 = z^2\) has a solution, then there exists a smaller solution.
Proof (by infinite descent):
Step 1: Assume a primitive solution exists

Suppose \((x, y, z)\) is a primitive solution with \(x, y, z > 0\) and \(\gcd(x, y, z) = 1\).

Then \(x^4 + y^4 = z^2\) means \((x^2)^2 + (y^2)^2 = (z)^2\).

So \((x^2, y^2, z)\) is a Pythagorean triple.

Step 2: Apply Pythagorean parametrization

By Theorem 12.3, there exist \(m > n > 0\) with \(\gcd(m, n) = 1\) such that: \[x^2 = m^2 - n^2, \quad y^2 = 2mn, \quad z = m^2 + n^2\]

We can assume \(x\) is odd and \(y\) is even (by swapping if necessary).

Step 3: Analyze x² = m² - n²

We have \(x^2 + n^2 = m^2\), so \((x, n, m)\) is a Pythagorean triple.

Since \(\gcd(x, n, m) = 1\) (from \(\gcd(x^2, y^2, z) = 1\)), it's primitive.

By Theorem 12.3, there exist \(r > s > 0\) with \(\gcd(r, s) = 1\) such that: \[x = r^2 - s^2, \quad n = 2rs, \quad m = r^2 + s^2\]

Step 4: Use y² = 2mn

We have \(y^2 = 2mn = 2(r^2 + s^2)(m)\)

Wait, we need to be more careful. We have \(m = r^2 + s^2\) and \(n = 2rs\).

So \(y^2 = 2mn = 2(r^2 + s^2)(r^2 + s^2) = 2(r^2 + s^2)^2\)

This gives \(y = (r^2 + s^2)\sqrt{2}\), which is impossible since \(y\) is an integer.

Let me reconsider... Actually, \(y^2 = 2mn = 2(r^2 + s^2)(m)\)

No wait, \(m = r^2 + s^2\) and \(n = 2rs\), so: \[y^2 = 2mn = 2(r^2 + s^2)(m)\]

This is wrong. Let me redo this.

Correct calculation:

We have \(y^2 = 2mn\) with \(m = r^2 + s^2\) and \(n = 2rs\).

So \(y^2 = 2(r^2 + s^2)(2rs) = 4rs(r^2 + s^2)\)

Thus \(y^2 = 4rs(r^2 + s^2)\)

For this to be a perfect square, we need \(rs(r^2 + s^2)\) to be a perfect square.

Step 5: Conclude with infinite descent

Since \(\gcd(r, s) = 1\) and \(r^2 + s^2\) is coprime to both \(r\) and \(s\) (when they're coprime), each must be a perfect square.

Let \(r = a^2\), \(s = b^2\), \(r^2 + s^2 = c^2\).

Then \(a^4 + b^4 = c^2\), giving a smaller solution!

By infinite descent, no solution exists. \(\square\)

3. Corollary: FLT for n = 4

Corollary 13.1 The equation \(x^4 + y^4 = z^4\) has no non-trivial integer solutions.
Proof:

If \(x^4 + y^4 = z^4\), then \(x^4 + y^4 = (z^2)^2\), so \(x^4 + y^4 = w^2\) where \(w = z^2\).

This contradicts Theorem 13.2. \(\square\)

Exercises:
  1. Show that \(x^4 + y^4 = z^2\) has no solution with \(xyz = 1\).
  2. Prove that if \(x^4 + y^4 = z^2\) has a solution, then there's one with \(z\) even.
  3. Find the smallest positive integer \(n\) such that \(x^4 + y^4 = n\) has no integer solutions.
  4. Show that \(x^4 + 4y^4 = z^2\) has no non-trivial solutions.
  5. Prove: If \(x^4 + y^4 = z^2\) and \(\gcd(x, y) = 1\), then \(x, y\) have opposite parity.
  6. Show that \(x^4 + y^4 = 17z^2\) has no non-trivial solutions.
  7. Prove: In any primitive solution to \(x^4 + y^4 = z^2\), \(z \equiv 1 \pmod{4}\).
  8. Show that \(x^4 + y^4 = z^2\) implies \(x^2 + y^2\) is not a square (unless trivial).
