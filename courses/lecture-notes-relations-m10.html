Lecture 5: Relations and Functions

Mathematics 10 - Chapter 5

5.1 Relations and Functions

A relation is a set of ordered pairs. A function is a special type of relation where each input has exactly one output.

Why This Distinction Matters: Functions model real-world situations where one quantity depends on another. For example, the temperature at a given time is a function - at any specific time, there's only one temperature. But the relation between people and their birthdays is not a function - multiple people can share a birthday.

Function Definition

A relation is a function if and only if each element in the domain corresponds to exactly one element in the range.

Vertical Line Test: A graph represents a function if no vertical line intersects the graph more than once.

Example 1: Identifying Functions

Determine if the relation \(\{(1,2), (2,3), (3,4), (1,5)\}\) is a function.

Since input 1 corresponds to both 2 and 5, this is NOT a function.

Motivation: This helps us understand which relationships can be modeled mathematically as functions.

5.2 Domain and Range of a Relation

The domain is the set of all possible inputs. The range is the set of all possible outputs.

Real-World Connection: In a function modeling the height of a ball over time, the domain might be restricted to non-negative time values, and the range would be from the ground to the maximum height.

Finding Domain and Range

From a table or set of points: List all x-values (domain) and y-values (range)

From a graph: Project onto x-axis (domain) and y-axis (range)

From an equation: Consider restrictions (division by zero, square roots of negative numbers, etc.)

5.3 Representing Relations and Functions

Relations and functions can be represented in multiple ways: tables, graphs, mapping diagrams, and equations.

Why Multiple Representations? Different representations reveal different properties. A table shows specific values, a graph shows trends, and an equation allows for precise calculations.

5.4 Interpreting Graphs of Relations and Functions

Graphs provide visual insight into the behavior of functions. We can identify:

  • Domain and range from the extent of the graph
  • Intercepts where the graph crosses axes
  • Increasing/decreasing intervals
  • Maximum and minimum values
  • Rate of change from steepness
Example 2: Analyzing a Graph

For a graph of a ball's height over time, we can see when it was thrown, when it hits the ground, and its maximum height.

Motivation: This is used in physics to analyze motion, in economics to understand profit trends, and in biology to model population growth.

5.5 Function Notation

Function notation \(f(x)\) represents the output of function \(f\) when the input is \(x\).

Why Use Function Notation? It's more precise than \(y =\) notation. We can have multiple functions (f, g, h) and easily work with compositions. It also emphasizes that a function is a process that transforms inputs to outputs.

Function Notation Examples

If \(f(x) = 2x + 3\), then \(f(5) = 13\) and \(f(-1) = 1\)

If \(g(x) = x^2 - 4\), then \(g(3) = 5\) and \(g(-3) = 5\)

Note: Different inputs can give the same output - this is fine for functions, but not for inverses.

5.6 Domain and Range of a Function

For functions defined by equations, we must consider mathematical restrictions:

  • Denominator cannot be zero
  • Expression under a square root must be non-negative
  • Logarithm arguments must be positive
Example 3: Finding Domain

Find the domain of \(f(x) = \frac{1}{x-2} + \sqrt{x+3}\).

Need: \(x-2 \neq 0\) and \(x+3 \geq 0\)

So: \(x \neq 2\) and \(x \geq -3\)

Domain: \([-3, 2) \cup (2, \infty)\)

Motivation: This ensures our function gives real, meaningful outputs.

5.7 Domain and Range of a Graph

From a graph, we can read the domain and range by looking at the extent of the graph.

Application: In data analysis, we use graphs to understand the practical limits of our data. A graph of temperature over a day shows the actual range of temperatures recorded.

5.8 Applying the Distance Formula

The distance between two points \((x_1, y_1)\) and \((x_2, y_2)\) is:

\(d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}\)

Connection to Pythagorean Theorem: This formula comes from the Pythagorean theorem. The horizontal and vertical differences form the legs of a right triangle, and the distance is the hypotenuse.

Example 4: Distance Between Cities

Find the distance between Vancouver (49.3°N, 123.1°W) and Seattle (47.6°N, 122.3°W).

Using the distance formula (scaled appropriately): approximately 115 km

Motivation: This is used in navigation, geography, and computer graphics for calculating distances.
