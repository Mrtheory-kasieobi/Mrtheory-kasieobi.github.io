Lecture 5: Relations and Functions

Mathematics 10 - Chapter 5

5.1 Relations and Functions

A relation is any set of ordered pairs \((x, y)\). The first number \(x\) is the input, and the second number \(y\) is the output. A function is a relation where each input has exactly one output.

Key words: An ordered pair \((x,y)\) lists an input first and its output second. The input is the value you choose, often \(x\). The output is the value that results, often \(y\).

Relation: any set of ordered pairs. For example, \(\{(1,2),(2,3),(1,4)\}\) is a relation because it simply lists pairings.

Function: a relation in which each input has exactly one output. A mapping draws arrows from inputs to outputs; a function has only one arrow leaving each input, though two inputs may point to the same output.

Why This Distinction Matters: Functions model situations where one quantity depends on another. The temperature at a given time is a function: at one moment there is only one temperature. The relation between people and birthdays is not a function, because several people can share a birthday.

One output, not one input: Two different inputs may share the same output, so \((1, 4)\) and \((2, 4)\) can both belong to a function. What is not allowed is one input paired with two different outputs.

Function Definition

A relation is a function when every input is paired with exactly one output.

Vertical Line Test: A graph is a function if no vertical line touches it more than once.

Why the vertical line test works: A vertical line is all the points with the same \(x\)-value, so it stands for one input. If the line crosses the graph twice, that input has two outputs and the graph is not a function. If every vertical line crosses at most once, each input has at most one output.

Yes example: The graph of \(y=2x+1\) is a straight line. Any vertical line \(x=k\) crosses it exactly once, so it passes the test and is a function.

No example: A circle such as \(x^2+y^2=25\) fails. The vertical line \(x=0\) meets it at \((0,5)\) and \((0,-5)\), so one input gives two outputs and the graph is not a function.

Another yes example: A parabola \(y=x^2\) passes: each vertical line touches it at most once. A horizontal line may touch it twice, and that is fine.

Example 1: Identifying Functions

Is \(\{(1,2), (2,3), (3,4), (1,5)\}\) a function?

Input \(1\) is paired with both \(2\) and \(5\), so this relation is not a function.

Check: List the inputs: \(1, 2, 3, 1\). The repeated \(1\) is the giveaway.

5.2 Domain and Range of a Relation

The domain is the set of all inputs, and the range is the set of all outputs. From ordered pairs, the domain is the set of first coordinates and the range is the set of second coordinates. List each value only once, even if it repeats.

Set What it collects From ordered pairs
Domain All possible inputs First coordinates, listed once each
Range All resulting outputs Second coordinates, listed once each

Real-World Connection: For the height of a ball over time, the domain might start at time \(0\) and end when the ball lands. The range runs from the ground up to the maximum height.

From a table or mapping diagram: Read down the input column for the domain and down the output column for the range. In a mapping diagram, the domain is the left group of values and the range is the right group; arrows show which input goes with which output. Two arrows may land on the same output.

From a graph: Look at how far the graph stretches left to right for the domain, and how far it stretches bottom to top for the range. Imagine squashing the graph onto each axis: the shadow on the \(x\)-axis is the domain, and the shadow on the \(y\)-axis is the range.

Graph example: A curve runs from \(x=-3\) to \(x=4\) and from \(y=-2\) up to \(y=5\). Its domain is \([-3,4]\) and its range is \([-2,5]\).

Repeated domain values: If \((2,3)\) appears twice, list \(2\) only once in the domain and \(3\) only once in the range. If \((2,3)\) and \((2,4)\) both appear, the input \(2\) has two outputs, so the relation is not a function.

Interval notation basics: \([a,b]\) includes \(a\) and \(b\); \((a,b)\) leaves them out. The symbols \(\infty\) and \(-\infty\) always take parentheses, never brackets, because they are not endpoints you can reach.

Finding Domain and Range

Ordered pairs: Domain = all \(x\)-values; range = all \(y\)-values.

Graph: Read left-to-right extent for the domain and bottom-to-top extent for the range.

Equation: Check for division by zero and square roots of negative numbers.

Quick example: For \(\{(1,5), (2,5), (3,7)\}\), the domain is \(\{1, 2, 3\}\) and the range is \(\{5, 7\}\). The output \(5\) is listed once.

5.3 Representing Relations and Functions

Relations and functions can be shown in several ways: ordered pairs, tables, mapping diagrams, graphs, and equations. All of them describe the same pairing of inputs with outputs.

Why Multiple Representations? Each view shows something different. A table gives exact values, a graph shows the overall trend, and an equation lets you calculate any value you need.

Same relation, four views: For \(y = 2x + 1\), a table might list \(x = 0, 1, 2\) with \(y = 1, 3, 5\). The ordered pairs are \((0,1), (1,3), (2,5)\). A mapping diagram draws arrows \(0 \to 1\), \(1 \to 3\), and \(2 \to 5\). A graph plots those points on a coordinate grid.

Check your answer: Using \(y = 2x + 1\), what output belongs to \(x = 3\)? Substituting gives \(y = 2(3) + 1 = 7\), so the point \((3, 7)\) belongs on the graph.

Function notation as a representation: \(f(x)\) is a name for the output of the function \(f\) when the input is \(x\). It does not mean \(f\) times \(x\). Read \(f(x)\) as "f of x".

Worked evaluation: Let \(f(x)=3x-5\). Find \(f(-2)\).

Replace \(x\) with \(-2\): \(f(-2)=3(-2)-5=-6-5=-11\).

Check: The point \((-2,-11)\) belongs to the graph of \(y=3x-5\), and \(3(-2)-5=-11\).

5.4 Interpreting Graphs of Relations and Functions

A graph shows the whole story of a relation at a glance. From it we can identify:

  • Domain and range: how far the graph extends left to right and bottom to top
  • Intercepts: where the graph crosses the \(x\)-axis or \(y\)-axis
  • Increasing or decreasing: whether the graph rises or falls as you move to the right
  • Maximum and minimum: the highest and lowest points reached
  • Rate of change: a steeper graph means the output changes faster for each step in the input
Example 2: Analyzing a Graph

A graph of a ball's height versus time shows the starting height at \(t = 0\), the highest point, and the time when the height returns to \(0\).

Check: At the peak, the graph stops rising and starts falling, so that point is the maximum height.

5.5 Function Notation

The notation \(f(x)\) names the output of the function \(f\) for the input \(x\). Read it as "\(f\) of \(x\)". It is another way to write \(y\), but it also tells you which function you are using.

Not multiplication: \(f(x)\) does not mean \(f\times x\). The parentheses hold the input; they do not signal multiplication.

Why Use Function Notation? It reminds us that a function is a process: put an input in, get one output out. We can label different functions \(f\), \(g\), or \(h\) and know which rule to apply.

A process in three steps: Let \(f(x) = 2x + 3\). Find \(f(4)\).

Step 1: Replace \(x\) with \(4\): \(f(4) = 2(4) + 3\).

Step 2: Multiply: \(f(4) = 8 + 3\).

Step 3: Add: \(f(4) = 11\). The input \(4\) produces the output \(11\).

Check your answer: The point \((4, 11)\) should satisfy \(y = 2x + 3\), and indeed \(2(4) + 3 = 11\).

Function Notation Examples

If \(f(x) = 2x + 3\), then \(f(5) = 13\) and \(f(-1) = 1\).

If \(g(x) = x^2 - 4\), then \(g(3) = 5\) and \(g(-3) = 5\).

Note: Different inputs may give the same output; the relation is still a function.

5.6 Domain and Range of a Function

When a function is given by an equation, the domain includes every input that produces a real number. Most Grade 10 restrictions come from two rules:

  • Denominators: division by zero is undefined, so set the denominator \(\neq 0\) and solve.
  • Square roots: the number under a square root must be \(\geq 0\), because the square of a real number is never negative.

Average rate of change: For a function, this compares two points and measures how much the output changes per one unit of input. It is \(\frac{\text{change in output}}{\text{change in input}}=\frac{y_2-y_1}{x_2-x_1}\).

Worked example: From \((1,3)\) to \((4,9)\), the average rate of change is \(\frac{9-3}{4-1}=\frac{6}{3}=2\). On average, \(y\) rises \(2\) units for each \(1\) unit increase in \(x\).

Useful notation: \([a, b]\) includes both endpoints, \((a, b)\) excludes them, and \(\infty\) means the values keep going without end.

Example 3: Finding Domain

Find the domain of \(f(x) = \frac{1}{x-2} + \sqrt{x+3}\).

Denominator: \(x - 2 \neq 0\), so \(x \neq 2\).

Square root: \(x + 3 \geq 0\), so \(x \geq -3\).

Domain: \([-3, 2) \cup (2, \infty)\).

Check: \(x = -3\) works because \(\sqrt{0} = 0\), but \(x = 2\) is excluded because it makes the denominator \(0\).

5.7 Domain and Range of a Graph

To read a graph's domain, find the smallest and largest \(x\)-values that appear. To read its range, find the smallest and largest \(y\)-values. Arrows at the ends of a curve mean the graph continues, so that end uses \(\infty\) or \(-\infty\).

Filled or open dots: A filled dot means the endpoint is included, written with a square bracket in interval notation. An open dot means the endpoint is left out, written with a parenthesis.

Example: A curve starts at \((-2, -1)\) with a filled dot, ends at \((4, 5)\) with a filled dot, and never goes higher than \(y = 5\) or lower than \(y = -1\). Its domain is \([-2, 4]\) and its range is \([-1, 5]\).

Check your answer: Does \(x = 5\) belong to the domain? No, the graph stops at \(x = 4\).

Common Mistakes and Considerations:

  • Mixing up input and output: the domain is the set of \(x\)-values, not the \(y\)-values.
  • Repeating a domain value in a list: each input is written only once.
  • Thinking two inputs cannot share an output: \((1,4)\) and \((2,4)\) are fine in a function.
  • Using brackets where a value is excluded: \((2,5)\) leaves out \(2\) and \(5\), while \([2,5]\) includes them.
  • Writing \([\infty,4]\): infinity always uses a parenthesis, so \((-\infty,4]\) is correct.

5.8 Applying the Distance Formula

On a coordinate grid, the distance between \((x_1, y_1)\) and \((x_2, y_2)\) is:

\[d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\]

Connection to the Pythagorean theorem: Draw a right triangle with the horizontal difference \(x_2 - x_1\) as one leg and the vertical difference \(y_2 - y_1\) as the other. The distance between the points is the hypotenuse, so \(d^2 = (\text{horizontal leg})^2 + (\text{vertical leg})^2\).

Derivation: Place the two points on a grid and draw a right triangle. The horizontal leg has length \(|x_2-x_1|\) and the vertical leg has length \(|y_2-y_1|\). The distance \(d\) is the hypotenuse.

\[d^2=(x_2-x_1)^2+(y_2-y_1)^2\]

Taking the nonnegative square root gives the distance formula.

Example 4: Distance on a Coordinate Grid

Find the distance between \(A(1, 2)\) and \(B(4, 6)\).

Horizontal change: \(4 - 1 = 3\). Vertical change: \(6 - 2 = 4\).

\(d = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5\).

Pythagorean check: \(3^2 + 4^2 = 9 + 16 = 25 = 5^2\).

Example 5: Distance with Negative Coordinates

Find the distance between \(A(-2,1)\) and \(B(4,9)\).

Horizontal change: \(4-(-2)=6\). Vertical change: \(9-1=8\).

\(d=\sqrt{6^2+8^2}=\sqrt{36+64}=\sqrt{100}=10\).

Check: \(6^2+8^2=36+64=100=10^2\), so the distance is \(10\) units.

5.9 Check Your Understanding

Try These
  1. Is \(\{(1,2),(2,3),(1,4)\}\) a function? Explain.
  2. Find the domain and range of \(\{(0,5),(2,5),(3,7)\}\).
  3. If \(f(x)=2x-1\), find \(f(3)\).
Answers with Brief Work

1. No. Input \(1\) has two outputs, \(2\) and \(4\), so the relation fails the definition of a function.

2. Domain \(\{0,2,3\}\); range \(\{5,7\}\). The output \(5\) is listed once.

3. \(f(3)=2(3)-1=6-1=5\).

Bonus: Same Output, Different Inputs

A function never gives one input two outputs, but two different inputs may share an output. For \(g(x) = x^2\), both \(g(3) = 9\) and \(g(-3) = 9\), so two arrows in the mapping diagram land on \(9\) and the relation is still a function.

A vertical line still meets the graph of \(y = x^2\) only once for each input, even though a horizontal line might meet it twice. Check yourself: does \(\{(1,4), (2,4), (3,5)\}\) pass the vertical line test? Yes, because no input repeats.
