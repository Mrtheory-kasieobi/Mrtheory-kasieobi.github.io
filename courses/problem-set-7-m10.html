Problem Set 7: Systems of Linear Equations

Mathematics 10 - Chapter 7 Medium

Problems

Problem 1

Solve by substitution: \(y = 2x + 1\) and \(3x + y = 10\)

Problem 2

Solve by elimination: \(2x + 3y = 12\) and \(4x - 3y = 6\)

Problem 3

Solve: \(x + y + z = 6\), \(2x - y + z = 2\), \(x + 2y - z = 4\)

Problem 4

Investment problem: $3000 is split between two accounts paying 4% and 6% interest. If total interest is $150, find the amount in each account.

Problem 5

Find the intersection point of \(y = x + 2\) and \(y = -2x + 10\)

Problem 6

Determine if the system has one, none, or infinitely many solutions: \(3x + 2y = 6\) and \(6x + 4y = 12\)

Problem 7

Solve: \(\frac{1}{2}x + \frac{1}{3}y = 2\) and \(\frac{1}{4}x - y = -1\) (Clear fractions first)

Problem 8

Find two numbers if their sum is 15 and their difference is 3

Bonus Problems

Bonus Problem 1 Medium

Reflection Puzzle: A point A(2, 3) is reflected over the line \(y = x + 1\). Find the coordinates of the reflected point A'. Then, if point B is the reflection of A' over the x-axis, what are the coordinates of B?

Bonus Problem 2 Hard

Intersection Detective: Three lines are given: \(L_1: y = x + 1\), \(L_2: y = -x + 5\), and \(L_3: y = 2x - 1\). Find all intersection points, then determine which pair of lines forms the shortest distance between their intersection points.

Bonus Problem 3 Hard

System Constraint: A system of two linear equations has the property that if you swap the coefficients of x and y in the second equation, the solution changes by exactly 2 units in each coordinate. If the original system is \(2x + 3y = 12\) and \(ax + by = c\), find the values of \(a\) and \(b\) (given that \(c = 10\)).
