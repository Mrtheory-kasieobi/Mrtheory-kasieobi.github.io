Rational Expressions and Equations

Precalculus 11 - Lecture Notes
British Columbia Curriculum | Last Updated: 2026

1. Introduction to Rational Expressions

A rational expression is a fraction in which the numerator and/or denominator are polynomials.

Definition: A rational expression is of the form \(\frac{P(x)}{Q(x)}\), where \(P(x)\) and \(Q(x)\) are polynomials and \(Q(x) \neq 0\).

1.1 Non-Permissible Values and Domain Restrictions

Just as \(\frac{1}{0}\) is undefined in arithmetic, a rational expression is undefined whenever its denominator equals zero. These values are called non-permissible values.

Key Concept:

Algebraic cancellation does NOT mean the original function is defined at the cancelled values!

When we simplify \(\frac{(x - 2)(x + 1)}{x - 2}\) to \(x + 1\), the simplified form is defined at \(x = 2\), but the original expression is NOT. Always state restrictions!

Example 1: Finding the Domain and Restrictions

Find the domain of \(\frac{x + 2}{x^2 - 9}\)

Solution:

Step 1: Find non-permissible values

Set denominator equal to zero: \(x^2 - 9 = 0\)

\(x^2 = 9\), so \(x = \pm 3\)

Non-permissible values: \(x \neq 3\) and \(x \neq -3\)

Domain: \(\{x \in \mathbb{R} \mid x \neq \pm 3\}\) or \((-\infty, -3) \cup (-3, 3) \cup (3, \infty)\)

Example 2: Hole vs. Vertical Asymptote

Consider \(f(x) = \frac{x^2 - 4}{x - 2}\) and \(g(x) = \frac{x^2 - 4}{x^2 - 4}\)

Solution for f(x):

\(f(x) = \frac{(x - 2)(x + 2)}{x - 2}\)

Cancel: \(f(x) = x + 2\), with \(x \neq 2\) (hole at x = 2)

Solution for g(x):

\(g(x) = \frac{(x - 2)(x + 2)}{(x - 2)(x + 2)}\)

Cancel: \(g(x) = 1\), with \(x \neq \pm 2\) (holes at x = 2 and x = -2)

2. Simplifying Rational Expressions

To simplify a rational expression, factor the numerator and denominator, then cancel common factors.

Steps to Simplify:
1. Factor numerator and denominator completely
2. Identify non-permissible values (from original denominator)
3. Cancel common factors
4. State final restrictions
Example 3: Simplifying with Restrictions

Simplify: \(\frac{x^2 - 9}{x^2 - 6x + 9}\)

Solution:

Step 1: Factor

Numerator: \(x^2 - 9 = (x + 3)(x - 3)\)

Denominator: \(x^2 - 6x + 9 = (x - 3)^2\)

Step 2: State restrictions before cancelling

Original denominator: \((x - 3)^2 = 0\) when \(x = 3\)

Restriction: \(x \neq 3\)

Step 3: Simplify

\[\frac{x^2 - 9}{x^2 - 6x + 9} = \frac{(x + 3)(x - 3)}{(x - 3)(x - 3)} = \frac{x + 3}{x - 3}\]

3. Multiplying and Dividing Rational Expressions

3.1 Multiplying Rational Expressions

To multiply rational expressions, multiply the numerators and denominators, then simplify. Always identify all non-permissible values!

\[\frac{P(x)}{Q(x)} \cdot \frac{R(x)}{S(x)} = \frac{P(x) \cdot R(x)}{Q(x) \cdot S(x)}\]
Example 4: Multiplication with Full Analysis

Multiply: \(\frac{x^2 - 4}{x^2 - x - 6} \cdot \frac{x + 2}{x - 2}\)

Solution:

Step 1: Identify restrictions from original denominators

\(x^2 - x - 6 = 0 \Rightarrow (x - 3)(x + 2) = 0 \Rightarrow x \neq 3, -2\)

\(x - 2 = 0 \Rightarrow x \neq 2\)

Restrictions: \(x \neq 3, -2, 2\)

Step 2: Multiply

Factor: \(\frac{(x + 2)(x - 2)}{(x - 3)(x + 2)} \cdot \frac{x + 2}{x - 2}\)

Result after canceling: \(\frac{x + 2}{x - 3}\)

3.2 Dividing Rational Expressions

To divide rational expressions, multiply by the reciprocal of the divisor. The restrictions multiply as well!

\[\frac{P(x)}{Q(x)} \div \frac{R(x)}{S(x)} = \frac{P(x)}{Q(x)} \cdot \frac{S(x)}{R(x)}\]
Example 5: Division with Restrictions

Divide: \(\frac{x^2 - 1}{x^2 + 5x + 6} \div \frac{x - 1}{x + 3}\)

Solution:

Step 1: Identify restrictions

From original denominators: \(x^2 + 5x + 6 = (x + 2)(x + 3) = 0 \Rightarrow x \neq -2, -3\)

From divisor denominator: \(x - 1 = 0 \Rightarrow x \neq 1\)

Restrictions: \(x \neq -3, -2, 1\)

Step 2: Multiply by reciprocal

\[\frac{x^2 - 1}{x^2 + 5x + 6} \cdot \frac{x + 3}{x - 1} = \frac{(x + 1)(x - 1)}{(x + 2)(x + 3)} \cdot \frac{x + 3}{x - 1} = \frac{x + 1}{x + 2}\]

4. Adding and Subtracting Rational Expressions

To add or subtract rational expressions, find a common denominator, then combine the numerators. The LCD must incorporate ALL factors from ALL denominators.

4.1 Finding the Least Common Denominator (LCD)

Example 6: Adding with Different Denominators

Add: \(\frac{2}{x - 1} + \frac{3}{x + 2}\)

Solution:

Step 1: Identify restrictions

\(x \neq 1\) and \(x \neq -2\)

Step 2: Find LCD

LCD = \((x - 1)(x + 2)\)

Step 3: Rewrite with common denominator

\[\frac{2(x + 2)}{(x - 1)(x + 2)} + \frac{3(x - 1)}{(x + 2)(x - 1)}\]

Step 4: Combine numerators

\[= \frac{2x + 4 + 3x - 3}{(x - 1)(x + 2)} = \frac{5x + 1}{(x - 1)(x + 2)}\]

Final answer: \(\frac{5x + 1}{(x - 1)(x + 2)}\), \(x \neq 1, -2\)

4.2 Adding with Like Denominators

\[\frac{P(x)}{Q(x)} \pm \frac{R(x)}{Q(x)} = \frac{P(x) \pm R(x)}{Q(x)}\]
Common Error:

DO NOT cancel terms that are added or subtracted in the numerator! Only cancel factors that are multiplied.

Example: \(\frac{x + 2}{x + 3}\) cannot be simplified to \(\frac{2}{3}\)

5. Solving Rational Equations

A rational equation is an equation containing rational expressions. Solving these requires careful attention to domain restrictions.

Definition: A rational equation is an equation that involves one or more rational expressions.

5.1 Solution Strategy

  1. Identify restrictions from all denominators BEFORE solving
  2. Multiply both sides by the LCD (least common denominator)
  3. Solve the resulting equation (usually linear or quadratic)
  4. Check each solution against the restrictions
  5. Verify solutions in the original equation (may be extraneous)
Example 7: Complete Solution Process

Solve: \(\frac{3}{x + 2} = \frac{5}{x - 1}\)

Solution:

Step 1: Restrictions

\(x \neq -2\) and \(x \neq 1\)

Step 2: Cross multiply or find LCD

Multiply both sides by \((x + 2)(x - 1)\):

\[3(x - 1) = 5(x + 2)\]

Step 3: Solve

\[3x - 3 = 5x + 10\]

\[-2x = 13\]

\[x = -\frac{13}{2}\]

Step 4: Check restrictions

\(-\frac{13}{2} \neq -2\) and \(-\frac{13}{2} \neq 1\) ✓

Step 5: Verify in original

Both sides equal \(-\frac{5}{15} = -\frac{1}{3}\) ✓

5.2 Extraneous Solutions

When multiplying both sides of an equation by an expression containing a variable, we may introduce solutions that don't satisfy the original equation.

Critical Warning:

Always substitute your solutions back into the ORIGINAL equation. If any denominator becomes zero, that solution is extraneous and must be rejected.

Example 8: Identifying Extraneous Solutions

Solve: \(\frac{x}{x - 2} = \frac{2}{x - 2}\)

Solution:

Restriction: \(x \neq 2\)

Solve:

Multiply by \(x - 2\): \(x = 2\)

Check restrictions:

\(x = 2\) makes the denominator zero!

Conclusion: No solution (the equation is undefined for all valid inputs)

Alternatively: The equation \(\frac{x}{x - 2} = \frac{2}{x - 2}\) implies \(x = 2\), but \(x = 2\) is not in the domain.

5.3 Solving Rational Equations Resulting in Quadratics

Example 9: Quadratic Result

Solve: \(\frac{1}{x} + \frac{1}{x + 4} = \frac{2}{x^2 + 4x}\)

Solution:

Step 1: Factor denominator and find restrictions

\(x^2 + 4x = x(x + 4)\)

Restrictions: \(x \neq 0\) and \(x \neq -4\)

Step 2: Multiply by LCD = x(x + 4)

\[(x + 4) + x = 2\]

\(2x + 4 = 2\)

\(2x = -2\)

\(x = -1\)

Step 3: Check restrictions

\(-1 \neq 0\) and \(-1 \neq -4\) ✓

Step 4: Verify

\[\frac{1}{-1} + \frac{1}{3} = -1 + \frac{1}{3} = -\frac{2}{3}\]

\[\frac{2}{1 - 4} = \frac{2}{-3} = -\frac{2}{3}\] ✓

6. Summary of Key Concepts

Concept Key Points
Rational Expression \(\frac{P(x)}{Q(x)}\), undefined when \(Q(x) = 0\)
Non-permissible Values Values making denominator zero - ALWAYS state!
Cancellation Warning Cancelling doesn't remove restrictions!
Multiplying Multiply numerators × denominators, state all restrictions
Dividing Multiply by reciprocal, restrictions multiply
Adding/Subtracting Find LCD, combine numerators, keep restrictions
Solving Equations State restrictions → Solve → Check → Verify
Extraneous Solutions Solutions not in the domain - must reject

7. Practice Problems

Problem 1

Simplify \(\frac{x^2 - 25}{x^2 - 8x + 15}\). State restrictions.

Problem 2

Multiply: \(\frac{x^2 + x - 6}{x^2 - 1} \cdot \frac{x - 2}{x + 3}\). State all restrictions.

Problem 3

Subtract: \(\frac{3}{x + 2} - \frac{2}{x - 1}\). State restrictions.

Problem 4

Solve: \(\frac{x}{x + 3} + \frac{2}{x - 2} = 1\). Check for extraneous solutions.

Problem 5

Find the domain of \(f(x) = \frac{x^2 + 1}{x^2 - 4x + 3}\). Express in interval notation.

Problem 6

Solve: \(\frac{2}{x - 1} - \frac{3}{x} = \frac{1}{x(x - 1)}\). Verify all solutions.
