Worked Solutions

Each solution gives one complete route and notes where a common error can occur.

  1. 1. A proposition is a declarative statement with a definite truth value. “Every prime greater than 2 is odd” is true. The other options are a question, a command, and a subjective opinion.
  2. 2. The negation of \(\forall x\,(P(x)\to Q(x))\) is \(\exists x\,\neg(P(x)\to Q(x))\), i.e. \(\exists x\,(P(x)\land\neg Q(x))\). Thus the negation is \(\exists n\in\mathbb{Z}\,(n\text{ even}\land n^2\text{ odd})\).
  3. 3. The conditional \(p\to q\) is false only when \(p\) is true and \(q\) is false, which is also when \(\neg p\lor q\) is false. Hence they are logically equivalent.
  4. 4. Since \(q\) is false, \(\neg q\) is true. Also \(p\land q\), \(p\leftrightarrow q\), and \(p\to q\) are false in this truth assignment.
  5. 5. The symmetric difference contains elements in exactly one of the two sets: \(A\triangle B=(A\setminus B)\cup(B\setminus A)=\{1,4\}\).
  6. 6. \(x\in A\setminus(B\cap C)\) means \(x\in A\) and \(x\notin B\cap C\), i.e. \(x\notin B\) or \(x\notin C\). Hence \(x\in(A\setminus B)\cup(A\setminus C)\). The other identities fail in general.
  7. 7. Surjectivity means the image equals the codomain: every \(b\in B\) has at least one preimage \(a\in A\). Option A defines injectivity.
  8. 8. Congruence modulo \(n\) is reflexive because \(n\mid 0\), symmetric because divisibility is unchanged by sign, and transitive because \(n\mid(a-b)\) and \(n\mid(b-c)\) imply \(n\mid(a-c)\).
  9. 9. The contrapositive of \(P\to Q\) is \(\neg Q\to\neg P\). Here \(P\) is “\(n^2\) is even” and \(Q\) is “\(n\) is even”, so the contrapositive is “if \(n\) is odd, then \(n^2\) is odd”.
  10. 10. The empty set has no elements, while \(\{\varnothing\}\) has one element, namely \(\varnothing\). Thus they are not equal. The other statements are true.
  11. 11. Let \(n=2k\) with \(k\in\mathbb{Z}\). Then \(n^2=(2k)^2=4k^2=2(2k^2)\), and \(2k^2\in\mathbb{Z}\), so \(n^2\) is even.
  12. 12. The negation is: there exists a continuous function that is not differentiable. In symbols, \(\exists f\,(f\text{ continuous}\land f\text{ not differentiable})\). For example, \(f(x)=|x|\) is continuous everywhere but not differentiable at \(0\).
  13. 13. For \(\subseteq\), take \(x\in A\cap(B\cup C)\). Then \(x\in A\) and \(x\in B\) or \(x\in C\). If \(x\in B\), then \(x\in A\cap B\); if \(x\in C\), then \(x\in A\cap C\). Thus \(x\in(A\cap B)\cup(A\cap C)\). Conversely, if \(x\in(A\cap B)\cup(A\cap C)\), then \(x\in A\) and \(x\in B\cup C\), so \(x\in A\cap(B\cup C)\).
  14. 14. Prove the contrapositive: if \(n\) is even, then \(3n+2\) is even. Write \(n=2k\). Then \(3n+2=6k+2=2(3k+1)\), which is even. Hence if \(3n+2\) is odd, \(n\) cannot be even, so \(n\) is odd.
  15. 15. Suppose \(\sqrt2=a/b\) in lowest terms with \(a,b\in\mathbb{Z}\), \(b\ne0\). Then \(a^2=2b^2\), so \(a^2\) is even and therefore \(a\) is even. Write \(a=2k\); then \(4k^2=2b^2\), so \(b^2=2k^2\), making \(b\) even. Both \(a\) and \(b\) even contradicts lowest terms. Therefore \(\sqrt2\) is irrational.
  16. 16. From \(a\mid b\), choose \(k\in\mathbb{Z}\) with \(b=ak\). From \(b\mid c\), choose \(l\in\mathbb{Z}\) with \(c=bl\). Then \(c=(ak)l=a(kl)\), with \(kl\in\mathbb{Z}\), so \(a\mid c\).
  17. 17. Suppose \(f(a)=f(b)\). Then \(2a+1=2b+1\), so \(2a=2b\), and hence \(a=b\). By definition, \(f\) is injective.
  18. 18. The first statement is true: given \(x\), choose \(y=-x\), so \(x+y=0\). The second is false because the value of \(y\) would have to work for every \(x\) simultaneously; no fixed integer does. For instance, \(x=0\) forces \(y=0\), while \(x=1\) forces \(y=-1\).
  19. 19. Suppose \(A\cup B=A\). If \(x\in B\), then \(x\in A\cup B=A\), so \(B\subseteq A\). Conversely, suppose \(B\subseteq A\). If \(x\in A\cup B\), then \(x\in A\) or \(x\in B\); in the second case \(x\in A\) by inclusion. Hence \(A\cup B\subseteq A\), and \(A\subseteq A\cup B\) always, so equality follows.
  20. 20. Every integer is even or odd. If \(n=2k\), then \(n^2=4k^2\equiv0\pmod4\). If \(n=2k+1\), then \(n^2=4k^2+4k+1=4k(k+1)+1\equiv1\pmod4\). These cases exhaust all integers.
  21. 21. The statement is false. Let \(A=\varnothing\), \(B=\{1\}\), and \(C=\{2\}\). Then \(A\cap B=A\cap C=\varnothing\), but \(B\ne C\). Equality of the intersections with a fixed set does not determine the original sets.
