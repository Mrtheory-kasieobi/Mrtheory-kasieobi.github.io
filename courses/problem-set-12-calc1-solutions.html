Problem Set 12: Advanced Integration - SOLUTIONS

Calculus I - Week 12

Solution Guide

Note: These are detailed solutions for advanced integration techniques.

Problem 1: \(\int \frac{dx}{x^2 - 4}\)

Solution:
Step 1: Use partial fractions
\(\frac{1}{x^2-4} = \frac{1}{(x-2)(x+2)} = \frac{A}{x-2} + \frac{B}{x+2}\)
Step 2: Find A and B
\(1 = A(x+2) + B(x-2)\)
\(x = 2: 1 = 4A \Rightarrow A = \frac{1}{4}\)
\(x = -2: 1 = -4B \Rightarrow B = -\frac{1}{4}\)
Step 3: Integrate
\(\frac{1}{4}\int \frac{dx}{x-2} - \frac{1}{4}\int \frac{dx}{x+2}\)
Step 4: Result
\(\frac{1}{4}\ln|x-2| - \frac{1}{4}\ln|x+2| + C = \frac{1}{4}\ln\left|\frac{x-2}{x+2}\right| + C\)
Final Answer:
\(\boxed{\frac{1}{4}\ln\left|\frac{x-2}{x+2}\right| + C}\)

Problem 2: \(\int \frac{dx}{\sqrt{4-x^2}}\)

Solution:
Step 1: Factor out constant
\(\int \frac{dx}{\sqrt{4-x^2}} = \int \frac{dx}{\sqrt{4(1-x^2/4)}} = \frac{1}{2}\int \frac{dx}{\sqrt{1-(x/2)^2}}\)
Step 2: Recognize arcsine form
\(\int \frac{du}{\sqrt{1-u^2}} = \sin^{-1}u + C\)
Step 3: Apply formula
\(\frac{1}{2} \cdot 2\sin^{-1}\frac{x}{2} = \sin^{-1}\frac{x}{2}\)
Final Answer:
\(\boxed{\sin^{-1}\frac{x}{2} + C}\)

Problem 3: \(\int \frac{x}{\sqrt{x^2 + 1}} \, dx\)

Solution:
Step 1: Use substitution
Let \(u = x^2 + 1\), \(du = 2x dx\), so \(x dx = \frac{du}{2}\)
Step 2: Rewrite integral
\(\frac{1}{2}\int u^{-1/2} du\)
Step 3: Integrate
\(\frac{1}{2} \cdot 2u^{1/2} = u^{1/2}\)
Step 4: Substitute back
\(\sqrt{x^2 + 1} + C\)
Final Answer:
\(\boxed{\sqrt{x^2 + 1} + C}\)

Problem 4: \(\int \frac{dx}{(x^2+1)^2}\)

Solution:
Step 1: Use trigonometric substitution
Let \(x = \tan\theta\), \(dx = \sec^2\theta d\theta\)
Step 2: Rewrite integrand
\(\int \frac{\sec^2\theta d\theta}{(\tan^2\theta+1)^2} = \int \frac{\sec^2\theta}{\sec^4\theta} d\theta = \int \cos^2\theta \, d\theta\)
Step 3: Use half-angle identity
\(\cos^2\theta = \frac{1+\cos 2\theta}{2}\)
Step 4: Integrate
\(\frac{1}{2}[\theta + \frac{\sin 2\theta}{2}] = \frac{\theta}{2} + \frac{\sin 2\theta}{4}\)
Step 5: Back-substitute
\(\theta = \tan^{-1}x\), \(\sin 2\theta = \frac{2x}{x^2+1}\)
Final Answer:
\(\boxed{\frac{1}{2}\tan^{-1}x + \frac{x}{2(x^2+1)} + C}\)

Problem 5: \(\int e^x \cos x \, dx\)

Solution:
Step 1: Use integration by parts twice
Let \(u = e^x\), \(dv = \cos x dx\)
\(du = e^x dx\), \(v = \sin x\)
Step 2: First application
\(\int e^x \cos x dx = e^x \sin x - \int e^x \sin x dx\)
Step 3: Apply parts again to second integral
Let \(u = e^x\), \(dv = \sin x dx\)
\(du = e^x dx\), \(v = -\cos x\)
Step 4: Second application
\(\int e^x \sin x dx = -e^x \cos x + \int e^x \cos x dx\)
Step 5: Substitute back and solve
\(\int e^x \cos x dx = e^x \sin x - [-e^x \cos x + \int e^x \cos x dx]\)
\(\int e^x \cos x dx = e^x \sin x + e^x \cos x - \int e^x \cos x dx\)
Step 6: Collect and solve
\(2\int e^x \cos x dx = e^x(\sin x + \cos x)\)
Final Answer:
\(\boxed{\frac{e^x(\sin x + \cos x)}{2} + C}\)

Problem 6: \(\int \frac{dx}{x\sqrt{x^2 - 1}}\)

Solution:
Step 1: Use substitution
Let \(u = \sqrt{x^2 - 1}\), then \(u^2 = x^2 - 1\), \(2u du = 2x dx\)
Step 2: Alternative: recognize arcsec form
\(\int \frac{dx}{x\sqrt{x^2-1}} = \sec^{-1}|x| + C\)
Final Answer:
\(\boxed{\sec^{-1}|x| + C}\)

Problem 7: \(\int \frac{dx}{\sin x}\)

Solution:
Step 1: Multiply by clever form
\(\int \csc x dx = \int \csc x \cdot \frac{\csc x - \cot x}{\csc x - \cot x} dx\)
Step 2: Use substitution
Let \(u = \csc x - \cot x\), \(du = -\csc x \cot x + \csc^2 x = \csc x(\csc x - \cot x)\)
Step 3: Rewrite integral
\(\int \frac{-du}{u} = -\ln|u| + C\)
Step 4: Substitute back
\(-\ln|\csc x - \cot x| + C = \ln|\csc x + \cot x| + C\)
Final Answer:
\(\boxed{\ln|\csc x + \cot x| + C}\)

Problem 8: \(\int_0^{\pi/2} \frac{\sin x}{\sin x + \cos x} dx\)

Solution:
Step 1: Use symmetry trick
\(I = \int_0^{\pi/2} \frac{\sin x}{\sin x + \cos x} dx\)
Also \(I = \int_0^{\pi/2} \frac{\cos x}{\cos x + \sin x} dx\) (substitute \(u = \frac{\pi}{2} - x\))
Step 2: Add the two expressions
\(2I = \int_0^{\pi/2} \frac{\sin x + \cos x}{\sin x + \cos x} dx = \int_0^{\pi/2} 1 dx\)
Step 3: Solve for I
\(2I = \frac{\pi}{2} \Rightarrow I = \frac{\pi}{4}\)
Final Answer:
\(\boxed{\frac{\pi}{4}}\)

Problem 9: \(\int \frac{dx}{x^2 + 6x + 13}\)

Solution:
Step 1: Complete the square
\(x^2 + 6x + 13 = (x+3)^2 + 4\)
Step 2: Use arctangent formula
\(\int \frac{dx}{(x+3)^2 + 4} = \frac{1}{2}\tan^{-1}\frac{x+3}{2} + C\)
Final Answer:
\(\boxed{\frac{1}{2}\tan^{-1}\frac{x+3}{2} + C}\)

Problem 10: \(\int \frac{x^2}{x^2 + 1} \, dx\)

Solution:
Step 1: Polynomial long division
\(\frac{x^2}{x^2 + 1} = 1 - \frac{1}{x^2 + 1}\)
Step 2: Split integral
\(\int \left(1 - \frac{1}{x^2+1}\right) dx = \int 1 dx - \int \frac{dx}{x^2+1}\)
Step 3: Integrate
\(x - \tan^{-1}x + C\)
Final Answer:
\(\boxed{x - \tan^{-1}x + C}\)

Bonus 1: \(\int \frac{dx}{\sqrt{x}(\sqrt{x} + 1)^2}\)

Solution:
Step 1: Use substitution
Let \(u = \sqrt{x} + 1\), then \(du = \frac{1}{2\sqrt{x}}dx\), so \(\frac{dx}{\sqrt{x}} = 2du\)
Step 2: Rewrite integral
\(\int \frac{2du}{u^2} = 2\int u^{-2} du\)
Step 3: Integrate
\(2 \cdot (-u^{-1}) = -\frac{2}{u}\)
Step 4: Substitute back
\(-\frac{2}{\sqrt{x}+1} + C\)
Final Answer:
\(\boxed{-\frac{2}{\sqrt{x}+1} + C}\)

Bonus 2: \(\int_0^1 \frac{\ln x}{1+x} dx\)

Solution:
Step 1: Expand denominator as geometric series
\(\frac{1}{1+x} = \sum_{n=0}^{\infty} (-x)^n = \sum_{n=0}^{\infty} (-1)^n x^n\) for \(|x| < 1\)
Step 2: Integrate term by term
\(\int_0^1 \ln x \cdot \sum_{n=0}^{\infty} (-1)^n x^n dx = \sum_{n=0}^{\infty} (-1)^n \int_0^1 x^n \ln x \, dx\)
Step 3: Use known integral
\(\int_0^1 x^n \ln x \, dx = -\frac{1}{(n+1)^2}\)
Step 4: Sum the series
\(-\sum_{n=0}^{\infty} \frac{(-1)^n}{(n+1)^2} = -\sum_{k=1}^{\infty} \frac{(-1)^{k-1}}{k^2} = -(\text{Catalan's constant } G - \frac{\pi^2}{12})\)
Actually: \(-\sum_{k=1}^{\infty} \frac{(-1)^{k-1}}{k^2} = -(\frac{\pi^2}{12})\)
Final Answer:
\(\boxed{-\frac{\pi^2}{12}}\)
