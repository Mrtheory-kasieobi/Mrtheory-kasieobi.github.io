Lecture 3: Set Theory: Operations and Identities

Introduction to Proofs · Week 3

Lecture 3Set Theory: Operations and Identities

Learning objectives

By the end of this lecture you should be able to:

  • Use set notation precisely, including membership, subsets and power sets.
  • Interpret union, intersection, difference, complement and symmetric difference.
  • Prove set identities by element chasing and by logical equivalences.
  • Work with indexed families of sets and generalised De Morgan laws.
  • Avoid common errors involving the empty set and unordered versus ordered collections.
Beginner's bridge

A set is a collection considered as one object. The symbol \(\in\) connects an element to a set, while \(\subseteq\) compares two sets. For example, \(1\in\{1,2\}\) and \(\{1\}\subseteq\{1,2\}\), but \(1\not\subseteq\{1,2\}\) and \(\{1\}\notin\{1,2\}\). When this distinction is clear, set proofs become much easier.

The empty set \(\varnothing\) has no elements. The statement \(A\subseteq B\) means every element of \(A\) is also an element of \(B\). Because there is no element of \(\varnothing\) to check, \(\varnothing\subseteq B\) is true for every set \(B\).

1. Sets, membership and inclusion

Definition 3.1 A set is a well-defined collection of objects, called its elements or members. We write \(x\in A\) if \(x\) is an element of \(A\), and \(x\notin A\) otherwise. The empty set, denoted \(\varnothing\) or \(\{\}\), is the unique set with no elements.

Sets may be listed, as in \(A=\{1,2,3\}\), or described by a property, as in \(B=\{n\in\mathbb{Z}: n\text{ is even}\}\). Well-definedness means membership can be decided unambiguously; "the set of large numbers" is not a set in this sense unless "large" is specified.

Definition 3.2 (Subset and equality) \(A\subseteq B\) means every element of \(A\) is an element of \(B\), i.e. \(\forall x(x\in A\to x\in B)\). Sets are equal exactly when they have the same elements: \[A=B\iff(A\subseteq B\land B\subseteq A).\] If \(A\subseteq B\) and \(A\ne B\), write \(A\subsetneq B\).
Proof of the extensionality criterion. If \(A=B\), then every element of \(A\) is an element of \(B\) and conversely, so both inclusions hold. Conversely, suppose \(A\subseteq B\) and \(B\subseteq A\). If \(x\in A\), then \(x\in B\); if \(x\in B\), then \(x\in A\). Thus \(A\) and \(B\) have exactly the same members, so \(A=B\). \(\square\)
Example 3.3 \(\{1,2\}\subseteq\{1,2,3\}\), and \(\varnothing\subseteq A\) for every set \(A\). The latter holds vacuously: the implication \(x\in\varnothing\to x\in A\) has a false antecedent for every \(x\). Note that \(\varnothing\ne\{\varnothing\}\): the first set has no elements, the second has one element, namely the empty set.

2. Power sets and size

Definition 3.4 (Power set) The power set of \(A\) is \[\mathcal{P}(A)=\{X:X\subseteq A\},\] the set of all subsets of \(A\).
Example 3.5 If \(A=\{1,2\}\), then \(\mathcal{P}(A)=\{\varnothing,\{1\},\{2\},\{1,2\}\}\), which has \(4=2^2\) elements. If \(A=\varnothing\), then \(\mathcal{P}(A)=\{\varnothing\}\), which has \(1=2^0\) element.

For a finite set \(A\) with \(n\) elements, \(|\mathcal{P}(A)|=2^n\). This can be proved by induction on \(n\), or by observing that each subset corresponds to a choice of "include" or "exclude" for each element. We will return to this counting argument in Lecture 10.

3. Set operations

Definition 3.6 Let \(A,B\) be subsets of a universal set \(U\).
  • \(A\cup B=\{x:x\in A\text{ or }x\in B\}\) (union).
  • \(A\cap B=\{x:x\in A\text{ and }x\in B\}\) (intersection).
  • \(A\setminus B=\{x:x\in A\text{ and }x\notin B\}\) (difference).
  • \(A^{c}=\{x\in U:x\notin A\}\) (complement relative to \(U\)).
  • \(A\triangle B=(A\setminus B)\cup(B\setminus A)\) (symmetric difference).
Sets \(A\) and \(B\) are disjoint if \(A\cap B=\varnothing\).

The "or" in the union is inclusive: an element in both sets is still in the union. Membership tables for sets parallel truth tables: replace \(p\) by \(x\in A\) and \(q\) by \(x\in B\). For example, \(x\in A\cap B\) corresponds to \(p\land q\), and \(x\in A^c\) corresponds to \(\neg p\).

Theorem 3.7 (De Morgan laws for sets) \[(A\cup B)^c=A^c\cap B^c,\qquad (A\cap B)^c=A^c\cup B^c.\] More generally, \(A\setminus(B\cup C)=(A\setminus B)\cap(A\setminus C)\) and \(A\setminus(B\cap C)=(A\setminus B)\cup(A\setminus C)\).
Proof of the first law. For any \(x\in U\), \[x\in(A\cup B)^c\iff\neg(x\in A\cup B)\iff\neg(x\in A\text{ or }x\in B)\] \[\iff(x\notin A\text{ and }x\notin B)\iff x\in A^c\cap B^c.\] The chain of equivalences shows the two sets have exactly the same elements, so they are equal by Definition 3.2. \(\square\)

4. Proving set identities

An element-chasing proof of \(A=B\) proves both inclusions. To show \(A\subseteq B\), take an arbitrary \(x\in A\) and deduce \(x\in B\). To show \(B\subseteq A\), reverse the process. Each step must be an implication; if you use an equivalence, the reverse inclusion often comes for free.

Example 3.8 Prove \(A\cap(B\cup C)=(A\cap B)\cup(A\cap C)\).
Forward inclusion. Let \(x\in A\cap(B\cup C)\). Then \(x\in A\) and \(x\in B\cup C\), so \(x\in B\) or \(x\in C\). If \(x\in B\), then \(x\in A\cap B\); if \(x\in C\), then \(x\in A\cap C\). Either way \(x\in(A\cap B)\cup(A\cap C)\).
Reverse inclusion. Let \(x\in(A\cap B)\cup(A\cap C)\). If \(x\in A\cap B\), then \(x\in A\) and \(x\in B\subseteq B\cup C\), hence \(x\in A\cap(B\cup C)\). The case \(x\in A\cap C\) is identical with \(C\) in place of \(B\).

Alternatively, the truth-table equivalence \(p\land(q\lor r)\equiv(p\land q)\lor(p\land r)\) proves both inclusions at once.

Some identities fail for subtle reasons. For instance, \(A\setminus(B\setminus C)\) is generally not equal to \((A\setminus B)\cup C\): take \(A=\{1\},B=\{2\},C=\{2\}\). Then the left side is \(\{1\}\) while the right side is \(\{1,2\}\). Always test a proposed identity on small examples before attempting a proof.

5. Indexed families

Definition 3.9 If \(I\) is a set and each \(i\in I\) is assigned a set \(A_i\), the collection \(\{A_i:i\in I\}\) is an indexed family, and \(I\) is the index set. Define \[\bigcup_{i\in I}A_i=\{x:\exists i\in I,\,x\in A_i\},\qquad \bigcap_{i\in I}A_i=\{x:\forall i\in I,\,x\in A_i\}.\]
Theorem 3.10 (Generalised De Morgan laws) For any indexed family \(\{A_i\}_{i\in I}\) of subsets of \(U\), \[\Big(\bigcup_{i\in I}A_i\Big)^c=\bigcap_{i\in I}A_i^c,\qquad \Big(\bigcap_{i\in I}A_i\Big)^c=\bigcup_{i\in I}A_i^c.\]
Proof of the first law. For \(x\in U\), \[x\in\Big(\bigcup_{i\in I}A_i\Big)^c\iff\forall i\in I\,(x\notin A_i)\iff\forall i\in I\,(x\in A_i^c)\iff x\in\bigcap_{i\in I}A_i^c.\] The middle equivalence is the quantifier negation law from Lecture 2. \(\square\)

When \(I=\varnothing\), the empty intersection \(\bigcap_{i\in\varnothing}A_i\) is conventionally the whole universe \(U\), while the empty union is \(\varnothing\). This convention makes the generalised De Morgan laws and the identity \(\bigcap_{i\in I}A_i\subseteq\bigcup_{i\in I}A_i\) behave consistently, and mirrors the truth values of \(\forall\) and \(\exists\) over an empty index set.

6. Extra detail: the element-chasing template

To prove \(A\subseteq B\): let \(x\in A\), and deduce \(x\in B\).
To prove \(A=B\): prove \(A\subseteq B\) and \(B\subseteq A\) separately.
To prove \(x\in A\cap B\): prove \(x\in A\) and \(x\in B\).
To prove \(x\in A\cup B\): prove \(x\in A\) or \(x\in B\).

These templates turn set equalities into implication proofs. For instance, if \(x\in A\cap(B\cup C)\), then \(x\in A\) and either \(x\in B\) or \(x\in C\), which is exactly the statement that \(x\in(A\cap B)\cup(A\cap C)\).

Theorem 3.10 If \(A\) is finite with \(|A|=n\), then \(|\mathcal{P}(A)|=2^n\).
Proof. Each subset is determined by deciding, for each of the \(n\) elements, whether to include it. There are two choices for each element, so the product principle gives \(2^n\) subsets. \(\square\)
Exercises
  1. List all elements of \(\mathcal{P}(\{a,b,c\})\).
  2. Decide whether \(\varnothing\subseteq\{\varnothing\}\), \(\varnothing\in\{\varnothing\}\), and \(\{\varnothing\}\subseteq\mathcal{P}(\varnothing)\).
  3. Prove \(A\setminus B=A\cap B^c\).
  4. Prove \((A\cup B)\setminus(A\cap B)=A riangle B\) by element chasing.
  5. Give an example with \(A\cap B=A\cap C\) but \(B e C\).
  6. Prove \(A\subseteq B\) if and only if \(A\cap B^c=\varnothing\).
  7. Let \(A_n=\{n,n+1,n+2,\ldots\}\) for \(n\in\mathbb{N}\). Find \(\bigcup_{n\in\mathbb{N}}A_n\) and \(\bigcap_{n\in\mathbb{N}}A_n\).
  8. Show that \(A riangle B=B riangle A\) and \(A riangle\varnothing=A\).
