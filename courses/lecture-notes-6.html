Lecture 6: Arithmetic Functions and Möbius Inversion

Lecture 6Arithmetic Functions and Möbius Inversion

1. Arithmetic Functions

Definition 6.1 (Arithmetic Function) An arithmetic function is a function \(f: \mathbb{N} \to \mathbb{C}\) defined on the positive integers.
Definition 6.2 (Multiplicative Function) An arithmetic function \(f\) is called multiplicative if \(f(mn) = f(m)f(n)\) whenever \(\gcd(m, n) = 1\). It is completely multiplicative if this holds for all \(m, n\).
Example 6.1 Some important arithmetic functions:
  • \(\tau(n)\): Number of positive divisors of \(n\)
  • \(\sigma(n)\): Sum of positive divisors of \(n\)
  • \(\phi(n)\): Euler's totient function
  • \(\omega(n)\): Number of distinct prime factors
  • \(\Omega(n)\): Total number of prime factors (with multiplicity)

2. Dirichlet Convolution

Definition 6.3 (Dirichlet Convolution) For two arithmetic functions \(f\) and \(g\), their Dirichlet convolution is defined by: \[(f * g)(n) = \sum_{d \mid n} f(d) g\left(\frac{n}{d}\right)\]
Theorem 6.1 The Dirichlet convolution is commutative and associative:
  • \(f * g = g * f\)
  • \((f * g) * h = f * (g * h)\)
Example 6.2 Compute \(\tau * \sigma\) at \(n = 6\).

We have \(\tau(1) = 1, \tau(2) = 2, \tau(3) = 2, \tau(6) = 4\)

And \(\sigma(1) = 1, \sigma(2) = 3, \sigma(3) = 4, \sigma(6) = 12\)

Therefore: \[(\tau * \sigma)(6) = \tau(1)\sigma(6) + \tau(2)\sigma(3) + \tau(3)\sigma(2) + \tau(6)\sigma(1)\] \[= 1 \cdot 12 + 2 \cdot 4 + 2 \cdot 3 + 4 \cdot 1 = 12 + 8 + 6 + 4 = 30\]

3. The Möbius Function

Definition 6.4 (Möbius Function) The Möbius function \(\mu(n)\) is defined by: \[\mu(n) = \begin{cases} 1 & \text{if } n = 1 \\ (-1)^k & \text{if } n \text{ is the product of } k \text{ distinct primes} \\ 0 & \text{if } n \text{ has a squared prime factor} \end{cases}\]
Example 6.3 Compute \(\mu(n)\) for \(n = 1, 2, 3, 4, 5, 6, 10, 12, 30\).
  • \(\mu(1) = 1\)
  • \(\mu(2) = -1\) (one prime)
  • \(\mu(3) = -1\) (one prime)
  • \(\mu(4) = 0\) (has \(2^2\))
  • \(\mu(5) = -1\) (one prime)
  • \(\mu(6) = 1\) (two distinct primes: 2, 3)
  • \(\mu(10) = 1\) (two distinct primes: 2, 5)
  • \(\mu(12) = 0\) (has \(2^2\))
  • \(\mu(30) = -1\) (three distinct primes: 2, 3, 5)

4. Möbius Inversion Formula

Theorem 6.2 (Möbius Inversion Formula) Let \(f\) and \(g\) be arithmetic functions such that: \[g(n) = \sum_{d \mid n} f(d)\] Then we can recover \(f\) from \(g\) by: \[f(n) = \sum_{d \mid n} \mu(d) g\left(\frac{n}{d}\right)\]
Proof:
Step 1: Set up the relationship

We are given \(g = f * \mathbf{1}\), where \(\mathbf{1}(n) = 1\) for all \(n\).

Step 2: Use the key identity

The key identity is: \(\mu * \mathbf{1} = \varepsilon\), where \(\varepsilon(1) = 1\) and \(\varepsilon(n) = 0\) for \(n > 1\).

This means: \(\sum_{d \mid n} \mu(d) = \begin{cases} 1 & \text{if } n = 1 \\ 0 & \text{if } n > 1 \end{cases}\)

Step 3: Convolve both sides

Starting from \(g = f * \mathbf{1}\):

Multiply both sides by \(\mu\) (convolution with \(\mu\)\):

\(g * \mu = (f * \mathbf{1}) * \mu = f * (\mathbf{1} * \mu) = f * \varepsilon = f\)

Therefore: \(f = g * \mu\), which gives the desired formula. \(\square\)

Example 6.4 Use Möbius inversion to find \(\phi(n)\) given that \(\sum_{d \mid n} \phi(d) = n\).

By Möbius inversion:

\(\phi(n) = \sum_{d \mid n} \mu(d) \cdot \frac{n}{d} = n \sum_{d \mid n} \frac{\mu(d)}{d}\)

For \(n = 6\): \[\phi(6) = \sum_{d \mid 6} \mu(d) \cdot \frac{6}{d} = \mu(1) \cdot 6 + \mu(2) \cdot 3 + \mu(3) \cdot 2 + \mu(6) \cdot 1\] \[= 1 \cdot 6 + (-1) \cdot 3 + (-1) \cdot 2 + 1 \cdot 1 = 6 - 3 - 2 + 1 = 2\]

We verify: The numbers coprime to 6 are 1 and 5, so \(\phi(6) = 2\). ✓

Exercises:
  1. Compute \(\mu(105)\), \(\mu(18)\), and \(\mu(36)\)
  2. Verify that \(\mu * \mathbf{1} = \varepsilon\) for \(n = 1, 2, 3, 4, 6, 12\)
  3. Use Möbius inversion to find an explicit formula for \(\phi(n)\)
  4. Show that if \(f\) is multiplicative, then \(f * \mu\) is also multiplicative
  5. Prove that \(\sum_{d \mid n} \mu(d) = 0\) for all \(n > 1\)
  6. Find all \(n\) such that \(\mu(n) = 0\) and \(\mu(n) = 1\)
  7. Use Möbius inversion to derive \(\phi(n) = n \prod_{p \mid n} \left(1 - \frac{1}{p}\right)\)
  8. Show that \(\tau = 1 * 1\) and \(\sigma = 1 * \text{id}\), where \(\text{id}(n) = n\)
