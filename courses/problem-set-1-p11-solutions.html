Solutions: Problem Set 1

Real Numbers and Rational Exponents - Precalculus 11
Solution 1

(a) \(\sqrt{49}\): \(\sqrt{49} = 7\) is a natural number, whole number, integer, and rational.

(b) \(-\frac{8}{3}\): This is a rational number (negative fraction).

(c) \(0.\overline{6}\): \(0.\overline{6} = \frac{2}{3}\) is rational (repeating decimal).

(d) \(\pi\): Irrational (non-repeating, non-terminating decimal).

(e) \(\sqrt{2}\): Irrational (cannot be expressed as a fraction).

Solution 2

(a) \(8^{2/3}\): \(8^{2/3} = (\sqrt[3]{8})^2 = 2^2 = 4\)

(b) \(27^{-1/3}\): \(27^{-1/3} = \frac{1}{\sqrt[3]{27}} = \frac{1}{3}\)

(c) \(x^{2/3} \cdot x^{1/2}\): \(x^{2/3 + 1/2} = x^{4/6 + 3/6} = x^{7/6}\)

Solution 3

(a) \(\sqrt[3]{125}\): \(\sqrt[3]{125} = 5\)

(b) \(16^{3/4}\): \(16^{3/4} = (\sqrt[4]{16})^3 = 2^3 = 8\)

(c) \(\frac{1}{\sqrt{8}}\): \(\frac{1}{\sqrt{8}} = \frac{1}{2\sqrt{2}} = \frac{\sqrt{2}}{4}\)

Solution 4

(a) \(x^{2/3} \cdot x^{1/6}\): \(x^{2/3 + 1/6} = x^{5/6}\)

(b) \((y^{3/4})^2\): \(y^{3/4 \cdot 2} = y^{6/4} = y^{3/2}\)

(c) \(\frac{a^{5/2}}{a^{1/2}}\): \(a^{5/2 - 1/2} = a^{4/2} = a^2\)

Solution 5

For \(f(x) = \frac{1}{\sqrt[3]{x-2}}\):

The cube root is defined for all real numbers, so the only restriction is that the denominator cannot equal zero:

\(\sqrt[3]{x-2} \neq 0\), which means \(x - 2 \neq 0\), so \(x \neq 2\).

Domain: \((-\infty, 2) \cup (2, \infty)\)

Solution 6

Solution: \(\sqrt{x + 5} = 3\)

Square both sides: \(x + 5 = 9\)

Solve: \(x = 4\)

Check: \(\sqrt{4 + 5} = \sqrt{9} = 3\) ✓

Solution 7

Factor numerator: \(\frac{x^2 - 25}{x - 5} = \frac{(x-5)(x+5)}{x - 5}\)

Cancel: \(x + 5\), where \(x \neq 5\) (restriction - original denominator cannot be zero).

Solution 8

Evaluate each term:

\(8^{2/3} = (\sqrt[3]{8})^2 = 2^2 = 4\)

\(9^{1/2} = \sqrt{9} = 3\)

\(27^{1/3} = \sqrt[3]{27} = 3\)

Compute: \(\frac{4 \cdot 3}{3} = 4\)

Bonus Solutions

Bonus Solution 1

Simplify: \(\frac{\sqrt{18} \cdot \sqrt{2}}{\sqrt{8}}\)

Solution:

Combine radicals: \(\frac{\sqrt{18 \cdot 2}}{\sqrt{8}} = \frac{\sqrt{36}}{\sqrt{8}}\)

Simplify: \(\frac{6}{\sqrt{8}} = \frac{6}{2\sqrt{2}} = \frac{3}{\sqrt{2}} = \frac{3\sqrt{2}}{2}\)

Bonus Solution 2

Given \(x^{2/3} = 4\)

Raise both sides to the reciprocal power: \(x = 4^{3/2}\)

\(x = (\sqrt{4})^3 = 2^3 = 8\)

Check: \(8^{2/3} = (\sqrt[3]{8})^2 = 2^2 = 4\) ✓
