Solutions: Problem Set 4

Introduction to Proofs - Lecture 4

Key ideas used in these solutions

  • Equivalence classes partition the underlying set; the proof uses all three defining properties.
  • Injectivity is proved by starting from equal outputs; surjectivity by constructing a preimage for an arbitrary output.
  • Composition respects injectivity and surjectivity, and inverses exist exactly for bijections.
  • Preimages of sets behave better than images because the definition is a membership condition.

Worked solutions

Problem 1: Let \(a\sim b\) on \(\mathbb{Z}\) mean \(a\equiv b\pmod 3\). Prove \(\sim\) is an equivalence relation and list its distinct equivalence classes.
Reflexivity. \(a-a=0=0\cdot3\), so \(a\sim a\).
Symmetry. If \(a\sim b\), then \(a-b=3k\), so \(b-a=3(-k)\), hence \(b\sim a\).
Transitivity. If \(a-b=3k\) and \(b-c=3\ell\), then \(a-c=3(k+\ell)\), hence \(a\sim c\).
Classes. By the division algorithm every integer has remainder \(0,1\), or \(2\) modulo \(3\). Thus the distinct classes are \([0]=3\mathbb{Z}\), \([1]=3\mathbb{Z}+1\), \([2]=3\mathbb{Z}+2\); they are pairwise disjoint and cover \(\mathbb{Z}\).
Problem 2: Give an explicit example of a relation on \(\{1,2\}\) that is symmetric and transitive but not reflexive, and explain why this does not contradict Theorem 4.5.

Take \(R=\varnothing\) on \(A=\{1,2\}\). It is symmetric and transitive vacuously, since there are no pairs \((a,b)\in R\) to test. It is not reflexive because \((1,1)\notin R\) and \((2,2)\notin R\). Theorem 4.5 assumes all three properties, including reflexivity; symmetry and transitivity alone are insufficient. Another example is \(R=\{(1,1)\}\), which is symmetric and transitive but not reflexive at \(2\).

Problem 3: Prove that the relation \(\le\) on \(\mathbb{R}\) is a total order.
Reflexivity. \(a\le a\) for every real \(a\).
Antisymmetry. If \(a\le b\) and \(b\le a\), then \(a=b\) by the basic order property of \(\mathbb{R}\).
Transitivity. If \(a\le b\) and \(b\le c\), then \(a\le c\).
Totality. For any \(a,b\in\mathbb{R}\), either \(a\le b\) or \(b\le a\) by the law of trichotomy. Hence \(\le\) is a total order.
Problem 4: Prove that \(f:\mathbb{R}\setminus\{1\} o\mathbb{R}\setminus\{2\}\), \(f(x)=\frac{2x}{x-1}\) is injective, and find its range. Is it surjective onto \(\mathbb{R}\setminus\{2\}\)?
Injectivity. Suppose \(\frac{2a}{a-1}=\frac{2b}{b-1}\) with \(a,b\ne1\). Cross-multiplying gives \(2a(b-1)=2b(a-1)\), so \(2ab-2a=2ab-2b\), hence \(a=b\).
Range. Solve \(y=\frac{2x}{x-1}\) for \(x\): \(y(x-1)=2x\), so \(x(y-2)=y\), and \(x=\frac{y}{y-2}\) whenever \(y\ne2\). For \(y=2\) the equation becomes \(2x-2=2x\), impossible. Thus the range is \(\mathbb{R}\setminus\{2\}\).
Conclusion. For each \(y\ne2\), \(x=y/(y-2)\) is defined and not equal to \(1\) (since \(y\ne y-2\)), so \(f(x)=y\). Hence \(f\) is bijective onto the stated codomain.
Problem 5: Let \(f:A o B\), and let \(S,T\subseteq A\). Prove \(f(S\cup T)=f(S)\cup f(T)\), and give an example where \(f(S\cap T) e f(S)\cap f(T)\).
Union. If \(y\in f(S\cup T)\), then \(y=f(x)\) for some \(x\in S\cup T\), so \(x\in S\) or \(x\in T\); hence \(y\in f(S)\) or \(y\in f(T)\). Conversely, if \(y\in f(S)\cup f(T)\), then \(y=f(x)\) with \(x\in S\) or \(x\in T\), so \(x\in S\cup T\) and \(y\in f(S\cup T)\).
Intersection counterexample. Let \(f:\mathbb{R}\to\mathbb{R}\), \(f(x)=x^2\), \(S=\{-1\}\), \(T=\{1\}\). Then \(S\cap T=\varnothing\), so \(f(S\cap T)=\varnothing\), while \(f(S)=f(T)=\{1\}\), so \(f(S)\cap f(T)=\{1\}\).

If \(f\) is injective, equality does hold for intersections: a common output \(y=f(s)=f(t)\) forces \(s=t\), so \(s\in S\cap T\).

Problem 6: Prove part (2) of Theorem 4.12: if \(f:A o B\) and \(g:B o C\) are surjective, then \(g\circ f\) is surjective.

Let \(c\in C\) be arbitrary. Since \(g\) is surjective, there exists \(b\in B\) with \(g(b)=c\). Since \(f\) is surjective, there exists \(a\in A\) with \(f(a)=b\). Then \((g\circ f)(a)=g(f(a))=g(b)=c\). Since \(c\) was arbitrary, every element of \(C\) has a preimage under \(g\circ f\), so the composition is surjective.

Problem 7: A function \(f:A o B\) satisfies \(f^{-1}(\{b\})=\{a\}\) for every \(b\in B\) and a fixed \(a\in A\). What can you conclude about \(A\), \(B\), and \(f\)? Justify.

Since every fibre \(f^{-1}(\{b\})\) equals the same singleton \(\{a\}\), there can be only one element \(b\in B\); otherwise two distinct fibres would both contain \(a\), forcing \(f(a)\) to be two different values. Also \(B\ne\varnothing\) because the hypothesis refers to every \(b\in B\). Thus \(B=\{b_0\}\) for some \(b_0\), \(A=\{a\}\), and \(f(a)=b_0\); the function is the unique bijection from a one-element set to a one-element set.

Problem 8: Prove that if \(g\circ f\) is injective, then \(f\) is injective. Give a counterexample to the claim that \(g\) must also be injective.
Proof for \(f\). Suppose \(f(a_1)=f(a_2)\). Applying \(g\) gives \(g(f(a_1))=g(f(a_2))\), i.e. \((g\circ f)(a_1)=(g\circ f)(a_2)\). Injectivity of \(g\circ f\) gives \(a_1=a_2\), so \(f\) is injective.
Counterexample for \(g\). Let \(f:\{1\}\to\{1,2\}\) be \(f(1)=1\), and \(g:\{1,2\}\to\{1\}\) be constant. Then \(g\circ f\) maps the one-element domain injectively into \(\{1\}\), but \(g\) is not injective since \(g(1)=g(2)\).
Bonus Problem: Prove that if \(f:A\to B\) and \(g:B\to C\) are injective, then \(g\circ f:A\to C\) is injective.
Suppose \((g\circ f)(a_1)=(g\circ f)(a_2)\). Then \(g(f(a_1))=g(f(a_2))\). Since \(g\) is injective, \(f(a_1)=f(a_2)\). Since \(f\) is injective, \(a_1=a_2\). Therefore \(g\circ f\) is injective.
