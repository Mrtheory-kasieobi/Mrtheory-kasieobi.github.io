Problem Set 2: Euclidean Algorithm and Bézout's Identity

Elementary Number Theory - Week 2 Medium

Problems

Problem 1

Compute \(\gcd(1071, 462)\) using the Euclidean algorithm.

Problem 2

Find integers \(x, y\) such that \(56x + 15y = \gcd(56, 15)\).

Problem 3

Apply the extended Euclidean algorithm to find \(\gcd(120, 23)\) and express it as a linear combination.

Problem 4

Prove: If \(d = \gcd(a, b)\), then there exist integers \(x, y\) such that \(ax + by = d\).

Problem 5

Show that \(\gcd(a, b) = \gcd(a + b, a - b)\) when \(a, b\) are both odd.

Problem 6

Find all integer solutions to \(15x + 25y = 5\).

Problem 7

Prove: If \(ax + by = c\) has integer solutions, then \(\gcd(a, b) \mid c\).

Problem 8

Find the multiplicative inverse of 17 modulo 31.

Problem 9

Show that if \(\gcd(a, b) = 1\), there are infinitely many solutions to \(ax + by = 1\).

Problem 10

Use the extended Euclidean algorithm to write \(\gcd(81, 36)\) as a linear combination.

Bonus Problems

Bonus Problem 1

Challenge: Prove that if \(ax + by = c\) and \(ax' + by' = c'\), then any linear combination of these solutions is also a solution to a related equation.

Bonus Problem 2

Challenge: Find the smallest positive integer that can be written as \(17x + 29y\) for integers \(x, y\).

Bonus Problem 3

Challenge: Prove that if \(\gcd(a, b) = d\), then \(\gcd(\frac{a}{d}, \frac{b}{d}) = 1\).
