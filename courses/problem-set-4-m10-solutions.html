Problem Set 4: Roots and Powers

Mathematics 10 - Chapter 4 Solutions

Solutions

Problem 1: Simplify: \(x^5 \times x^3 \div x^2\)
Apply \(a^m \times a^n = a^{m+n}\): \(x^5 \times x^3 = x^{5+3} = x^8\)
Apply \(\frac{a^m}{a^n} = a^{m-n}\): \(x^8 \div x^2 = x^{8-2} = x^6\)
Answer: \(x^6\)
Problem 2: Simplify: \((x^2 y^3)^4 \div (x y^2)^2\)
Apply power of power: \((x^2 y^3)^4 = x^{2 \times 4} y^{3 \times 4} = x^8 y^{12}\)
Apply power of power: \((x y^2)^2 = x^2 y^{2 \times 2} = x^2 y^4\)
Divide: \(\frac{x^8 y^{12}}{x^2 y^4} = x^{8-2} y^{12-4} = x^6 y^8\)
Answer: \(x^6 y^8\)
Problem 3: Simplify: \(\frac{(2a^{-3})^2}{(4a^{-1})^2}\)
Numerator: \((2a^{-3})^2 = 4a^{-6}\)
Denominator: \((4a^{-1})^2 = 16a^{-2}\)
Divide: \(\frac{4a^{-6}}{16a^{-2}} = \frac{4}{16} \times a^{-6-(-2)} = \frac{1}{4} a^{-4}\)
Convert negative exponent: \(\frac{1}{4} a^{-4} = \frac{1}{4a^4}\)
Answer: \(\frac{1}{4a^4}\)
Problem 4: Express in scientific notation: \(0.0000456\) and \(5,400,000\)
For \(0.0000456\): Move decimal 5 places right to get 4.56, so \(4.56 \times 10^{-5}\)
For \(5,400,000\): Move decimal 6 places left to get 5.4, so \(5.4 \times 10^6\)
Answer: \(4.56 \times 10^{-5}\) and \(5.4 \times 10^6\)
Problem 5: Simplify: \(\left(\frac{a^{-2}b^3}{a^4b^{-1}}\right)^{-2}\)
Inside the fraction: \(\frac{a^{-2}b^3}{a^4b^{-1}} = a^{-2-4} b^{3-(-1)} = a^{-6} b^4\)
Apply outer exponent: \((a^{-6} b^4)^{-2} = a^{-6 \times (-2)} b^{4 \times (-2)} = a^{12} b^{-8}\)
Convert negative exponent: \(a^{12} b^{-8} = \frac{a^{12}}{b^8}\)
Answer: \(\frac{a^{12}}{b^8}\)
Problem 6: Evaluate: \((2.5 \times 10^3) \times (4 \times 10^5)\)
Multiply coefficients: \(2.5 \times 4 = 10\)
Add exponents: \(10^3 \times 10^5 = 10^{3+5} = 10^8\)
Result: \(10 \times 10^8 = 10^9\)
Answer: \(1 \times 10^9\) or \(10^9\)
Problem 7: Simplify: \(\frac{(3x^2y^{-1})^3}{(9xy^2)^2}\)
Numerator: \((3x^2y^{-1})^3 = 27x^6 y^{-3}\)
Denominator: \((9xy^2)^2 = 81x^2 y^4\)
Divide: \(\frac{27x^6 y^{-3}}{81x^2 y^4} = \frac{27}{81} \times x^{6-2} \times y^{-3-4} = \frac{1}{3} x^4 y^{-7}\)
Convert negative exponent: \(\frac{x^4}{3y^7}\)
Answer: \(\frac{x^4}{3y^7}\)
Problem 8: Find the value of \(n\) if \(2^n = 0.125\)
Convert 0.125 to fraction: \(0.125 = \frac{125}{1000} = \frac{1}{8}\)
Express as power of 2: \(\frac{1}{8} = \frac{1}{2^3} = 2^{-3}\)
So: \(2^n = 2^{-3}\)
Answer: \(n = -3\)

Bonus Solutions

Bonus Problem 1: Exponent Detective
Factor 72: \(72 = 8 \times 9 = 2^3 \times 3^2\), so \(a = 3, b = 2\)
Factor 108: \(108 = 4 \times 27 = 2^2 \times 3^3\), so \(c = 2, d = 3\)
\(a + b + c + d = 3 + 2 + 2 + 3 = 10\)
For \(xy\): \(x = 2^3 \times 3^2\), \(y = 2^2 \times 3^3\)
\(xy = 2^{3+2} \times 3^{2+3} = 2^5 \times 3^5\)
Answer: \(a + b + c + d = 10\). \(xy = 2^5 \times 3^5\).
Bonus Problem 2: Scientific Notation Puzzle
\(N \times 10^{-50} = 2.5 \times 10^{100} \times 10^{-50} = 2.5 \times 10^{50}\)
\(N \times 10^{-50} + N \times 10^{-50} = 2 \times (2.5 \times 10^{50}) = 5 \times 10^{50}\)
In scientific notation: \(5.0 \times 10^{50}\)
Number: 5 followed by 50 zeros
Zeros between first and last digit: 50 zeros
Answer: \(5.0 \times 10^{50}\), with 50 zeros between first and last digit.
Bonus Problem 3: Power Tower Challenge
Find smallest \(k = 2^a + 2^b\) (with \(a \neq b\)) divisible by 3
Try small values: \(2^0 + 2^1 = 1 + 2 = 3\) ✓
\(k = 3 = 3 \times 10^0\) in scientific notation
Answer: \(k = 3 = 3.0 \times 10^0\).
