Lecture 4: Functions and Relations

Introduction to Proofs · Week 4

Lecture 4Functions and Relations

Learning objectives

By the end of this lecture you should be able to:

  • Define relations and test reflexivity, symmetry and transitivity.
  • Explain equivalence relations, equivalence classes and their connection to partitions.
  • Recognise partial orders and total orders.
  • Define functions precisely and prove injectivity or surjectivity.
  • Compose functions and analyse inverse functions and images of sets.
Beginner's bridge

A relation is a rule that answers yes or no to “are these two objects related?”. A function is a special relation: every input has exactly one output. On \(\mathbb{Z}\), the rule \(f(n)=2n\) is a function. It is injective because two inputs with the same output must be equal, but it is not surjective onto \(\mathbb{Z}\) because no odd integer is hit.

An equivalence relation is a relation that behaves like equality after you decide which differences to ignore. Congruence modulo \(n\) ignores differences that are multiples of \(n\), so \(17\equiv2\pmod5\). The resulting equivalence classes group integers by remainder.

1. Relations

Definition 4.1 (Relation) A (binary) relation from a set \(A\) to a set \(B\) is a subset \(R\subseteq A\times B\). If \((a,b)\in R\), write \(aRb\). A relation on \(A\) is a subset of \(A\times A\).

Since a relation is a set, equality of relations means equality as sets of ordered pairs. The domain of \(R\) is \(\{a\in A:\exists b\in B,\,(a,b)\in R\}\), and its range is \(\{b\in B:\exists a\in A,\,(a,b)\in R\}\).

Definition 4.2 (Properties of a relation on \(A\))
  • Reflexive: \(\forall a\in A,\,(a,a)\in R\).
  • Symmetric: \(\forall a,b\in A,\,(a,b)\in R\to(b,a)\in R\).
  • Antisymmetric: \(\forall a,b\in A,\,[(a,b)\in R\land(b,a)\in R]\to a=b\).
  • Transitive: \(\forall a,b,c\in A,\,[(a,b)\in R\land(b,c)\in R]\to(a,c)\in R\).
Example 4.3 On \(\mathbb{Z}\), the relation \(\le\) is reflexive, antisymmetric and transitive, but not symmetric. The relation \(=\) has all four properties. The relation "\(a\) divides \(b\)" on \(\mathbb{N}\) is reflexive and transitive, and antisymmetric on \(\mathbb{N}\), but not symmetric. On \(\mathbb{Z}\), divisibility is not antisymmetric because \(2\mid-2\) and \(-2\mid2\) while \(2\ne-2\).

2. Equivalence relations and partitions

Definition 4.4 (Equivalence relation) A relation \(\sim\) on \(A\) that is reflexive, symmetric and transitive is an equivalence relation. For \(a\in A\), the equivalence class of \(a\) is \([a]=\{x\in A:x\sim a\}\). The set of all classes is denoted \(A/{\sim}\) and called the quotient of \(A\) by \(\sim\).
Theorem 4.5 If \(\sim\) is an equivalence relation on \(A\), then:
  1. \(a\in[a]\) for every \(a\in A\).
  2. \([a]=[b]\) if and only if \(a\sim b\).
  3. Any two classes are either equal or disjoint.
  4. \(\bigcup_{a\in A}[a]=A\).
Thus the equivalence classes form a partition of \(A\): a collection of nonempty, pairwise disjoint subsets whose union is \(A\).
Proof of (2) and (3). If \([a]=[b]\), then \(a\in[a]=[b]\), so \(a\sim b\) by the definition of \([b]\) and symmetry. Conversely, suppose \(a\sim b\). If \(x\in[a]\), then \(x\sim a\); with \(a\sim b\), transitivity gives \(x\sim b\), so \(x\in[b]\). Hence \([a]\subseteq[b]\); the reverse inclusion follows by symmetry from \(b\sim a\). For (3), suppose \([a]\cap[b]\ne\varnothing\) and choose \(c\) in the intersection. Then \(a\sim c\sim b\), so \(a\sim b\), and by (2) the classes are equal. \(\square\)
Example 4.6 Congruence modulo \(n\) on \(\mathbb{Z}\), defined by \(a\sim b\iff a\equiv b\pmod n\), is an equivalence relation (proved in Lecture 3 of the number theory course). Its classes are residue classes: \(\mathbb{Z}/{\sim}=\{[0],[1],\ldots,[n-1]\}\), which partition \(\mathbb{Z}\).

3. Order relations

Definition 4.7 (Partial order) A relation \(\preceq\) on \(A\) that is reflexive, antisymmetric and transitive is a partial order, and \((A,\preceq)\) is a poset. If in addition every pair \(a,b\in A\) satisfies \(a\preceq b\) or \(b\preceq a\), the order is total (linear).

On \(\mathbb{R}\), \(\le\) is a total order. On \(\mathcal{P}(X)\), inclusion \(\subseteq\) is a partial order: \(\{1\}\not\subseteq\{2\}\) and \(\{2\}\not\subseteq\{1\}\), so it is not total. In a poset, an element \(m\) is minimal if no element is strictly below it; it is a least element if it is below every element. A least element is minimal, but a minimal element need not be least: in \(\mathcal{P}(\{1,2\})\setminus\{\varnothing\}\) under inclusion, both \(\{1\}\) and \(\{2\}\) are minimal and neither is least.

The well-ordering principle states that every nonempty set of positive integers has a least element. This is a fundamental tool for induction, which we study in Lecture 8.

4. Functions

Definition 4.8 (Function) A function \(f:A\to B\) is a relation from \(A\) to \(B\) such that for every \(a\in A\) there is exactly one \(b\in B\) with \((a,b)\in f\). We write \(f(a)=b\), call \(A\) the domain and \(B\) the codomain, and call \(b\) the image of \(a\).

Two functions are equal exactly when they have the same domain and the same value at every element of that domain. The codomain is part of the data of a function: \(f:\mathbb{R}\to\mathbb{R}\), \(f(x)=x^2\) and \(g:\mathbb{R}\to[0,\infty)\), \(g(x)=x^2\) are different functions even though their rules agree.

Definition 4.9 (Injective, surjective, bijective) For \(f:A\to B\):
  • \(f\) is injective (one-to-one) if \(f(a_1)=f(a_2)\implies a_1=a_2\) for all \(a_1,a_2\in A\).
  • \(f\) is surjective (onto) if for every \(b\in B\) there exists \(a\in A\) with \(f(a)=b\).
  • \(f\) is bijective if it is both injective and surjective.
The image of \(f\) is \(f(A)=\{f(a):a\in A\}\), so surjectivity is the statement \(f(A)=B\). For \(S\subseteq B\), the preimage is \(f^{-1}(S)=\{a\in A:f(a)\in S\}\).
Example 4.10 Let \(f:\mathbb{R}\to\mathbb{R}\), \(f(x)=x^2\). It is not injective, since \(f(-1)=f(1)\), and not surjective, since no real \(x\) satisfies \(x^2=-1\). If the domain is restricted to \([0,\infty)\) and codomain to \([0,\infty)\), the same formula gives a bijection.

To prove injectivity, start with the equation \(f(a_1)=f(a_2)\) and deduce \(a_1=a_2\). To prove surjectivity, let \(b\in B\) be arbitrary and construct an \(a\in A\) with \(f(a)=b\); the constructed \(a\) may depend on \(b\).

5. Composition, inverses, and images

Definition 4.11 If \(f:A\to B\) and \(g:B\to C\), their composition is \(g\circ f:A\to C\), \((g\circ f)(a)=g(f(a))\). A function \(g:B\to A\) is an inverse of \(f\) if \(g\circ f=\operatorname{id}_A\) and \(f\circ g=\operatorname{id}_B\).
Theorem 4.12
  1. If \(f\) and \(g\) are injective, then \(g\circ f\) is injective.
  2. If \(f\) and \(g\) are surjective, then \(g\circ f\) is surjective.
  3. A function \(f:A\to B\) has an inverse if and only if it is bijective; when the inverse exists it is unique and denoted \(f^{-1}\).
  4. For any \(f:A\to B\) and \(S,T\subseteq B\): \(f^{-1}(S\cup T)=f^{-1}(S)\cup f^{-1}(T)\) and \(f^{-1}(S\cap T)=f^{-1}(S)\cap f^{-1}(T)\).
Proof of (1) and (3). For (1), suppose \(g(f(a_1))=g(f(a_2))\). Injectivity of \(g\) gives \(f(a_1)=f(a_2)\), and injectivity of \(f\) gives \(a_1=a_2\). For (3), if \(g\) is an inverse and \(f(a_1)=f(a_2)\), applying \(g\) gives \(a_1=a_2\), so \(f\) is injective; for \(b\in B\), \(a=g(b)\) satisfies \(f(a)=b\), so \(f\) is surjective. Conversely, if \(f\) is bijective, define \(g(b)\) to be the unique \(a\) with \(f(a)=b\); then \(g(f(a))=a\) and \(f(g(b))=b\). Uniqueness follows because if \(g\) and \(h\) are both inverses, \(g=g\circ\operatorname{id}_B=g\circ(f\circ h)=(g\circ f)\circ h=\operatorname{id}_A\circ h=h\). \(\square\)

Part (4) is proved by element chasing: \(a\in f^{-1}(S\cup T)\iff f(a)\in S\cup T\iff f(a)\in S\text{ or }f(a)\in T\iff a\in f^{-1}(S)\cup f^{-1}(T)\). Notice that preimages preserve unions and intersections in both directions; images preserve unions but only preserve intersections when \(f\) is injective.

6. Extra detail: classes partition the domain

Theorem 4.10 If \(\sim\) is an equivalence relation on \(A\), then any two equivalence classes are either equal or disjoint.
Proof. Suppose \([a]\cap[b]\ne\varnothing\), and choose \(c\) in the intersection. Then \(c\sim a\) and \(c\sim b\). By symmetry, \(a\sim c\), and by transitivity, \(a\sim b\). If \(x\in[a]\), then \(x\sim a\sim b\), so \(x\in[b]\); hence \([a]\subseteq[b]\). The reverse inclusion follows similarly from \(b\sim a\). Therefore \([a]=[b]\). If the classes do not intersect, they are disjoint. \(\square\)

This theorem is why equivalence classes form a partition: every element lies in at least one class by reflexivity, and distinct classes do not overlap. For functions, the corresponding structural result is that \(f\) is bijective exactly when there is an inverse function \(f^{-1}:B\to A\).

Exercises
  1. On \(\mathbb{Z}\), define \(a\sim b\) iff \(a-b\) is even. Verify that \(\sim\) is an equivalence relation and describe its classes.
  2. Give an example of a relation that is symmetric and transitive but not reflexive.
  3. Decide whether \(\subseteq\) on \(\mathcal{P}(\{1,2,3\})\) is a total order.
  4. Prove that \(f:\mathbb{R} o\mathbb{R}\), \(f(x)=3x+1\) is bijective by finding an explicit inverse.
  5. Let \(f:\mathbb{R} o\mathbb{R}\), \(f(x)=x^2\). Find \(f^{-1}([4,9])\).
  6. Prove that a composition of two surjections is surjective.
  7. Give an example showing that \(f(S\cap T) e f(S)\cap f(T)\) can happen.
  8. If \(f:A o B\) is injective and \(S\subseteq A\), prove \(f^{-1}(f(S))=S\).
