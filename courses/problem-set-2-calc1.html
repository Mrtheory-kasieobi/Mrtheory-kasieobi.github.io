Problem Set 2: Limits and Continuity

Calculus I - Week 2

Instructions

Show all work. No calculators. Write clearly and show each step.

Problems

  • 1. Evaluate \(\lim_{x \to 3} \frac{x^2 - 9}{x - 3}\)
  • 2. Evaluate \(\lim_{x \to 0} \frac{\sin(5x)}{x}\)
  • 3. Evaluate \(\lim_{x \to 2} \frac{\sqrt{x+2} - 2}{x - 2}\)
  • 4. Find \(\lim_{x \to \infty} \frac{3x^2 + 2x - 1}{2x^2 + 5}\)
  • 5. Find \(\lim_{x \to 0^+} \ln x\)
  • 6. Evaluate \(\lim_{x \to 0} \frac{e^x - 1}{x}\)
  • 7. Evaluate \(\lim_{x \to 1} \frac{x^3 - 1}{x^4 - 1}\)
  • 8. Use the definition of continuity to determine if \(f(x) = \frac{x^2 - 4}{x - 2}\) is continuous at \(x = 2\).
  • 9. Find all values of \(a\) such that the function is continuous everywhere: \[ f(x) = \begin{cases} x^2 + 1 & \text{if } x < 2 \\ ax + 3 & \text{if } x \geq 2 \end{cases} \]
  • 10. Prove that \(\lim_{x \to 0} \frac{1 - \cos x}{x} = 0\) using the limit \(\lim_{x \to 0} \frac{\sin x}{x} = 1\)
Bonus Problems (10 points each):
  • B1. Evaluate \(\lim_{x \to 0} \frac{\tan x - \sin x}{x^3}\)
  • B2. Prove that if \(f\) and \(g\) are continuous at \(a\), then \(f \cdot g\) is continuous at \(a\).
