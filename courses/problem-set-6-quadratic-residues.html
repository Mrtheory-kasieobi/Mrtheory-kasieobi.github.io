Problem Set 6: Quadratic Residues and the Legendre Symbol

Elementary Number Theory - Week 6 Medium

Problems

Problem 1

Determine whether 3 is a quadratic residue modulo 11.

Problem 2

Compute \(\left(\frac{5}{7}\right)\) using Euler's criterion.

Problem 3

Find all quadratic residues modulo 13.

Problem 4

Compute \(\left(\frac{-1}{p}\right)\) for prime \(p\).

Problem 5

Show that if \(p \equiv 1 \pmod{4}\), then \(\left(\frac{-1}{p}\right) = 1\).

Problem 6

Compute \(\left(\frac{2}{p}\right)\) for odd prime \(p\).

Problem 7

Find all \(x\) such that \(x^2 \equiv 7 \pmod{29}\).

Problem 8

Prove: \(\left(\frac{ab}{p}\right) = \left(\frac{a}{p}\right)\left(\frac{b}{p}\right)\).

Problem 9

Compute \(\left(\frac{3}{17}\right)\) using quadratic reciprocity.

Problem 10

Show that \(\left(\frac{a^2}{p}\right) = 1\) for \(p \nmid a\).

Bonus Problems

Bonus Problem 1

Challenge: Prove: \(\left(\frac{-1}{p}\right) = (-1)^{\frac{p-1}{2}}\).

Bonus Problem 2

Challenge: Show that \(\left(\frac{2}{p}\right) = (-1)^{\frac{p^2-1}{8}}\).

Bonus Problem 3

Challenge: Prove: If \(p \equiv 1 \pmod{3}\), then \(\left(\frac{-3}{p}\right) = 1\).
