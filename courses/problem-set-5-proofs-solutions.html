Solutions: Problem Set 5

Introduction to Proofs - Lecture 5

Key ideas used in these solutions

  • An even integer has the form \(2k\), an odd integer \(2k+1\), and \(a\mid b\) means \(b=ak\).
  • Proof by contrapositive replaces \(p o q\) with the equivalent \( eg q o eg p\).
  • A biconditional requires two separate proofs.
  • Case splits must cover every possibility allowed by the hypotheses.

Worked solutions

Problem 1: Prove directly: if \(a\) is even and \(b\) is odd, then \(a+b\) is odd.

Write \(a=2k\) and \(b=2\ell+1\) with \(k,\ell\in\mathbb{Z}\). Then \[a+b=2k+2\ell+1=2(k+\ell)+1.\] Since \(k+\ell\in\mathbb{Z}\), the sum \(a+b\) has the form \(2m+1\), so it is odd.

Problem 2: Prove: if \(a\mid b\), then \(a\mid bc\) for every integer \(c\).

Assume \(a\mid b\). Then \(b=ak\) for some \(k\in\mathbb{Z}\). Multiplying by \(c\) gives \(bc=(ak)c=a(kc)\). Since \(kc\in\mathbb{Z}\), the definition of divisibility gives \(a\mid bc\).

Problem 3: Prove by contrapositive: if \(n^2\) is divisible by \(5\), then \(n\) is divisible by \(5\).

We prove the contrapositive: if \(5\nmid n\), then \(5\nmid n^2\). Every integer is congruent to \(0,1,2,3\), or \(4\) modulo \(5\). If \(5\nmid n\), the residue is \(1,2,3\), or \(4\). Squaring these residues modulo \(5\) gives \(1,4,4,1\) respectively; none is \(0\). Hence \(n^2\not\equiv0\pmod5\), i.e. \(5\nmid n^2\). By contraposition the original implication holds.

Problem 4: Prove that if \(n\) is odd, then \(n^2\equiv1\pmod 8\).

Let \(n=2k+1\). Then \(n^2=4k^2+4k+1=4k(k+1)+1\). The product \(k(k+1)\) is even because consecutive integers have opposite parity, so \(k(k+1)=2m\) for some \(m\in\mathbb{Z}\). Therefore \(n^2=8m+1\), so \(n^2-1=8m\) and \(n^2\equiv1\pmod8\).

Problem 5: Prove or disprove: if \(a\mid b+c\), then \(a\mid b\) or \(a\mid c\).

The statement is false. Take \(a=2\), \(b=1\), and \(c=1\). Then \(b+c=2\), so \(2\mid2\), but \(2\nmid1\) and \(2\nmid1\). This illustrates that divisibility of a sum does not force divisibility of the summands. The converse statement (if \(a\mid b\) and \(a\mid c\), then \(a\mid b+c\)) is true and was proved in the number theory setting.

Problem 6: Prove by cases: for every integer \(n\), \(n^2\equiv0\) or \(1\pmod4\).
Case 1: \(n\) even. Write \(n=2k\). Then \(n^2=4k^2\equiv0\pmod4\).
Case 2: \(n\) odd. Write \(n=2k+1\). Then \(n^2=4k^2+4k+1=4(k^2+k)+1\equiv1\pmod4\).

Every integer is even or odd, so the two cases exhaust all possibilities and the conclusion follows.

Problem 7: Prove that \(2n^2+1\) and \(n^2-1\) cannot both be even for the same integer \(n\).

Use contrapositive-style reasoning on parity. If \(n\) is even, \(n=2k\), then \(n^2-1=4k^2-1=2(2k^2-1)+1\) is odd. If \(n\) is odd, \(n=2k+1\), then \(2n^2+1=2(2k+1)^2+1\), which is odd. Since \(n\) is either even or odd, at least one of the two expressions is odd; they cannot both be even.

Problem 8: Prove: \(\gcd(a,b)=1\) if and only if there exist integers \(x,y\) with \(ax+by=1\).
Forward (\(\Rightarrow\)). This is Bézout's identity: applying the Euclidean algorithm to \(a,b\) produces integers \(x,y\) with \(ax+by=\gcd(a,b)=1\).
Reverse (\(\Leftarrow\)). Suppose \(ax+by=1\), and let \(d=\gcd(a,b)\). Then \(d\mid a\) and \(d\mid b\), so \(d\mid(ax+by)=1\). Since \(d\) is a positive divisor of \(1\), \(d=1\).

Both directions are needed: the forward direction supplies the coefficients, and the reverse direction shows that any such linear combination forces the gcd to be \(1\).

Bonus Problem: Prove that if \(a\mid b\) and \(a\mid c\), then \(a\mid mb+nc\) for all integers \(m,n\).
Write \(b=ak\) and \(c=al\). Then \(mb+nc=m(ak)+n(al)=a(mk+nl)\). Since \(mk+nl\in\mathbb{Z}\), it follows that \(a\mid mb+nc\).
