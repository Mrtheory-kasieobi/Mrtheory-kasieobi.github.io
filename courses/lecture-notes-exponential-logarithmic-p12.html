Exponential and Logarithmic Functions

Precalculus 12 - Lecture Notes
British Columbia Curriculum | Last Updated: 2026

1. Characteristics of Exponential Functions

An exponential function has the form \(f(x) = a^x\) where \(a > 0\) and \(a \neq 1\).

Definition: An exponential function is a function of the form \(f(x) = a \cdot b^x\) where \(a\) and \(b\) are positive real numbers and \(b \neq 1\).

1.1 Key Properties

  • Domain: all real numbers
  • Range: \((0, \infty)\)
  • Horizontal asymptote: \(y = 0\)
  • If \(a > 1\): increasing function
  • If \(0 < a < 1\): decreasing function
Example 1: Analyzing Exponential Functions

Analyze \(f(x) = 2 \cdot 3^x\).

Since \(a = 2 > 0\) and \(b = 3 > 1\), this is an increasing exponential function.

Y-intercept: \(f(0) = 2 \cdot 3^0 = 2\)

As \(x \to \infty\), \(f(x) \to \infty\); as \(x \to -\infty\), \(f(x) \to 0\)

2. Transformations of Exponential Functions

Transformed Exponential Function:
\[f(x) = a \cdot b^{x - h} + k\]
Example 2: Transformed Exponential

Graph \(f(x) = 2 \cdot 3^{x - 1} - 4\).

Starting from \(g(x) = 3^x\):

  1. Shift right 1 unit: \(3^{x-1}\)
  2. Vertical stretch by 2: \(2 \cdot 3^{x-1}\)
  3. Shift down 4 units: \(2 \cdot 3^{x-1} - 4\)

Horizontal asymptote: \(y = -4\)

3. Solving Exponential Equations

Example 3: Solving Exponential Equations

Solve \(2^{x+1} = 16\).

Express both sides with base 2: \(2^{x+1} = 2^4\)

Therefore: \(x + 1 = 4\), so \(x = 3\)

3.1 Using Logarithms to Solve

When we cannot easily express both sides with the same base, we use logarithms.

Example 4: Using Logarithms

Solve \(3^x = 10\).

Take logarithm of both sides: \(\log(3^x) = \log(10)\)

\(x\log(3) = 1\)

\(x = \frac{1}{\log(3)} = \frac{1}{\ln(3)} \approx 0.910\)

4. Understanding Logarithms

4.1 Definition and Properties

A logarithm is the inverse of an exponential function.

Definition: If \(b^y = x\), then \(\log_b(x) = y\).
Key Properties:
\[\log_b(xy) = \log_b(x) + \log_b(y)\]
\[\log_b\left(\frac{x}{y}\right) = \log_b(x) - \log_b(y)\]
\[\log_b(x^n) = n\log_b(x)\]

5. Transformations of Logarithmic Functions

Transformed Logarithmic Function:
\[f(x) = a \cdot \log_b(x - h) + k\]
Example 5: Logarithmic Transformation

Graph \(f(x) = 2\log_3(x + 1) - 1\).

Starting from \(g(x) = \log_3(x)\):

  1. Shift left 1 unit: \(\log_3(x + 1)\)
  2. Vertical stretch by 2: \(2\log_3(x + 1)\)
  3. Shift down 1 unit: \(2\log_3(x + 1) - 1\)

Vertical asymptote: \(x = -1\)

6. Laws of Logarithms

Product Rule: \(\log_b(xy) = \log_b(x) + \log_b(y)\)
Quotient Rule: \(\log_b\left(\frac{x}{y}\right) = \log_b(x) - \log_b(y)\)
Power Rule: \(\log_b(x^n) = n\log_b(x)\)
Example 6: Using Laws of Logarithms

Simplify: \(\log_2(8x^3) - \log_2(4x)\)

\(\log_2(8x^3) - \log_2(4x) = \log_2\left(\frac{8x^3}{4x}\right) = \log_2(2x^2) = \log_2(2) + \log_2(x^2) = 1 + 2\log_2(x)\)

7. Logarithmic and Exponential Equations

Example 7: Solving Logarithmic Equations

Solve \(\log_3(x + 2) + \log_3(x - 1) = 1\).

Combine: \(\log_3((x + 2)(x - 1)) = 1\)

\((x + 2)(x - 1) = 3^1 = 3\)

\(x^2 + x - 2 = 3\)

\(x^2 + x - 5 = 0\)

\(x = \frac{-1 \pm \sqrt{21}}{2}\) (check domain: \(x > 1\) or \(x < -2\))

8. Practice Problems

Problem 1

Solve \(5^{2x} = 125\) for \(x\).

Problem 2

Simplify: \(\log(x^2) + \log(\sqrt{x}) - \log(2x)\)

Problem 3

Solve \(\ln(x - 1) + \ln(x + 2) = \ln(6)\)
