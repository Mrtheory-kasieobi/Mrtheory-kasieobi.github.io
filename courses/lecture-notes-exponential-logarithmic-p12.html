Exponential and Logarithmic Functions

Precalculus 12 - Lecture Notes
British Columbia Curriculum | Last Updated: 2026

1. Exponential Functions

Exponential functions model phenomena where the rate of change is proportional to the current value - from bacterial growth to compound interest. They are fundamental to understanding continuous processes.

1.1 Definition and Standard Form

Definition: An exponential function has the form \(f(x) = a \cdot b^x\) where:
  • \(a\) = initial value (y-intercept when x = 0)
  • \(b\) = base (b > 0, b ≠ 1)
  • \(x\) = exponent (input variable)
Why b > 0?

If b ≤ 0, then b^x is undefined for many values of x (like b = -2 and x = 1/2 gives √(-2)). We require b > 0 to ensure the function is defined for all real numbers.

1.2 The Natural Exponential f(x) = e^x

The number \(e \approx 2.71828\) is a special base. The function \(f(x) = e^x\) is called the natural exponential function.

Natural Base: \(e = \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n \approx 2.71828\)

The natural exponential has the special property that its rate of change equals its value at every point.

1.3 Domain and Range

Function Type Domain Range
\(f(x) = a \cdot b^x\) (a > 0) All real numbers \((0, \infty)\)
\(f(x) = a \cdot b^x\) (a < 0) All real numbers \((-\infty, 0)\)
\(f(x) = e^x\) All real numbers \((0, \infty)\)

1.4 Growth and Decay Models

When b > 1: exponential growth (values increase rapidly)
When 0 < b < 1: exponential decay (values decrease toward 0)

Compound Growth Model:
\(A = P(1 + r)^t\) for discrete compounding
\(A = Pe^{rt}\) for continuous compounding
Example 1: Population Growth

A population of 1000 doubles every 5 years. Find the population after 15 years.

Growth model: \(P(t) = 1000 \cdot 2^{t/5}\)

After 15 years: \(P(15) = 1000 \cdot 2^{15/5} = 1000 \cdot 2^3 = 8000\)

1.5 Transformations of Exponential Functions

The general form combines all transformations:

Transformed Exponential:
\(f(x) = a \cdot b^{x - h} + k\)
Parameter Effect
a Vertical stretch/compression by |a|, reflection if a < 0
b Base: b > 1 (growth), 0 < b < 1 (decay)
h Horizontal shift by h units
k Vertical shift by k units (shifts horizontal asymptote)
Example 2: Transforming an Exponential

Describe the transformations from \(f(x) = e^x\) to \(g(x) = -2e^{x+1} + 3\):

  1. Left shift by 1: \(e^{x+1}\)
  2. Vertical stretch by 2: \(2e^{x+1}\)
  3. Reflection across x-axis: \(-2e^{x+1}\)
  4. Up shift by 3: \(-2e^{x+1} + 3\)

Horizontal asymptote: y = 3

2. Logarithmic Functions

2.1 Definition as Inverse Functions

Logarithms are defined as the inverse operation of exponentials.

Definition: If \(b^y = x\) where b > 0, b ≠ 1, then \(\log_b(x) = y\)

This means: "The logarithm base b of x is the exponent to which b must be raised to get x."

2.2 Domain and Range

Function Type Domain Range
\(f(x) = \log_b(x)\) \((0, \infty)\) All real numbers
\(f(x) = \ln(x)\) \((0, \infty)\) All real numbers

2.3 Common and Natural Logarithms

  • Common Logarithm: \(\log x\) means \(\log_{10}(x)\)
  • Natural Logarithm: \(\ln x\) means \(\log_e(x)\)
Why Only x > 0?

There is no real number y such that \(b^y = x\) when x ≤ 0 (for b > 0, b ≠ 1). This is why the domain of logarithms is only positive numbers.

2.4 Transformations of Logarithmic Functions

Transformed Logarithm:
\(f(x) = a \cdot \log_b(x - h) + k\)
Parameter Effect
a Vertical stretch by |a|, reflection if a < 0
h Horizontal shift (vertical asymptote at x = h)
k Vertical shift by k units
Example 3: Graphing a Logarithm

Graph \(f(x) = 2\log_3(x + 1) - 1\):

  • Vertical asymptote: x = -1 (where log argument = 0)
  • Point when x = 0: \(f(0) = 2\log_3(1) - 1 = -1\) → point (0, -1)
  • Point when x = 2: \(f(2) = 2\log_3(3) - 1 = 1\) → point (2, 1)

3. Laws of Logarithms

Logarithm laws are not arbitrary formulas to memorize. They arise from the fundamental properties of exponents.

3.1 Derivation from Exponent Laws

Since \(b^m \cdot b^n = b^{m+n}\), taking \(\log_b\) of both sides gives \(\log_b(b^m \cdot b^n) = m + n = \log_b(b^m) + \log_b(b^n)\)

PRODUCT RULE: \(\log_b(xy) = \log_b(x) + \log_b(y)\)
This works because multiplication of arguments becomes addition of exponents, which becomes addition of logarithms.

3.2 The Three Fundamental Laws

\[ \begin{aligned} \text{Product Rule: } & \log_b(xy) = \log_b(x) + \log_b(y) \\[6pt] \text{Quotient Rule: } & \log_b\left(\frac{x}{y}\right) = \log_b(x) - \log_b(y) \\[6pt] \text{Power Rule: } & \log_b(x^n) = n\log_b(x) \end{aligned} \]
Example 4: Applying Log Laws

Simplify: \(\log_2(8x^2) - \log_2(4x)\)

  1. Apply quotient rule: \(\log_2\left(\frac{8x^2}{4x}\right) = \log_2(2x)\)
  2. Apply product rule: \(\log_2(2) + \log_2(x) = 1 + \log_2(x)\)
Example 5: Deriving a Log Law

Show why \(\log_b(x^n) = n\log_b(x)\):

Let \(y = \log_b(x)\), so \(b^y = x\)

Then \(x^n = (b^y)^n = b^{ny}\)

Therefore \(\log_b(x^n) = ny = n \cdot \log_b(x)\)

3.3 Change of Base Formula

Change of Base:
\(\log_b(x) = \frac{\log_k(x)}{\log_k(b)}\) for any valid base k

Common forms: \(\log_b(x) = \frac{\ln(x)}{\ln(b)} = \frac{\log(x)}{\log(b)}\)

4. Solving Exponential Equations

4.1 Same Base Method

When both sides can be expressed with the same base, equate the exponents.

Example 6: Same Base

Solve \(3^{2x-1} = 27\)

Express 27 as power of 3: \(3^{2x-1} = 3^3\)

Equate exponents: \(2x - 1 = 3\) → \(x = 2\)

4.2 Using Logarithms

When bases cannot easily match, use logarithms to solve.

Example 7: Using Logarithms

Solve \(5^x = 20\)

Take natural log: \(\ln(5^x) = \ln(20)\)

Power rule: \(x \ln(5) = \ln(20)\)

Solve: \(x = \frac{\ln(20)}{\ln(5)} \approx 1.861\)

5. Solving Logarithmic Equations

Example 8: Solving Log Equations

Solve \(\ln(x + 2) + \ln(x - 1) = \ln(6)\)

  1. Combine left side: \(\ln((x+2)(x-1)) = \ln(6)\)
  2. Remove logs: \((x+2)(x-1) = 6\)
  3. Expand: \(x^2 + x - 2 = 6\)
  4. Solve: \(x^2 + x - 8 = 0\)
  5. Quadratic formula: \(x = \frac{-1 \pm \sqrt{33}}{2}\)

Check domain: need x + 2 > 0 AND x - 1 > 0, so x > 1

Valid solution: \(x = \frac{-1 + \sqrt{33}}{2} \approx 2.37\)

6. Applications

6.1 Exponential Growth and Decay

General Model:
\(y = y_0 e^{kt}\)
where \(y_0\) = initial value, k = growth rate constant
Sign of k:

k > 0 means growth (population, compound interest)
k < 0 means decay (radioactive decay, Newton's Law of Cooling)

Example 9: Continuous Compound Interest

You invest $1000 at 5% annual interest compounded continuously. Find the value after 10 years.

\(A = Pe^{rt} = 1000e^{0.05 \cdot 10} = 1000e^{0.5} \approx \$1,648.72\)

7. Practice Problems

Problem 1

Solve \(2^{x+3} = 5^{2x-1}\). Express your answer in terms of natural logarithms.

Problem 2

Simplify: \(\log_3(54) + \log_3(2) - \log_3(8)\)

Problem 3

A bacteria culture grows exponentially. There are 500 bacteria at t = 0 and 4000 at t = 3 hours. Find an exponential model and use it to predict the population after 5 hours.

Problem 4

Solve: \(\log(x + 3) - \log(x) = 1\) (use common logarithm)

Problem 5

Find the pH of a solution with hydrogen ion concentration \([H^+] = 1 \times 10^{-4}\) M using \(pH = -\log[H^+]\).

Why These Concepts Matter

Domain of Logarithms (x > 0):

There is no real number y such that b^y = x when x ≤ 0 (for b > 0, b ≠ 1). This is why the domain of logarithms is only positive numbers.

Base Restriction (b > 0, b ≠ 1):

For b ≤ 0, b^x is undefined for many values of x (like b = -2 and x = 1/2 gives √(-2)). We require b > 0 to ensure the function is defined for all real numbers.

Sign of k in Transformed Exponentials:

The vertical shift parameter k determines the horizontal asymptote. This is crucial in modeling real-world scenarios where quantities approach but never reach a limiting value (like cooling objects approaching room temperature).

Logarithm Laws:

Logarithm laws are not arbitrary formulas to memorize. They derive directly from exponent laws. Because b^m · b^n = b^(m+n), we get log_b(xy) = log_b(x) + log_b(y). Understanding these derivations prevents rote memorization and builds deeper mathematical insight.
