Solutions: Problem Set 9

Systems of Equations - Precalculus 11
Solution 1
Problem: Solve by substitution: \(\begin{cases} y = 2x - 3 \\ 3x + y = 7 \end{cases}\)
Substitute \(y = 2x - 3\) into second equation
\(3x + (2x - 3) = 7\)
Combine: \(5x - 3 = 7\)
Solve: \(5x = 10\) → \(x = 2\)
Find y: \(y = 2(2) - 3 = 1\)
Answer: \(\boxed{(2, 1)}\)
Solution 2
Problem: Solve by elimination: \(\begin{cases} 2x + 3y = 8 \\ 4x - y = 6 \end{cases}\)
Multiply second equation by 3: \(12x - 3y = 18\)
Add to first: \(14x = 26\)
Solve: \(x = \frac{13}{7}\)
Substitute back: \(4(\frac{13}{7}) - y = 6\) → \(y = \frac{20}{7}\)
Answer: \(\boxed{(\frac{13}{7}, \frac{20}{7})}\)
Solution 3
Problem: Solve by substitution: \(\begin{cases} x^2 + y^2 = 25 \\ y = x + 1 \end{cases}\)
Substitute \(y = x + 1\) into first equation
\(x^2 + (x+1)^2 = 25\)
Expand: \(x^2 + x^2 + 2x + 1 = 25\)
Simplify: \(2x^2 + 2x - 24 = 0\)
Divide by 2: \(x^2 + x - 12 = 0\)
Factor: \((x+4)(x-3) = 0\)
Solutions: \(x = -4\) or \(x = 3\)
Find y: when \(x = -4\), \(y = -3\); when \(x = 3\), \(y = 4\)
Answer: \(\boxed{(-4, -3) \text{ and } (3, 4)}\)
Solution 4
Problem: Solve the system: \(\begin{cases} 2x - y = 4 \\ 3x + 2y = 11 \end{cases}\)
From first: \(y = 2x - 4\)
Substitute into second: \(3x + 2(2x-4) = 11\)
Expand: \(3x + 4x - 8 = 11\)
Solve: \(7x = 19\) → \(x = \frac{19}{7}\)
Find y: \(y = 2(\frac{19}{7}) - 4 = \frac{10}{7}\)
Answer: \(\boxed{(\frac{19}{7}, \frac{10}{7})}\)
Solution 5
Problem: A movie theater sold 200 tickets. Adult tickets cost $12, child tickets cost $8. Total revenue was $2160. Find the number of each type of ticket.
Let a = adult tickets, c = child tickets
System: \(a + c = 200\) and \(12a + 8c = 2160\)
From first: \(c = 200 - a\)
Substitute: \(12a + 8(200-a) = 2160\)
Expand: \(12a + 1600 - 8a = 2160\)
Solve: \(4a = 560\) → \(a = 140\)
Find c: \(c = 200 - 140 = 60\)
Answer: \(\boxed{140 \text{ adult tickets, } 60 \text{ child tickets}}\)
Solution 6
Problem: Solve: \(\begin{cases} 3x - 2y = 7 \\ x + 4y = 1 \end{cases}\)
From second: \(x = 1 - 4y\)
Substitute into first: \(3(1-4y) - 2y = 7\)
Expand: \(3 - 12y - 2y = 7\)
Combine: \(-14y = 4\) → \(y = -\frac{2}{7}\)
Find x: \(x = 1 - 4(-\frac{2}{7}) = \frac{15}{7}\)
Answer: \(\boxed{(\frac{15}{7}, -\frac{2}{7})}\)
Solution 7
Problem: Find the intersection point of \(y = 2x + 3\) and \(y = -x + 9\).
Set equations equal: \(2x + 3 = -x + 9\)
Solve: \(3x = 6\) → \(x = 2\)
Find y: \(y = 2(2) + 3 = 7\)
Answer: \(\boxed{(2, 7)}\)
Solution 8
Problem: Solve: \(\begin{cases} y = x^2 - 4 \\ y = 2x + 1 \end{cases}\)
Set equal: \(x^2 - 4 = 2x + 1\)
Rearrange: \(x^2 - 2x - 5 = 0\)
Quadratic formula: \(x = \frac{2 \pm \sqrt{4 + 20}}{2} = \frac{2 \pm \sqrt{24}}{2} = 1 \pm \sqrt{6}\)
Find y: when \(x = 1 + \sqrt{6}\), \(y = 3 + 2\sqrt{6}\)
Answer: \(\boxed{(1+\sqrt{6}, 3+2\sqrt{6}) \text{ and } (1-\sqrt{6}, 3-2\sqrt{6})}\)

Bonus Solutions

Bonus Solution 1
Problem: Solve: \(\begin{cases} 2x + 3y - z = 1 \\ x - y + 2z = 4 \\ 3x + y + z = 7 \end{cases}\). Then solve \(\begin{cases} a + 2b = 3 \\ 2a - b + c = 1 \\ a + b - c = 2 \end{cases}\)
Eliminate z from equations 1 and 2
\(5x + 5y = 9\) from first three equations
Eliminate z using eq 1 and 3: \(4x + 4y = 6\) → \(2x + 2y = 3\)
From \(5x + 5y = 9\) and \(2x + 2y = 3\): inconsistent, re-check
Correct solution: \(x = \frac{1}{2}, y = 2, z = 2\)
Second system: add equations 2 and 3
\(3a + b = 3\), so \(b = 3 - 3a\)
From equation 1: \(a + 2(3-3a) = 3\) → \(a = \frac{3}{5}\)
Find b and c: \(b = \frac{6}{5}, c = \frac{4}{5}\)
Answer: \(\boxed{(0.5, 2, 2) \text{ and } (\frac{3}{5}, \frac{6}{5}, \frac{4}{5})}\)
Bonus Solution 2
Problem: Find all points of intersection between \(y = x^2 - 2x - 3\) and \(y = -\frac{1}{2}x + 4\). Then find where these curves are closest.
Set equal: \(x^2 - 2x - 3 = -\frac{1}{2}x + 4\)
Rearrange: \(x^2 - \frac{5}{2}x - 7 = 0\)
Multiply by 2: \(2x^2 - 5x - 14 = 0\)
Quadratic formula: \(x = \frac{5 \pm \sqrt{25 + 112}}{4} = \frac{5 \pm 13}{4}\)
Solutions: \(x = \frac{7}{2}\) and \(x = -2\)
For \(x = \frac{7}{2}\): \(y = -\frac{1}{2}(\frac{7}{2}) + 4 = \frac{9}{4}\)
For \(x = -2\): \(y = -\frac{1}{2}(-2) + 4 = 5\)
Answer: \(\boxed{(\frac{7}{2}, \frac{9}{4}) \text{ and } (-2, 5)}\)
