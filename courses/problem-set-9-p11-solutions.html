Problem Set 9 Solutions

Absolute Value Functions and Equations | Precalculus 11

Solutions

Problem 1

Solution:

\[|2x - 3| = 7\]

Two cases:

Case 1: \(2x - 3 = 7 \Rightarrow 2x = 10 \Rightarrow x = 5\)

Case 2: \(2x - 3 = -7 \Rightarrow 2x = -4 \Rightarrow x = -2\)

Solution: \(x = 5, -2\)

Problem 2

Solution:

\[|x + 5| = |x - 3|\]

Both sides non-negative, square both sides:

\[(x + 5)^2 = (x - 3)^2\]

\[x^2 + 10x + 25 = x^2 - 6x + 9\]

\[16x = -16\]

\[x = -1\]

Check: \(|-1 + 5| = 4 = |-1 - 3|\) ✓

Solution: \(x = -1\)

Problem 3

Solution:

\[|3x + 1| = |2x - 4|\]

Case 1: \(3x + 1 = 2x - 4 \Rightarrow x = -5\)

Case 2: \(3x + 1 = -(2x - 4) = -2x + 4 \Rightarrow 5x = 3 \Rightarrow x = \frac{3}{5}\)

Check: \(x = -5\): \(|-14| = |14| = 14\) ✓

Check: \(x = \frac{3}{5}\): \(|3 - 2| = |0.6 - 4| = |2.4| = 2.4\) ✓

Solution: \(x = -5, \frac{3}{5}\)

Problem 4

Solution:

\[2|x - 4| = x + 2\]

RHS must be non-negative: \(x + 2 \geq 0 \Rightarrow x \geq -2\)

Case 1: \(x \geq 4\): \(2(x-4) = x + 2 \Rightarrow 2x - 8 = x + 2 \Rightarrow x = 10\)

Check: \(10 \geq 4\) ✓

Case 2: \(x < 4\): \(-2(x-4) = x + 2 \Rightarrow -2x + 8 = x + 2 \Rightarrow x = 2\)

Check: \(2 < 4\) ✓

Solution: \(x = 2, 10\)

Problem 5

Solution:

\[|x - 2| = 3x + 5\]

RHS must be non-negative: \(3x + 5 \geq 0 \Rightarrow x \geq -\frac{5}{3}\)

Case 1: \(x \geq 2\): \(x - 2 = 3x + 5 \Rightarrow -2x = 7 \Rightarrow x = -\frac{7}{2}\)

Check: \(-\frac{7}{2} < 2\) ✗ Invalid

Case 2: \(x < 2\): \(-(x - 2) = 3x + 5 \Rightarrow -x + 2 = 3x + 5 \Rightarrow -4x = 3 \Rightarrow x = -\frac{3}{4}\)

Check: \(-\frac{3}{4} \geq -\frac{5}{3}\) ✓ and \(-\frac{3}{4} < 2\) ✓

Solution: \(x = -\frac{3}{4}\)

Problem 6

Solution:

Vertex is at \((-2, -3)\)

The vertex of \(|x|\) is at \((0, 0)\)

Shift left 2: \(|x + 2|\) gives vertex at \((-2, 0)\)

Shift down 3: \(|x + 2| - 3\) gives vertex at \((-2, -3)\)

Equation: \(f(x) = |x + 2| - 3\)

Vertex: \((-2, -3)\)

Axis of symmetry: \(x = -2\)

Problem 7

Solution:

\[|2x - 1| < 5\]

\(-5 < 2x - 1 < 5\)

\(-4 < 2x < 6\)

\[-2 < x < 3\]

Solution: \(x \in (-2, 3)\)

Problem 8

Solution:

\[|x + 3| \geq 4\]

Two cases: \(x + 3 \leq -4\) or \(x + 3 \geq 4\)

\[x \leq -7 \quad \text{or} \quad x \geq 1\]

Solution: \(x \in (-\infty, -7] \cup [1, \infty)\)

Problem 9

Solution:

Set \(f(x) = 0\): \(|x - 1| + 2 - 3 = 0\)

\[|x - 1| = 1\]

\[x - 1 = 1 \quad \text{or} \quad x - 1 = -1\]

\[x = 2 \quad \text{or} \quad x = 0\]

X-intercepts: \((0, 0)\) and \((2, 0)\)

Problem 10

Solution:

Vertex: \((-2, 3)\), passes through: \((0, 7)\)

V-shaped: \(f(x) = a|x + 2| + 3\)

Substitute \((0, 7)\): \(7 = a|0 + 2| + 3\)

\[7 = 2a + 3\]

\[a = 2\]

Equation: \(f(x) = 2|x + 2| + 3\)
