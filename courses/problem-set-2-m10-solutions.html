Problem Set 2: Trigonometry

Mathematics 10 - Chapter 2 Solutions

Solutions

Problem 1: Ladder against wall
Given: ladder = 10 m, angle = \(60^\circ\), height up wall = 8 m
Using cosine: \(\cos 60^\circ = \text{adjacent}/\text{hypotenuse} = \text{distance}/10\)
distance = 10 × \(\cos 60^\circ\) = 10 × \(\frac{1}{2}\) = 5 m
Verify with sine: \(\sin 60^\circ = \text{opposite}/\text{hypotenuse} = 8/10 = 0.8\)
But \(\sin 60^\circ = \frac{\sqrt{3}}{2} \approx 0.866\), so there's an inconsistency. The given height (8 m) doesn't match the angle (\(60^\circ\)) and ladder length (10 m).
Answer: 5 m from the wall (theoretical), but the given values are inconsistent.
Problem 2: Tree height
Distance = 30 m, angle = \(25^\circ\)
\(\tan 25^\circ = \text{height}/30\)
height = 30 × \(\tan 25^\circ\) ≈ 30 × 0.4663 = 13.99 m
Answer: Approximately 14 m tall.
Problem 3: Right triangle trig ratios
Legs: 5 cm and 12 cm. Hypotenuse = \(\sqrt{5^2 + 12^2}\) = \(\sqrt{25 + 144}\) = \(\sqrt{169}\) = 13 cm
Angle opposite 5 cm side (call it \(\theta\)): \(\sin \theta = 5/13\), \(\cos \theta = 12/13\), \(\tan \theta = 5/12\)
Answer: \(\sin \theta = 5/13\), \(\cos \theta = 12/13\), \(\tan \theta = 5/12\)
Problem 4: Building height
Distance = 20 m, angle = \(35^\circ\)
height = 20 × \(\tan 35^\circ\) ≈ 20 × 0.7002 = 14.00 m
If 5 m closer (15 m from building):
new height = 15 × \(\tan 35^\circ\) ≈ 15 × 0.7002 = 10.50 m (same building)
Answer: Building ≈ 14 m tall. Angle from 15 m: \(\tan^{-1}(14/15)\) ≈ \(43^\circ\)
Problem 5: Airplane altitude
Observers 40 m apart, angles \(30^\circ\) and \(45^\circ\)
Let h = altitude, d = horizontal distance from first observer
\(\tan 30^\circ = h/d \rightarrow d = h/\tan 30^\circ = h\sqrt{3}\)
\(\tan 45^\circ = h/(40-d) \rightarrow 40-d = h \rightarrow d = 40-h\)
\(h\sqrt{3} = 40-h \rightarrow h(\sqrt{3} + 1) = 40 \rightarrow h = 40/(\sqrt{3} + 1) \approx 40/2.732 \approx 14.64\) m
Answer: Approximately 14.6 m altitude.
Problem 6: Right triangle with hypotenuse 10
Hypotenuse = 10, angle = \(40^\circ\)
Adjacent side = 10 × \(\cos 40^\circ\) ≈ 10 × 0.7660 = 7.66
Opposite side = 10 × \(\sin 40^\circ\) ≈ 10 × 0.6428 = 6.43
Answer: Other sides ≈ 7.66 and 6.43.
Problem 7: Kite string length
Height = 40 m, angle = \(65^\circ\)
\(\sin 65^\circ = \text{opposite}/\text{hypotenuse} = 40/\text{string}\)
string = \(40/\sin 65^\circ\) ≈ 40/0.9063 ≈ 44.13 m
Answer: Approximately 44.1 m.

Bonus Solutions

Bonus Problem 1: Angle Chase
Let tree height = h, distance from A to tree base = d
From point A: \(\tan 30^\circ = h/d \rightarrow h = d \tan 30^\circ = d/\sqrt{3}\)
From point B (20 m closer): \(\tan 45^\circ = h/(d-20) \rightarrow h = d - 20\)
Set equal: \(d/\sqrt{3} = d - 20 \rightarrow d = \sqrt{3}(d - 20) \rightarrow d = \sqrt{3}d - 20\sqrt{3}\)
\(d(1 - \sqrt{3}) = -20\sqrt{3} \rightarrow d = 20\sqrt{3}/(\sqrt{3} - 1) = 10\sqrt{3}(\sqrt{3} + 1)\)
\(h = d - 20 = 10\sqrt{3}(\sqrt{3} + 1) - 20 = 30\sqrt{3} + 10\sqrt{3} - 20 \approx 71.96\) m
Point C is 10 m farther than B, so distance from C = d + 10
Angle from C: \(\tan \theta = h/(d + 10)\)
\(\theta = \tan^{-1}(h/(d + 10)) \approx \tan^{-1}(71.96/81.96) \approx 41.2^\circ\)
Answer: Approximately \(41.2^\circ\)
Bonus Problem 2: Reciprocal Angles
In right triangle ABC with right angle at C: A + B = \(90^\circ\), so B = \(90^\circ\) - A
Given: \(\tan(A) \times \sin(B) = 1\)
Since B = \(90^\circ\) - A: \(\sin(B) = \sin(90^\circ - A) = \cos(A)\)
So: \(\tan(A) \times \cos(A) = 1\)
\(\tan(A) = \sin(A)/\cos(A)\), so: \(\sin(A)/\cos(A) \times \cos(A) = \sin(A) = 1\)
Therefore A = \(90^\circ\), but this contradicts A + B = \(90^\circ\)
Re-check: If B = \(90^\circ\) - A, then \(\sin(B) = \cos(A)\)
\(\tan(A) \times \cos(A) = \sin(A)/\cos(A) \times \cos(A) = \sin(A) = 1\)
This means A = \(90^\circ\), which is impossible for a right triangle
The only solution is when the triangle degenerates: A = \(90^\circ\), B = \(0^\circ\)
Answer: No valid solution in a proper right triangle.
Bonus Problem 3: Nested Triangles
Isosceles triangle with vertex angle \(20^\circ\), base angles = \(80^\circ\) each
Interior point P with angles to base vertices: \(30^\circ\) and \(50^\circ\)
Let the base be AB, with angle at P to A = \(30^\circ\), to B = \(50^\circ\)
Third angle at P: \(180^\circ - 30^\circ - 50^\circ = 100^\circ\)
By Law of Sines in triangle PAB: \(\frac{PA}{\sin 50^\circ} = \frac{PB}{\sin 30^\circ} = \frac{AB}{\sin 100^\circ}\)
Answer: The small triangle has angles \(30^\circ\), \(50^\circ\), \(100^\circ\).
