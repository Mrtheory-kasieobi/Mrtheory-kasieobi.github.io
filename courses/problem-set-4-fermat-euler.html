Problem Set 4: Fermat's Little Theorem and Euler's Theorem

Elementary Number Theory - Week 4 Medium

Problems

Problem 1

Verify Fermat's Little Theorem for \(a = 3\) and \(p = 7\).

Problem 2

Find the remainder when \(2^{100}\) is divided by 11 using Fermat's Little Theorem.

Problem 3

Prove that if \(p\) is prime and \(p \nmid a\), then \(a^{p-1} \equiv 1 \pmod{p}\).

Problem 4

Compute \(\phi(30)\), where \(\phi\) is Euler's totient function.

Problem 5

Verify Euler's theorem for \(a = 5\) and \(n = 12\).

Problem 6

Find the last two digits of \(3^{100}\) using Euler's theorem.

Problem 7

Prove: If \(p\) is prime, then \(\phi(p) = p-1\).

Problem 8

Show that \(\phi(n)\) is even for all \(n > 2\).

Problem 9

Find all integers \(a\) such that \(a^5 \equiv a \pmod{5}\).

Problem 10

Prove: If \(m \mid n\), then \(\phi(m) \mid \phi(n)\)?

Bonus Problems

Bonus Problem 1

Challenge: Show that a composite number \(n\) satisfying \(a^n \equiv a \pmod{n}\) for all integers \(a\) is called a Carmichael number. Verify that 561 is a Carmichael number.

Bonus Problem 2

Challenge: Prove Euler's theorem using Lagrange's theorem from group theory.

Bonus Problem 3

Challenge: Find the smallest positive integer \(k\) such that \(2^k \equiv 1 \pmod{37}\)
