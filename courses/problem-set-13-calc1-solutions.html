Problem Set 13: Final Review - SOLUTIONS

Calculus I - Final Exam Review

Solution Guide

Note: Comprehensive review of all Calculus I topics with detailed solutions.

Problem 1: \(\lim_{x \to \infty} \frac{3x^2 + 2x - 1}{2x^2 + 5}\)

Solution:
Step 1: Divide numerator and denominator by highest power
\(\lim_{x \to \infty} \frac{3 + \frac{2}{x} - \frac{1}{x^2}}{2 + \frac{5}{x^2}}\)
Step 2: Evaluate limit
As \(x \to \infty\): \(\frac{2}{x} \to 0\), \(\frac{1}{x^2} \to 0\), \(\frac{5}{x^2} \to 0\)
Step 3: Result
\(\frac{3 + 0 - 0}{2 + 0} = \frac{3}{2}\)
Final Answer:
\(\boxed{\frac{3}{2}}\)

Problem 2: Find \(\frac{d}{dx}[(x^2 + 1)^{10}]\)

Solution:
Step 1: Apply chain rule
\(\frac{d}{dx}[u^{10}] = 10u^9 \cdot \frac{du}{dx}\) where \(u = x^2 + 1\)
Step 2: Find du/dx
\(\frac{du}{dx} = 2x\)
Step 3: Combine
\(10(x^2+1)^9 \cdot 2x = 20x(x^2+1)^9\)
Final Answer:
\(\boxed{20x(x^2+1)^9}\)

Problem 3: Find critical points of \(f(x) = x^3 - 6x^2 + 9x + 1\)

Solution:
Step 1: Find derivative
\(f'(x) = 3x^2 - 12x + 9\)
Step 2: Factor
\(f'(x) = 3(x^2 - 4x + 3) = 3(x-1)(x-3)\)
Step 3: Set equal to zero
\(x = 1\) or \(x = 3\)
Final Answer:
\(\boxed{x = 1, 3}\)

Problem 4: \(\int_0^1 (3x^2 + 2x + 1) \, dx\)

Solution:
Step 1: Find antiderivative
\(\int (3x^2 + 2x + 1) dx = x^3 + x^2 + x\)
Step 2: Apply FTC
\([x^3 + x^2 + x]_0^1 = (1 + 1 + 1) - 0 = 3\)
Final Answer:
\(\boxed{3}\)

Problem 5: Find \(\frac{d}{dx}[\sin^{-1}(2x)]\)

Solution:
Step 1: Apply chain rule
\(\frac{d}{dx}[\sin^{-1}(u)] = \frac{1}{\sqrt{1-u^2}} \cdot \frac{du}{dx}\) where \(u = 2x\)
Step 2: Find du/dx
\(\frac{du}{dx} = 2\)
Step 3: Combine
\(\frac{2}{\sqrt{1-(2x)^2}} = \frac{2}{\sqrt{1-4x^2}}\)
Final Answer:
\(\boxed{\frac{2}{\sqrt{1-4x^2}}}\) for \(|x| < \frac{1}{2}\)

Problem 6: \(\int \frac{dx}{x \ln x}\) for \(x > 1\)

Solution:
Step 1: Use substitution
Let \(u = \ln x\), \(du = \frac{1}{x}dx\)
Step 2: Rewrite integral
\(\int \frac{1}{u} du\)
Step 3: Integrate
\(\ln|u| + C = \ln(\ln x) + C\)
Final Answer:
\(\boxed{\ln(\ln x) + C}\)

Problem 7: Area between \(y = x^2\) and \(y = x + 2\)

Solution:
Step 1: Find intersection points
\(x^2 = x + 2 \Rightarrow x^2 - x - 2 = 0 \Rightarrow (x-2)(x+1) = 0\)
\(x = -1, 2\)
Step 2: Determine which is on top
At \(x = 0\): \(x + 2 = 2 > 0 = x^2\)
Step 3: Set up integral
\(\text{Area} = \int_{-1}^2 [(x+2) - x^2] dx\)
Step 4: Integrate
\(\left[x + 2x - \frac{x^3}{3}\right]_{-1}^2 = \left[\frac{3x^2}{2} - \frac{x^3}{3}\right]_{-1}^2\)
Step 5: Evaluate
\((\frac{12}{2} - \frac{8}{3}) - (\frac{3}{2} + \frac{1}{3}) = \frac{9}{3} = 3\)
Final Answer:
\(\boxed{3}\)

Problem 8: \(\int \frac{dx}{\sqrt{1-9x^2}}\)

Solution:
Step 1: Factor out constant
\(\int \frac{dx}{\sqrt{1-9x^2}} = \int \frac{dx}{\sqrt{1-(3x)^2}}\)
Step 2: Use arcsine formula
\(\int \frac{du}{\sqrt{1-u^2}} = \sin^{-1}u + C\) with \(u = 3x\)
Final Answer:
\(\boxed{\frac{1}{3}\sin^{-1}(3x) + C}\)

Problem 9: Find the equation of tangent to \(y = \ln x\) at \(x = e^2\)

Solution:
Step 1: Find point
\(y = \ln(e^2) = 2\), point is \((e^2, 2)\)
Step 2: Find derivative
\(\frac{dy}{dx} = \frac{1}{x}\), at \(x = e^2\): slope = \(\frac{1}{e^2}\)
Step 3: Use point-slope form
\(y - 2 = \frac{1}{e^2}(x - e^2)\)
Step 4: Simplify
\(y = \frac{x}{e^2} - 1 + 2 = \frac{x}{e^2} + 1\)
Final Answer:
\(\boxed{y = \frac{x}{e^2} + 1}\)

Problem 10: Find volume of solid obtained by rotating \(y = \sqrt{x}\) about x-axis from \(x = 0\) to \(x = 4\)

Solution:
Step 1: Use disk method
Radius = \(y = \sqrt{x}\)
Step 2: Set up integral
\(V = \pi \int_0^4 (\sqrt{x})^2 dx = \pi \int_0^4 x \, dx\)
Step 3: Integrate
\(\pi \left[\frac{x^2}{2}\right]_0^4 = \pi \cdot \frac{16}{2}\)
Final Answer:
\(\boxed{8\pi}\)

Bonus 1: \(\int \frac{e^{2x}}{1+e^{4x}} \, dx\)

Solution:
Step 1: Use substitution
Let \(u = e^{2x}\), \(du = 2e^{2x}dx\)
Step 2: Rewrite integral
\(\frac{1}{2}\int \frac{du}{1+u^2}\)
Step 3: Integrate
\(\frac{1}{2}\tan^{-1}u + C\)
Step 4: Substitute back
\(\frac{1}{2}\tan^{-1}(e^{2x}) + C\)
Final Answer:
\(\boxed{\frac{1}{2}\tan^{-1}(e^{2x}) + C}\)

Bonus 2: Find absolute extrema of \(f(x) = x^3 - 3x^2 - 9x + 5\) on \([-2, 4]\)

Solution:
Step 1: Find critical points
\(f'(x) = 3x^2 - 6x - 9 = 3(x^2 - 2x - 3) = 3(x-3)(x+1)\)
Critical points: \(x = -1, 3\)
Step 2: Evaluate at critical points and endpoints
\(f(-2) = -8 - 12 + 18 + 5 = 3\)
\(f(-1) = -1 - 3 + 9 + 5 = 10\)
\(f(3) = 27 - 27 - 27 + 5 = -22\)
\(f(4) = 64 - 48 - 36 + 5 = -15\)
Step 3: Identify extrema
Absolute maximum: \(f(-1) = 10\)
Absolute minimum: \(f(3) = -22\)
Final Answer:
\(\boxed{\text{Abs max: } (-1, 10), \text{ abs min: } (3, -22)}\)
