Problem Set 13: Final Review - SOLUTIONS

Calculus I - Week 15

Solution Guide

Problem 1: \(\lim_{x \to \infty} \frac{\ln x}{x}\)

Solution: L'Hôpital: \(\frac{1/x}{1} = \frac{1}{x} \to 0\)

Problem 2: \(\lim_{x \to 0} \frac{\tan x - x}{x^3}\)

Solution: L'Hôpital 3 times: \(\frac{\sec^2 x}{3x} \to \frac{1}{3}\)

Problem 3: \(\frac{d}{dx}[\ln(\sin x)]\)

Solution: Chain rule: \(\frac{1}{\sin x} \cdot \cos x = \cot x\)

Problem 4: \(\frac{d}{dx}[x^{\sin x}]\)

Solution: Logarithmic differentiation. Let \(y = x^{\sin x}\).
\(\ln y = \sin x \ln x\).
\(\frac{y'}{y} = \cos x \ln x + \frac{\sin x}{x}\).
\(y' = x^{\sin x}(\cos x \ln x + \frac{\sin x}{x})\)

Problem 5: \(\int \frac{1}{x^2 + 2x + 2} \, dx\)

Solution: Complete square: \((x+1)^2 + 1\).
\(\tan^{-1}(x+1) + C\)

Problem 6: \(\int_0^{\pi/2} x \sin x \, dx\)

Solution: Integration by parts: \(u = x, dv = \sin x dx\).
\([ -x\cos x]_0^{\pi/2} + \int_0^{\pi/2} \cos x dx = \frac{\pi}{2} + 1\)

Problem 7: Find area between \(y = e^x\) and \(y = x\) on \([0, 1]\)

Solution: \(e^x > x\) on \([0,1]\).
\(\int_0^1 (e^x - x)dx = [e^x - \frac{x^2}{2}]_0^1 = e - \frac{1}{2} - 1 = e - \frac{3}{2}\)

Problem 8: Volume of solid obtained by rotating \(y = \ln x\) about x-axis from 1 to e

Solution: \(V = \pi \int_1^e (\ln x)^2 dx\). Integration by parts twice.
Result: \(\frac{\pi}{2}(2\ln 2 - 1)\)

Problem 9: Position function \(s(t) = t^3 - 6t^2 + 9t\)

Solution: Velocity: \(v(t) = s'(t) = 3t^2 - 12t + 9\).
Acceleration: \(a(t) = s''(t) = 6t - 12\).
At rest when \(v = 0\): \(t = 1, 3\).

Problem 10: Water tower shaped as inverted cone, radius 5m, height 12m

Solution: Similar triangles: \(\frac{r}{h} = \frac{5}{12}\).
Work: \(W = \int_0^{12} \rho g \pi r^2(12-h) dh\) where \(r = \frac{5h}{12}\)

Bonus 1: \(\int \frac{dx}{x \ln x \ln(\ln x)}\)

Solution: Substitution: \(u = \ln(\ln x)\). Result: \(\ln|\ln(\ln x)| + C\)

Bonus 2: Mean Value Theorem for Integrals

Solution: If \(f\) continuous on \([a,b]\), exists \(c \in [a,b]\) such that \(f(c) = \frac{1}{b-a}\int_a^b f(x)dx\).
This is the average value theorem.
