Problem Set 7: Exponential and Logarithmic Functions

Precalculus 12 - Chapter 7 Solutions

Solutions

Problem 1: Solve: \(2^{x+3} = 8^{x-1}\). Express your answer in terms of logarithms.
Express both sides with base 2: \(2^{x+3} = (2^3)^{x-1}\)
Simplify: \(2^{x+3} = 2^{3(x-1)} = 2^{3x-3}\)
Since bases equal: \(x + 3 = 3x - 3\)
Solve: \(3 + 3 = 3x - x\), so \(6 = 2x\)
Answer: \(x = 3\)
Problem 2: Simplify: \(\log_2(8) + \log_2(x) - \log_2(4) + \log_2(x-2)\)
Simplify known logs: \(\log_2(8) = 3\), \(\log_2(4) = 2\)
Expression: \(3 + \log_2(x) - 2 + \log_2(x-2)\)
Combine: \(1 + \log_2(x) + \log_2(x-2)\)
Use product rule: \(1 + \log_2(x(x-2))\)
Further: \(\log_2(2) + \log_2(x^2 - 2x) = \log_2(2(x^2 - 2x))\)
Answer: \(\log_2(2x^2 - 4x)\)
Problem 3: A population grows according to \(P(t) = 1000e^{0.03t}\). When will it reach 2000? What is the doubling time?
Set \(P(t) = 2000\): \(1000e^{0.03t} = 2000\)
Divide: \(e^{0.03t} = 2\)
Take natural log: \(0.03t = \ln(2)\)
Solve: \(t = \frac{\ln(2)}{0.03} \approx \frac{0.693}{0.03} \approx 23.1\) years
Doubling time = \(t_d = \frac{\ln(2)}{r} = \frac{\ln(2)}{0.03} \approx 23.1\) years
Answer: Reaches 2000 at t ≈ 23.1 years, Doubling time ≈ 23.1 years
Problem 4: Solve: \(\ln(x + 5) - \ln(2) = 3\). Check your answer.
Combine logs: \(\ln\left(\frac{x + 5}{2}\right) = 3\)
Exponentiate: \(\frac{x + 5}{2} = e^3\)
Solve: \(x + 5 = 2e^3\)
\(x = 2e^3 - 5\)
Check: \(x + 5 = 2e^3 > 0\), and \(x + 5 = 2e^3 > 0\) ✓
Answer: \(x = 2e^3 - 5\)
Problem 5: Carbon-14 has half-life 5730 years. If 25% remains, how old is the sample? Use \(A = A_0e^{-kt}\) with \(k = \frac{\ln 2}{5730}\).
Given: \(A = 0.25A_0\), so \(\frac{A}{A_0} = 0.25\)
Use: \(0.25 = e^{-kt}\)
Take natural log: \(\ln(0.25) = -kt\)
Note: \(0.25 = \frac{1}{4} = \left(\frac{1}{2}\right)^2\), so two half-lives
Or: \(\ln(0.25) = -2\ln(2)\)
So: \(-2\ln(2) = -kt\), giving \(t = \frac{2\ln(2)}{k}\)
Since \(k = \frac{\ln 2}{5730}\): \(t = \frac{2\ln(2) \times 5730}{\ln 2} = 2 \times 5730\)
Answer: 11,460 years old
Problem 6: Graph \(f(x) = 2^x - 3\) and \(g(x) = \log_2(x + 1)\) on the same axes. Identify domain, range, and asymptotes.
For \(f(x) = 2^x - 3\):
Domain: \((-\infty, \infty)\)
Range: \((-3, \infty)\)
Horizontal asymptote: \(y = -3\)
y-intercept: \(f(0) = 1 - 3 = -2\)
For \(g(x) = \log_2(x + 1)\):
Domain: \(x > -1\), i.e., \((-1, \infty)\)
Range: \((-\infty, \infty)\)
Vertical asymptote: \(x = -1\)
x-intercept: \(g(x) = 0\) when \(x + 1 = 1\), so \(x = 0\)
See graph: F(x) has HA y=-3, G(x) has VA x=-1
Problem 7: Find the inverse of \(f(x) = 3e^{2x-1} + 5\).
Let \(y = 3e^{2x-1} + 5\)
Subtract 5: \(y - 5 = 3e^{2x-1}\)
Divide by 3: \(\frac{y - 5}{3} = e^{2x-1}\)
Take natural log: \(\ln\left(\frac{y - 5}{3}\right) = 2x - 1\)
Add 1: \(\ln\left(\frac{y - 5}{3}\right) + 1 = 2x\)
Divide by 2: \(x = \frac{1}{2}\left(\ln\left(\frac{y - 5}{3}\right) + 1\right)\)
Swap variables: \(y = \frac{1}{2}\left(\ln\left(\frac{x - 5}{3}\right) + 1\right)\)
Answer: \(f^{-1}(x) = \frac{1}{2}\left(\ln\left(\frac{x - 5}{3}\right) + 1\right)\)
Problem 8: Newton's Law of Cooling: \(T(t) = T_s + (T_0 - T_s)e^{-kt}\). A coffee at 95°C cools in a 20°C room. After 10 min it's 75°C. Find k and when it reaches 30°C.
Given: \(T_s = 20\), \(T_0 = 95\), \(T(10) = 75\)
Substitute: \(75 = 20 + (95 - 20)e^{-10k}\)
Simplify: \(55 = 75e^{-10k}\)
Divide: \(\frac{55}{75} = e^{-10k}\)
Take ln: \(\ln\left(\frac{11}{15}\right) = -10k\)
Solve: \(k = -\frac{1}{10}\ln\left(\frac{11}{15}\right) = \frac{1}{10}\ln\left(\frac{15}{11}\right)\)
Calculate: \(k \approx 0.0303\) min⁻¹
Find when \(T = 30\): \(30 = 20 + 75e^{-kt}\)
\(10 = 75e^{-kt}\), so \(e^{-kt} = \frac{2}{15}\)
\(-kt = \ln\left(\frac{2}{15}\right)\)
\(t = -\frac{1}{k}\ln\left(\frac{2}{15}\right) = \frac{1}{0.0303}\ln(7.5) \approx 66.8\) minutes
Answer: \(k = \frac{\ln(15/11)}{10}\), Reaches 30°C at t ≈ 66.8 min

Bonus Solutions

Bonus Problem 1: Find all real solutions to: \(\log_3(x + 1) + \log_3(x - 1) = 2\).
Combine logs: \(\log_3((x+1)(x-1)) = 2\)
Exponentiate: \((x+1)(x-1) = 3^2 = 9\)
Simplify: \(x^2 - 1 = 9\)
Solve: \(x^2 = 10\), so \(x = \pm\sqrt{10}\)
Check domain: Need \(x + 1 > 0\) and \(x - 1 > 0\), so \(x > 1\)
Only valid solution: \(x = \sqrt{10}\)
Answer: \(x = \sqrt{10}\)
Bonus Problem 2: Use the change of base formula to express \(\log_5(7)\) in terms of natural logarithms. Then solve for \(x\) if \(\log_5(7) = \frac{\ln x}{\ln 3}\).
Change of base: \(\log_5(7) = \frac{\ln 7}{\ln 5}\)
Given: \(\frac{\ln 7}{\ln 5} = \frac{\ln x}{\ln 3}\)
Cross multiply: \((\ln 7)(\ln 3) = (\ln 5)(\ln x)\)
Solve for \(\ln x\): \(\ln x = \frac{\ln 7 \cdot \ln 3}{\ln 5}\)
Exponentiate: \(x = e^{\frac{\ln 7 \cdot \ln 3}{\ln 5}}\)
Or: \(x = 7^{\frac{\ln 3}{\ln 5}} = 7^{\log_5(3)}\)
Answer: \(x = 7^{\log_5(3)}\) or numerically ≈ 2.17
