Problem Set 5: Arithmetic Functions and Möbius Inversion

Elementary Number Theory - Week 5 Medium

Problems

Problem 1

Compute \(\sigma(12)\) and \(\phi(12)\), where \(\sigma(n)\) is the sum of divisors function and \(\phi\) is Euler's totient function.

Problem 2

Find \(\sigma(15)\), \(\sigma(16)\), and \(\sigma(17)\).

Problem 3

Prove that \(\phi(p) = p-1\) for any prime \(p\).

Problem 4

Show that \(\sigma(p^k) = 1 + p + p^2 + \cdots + p^k\) for prime \(p\) and \(k \geq 1\).

Problem 5

Compute \(\mu(30)\), \(\mu(31)\), and \(\mu(32)\), where \(\mu\) is the Möbius function.

Problem 6

Prove Möbius inversion formula: If \(g(n) = \sum_{d|n} f(d)\), then \(f(n) = \sum_{d|n} \mu(d) g(n/d)\).

Problem 7

Show that \(\sum_{d|n} \phi(d) = n\) for all \(n \geq 1\).

Problem 8

Find all positive integers \(n\) such that \(\phi(n) = 10\).

Problem 9

Prove: If \(n = p_1^{a_1} \cdots p_k^{a_k}\), then \(\phi(n) = n \prod_{i=1}^k \left(1 - \frac{1}{p_i}\right)\).

Problem 10

Compute \(\sum_{n=1}^{10} \phi(n)\).

Bonus Problems

Bonus Problem 1

Challenge: Prove that \(\sum_{n \leq x} \phi(n) = \frac{3x^2}{\pi^2} + O(x \log x)\).

Bonus Problem 2

Challenge: Show that \(\sum_{n=1}^{\infty} \frac{\mu(n)}{n^s} = \frac{1}{\zeta(s)}\) for \(\operatorname{Re}(s) > 1\).

Bonus Problem 3

Challenge: Find all \(n\) such that \(\phi(n) = \frac{n}{2}\).
